## Opened sources (curl -L + body read, 2026-11-10, Asia/Shanghai UTC+8)

- `wiki-eightpt` / Wikipedia — Eight-point algorithm: https://en.wikipedia.org/wiki/Eight-point_algorithm, HTTP 200, HTML body verified (mw-parser-output). Longuet-Higgins 1981 for E; coplanarity constraint `y′ᵀ E y = 0` in normalized image coordinates; Step 1 row `ỹ`; Step 2 singular vector of the smallest singular value (total least squares, `‖e‖ = 1`); Step 3 internal constraint by SVD (the article keeps `s1, s2, 0`; the toy uses the essential-matrix form `(s, s, 0)` from the Essential matrix article); "Normalized algorithm": ill-conditioned `Y` for pixel coordinates in 0–1000/2000 and points such as `(700, 700) ± (100, 100)`; Hartley 1997: translate to the centroid, scale to a fixed mean distance (rendered as "2" on the fetched page — the root sign is lost in rendering; Hartley's value is √2, which the toy uses and the lesson says so), `F = (T′)ᵀ F̄ T`. 以原文为准.
- `wiki-essential` / Wikipedia — Essential matrix: https://en.wikipedia.org/wiki/Essential_matrix, HTTP 200, HTML body verified. Properties: rotation × skew-symmetric → two equal singular values and one zero; defined up to scale. "Finding one solution": `E = U Σ Vᵀ`, `W`, `R = U W⁻¹ Vᵀ`, `[t]× = U W Σ Uᵀ`; four solution classes, only one with points in front of both cameras; sign of E flipped if `det(R) = −1`. 以原文为准.
- `wiki-epipolar` / Wikipedia — Epipolar geometry: https://en.wikipedia.org/wiki/Epipolar_geometry, HTTP 200, HTML body verified. Epipoles, epipolar lines (all pass through the epipole), epipolar plane; pinhole assumption. 以原文为准.
- `quickgrasp-html` / QuickGrasp, arXiv 2504.19716v2 HTML: https://arxiv.org/html/2504.19716v2, HTTP 200, LaTeXML body read (not a JavaScript shell). §I: "The epsilon ball criterion is often used for multi-fingered hands, while force closure is used for antipodal grasping." §II-D: for two-fingered antipodal grasping the GWS is degenerate, so GWS volume and epsilon radius can mislead (a non-force-closure grasp on a cylinder can outscore the diametric grasp); "For two-fingered antipodal grasping, the best quality criterion is force closure itself"; §III-A robust force-closure metric: perturb contacts over 100 trials, grasp-matrix singular values thresholded at 0.01. Numbers 以论文为准.
- `dexnet2-pdf` / Dex-Net 2.0, arXiv 1703.09312 PDF: https://arxiv.org/pdf/1703.09312.pdf, HTTP 200, 12 pages, body read via pdftotext. Grasp candidates are antipodal contact pairs sampled on the surface; analytic metrics (probability of force closure, robust / expected epsilon quality under pose and friction uncertainty, Monte Carlo) label 6.7 million synthetic point clouds that train a GQ-CNN. Numbers 以论文为准; GQ-CNN / GPU 本页未运行.
- `minwork-pdf` / Minimal Work, arXiv 1909.11226 PDF: https://arxiv.org/pdf/1909.11226.pdf, HTTP 200, 7 pages, body read via pdftotext. Force closure = resist any 6D disturbance with arbitrarily large grasp force; GWS volume and ε-metric widely used; ε = shortest distance from the origin to any GWS facet; GWS typically built with a bounded sum of force magnitudes; reliability metric `q_r` = resist a target wrench without exceeding the maximal closing force (the toy's `lift` stand-in follows this idea in the plane). 以论文为准.

## Toy design

- `eight_point_essential_toy.py` (5.4): two pinhole views, same known K (f 800 px, (640, 360), 1280 × 720), no distortion, no outliers; `x2 = R x1 + t`, `E = [t]× R`; 8° rotation about a random axis; 40 points at 4–8 m plus 40 held-out points. Arms: A raw-pixel eight-point → F → `E = Kᵀ F K`; B Hartley-normalised pixels; C calibrated `K⁻¹` coordinates without Hartley. Same internal-constraint step `(s, s, 0)` for all. One-sided Jacobi SVD on `Y` (never `YᵀY`); four-solution pose recovery with a cheirality vote. **Common random numbers** per (regime, seed): pose, points, held-out points, pixel noise; all arms read the same noisy pixels. Key numbers: noise_free all at round-off, B−A `t_deg` tie (identical on every seed), `e_err` near-tie 2.116e-16±2.124e-15, `epi_px` −2.344e-13±1.451e-13 labelled clear (5/5) but 10⁻¹³ px — disclosed as round-off with no practical value; pixel_noise (1 px) B−A `e_err` −0.0683±0.0510 clear 5/5, `t_deg` −3.8675±2.8843 clear 5/5, `epi_px` −0.4466±0.7592 near-tie (2/5 opposite); clustered (900, 500) ± 100 px: log10(s₁/s₈) 6.54 vs 1.17, B−A `e_err` −0.5187±0.3957, `epi_px` −204.7447±197.8867, `t_deg` −66.0674±59.7247 (all clear 5/5); every noisy C−B line near-tie (tiny_baseline C−B `e_err` 0.4450±0.4568 near-tie although 5/5 same sign, disclosed); tiny_baseline (1 cm): every arm loses the translation direction (90.0 / 64.7 / 87.9°) while `epi_px` ≈ 0.8–1.0 px — metric blind to t, demonstrated in prose and tested.
- `antipodal_force_closure_toy.py` (7.6): planar rigid disc (r 40 mm) or box (80 × 50 mm); two point contacts with Coulomb friction (cone edges `n ± μ t`); wrench `(fx, fy, τ/L)`, L = largest radius; GWS = hull of the four primitive wrenches (sum of normal forces ≤ 1); FC = origin strictly inside; ε = distance to the nearest facet; `lift` stand-in = resist one shared disturbance within total normal force 1 (exact check over wrench triples). Planar on purpose: two-finger point-contact 3D GWS is degenerate (QuickGrasp). Arms: A first candidate; B largest ε on the **perceived** object; C = B's grasp with μ = 0. **Common random numbers** per (regime, seed, trial): true / perceived pose, 8 candidates, disturbance. 5 seeds × 40 trials. Key numbers: disc_noisy_centre B−A fc 0.3500±0.0685 clear 5/5, eps 0.0820±0.0136 clear 5/5, lift 0.1250±0.1173 clear with 1 of 5 opposite (disclosed), 22/200 picks FC only on the perceived disc; box_near_perfect B−A fc **tie (identical on every seed)**, eps 0.0484±0.0071 small but consistent 5/5, lift 0.0550±0.0411 small but consistent (no seed opposite, 1 of 5 equal), L/2 changes B's pick 12/200; box_pose_error fc 0.2100±0.1220 clear 5/5, lift 0.0600±0.0877 near-tie (1/5 opposite), 100/200 picks FC only on the perceived box; C frictionless: 0 on all metrics by construction (disclosed as a model fact).

Label helpers follow #153 (`mean_sd`, `sign_note`, `fmt_pair`, `verdict`) with two changes: values below 5×10⁻⁴ print in e-notation (no hidden signed zero) and `sign_note` says "no seed has the opposite sign, k of 5 equal" when only zeros break the same-sign count.
