## Opened sources (curl -L + body read, 2026-11-09, Asia/Shanghai UTC+8)

- `mr-manipulability` / Lynch & Park, *Modern Robotics*, May 2017 preprint PDF: https://hades.mech.northwestern.edu/images/7/7f/MR.pdf, HTTP 200, body read with `pdftotext -layout` (§5.4 Manipulability, pp. 196–199). Unit joint-rate sphere → ellipsoid `q̇ᵀ(JJᵀ)⁻¹q̇ = 1`; axes = eigenvectors of `A = JJᵀ`, semi-axes `√λᵢ`; volume ∝ `√det(JJᵀ)`; `µ1 = √(λmax/λmin)`, `µ2 = λmax/λmin` (condition number of `A`), `µ3 = √det A`; separate angular / linear ellipsoids; force ellipsoid `B = A⁻¹`, semi-axes `1/√λᵢ`. The book cites Yoshikawa, "Manipulability of robotic mechanisms" (ref. [195]); **that paper was not opened**, so the lesson names the measure via the book's citation only. Numbers 以原文为准.
- `wiki-manipulability` / Wikipedia — Manipulability ellipsoid: https://en.wikipedia.org/wiki/Manipulability_ellipsoid, HTTP 200, HTML body verified (a stub): ellipsoid `{ξ : ξᵀ(JJᵀ)⁻¹ξ ≤ 1}`, axes via SVD of `J`, measure → 0 at a singular configuration.
- `pcl-normal-estimation` / PCL tutorial — Estimating Surface Normals in a PointCloud: https://pcl.readthedocs.io/projects/tutorials/en/latest/normal_estimation.html, HTTP 200, HTML body verified. Least-squares tangent plane → PCA of the nearest-neighbour covariance; sign ambiguous; flip toward a known viewpoint (`flipNormalTowardsViewpoint`, default `(0,0,0)`), not valid for several viewpoints; scale `k` / radius: too large smears edges and suppresses detail; `computePointNormal` returns a curvature from the eigenvalues. Equations on the page are images, so only the prose is used.
- `o3d-pcd-normals` / Open3D tutorial — Point cloud (release): https://www.open3d.org/docs/release/tutorial/geometry/pointcloud.html, HTTP 200, HTML body verified (rendered notebook, not a JS shell). `estimate_normals` with `KDTreeSearchParamHybrid(radius=0.1, max_nn=30)`; covariance analysis gives two opposite candidates ("normal orientation problem"); `orient_normals_to_align_with_direction`, `orient_normals_towards_camera_location`.

The 2R identity `w = σ1σ2 = |det J| = L1L2|sin q2|`, the explicit-Euler error-loop condition `KP·DT < 2` and the neighbourhood-radius estimate `spacing·√(k/π)` are derived in the lessons and checked in `tools/test_b12_manip_normals_toys.py` (finite-difference Jacobian, `√det(JJᵀ)` vs `σ1σ2`, R_CAP threshold, DLS → inverse as λ → 0, Jacobi vs known rotated spectra, exact tilted plane, finite-difference height-field normals); they are not quoted from a source.

## Toy design

- `manipulability_yoshikawa_toy.py` (kinematics-ik): planar 2R stand-in, L1 = 0.116 m, L2 = 0.135 m; position Jacobian only; no joint-position / torque limits or dynamics; joint-rate limit 3 rad/s (uniform scaling). Radial line at 0.05 m/s + 0.5 s hold; resolved rate, explicit Euler DT = 5 ms, KP = 20 1/s (`KP·DT = 0.1 < 2`). Arms A ignore-w (exact inverse) / B keep-w (reference reach capped at R_CAP = 0.2481 m where w = 0.3·L1L2) / C DLS λ = 0.01 m. **Common random numbers**: per (regime, seed) one heading, one actuator-rate-noise sequence (0.02 rad/s) and one tip-measurement-noise sequence (0.1 mm), all shared; no arm skips a noise source. far_from_singularity: A and B identical on every seed (tie: monitor never fires, tested bit-for-bit); C−A final error near-tie / small gap within seed noise; C−A RMS and hold rate small but consistent gaps. near_singularity: B loses on tracking (final 2.393±0.032 mm vs A 0.029±0.014 mm; paired A−B −2.3639±0.0415 mm) but keeps the largest w and calmest hold (6.982±0.726 vs 19.742±1.326 deg/s); B's lowest w over seeds (0.004614) sits just below W_MIN (reshaped reference, not a hard barrier). Metrics blind to torque, payload, orientation, joint limits and collisions.
- `pointcloud_pca_normals_toy.py` (depth-pointcloud): camera at origin, height field `z = 0.40 − A sin(2πx/Λ) sin(2πy/Λ)`, 41×41 grid at 5 mm (±1.25 mm jitter), Gaussian depth noise along z only, no outliers, one viewpoint; analytic truth. Arms A global plane (no per-point normals) / B PCA k = 20 / C PCA k = 4; all oriented toward (0,0,0). **Common random numbers**: per (regime, seed) jitter, every depth-noise draw and 60 interior queries shared. Metrics: mean angle to truth; local plane residual on a shared 12-point evaluation neighbourhood (rewards fitting noise — stated in prose). flat_low_noise: B loses to A on angle (paired B−A 0.7449±0.0397°) while the residual is a small but consistent gap in B's favour (−0.0070±0.0036 mm); ripple_noisy: B wins both; fine_ripple_low_noise: B loses to C on angle (paired B−C 5.2476±0.4954°) while the residual favours B (−0.1522±0.0143 mm, small but consistent gap). Raw-sign flips counted (300/300 on flat for every arm).
- Pair labels are computed in code from unrounded per-seed values: tie only if identical on every seed; near-tie / small gap within seed noise if |mean paired diff| ≤ its sd; small but consistent gap if larger but < 20 % of the smaller arm mean; else clear gap.
