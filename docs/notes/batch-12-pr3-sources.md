## Toy design

- `worldvla_action_mask_toy.py` (world-models-overview): linear-Gaussian stand-in. `s ~ N(0, I3)`, `x = s + σ_obs z`, `a_k = c_k·s` + demo noise 0.10, `c_k = (cos(0.3+0.15k), sin(0.3+0.15k), 0.5)`; ridge (λ = 1e-3 per sample) on 40 demos; one shared 256-bin tokenizer per step (paper's bin rule); decode error `N(0, 0.15²)` added to every arm's predictions at test time (stand-in for the paper's "limited action generalization"). Arms A causal (teacher-forced on the demo's previous action, run on its own previous token) / B masked / C parallel head. **Common random numbers**: per seed one set of demos, test scenes, observation noise `z`, demo noise and decode errors, shared by all arms **and** all four regimes (H1 / H5 / H10 at σ_obs 0.3, H10 at 0.05). Results: H = 1 tie, identical on every seed; H5 chunk RMSE paired A−B 0.0396±0.0114 (small but consistent); H10 0.0634±0.0117 (small but consistent), last-step 0.1015±0.0254 and success −0.0850±0.0296 clear gaps; clean vision RMSE small but consistent gaps (one only 0.0001 above its sd), success near-tie 0.0000±0.0094; B = C identical on every seed in every regime. A's previous-action weight 0.898 / 0.889 noisy vs 0.265 clean. Prose states that without the decode error and with many demos A approaches B (tested: SIGMA_DEC = 0, 1500 demos, |gap| < 0.005), so the toy illustrates the paper's mechanism rather than proving it. Metrics open-loop; blind to decode latency, closed-loop recovery and reactivity.
- `xvla_soft_prompt_toy.py` (cross-embodiment-datasets): bilinear stand-in `a = (Σ h_e[j] T_j) x` + noise 0.10, D = 6, 2-D action. Arms A pooled map / B one-hot ID as fixed prompt (= separate linear heads, the paper's per-domain idea, nothing shared) / C K = 2 learned prompts + shared backbone fitted by ALS (60 sweeps; a local rerun with 200 sweeps moved every printed mean by ≤ 0.0013 and changed no label). Held-out embodiment with 4 demos: A ridge toward pooled, B fresh head ridge toward zero, C frozen backbone + new prompt (2 numbers) — only the paper's warm-up step. **Common random numbers**: per (regime, seed) hardware vectors, maps, demos and noise, adaptation demos and test inputs shared; C's prompt init from its own fixed seed. Results: single_embodiment A = B identical on every seed, C−B seen −0.0007±0.0009 near-tie, C loses on the new embodiment (0.2406±0.2119, labelled clear, |m| only ≈0.03 above sd, C better on 1 of 5 seeds); shared_low_rank C wins both (C−B −0.1122±0.0401 seen, −0.4428±0.3071 new); unrelated_full_rank C loses on seen (0.5499±0.0422), new-embodiment C−B 0.1692±0.1618 small but consistent (only just), other new-embodiment pairs near-ties. Metrics blind to cameras, compute, training stability and closed-loop success.
- Pair labels are computed in code from unrounded per-seed values: tie only if identical on every seed; near-tie / small gap within seed noise if |mean paired diff| ≤ its sd; otherwise consistent (|mean| > sd), called small if < 20 % of the smaller arm mean, else clear gap. The 20 % rule only decides "small". Values that would round to zero are printed in exponent form; no signed zero is printed (tested). Success in the WorldVLA toy is compared as integer counts, so paired means carry no floating residue.

Independent tests: `tools/test_b12_worldvla_xvla_toys.py` (17 tests; also executed by the batch-12 PR3 block in `tools/check_diagrams.mjs`): label rule, no signed zero, ridge closed form, CRN across arms and regimes, tokenizer bins and clamping, H = 1 and masked = parallel bit-identities, previous-action weight vs vision noise, gap vanishing without decode error, one-hot prompt = separate head, ridge prior pull, single-embodiment pooled = head, noiseless low-rank recovery by ALS, unrelated regime rank deficiency.
