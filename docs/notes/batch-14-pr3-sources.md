## Toy design

- `hybridvla_action_ensemble_toy.py` (6.2): two head **error models**, not trained networks; **no integration step** (no time step, the 4-step DDIM sampler is not simulated), so no step-size stability criterion applies (tests check there is no time-step constant). Arms A AR only (64 bins) / B diffusion only / C average when `c > 0.96`, else diffusion. Assumption stated in the prose: the heads' mode errors are independent (HybridVLA conditions AR on diffusion latents, so the paper's heads are probably more correlated). **Common random numbers** per (regime, seed): episode kind, modes, target, both evidence draws, both noise draws, wrong-mode picks; 400 episodes × 5 seeds. Key lines: precision C−A succ 21.8500±1.3647 (clear, 5/5), C−B succ 7.0500±2.0797 (small but consistent, 5/5); semantic C−B succ **tie: identical on every seed** (structural, tested per episode), C−A succ −26.8500±2.5593 (C loses to the AR specialist, clear, 5/5); mixed C−A succ −2.9000±1.5268 (C loses to the best single head, small but consistent, 5/5), C−B succ 2.5000±1.9203 (small but consistent, 1 of 5 opposite sign); easy_precision success **tie** for C−A and C−B, error C−A −4.0500±0.1511 (clear), C−B −0.9276±0.3680 (small but consistent).
- `cot_vla_subgoal_toy.py` (6.3): count tables on a 24-cell track; **no time-step integration** (integer cell moves; tested). Arms A direct chunk / B subgoal every chunk then a task-agnostic direction→action table / C subgoal every 2nd chunk. Both A and B fall back to the task's most common demo action on unseen keys. Subgoal horizon cut at the first stage change (assumption in prose; tested). **Common random numbers** per (regime, seed): task, action demos, 30 other-task demos, videos, 40 test starts. Steps capped at 60 (lower bound for failing arms). Tokens counted at the paper's sizes (cost count, not timing). Key lines: multi_stage_video B−A succ 62.0000±44.8400 (clear, 5/5), steps −15.5750±8.8540 (clear, 5/5), tok 2150.0000±360.7561 (B costs more, clear, 5/5), C−B succ −50.5000±35.1959 (clear, 5/5); multi_stage_no_video B−A succ 2.5000±3.5355 (**near-tie**), tok 3610.0800±111.2090 (**B loses**, clear, 5/5), C−B succ −33.5000±29.9270 (clear, no seed opposite, 1 of 5 equal); multi_stage_action_rich B−A succ 2.5000±5.5902 (**near-tie**, 4 of 5 equal), tok 2128.1200±321.1586 (**B loses**), C−B succ −44.5000±35.8556 (clear, 5/5); single_reach B−A succ 2.5000±3.5355 (**near-tie**), tok 720.3600±127.4848 (**B loses**), C−B succ **tie: identical on every seed**, C−B steps 7.4000±1.8868 (C slower, clear, 5/5).
- Design iterations (disclosed): a first CoT draft let the subgoal look past a stage change, so the direction→action table walked straight past waypoints and B failed everywhere; the cut at the first stage change was added and stated as an assumption. The same draft gave B a "stay" fallback while A had the task prior; both now use the same prior. The stale refresh was set to every 2nd chunk (every 3rd made C fail on every multi-stage seed through the step budget alone). These changes were made after seeing intermediate numbers. The first is a bug fix and the second removes an unequal fallback; `STALE` was picked between 2 and 3 after seeing both runs, because 3 made C fail on every multi-stage seed through the step budget alone. Each change applies to all regimes and arms alike.

No line in either expected file triggers the numerically-zero rule; the rule (|m| and sd < 1e-9, checked after the exact-tie test and before the sd test, no sign count) is implemented, unit-tested on hand-made data and defined in the en/zh prose. No arm diverged or failed to run.

Independent tests: `tools/test_b14p3_hybrid_cot_toys.py` (also executed by the batch-14 PR3 block in `tools/check_diagrams.mjs`): label order and thresholds, no signed zero, no time-step constant / integer cell moves, expected bytes on rerun, common random numbers, the semantic C≡B identity per episode, the worked-example probabilities, subgoal never skipping a stage, token accounting, and C with `STALE = 1` equal to B.
