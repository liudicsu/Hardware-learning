## 选一个 CAD 工具

第三个月的目标，是做出一个能真正装到别的东西上的实体零件：舵机、螺丝、轴承，或者另一块打印件。第一个决定不是某个功能，而是工具。课程的建议很直接：选一个 CAD 软件，然后深入用下去。四个都试一遍看起来很勤奋，但每个软件对草图、<Term id="constraint">约束</Term>、装配的叫法都不同，换来换去消耗的正是你最需要的东西——画图的时间。目标不是收集软件，而是把零件做完。

没有完美的选择，工具之间的差别也没有网上说的那么大。在下面四个工具中的任何一个投入大约 20 小时之后，学习曲线会趋同，工具本身远没有“把零件做完”重要。选一个最符合你处境和约束条件的，然后停止逛街。

| --- | --- | --- | --- |
| Onshape 免费版 | 免费，浏览器内 | 你不在意设计公开；任何电脑都能跑，Chromebook 也行；装配和配合（mate）直接对应固定、转动、滑动这类真实关节 | 免费版的所有文档都是公开的 |
| Fusion 个人版 | 个人非商业用途免费（年收入低于 $1,000） | 你以后想用 CAM 和 3D 打印集成 | 可导入导出的文件类型受限；许可期 1 年，到期可续期（按 Autodesk 官网）；以注册时官网为准 |

## 草图与约束

参数化 CAD 是一个循环：先画 2D 草图，把它变成特征——拉伸（extrude）、旋转（revolve）、切除（cut）、圆角（fillet）——再在结果上画下一张草图。顺序记录在历史里，通常叫特征树（feature tree）。修改早期草图，后面的特征会依次重建。这就是它全部的承诺：模型是一组指令，而不是一个冻住的形状。

草图有<Term id="degrees-of-freedom">自由度</Term>（degree of freedom, DOF）。2D 里一个自由点有 2 个自由度：x 和 y。一条线更多，因为两端都能动。约束（水平、竖直、重合、相等、相切、固定）消除自由度；尺寸也消除自由度，因为它固定了一段距离或一个角度。草图的自由度为 0 时，就是全约束（fully constrained）。多数工具用颜色表示这一点——Onshape、FreeCAD、Fusion 里线条会变黑——或者显示一个降到 0 的计数器。

为什么要这么较真？因为欠约束的草图会在你以后修改别的东西时自行移动：你改一个孔的位置，某条从没标注过的线就滑到一边，支架尺寸随之改变。约束显示不是装饰，它是“可以安全编辑的模型”和“会自己改自己的模型”之间的分界线。

### 从零到全约束

画一个由四条线组成的矩形，端点已经连好。端点连好后，它是一个闭合环，有四个角点；每个角点可以在 x、y 方向移动，所以起始是 8 DOF。然后一条一条加约束：

```text
4 个角点 × 每个 2 DOF = 8 DOF
2 个水平约束           = −2 → 6 DOF
2 个竖直约束           = −2 → 4 DOF
一个角点与原点重合      = −2 → 2 DOF
宽度尺寸 40.2 mm       = −1 → 1 DOF
高度尺寸 20.4 mm       = −1 → 0 DOF（全约束）
```

与原点重合去掉两个自由度，因为它同时固定 x 和 y。宽度和高度各去掉一个，因为每个只固定一段距离。40.2 和 20.4 不是随便写的：它们就是本课后面那块支架板的长度和高度。草图全约束之后，改任何一个尺寸都只会改变一件确定的事。

一个圆有 3 DOF：圆心 x、圆心 y 和半径。所以放一个螺丝孔需要 2 个位置尺寸加 1 个直径。如果孔在中心线上，可以用对称约束省掉一个位置尺寸，但计数思路不变。这也是为什么“看起来位置对了”的孔还没有完成：没有直径和两个位置，它仍然可以移动或改变大小。

几条实战习惯：

- 从<Term id="datum">基准</Term>（datum）标注——原点、中心线、一条参考边——不要边到边串联尺寸。串联尺寸会累积误差，一次修改会沿着链条一路传下去。
- 舵机支架这类零件，用关于中心线的对称约束。一个尺寸控制两边，改尺寸后仍然对称。
- 不要用眼睛把线“看”成水平，要约束它。偏 0.2° 在屏幕上完全看不出来，做出来的支架却是歪的。

反过来是过约束（over-constrained）：两条约束对同一自由度提出矛盾要求，工具会标红或直接拒绝该约束。正确的做法是删掉一条约束，而不是把数字挪来挪去直到警告消失。互相矛盾的尺寸不是更精确，只是坏得更隐蔽。

## 用参数驱动零件

参数化设计真正有用，是当零件由变量驱动，而不是每个特征里手敲数字。改一个尺寸，整个零件更新。在图形界面里，这些叫法不同：Onshape 叫 variables，Fusion 叫 Change Parameters，FreeCAD 用 spreadsheet 或 VarSet。名字不同，思路完全一样。

凡是依赖硬件的尺寸（舵机体、螺丝大小）或依赖打印机的尺寸（间隙），都做成命名参数。派生尺寸写成表达式，绝不重新敲一遍。比如切口长度是 `cut_l = servo_l + 2 * clearance`，而不是另一个需要你手动保持同步的数字。表达式本身就是文档：它说明了这个数为什么是这个数。第 2 课的卡扣外壳和第 6 课的夹爪手指，每个尺寸也都是这样由参数驱动的。

### 拆开支架文件

<CodeSource path="examples/month-3/cad-parametric/servo_bracket.scad" />

```scad
// servo_bracket.scad: a parametric L-bracket for an SG90-class micro servo.
// Every size is a named parameter. Measure YOUR servo with calipers and change
// the numbers at the top; never trust one datasheet drawing.
//   Render:  openscad -o servo_bracket.stl servo_bracket.scad
//   Change one value from the command line:  openscad -D clearance=0.4 -o b.stl servo_bracket.scad

// --- the servo (common SG90 drawing: body 22.2 x 11.8 mm, 32.2 mm across the tabs) ---
servo_l      = 22.2;   // body length, mm
servo_w      = 11.8;   // body width, mm
tab_span     = 32.2;   // length across both mounting tabs, mm
hole_pitch   = 27.5;   // tab screw spacing: not on that drawing; sources say 27-28, measure it
hole_d       = 2.0;    // tab hole for an M2 / self-tapping screw, mm

// --- the printer and the bracket ---
clearance    = 0.3;    // gap on each side of the body (from your tolerance gauge, Lesson 2)
wall         = 3.0;    // plate thickness, mm
margin       = 4.0;    // material left around the cut-out, mm
base_depth   = 26.0;   // how far the foot sticks out, mm (servo body hangs ~16 mm behind the plate)
mount_d      = 3.4;    // foot holes for M3 screws (3 mm + clearance), mm

// --- derived sizes: computed, never typed in twice ---
cut_l   = servo_l + 2 * clearance;
cut_w   = servo_w + 2 * clearance;
plate_l = tab_span + 2 * margin;
plate_h = cut_w + 2 * margin;

echo("cut-out (mm)", cut_l, "x", cut_w);
echo("plate (mm)", plate_l, "x", plate_h, "x", wall);
echo("screw pitch (mm)", hole_pitch, "tab overhang each side (mm)", (tab_span - servo_l) / 2);
assert(hole_pitch > cut_l + hole_d, "screw holes would cut into the body opening");
assert(hole_pitch < tab_span - hole_d, "screw holes would fall off the tabs");

$fn = 32;

module plate() {                       // upright plate that the servo tabs screw onto
  difference() {
    cube([plate_l, wall, plate_h]);
    translate([(plate_l - cut_l) / 2, -1, margin])
      cube([cut_l, wall + 2, cut_w]);
    for (s = [-1, 1])
      translate([plate_l / 2 + s * hole_pitch / 2, -1, plate_h / 2])
        rotate([-90, 0, 0]) cylinder(d = hole_d, h = wall + 2);
  }
}

module foot() {                        // horizontal foot that bolts to the robot
  difference() {
    cube([plate_l, base_depth, wall]);
    for (s = [-1, 1])
      translate([plate_l / 2 + s * 10, base_depth - 5, -1])   // in front of the servo body
        cylinder(d = mount_d, h = wall + 2);
  }
}

module gusset() {                      // triangular rib: stops the plate flexing
  rotate([90, 0, 90]) linear_extrude(wall)
    polygon([[wall, wall], [base_depth, wall], [wall, plate_h * 0.6]]);
}

plate();
foot();
gusset();
translate([plate_l - wall, 0, 0]) gusset();
```

文件里的参数分三组。第一组描述舵机：机身长、机身宽、两片安装耳的总跨度、安装耳孔距和孔径。注释说明了数字的出处，也标出了哪一个不确定。第二组描述打印机和支架：间隙、板厚、切口周围的材料余量、底脚深度和底脚螺丝直径。第三组是派生尺寸：`cut_l`、`cut_w`、`plate_l`、`plate_h` 都由前两组算出来。

`echo()` 打印派生尺寸，让你看到模型实际建成了什么，而不是你以为自己敲了什么。两个 `assert()` 是护栏。第一个在安装耳孔会切进机身开口时停止渲染；第二个在孔会掉出安装耳时停止渲染。断言失败比打印失败便宜得多。

剩下的部分是形状。`plate()` 是立板，带舵机开口和两个安装耳孔。`foot()` 是水平底脚，带两个 M3 孔。`gusset()` 是三角形加强筋，放了两块，一边一块；舵机拉立板时，就是这条筋阻止立板弯曲。`difference()` 从实体块里减掉开口和孔；切割体多伸出的 `-1` 偏移让刀具完全穿过去，而不是留下一层薄皮。`$fn = 32` 控制圆的分段数。

```text
ECHO: "plate (mm)", 40.2, "x", 20.4, "x", 3

```

现在从命令行改一个参数：

```text
$ cd ~/Hardware-learning/examples/month-3/cad-parametric
$ openscad -D clearance=0.15 -o b.stl servo_bracket.scad 2>&1 | grep cut-out
ECHO: "cut-out (mm)", 22.5, "x", 12.1
```

算术就在输出里。长度是 22.2 + 2 × 0.15 = 22.5 mm，宽度是 11.8 + 2 × 0.15 = 12.1 mm。板长仍然是 40.2 mm，因为它只依赖 `tab_span` 和 `margin`：32.2 + 2 × 4.0 = 40.2。凡是依赖切口的尺寸（比如板高）会跟着切口变；不用间隙的尺寸则不动。这就是派生尺寸的意义：改一个输入，只有依赖它的量移动。

## 从数据手册出发

课程的规则很简单：围绕你真正拥有的硬件设计，从数据手册的图出发，而不是凭眼睛。数据手册图不是建议，它是厂家描述的、你必须装进去的外形包络。但它也不是一份完整的制造图，缺的那几个数正是新手翻车的地方。

常见的 TowerPro 风格 SG90 图给出：机身 22.2 × 11.8 mm，两片安装耳总跨度 32.2 mm，总高 31 mm，从底部到安装耳下表面 16 mm。规格表把尺寸四舍五入成“约 22.2 × 11.8 × 31 mm”。这些足够排立板和开口，但它没有给安装耳孔距。

其他来源对这一点并不一致。27.5 mm 是引用最多的数字，某个卖家写 28 mm，还有网站给出 23 × 32 mm 的“孔位图”——而 22.2 mm 的机身、32.2 mm 的耳跨根本装不下这样的孔位。最后这个例子提醒你：网上抄来抄去的数字，需要做一次常识检查。安装耳总共才跨 32.2 mm，机身才 22.2 mm 宽，一个 23 × 32 的图案描述的不是这只舵机。

只看图也能估：每片耳伸出 (32.2 − 22.2) / 2 = 5 mm。孔开在耳中间，就得到 22.2 + 5 = 27.2 mm，接近 27.5。这是一个合理的起点，不是测量值。所以：从图出发，把所有找不到出处的数字在注释里标成估计值——`servo_bracket.scad` 就是这么做的——然后在打印前用卡尺量自己的舵机。

### 用卡尺测量

先把卡尺归零，测三次，取中间值。孔距的算法是：两孔外到外减去一个孔径，或者两孔内到内加上一个孔径。两种都对，因为外到外包含的是两个半孔，合起来正好一个完整直径。

```text
外到外 29.5 mm，孔径 2.0 mm
孔距 = 29.5 − 2.0 = 27.5 mm
```

这组示例读数恰好得到 27.5 mm，也就是引用最多的那个数；你的舵机不一定是这个数。如果你的量出 28.1 mm，就把参数改成 28.1，并把这次测量写进装配记录（fit log）。不要把自己的测量和网站上的数字取平均；要平均，也只平均自己的三次读数。

间隙是图纸给不了的另一个数。图纸是名义尺寸；打印出来的孔通常偏小，外形通常偏大，所以切口每边都要留间隙。这里的 0.3 mm 是占位值，等第 2 课的公差测试件（tolerance gauge）给出你打印机的真实数字后再替换。调得好的机器可能接近这个值；过挤出或象脚明显的机器，0.3 mm 可能远远不够。

输出轴间隙和机身间隙是两回事。支架不能碰到输出轴，也不能碰到转动的舵机臂。矩形切口只避开了机身，但舵机臂会扫过一个圆，螺丝头或加强筋可能正好坐在这个圆里。要在装配里检查运动包络，不能只看静态配合。

断言能提前抓住一类坏数字。把孔距设成 24 mm：

```text
$ cd ~/Hardware-learning/examples/month-3/cad-parametric
$ openscad -D hole_pitch=24 -o b.stl servo_bracket.scad 2>&1 | grep ERROR
ERROR: Assertion '(hole_pitch > (cut_l + hole_d))' failed: "screw holes would cut into the body opening" in file servo_bracket.scad, line 30
```

24 mm 小于 `cut_l + hole_d` = 22.8 + 2.0 = 24.8 mm，所以孔会破进开口，而不是落在实心的安装耳材料里。断言把沉默的坏零件变成响亮的错误，避免你浪费耗材。它不能证明设计正确，只检查了作者想到的那两个关系。该量的还是得量。

## 装配与配合

装配把零件按相对位置放在一起。空间里的自由刚体有 6 个自由度：3 个平移加 3 个旋转。配合（mate）去掉其中一部分，留下其余部分。真实关节也正是这样工作的，所以一个好的装配不只是为了出图。

| 配合 | 剩余 DOF | 真实关节 | 机器人上的例子 |
| --- | --- | --- | --- |
| 固定（fixed） | 0 | 螺栓或焊接接头 | 支架用螺栓固定在底盘上 |
| 转动（revolute） | 1 个旋转 | 铰链、舵机输出 | SO-101 的一节臂 |
| 滑动（slider） | 1 个平移 | 直线导轨、抽屉 | 导轨上的相机滑座 |

每种配合都是两个零件之间的一组几何约束。转动配合让两个零件共用一根轴，比如支架孔的轴线和舵盘轴的轴线，这去掉了 2 个平移和 2 个旋转；它还让两个零件各有一个平面保持重合，这去掉了沿轴线的平移：6 − 5 = 1 个自由度，即绕这根轴的转动。滑动配合同样让零件共用一根轴，但禁止绕轴转动，所以剩下的 1 个自由度是沿轴线的平移。固定配合把 6 个自由度全部去掉。多数工具还允许给配合剩下的自由度加限位；在 Onshape 里，转动配合和滑动配合都可以设最小值和最大值，装配由此知道某个关节只能转比如 ±90°。

理想配合不等于舵机。理想的转动配合没有间隙、没有摩擦，并且正好停在限位上。真实舵机的输出轴在齿轮之间有回差（第 3 课），所以电机不动时，连杆仍能晃动零点几度；它有摩擦，要靠控制器去克服（第 4 课）；它的行程止于舵机的位置范围或机械臂自身的硬限位。在模型里给这部分晃动留出间隙，并把每个配合的限位设成真实关节允许运动的范围，而不是舵机的全行程。

装配要照真实运动方式来做，这样你才能拖动整个行程、看见碰撞。舵机要作为真实零件加入，不要凭眼睛画一个盒子。很多卖家和 SO-101 仓库都发布舵机的 STEP 模型；第 5 课用的就是这些已发布模型。外形尺寸正确的盒子能装进支架，却看不出舵机臂扫到哪里、线从哪里出来。

干涉检查是装配的第二个任务。多数工具能显示两个零件在哪里重叠，有些还能沿运动路径检查碰撞。第 2 课在 OpenSCAD 里用闭合盖子和底座求交，做的也是同一件事：交集只要有体积，就是干涉。在软件里发现只要几分钟；打印完再发现，就是一卷耗材和一个下午。运动仿真（motion study）驱动配合剩下的那个自由度，比如让转动配合的角度从最小值走到最大值，带动与之相连的所有零件，并在途经的每个位置检查是否重叠。多关节机械臂要逐个关节驱动，再驱动几个关节组合起来的姿态，因为有些干涉只在几个关节同时接近限位时才会出现。

## STEP、STL 与 3MF

三种格式几乎覆盖了业余机器人所需的全部情况，而混淆它们会带来很多不必要的痛苦。

STEP 是精确几何：真正的圆柱、平面和边，以实体模型保存。任何 CAD 工具都能编辑它，是分享设计、找加工店做零件的格式。如果朋友想改你的孔径，就发 STEP。

STL 只是三角网格。它没有单位，也没有真正的圆：一个 2 mm 的孔会变成有限个平面的多边形。切片器吃 STL，所以它到处都是，但它是编辑的死胡同。不要把 STL 当成母版文件。

3MF 也是网格，但一个文件里带单位、颜色、多个零件和打印设置。它越来越成为更好的切片格式，尤其当一次打印有多个实体或需要特定摆放方向时。它仍然是输出格式，不是 CAD 模型的替代品。

### 文件里装的是什么

用文本编辑器打开这三种文件，差别一目了然。

STEP 文件（ISO 10303-21）是纯文本：一串编了号的实体，彼此按编号引用。一个 3 mm 的孔以带精确半径的曲面实体保存，文件里还统一声明一次长度单位：

```text
#120 = CYLINDRICAL_SURFACE('', #121, 1.5);
#300 = ( LENGTH_UNIT() NAMED_UNIT(*) SI_UNIT(.MILLI.,.METRE.) );
```

这个圆柱面绕实体 #121 定义的轴线，半径 1.5，单位由单位实体定为毫米。CAD 工具读回来的仍是一个真正的圆柱面，所以文件交换之后孔还能编辑。

STL 文件只是一串三角形。ASCII 格式里，每个三角形是一个 facet，带一个法向量（指向零件外侧的方向）和三个顶点。下面是零件底面上的一个三角形：

```text
facet normal 0 0 -1
  outer loop
    vertex 0 0 0
    vertex 0 10 0
    vertex 10 0 0
  endloop
endfacet
```

文件里任何地方都没有单位。切片器默认按毫米读，所以按英寸导出的零件会小 25.4 倍。二进制格式依次存 80 字节的文件头、4 字节的三角形数量，以及每个三角形 50 字节（法向量和三个顶点共 12 个 4 字节浮点数，外加 2 个备用字节），所以 n 个三角形的二进制 STL 是 84 + 50 × n 字节：下面那个 580 个三角形的支架就是 84 + 50 × 580 = 29,084 字节。

3MF 文件是一个 ZIP 压缩包。包里的 3D/3dmodel.model 是 XML，声明单位，每个顶点只列一次，三角形按顶点序号引用（此处有删节）：

```text
<model unit="millimeter" xmlns="http://schemas.microsoft.com/3dmanufacturing/core/2015/02">
  <resources>
    <basematerials id="1"><base name="PLA red" displaycolor="#FF0000" /></basematerials>
    <object id="2" type="model" pid="1" pindex="0">
      <mesh>
        <vertices><vertex x="0" y="0" z="0" /> ...</vertices>
        <triangles><triangle v1="0" v2="1" v3="2" /> ...</triangles>
      </mesh>
    </object>
  </resources>
  <build><item objectid="2" /></build>
</model>
```

unit 属性确定比例，basematerials 记录颜色，每个 object 是一个独立零件。打印设置不在 3MF 核心规范里。各切片器往压缩包里加自己的文件（PrusaSlicer 加 Metadata/Slic3r_PE.config，OrcaSlicer 和 Bambu Studio 加 Metadata/project_settings.config），所以这些设置只有写入它的那个切片器才能完整读回。

<Quiz id="q7" question="一个有 1000 个三角形的二进制 STL 有多少字节？" answer={50084} unit="字节" explanation="80 字节文件头 + 4 字节三角形数量 + 每个三角形 50 字节：84 + 50 × 1000 = 50,084 字节。" />

规则是：保留 CAD 文件，并导出 STEP，作为母版。STL 和 3MF 是随时可以重新生成的一次性输出。只留 STL，就等于丢掉了带参数的几何源文件，只剩下一份无法回溯的网格。

切片前还要注意孔的边数。OpenSCAD 的 `$fn` 决定一个圆有多少条边；支架用 `$fn = 32`。在这个尺度下，M2 或 M3 的孔够用了，但压配或轴承座可能需要更多。边越多，圆越光滑，文件也越大；边太少，拧螺丝时能感觉到孔是“棱”的。切片前检查网格。

### 切片前检查网格

```python
"""stl_info.py: check an exported STL before you slice it.

Prints the bounding box, the triangle count, whether every edge is shared by exactly two
triangles (a "watertight" mesh that slicers can fill), the volume, and the mass of a solid
print. Reads ASCII or binary STL. No packages needed.
Usage: python3 stl_info.py part.stl [density g/cm^3, default 1.24 for PLA]
"""
import struct
import sys
from collections import Counter


def load(path):
    data = open(path, "rb").read()
    if data[:5] == b"solid" and b"facet" in data[:400]:          # ASCII STL
        nums = [tuple(map(float, line.split()[1:4]))
                for line in data.decode().splitlines() if line.strip().startswith("vertex")]
        return [nums[i:i + 3] for i in range(0, len(nums), 3)]
    (count,) = struct.unpack_from("<I", data, 80)                 # binary STL
    tris = []
    for i in range(count):
        v = struct.unpack_from("<12f", data, 84 + 50 * i)
        tris.append([v[3:6], v[6:9], v[9:12]])
    return tris


def volume(tris):
    """Sum of signed tetrahedra from the origin: exact for a closed mesh."""
    total = 0.0
    for a, b, c in tris:
        total += (a[0] * (b[1] * c[2] - b[2] * c[1])
                  - a[1] * (b[0] * c[2] - b[2] * c[0])
                  + a[2] * (b[0] * c[1] - b[1] * c[0])) / 6.0
    return abs(total)


def main():
    path = sys.argv[1]
    density = float(sys.argv[2]) if len(sys.argv) > 2 else 1.24
    tris = load(path)
    pts = [p for t in tris for p in t]
    lo = [min(p[i] for p in pts) for i in range(3)]
    hi = [max(p[i] for p in pts) for i in range(3)]
    edges = Counter()
    for t in tris:
        for i in range(3):
            edges[tuple(sorted((t[i], t[(i + 1) % 3])))] += 1
    open_edges = sum(1 for n in edges.values() if n != 2)
    vol = volume(tris) / 1000.0                                   # mm^3 -> cm^3
    print(f"size: {hi[0] - lo[0]:.1f} x {hi[1] - lo[1]:.1f} x {hi[2] - lo[2]:.1f} mm")
    print(f"triangles: {len(tris)}, edges not shared by exactly 2: {open_edges}"
          + ("  (watertight)" if open_edges == 0 else "  (NOT watertight: fix before slicing)"))
    print(f"volume: {vol:.2f} cm^3, solid mass at {density} g/cm^3: {vol * density:.1f} g")


if __name__ == "__main__":
    main()
```

```text
$ python3 stl_info.py servo_bracket.stl
```

尺寸对应板长 40.2 mm、底脚深度 26.0 mm、板高 20.4 mm。watertight 表示每条三角形边正好被两个三角形共享，切片器能分清内外并正确填充。体积技巧是把有符号四面体从原点加起来；对闭合网格来说，外面的符号会互相抵消，剩下真实体积。6.1 g 是 100 % 实心零件的质量；切片器按壁厚和 15–20 % 填充估算会更低。

### 双边尺寸链入门

一维装配链的每一环带有双边半宽 `t_i`（尺寸可动 `±t_i`）。累积半宽预测：

| 方法 | 半宽 |
|---|---|
| 最坏情况 | `Σ \|t_i\|` |
| RSS | `√(Σ t_i²)` |
| 基准重根 | 在中间基准之后的**更短**链上做最坏情况 |

**RSS 假设：** 平方和开方预测假定各件误差**相互独立**、**居中**（均值靠近名义值），且近似**正态**。玩具的 `long_skew` 制度正因**违反**这些假设（单侧、非正态累积）而对 RSS 不安全。

**3σ 约定：** 正态蒙特卡洛把每个双边半宽当作 `±t ≈ ±3σ`，故 **`σ = t/3`**。

MMC/LMC 入门：材料条件修饰符会随特征离开最大 / 最小实体而改变可用公差；本玩具停留在双边尺寸累积数学，**不声称** ASME Y14.5 认证。

### 公平设置

`gdt_tolerance_stack_toy.py` 是**合成**的，只用标准库。每个臂在同一制度内共享**同一**名义尺寸链与**同一**双边半宽：

| 臂 | 预测 |
|---|---|
| A_worst_case | 全链 `Σ\|t_i\|` |
| B_rss | 全链 `√(Σ t_i²)` |
| C_datum_reroot | 丢掉中间基准之前的尺寸后做最坏情况 |

制度：`short_chain`（1 维——最坏**等于** RSS，平局）、`long_normal`（6 维，正态 MC）、`long_skew`（相同公差，单侧偏斜 MC——**RSS 覆盖不足**，不安全）。指标：预测半宽 vs 蒙特卡洛命中率。五多种子 mean±sd。

<CodeSource path="examples/month-3/cad-parametric/gdt_tolerance_stack_toy.py" />

```python
#!/usr/bin/env python3
"""Synthetic GD&T bilateral / tolerance stack-up literacy toy. Stdlib only.

Shared nominal chain and shared bilateral half-widths within each regime.
Arms differ only in how the stack prediction is formed:
  A_worst_case   half-width = sum |t_i|  (linear worst-case)
  B_rss          half-width = sqrt(sum t_i^2)  (root-sum-square)
  C_datum_reroot re-root on a mid datum → shorter chain, then worst-case on that chain

Regimes (≥5 Monte Carlo seeds):
  short_chain   1 dim — worst-case == RSS (exact tie)
  long_normal   6 dims, normal MC — RSS covers most hits; worst is wider
  long_skew     6 dims, one-sided skew MC — violates RSS iid/centered/normal assumptions (unsafe)

Not an ASME Y14.5 certification. Real CMM / GD&T drawing lab: 本页未运行.
"""
from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
ARMS = ("A_worst_case", "B_rss", "C_datum_reroot")
N_MC = 2000  # samples per seed


def worst_half(tols: list[float]) -> float:
    return sum(abs(t) for t in tols)


def rss_half(tols: list[float]) -> float:
    return math.sqrt(sum(t * t for t in tols))


def predict(arm: str, tols: list[float], reroot_idx: int) -> float:
    if arm == "A_worst_case":
        return worst_half(tols)
    if arm == "B_rss":
        return rss_half(tols)
    if arm == "C_datum_reroot":
        # Re-root: keep only dims after the datum (shorter stack)
        short = tols[reroot_idx:]
        return worst_half(short)
    raise ValueError(arm)


def mc_stack(
    tols: list[float], seed: int, dist: str
) -> list[float]:
    """Return N_MC signed stack errors for the full chain."""
    rng = random.Random(40_000 + seed)
    out = []
    for _ in range(N_MC):
        s = 0.0
        for t in tols:
            if dist == "normal":
                # 3σ convention: ±t ≈ ±3σ ⇒ σ = t/3
                s += rng.gauss(0.0, abs(t) / 3.0)
            elif dist == "skew":
                # One-sided: exponential excess toward +tol (non-normal)
                # mean shift so mass sits near + side; unsafe for symmetric RSS
                u = rng.random()
                # triangular-ish toward +t
                s += abs(t) * (1.0 - math.sqrt(1.0 - u))  # in [0, t]
            else:
                raise ValueError(dist)
        out.append(s)
    return out


def hit_rate(samples: list[float], half: float) -> float:
    return sum(1 for x in samples if abs(x) <= half + 1e-15) / len(samples)


def mean_sd(xs: list[float]) -> tuple[float, float]:
    mu = sum(xs) / len(xs)
    var = sum((x - mu) ** 2 for x in xs) / (len(xs) - 1)
    return mu, math.sqrt(var)


REGIMES = (
    # name, tols (bilateral half-widths, mm synthetic), reroot_idx, dist
    ("short_chain", [0.15], 0, "normal"),  # 1 dim: worst == RSS (exact tie)
    ("long_normal", [0.05, 0.08, 0.06, 0.10, 0.07, 0.09], 3, "normal"),
    ("long_skew", [0.05, 0.08, 0.06, 0.10, 0.07, 0.09], 3, "skew"),
)


def main() -> None:
    print(
        "Synthetic GD&T / tolerance-stack toy; shared chain/tolerances; "
        "not an ASME Y14.5 certification"
    )
    print(
        f"N_MC={N_MC} seeds={len(SEEDS)}; "
        "A=worst-case sum|t|; B=RSS sqrt(sum t^2); C=datum re-root then worst"
    )
    print(
        "regime arm pred_half_mm mc_hit_rate mean_abs_stack_mm "
        "(pred fixed; hit/mean over seeds mean+-sd)"
    )
    summary = {}
    for reg_name, tols, reroot, dist in REGIMES:
        for arm in ARMS:
            pred = predict(arm, tols, reroot)
            hits, means = [], []
            for seed in SEEDS:
                samples = mc_stack(tols, seed, dist)
                # For C, MC should be on the shortened chain for a fair hit test
                if arm == "C_datum_reroot":
                    samples = mc_stack(tols[reroot:], seed, dist)
                hits.append(hit_rate(samples, pred))
                means.append(sum(abs(x) for x in samples) / len(samples))
            hm, hs = mean_sd(hits)
            mm, ms = mean_sd(means)
            summary[(reg_name, arm)] = (pred, hm)
            print(
                f"{reg_name} {arm} {pred:.4f} {hm:.4f}+-{hs:.4f} "
                f"{mm:.4f}+-{ms:.4f}"
            )
    # Short-chain tie: worst ≈ RSS
    pw = predict("A_worst_case", REGIMES[0][1], REGIMES[0][2])
    pr = predict("B_rss", REGIMES[0][1], REGIMES[0][2])
    print(
        f"short_chain: |worst - RSS| = {abs(pw - pr):.4e} mm "
```

## 过盈配合：压入与热装

本课前面把两个零件之间的重叠都当成错误：装配体的干涉检查找出两个零件共享的体积，然后你去修掉它。**过盈配合**是有意制造重叠。轴做得比孔略大，靠外力压入或靠热胀冷缩装到一起，接头之后靠摩擦保持。本节在同一根轴和同一个轮毂上把它和间隙配合作比较。这**不是**上面 CAD 的干涉（碰撞）检查，也**不是**把 GD&T 公差累积再做一遍：这里没有尺寸链，只有一根轴和一个孔。

<Resource id="wiki-interference-fit" />

**实际打开的来源（已读 HTML 正文）。**

- **Wikipedia — Interference fit** 的内容如下。
  - 过盈配合也叫压入配合或摩擦配合，是两个紧配零件之间的一种连接，零件被推到一起之后“靠摩擦保持在一起”（is held together by friction after the parts are pushed together）。
  - 配合的松紧由过盈量控制，也就是**配合余量**（allowance，相对公称尺寸的计划差值）。余量取决于材料、尺寸和想要的松紧程度，通常查表得到。
  - 它给的例子：10 mm 的不锈钢轴，余量 3–10 µm 时形成紧配合；常见经验值是直径的 0.1–0.25 %（0.15 % 算合理平均值），而且直径越大，每单位直径的余量越小。
  - 装配方法有两种，一是**外力**（压力机，轴和孔的边缘倒角来引导），二是**热胀冷缩**，即加热外件或冷却内件，用很小的力甚至不用力装好，温度恢复后过盈也恢复（热装）。
  - 数字以原文为准。真实压力机、加热炉或扭矩测试**本页未运行**。

### 余量、接触压力与保持扭矩

该页面没有给出压力公式，所以 toy 用的是一个教科书式的替身，并明确这样说：同材料实心轴上的厚壁轮毂，在轮毂孔壁应力达到屈服值之前保持弹性。一般的 Lamé 接触压力关系适用于异材和空心轴，见 RoyMech（Thick-Walled Cylinders；已读正文）。它用界面半径 `c` 处的径向过盈 `δ_r` 写出：

<Formula label="一般 Lamé 接触压力（异材，轴可空心）">p = δ_r / ( c · ( (1/E_h) · ((b² + c²)/(b² − c²) + ν_h) + (1/E_s) · ((c² + a²)/(c² − a²) − ν_s) ) )</Formula>

其中 `a` 是轴的内半径（实心轴为 0），`b` 是轮毂外半径，`E_h`、`ν_h` 与 `E_s`、`ν_s` 分别是轮毂和轴的弹性模量与泊松比。RoyMech 的 `δ_r` 是径向过盈；本页 toy 的 `δ` 是直径过盈，因此 `δ_r = δ / 2`，且 `d = 2c`、`D = 2b`。轴为实心时，轴那一项化为 `(1 − ν_s)/E_s`。当两部分还有相同的 `E` 和相同的 `ν` 时，`ν` 项相消，上式就化成本页 toy 用的公式（下面这条）。

<Formula label="装配后的过盈量（正为过盈，负为间隙）">δ = d_shaft − d_hole</Formula>

<Formula label="接触压力，同材料、实心轴（toy 替身）">p = E · δ / (2 · d) · (1 − (d / D)²)</Formula>

<Formula label="压入或滑移所需的摩擦力，以及保持扭矩">F = μ · p · π · d · L,  T = F · d / 2</Formula>

<Formula label="热装：轮毂加热 ΔT 时孔径的增大量">Δd = α · ΔT · d</Formula>

**算例。** 取 `d = 20 mm`、`D = 40 mm`、`E = 200000 MPa`，每毫米过盈对应的压力为 `200000 / 40 × 0.75 = 3750 MPa`。规定的轻过盈 `δ = 0.025 mm` 给出 `p = 93.75 MPa`；轮毂孔壁的环向应力为 `p × (40² + 20²) / (40² − 20²) = 93.75 × 1.6667 = 156.25 MPa`，是 250 MPa 屈服值的 `0.625`。取 `μ = 0.15`、`L = 15 mm`，冷态压入需要 `F = 0.15 × 93.75 × π × 20 × 15 ≈ 13.25 kN`，装好后能保持 `T = F × 0.01 m ≈ 132.5 N m`，远大于 30 N m 的负载。把轮毂加热 150 K，孔径增大 `12e-6 × 150 × 20 = 0.036 mm`，比公差允许的最大过盈（0.035 mm）还大，所以可以不用力滑进去。过大的配合 `δ = 0.070 mm` 给出 `p = 262.5 MPa`、环向应力 `437.5 MPa`，是屈服值的 `1.75` 倍；用同样的加热温度，热态下仍剩 0.034 mm 的过盈。

**配合的正确性判据。** toy 报告轮毂冷却回来之后的 `δ`，并打印每组的符号范围（间隙、过盈或混合）。对热装，它检查热态下剩下的过盈 `δ − α · ΔT · d`；压入力按这个值计算，只有热态孔径大于轴径时才为零。

**这里没有积分步长。** 每个数都是按零件、按负载循环算出的闭式值；没有时间推进，所以没有需要说明的步长判据。有一个测试检查 toy 里没有步长变量，并检查上面的手算值与它的函数一致。

### 公平设置

`interference_press_fit_toy.py` 是**合成**模型，只用标准库。**模型假设**如下。

- 某个负载循环的扭矩超过保持扭矩时，零件打滑。间隙配合只靠一颗紧定螺钉保持，螺钉的摩擦扭矩按零件从 N(40, 8) N m 抽取。

| 组 | 配合 | 余量 | 装配方式 |
|---|---|---|---|
| A_clear | 间隙配合 + 紧定螺钉 | −0.020 mm（孔大） | 直接滑入 |

| C_heavy | 过大过盈 | +0.070 mm | 与 B 相同的加热 ΔT |

| 情形 | 负载（N m） | 加热 ΔT | 预期（第一次运行之前写下） |
|---|---|---|---|
| loaded_vibration | 30 ± 15 | 150 K | 打滑上 B 稳定胜过 A |

```python
#!/usr/bin/env python3
"""Interference (press / shrink) fit vs clearance fit on one shared shaft and hub.

Synthetic, stdlib only.  Not this lesson's CAD *interference check* (that finds overlapping
volume in an assembly and treats it as a clash to fix); here the overlap is the design intent,
the allowance.  Not the GD&T tolerance-stack toy above (no dimension chain, no RSS).  Real press,
oven, strain gauges or a torque test: 本页未运行.  Wikipedia "Interference fit" statements are
以原文为准; the pressure / stress formulas below are a textbook-style stand-in, not a design code.

Part: steel shaft, nominal diameter D_NOM mm, in a steel hub of outer diameter D_OUT mm over an
engaged length L_ENG mm.  Diameters are measured at the same (room) temperature after assembly.
Model assumptions (a stand-in):
  delta = d_shaft - d_hole                     (> 0 interference, < 0 clearance)
  p     = E * delta / (2 * D_NOM) * (1 - (D_NOM / D_OUT)^2)   contact pressure, MPa
          (thick-walled hub on a solid shaft of the same material, elastic)
  hoop  = p * (D_OUT^2 + D_NOM^2) / (D_OUT^2 - D_NOM^2)       hub bore hoop stress, MPa
  F     = MU * p * pi * D_NOM * L_ENG                          axial force to press / to slide, N
  T     = F * D_NOM / 2 / 1000                                 friction holding torque, N m
If hoop > SIGMA_Y the hub yields: the pressure that the joint keeps is capped at the value that
gives hoop = SIGMA_Y, and the part is counted as yielded (a stand-in for a damaged hub).
Shrink fitting: the hub is heated by DT_OVEN before assembly; its bore grows by
ALPHA * DT_OVEN * D_NOM.  The press force is computed from the interference that remains while
hot, max(0, delta - ALPHA * DT_OVEN * D_NOM); once the hub cools back, delta is the full value.
No integration step: every quantity is a closed-form value per part and per load cycle; there is
no time stepping, so there is no step-size criterion to state (a test checks that the output does
not depend on any step).
Arms (same nominal size, same tolerance draws):
  A_clear   clearance fit, hole ALLOW_A larger than the shaft; held by a set screw whose friction
            torque is drawn per part (N(SET_MEAN, SET_SD) N m); no oven.
  B_fit     specified light interference ALLOW_B, shrink-fitted with the regime's DT_OVEN.
  C_heavy   excessive interference ALLOW_C, same DT_OVEN as B.
Common random numbers: for each (regime, seed), PARTS parts are drawn once: a uniform position in
the tolerance band for the shaft and for the hole (each +-TOL mm around its arm's nominal), the
set-screw torque, and CYCLES load torques per part from N(load mean, load sd) clipped at 0.  The
same draws are used by all three arms.
Metrics per seed: slip % (load cycles whose torque exceeds the holding torque), press force in kN
(mean over parts), hoop / SIGMA_Y (mean over parts), yielded % of parts.
Regimes and expectations, written before the first run:
  loaded_vibration  load 30 +- 15 N m, DT_OVEN 150 K   B consistent win over A on slip
  no_load           load 0,            DT_OVEN 150 K   A and B tie on slip and press force
  press_no_oven     load 30 +- 15 N m, DT_OVEN 0 K     B loses to A on press force (pressed cold);
                                                       C loses to B on stress (yields) and force
  C never beats B on stress or press force.
"""
import math
import random

SEEDS = (0, 1, 2, 3, 4)
D_NOM = 20.0      # mm
D_OUT = 40.0      # mm
L_ENG = 15.0      # mm
E = 200000.0      # MPa
MU = 0.15
SIGMA_Y = 250.0   # MPa, hub yield stand-in
ALPHA = 12e-6     # 1/K, steel
TOL = 0.005       # mm, +- band on each diameter
ALLOW_A = -0.020  # mm, clearance (hole larger)
ALLOW_B = 0.025   # mm, light interference
ALLOW_C = 0.070   # mm, excessive interference
SET_MEAN, SET_SD = 40.0, 8.0  # N m, set screw friction torque
PARTS = 20
CYCLES = 200
NUM_ZERO = 1e-9
ARMS = ("A_clear", "B_fit", "C_heavy")
ALLOW = {"A_clear": ALLOW_A, "B_fit": ALLOW_B, "C_heavy": ALLOW_C}
# name: (load mean N m, load sd N m, DT_OVEN K); written before the first run
REGIMES = {
    "loaded_vibration": (30.0, 15.0, 150.0),
    "no_load": (0.0, 0.0, 150.0),
    "press_no_oven": (30.0, 15.0, 0.0),
}
STREAM = {"loaded_vibration": 0, "no_load": 1, "press_no_oven": 2}

K_P = E / (2.0 * D_NOM) * (1.0 - (D_NOM / D_OUT) ** 2)          # MPa per mm of interference
K_HOOP = (D_OUT ** 2 + D_NOM ** 2) / (D_OUT ** 2 - D_NOM ** 2)  # hoop / p
P_YIELD = SIGMA_Y / K_HOOP                                       # pressure at first yield


def pressure(delta):
    return K_P * delta if delta > 0.0 else 0.0


def axial_force(p):
    return MU * p * math.pi * D_NOM * L_ENG


def torque(p):
    return axial_force(p) * D_NOM / 2.0 / 1000.0


def shared_draws(regime, seed):
    rng = random.Random(1000 * STREAM[regime] + seed)
    mean, sd, _ = REGIMES[regime]
    parts = []
    for _ in range(PARTS):
        u_shaft, u_hole = rng.uniform(-1.0, 1.0), rng.uniform(-1.0, 1.0)
        t_set = max(0.0, rng.gauss(SET_MEAN, SET_SD))
        loads = [max(0.0, rng.gauss(mean, sd)) if sd > 0 else mean for _ in range(CYCLES)]
        parts.append((u_shaft, u_hole, t_set, loads))
    return parts


def part_result(arm, part, dt_oven):
    u_shaft, u_hole, t_set, loads = part
    d_shaft = D_NOM + ALLOW[arm] / 2.0 + TOL * u_shaft
    d_hole = D_NOM - ALLOW[arm] / 2.0 + TOL * u_hole
    delta = d_shaft - d_hole                      # after the hub has cooled back
    oven = dt_oven if arm != "A_clear" else 0.0
    hot_delta = delta - ALPHA * oven * D_NOM      # interference left while the hub is hot
    press = axial_force(pressure(hot_delta))
    p = pressure(delta)
    hoop = K_HOOP * p
    yielded = hoop > SIGMA_Y
    hold = t_set if delta <= 0.0 else torque(min(p, P_YIELD))
    slips = sum(1 for q in loads if q > hold)
    return {"delta": delta, "hot": hot_delta, "slip": 100.0 * slips / len(loads), "press": press / 1000.0,
            "stress": hoop / SIGMA_Y, "yield": 100.0 if yielded else 0.0}


def evaluate(arm, regime, parts):
    dt_oven = REGIMES[regime][2]
    rs = [part_result(arm, pt, dt_oven) for pt in parts]
    out = {k: sum(r[k] for r in rs) / len(rs) for k in ("slip", "press", "stress", "yield")}
    out["dmin"] = min(r["delta"] for r in rs)
    out["dmax"] = max(r["delta"] for r in rs)
    out["hotmax"] = max(r["hot"] for r in rs)
    return out


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


def main():
    print("Synthetic shaft-hub fit: clearance + set screw vs light shrink fit vs excessive interference; not a CAD clash check, not GD&T")
    print(f"D_NOM={D_NOM} mm D_OUT={D_OUT} mm L_ENG={L_ENG} mm E={E:.0f} MPa MU={MU} SIGMA_Y={SIGMA_Y} MPa ALPHA={ALPHA} 1/K TOL=+-{TOL} mm parts={PARTS} cycles={CYCLES} seeds={len(SEEDS)}")
    print(f"allowance A={ALLOW_A} B={ALLOW_B} C={ALLOW_C} mm; p per mm of interference {K_P:.1f} MPa; hoop/p {K_HOOP:.4f}; p at first yield {P_YIELD:.2f} MPa")
    print(f"oven growth at 150 K: ALPHA*DT*D_NOM = {ALPHA * 150.0 * D_NOM:.4f} mm")
    print("no integration step: closed-form pressure, force and torque per part and per load cycle")
```

### 解读各情形

本页标签按以下顺序使用。**打平：每个种子都完全相同**只用于配对的逐种子差值在每个种子上都严格为零；`|配对均值|` 和它的标准差都小于 1e-9 时标为**数值上为零（浮点残差），等同打平**（这种行不打印同号计数）；`|配对均值| ≤ sd` 时为**接近打平、差距很小，在种子噪声之内**；否则是**稳定**差距（`|配对均值| > sd`），`|m|` 小于两组中较小均值的 20 % 时叫**小**，否则叫**明显**；20 % 规则只用来在这两个词之间选择。每条稳定的行都带 5 个种子上的同号计数，符号相反的种子都会报告；只有同号计数不能让差距变成稳定。差距都由未四舍五入的数值计算。配对差值是 B−A 和 C−B。`slip` 是打滑占负载循环的百分比，`press` 是压入力（kN），`stress` 是孔壁环向应力除以屈服值。

- **loaded_vibration** 的结果如下。
  - **过盈配合赢了，差距明显。** B−A 打滑 −25.4300±4.5789 个百分点，5 个种子全部同号。只要负载峰值超过 A 的紧定螺钉摩擦扭矩，螺钉就会松动；B 的配合在整个公差带内能保持约 80 到 186 N m，从不打滑。
