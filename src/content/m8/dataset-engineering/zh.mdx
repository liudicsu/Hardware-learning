```python
#!/usr/bin/env python3
"""dataset_audit.py: audit a tiny synthetic LeRobot-v3-style dataset (stdlib only).

Layout (toy mirror of LeRobotDataset v3 ideas — many episodes per file, metadata
locates episode boundaries; not a Hub download):
  synthetic_lerobot/meta/info.json
  synthetic_lerobot/meta/episodes.jsonl
  synthetic_lerobot/data/chunk-000.json   # list of frame dicts; episode_index field

Reports: episodes per variation, mean duration, action min/max, missing-frame
gaps, and which variations are under-covered (< target_min episodes).
usage: python3 dataset_audit.py
"""
from __future__ import annotations

import json
import math
import os
from collections import defaultdict

HERE = os.path.dirname(os.path.abspath(__file__))
ROOT = os.path.join(HERE, "synthetic_lerobot")
TARGET_MIN = 8  # SmolVLA docs suggest ~50 for real tasks; toy threshold is smaller


def main() -> None:
    with open(os.path.join(ROOT, "meta", "info.json"), encoding="utf-8") as f:
        info = json.load(f)
    fps = float(info["fps"])
    episodes = []
    with open(os.path.join(ROOT, "meta", "episodes.jsonl"), encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                episodes.append(json.loads(line))
    with open(os.path.join(ROOT, "data", "chunk-000.json"), encoding="utf-8") as f:
        frames = json.load(f)

    by_ep: dict[int, list[dict]] = defaultdict(list)
    for fr in frames:
        by_ep[int(fr["episode_index"])].append(fr)

    print(f"dataset {info['repo_id']}  fps={fps:g}  episodes={len(episodes)}  frames={len(frames)}")
    print(f"{'variation':<16} {'n_ep':>5} {'mean_s':>8} {'action_min':>11} {'action_max':>11} {'miss':>5} {'flag':>10}")

    under = []
    for ep_meta in episodes:
        eid = int(ep_meta["episode_index"])
        var = ep_meta["variation"]
        seq = sorted(by_ep[eid], key=lambda r: int(r["frame_index"]))
        # duration from frame count / fps
        dur = len(seq) / fps if fps else float("nan")
        actions = [float(r["action"][0]) for r in seq]  # first joint for range
        amin = min(actions) if actions else float("nan")
        amax = max(actions) if actions else float("nan")
        # missing frames: gaps in frame_index
        idxs = [int(r["frame_index"]) for r in seq]
        miss = 0
        if idxs:
            expect = list(range(idxs[0], idxs[-1] + 1))
            miss = len(expect) - len(idxs)
        ep_meta["_dur"] = dur
        ep_meta["_amin"] = amin
        ep_meta["_amax"] = amax
        ep_meta["_miss"] = miss
        ep_meta["_n"] = len(seq)

    # aggregate by variation
    groups: dict[str, list[dict]] = defaultdict(list)
    for ep_meta in episodes:
        groups[ep_meta["variation"]].append(ep_meta)

    for var in sorted(groups):
        eps = groups[var]
        n = len(eps)
        mean_s = sum(e["_dur"] for e in eps) / n
        amin = min(e["_amin"] for e in eps)
        amax = max(e["_amax"] for e in eps)
        miss = sum(e["_miss"] for e in eps)
        flag = "UNDER" if n < TARGET_MIN else "ok"
        if flag == "UNDER":
            under.append(var)
        print(f"{var:<16} {n:5d} {mean_s:8.2f} {amin:11.3f} {amax:11.3f} {miss:5d} {flag:>10}")

    print(f"target_min_episodes_per_variation={TARGET_MIN}")
    if under:
        print("under_covered: " + ", ".join(under))
    else:
        print("under_covered: (none)")
    # pinned totals for check_diagrams
    print(f"total_variations={len(groups)} total_episodes={len(episodes)}")


if __name__ == "__main__":
    main()
```

## 常见错误

- **录 20 条一模一样的集。** 要数变化，不只数总数。
- **不留评估起始位。** 每个评估姿势都进过训练，成功率就不是评估。
- **以为一集一个文件。** v3 多集共用 Parquet/MP4；边界在元数据。
- **无视缺帧。** `cube_C` 里一个缺口已是数据事故；用审计脚本找，别靠眼扫。

## 日志分块 CRC：查损坏，不是身份认证
字节完好的日志也可能标签差、缺帧或录制规程单薄；有用的演示也可能悄悄损坏。因此把接收阶段的完整性筛查当作独立问题。本玩具用**合成 16 字节块**，不处理真实 Parquet/MP4/bag，**不声称 LeRobotDataset v3 存储这种 CRC**。原有数据审计与留出起始纪律仍保留；这里不是 CAN/EtherCAT 故障隔离、QoS 接收或 Dynamixel 包教程。

<Resource id="crc-polynomial-reference" />

已打开的 CRC 参考是**二手资料**，不是协议标准。CRC 在 GF(2) 上做多项式除法，加法是 XOR，不带整数进位。这里选 **CRC-32/IEEE (CRC-32/ISO-HDLC)**，普通多项式 **0x04C11DB7** 隐含最高32次项；反射位循环用 **0xEDB88320**，初值与 xorout 都为 **0xFFFFFFFF**，按字节顺序、字节内 **LSB-first** 处理。这不是 CRC-32C。ASCII 检查值为 **CRC32("123456789") = 0xCBF43926**；显式逐位实现与 Python 标准库 `zlib.crc32` 交叉核对，不是硬编码答案。

一手延伸阅读：Koopman 与 Chakravarty（2004）的 [Cyclic Redundancy Code (CRC) Polynomial Selection For Embedded Networks](https://users.ece.cmu.edu/~koopman/roses/dsn04/koopman04_crc_poly_embedded.pdf)，DSN 2004，以及 [Philip Koopman 的 CRC 多项式选择表 / CRC Zoo](https://users.ece.cmu.edu/~koopman/crc/)。这些一手资料联系消息长度、Hamming 距离与多项式选择，不改变本玩具声明的 CRC-32/IEEE 约定或已测损坏样本。

### 相同载荷、相同损坏、三个检查器

`dataset_crc_integrity_toy.py` 共享四份 16 字节载荷：全零、全 FF、递增0…15、`(37*j+11) mod256`。每个损坏副本同时交给**不检查**、**sum8=sum(bytes) mod256**、**CRC32**，收到相同字节和原始已存校验值；不检查组忽略标签。本实验中标签、长度和帧边界保持完好，不模拟插入/删除或某种存储/信道的故障概率。损坏完全确定性，因此无需随机种子，也不作五种子不确定性声明。

| 损坏语料 | 个数 | 不检查漏检 | sum8 漏检 | CRC32 漏检 |
|---|---|---|---|---|
| 每个单比特位置 | 512 | 512/512 | 0/512 | 0/512 |
| 跨度2…32 的全一突发，每个可放位置 | 13888 | 13888/13888 | 116/13888 (0.008353) | 0/13888 |
| 相邻平衡字节（+1、−1 mod256） | 32 | 32/32 | 32/32 | 0/32 |
| 刻意构造的32次生成多项式错误，跨度33 | 4 | 4/4 | 0/4 | 4/4 |

**漏检率 = 接受的损坏个数 / 损坏个数**，不是正常记录占比，也不是真实信道概率估计。四个干净块在三个检查器中全部通过。平衡字节暴露求和抵消；33位案例暴露真实 CRC 碰撞，甚至是 sum8 能抓住的案例，不能说 CRC 抓住所有错误或对每种图样都支配任何校验和。

### 为什么任意一个跨度 ≤32 位的突发都能检测

等长、同边界消息比较错误时，CRC 初值 / xorout 的偏置会抵消。跨度L 的突发可写为 `E(x)=x^k B(x)`，首尾非零、`degree(B)=L−1`。生成多项式次数32、常数项1，没有 x 因子；L≤32 时，次数小于32 的非零 B 不可能被它整除。因此能检测**任意一个非零、跨度≤32位的突发**，也包括内部稀疏图样，不限于连续全一。此代数保证不来自有限的全一枚举；不保证抓住合并跨度更长的多个分散突发，也不保证全部长错误。反射33位完整生成多项式掩码 `(0xEDB88320<<1)|1` 就是明确漏检例子。

**CRC ≠ authentication**：能同时改载荷和标签的对手可以重新计算；玩具翻转载荷一位，替换两种标签后，两个检查器均接受。普通无密钥 hash 也不能单独认证可被替换的日志；有此需求应另选合适的认证机制 / 信任模型，不靠这个 CRC 玩具。真实录制/存储故障及集成：**本页未运行**，不宣称密码或安全认证。

```python
#!/usr/bin/env python3
"""Deterministic synthetic logged chunks, NOT a change to LeRobot/Parquet format.
Same original payload/tags and exact corrupted cases for no-check, sum8, CRC32.
CRC-32/IEEE (ISO-HDLC): reflected 0xEDB88320, init/xorout 0xFFFFFFFF.
Payload-only errors; stored tags/length/framing intact in this experiment.
CRC is error detection, NOT authentication: collisions exist and tags can be forged.
"""
import zlib

POLY=0xEDB88320
PAYLOADS=(bytes(16),bytes([255])*16,bytes(range(16)),bytes((37*j+11)%256 for j in range(16)))


def crc32(data):
    state=0xFFFFFFFF
    for byte in data:
        state^=byte
        for _ in range(8):
            state=(state>>1)^(POLY if state&1 else 0)
    return state^0xFFFFFFFF


def sum8(data):
    return sum(data)&0xFF


def flip(data, start, mask):
    result=bytearray(data)
    for j in range(mask.bit_length()):
        if mask>>j&1:
            bit=start+j
            result[bit//8]^=1<<(bit%8)  # Contiguous on the reflected, LSB-first bit stream.
    return bytes(result)


def corpus():
    """All locations; 1-bit errors and all-ones bursts are samples, not all shapes."""
    rows=[]
    for original in PAYLOADS:
        for start in range(128):
            rows.append(("single_bit",original,flip(original,start,1)))
        for length in range(2,33):
            for start in range(129-length):
                rows.append(("burst_2to32",original,flip(original,start,(1<<length)-1)))
        for j in range(0,16,2):
            changed=bytearray(original)
            changed[j]=(changed[j]+1)&255
            changed[j+1]=(changed[j+1]-1)&255
            rows.append(("balanced_bytes",original,bytes(changed)))
        # Full reversed generator spans33 bits: an explicit long-burst collision.
        rows.append(("generator_33",original,flip(original,0,(POLY<<1)|1)))
    return tuple(rows)


def accepted(arm, received, tags):
    if arm=="no_check":
        return True
    if arm=="sum8":
        return sum8(received)==tags[0]
    if arm=="CRC32":
        return crc32(received)==tags[1]
    raise ValueError("unknown integrity arm")


def main():
    assert crc32(b"123456789")==0xCBF43926
    print(f'CRC32_IEEE("123456789")=0x{crc32(b"123456789"):08X}; reflected_poly=0x{POLY:08X}')
    print("init=xorout=0xFFFFFFFF; same4 synthetic16-byte chunks; tags/framing uncorrupted")
    print("group arm corrupted undetected undetected_rate")
    rows=corpus()
    for group in ("single_bit","burst_2to32","balanced_bytes","generator_33"):
        cases=tuple((original,received) for kind,original,received in rows if kind==group)
        for arm in ("no_check","sum8","CRC32"):
            misses=0
            for original,received in cases:
                assert received!=original
                assert crc32(received)==zlib.crc32(received)&0xFFFFFFFF
                misses+=accepted(arm,received,(sum8(original),crc32(original)))
            print(f"{group} {arm} {len(cases)} {misses} {misses/len(cases):.6f}")
    clean=[sum(accepted(arm,p,(sum8(p),crc32(p))) for p in PAYLOADS) for arm in ("no_check","sum8","CRC32")]
    print(f"clean acceptance: no_check={clean[0]}/4 sum8={clean[1]}/4 CRC32={clean[2]}/4")
    original=PAYLOADS[2];tampered=flip(original,0,1)
    forged=(sum8(tampered),crc32(tampered))
    print(f"attacker_recomputed_tags: sum8_accept={int(accepted('sum8',tampered,forged))} CRC32_accept={int(accepted('CRC32',tampered,forged))}")
    print("CRC detects ANY single nonzero burst span<=32 bits by polynomial degree, not by this finite enumeration")
    print("33-bit collision is deliberate; CRC != authentication; no random/channel-probability claim")
    print("Real recording/storage faults and format integration: 本页未运行")


if __name__=="__main__":
    main()
```

### 练习

1. 用逐位函数与 zlib 双重核对 0xCBF43926，区分反射多项式、初值、xorout 与 CRC-32C。
2. 为三个检查器重建同一损坏语料和分母，解释116 个 sum8 突发漏检及全部32 个平衡字节漏检。
3. 推导任意单突发≤32 的次数论证，再看33 位碰撞；为什么有限枚举本身不是证明？
4. 篡改后重算标签并说明认证为何失败；列出覆盖之外的边界、缺块、标签与实际格式集成。

#!/usr/bin/env python3
"""Synthetic heterogeneous co-training stand-in for a pi0.5-style mixture.

Stdlib only. Shared scenes, instructions and evaluation features are drawn
once per (regime, seed) and then read by every arm (common random numbers).

Arm A uses only target-robot / in-domain action features. Arm B is a
co-training mixture stand-in: declared target-robot, web, subtask and
other-robot weights. Arm C uses the web / subtask / other-robot features
with no target-robot actions.

This is a linear lookup stand-in, not pi0.5 weights and not a house rollout.
It is not Knowledge Insulation, not a pi0 10-step flow-matching convention,
not a FAST-then-flow architecture, and not RTC latency. Paper first-phase
non-target-data percentage and house-clean figures are 以论文为准 and are
not toy outputs. GPU / pi0.5 weights / real homes: 本页未运行.

Regimes and parameters were written before the first run.

Labels: tie = identical on every seed; numerically zero = |paired mean| and sd
both < 1e-9; |m| <= sd = near-tie; |m| > sd = consistent gap (small if |m| < 20 %
of the smaller arm mean, else clear), with a sign count. ROUND_HALF_UP output.
"""
import math
import random
from decimal import ROUND_HALF_UP, Decimal, getcontext

getcontext().rounding = ROUND_HALF_UP

SEEDS = (0, 1, 2, 3, 4)
NUM_ZERO = 1e-9

# Declared toy parameters (linear lookup stand-in, not paper percentages).
N_SCENES = 25
BIAS = 0.0500
SIG = 0.0800
CLIP_LO = 0.0000
CLIP_HI = 1.0000
W_TARGET = 0.4000
W_WEB = 0.2000
W_SUBTASK = 0.2500
W_OTHER = 0.1500
W_TARGET_A = 1.0000
W_TARGET_C = 0.0000

# In-domain lab-like: target and co-train features are similarly informative.
# OOD / new-home stand-in: target-robot features drop; web / subtask stay useful.
MUS = {
    "in_domain": {"target": 0.7500, "web": 0.7500, "subtask": 0.7500, "other": 0.7500},
    "ood_new_home": {"target": 0.3500, "web": 0.6000, "subtask": 0.6000, "other": 0.5500},
}

METRICS = ("success",)
ARMS = ("A_target_only", "B_cotrain", "C_no_target")
PAIRS = (("B", "A"), ("C", "B"), ("C", "A"))

# name: declared expectation; written before the first run
REGIMES = {
    "in_domain": "A and B may near-tie on success (lab-like in-domain task) - keep",
    "ood_new_home": "B consistently above A on success (OOD new-home stand-in) - keep",
}

REGIME_IDS = {"in_domain": 0, "ood_new_home": 1}

C_EXPECT = "C loses to B on success (no target-robot actions) - keep"

ALT_SIG = 0.1200
ALT_W = {"target": 0.5000, "web": 0.2000, "subtask": 0.2000, "other": 0.1000}


def mean_sd(xs):
    if all(x == xs[0] for x in xs):
        return xs[0], 0.0
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-4:
        return format(Decimal(repr(x)), ".3e")
    s = format(Decimal(repr(x)), ".4f")
    return "0.0000" if s == "-0.0000" else s


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def clip(x, lo=CLIP_LO, hi=CLIP_HI):
    return lo if x < lo else hi if x > hi else x


def draw_features(regime, seed, sig=SIG):
    rng = random.Random(seed + 1000 * REGIME_IDS[regime] + int(round(1000 * sig)))
    if sig == SIG:
        rng = random.Random(seed + 1000 * REGIME_IDS[regime])
    mus = MUS[regime]
    scenes = []
    for _ in range(N_SCENES):
        target = clip(rng.gauss(mus["target"], sig))
        web = clip(rng.gauss(mus["web"], sig))
        subtask = clip(rng.gauss(mus["subtask"], sig))
        other = clip(rng.gauss(mus["other"], sig))
        scenes.append((target, web, subtask, other))
    return scenes


def score_of(feat, weights):
    target, web, subtask, other = feat
    raw = (
        BIAS
        + weights["target"] * target
        + weights["web"] * web
        + weights["subtask"] * subtask
        + weights["other"] * other
    )
    return clip(raw)


def arm_weights():
    return {
        "A_target_only": {"target": W_TARGET_A, "web": 0.0, "subtask": 0.0, "other": 0.0},
        "B_cotrain": {"target": W_TARGET, "web": W_WEB, "subtask": W_SUBTASK, "other": W_OTHER},
        "C_no_target": {"target": W_TARGET_C, "web": W_WEB, "subtask": W_SUBTASK, "other": W_OTHER},
    }


def run_regime(regime, seed, sig=SIG, b_weights=None):
    scenes = draw_features(regime, seed, sig=sig)
    weights = arm_weights()
    if b_weights is not None:
        weights["B_cotrain"] = b_weights
        weights["C_no_target"] = {
            "target": W_TARGET_C,
            "web": b_weights["web"],
            "subtask": b_weights["subtask"],
            "other": b_weights["other"],
        }
    out = {}
    for arm, w in weights.items():
        suc = sum(score_of(feat, w) for feat in scenes) / float(N_SCENES)
        out[arm] = {"success": suc}
    return out


def main():
    w_sum = W_TARGET + W_WEB + W_SUBTASK + W_OTHER
    c_sum = W_WEB + W_SUBTASK + W_OTHER
    print(
        "Heterogeneous co-training toy: shared synthetic scenes / instructions / "
        "eval under common random numbers (linear lookup stand-in, not pi0.5 "
        "weights, not a house rollout)"
    )
    print(
        "Paper first-phase non-target-data percentage and house-clean figures "
        "以论文为准 and are not toy outputs; GPU / pi0.5 weights / real homes: "
        "本页未运行"
    )
    print(
        f"seeds={len(SEEDS)} n_scenes={num(float(N_SCENES))} bias={num(BIAS)} "
        f"sig={num(SIG)} clip_lo={num(CLIP_LO)} clip_hi={num(CLIP_HI)} "
        f"w_target={num(W_TARGET)} w_web={num(W_WEB)} w_subtask={num(W_SUBTASK)} "
        f"w_other={num(W_OTHER)} w_sum={num(w_sum)} "
        f"w_target_A={num(W_TARGET_A)} w_target_C={num(W_TARGET_C)} "
        f"c_used_weight_sum={num(c_sum)} "
        f"mu_in_domain_target={num(MUS['in_domain']['target'])} "
        f"mu_in_domain_web={num(MUS['in_domain']['web'])} "
        f"mu_in_domain_subtask={num(MUS['in_domain']['subtask'])} "
        f"mu_in_domain_other={num(MUS['in_domain']['other'])} "
        f"mu_ood_target={num(MUS['ood_new_home']['target'])} "
        f"mu_ood_web={num(MUS['ood_new_home']['web'])} "
        f"mu_ood_subtask={num(MUS['ood_new_home']['subtask'])} "
        f"mu_ood_other={num(MUS['ood_new_home']['other'])}"
    )
    print("Regimes and parameters were written before the first run")
    print(
        "Common random numbers: the scene / instruction / eval feature draws "
        "are shared across arms at each regime and seed"
    )
    print(f"hand_calc n_scenes = {num(float(N_SCENES))}")
    print(
        f"hand_calc B mixture weights {num(W_TARGET)} + {num(W_WEB)} + "
        f"{num(W_SUBTASK)} + {num(W_OTHER)} = {num(w_sum)}"
    )
    print(
        f"hand_calc C used-weight sum {num(W_WEB)} + {num(W_SUBTASK)} + "
        f"{num(W_OTHER)} = {num(c_sum)} (w_target_C = {num(W_TARGET_C)}, not renormalized)"
    )
    print(f"hand_calc bias = {num(BIAS)} sig = {num(SIG)} clip = {num(CLIP_LO)} to {num(CLIP_HI)}")
    print(
        f"hand_calc in_domain mus target/web/subtask/other = "
        f"{num(MUS['in_domain']['target'])}, {num(MUS['in_domain']['web'])}, "
        f"{num(MUS['in_domain']['subtask'])}, {num(MUS['in_domain']['other'])}"
    )
    print(
        f"hand_calc ood_new_home mus target/web/subtask/other = "
        f"{num(MUS['ood_new_home']['target'])}, {num(MUS['ood_new_home']['web'])}, "
        f"{num(MUS['ood_new_home']['subtask'])}, {num(MUS['ood_new_home']['other'])}"
    )
    print(
        f"hand_calc in_domain expected A ~ {num(BIAS)} + {num(W_TARGET_A)} * "
        f"{num(MUS['in_domain']['target'])} = {num(BIAS + W_TARGET_A * MUS['in_domain']['target'])}"
    )
    print(
        f"hand_calc in_domain expected B ~ {num(BIAS)} + {num(w_sum)} * "
        f"{num(MUS['in_domain']['target'])} = {num(BIAS + w_sum * MUS['in_domain']['target'])}"
    )
    ood = MUS["ood_new_home"]
    b_ood = BIAS + W_TARGET * ood["target"] + W_WEB * ood["web"] + W_SUBTASK * ood["subtask"] + W_OTHER * ood["other"]
    a_ood = BIAS + W_TARGET_A * ood["target"]
    c_ood = BIAS + W_WEB * ood["web"] + W_SUBTASK * ood["subtask"] + W_OTHER * ood["other"]
    print(f"hand_calc ood_new_home expected A ~ {num(a_ood)}")
    print(f"hand_calc ood_new_home expected B ~ {num(b_ood)}")
    print(f"hand_calc ood_new_home expected C ~ {num(c_ood)}")

    for r, exp in REGIMES.items():
        print(f"declared {r}: {exp}")
        print(f"declared {r} C: {C_EXPECT}")

    store = {r: {arm: {m: [] for m in METRICS} for arm in ARMS} for r in REGIMES}
    alt_sig = {r: {arm: {m: [] for m in METRICS} for arm in ARMS} for r in REGIMES}
    alt_w = {r: {arm: {m: [] for m in METRICS} for arm in ARMS} for r in REGIMES}
    for seed in SEEDS:
        for r in REGIMES:
            official = run_regime(r, seed)
            sig_run = run_regime(r, seed, sig=ALT_SIG)
            w_run = run_regime(r, seed, b_weights=ALT_W)
            for arm in ARMS:
                for m in METRICS:
                    store[r][arm][m].append(official[arm][m])
                    alt_sig[r][arm][m].append(sig_run[arm][m])
                    alt_w[r][arm][m].append(w_run[arm][m])

    for r in REGIMES:
        print(f"regime {r}")
        for arm in ARMS:
            for m in METRICS:
                mu, sd = mean_sd(store[r][arm][m])
                print(f"  {arm} {m}: {num(mu)}+-{num(sd)}")
        for left, right in PAIRS:
            la = [a for a in ARMS if a.startswith(left + "_")][0]
            ra = [a for a in ARMS if a.startswith(right + "_")][0]
            for m in METRICS:
                print(f"  paired {left}-{right} {m}: {verdict(store[r][la][m], store[r][ra][m])}")

    print("alternatives on the same seeds (not adopted):")
    print(f"  alternative sig={num(ALT_SIG)}")
    for r in REGIMES:
        print(f"  regime {r}")
        for left, right in (("B", "A"), ("C", "B")):
            la = [a for a in ARMS if a.startswith(left + "_")][0]
            ra = [a for a in ARMS if a.startswith(right + "_")][0]
            print(
                f"    paired {left}-{right} success: "
                f"{verdict(alt_sig[r][la]['success'], alt_sig[r][ra]['success'])}"
            )
    print(
        f"  alternative B weights target={num(ALT_W['target'])} web={num(ALT_W['web'])} "
        f"subtask={num(ALT_W['subtask'])} other={num(ALT_W['other'])}"
    )
    for r in REGIMES:
        print(f"  regime {r}")
        for left, right in (("B", "A"), ("C", "B")):
            la = [a for a in ARMS if a.startswith(left + "_")][0]
            ra = [a for a in ARMS if a.startswith(right + "_")][0]
            print(
                f"    paired {left}-{right} success: "
                f"{verdict(alt_w[r][la]['success'], alt_w[r][ra]['success'])}"
            )


if __name__ == "__main__":
    main()
