Month 6 taught you to evaluate a policy on a fixed list of starts. Month 8 starts one step earlier: the dataset that makes that evaluation honest. A pretrained VLA is only as good as the episodes you fine-tune on. This lesson writes a **variation × repetition** recording protocol, reads what LeRobotDataset v3 changed about on-disk layout, audits a tiny synthetic fixture on the CPU, and links evaluation starts back to Month 6. Open X-Embodiment (arXiv 2310.08864) is the large-scale reason people care about shared formats at all.

## Variation × repetition

A single tidy demo that always starts from the same pose teaches a brittle policy. The SmolVLA docs suggest starting around **~50 episodes** for one task; their pick-and-place example used **5 cube positions × 10 episodes**. Under **25** episodes was not enough in that setup. Treat that as a starting rule of thumb, then write your own grid:

| variation factor | levels | episodes per level |
|------------------|--------|--------------------|
| object pose      | 5      | 10                 |
| lighting         | …      | …                  |

Fill `examples/month-8/dataset-engineering/protocol.md` before the first teleop session. Exclusion rules belong on the same page: lost tracking, e-stop, collision, teleop freeze, wrong instruction spoken.

## LeRobotDataset v3

Hugging Face's LeRobot **dataset v3** docs describe a layout where **metadata locates episode boundaries**, and **many episodes can share one Parquet and one MP4**. That is the opposite of "one file per episode". For large Hub datasets you stream with `StreamingLeRobotDataset` instead of downloading everything first. The toy in this lesson mirrors the idea with JSON: `meta/episodes.jsonl` names each episode and variation; `data/chunk-000.json` holds frames from several episodes with an `episode_index` field.

```python
#!/usr/bin/env python3
"""dataset_audit.py: audit a tiny synthetic LeRobot-v3-style dataset (stdlib only).

Layout (toy mirror of LeRobotDataset v3 ideas — many episodes per file, metadata
locates episode boundaries; not a Hub download):
  synthetic_lerobot/meta/info.json
  synthetic_lerobot/meta/episodes.jsonl
  synthetic_lerobot/data/chunk-000.json   # list of frame dicts; episode_index field

Reports: episodes per variation, mean duration, action min/max, missing-frame
gaps, and which variations are under-covered (< target_min episodes).
usage: python3 dataset_audit.py
"""
from __future__ import annotations

import json
import math
import os
from collections import defaultdict

HERE = os.path.dirname(os.path.abspath(__file__))
ROOT = os.path.join(HERE, "synthetic_lerobot")
TARGET_MIN = 8  # SmolVLA docs suggest ~50 for real tasks; toy threshold is smaller


def main() -> None:
    with open(os.path.join(ROOT, "meta", "info.json"), encoding="utf-8") as f:
        info = json.load(f)
    fps = float(info["fps"])
    episodes = []
    with open(os.path.join(ROOT, "meta", "episodes.jsonl"), encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                episodes.append(json.loads(line))
    with open(os.path.join(ROOT, "data", "chunk-000.json"), encoding="utf-8") as f:
        frames = json.load(f)

    by_ep: dict[int, list[dict]] = defaultdict(list)
    for fr in frames:
        by_ep[int(fr["episode_index"])].append(fr)

    print(f"dataset {info['repo_id']}  fps={fps:g}  episodes={len(episodes)}  frames={len(frames)}")
    print(f"{'variation':<16} {'n_ep':>5} {'mean_s':>8} {'action_min':>11} {'action_max':>11} {'miss':>5} {'flag':>10}")

    under = []
    for ep_meta in episodes:
        eid = int(ep_meta["episode_index"])
        var = ep_meta["variation"]
        seq = sorted(by_ep[eid], key=lambda r: int(r["frame_index"]))
        # duration from frame count / fps
        dur = len(seq) / fps if fps else float("nan")
        actions = [float(r["action"][0]) for r in seq]  # first joint for range
        amin = min(actions) if actions else float("nan")
        amax = max(actions) if actions else float("nan")
        # missing frames: gaps in frame_index
        idxs = [int(r["frame_index"]) for r in seq]
        miss = 0
        if idxs:
            expect = list(range(idxs[0], idxs[-1] + 1))
            miss = len(expect) - len(idxs)
        ep_meta["_dur"] = dur
        ep_meta["_amin"] = amin
        ep_meta["_amax"] = amax
        ep_meta["_miss"] = miss
        ep_meta["_n"] = len(seq)

    # aggregate by variation
    groups: dict[str, list[dict]] = defaultdict(list)
    for ep_meta in episodes:
        groups[ep_meta["variation"]].append(ep_meta)

    for var in sorted(groups):
        eps = groups[var]
        n = len(eps)
        mean_s = sum(e["_dur"] for e in eps) / n
        amin = min(e["_amin"] for e in eps)
        amax = max(e["_amax"] for e in eps)
        miss = sum(e["_miss"] for e in eps)
        flag = "UNDER" if n < TARGET_MIN else "ok"
        if flag == "UNDER":
            under.append(var)
        print(f"{var:<16} {n:5d} {mean_s:8.2f} {amin:11.3f} {amax:11.3f} {miss:5d} {flag:>10}")

    print(f"target_min_episodes_per_variation={TARGET_MIN}")
    if under:
        print("under_covered: " + ", ".join(under))
    else:
        print("under_covered: (none)")
    # pinned totals for check_diagrams
    print(f"total_variations={len(groups)} total_episodes={len(episodes)}")


if __name__ == "__main__":
    main()
```

## Evaluation starts (Month 6)

Keep the Month 6 rule: **20 evaluation start poses**, and **5 must not appear in the training set**. Write those five into `protocol.md` before you record. Otherwise the Wilson interval you report in Month 6 / the capstone is measuring memorisation, not the task.

## Open X-Embodiment

Open X-Embodiment (arXiv **2310.08864**) gathers many robot datasets into one ecosystem and trains generalist policies (RT-X). You will not download OXE in this lesson. The takeaway for a single SO-101 bench is format and protocol discipline: shared schemas and honest variation beats one more silent demo from the same pose.

## Common mistakes

- **Recording 20 identical episodes.** Count variations, not only total episodes.
- **Skipping the hold-out starts.** If every eval pose was in training, the success rate is not an evaluation.
- **Assuming one file per episode.** v3 packs many episodes per Parquet/MP4; boundaries live in metadata.
- **Ignoring missing frames.** One gap in `cube_C` is already a data bug; find it with an audit script, not by eye.
