```python
#!/usr/bin/env python3
"""bag_stats.py: topic rates and drop gaps from a synthetic rosbag2/MCAP fixture.

Real Jazzy rosbag2 defaults to the mcap storage plugin
(rosbag2_storage::get_default_storage_id() returns \"mcap\" on the jazzy branch).
This toy reads a JSON timeline that mirrors per-topic stamp sequences extracted
from such a bag — no libmcap required, so expected/ stays CPU-reproducible.

Reports Hz estimates and inter-arrival gaps that exceed 1.5× the nominal period.
usage: python3 bag_stats.py
"""
from __future__ import annotations

import json
import os

HERE = os.path.dirname(os.path.abspath(__file__))
FIX = os.path.join(HERE, "sample_bag", "timeline.json")


def main() -> None:
    with open(FIX, encoding="utf-8") as f:
        bag = json.load(f)
    assert bag.get("storage_id") == "mcap"
    print(
        f"bag={bag['uri']} storage_id={bag['storage_id']} "
        f"duration_s={bag['duration_s']:g} (synthetic fixture; not a binary .mcap)"
    )
    print(f"{'topic':<28} {'n':>5} {'hz_est':>8} {'nominal':>8} {'gaps':>5}")
    total_gaps = 0
    for topic in bag["topics"]:
        name = topic["name"]
        stamps = topic["stamps_ns"]
        nominal_hz = float(topic["nominal_hz"])
        n = len(stamps)
        if n >= 2:
            dur = (stamps[-1] - stamps[0]) / 1e9
            hz = (n - 1) / dur if dur > 0 else float("nan")
        else:
            hz = 0.0
        period = 1e9 / nominal_hz
        gaps = 0
        for a, b in zip(stamps, stamps[1:]):
            if (b - a) > 1.5 * period:
                gaps += 1
        total_gaps += gaps
        print(f"{name:<28} {n:5d} {hz:8.2f} {nominal_hz:8.1f} {gaps:5d}")
    print(f"total_gap_events={total_gaps}")
    print("ok: fixture storage_id is mcap (Jazzy rosbag2 default)")


if __name__ == "__main__":
    main()
```

## Bag acceptance ≠ folder exists

A folder on disk is not a valid recording. `bag_qos_accept_toy.py` gates synthetic timelines with three checks (all must pass):

1. **Required topics present with `n > 0`.** Missing `/camera/color/image_raw` with `n==0` → **REJECT** even if the folder exists.
2. **Gap budget.** Inter-arrival gaps above `1.5×` the nominal period; more than `max_gaps_allowed=2` on a required topic → **REJECT**.
3. **Message budget.** Each required topic must meet a pinned `budget_min` (`n >= budget_min`). Fixed demo rows: `n=100` vs `budget_min=90` → PASS; `n=10` vs `budget_min=50` → FAIL. **Do not swap those comparisons.**

### Request vs Offered, recorder adapt, and durability (F1)

ROS 2 QoS uses a **Request vs Offered** model ([About QoS Settings — Jazzy](https://docs.ros.org/en/jazzy/Concepts/Intermediate/About-Quality-of-Service-Settings.html); RST mirror: `ros2/ros2_documentation` jazzy `About-Quality-of-Service-Settings.rst`). Subscriptions **request** a minimum quality; publishers **offer** a maximum. A connection forms only if **every** requested policy is not more stringent than the offered one. Incompatible reliability or durability ⇒ no match ⇒ no messages delivered (a recorder whose **override** requests too much looks “empty” on that topic).

**Recorder default vs overrides** (Jazzy [rosbag2 README — Overriding QoS Profiles](https://github.com/ros2/rosbag2/blob/jazzy/README.md); raw `https://raw.githubusercontent.com/ros2/rosbag2/jazzy/README.md`):

- **Default (no override):** rosbag2 **adapts** its *requested* subscription QoS to the publishers’ *offered* profiles. Source code: `Rosbag2QoS::adapt_request_to_offers` in [`rosbag2_storage/.../qos.cpp`](https://github.com/ros2/rosbag2/blob/jazzy/rosbag2_storage/src/rosbag2_storage/qos.cpp), called from the recorder’s `subscription_qos_for_topic` when no override is set ([`recorder.cpp`](https://github.com/ros2/rosbag2/blob/jazzy/rosbag2_transport/src/rosbag2_transport/recorder.cpp)). Rules in Jazzy `qos.cpp`:
  - **History:** `keep_last(max offered depth)` if that depth > 1; otherwise (e.g. every publisher offers `keep_last` depth=1) it falls back to **`keep_all`** (DEBUG log: “Falling back to the RMW_QOS_POLICY_HISTORY_KEEP_ALL”).
  - **Reliability:** `reliable` only if **all** publishers offer reliable; if publishers mix reliable/best_effort it falls back to **`best_effort`** and logs a WARN — it still connects to every publisher, but some messages from reliable publishers may be dropped.
  - **Durability:** `transient_local` only if **all** publishers offer transient_local; if they mix transient_local/volatile it falls back to **`volatile`** and logs a WARN — it still connects, but previously published latched messages are not retrieved.
  - So the default adapt never produces “no connection”; mixed publishers only cost reliability / retention semantics.
- **Overrides:** `--qos-profile-overrides-path` forces a **manual requested** profile for named topics (same README; `recorder.cpp` returns the override and skips adapt). Use it when the default adapt is wrong for your late-join / latching case. **RxO matching is per publisher–subscriber pair** (About QoS: compatibility is unaffected by other publishers on the same topic). An override that is too strict fails to match **only the incompatible publishers**; messages from compatible publishers still arrive. **Zero messages on that topic are only possible when every relevant publisher mismatches** (e.g. request `reliable` while every publisher offers best_effort, or request `transient_local` while every publisher offers volatile). Counterexample: two publishers offering reliable + best_effort, override requests `reliable` → still receives from the reliable one (`bag_qos_accept_toy.py` `override_match_demo`). Default adapt never produces “no connection”; only a too-strict override can, and only when all publishers mismatch.

**Durability and late joiners** (About QoS durability + compat table):

- **Volatile:** delivers only samples published *after* the subscriber joins. A late-joining recorder on a volatile topic **misses prior samples**.
- **Transient local:** the publisher may keep history for late-joining subscriptions **while that publisher is still alive** and still offering transient_local, with history (`keep_last` depth or `keep_all`) actually holding samples. This is **not** inventing out-of-process DDS persistence beyond transient_local.
- Prerequisites for retained samples: live publisher offering transient_local; history cache non-empty; subscriber request compatible (transient_local request needs a transient_local offer). Pub Volatile + Sub Transient local ⇒ **no communication**.

**Durability compatibility** (About QoS — Compatibility of durability QoS policies):

| Publisher | Subscription | Compatible | Result |
|---|---|---|---|
| Volatile | Volatile | Yes | New messages only |
| Volatile | Transient local | **No** | No communication |
| Transient local | Volatile | Yes | New messages only |
| Transient local | Transient local | Yes | New + retained |

To get “latched” behaviour for late joiners, **both** sides must agree on transient local.

**Other compatibility boundaries** (same About QoS — Jazzy RST tables; history/depth are **not** in the matching tables):

- **History / depth do not decide matching.** `keep_last` vs `keep_all` and the numeric depth affect caching, not whether a publisher–subscriber pair connects.
- **Deadline:** offered deadline must be **≤** requested (a publisher that promises a tighter cadence satisfies a looser request). Publisher `Default` + subscription finite deadline ⇒ **incompatible**.
- **Lease duration:** same direction as deadline — offered lease ≤ requested.
- **Liveliness:** Automatic < Manual by topic. Publisher Automatic + subscription Manual by topic ⇒ **No**; Manual by topic publisher + Automatic subscription ⇒ **Yes**.

```python
#!/usr/bin/env python3
"""bag_qos_accept_toy.py: synthetic rosbag2/MCAP *acceptance* gate (stdlib).

Acceptance ≠ "the bag folder exists". A recording is accepted only when:
  1. every required topic is present with n > 0 messages
  2. inter-arrival gaps stay within max_gaps_allowed (1.5× nominal period)
  3. per-topic message counts meet a fixed message budget (n >= budget_min)

QoS override YAML keys are taken from the ros2/rosbag2 **jazzy** README
section "Overriding QoS Profiles":
  https://github.com/ros2/rosbag2/blob/jazzy/README.md
  (raw: https://raw.githubusercontent.com/ros2/rosbag2/jazzy/README.md)
That README verifies the YAML *keys* (example uses durability: volatile).
The Request vs Offered model and durability compatibility table live in
About QoS Settings (Jazzy):
  https://docs.ros.org/en/jazzy/Concepts/Intermediate/About-Quality-of-Service-Settings.html
Recorder default adapt: Rosbag2QoS::adapt_request_to_offers
  (rosbag2_storage/.../qos.cpp; called from recorder.cpp when no override).
  Mixed reliable/best_effort -> best_effort, mixed transient_local/volatile
  -> volatile (WARN, still connects); max offered depth <= 1 -> keep_all.
RxO matching is per publisher–subscriber pair: an override that is too
strict fails to match only the incompatible publishers; zero messages on
the topic are only possible when EVERY relevant publisher mismatches.

MCAP ROS 2 getting-started: https://mcap.dev/guides/getting-started/ros-2
docs.ros.org QoS How-To for record/playback: optional when About QoS +
Jazzy README + recorder source already cover the teaching.

No binary .mcap / real bags in CI — JSON timeline fixtures only.
Live bag record, Foxglove, Rerun, wandb = 本页未运行.

usage: python3 bag_qos_accept_toy.py
"""
from __future__ import annotations

import json
import os

HERE = os.path.dirname(os.path.abspath(__file__))
FIX = os.path.join(HERE, "accept_fixtures")
QOS_YAML = os.path.join(FIX, "qos_override.yaml")

# Keys from jazzy README example under "Overriding QoS Profiles".
JAZZY_README_QOS_KEYS = (
    "history",
    "depth",
    "reliability",
    "durability",
    "deadline",
    "lifespan",
    "liveliness",
    "liveliness_lease_duration",
    "avoid_ros_namespace_conventions",
)

REQUIRED_TOPICS = (
    "/joint_states",
    "/camera/color/image_raw",
    "/tf",
)

# Fixed message-budget table — do NOT swap the pass/fail comparisons.
# pass example: n=100 >= budget_min=90 → PASS
# fail example: n=10  >= budget_min=50 → FAIL (reject)
FIXED_BUDGET_PASS = {"label": "fixed_ok", "n": 100, "budget_min": 90}
FIXED_BUDGET_FAIL = {"label": "fixed_fail", "n": 10, "budget_min": 50}

# Per-topic budgets applied to fixture bags (messages over the recording).
TOPIC_BUDGET_MIN = {
    "/joint_states": 90,
    "/camera/color/image_raw": 20,
    "/tf": 50,
}

MAX_GAPS_ALLOWED = 2
GAP_FACTOR = 1.5


def count_gaps(stamps_ns: list[int], nominal_hz: float) -> int:
    if len(stamps_ns) < 2 or nominal_hz <= 0:
        return 0
    period = 1e9 / nominal_hz
    gaps = 0
    for a, b in zip(stamps_ns, stamps_ns[1:]):
        if (b - a) > GAP_FACTOR * period:
            gaps += 1
    return gaps


def load_qos_keys(path: str) -> list[str]:
    """Parse top-level per-topic keys from the override YAML (no PyYAML)."""
    keys: list[str] = []
    with open(path, encoding="utf-8") as f:
        for line in f:
            raw = line.rstrip("\n")
            if not raw or raw.lstrip().startswith("#"):
                continue
            # topic header: "/name:" at column 0
            if raw.startswith("/") and raw.endswith(":"):
                continue
            # policy line: two-space indent, "key:" or "key: value"
            if raw.startswith("  ") and not raw.startswith("    "):
                key = raw.strip().split(":", 1)[0]
                if key not in keys:
                    keys.append(key)
    return keys


def accept_bag(bag: dict) -> tuple[str, str, dict]:
    """Return (decision, reason, detail). folder_exists alone never accepts."""
    detail: dict = {
        "folder_exists": bool(bag.get("folder_exists")),
        "uri": bag.get("uri"),
    }
    if not bag.get("folder_exists"):
        return "REJECT", "folder_missing", detail

    by_name = {t["name"]: t for t in bag.get("topics", [])}

    for req in REQUIRED_TOPICS:
        topic = by_name.get(req)
        n = 0 if topic is None else len(topic.get("stamps_ns", []))
        detail[f"n:{req}"] = n
        if topic is None or n == 0:
            detail["missing_topic"] = req
            return "REJECT", "missing_required_topic", detail

    for req in REQUIRED_TOPICS:
        topic = by_name[req]
        gaps = count_gaps(topic["stamps_ns"], float(topic["nominal_hz"]))
        detail[f"gaps:{req}"] = gaps
        if gaps > MAX_GAPS_ALLOWED:
            detail["gap_topic"] = req
            return "REJECT", "gap_exceeded", detail

    for req in REQUIRED_TOPICS:
        n = len(by_name[req]["stamps_ns"])
        budget = TOPIC_BUDGET_MIN[req]
        detail[f"budget:{req}"] = budget
        if n < budget:
            detail["budget_topic"] = req
            return "REJECT", "below_message_budget", detail

    return "ACCEPT", "ok", detail


def fixed_budget_demo() -> None:
    """Pinned comparisons — swapping pass/fail numbers must not be done."""
    ok = FIXED_BUDGET_PASS
    bad = FIXED_BUDGET_FAIL
    ok_pass = ok["n"] >= ok["budget_min"]
    bad_pass = bad["n"] >= bad["budget_min"]
    print(
        f"fixed_budget_examples "
        f"{ok['label']}: n={ok['n']} budget_min={ok['budget_min']} "
        f"cmp=ge → {'PASS' if ok_pass else 'FAIL'}; "
        f"{bad['label']}: n={bad['n']} budget_min={bad['budget_min']} "
        f"cmp=ge → {'PASS' if bad_pass else 'FAIL'} "
        f"(do not swap comparisons)"
    )
    assert ok_pass and not bad_pass
    # Guard against accidental swap of the two example rows.
    assert ok["n"] > bad["n"]
    assert ok["budget_min"] > bad["budget_min"]


def override_match_demo() -> None:
    """Per-publisher RxO matching under a too-strict override (stdlib demo).

    Matching is pairwise. An override requests one profile; each publisher
    is checked independently. Zero messages require ALL publishers to
    mismatch — a mixed reliable+best_effort topic with override=reliable
    still receives from the reliable publisher.
    """
    # reliability offered rank: reliable > best_effort (request must not
    # be more stringent than offer).
    def reliability_ok(offered: str, requested: str) -> bool:
        if requested == "best_effort":
            return True
        return offered == "reliable"

    cases = [
        {
            "label": "mixed_pubs_override_reliable",
            "pubs": ["reliable", "best_effort"],
            "request": "reliable",
        },
        {
            "label": "all_best_effort_override_reliable",
            "pubs": ["best_effort", "best_effort"],
            "request": "reliable",
        },
    ]
    print("override_match_demo (RxO is per publisher–subscriber pair):")
    for c in cases:
        matches = [p for p in c["pubs"] if reliability_ok(p, c["request"])]
        n_match = len(matches)
        zero = n_match == 0
        print(
            f"  {c['label']}: pubs={','.join(c['pubs'])} "
            f"request={c['request']} matched={n_match}/{len(c['pubs'])} "
            f"from={','.join(matches) if matches else 'none'} "
            f"zero_messages={'yes' if zero else 'no'}"
        )
    # Locked teaching asserts.
    mixed = cases[0]
    mixed_matches = [p for p in mixed["pubs"] if reliability_ok(p, mixed["request"])]
    assert mixed_matches == ["reliable"], mixed_matches
    all_be = cases[1]
    all_be_matches = [p for p in all_be["pubs"] if reliability_ok(p, all_be["request"])]
    assert all_be_matches == [], all_be_matches
    print(
        "override_match_note: too-strict override drops only incompatible "
        "publishers; zero messages only when ALL publishers mismatch"
    )


def main() -> None:
    qos_keys = load_qos_keys(QOS_YAML)
    print("bag_qos_accept_toy fixtures=accept_fixtures seed=n/a (deterministic)")
    print(f"qos_override_keys={','.join(qos_keys)}")
    missing = [k for k in JAZZY_README_QOS_KEYS if k not in qos_keys]
    extra = [k for k in qos_keys if k not in JAZZY_README_QOS_KEYS]
    assert not missing and not extra, (missing, extra)
    print(
        "qos_source=ros2/rosbag2 jazzy README Overriding QoS Profiles (YAML keys); "
        "durability compatibility table from Jazzy About QoS "
        "(the rosbag2 README has no such table)"
    )
    print(
        f"required_topics={','.join(REQUIRED_TOPICS)} "
        f"max_gaps_allowed={MAX_GAPS_ALLOWED} gap_factor={GAP_FACTOR}"
    )
    fixed_budget_demo()
    override_match_demo()

    cases = [
        "pass_clean.json",
        "missing_topic.json",
        "gap_heavy.json",
        "budget_short.json",
        "empty_folder.json",
    ]
    accept_n = 0
    reject_n = 0
    for name in cases:
        with open(os.path.join(FIX, name), encoding="utf-8") as f:
            bag = json.load(f)
        decision, reason, detail = accept_bag(bag)
        if decision == "ACCEPT":
            accept_n += 1
        else:
            reject_n += 1
        extra = ""
        if reason == "missing_required_topic":
            extra = f" topic={detail.get('missing_topic')} n=0"
        elif reason == "gap_exceeded":
            t = detail["gap_topic"]
            extra = f" topic={t} gaps={detail[f'gaps:{t}']}"
        elif reason == "below_message_budget":
            t = detail["budget_topic"]
            extra = (
                f" topic={t} n={detail[f'n:{t}']} "
                f"budget_min={detail[f'budget:{t}']}"
            )
        print(
            f"case={bag['uri']} folder_exists={detail['folder_exists']} "
            f"decision={decision} reason={reason}{extra}"
        )

    print(f"summary accept={accept_n} reject={reject_n}")
    assert accept_n == 1 and reject_n == 4
    print(
        "ok: acceptance ≠ folder_exists; synthetic fixtures only "
        "(no binary mcap; live bag/Foxglove/Rerun/wandb 本页未运行)"
    )


if __name__ == "__main__":
    main()
```

## Common mistakes

- **Putting Dev Container CI into this site's repo.** Student package CI ≠ Hardware-learning website CI.
- **Assuming sqlite3 is still the default.** On Jazzy the default storage_id is mcap.
- **Ignoring gap counts.** A "50 Hz" joint topic at 49 Hz with gaps is already a logging bug.
- **Treating “folder exists” as bag acceptance.** Missing required topics (`n==0`), gap overruns or under-budget counts must reject.
- **Inventing QoS YAML keys, or citing the rosbag2 README for `transient_local` compatibility.** Use only the README’s keys; take durability compatibility (Pub volatile + Sub transient_local ⇒ no connection) from About QoS, and remember only a too-strict override — not default adapt — can yield no connection, and only when **all** publishers on that topic mismatch.
- **Assuming one mismatched publisher zeros the whole topic.** RxO is pairwise; a reliable+best_effort mix with override=`reliable` still records the reliable publisher.
- **Treating wandb as optional forever.** When you fine-tune (lesson 8.2), a run without hyperparams logged is hard to defend in the capstone README.
