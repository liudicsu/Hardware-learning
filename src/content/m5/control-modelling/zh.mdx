第 3 个月结束时，你已经在同一个机械臂关节上跑通了 PID。[复习第 3 个月的 PID](/zh/month/month-3/pid-control) 可以找回 P、I、D、积分饱和和调参步骤；这些内容本课不再重复。这一课往深处走：给被控对象（plant）建模，写出<Term id="transfer-function">传递函数</Term>，用 <Term id="bode-plot">Bode</Term> 图看回路，再用增益裕度和<Term id="phase-margin">相位裕度</Term>判断稳定性。状态空间和 LQR 是下一课。

## 为什么要给关节建模

还是第 3 个月的那个关节：J = 0.004 kg·m²，B = 0.05 N·m/(rad/s)，重力力矩为 0.4 N·m × cos(q)。重力前馈（gravity feedforward）根据测到的角度算出重力力矩并加到指令上；模型准确时，它正好抵消重力，剩下的就是线性关系：力矩 u 对应 J q'' + B q'。传递函数和 Bode 图描述的都是线性对象，而测试时把阶跃取得很小，就是为了让真实关节尽量处在线性模型适用的范围内。

<Formula label="带重力前馈的对象：单位力矩对应的角度">G(s) = 1 / (J s² + B s) = 1 / (s (J s + B))</Formula>

代入 J = 0.004 kg·m²、B = 0.05 N·m/(rad/s)，分母可以写成 s(J s + B)。一个极点在 s = 0，它是把力矩变成速度的自由积分器；另一个极点在 s = −B/J = −12.5 1/s，是一阶惯性环节，时间常数 J/B = 0.004 / 0.05 = 0.08 s。力矩阶跃之后，速度在 0.08 s 达到最终值的 63 %。

第 3 个月的增益是按角度给的：0.05 N·m/度、0.002 N·m/(度/秒)。乘以 180/π 换成 SI：0.05 × 180/π = 2.86 N·m/rad，0.002 × 180/π = 0.115 N·m/(rad/s)。下面的模型就用这两个换算后的增益，所以它描述的就是你手调过的那条回路。

## 用实测数据识别模型

在相信任何裕度之前，先确认模型和电机对得上。最简单的试验是开环力矩阶跃：保持一个恒定的力矩 u（重力前馈仍然打开），让关节从静止开始加速，同时记录速度。速度是一阶响应，最终速度是 u/B，达到 63 % 的时间是 tau = J/B。取 u = 0.2 N·m、B = 0.05 N·m/(rad/s)，最终速度应为 0.2 / 0.05 = 4 rad/s；记录在 0.5 s 结束，大约是六个时间常数，这时速度还差 0.2 %，所以读数是 3.99 rad/s。63 % 点在 0.080 s，于是 J = B × tau = 0.05 × 0.080 = 0.0040 kg·m²。

```python
"""joint_freq.py: model the Month 3 arm joint, then read its loop in the frequency domain.

The joint is the one from pid_sim.py (J = 0.004 kg*m^2, B = 0.05 N*m per rad/s, gravity
0.4 N*m * cos(angle)), with gravity cancelled by a feedforward term so that what is left
is linear: torque -> J*q'' + B*q'. The controller runs at 200 Hz, holds its torque for one
period (zero-order hold) and, like most real firmware, applies the torque computed from a
reading one period later (one sample of delay). Units are SI: angles in rad, gains in
N*m per rad and N*m per rad/s (Month 3's 0.05 N*m per degree is 2.86 N*m per rad).
"""
import cmath
import math

J, B, GRAV, T = 0.004, 0.05, 0.4, 0.005
A = B / J                                    # 12.5 1/s, so the time constant J/B is 0.08 s
E = math.exp(-A * T)
# exact discretisation of J*q'' + B*q' = u with the torque held over each period
PHI = ((1.0, (1 - E) / A), (0.0, E))
GAM = ((T - (1 - E) / A) / (A * J), (1 - E) / (A * J))


def step(q, w, u):
    return (q + PHI[0][1] * w + GAM[0] * u, E * w + GAM[1] * u)


def identify():
    """Open-loop test: hold 0.2 N*m (plus gravity feedforward) and log the speed."""
    print("Open-loop step: 0.2 N*m from rest, speed logged at 200 Hz")
    q, w, log = 0.0, 0.0, []
    for k in range(101):
        log.append((k * T, w))
        q, w = step(q, w, 0.2)
    for t, s in log[::8][:8]:
        print(f"  t = {t:4.2f} s   speed {s:5.2f} rad/s")
    final = log[-1][1]
    t63 = next(t for t, s in log if s >= 0.632 * final)
    b = 0.2 / final
    print(f"  final speed {final:.2f} rad/s -> B = 0.2 / {final:.2f} = {b:.3f} N*m per rad/s")
    print(f"  63 % of it at t = {t63:.3f} s -> J = B x tau = {b * t63:.4f} kg*m^2")


def loop(kp, kd, w):
    """Loop gain L = C * P at angular frequency w (rad/s), with z = e^(jwT)."""
    z = cmath.exp(1j * w * T)
    det = (z - PHI[0][0]) * (z - PHI[1][1]) - PHI[0][1] * PHI[1][0]
    plant = ((z - PHI[1][1]) * GAM[0] + PHI[0][1] * GAM[1]) / det   # angle / torque
    pd = kp + kd * (1 - 1 / z) / T
    return pd * plant / z                                           # one sample of delay


def margins(kp, kd):
    """Gain and phase margins from a fine logarithmic sweep up to the Nyquist frequency."""
    ws = [10 ** (k / 2000) for k in range(-2000, int(2000 * math.log10(math.pi / T)))]
    wc = pm = wpc = gm = None
    last_ph, unwrap, prev = None, 0.0, None
    for w in ws:
        l = loop(kp, kd, w)
        ph = math.degrees(cmath.phase(l))
        if last_ph is not None and ph - last_ph > 180:
            unwrap -= 360                     # keep the phase continuous
        last_ph = ph
        ph += unwrap
        if prev is not None:
            if wc is None and abs(prev[1]) >= 1 > abs(l):
                wc, pm = w, 180 + ph
            if wpc is None and prev[2] > -180 >= ph:
                wpc, gm = w, -20 * math.log10(abs(l))
        prev = (w, l, ph)
    return wc, pm, wpc, gm


def bode(kp, kd):
    print(f"Loop gain, kp = {kp} N*m/rad, kd = {kd} N*m/(rad/s)")
    print("   w (rad/s)  |L| (dB)  phase (deg)")
    for w in (1, 3, 10, 30, 100, 300):
        l = loop(kp, kd, w)
        ph = math.degrees(cmath.phase(l))
        ph = ph - 360 if ph > 0 else ph
        print(f"  {w:9.0f}  {20 * math.log10(abs(l)):8.1f}  {ph:11.1f}")
    wc, pm, wpc, gm = margins(kp, kd)
    print(f"  gain crossover {wc:.1f} rad/s, phase margin {pm:.0f} deg")
    print(f"  phase crossover {wpc:.1f} rad/s, gain margin {gm:.1f} dB (x {10 ** (gm / 20):.1f})")


def closed(kp, kd, target=0.1, seconds=2.0):
    """Closed-loop step of 0.1 rad (about 6 degrees), small enough to stay linear."""
    q, w, u, prev = 0.0, 0.0, 0.0, 0.0
    peak, hist = 0.0, []
    for k in range(int(seconds / T)):
        rate = (q - prev) / T
        prev = q
        nxt = kp * (target - q) - kd * rate      # computed now, applied next period
        q, w = step(q, w, u)
        u = nxt
        peak = max(peak, q)
        hist.append(q - target)
    early, late = hist[100:200], hist[-100:]     # 0.5-1.0 s and the last 0.5 s
    size = lambda h: max(h) - min(h)
    ups = [k for k in range(len(hist) - 100, len(hist) - 1) if hist[k] < 0 <= hist[k + 1]]
    freq = 2 * math.pi * (len(ups) - 1) / ((ups[-1] - ups[0]) * T) if len(ups) > 2 else None
    return 100 * max(0.0, peak - target) / target, size(early), size(late), freq


def sweep():
    _, _, wpc, gm = margins(1.0, 0.0)
    print(f"P only, kp = 1.0: gain margin {gm:.1f} dB, so the loop should ring at {wpc:.1f} rad/s")
    print(f"and turn unstable near kp = 1.0 x {10 ** (gm / 20):.2f} = {10 ** (gm / 20):.2f}. Check it on 0.1 rad steps:")
    print("     kp     kd   PM (deg)  overshoot  swing 0.5-1 s  swing 1.5-2 s  ringing at")
    for kp, kd in ((0.5, 0), (1.0, 0), (2.0, 0), (2.86, 0), (6.5, 0), (7.0, 0), (2.86, 0.115)):
        _, pm, _, _ = margins(kp, kd)
        over, early, late, freq = closed(kp, kd)
        f = f"{freq:.1f} rad/s" if freq and late > 1e-4 else "-"
        o = f"{over:6.0f} %" if late < early else "  grows"
        print(f"  {kp:5.2f}  {kd:5.3f}  {pm:8.0f}   {o}   {1000 * early:8.2f} mrad  {1000 * late:9.2f} mrad  {f}")


if __name__ == "__main__":
    identify()
    print()
    bode(2.86, 0.115)
    print()
    sweep()
```

## 在频域里读回路

把控制器写成 C，把对象写成 P，回路增益就是 L = C × P。幅值用分贝表示：20 log10 |L|，所以 0 dB 就是 |L| = 1。相位表示指令绕回路一圈回到相加点时的滞后。两个关键频率：增益穿越频率（gain crossover）是 |L| = 1（0 dB）的地方；相位穿越频率（phase crossover）是相位到达 −180° 的地方。

<Formula label="增益裕度：在相位穿越频率处，回路还能把增益放大多少倍才让 |L| 到 1">GM = 1 / |L(jω_pc)|，换算成分贝：GM_dB = −20 log10 |L(jω_pc)|</Formula>

<Formula label="相位裕度：在增益穿越频率处，相位还能再滞后多少度才到 −180°">PM = 180° + ∠L(jω_c)</Formula>

用第 3 个月的增益 kp = 2.86 N·m/rad、kd = 0.115 N·m/(rad/s)，模型给出下表。|L| 在 34.6 rad/s 穿过 0 dB（读在表中 30 与 100 rad/s 两行之间），那里 `∠L(34.6 rad/s) ≈ −124°`，所以 `PM = 180° + (−124°) = 56°`。相位在 150.8 rad/s 到达 −180°，那里 `|L(150.8 rad/s)| ≈ −14.2 dB`，<Term id="gain-margin">增益裕度</Term>就是 14.2 dB，也就是 `10^(14.2/20) = 5.1` 倍。300 rad/s 那一行相位已经是 −263°，早过了 −180°；裕度读的是第一次穿越。

这些数字已经包含了两处连续的 C × P 草图会漏掉的滞后。控制器在一个周期内保持力矩不变（零阶保持，zero-order hold），而固件施加的力矩是根据上一拍的读数算出来的，相当于晚了一个采样周期。200 Hz 下每个采样是 5 ms。T 秒的延迟会带来 ω × T 弧度的相位滞后，频率越高越多：在 34.6 rad/s 的穿越频率处，一个采样的延迟就是 34.6 × 0.005 = 0.17 rad，约 10°；零阶保持相当于半个采样，再多约 5°。这 15° 的裕度，无延迟的 Bode 图会算出来，真实回路却没有。

## 从裕度预测阶跃响应

裕度不是装饰，它直接预测闭环会怎么动。kd = 0 时，加大 kp 会把每个频率上的 |L| 都抬高，增益穿越点右移，进入相位滞后更大的区域。PM 下降，阶跃响应的超调就上升。

kp = 1.0、只用 P 时，增益裕度是 16.6 dB，也就是 10^(16.6/20) = 6.8 倍的增益。持续振荡的条件是 `|L| = 1` 且 `∠L = −180°`。只缩放 kp 会改变幅值、不改变相位，所以 −180° 只能出现在相位穿越频率 ω_pc = 40.2 rad/s（这就是振荡频率），那里的增益还要再放大 6.8 倍，于是 `kp_crit = 1.0 × 6.8 = 6.8 ≈ 6.79`。同一个裕度因此预测：回路会在 40.2 rad/s 附近振荡，并在 kp 接近 6.79 时失稳。扫描结果和它一致：kp 取 0.5、1、2、2.86 时，PM 依次是 53°、37°、22°、15°，超调依次是 15 %、33 %、54 %、66 %。kp = 6.5 时 PM 只有 1°，超调 98 %，39.3 rad/s 的振荡衰减得很慢，两个时间窗的摆幅只从 172.47 mrad 降到 137.12 mrad。kp = 7.0 时 PM 是 −1°，40.5 rad/s 的振荡从 236.89 mrad 增长到 285.66 mrad。预测和阶跃响应对上了。

## 持续激励对照公平阶跃（系统辨识）

第 1 节已经用一次开环力矩阶跃辨识出 B 和 J。对一阶速度环节这往往够用：PE **不是**「两个参数 ⇒ 阶跃不可辨识」。持续激励（persistency of excitation）说的是**辨识时域内回归子是否足够丰富**，也就是 `ΦᵀΦ` 是否良态（Ljung 输入信号章节，见 MIT OCW 6.435 大纲指针；De Nicolao 1997 教程对比方程误差与输出误差）。玩具报告的是**有限窗口** Gram 条件数 `cond(ΦᵀΦ)`，作为本时域上丰富度的实用诊断；**严格 PE** 是更强的断言（窗口 Gram 随窗口增长有正定下界），**本页不声称**。结构更丰富时，同一个阶跃可能让 `ΦᵀΦ` 病态——要用**测到的**条件数和参数误差说话，而不是事先保证「更丰富输入一定赢」。

### 公平对比

玩具锁死三条，避免不公平对比：

1. **同时长** N = 200 个采样。
2. **同一条噪声序列**（同一 case 的每个输入臂共用）。
3. **输入能量** `Σ u²` 对齐到 `ENERGY_TOL = 0.01` 以内（更丰富输入会缩放到与阶跃相同的能量）。同时打印峰值 `|u|`——不要拿一个很小的阶跃去比一个很大的 PRBS。

### 估计器要诚实

**噪声模型（锁定）：**独立加性**测量**噪声。无噪状态 `z` 按 ARX 递推；测量输出为 `y = z + v`，且 `v` 与 `(z, u)` 独立。这**不是** ARX *新息*模型 `y_k = a y_{k-1} + b u_{k-1} + e_k`（那种模型里 `e_k` 与滞后回归子独立，OLS 一致）。

拟合是**方程误差 OLS**（ARX 风格）：`Φ` 的行里含有滞后的**测量** `y`。滞后输出带着 `v`，因此 OLS 是 **errors-in-variables（EIV）/ 方程误差**估计——打印的 `‖θ̂−θ‖` **包含该 EE-OLS 偏差**。**不得**声称无偏（有限样本或渐近都不行）。输出误差（OE）或工具变量（IV）是另一类估计器，本页未实现。第 7 个月的 `sysid_fit` 只作指针，不在此重做。

#!/usr/bin/env python3
"""sysid_pe_compare_toy.py: PE vs step — fair energy, report conditioning (stdlib).

Persistency of excitation (PE) is about the RICHNESS of the regressors over the
identification horizon (how well-conditioned ΦᵀΦ is), not a claim that "two
parameters ⇒ a step cannot identify them." A transient step often identifies a
first-order time constant τ; for a richer structure the same step can leave
ΦᵀΦ ill-conditioned. Numbers decide — this toy reports them and does not
guarantee that PE always wins.

Fair comparison LOCKED: same horizon N, the SAME measurement-noise sequence for
every input arm of a case, and input energy Σ u² matched within ENERGY_TOL
(the richer input is scaled to the step's energy). Peak |u| is also printed.

Noise model (LOCKED): independent additive measurement noise. A noise-free
state z follows the ARX recursion; the measured output is y = z + v with
v ~ N(0, σ²) independent of (z, u). Equation-error OLS then puts noisy lagged
y into Φ, so it is an errors-in-variables (EIV) estimator: the printed
‖θ̂−θ‖ includes that EE-OLS bias. This is NOT the ARX *innovation* model
y_k = a y_{k-1} + b u_{k-1} + e_k (where e_k is independent of the lagged
regressors and OLS is consistent). An output-error (OE) or instrumental-
variable (IV) fit would be a different estimator; not implemented here.

The finite-window Gram cond(ΦᵀΦ) is a practical diagnostic of regressor
richness on this horizon. Strict PE is a stronger statement (a positive-
definite lower bound on the window Gram as the window grows); the toy
reports the diagnostic, not a PE certificate.

Pointers (no copyrighted book text pasted): Ljung, System Identification, 2ed
(ISBN 0136566952) via the MIT OCW 6.435 syllabus; De Nicolao 1997 tutorial on
OE vs EE and PE. Existing lesson 5.1 step-τ identification and Month 7
sysid_fit are siblings, not redone here.
usage: python3 sysid_pe_compare_toy.py
"""
from __future__ import annotations

import math
import random

SEED = 51
N = 200                 # identification horizon (samples), shared
DT = 0.01               # s
ENERGY_TOL = 0.01       # |E_step - E_other| / E_step must be <= this
NOISE_STD = 0.02        # additive measurement noise v on y = z + v (same stream per case)

# Case A: first-order speed plant  τ z' + z = K u  (discrete ARX-1 on noise-free z).
# A single step is classically enough to read τ; PE is not required.
TAU_A = 0.08            # s  (matches the Month 3 / 5.1 joint time constant)
K_A = 1.0
A_TRUE_A = math.exp(-DT / TAU_A)
B_TRUE_A = K_A * (1.0 - A_TRUE_A)

# Case B: second-order ARX-2 with a slow and a fast mode. A step puts almost
# all energy at DC; a richer two-tone input improves the conditioning of ΦᵀΦ.
A1_TRUE_B = 1.70
A2_TRUE_B = -0.72
B_TRUE_B = 0.05


def prbs(rng: random.Random, n: int, amp: float) -> list[float]:
    """±amp pseudo-random binary sequence (clock every 4 samples)."""
    u, level = [], amp
    for k in range(n):
        if k % 4 == 0:
            level = amp if rng.random() < 0.5 else -amp
        u.append(level)
    return u


def two_tone(n: int, amp: float, f1: float = 1.5, f2: float = 7.0) -> list[float]:
    """Sum of two sines (Hz) — richer spectrum than a single step."""
    return [amp * (math.sin(2 * math.pi * f1 * k * DT)
                   + 0.7 * math.sin(2 * math.pi * f2 * k * DT)) for k in range(n)]


def scale_energy(u: list[float], target: float) -> list[float]:
    e = sum(v * v for v in u)
    if e <= 0.0:
        return list(u)
    s = math.sqrt(target / e)
    return [s * v for v in u]


def sim_meas_arx1(u: list[float], a: float, b: float, noise: list[float]) -> list[float]:
    """Noise-free ARX-1 state z; measured y = z + v (independent measurement noise)."""
    z = [0.0] * len(u)
    y = [0.0] * len(u)
    for k in range(1, len(u)):
        z[k] = a * z[k - 1] + b * u[k - 1]
        y[k] = z[k] + noise[k]
    return y


def sim_meas_arx2(
    u: list[float], a1: float, a2: float, b: float, noise: list[float]
) -> list[float]:
    """Noise-free ARX-2 state z; measured y = z + v (independent measurement noise)."""
    z = [0.0] * len(u)
    y = [0.0] * len(u)
    for k in range(2, len(u)):
        z[k] = a1 * z[k - 1] + a2 * z[k - 2] + b * u[k - 1]
        y[k] = z[k] + noise[k]
    return y


def ols(phi: list[list[float]], yy: list[float]) -> tuple[list[float], float]:
    """θ̂ = (ΦᵀΦ)⁻¹ Φᵀ y via Gaussian elimination; also return cond(ΦᵀΦ)."""
    p = len(phi[0])
    g = [[0.0] * p for _ in range(p)]
    rhs = [0.0] * p
    for row, yk in zip(phi, yy):
        for i in range(p):
            rhs[i] += row[i] * yk
            for j in range(p):
                g[i][j] += row[i] * row[j]
    # 2-norm condition via eigenvalue ratio of the Gram matrix (p small).
    cond = _cond(g)
    theta = _solve(g, rhs)
    return theta, cond


def _cond(g: list[list[float]]) -> float:
    # For p=2 use closed form; for p=3 use characteristic polynomial roots via
    # numpy-free power iteration on G and G^{-1} for rough 2-norm cond.
    p = len(g)
    if p == 2:
        tr = g[0][0] + g[1][1]
        det = g[0][0] * g[1][1] - g[0][1] * g[1][0]
        # eigenvalues of 2x2: roots of λ² - tr λ + det = 0
        disc = max(0.0, tr * tr - 4.0 * det)
        lam1 = 0.5 * (tr + math.sqrt(disc))
        lam2 = 0.5 * (tr - math.sqrt(disc))
        return abs(lam1 / lam2) if abs(lam2) > 1e-18 else float("inf")
    # Power iteration for λ_max(G) and λ_max(G^{-1}).
    def power(mat, iters=40):
        v = [1.0] * p
        for _ in range(iters):
            w = [sum(mat[i][j] * v[j] for j in range(p)) for i in range(p)]
            nrm = math.sqrt(sum(x * x for x in w)) or 1.0
            v = [x / nrm for x in w]
        w = [sum(mat[i][j] * v[j] for j in range(p)) for i in range(p)]
        return sum(v[i] * w[i] for i in range(p))
    lam_max = power(g)
    ginv = _invert(g)
    lam_min_inv = power(ginv)  # ≈ 1/λ_min
    lam_min = 1.0 / lam_min_inv if abs(lam_min_inv) > 1e-18 else 0.0
    return abs(lam_max / lam_min) if abs(lam_min) > 1e-18 else float("inf")


def _invert(g: list[list[float]]) -> list[list[float]]:
    p = len(g)
    a = [row[:] + [1.0 if i == j else 0.0 for j in range(p)] for i, row in enumerate(g)]
    for col in range(p):
        piv = max(range(col, p), key=lambda r: abs(a[r][col]))
        a[col], a[piv] = a[piv], a[col]
        div = a[col][col]
        for j in range(2 * p):
            a[col][j] /= div
        for r in range(p):
            if r == col:
                continue
            f = a[r][col]
            for j in range(2 * p):
                a[r][j] -= f * a[col][j]
    return [row[p:] for row in a]


def _solve(g: list[list[float]], rhs: list[float]) -> list[float]:
    p = len(g)
    a = [g[i][:] + [rhs[i]] for i in range(p)]
    for col in range(p):
        piv = max(range(col, p), key=lambda r: abs(a[r][col]))
        a[col], a[piv] = a[piv], a[col]
        div = a[col][col]
        for j in range(p + 1):
            a[col][j] /= div
        for r in range(p):
            if r == col:
                continue
            f = a[r][col]
            for j in range(p + 1):
                a[r][j] -= f * a[col][j]
    return [a[i][p] for i in range(p)]


def fit_arx1(u: list[float], y: list[float]) -> tuple[list[float], float, float]:
    phi, yy = [], []
    for k in range(1, len(u)):
        phi.append([y[k - 1], u[k - 1]])
        yy.append(y[k])
    theta, cond = ols(phi, yy)
    true = [A_TRUE_A, B_TRUE_A]
    err = math.sqrt(sum((theta[i] - true[i]) ** 2 for i in range(2)))
    return theta, cond, err


def fit_arx2(u: list[float], y: list[float]) -> tuple[list[float], float, float]:
    phi, yy = [], []
    for k in range(2, len(u)):
        phi.append([y[k - 1], y[k - 2], u[k - 1]])
        yy.append(y[k])
    theta, cond = ols(phi, yy)
    true = [A1_TRUE_B, A2_TRUE_B, B_TRUE_B]
    err = math.sqrt(sum((theta[i] - true[i]) ** 2 for i in range(3)))
    return theta, cond, err


def energy(u: list[float]) -> float:
    return sum(v * v for v in u)


def peak(u: list[float]) -> float:
    return max(abs(v) for v in u)


def main() -> None:
    print(f"seed={SEED} N={N} dt={DT} energy_tol={ENERGY_TOL} noise_std={NOISE_STD}")
    print(
        "noise_model: y=z+v (independent measurement noise on noise-free ARX state z); "
        "NOT ARX innovation e_k"
    )
    print(
        "estimator: equation-error OLS (ARX) on noisy y in Phi → EIV / EE-OLS bias; "
        "NOT claimed unbiased (OE/IV not implemented)"
    )
    print(
        "PE diagnostic: finite-window cond(Phi^T Phi); "
        "strict PE = positive-definite lower bound on the window Gram (not claimed here)"
    )
    print()

    # ---- Case A: first-order τ — a step often suffices ----
    rng_n = random.Random(SEED)
    noise_a = [rng_n.gauss(0.0, NOISE_STD) for _ in range(N)]
    u_step_a = [0.0 if k < 10 else 1.0 for k in range(N)]
    e_step = energy(u_step_a)
    rng_prbs = random.Random(SEED + 1)
    u_prbs_raw = prbs(rng_prbs, N, amp=1.0)
    u_prbs_a = scale_energy(u_prbs_raw, e_step)

    print(f"case_A first_order_tau={TAU_A} K={K_A}  true_theta=[{A_TRUE_A:.6f}, {B_TRUE_A:.6f}]")
    print(f"{'input':<10} {'energy':>10} {'peak|u|':>10} {'cond(PhiTPhi)':>14} {'||theta_hat-theta||':>20}")
    results_a = []
    for name, u in (("step", u_step_a), ("prbs", u_prbs_a)):
        y = sim_meas_arx1(u, A_TRUE_A, B_TRUE_A, noise_a)
        theta, cond, err = fit_arx1(u, y)
        e = energy(u)
        print(f"{name:<10} {e:10.4f} {peak(u):10.4f} {cond:14.4g} {err:20.6f}")
        results_a.append((name, e, cond, err, theta))
    # energy match assert
    e0, e1 = results_a[0][1], results_a[1][1]
    rel = abs(e0 - e1) / e0
    assert rel <= ENERGY_TOL, f"case_A energy mismatch rel={rel}"
    print(f"energy_match_rel={rel:.6f} (tol={ENERGY_TOL})  "
          f"step_err={results_a[0][3]:.6f} prbs_err={results_a[1][3]:.6f} "
          f"(step is capable; numbers decide, PE not guaranteed to win; "
          f"err includes EE-OLS bias from measurement noise)")
    print()

    # ---- Case B: second-order — richer input improves conditioning ----
    rng_n = random.Random(SEED + 7)   # fresh noise stream for case B, shared across its arms
    noise_b = [rng_n.gauss(0.0, NOISE_STD) for _ in range(N)]
    u_step_b = [0.0 if k < 10 else 1.0 for k in range(N)]
    e_step_b = energy(u_step_b)
    u_rich_b = scale_energy(two_tone(N, amp=1.0), e_step_b)

    print(f"case_B second_order  true_theta=[{A1_TRUE_B}, {A2_TRUE_B}, {B_TRUE_B}]")
    print(f"{'input':<10} {'energy':>10} {'peak|u|':>10} {'cond(PhiTPhi)':>14} {'||theta_hat-theta||':>20}")
    results_b = []
    for name, u in (("step", u_step_b), ("two_tone", u_rich_b)):
        y = sim_meas_arx2(u, A1_TRUE_B, A2_TRUE_B, B_TRUE_B, noise_b)
        theta, cond, err = fit_arx2(u, y)
        e = energy(u)
        print(f"{name:<10} {e:10.4f} {peak(u):10.4f} {cond:14.4g} {err:20.6f}")
        results_b.append((name, e, cond, err, theta))
    e0, e1 = results_b[0][1], results_b[1][1]
    rel = abs(e0 - e1) / e0
    assert rel <= ENERGY_TOL, f"case_B energy mismatch rel={rel}"
    # Report whether richer input improved conditioning (data-dependent; asserted direction).
    assert results_b[1][2] < results_b[0][2], (
        f"expected two_tone cond < step cond, got {results_b[1][2]} vs {results_b[0][2]}")
    print(f"energy_match_rel={rel:.6f} (tol={ENERGY_TOL})  "
          f"cond_step={results_b[0][2]:.4g} cond_two_tone={results_b[1][2]:.4g} "
          f"step_err={results_b[0][3]:.6f} two_tone_err={results_b[1][3]:.6f} "
          f"(richer input improved conditioning; err includes EE-OLS bias)")
    print("ok: fair energy; case_A step-capable; case_B richer input better cond; "
          "measurement-noise EIV → EE-OLS bias measured (real motor sysid 本页未运行)")


if __name__ == "__main__":
    main()

## 常见错误

- <strong>在弧度模型里塞进角度增益。</strong>第 3 个月的 0.05 N·m/度等于 2.86 N·m/rad。在以弧度计算的模型里直接用 0.05，回路会弱大约 57 倍，裕度就没有意义了。
- <strong>忘了保持和延迟。</strong>连续的 C × P Bode 图里没有采样。真实回路把力矩保持 5 ms，还会晚一个采样才作用；两者都增加相位滞后（在这个穿越频率处约 15°），漏掉它们，预测的 PM 就会过于乐观。
- <strong>拿没和实测对过的模型读裕度。</strong>如果开环阶跃的最终速度或 63 % 时间对不上，先修 B 和 J。参数错了，裕度就没有依据。
- <strong>忽略饱和。</strong>线性分析假设要求的力矩真的输出去了。电机一旦削顶，回路增益就不再是那个 L；测试阶跃要小，只在指令没有饱和的范围内扫增益。
- <strong>识别时换了负载。</strong>重力前馈抵消的是你建模的那部分重力，不是新加的负载或弹簧。要在关节实际工作的姿态和负载下测 tau 和 B；负载一变，J、B 和两个裕度都会动。
- **宣称「两参数 ⇒ 阶跃不可辨识」。** 一阶 τ 常常就是从阶跃读出来的。PE 讲的是回归子丰富度；应报告 `cond(ΦᵀΦ)` 和 `‖θ̂−θ‖`，而不是一刀切禁止阶跃。
- **输入能量不对齐就谈 PE。** 很大的 PRBS 对比很小的阶跃不是 PE 课。把 `Σ u²`（或峰值 `|u|`）限制在声明容差内。
- **对带噪 y 的方程误差 OLS 声称无偏。** 在 `y = z + v` 下，滞后测量 y 进了 `Φ` → EIV / EE-OLS 偏差；要明示，或改用 OE / IV。不要与 ARX 新息模型（那种下 OLS 一致）混淆。
- **把有限窗口 `cond(ΦᵀΦ)` 当成严格 PE 证书。** 打印的条件数是时域诊断；严格 PE 要求窗口 Gram 随窗口增长有正定下界。
