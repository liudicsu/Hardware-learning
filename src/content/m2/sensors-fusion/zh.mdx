## 机器人能感知什么

没有传感器的机器人，只是一台按预设动作“盲走”的机器：它执行计划，然后祈祷世界按计划变化。有了传感器，它才能把“我以为发生了什么”和“实际发生了什么”放在一起比较。停车、走直线、保持平衡、循线、发现轮子打滑，所有这些行为都从这次比较开始。

每种传感器只回答一个很窄的问题。下面这张表不是购物清单，而是一张“小车通常要问哪些问题”的地图。

| 传感器 | 测量什么 | 典型用途 | 注意什么 |
| --- | --- | --- | --- |
| 轮式编码器（wheel encoder） | 轮子转过的计数，通常还有方向 | 里程计、速度、走了多远（第 4 课） | 它只知道轮子转了多少；打滑或轮径填错，结果就会悄悄失真 |
| IMU（加速度计 + 陀螺仪，如 MPU-6050） | 含重力的加速度、<Term id="angular-velocity">角速度</Term> | 倾角、平衡、判断转向 | 有噪声、会漂移，必须做融合；它不是指南针 |
| 超声波 HC-SR04 | 用回声时间测距离 | 便宜的避障 | 波束宽，软表面会吸声；5 V 回波接 ESP32 要分压 |
| 飞行时间激光 VL53L0X | 用光的飞行时间测距离，I2C 接口 | 精确的近距离测距（最远约 2 m）；视场较窄（ST 标称约 25°），不会被超声回声搞混 | 深色、反光或透明目标以及强阳光都会缩短可用量程 |
| 反射式传感器（QTR、TCRT5000） | 有多少红外光被反射回来 | 循线（第 6 课） | 对安装高度、环境光和地面颜色很敏感；要在真实赛道上标定 |
| 二维激光雷达（如 RPLIDAR C1） | 一圈 360° 的距离 | 建图，后面几个月会用到 | 有转动部件，功耗和数据量更大，而且只看到同一高度的二维切片 |

其中编码器和 IMU 测的是机器人自己，其余几种测的是外部世界。这个区别在出故障时很有用：编码器出错，说明你对自身运动的模型不对；超声波出错，说明你对世界的描述不对，两者的修法完全不同。

价格只是大概，因为同一颗芯片在不同卖家手里能差好几倍：HC-SR04 约 $4，VL53L0X 约 $15，MPU-6050 模块约 $13，BNO085 约 $30。不要只按价格选，要选一种“它的失效方式你能接受”的传感器。

超声波传感器适合做第一个算例，因为算术简单，而且能看清“往返”这件事。室温下声速约 343 m/s，也就是 34 300 cm/s，即每微秒 0.0343 cm。HC-SR04 发出一小段超声，然后测量回声返回所需的时间。声音先到物体再返回，路程是距离的两倍，所以距离只取总路程的一半。

```text
Speed of sound ≈ 343 m/s = 0.0343 cm/µs
Echo time = 1166 µs (there and back)
Distance = 1166 µs × 0.0343 cm/µs / 2
         = 39.99 cm / 2
         = 20.0 cm
```

声速会随温度变化（大约每升高 1 °C 增加 0.6 m/s），所以 20.0 cm 是估计值，不是实验室级测量。对“前面是不是有把椅子”这种判断，它足够好用。

## 一页讲清 I2C

<Term id="i2c">I2C</Term>（Inter-Integrated Circuit，通常读作“I-squared-C”）是一根只有两条线的总线：SDA 传数据，SCL 传时钟，另外两块板必须共地。微控制器是控制器（controller），负责产生时钟；每个外设都有一个 7 位地址。每次通信开始时，控制器先发出“地址 + 读/写位”，只有认出这个地址的器件才会应答。

真正巧妙的是电气结构。每个器件的输出级都是 <Term id="open-drain">开漏（open-drain）</Term>：它可以把线拉低，却不能主动把线推高。高电平由上拉电阻（pull-up resistor）提供，典型值是 4.7–10 kΩ，很多模块板上已经自带。正因如此，两个器件不会发生总线冲突：如果它们同时把线拉低，那只是把同一个节点都接到地，线仍然是 0 V，不存在“一个输出高、一个输出低”的短路。

<Falstad title="开漏 I2C 总线与上拉电阻" circuit="i2cPullup" height={420} />

4.7 kΩ 上拉电阻在没有器件拉低时把线维持在 3.3 V。每个开关代表一个器件内部的输出晶体管。点一下任一开关，线被拉到 0 V；两个都点，仍然是 0 V，没有短路，也不会烧坏谁。这就是 I2C 允许许多器件共用总线的根本原因：任何器件都可以应答，而不会损坏其他器件。

I2C 的标准速率是 100 kHz 和 400 kHz。它不是长距离总线：线要短，地要共，尽量不要把 I2C 线沿着电机线拉过整个车架。Arduino Uno 上 SDA 是 A4，SCL 是 A5。ESP32 上几乎任意 GPIO 都能用作 I2C，经典默认是 SDA 21、SCL 22，也可以在 `Wire.begin(sda, scl)` 里传入你选的引脚。

地址冲突是最常见的实际问题。两个一模一样的传感器通常共用一个地址，不能直接挂在同一条总线上。很多芯片专门留了地址引脚：MPU-6050 的 AD0 接低电平是 0x68，接高电平是 0x69。如果模块没有地址引脚，就需要第二条总线或一个 I2C 多路复用器。

I2C 也不是你会遇到的唯一总线。SPI 用四根线——SCK、COPI（很多人仍叫它 MOSI）、CIPO（MISO），以及每个从设备一根片选 CS——没有地址，速度快得多，常见于显示屏、SD 卡和部分 IMU。UART（也就是串口）是点对点、异步的，只有 TX 和 RX，适合接 GPS 或做调试终端，但它不是共享总线。大多数机器人最后三种都会用到。

## 先找到它：I2C 扫描器

拿到任何新的 I2C 器件，第一个要跑的程序不是驱动，而是扫描器。它遍历 7 位地址空间，逐个问“这个地址有没有人”，然后把应答的地址打印出来。这几十行代码省下的时间，比任何库都多。

<CodeSource path="examples/month-2/sensors-fusion/i2c_scanner/i2c_scanner.ino" />

```cpp
// I2C scanner: try every 7-bit address and report the ones that answer.
#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();
  Serial.println(F("Scanning..."));
  int found = 0;
  for (uint8_t addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {      // 0 = the device acknowledged
      Serial.print(F("Found device at 0x"));
      if (addr < 16) Serial.print('0');
      Serial.println(addr, HEX);
      found++;
    }
  }
  Serial.print(found);
  Serial.println(F(" device(s) found"));
}

void loop() {}
```

`beginTransmission(address)` 只是把地址装进 Wire 库的缓冲区，`endTransmission()` 才真正把这次传输发出去并返回状态。中间没有写任何数据，所以这次传输本质上就是“这个地址有人吗？”返回 0 表示器件应答了（ACK），返回 2 表示地址没有得到应答。扫描器暂时不关心其他返回值；先分清 0 和非 0 就够了。

扫描器只能告诉你“有人应答”，不能告诉你“对方是谁”；另一个芯片完全可能用同一个地址。要确认身份，得读 WHO_AM_I 寄存器，后面很快就会讲到。

什么都没找到时，按这个顺序检查：传感器有没有供电和接地；SDA、SCL 有没有接反；`Wire.begin()` 或接线有没有用错引脚；模块有没有上拉电阻（有些裸模块没有）；3.3 V-only 的模块有没有接到错误的电源轨。如果扫描器不是打印结果而是卡住，很可能有一条线被持续拉低——常见原因是接线短路，或者某个器件把总线占住了。断电、检查接线，再重新上电。

## 读数据手册，而不是教程

这个月的里程碑不是“我抄了一个库的示例”，而是：给我一个传感器、一份数据手册和一块单片机，我能自己接线、自己读出数据。教程适合用来建立方向感，但它们会过时，会把<Term id="register">寄存器</Term>操作藏起来，而且很少告诉你它假设了哪种配置。

MPU-6050 的厂商 InvenSense 发布两份文档：一份产品规格书（product specification），一份单独的寄存器映射（register map）。前者告诉你芯片能做什么、引脚是什么、每个量程有多灵敏；后者告诉你该读写哪个字节。两份都要看。

本课用到的寄存器如下：

| 寄存器 | 地址 | 作用 |
| --- | --- | --- |
| WHO_AM_I | 0x75 | 固定读出 0x68——证明你在和正确的芯片说话 |
| PWR_MGMT_1 | 0x6B | 上电时第 6 位 SLEEP 是置位的——写 0x00 唤醒芯片，否则所有读数都是 0 |
| ACCEL_XOUT_H … | 0x3B–0x40 | 加速度 X、Y、Z，各 16 位 |
| TEMP_OUT | 0x41–0x42 | 温度 |
| GYRO_XOUT_H … | 0x43–0x48 | 陀螺仪 X、Y、Z |

寄存器地址和数值以十六进制书写；[数学参考页](/zh/math#hex)逐位讲解了 0x68 = 0b01101000 = 104。

WHO_AM_I 是嵌入式开发里最简单的一次自检。从 0x75 读一个字节，期望值是 0x68。读到 0xFF，通常是总线没接好或器件没应答；读到别的值，说明你在和另一颗芯片说话。

睡眠位是经典陷阱。复位后 PWR_MGMT_1 的第 6 位置位，芯片处于睡眠状态。这时你可以读一整天的寄存器，读到的全是 0。往 0x6B 写 0x00，稍等片刻，传感器才开始出数据。

数据是有符号 16 位、大端（big-endian）排列：高字节在前。从 0x3B 开始一次连读 14 个字节，依次得到加速度 X、Y、Z，温度，以及陀螺仪 X、Y、Z。连读还有一个好处：这些值属于同一次采样；如果一个寄存器一个寄存器地读，几毫秒的间隔可能把两个不同瞬间的数据拼在一起，机器人一动就会出错。

在默认量程下，灵敏度是固定且简单的：加速度计设为 ±2 g，即 16384 LSB/g；陀螺仪设为 ±250 °/s，即 131 LSB/(°/s)。两者都来自输出格式：每个轴是一个有符号 16 位数，−32768 … +32767，所选量程正好映射到这个范围上，所以 32768 / 2 g = 16384 LSB/g，32768 / 250 °/s = 131.07，数据手册列为 131 LSB/(°/s)。这些常数不是永远成立。改了 AFS_SEL 或 FS_SEL，常数也会变，所以一定要确认代码配置的是哪个量程。

```text
raw az = 16384  →  16384 / 16384 = 1.00 g
raw gy = −262   →  −262 / 131 = −2.0 °/s
```

第一行是板子平放时竖直轴上应该看到的数：1 g 重力。第二行是每秒 2 度的反向慢转。如果把原始字节存进无符号 16 位变量，负数会变成一个巨大的正数；要用 `int16_t`，并且按正确的字节顺序拼接。

**二进制补码。** 有符号 16 位数以<Term id="twos-complement">补码</Term>形式存储：最高位的权重是 −32768，其余 15 位的权重照常为 +1 … +16384，因此范围是 −32768 … +32767。要对一个值取负，就把每一位取反再加 1。

```text
262            = 0x0106 = 0000 0001 0000 0110
逐位取反       = 0xFEF9 = 1111 1110 1111 1001
加 1           = 0xFEFA = 1111 1110 1111 1010  = −262
按无符号读     = 0xFEFA = 65274 = 65536 − 262
高字节 0xFE、低字节 0xFA：(int16_t)((0xFE << 8) | 0xFA) = −262
```

## 两个都不完美的传感器

加速度计和陀螺仪的失效方式正好相反，这正是它们值得一起用的原因。

本节用到的数学都汇总在[数学参考页](/zh/math)：[正弦与余弦分量](/zh/math#trig-components)、[弧度](/zh/math#radians)、[对速率 × dt 累加](/zh/math#rate-accumulation)，以及脚本中噪声数字用到的[标准差](/zh/math#stddev-rms)。

加速度计测量加速度，而重力也算加速度。静止时，它感受到的唯一加速度就是竖直向下的 1 g 重力。如果板子绕 Y 轴倾斜了 θ 角，重力就会分解到 X、Z 两个轴上：`ax = g × sin θ`，`az = g × cos θ`。于是：

```text
θ = atan2(ax, az)
```

`atan2` 返回的是弧度，打印成角度前要乘 `180 / PI`。这个估计“平均而言”是对的，因为重力是绝对参考，误差不会累积。但它有噪声——每个采样都在抖——而且任何真实加速度都会污染它。振动、电机猛的一下、撞到桌子、机器人加速前进，都会叠加到重力上，加速度计分不清哪个是重力、哪个是运动。急加速时，它给出的“倾角”可能错得很离谱。

陀螺仪测的是角速度，不是角度。要得到角度就得积分：每个循环加上 `rate × dt`。结果平滑、响应快，对真实转动反应立刻。但它是相对的：它只知道“从开始到现在转了多少”。一个很小的<Term id="gyro-bias">零偏</Term>（bias），比如 1.5 °/s，积分起来就会变成无限增长的误差。

<Formula label="陀螺仪漂移">角度误差 = 零偏 × 时间</Formula>

```text
bias = 1.5 °/s
after 10 s: 1.5 °/s × 10 s = 15°
after 60 s: 1.5 °/s × 60 s = 90°
```

一分钟后，纯陀螺仪角度会错 90°，哪怕机器人根本没动。陀螺仪内部没有任何参考能发现这件事；它只是在忠实地积分自己的偏移。

## 互补滤波

<Term id="complementary-filter">互补滤波（complementary filter）</Term>是把两者结合的最简单方法，也是在碰卡尔曼滤波之前应该先写出来的东西。核心就是一行：

<Formula label="互补滤波">angle = α × (angle + rate × dt) + (1 − α) × accelAngle</Formula>

α 接近 1，典型值是 0.98。第一项拿上一时刻的估计，加上陀螺仪的预测；第二项把这个预测往加速度计角度那边拉。因为 α 接近 1，短时间尺度上陀螺仪说了算；因为 1 − α 虽小但不为零，长时间尺度上加速度计会赢。它相当于对陀螺仪做<Term id="low-high-pass-filter">高通</Term>、对加速度计做低通，两个权重加起来正好是 1。

时间常数（time constant）描述加速度计多快能把陀螺仪拉回来：

```text
τ = α × dt / (1 − α)
  = 0.98 × 0.01 s / 0.02
  = 0.49 s
```

时间常数衡量的是什么：先暂时放下加速度计这一项。每一步都保留上一时刻估计的 α 倍，所以 n 步之后，旧误差还剩下 αⁿ 倍。时间常数就是这剩余比例降到 1/e 所需的时间：

```text
αⁿ = e^(−1)  →  n = −1 / ln α = −1 / ln 0.98 = 49.5 步
τ = n × dt = 49.5 × 0.01 s = 0.495 s
```

当 α 接近 1 时，−ln α ≈ 1 − α，于是 τ ≈ dt / (1 − α) = 0.50 s。上面框里的公式 τ = α × dt / (1 − α) = 0.49 s，并不是对同一个衰减过程的第三种近似。它来自按期望时间常数选 α 的常用做法，α = τ / (τ + dt)，也就是课程自己的仿真所采用的形式（《你的前两台机器人：循线小车与自平衡车》平衡车模型里的 `a = 0.5 / (0.5 + dt_ctrl)`）；把该定义解出 τ，就得到 τ = α × dt / (1 − α)。上面的推导给出的是精确衰减时间 0.495 s，框里的公式则是设计惯例；在 α = 0.98、100 Hz 时，三个数值 0.49 s、0.495 s 和 0.50 s 相差约在 2 % 以内。

在 100 Hz（dt = 0.01 s）、α = 0.98 时，修正时间常数约为半秒。τ 越大越平滑但越慢；τ 越小响应越快，但放进来的加速度计噪声也越多。

下面这段 Python 在接线之前先把问题模拟一遍。板子先平放，在 t = 3 s 到 4 s 之间倾斜到 30°，保持到 7 s，然后在 7 s 到 8 s 之间放平。模拟陀螺仪读数偏高 1.5 °/s，加速度计带噪声。

```python
def simulate(alpha, seconds=12.0, seed=7):
    rng = random.Random(seed)
    gyro_only = fused = 0.0
    rows = []
    for i in range(1, int(seconds / DT) + 1):
        t = i * DT
        rate = (true_pitch(t) - true_pitch(t - DT)) / DT
        gyro = rate + GYRO_BIAS + rng.gauss(0, GYRO_NOISE)
        th = math.radians(true_pitch(t))
        ax = math.sin(th) + rng.gauss(0, ACCEL_NOISE)
        az = math.cos(th) + rng.gauss(0, ACCEL_NOISE)
        accel = math.degrees(math.atan2(ax, az))
        gyro_only += gyro * DT
        fused = alpha * (fused + gyro * DT) + (1 - alpha) * accel
        rows.append((t, true_pitch(t), gyro_only, accel, fused))
    return rows


def summary(rows):
    """Error of the fused angle: mean and spread while flat (t > 10 s), and the worst error overall."""
    flat = [r[4] - r[1] for r in rows if r[0] > 10]
    mean = sum(flat) / len(flat)
    spread = math.sqrt(sum((e - mean) ** 2 for e in flat) / len(flat))
    worst = max(abs(r[4] - r[1]) for r in rows)
    return mean, spread, worst


if __name__ == "__main__":
    rows = simulate(alpha=0.98)
    print(" t_s  true  gyro_only  accel_only  fused")
    for t, true, g, a, f in rows:
        if abs(t - round(t)) < 1e-9 and round(t) in (1, 3, 4, 7, 8, 12):
            print(f"{t:4.0f} {true:5.1f} {g:10.1f} {a:11.1f} {f:6.1f}")
    print()
    print("alpha  offset_flat  noise_flat  worst_error")
    for alpha in (0.90, 0.98, 0.995):
        mean, spread, worst = summary(simulate(alpha))
        print(f"{alpha:<6} {mean:10.2f}  {spread:10.2f}  {worst:11.1f}")
```

α 小，放进来的加速度计噪声多，但压陀螺零偏压得快；α 大，输出更平滑，却会留下更大的固定偏移，因为陀螺零偏漏进来了。稳态偏移近似为：

```text
offset ≈ α / (1 − α) × bias × dt
       = 0.98 / 0.02 × 1.5 °/s × 0.01 s
       = 0.735°
```

这个公式直接来自滤波方程本身。板子水平放置时，加速度计角度平均为 0°；进入稳态后估计值不再变化，于是等号两边出现同一个值 `angle`：

```text
angle = α × (angle + bias × dt) + (1 − α) × 0
angle × (1 − α) = α × bias × dt
angle = α × bias × dt / (1 − α) = 0.98 × 1.5 °/s × 0.01 s / 0.02 = 0.735°
```

这和表中测到的 0.72° 对得上（小差别来自噪声和四舍五入）。这个公式也解释了另外两行：α = 0.90 约为 0.135°，α = 0.995 约为 2.985°。

<strong>动手实验。</strong>本实验展示滤波器时间常数 τ 如何决定滞后，以及 1.5 °/s 陀螺零偏造成的稳态静差。

1. 保持 α 为默认值 0.980，读取 τ = 0.49 s 与零偏 1.5 °/s 造成的静差 = 0.7°。
2. 将 α 设为 0.900，读取 τ = 0.09 s 与静差 = 0.1°。
3. 将 α 设为 0.995，读取 τ = 1.99 s 与静差 = 3.0°。
4. 结论：静差等于零偏 × τ；α = 0.980 时 1.5 °/s × 0.49 s = 0.735°，显示为 0.7°，而 α 越大表示越长时间信任陀螺，因为 τ = α·dt/(1−α)。

正确的修法不是把 α 调小，而是从源头去掉零偏。让机器人静止，把陀螺仪平均 1–2 s——100 Hz 下就是 100–200 个采样——把这个平均值叫作 `bias`，之后每次积分前先减掉它。不要在机器人运动时标定，否则你会把真实转动也平均进零偏里。机器人发热或搬到温度差很多的房间时，零偏会变；开机时快速重标一次，成本很低。

## 放到真芯片上

把常见的 GY-521 模块接到 Uno 上，接线很短：VCC 接 5 V（模块上有 3.3 V 稳压器），GND 接 GND，SDA 接 A4，SCL 接 A5，AD0 悬空即为地址 0x68。多数 GY-521 在 I2C 线上已经有 3.3 V 上拉；但要看清你手里是哪一版，有些裸 MPU-6050 模块只支持 3.3 V，也没有稳压器。同一份代码可以跑在 ESP32 上，只是 I2C 引脚不同——用 `Wire.begin(sda, scl)` 传入你选的引脚，经典默认是 21 和 22——但 ESP32 是 3.3 V 逻辑，未经确认不要把 5 V 信号送进去。

<CodeSource path="examples/month-2/sensors-fusion/imu_pitch/imu_pitch.ino" />

```cpp
// MPU-6050 pitch angle three ways: gyro only, accelerometer only, complementary filter.
// Wiring (Uno): VCC -> 5V (the common GY-521 breakout has a regulator), GND -> GND,
// SDA -> A4, SCL -> A5. AD0 left unconnected -> address 0x68.
#include <Wire.h>

const uint8_t MPU = 0x68;
const uint8_t REG_PWR_MGMT_1 = 0x6B;
const uint8_t REG_ACCEL_XOUT_H = 0x3B;
const uint8_t REG_WHO_AM_I = 0x75;

const float ACCEL_LSB_PER_G = 16384.0;   // +-2 g range (datasheet, default)
const float GYRO_LSB_PER_DPS = 131.0;    // +-250 deg/s range (datasheet, default)
const float ALPHA = 0.98;                // complementary filter weight on the gyro
const unsigned long PERIOD_MS = 10;      // 100 Hz loop

float gyroOnly = 0, fused = 0;
unsigned long last = 0, lastPrint = 0;

void writeReg(uint8_t reg, uint8_t value) {
  Wire.beginTransmission(MPU);
  Wire.write(reg);
  Wire.write(value);
  Wire.endTransmission();
}

uint8_t readReg(uint8_t reg) {
  Wire.beginTransmission(MPU);
  Wire.write(reg);
  Wire.endTransmission(false);           // repeated start: keep the bus
  Wire.requestFrom(MPU, (uint8_t)1);
  return Wire.read();
}

int16_t read16() {                       // registers are big-endian: high byte first
  int16_t hi = Wire.read();
  return (hi << 8) | Wire.read();
}

void setup() {
  Serial.begin(115200);
  Wire.begin();
  writeReg(REG_PWR_MGMT_1, 0x00);        // the chip powers up asleep: clear SLEEP
  Serial.print(F("WHO_AM_I = 0x"));
  Serial.println(readReg(REG_WHO_AM_I), HEX);
  Serial.println(F("t_s,gyro_only,accel_only,fused"));
  last = millis();
}

void loop() {
  unsigned long now = millis();
  if (now - last < PERIOD_MS) return;
  float dt = (now - last) / 1000.0;
  last = now;

  Wire.beginTransmission(MPU);
  Wire.write(REG_ACCEL_XOUT_H);
  Wire.endTransmission(false);
  Wire.requestFrom(MPU, (uint8_t)14);    // accel XYZ, temperature, gyro XYZ
  int16_t ax = read16(), ay = read16(), az = read16();
  read16();                              // temperature, unused
  read16();                              // gyro X, unused
  int16_t gy = read16();
  read16();                              // gyro Z, unused

  float accelPitch = atan2(ax / ACCEL_LSB_PER_G, az / ACCEL_LSB_PER_G) * 180.0 / PI;
  float rate = gy / GYRO_LSB_PER_DPS;    // deg/s around the Y axis

  gyroOnly += rate * dt;                                       // drifts
  fused = ALPHA * (fused + rate * dt) + (1 - ALPHA) * accelPitch;  // does not

  if (now - lastPrint >= 1000) {         // one line per second
    lastPrint = now;
    Serial.print(now / 1000.0, 1);
    Serial.print(',');
    Serial.print(gyroOnly, 1);
    Serial.print(',');
    Serial.print(accelPitch, 1);
    Serial.print(',');
    Serial.println(fused, 1);
  }
}
```

逐段看一遍，每一行都在教东西。`writeReg(REG_PWR_MGMT_1, 0x00)` 先把睡眠位清掉。读 WHO_AM_I 用来验证：它确认地址、接线和总线都正常。`endTransmission(false)` 发出重复起始（repeated start）而不是释放总线，这样 MPU-6050 会保留寄存器指针，后面的 `requestFrom` 就从你刚选中的寄存器开始读。一次 14 字节的连读，把整组数据在同一个瞬间取回。

循环用的是第 2 课（定时与中断）里的 `millis()` 模式，但它测量 `dt`，而不是假设 `dt` 一定是 10 ms。这一点很重要：一次串口打印、一次慢的 I2C 传输、一个中断，都可能把循环拉长；滤波器必须用真实流逝的时间积分，而不是你希望的时间。这个安装方向下，陀螺仪的 Y 轴对应俯仰角；慢慢倾斜板子，确认 gyro-only 和 accel-only 朝同一个方向变化。如果方向相反，就把 rate 取负。

## 常见错误与检查清单

下面这些坑，最消耗新手的时间：

- 忘了唤醒 MPU-6050：不写 PWR_MGMT_1，所有读数都是零。
- 地址不对：AD0 被拉高，或者 0x68 已经被另一个器件占用。
- SDA 和 SCL 接反，或者忘了有些裸模块根本没有上拉电阻。
- I2C 线又长又松，还贴着电机线走，然后怪传感器。
- 把一个值的两个字节当成无符号数读，或者字节顺序反了，于是小的负数变成巨大的正数。
- 角度和弧度混用：`atan2` 返回弧度，忘了换算，结果会差大约 57 倍。
- 直接假设 `dt`，而不是测量它，尤其是串口打印或其他工作把循环拉长之后。
- 陀螺仪的轴或符号和加速度计角度对不上，两个修正方向相反。
- IMU 装得松松垮垮，或者紧贴振动电机，于是加速度计测到的是车架振动而不是重力。
- 把 5 V 的 HC-SR04 回波直接送进 ESP32 输入；要分压。

### 声明的离散噪声模型 → Q/R

全程使用度、deg/s 和秒。真倾角为 `12 sin(2πt/6) + 3 sin(2πt/2)` 度，dt=0.02s、1500次更新。合成加速度计角度为 `z=theta+na`，白噪声 sigma_a=1.5deg；此**仅重力角度模型排除平动加速度**、振动和比例误差，不在动态区间偷偷喂真值。陀螺读数是真角度有限差分角速度，加上一采样零偏与独立白噪声 sigma_g=0.5deg/s。初始零偏是未知抽样，sigma_b0=0.5deg/s；每次陀螺读数之后以增量标准差 `sigma_rw sqrt(dt)` 随机游走，sigma_rw=0.03deg/s/√s。

状态 x=[theta,bias]，`F=[[1,−dt],[0,1]]`，输入 `[dt gyro,0]`，`H=[1,0]`。本模型按采样保持零偏，使角度与零偏过程误差独立：`Q0=diag((sigma_g dt)², sigma_rw² dt)=diag(0.000100,0.000018)`，`R0=sigma_a²=2.250000`。它们来自**声明的合成噪声模型**，不是根据留出误差猜出或在器件上实测；也不是带交叉项的连续布朗过程精确离散化。预测 `x−=F x+B gyro`、`P−=F P Fᵀ+Q`；新息 `z−H x−`，增益 `K=P−Hᵀ/(H P−Hᵀ+R)`，更新 `x=x−+K innovation`。代码直接展开2×2协方差，不用 NumPy。

各滤波器用同一首个有噪加速度角初始化。KF 的 `P0=diag(R0,sigma_b0²)`，零偏**先验均值为0**，不是抽到的真零偏。**两种滤波器都不知道真实零偏**；`estimate()` 没有真值 / 真零偏输入。真值只进入调参目标和留出评分，不进入递归更新。

### 等量调参，然后冻结

普通互补用陀螺预测并按 α 混合，零偏固定为0。自适应变体除角度混合外，还用同一新息更新 `bhat -= kb dt innovation`；加入它是为了不因“只有 KF 能估偏”就宣布 KF 必胜。模型容量仍不同，已明示。

每个调参滤波器都用 **9候选 ×3调参种子 ×1500更新 =40500次递归更新**，相同均方误差目标、201/202/203数据流，没有额外搜索。普通互补 α 网格是0.5、0.65、0.8、0.9、0.95、0.97、0.985、0.995、0.999；自适应网格为 α 的0.9/0.97/0.995与 kb 的0.01/0.05/0.2 s⁻² 交叉。KF 将声明的 Q0、R0 分别乘0.5/1/2（3×3），不能根据评估真值任意拟合协方差。选中普通 α=**0.95**，自适应 α=**0.97**、kb=**0.2**，KF 乘数 **(1.0,1.0)**。这是相同候选 / 样本更新预算，不是相同浮点成本，也不等于连续最优解。

```python
#!/usr/bin/env python3
"""Shared tilt-only sensor stream; no filter receives true gyro bias.
Units: angle deg, rate deg/s, time s. Synthetic gravity-only accelerometer
angle (no translational acceleration), white gyro/accel noise, bias random walk.
During each sample gyro = finite-difference true rate + previous bias + noise;
bias then takes an independent random-walk increment. Model for x=[angle,bias]:
F=[[1,-dt],[0,1]], control=[dt*gyro,0], H=[1,0].
Q0=diag((sigma_g*dt)^2, sigma_rw^2*dt), R0=sigma_a^2.
P0=diag(R0,sigma_b0^2); bias prior MEAN=0, not the sampled true bias.
KF tests 3x3 scale factors of the declared Q0,R0. Plain complementary tests
9 alphas. Bias-adaptive complementary tests 3x3 alpha,bias-gain settings.
Each gets 9 candidates x 3 tuning seeds x 1500 updates=40500 updates, same
squared-error objective. Tuning truth is training-only supervision; held-out
truth scores frozen filters. Model knowledge is shared, not oracle bias.
Model capacity differs: plain complementary has no bias state; adaptive/KF do.
This is not an EKF INS, Allan-variance characterization or MPU6050 measurement.
"""
import itertools
import math
import random
import statistics

DT, N = 0.02, 1500
SIGMA_G, SIGMA_A = 0.5, 1.5
SIGMA_B0, SIGMA_RW = 0.5, 0.03
TUNE = (201, 202, 203)
EVAL = (221, 222, 223, 224, 225)
GRIDS = {
    "complementary": tuple((a, 0.) for a in (.5, .65, .8, .9, .95, .97, .985, .995, .999)),
    "bias_complementary": tuple(itertools.product((.9, .97, .995), (.01, .05, .2))),
    "KF": tuple(itertools.product((.5, 1., 2.), repeat=2)),
}


def angle(t):
    return 12 * math.sin(2 * math.pi * t / 6) + 3 * math.sin(2 * math.pi * t / 2)


def sensors(seed):
    rng = random.Random(seed)
    bias = rng.gauss(0, SIGMA_B0)
    truth = tuple(angle(k * DT) for k in range(N + 1))
    accel = [truth[0] + rng.gauss(0, SIGMA_A)]
    gyro = []
    for prev, now in zip(truth, truth[1:]):
        gyro.append((now - prev) / DT + bias + rng.gauss(0, SIGMA_G))
        bias += rng.gauss(0, SIGMA_RW * math.sqrt(DT))
        accel.append(now + rng.gauss(0, SIGMA_A))
    return tuple(gyro), tuple(accel), truth


def estimate(kind, config, gyro, accel):
    # No truth or true-bias argument; all arms initialize from the same z0.
    a, bhat = accel[0], 0.
    out = [a]
    p00, p01, p11 = SIGMA_A**2, 0., SIGMA_B0**2
    for g, z in zip(gyro, accel[1:]):
        pred = a + DT * (g - bhat)
        innovation = z - pred
        if kind == "gyro":
            a = pred
        elif kind == "accel":
            a = z
        elif kind in ("complementary", "bias_complementary"):
            alpha, kb = config
            a = pred + (1 - alpha) * innovation
            bhat -= kb * DT * innovation
        else:
            qscale, rscale = config
            qtheta = qscale * (SIGMA_G * DT)**2
            qbias = qscale * SIGMA_RW**2 * DT
            r = rscale * SIGMA_A**2
            pp00 = p00 - 2 * DT * p01 + DT**2 * p11 + qtheta
            pp01 = p01 - DT * p11
            pp11 = p11 + qbias
            k0, k1 = pp00 / (pp00 + r), pp01 / (pp00 + r)
            a, bhat = pred + k0 * innovation, bhat + k1 * innovation
            p00, p01, p11 = (1-k0)*pp00, (1-k0)*pp01, pp11-k1*pp01
            assert p00 >= 0 and p11 >= 0 and p00*p11-p01*p01 > -1e-12
        out.append(a)
    return out


def mse(estimate_values, truth):
    return statistics.fmean((a-b)**2 for a, b in zip(estimate_values, truth))


def main():
    assert set(TUNE).isdisjoint(EVAL) and all(len(g) == 9 for g in GRIDS.values())
    tuning = [sensors(s) for s in TUNE]
    chosen = {}
    for kind, grid in GRIDS.items():
        chosen[kind] = min(grid, key=lambda cfg: statistics.fmean(
            mse(estimate(kind, cfg, g, z), truth) for g, z, truth in tuning))
    print(f"dt={DT} N={N}; sigma_g={SIGMA_G} deg/s sigma_a={SIGMA_A} deg sigma_b0={SIGMA_B0} deg/s sigma_rw={SIGMA_RW} deg/s/sqrt(s)")
    print(f"Q0_diag={(SIGMA_G*DT)**2:.6f},{SIGMA_RW**2*DT:.6f}; R0={SIGMA_A**2:.6f}; bias_prior_mean=0 (not truth)")
    print("tune_seeds=201,202,203; held_out=221..225; 9 candidates x 3 x 1500 = 40500 updates/filter")
    for kind, cfg in chosen.items():
        print(f"selected {kind} {cfg}")
    arms = ("gyro", "accel", "complementary", "bias_complementary", "KF")
    scores = {a: [] for a in arms}
    print("held_out_seed gyro_RMSE_deg accel_RMSE_deg complementary_RMSE_deg bias_complementary_RMSE_deg KF_RMSE_deg")
    for seed in EVAL:
        g, z, truth = sensors(seed)
        row = [math.sqrt(mse(estimate(a, chosen.get(a), g, z), truth)) for a in arms]
        for a, value in zip(arms, row):
            scores[a].append(value)
        print(str(seed) + " " + " ".join(f"{v:.6f}" for v in row))
    print("arm mean_RMSE_deg population_sd min max")
    for a, values in scores.items():
        print(f"{a} {statistics.fmean(values):.6f} {statistics.pstdev(values):.6f} {min(values):.6f} {max(values):.6f}")
    print("shared data/prior model; neither filter knows true bias; no universal winner; IMU hardware 本页未运行")


if __name__ == "__main__":
    main()
```

## SPI 模式：共享导线，改变采样边沿
SPI 用 SCK、COPI/MOSI、CIPO/MISO 同步传位，CS 选择外设；CS 不是 I2C 地址。[Arduino SPI 文档](https://docs.arduino.cc/learn/communication/spi/)给出下表。**leading** 是从空闲电平离开的第一跳，**trailing** 是回到空闲的第二跳。CPOL 定空闲电平；CPHA=0 在 leading 采样、trailing 推出（首位要预先准备），CPHA=1 在 leading 推出、trailing 采样。

<Resource id="arduino-spi-modes" />

| 模式 | CPOL | CPHA | 空闲 | 采样 | 推出/输出 |
|---|---|---|---|---|---|
| SPI_MODE0 | 0 | 0 | 低 | 上升 | 下降 |
| SPI_MODE1 | 0 | 1 | 低 | 下降 | 上升 |
| SPI_MODE2 | 1 | 0 | 高 | 下降 | 上升 |
| SPI_MODE3 | 1 | 1 | 高 | 上升 | 下降 |

模式、CS 建立/保持、字长、位序和时钟上限都以器件数据手册为准，不能默认所有传感器都用 Mode0。**本节不给器件 MHz 数值**。`SPISettings` 分开指定时钟、MSBFIRST/LSBFIRST 和模式；`beginTransaction` 配置总线，不替代拉低/释放 CS。有些器件要求命令、地址和数据期间保持 CS，不能逐字节随意切换。

### 确定性共享边沿实验，不是模拟电气时序验证

`spi_mode_mismatch_toy.py` 对每种发送模式和位序生成一份物理 MOSI/SCK 流，**匹配**、**CPOL 错**、**CPHA 错**三接收组查看**同一导线**、同一载荷和 CS。载荷为 **A5 00 FF 3C 81 01 96 69**，共 64 位；同时测 MSB-first / LSB-first。CPOL 错（`mode XOR 2`）和 CPHA 错（`mode XOR 1`）在此理想解码器选中同一个相反物理边沿，因此两组结果相同，不是两次独立噪声实验。

全部时间是**合成任意单位**，不是 ns 或 MHz：半周期=1，推出到 MOSI 传播延迟=0.2，接收在边沿+0.1 或边沿+0.3 捕获。CPHA0 预装首位，CPHA1 声明空闲数据0。两种情况下匹配组都在稳定半周期后采样；错误组靠近推出边沿，变化前可能读到旧位，变化后可能读到下一位。这两个确定性孔径情形只说明时序约定被破坏，**不模拟真实亚稳态，也不保证某个错误字节**。错模式可能在某些图样上通过，甚至在一个合成孔径下全部通过，但不能据此放心使用。

报告 **BER = 错位数 / 64** 和接收首字节（发送 A5）。MSB-first 时 TX0、孔径0.3 的两错模式组均为 **27/64=0.421875**，首字节 **4A**（类左移）；TX1、孔径0.1 的 BER 相同，但首字节为 **52**（类右移）；TX2/3 重复对应边沿关系。匹配组在全部模式 / 位序 / 孔径下 BER 均为0。独立单字节 TX1/MSB/孔径0.1/RX0 中 **00→00** 通过，但 **FF→7F**、**A5→52**、**96→4B** 失败，不能只测全零。一个 CS 帧内的字节边界会带入前一位，连续流不能当作独立字节解释。

帧前/后 CS 为高时的时钟均忽略。玩具限定一个 CS 帧内是完整 8 位字，末尾不完整就拒收；这不是所有 SPI 协议的通则。正确采样的 96 若用相反位序解码会变成69，边沿正确并不等于位序正确。真实 SPI 器件、电气建立/保持和示波器测量：**本页未运行**。这里不重做 I2C 上升沿或原有传感器滤波。

```python
#!/usr/bin/env python3
"""Deterministic SPI edge surrogate; no device clock rate or analog validation.
Shared physical MOSI/SCK/CS per TX mode/order and aperture case for all RX arms.
Synthetic time units: half period=1, propagation=0.2, apertures=0.1/0.3.
Wrong-edge capture coincides with launch; which bit arrives is timing-dependent,
not a prediction of real metastability. Both clean mismatches and shifted garbage
are intentional. Eight-bit words in one active-low CS frame; COPI/MOSI only.
"""
from bisect import bisect_right

PAYLOAD = bytes((0xA5,0x00,0xFF,0x3C,0x81,0x01,0x96,0x69))
DELAY = .2
APERTURES = (.1,.3)
ORDERS = ("MSB","LSB")


def bits_of(data, order):
    positions=range(7,-1,-1) if order=="MSB" else range(8)
    return tuple((byte>>bit)&1 for byte in data for bit in positions)


def sample_rising(mode):
    cpol,cpha=divmod(mode,2)
    return (cpol==0) == (cpha==0)


def waveform(data, mode, order):
    cpol,cpha=divmod(mode,2)
    bits=bits_of(data,order)
    # Unselected clocks before/after the CS frame must not enter RX framing.
    edges=[(-2.,True,False),(-1.,False,False)]
    changes=[(-10.,0)]
    if cpha==0:
        changes.append((0.,bits[0]))  # First bit preloaded before leading edge at t=1.
    for j,bit in enumerate(bits):
        lead,trail=2*j+1.,2*j+2.
        edges.extend(((lead,cpol==0,True),(trail,cpol==1,True)))
        launch=lead if cpha else trail
        value=bit if cpha else (bits[j+1] if j+1<len(bits) else 0)
        changes.append((launch+DELAY,value))
    edges.extend(((2*len(bits)+1.,True,False),(2*len(bits)+2.,False,False)))
    return tuple(edges),tuple(changes)


def receive(wire, mode, order, aperture):
    edges,changes=wire
    times=tuple(t for t,_ in changes)
    captured=[]
    for time,rising,selected in edges:
        if selected and rising==sample_rising(mode):
            index=bisect_right(times,time+aperture)-1
            captured.append(changes[index][1])
    if len(captured)%8:
        raise ValueError("partial 8-bit CS frame")
    positions=range(7,-1,-1) if order=="MSB" else range(8)
    return bytes(sum(bit<<place for bit,place in zip(captured[j:j+8],positions))
                 for j in range(0,len(captured),8))


def bit_errors(expected, actual):
    if len(expected)!=len(actual):
        raise ValueError("framing length differs")
    return sum((a^b).bit_count() for a,b in zip(expected,actual))


def main():
    print("SPI synthetic edge schedule: half_period=1 prop_delay=0.2 aperture=0.1/0.3 time units")
    print("shared payload=A5 00 FF 3C 81 01 96 69; 64 bits; one active-low CS frame")
    print("TX_mode order aperture RX_arm RX_mode errors BER first_byte")
    for mode in range(4):
        for order in ORDERS:
            wire=waveform(PAYLOAD,mode,order)
            for aperture in APERTURES:
                for name,rx in (("matched",mode),("CPOL_wrong",mode^2),("CPHA_wrong",mode^1)):
                    result=receive(wire,rx,order,aperture)
                    errors=bit_errors(PAYLOAD,result)
                    print(f"{mode} {order} {aperture:.1f} {name} {rx} {errors} {errors/64:.6f} {result[0]:02X}")
    print("varied-pattern diagnostic: TX1 MSB aperture0.1 RX0 (wrong phase)")
    result=receive(waveform(PAYLOAD,1,"MSB"),0,"MSB",.1)
    print(" ".join(f"{a:02X}->{b:02X}" for a,b in zip(PAYLOAD,result)))
    print("isolated-byte same wrong mode/timing: "+" ".join(
        f"{v:02X}->{receive(waveform(bytes((v,)),1,'MSB'),0,'MSB',.1)[0]:02X}"
        for v in (0x00,0xFF,0xA5,0x96)))
    reversed_order=receive(waveform(bytes((0x96,)),0,"MSB"),0,"LSB",.1)
    print(f"wrong bit order: TX96 MSB decoded_LSB={reversed_order[0]:02X}")
    print("CS-high clocks ignored; partial 8-bit CS frames rejected; CS is not a device address")
    print("Wrong-edge zero BER is possible in this timing model, NOT proof of a compatible mode")
    print("No noise/no random seeds; no MHz claim; real device/scope: 本页未运行")


if __name__=="__main__":
    main()
```

## 磁力计硬铁与软铁标定

前面已经提醒：IMU「不是指南针」——陀螺积分会漂，原始磁力计读数也要先清理本地磁场才能当航向。机架内有两类近似不随时间变的畸变。**硬铁**偏置平移测量云的中心（同体磁化材料造成的永久偏移）。**软铁**拉伸把球面拉成椭球（或把水平圆拉成椭圆），即偏折已有磁场。本节标定这两者。它**不是** KF 对互补滤波的重做，也**不是**再写一段「IMU 不是指南针」的空话。

### 偏置与拉伸

水平面内，固定幅值的干净磁场在偏航时描出圆心在原点的圆。硬铁只移动圆心。软铁改变不同轴上的半径。对原始云做 `atan2(my, mx)` 的航向因此带有随偏航变化的误差，直到两者都被去掉。

**范围。** 地理磁偏角与平台倾角 / 磁倾角不在本节范围；此处航向只相对合成水平场 `B_true` 计量。

### 公平设定

`mag_hard_soft_iron_toy.py` 是**合成**的，只用标准库。每个臂共享**同一**真实水平磁场 `B_true = (1, 0)`、**同一** 72 个偏航采样（5° 一步）、**同一**对角软铁拉伸 `S = (1.35, 0.72)`、**同一**硬铁偏置 `b = (0.35, −0.22)`，以及**同一**多种子高斯噪声（σ = 0.03）：

| 臂 | 对共享样本的校正 |
|---|---|
| A_raw | 无 |
| B_hard_only | 减去样本均值偏置 |
| C_hard_soft | 去偏置 + 对角软铁缩放使轴 RMS 相等 |

```python
#!/usr/bin/env python3
"""Synthetic magnetometer hard/soft-iron calibration toy. Stdlib only.

Shared true field magnitude and shared yaw rotation path for every arm.
Measurement model (VectorNav-style): m_tilde = S_soft @ R(yaw) @ B_true + b_hard + noise.
Arms differ only in post-processing of the SAME samples:
  A_raw          heading from uncorrected XY
  B_hard_only    subtract estimated hard-iron bias (sample mean)
  C_hard_soft    bias subtract + diagonal soft-iron scale (axis std → unit circle)

Metrics: heading absolute error (deg) and residual radius RMS after mapping to
a unit circle. ≥5 noise seeds. Not an AHRS certification. Mag hardware: 本页未运行.
"""
from __future__ import annotations

import math
import random

B_TRUE = (1.0, 0.0)  # horizontal field in body-fixed world frame, synthetic units
# Permanent hard-iron bias (sphere/circle centre shift)
B_HARD = (0.35, -0.22)
# Soft-iron stretch (diagonal ellipsoid → circle stretch); off-diagonals omitted for clarity
S_SOFT = (1.35, 0.72)  # sx, sy
N_YAWS = 72  # 5° steps, full rotation
NOISE_SIGMA = 0.03
SEEDS = (0, 1, 2, 3, 4)
ARMS = ("A_raw", "B_hard_only", "C_hard_soft")


def wrap180(deg: float) -> float:
    while deg > 180.0:
        deg -= 360.0
    while deg <= -180.0:
        deg += 360.0
    return deg


def heading_deg(mx: float, my: float) -> float:
    return math.degrees(math.atan2(my, mx))


def true_path() -> list[tuple[float, float, float]]:
    """Return list of (yaw_deg, mx_world_rot, my_world_rot) without distortion."""
    rows = []
    for i in range(N_YAWS):
        yaw = 360.0 * i / N_YAWS
        c = math.cos(math.radians(yaw))
        s = math.sin(math.radians(yaw))
        # rotate true field into sensor frame as yaw changes (2D)
        mx = c * B_TRUE[0] + s * B_TRUE[1]
        my = -s * B_TRUE[0] + c * B_TRUE[1]
        rows.append((yaw, mx, my))
    return rows


def measure(path, seed: int) -> list[tuple[float, float, float]]:
    rng = random.Random(20_000 + seed)
    out = []
    sx, sy = S_SOFT
    bx, by = B_HARD
    for yaw, mx, my in path:
        # soft stretch then hard bias + noise (VectorNav: m_c = S(m - b) form inverted)
        tx = sx * mx + bx + rng.gauss(0.0, NOISE_SIGMA)
        ty = sy * my + by + rng.gauss(0.0, NOISE_SIGMA)
        out.append((yaw, tx, ty))
    return out


def calibrate_bias(samples):
    mx = sum(p[1] for p in samples) / len(samples)
    my = sum(p[2] for p in samples) / len(samples)
    return mx, my


def calibrate_soft(samples, bias):
    """Diagonal soft scale: map demeaned axes to equal RMS (unit-ish circle)."""
    bx, by = bias
    xs = [p[1] - bx for p in samples]
    ys = [p[2] - by for p in samples]
    rx = math.sqrt(sum(v * v for v in xs) / len(xs)) or 1.0
    ry = math.sqrt(sum(v * v for v in ys) / len(ys)) or 1.0
    # target radius = geometric mean
    target = math.sqrt(rx * ry)
    return target / rx, target / ry


def evaluate(samples, arm: str) -> tuple[float, float, float, float]:
    """Return mean |heading err|, sd, residual radius RMS, residual radius sd."""
    bias = calibrate_bias(samples)
    soft = calibrate_soft(samples, bias)
    errs = []
    radii = []
    for yaw, mx, my in samples:
        if arm == "A_raw":
            cx, cy = mx, my
        elif arm == "B_hard_only":
            cx, cy = mx - bias[0], my - bias[1]
        else:
            cx = soft[0] * (mx - bias[0])
            cy = soft[1] * (my - bias[1])
        est = heading_deg(cx, cy)
        # true heading of horizontal field in sensor frame equals yaw for B_TRUE=(1,0)
        # with our rotation convention: atan2(my,mx) of undistorted = -yaw
        true_h = heading_deg(
            math.cos(math.radians(yaw)) * B_TRUE[0] + math.sin(math.radians(yaw)) * B_TRUE[1],
            -math.sin(math.radians(yaw)) * B_TRUE[0] + math.cos(math.radians(yaw)) * B_TRUE[1],
        )
        errs.append(abs(wrap180(est - true_h)))
        radii.append(math.hypot(cx, cy))
    mu_e = sum(errs) / len(errs)
    # radius residual vs mean radius
    mu_r = sum(radii) / len(radii)
    resid = [abs(r - mu_r) for r in radii]
    rms = math.sqrt(sum(r * r for r in resid) / len(resid))
    sd_e = math.sqrt(sum((e - mu_e) ** 2 for e in errs) / (len(errs) - 1))
    mu_abs = sum(resid) / len(resid)
    sd_r = math.sqrt(sum((r - mu_abs) ** 2 for r in resid) / (len(resid) - 1))
    return mu_e, sd_e, rms, sd_r


def mean_sd(xs: list[float]) -> tuple[float, float]:
    mu = sum(xs) / len(xs)
    var = sum((x - mu) ** 2 for x in xs) / (len(xs) - 1)
    return mu, math.sqrt(var)


def main() -> None:
    path = true_path()
    print(
        "Synthetic mag hard/soft-iron toy; shared field/path; not an AHRS certification"
    )
    print(
        f"B_true={B_TRUE} b_hard={B_HARD} S_diag={S_SOFT} "
        f"N_yaws={N_YAWS} noise_sigma={NOISE_SIGMA} seeds={len(SEEDS)}"
    )
    print(
        "model: m_tilde = S_soft * R(yaw)*B_true + b_hard + noise "
        "(VectorNav hard=centre shift, soft=ellipse stretch)"
    )
    print(
        "arm mean_abs_heading_err_deg heading_err_sd_deg "
        "radius_resid_rms radius_resid_sd (mean+-sd over seeds)"
    )
    for arm in ARMS:
        cols_acc = [[] for _ in range(4)]
        for seed in SEEDS:
            samples = measure(path, seed)
            vals = evaluate(samples, arm)
            for i, v in enumerate(vals):
                cols_acc[i].append(v)
        print(
            f"{arm} "
            + " ".join(f"{mean_sd(c)[0]:.4f}+-{mean_sd(c)[1]:.4f}" for c in cols_acc)
        )
    print(
        "No winner declared beyond the defined metric: hard-only recenters; "
        "hard+soft also un-stretches; raw keeps both errors"
    )
    print("Mag turntable / real IMU: 本页未运行; VectorNav/Wikipedia definitions 以原文为准")


if __name__ == "__main__":
    main()
```

**本课要点**

- I2C：SDA 与 SCL，7 位地址，开漏线加 4.7–10 kΩ 上拉，100 或 400 kHz；Uno 上 SDA 是 A4、SCL 是 A5。
- MPU-6050 地址 0x68（AD0 拉高为 0x69）：WHO_AM_I（0x75）读出 0x68，向 PWR_MGMT_1（0x6B）写 0x00 即可唤醒。
- 原始数据是有符号 16 位补码，高字节在前：±2 g 时 32768 / 2 = 16384 LSB/g，±250 °/s 时 32768 / 250 ≈ 131 LSB/(°/s)。
- 加速度计俯仰角 θ = atan2(ax, az) 绝对但有噪声；积分后的陀螺仪平滑，但会以零偏 × 时间漂移（1.5 °/s → 60 s 内漂 90°）。
- 互补滤波：angle = α × (angle + rate × dt) + (1 − α) × accelAngle；100 Hz、α = 0.98 时 τ ≈ 0.49 s，1.5 °/s 零偏造成 0.735° 静差。
- 从源头去掉零偏：静止时把陀螺仪平均 1–2 s，积分前减去它。
