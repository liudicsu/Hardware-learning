[上一课](/zh/month/month-6/behaviour-cloning)克隆的专家在同一个地方总是做同一件事。人的操作不是这样。让人把杯子从障碍物旁边移过去，有人从左边绕，有人从右边绕，同一个人不同的日子也会两种都做。两种都对。一个被训练去预测“那个”动作的策略，必须面对含有两个正确答案的数据，而最简单的训练损失在这里会产生系统性错误。本课先在玩具任务上展示这种失败，再看当今最常用的模仿学习策略所依赖的两个想法：动作分块（ACT）和扩散（Diffusion Policy）。

## 两个正确答案

用平方误差损失训练的行为克隆，对每个观测选出让它与所有录制动作的平均平方距离最小的那个动作，也就是它们的<strong>均值</strong>。如果某处有 7 条示范向左偏 4.2 cm、3 条向右偏 4.2 cm，均值就是 (−7 + 3) / 10 × 4.2 = −1.7 cm：一个轻微向左的漂移，没有任何示范者这么做过，而且它可能恰好是最糟的选择——直直撞向示范者们正在绕开的障碍物。

<Formula label="平方误差损失学到的东西">π(o) = mean of the recorded actions at o, which is not one of them when the actions form two groups</Formula>

解决办法是学一个能表示整个动作分布、并能从中<strong>采样</strong>的策略，这样它会选左或选右，而不是两者的混合。ACT 用条件变分自编码器（conditional variational autoencoder，CVAE）对动作块建模；Diffusion Policy 用去噪扩散模型对动作块建模。两者还都一次预测未来的一<strong>块</strong>动作（chunk），而不是一个。

## 方块任务

模型是一个从 (0, 0) 附近出发、要到达 (0, 1) 的点状夹爪。中间放着一个边长 0.3 m 的方块，中心在 (0, 0.5)。专家先直行到 (0, 0.2) 的岔口，然后驶向 (−0.3, 0.4) 或 (+0.3, 0.4) 的路点（每条示范 50/50 随机选），再驶向目标。每一步最多移动 5 cm，外加每轴 0.5 cm 的执行器噪声。

所有策略看的东西都一样：离当前位置最近的 10 个录制帧。它们只在“怎么用这 10 帧”上不同，这恰好对应真实策略训练损失之间的区别。`average` 取它们动作的均值（相当于平方误差训练的网络）。`sample` 随机重放其中一个。`chunk N` 随机选一个，播放那条示范接下来的 N 个动作，再重新看。`diffusion` 运行真正的 DDPM 采样器；训练好的网络本该预测干净动作的地方，它直接用这 10 帧的精确答案。

<CodeSource path="examples/month-6/act-diffusion/multimodal.py" />

```python
"""multimodal.py: why averaging fails on multimodal demonstrations, and what action chunks and diffusion change.

A point gripper starts near (0, 0) and must reach GOAL (0, 1). A square block of side 0.3 m sits in the way,
centred at (0, 0.5). The expert drives straight up to a fork at (0, 0.2) and then passes it on the left or on the right, 50/50, chosen at the start of each
demonstration: both are equally good, so the demonstrations are multimodal. Each step moves at most 0.05 m
plus 0.5 cm of actuator noise per axis. Success: within 0.05 m of GOAL inside 60 steps without touching the block.

Policies (all look at the K = 10 recorded frames nearest the current position):
  average    the mean of their actions; this is what a network trained with a squared-error loss predicts
  sample     the action of one of them, chosen at random, every step
  chunk N    pick one of them at random and play the next N actions of its episode, then look again
             (action chunking, the core idea of ACT; ACT also blends overlapping chunks)
  diffusion  start from Gaussian noise and denoise a chunk of 8 actions in 20 DDPM steps, using the exact
             denoiser for the demonstration set (the function a diffusion policy's network is trained to
             approximate), then play the chunk and look again
Standard library only, fixed seeds.
"""
import math
import random

GOAL, BLOCK_Y, HALF, FORK_Y = (0.0, 1.0), 0.5, 0.15, 0.2
STEP, NOISE, MAX_STEPS, K = 0.05, 0.005, 60, 10


def hits_block(p):
    return abs(p[0]) <= HALF and abs(p[1] - BLOCK_Y) <= HALF


def toward(p, target):
    dx, dy = target[0] - p[0], target[1] - p[1]
    d = math.hypot(dx, dy)
    k = min(1.0, STEP / d) if d > 0 else 0.0
    return dx * k, dy * k


def expert(p, side):
    """Straight up to the fork at (0, 0.2), then to a waypoint beside the block, then to the goal.
    side is -1 (left) or +1 (right); before the fork both kinds of demo look the same."""
    if p[1] < FORK_Y and abs(p[0]) < 0.05:
        return toward(p, (0.0, FORK_Y + 0.05))
    if p[1] < 0.4 and abs(p[0]) < 0.28:
        return toward(p, (0.3 * side, 0.4))
    return toward(p, GOAL)


def run(choose, rng, record=None):
    """choose(p, t) returns a list of actions to play before asking again."""
    p = (rng.uniform(-0.03, 0.03), rng.uniform(-0.03, 0.03))
    plan, t = [], 0
    while t < MAX_STEPS:
        if not plan:
            plan = list(choose(p, t))
        a = plan.pop(0)
        if record is not None:
            record.append((p, a))
        p = (p[0] + a[0] + rng.gauss(0, NOISE), p[1] + a[1] + rng.gauss(0, NOISE))
        t += 1
        if hits_block(p):
            return 'block', t
        if math.hypot(p[0] - GOAL[0], p[1] - GOAL[1]) < 0.05:
            return 'success', t
    return 'timeout', t


def record_demos(n, rng):
    episodes = []
    for _ in range(n):
        side = rng.choice((-1, 1))
        rows = []
        run(lambda p, t: [expert(p, side)], rng, record=rows)
        episodes.append(rows)
    return episodes


class Demos:
    def __init__(self, episodes):
        self.frames = [(e, i, rows[i][0]) for e, rows in enumerate(episodes) for i in range(len(rows))]
        self.episodes = episodes

    def nearest(self, p, k=K):
        return sorted(self.frames, key=lambda f: (f[2][0] - p[0]) ** 2 + (f[2][1] - p[1]) ** 2)[:k]

    def chunk(self, frame, n):
        """The next n actions of that frame's episode, padded with zero moves at the end."""
        e, i, _ = frame
        acts = [a for _, a in self.episodes[e][i:i + n]]
        return acts + [(0.0, 0.0)] * (n - len(acts))


def average_policy(demos):
    def choose(p, t):
        near = demos.nearest(p)
        return [(sum(demos.chunk(f, 1)[0][0] for f in near) / K, sum(demos.chunk(f, 1)[0][1] for f in near) / K)]
    return choose


def chunk_policy(demos, n, rng):
    def choose(p, t):
        return demos.chunk(rng.choice(demos.nearest(p)), n)
    return choose


def diffusion_policy(demos, n, rng, steps=20):
    """DDPM sampling of an n-step action chunk with the exact denoiser of the K nearest demo chunks."""
    betas = [1e-4 + (0.2 - 1e-4) * s / (steps - 1) for s in range(steps)]
    alphas = [1 - b for b in betas]
    abar, prod = [], 1.0
    for a in alphas:
        prod *= a
        abar.append(prod)
    scale = 1 / STEP                     # work in units of one full step so the noise schedule fits

    def choose(p, t):
        data = [[v * scale for a in demos.chunk(f, n) for v in a] for f in demos.nearest(p)]
        dim = len(data[0])
        x = [rng.gauss(0, 1) for _ in range(dim)]
        for s in reversed(range(steps)):
            # exact denoiser: E[x0 | xs] for x0 drawn uniformly from data, xs = sqrt(abar) x0 + sqrt(1 - abar) noise
            logw = [-sum((xi - math.sqrt(abar[s]) * di) ** 2 for xi, di in zip(x, d)) / (2 * (1 - abar[s]))
                    for d in data]
            m = max(logw)
            w = [math.exp(v - m) for v in logw]
            x0 = [sum(wi * d[j] for wi, d in zip(w, data)) / sum(w) for j in range(dim)]
            if s == 0:
                x = x0
                break
            # DDPM posterior mean of x_{s-1} given xs and the predicted x0, plus its noise
            c0 = math.sqrt(abar[s - 1]) * betas[s] / (1 - abar[s])
            cs = math.sqrt(alphas[s]) * (1 - abar[s - 1]) / (1 - abar[s])
            sd = math.sqrt(betas[s] * (1 - abar[s - 1]) / (1 - abar[s]))
            x = [c0 * a0 + cs * xs + sd * rng.gauss(0, 1) for a0, xs in zip(x0, x)]
        return [(x[2 * j] / scale, x[2 * j + 1] / scale) for j in range(n)]
    return choose


def evaluate(label, make, n=100):
    rng = random.Random(2026)
    choose = make(random.Random(11))
    counts = {'success': 0, 'block': 0, 'timeout': 0}
    steps = []
    for _ in range(n):
        result, t = run(choose, rng)
        counts[result] += 1
        if result == 'success':
            steps.append(t)
    mean = f'{sum(steps) / len(steps):.1f}' if steps else '-'
    print(f'{label:<16} success {counts["success"]:>3}/100   hit block {counts["block"]:>3}   '
          f'timeout {counts["timeout"]:>3}   mean steps to goal {mean}')


def main():
    episodes = record_demos(40, random.Random(5))
    lefts = sum(1 for rows in episodes if min(p[0] for p, _ in rows) < -0.1)
    demos = Demos(episodes)
    print(f'40 expert demos: {lefts} pass on the left, {40 - lefts} on the right, {len(demos.frames)} frames')

    print('\nSideways part dx of the first action just past the fork, at (0, 0.23), 200 draws per policy')
    edges = [-0.05, -0.03, -0.01, 0.01, 0.03, 0.05]
    print('  dx bin (cm)  ' + ''.join(f'{100 * lo:+.0f}..{100 * hi:+.0f}'.rjust(9) for lo, hi in zip(edges, edges[1:])))
    rng = random.Random(3)
    near = [demos.chunk(f, 1)[0][0] for f in demos.nearest((0.0, 0.23))]
    rows = [('10 demo frames', near)]
    for label, choose in [('average', average_policy(demos)), ('sample', chunk_policy(demos, 1, rng)),
                          ('diffusion', diffusion_policy(demos, 1, rng))]:
        rows.append((label, [choose((0.0, 0.23), 0)[0][0] for _ in range(200)]))
    for label, dx in rows:
        bins = [sum(1 for v in dx if lo <= v < hi or (hi == edges[-1] and v == hi)) for lo, hi in zip(edges, edges[1:])]
        print(f'  {label:<14}' + ''.join(f'{c:>9}' for c in bins))

    print('\nRollouts: 100 each with 0.5 cm actuator noise, same seed for every policy')
    evaluate('average', lambda r: average_policy(demos))
    evaluate('sample', lambda r: chunk_policy(demos, 1, r))
    for n in (4, 8, 16):
        evaluate(f'chunk {n}', lambda r, n=n: chunk_policy(demos, n, r))
    evaluate('diffusion 1', lambda r: diffusion_policy(demos, 1, r))
    evaluate('diffusion 8', lambda r: diffusion_policy(demos, 8, r))


if __name__ == '__main__':
    main()
```

## 动作分块：ACT 多了什么

ACT（Action Chunking with Transformers，来自 ALOHA 双臂机器人的工作；Zhao 等人，arXiv:2304.13705）一次预测接下来的 k 个动作，论文里在 50 Hz 下取 k = 100，也就是 2 秒。分块有三方面好处。策略做的决策少了 k 倍，有效时域缩短为原来的 1/k，单步预测误差在闭环里把状态推离示范分布的机会也就少了（§IV-A）。一个动作块内部是一致的：它不会在中途从“往左”变成“往右”。它还能处理观测无法说明下一步的示范，比如人在动手前停顿了一下，因为动作块本身带着时间信息。为了让运动平滑，ACT 每一步都查询一次策略，而不是每个块只查一次。在时刻 t，所有覆盖 t 的历史预测放进 FIFO；再用指数权重 w_i = exp(−m · i) 混合，其中 i = 0 是该时刻最旧的那次预测，m（论文里的集成权重）决定新观测接管的快慢。执行的动作是归一化后的加权和（算法 2）。这就是时间集成（temporal ensembling）：它平均的是同一时刻的多次预报，而不是相邻时刻，因此不会带来普通平滑的滞后。

动作块也有代价，玩具模型把它展示得很清楚。两次决策之间，动作块是<strong>开环</strong>执行的：

## 扩散策略

扩散模型生成样本的方式是：从纯高斯噪声出发，分很多小步把噪声去掉。训练时给录制的动作块加噪声，x_s = √ᾱ_s x_0 + √(1 − ᾱ_s) ε，并训练一个网络根据 x_s、步数 s 和观测去预测噪声 ε（等价于预测干净的动作块 x_0）。采样时反过来：从噪声出发，预测 x_0，走到噪声稍少的 x，重复。因为每次采样从不同的噪声出发，结果会落进某一个模式里，而不是把它们平均。Diffusion Policy（Chi 等人）用这种方式预测 16 个动作的块，执行前 8 个后再重新规划。

<Formula label="前向加噪，第 s 步">x_s = √ᾱ_s · x_0 + √(1 − ᾱ_s) · ε,   ε ~ N(0, I)</Formula>

这里的模型省掉了网络。对一组固定的数据点，从 x_s 预测 x_0 的最佳答案有解析形式：数据点的加权平均，权重是每个点产生出 x_s 的可能性。在正向过程 x_s = √ᾱ_s x_0 + √(1 − ᾱ_s) ε 下，该权重就是把每个示范块 d 当作 x_0 时、当前噪声块的高斯密度：w_d ∝ exp(−‖x_s − √ᾱ_s d‖² / (2(1 − ᾱ_s)))，也就是 `diffusion_policy` 里实际计算的量。去噪早期权重分散在这 10 个点上；随着 ᾱ_s → 1、残余噪声变小，某一个权重占主导，采样器就会收敛到这 10 个已记住的块之一，而不是它们的平均。这正是网络训练所逼近的函数，所以程序用这 10 个最近帧的完美去噪器运行真正的 20 步 DDPM 采样器：

## 常见错误

- <strong>在不知不觉中对多个模式取平均。</strong>如果策略逐渐移向两个选项的中间，或在两者之间停留，检查一下你的示范里是否有两种做法。要么始终用同一种方式示范，要么用能采样的策略。
- <strong>以为分块没有代价。</strong>动作块在下一次决策之前是开环运行的。余量很小、物体在动或抓取在打滑时，策略需要更早地重新观察；调整每次决策执行的动作数，并测量效果。
- <strong>在不同数据或种子上比较策略。</strong>上面每一行都用同样的 40 条示范、同一个种子和同样的运行次数。第 4 课更进一步，给每次运行单独设种子，让每个策略遇到完全相同的初始条件；在硬件上，这意味着每个策略都用同一份起始位置清单。
- <strong>把只会记忆的策略当成好策略。</strong>这里的扩散策略只能重放示范。在宣称策略能泛化之前，先在数据集里没有的起始位置上测试。
- <strong>混淆训练成本和推理成本。</strong>扩散策略每个动作块需要多次通过网络，所以要在真正运行它的那台电脑上确认推理跟得上控制频率，而不只是在训练用的 GPU 上。

## 双手完成同一个共享任务
策略能表达多模态动作，仍可能双手配合不好。另加**合成运动学共享带条运输**：两个一维指尖滑台把同一柔顺带条的端点移到目标中心，同时保持名义间距 **0.6 m**。它不是刚体 / 载荷 / 力仿真；间距误差是**运动学柔顺代理**，不是真实应变或力。它不是 ORCA-lite 多机器人走廊，也不重做 ACT 分块数学。下述单位 / 间隙 / 控制增益都是合成设置，不是机器人规格。

### 可用信息相同，耦合方式不同

每 tick **每种模式的左右臂都 RECEIVE 完整同一字段** `(noisy xL,xR,vL,vR,goalL,goalR,span)`。任何组都拿不到干净状态、隐藏执行器增益或未来噪声。每种子各模式的物体 / 端点初态、目标、隐藏增益及外生传感 / 扰动流相同；动作不同导致真实轨迹不同，共用随机数不表示不同轨迹的观测数值也一样。

| 模式 | 左臂观察 / 使用 | 右臂观察 / 使用 |
|---|---|---|
| independent | 观察完整快照，刻意只用自身位置与目标 | 观察完整快照，刻意只用自身位置与目标 |
| leader-follower | 观察完整快照，目标反馈；测得间距短缺超过0.06 m 就等右臂 | 观察完整快照，跟随测得左位置 + 名义间距，前馈测得左速度 |
| joint | 观察完整快照，共享中心误差 + 间距修正 | 观察完整快照，共享中心误差 − 间距修正 |

因此 independent 是**因子化控制律**，不是用局部传感组对照全知集中 oracle。改变的是耦合 / 协调方式，所有可用观测字段及物理动作预算相同。控制器是固定解析律，不是学习的 TwinVLA 头。独立组对端点误差用增益2；主从组同样增益2，再加等待门 / 从臂前馈；联合组中心增益2、间距增益5。位置反馈增益单位为 s⁻¹。这些声明的设计选择不是普遍最优，也没有用这组评估种子调参。

五种子全部用 **11/23/37/53/71**，初始中心±0.05 m、间距0.6±0.02 m，运输距离 **0.75–0.9 m**。左响应增益0.9–1.0、右0.55–0.8 表示非对称对象，各方法共用且不告诉任何控制器。独立高斯传感噪声 σ=**0.003 m /0.01 m/s**，速度扰动 σ=**0.006 m/s**；对象加速度和速度统一截到 **0.8 m/s² /0.35 m/s**。每模式跑满 **400 tick ×0.02 s =8 s**，首次到达后也继续，共 **800 条端点命令**，不靠提前退出省预算。

```python
#!/usr/bin/env python3
"""Synthetic two-endpoint shared-strap transport, not TwinVLA inference.
All modes/arms RECEIVE (noisy xL,xR,vL,vR,goalL,goalR,span) every tick.
Independent deliberately factorizes local feedback, not local-only sensor access.
Leader-follower uses left velocity/position and a left waiting gate; joint uses
center/span feedback. No controller receives latent actuator gain or future noise.
Each mode runs all400 ticks, including after first arrival, with same plant/noise.
Span error is a kinematic compliance proxy, NOT a force/strain dynamics model.
"""
from math import sqrt
from random import Random
from statistics import mean, pstdev

SEEDS=(11,23,37,53,71)
MODES=('independent','leader_follower','joint')
TICKS, DT, VMAX, AMAX=400,.02,.35,.8
SPAN, COLLISION_DISTANCE=.6,.32


def clip(x,bound):return max(-bound,min(bound,x))


def make_case(seed):
    r=Random(seed);center=r.uniform(-.05,.05);span=SPAN+r.uniform(-.02,.02)
    start=(center-span/2,center+span/2);goal=center+r.uniform(.75,.9)
    gains=(r.uniform(.9,1.),r.uniform(.55,.8))
    # All modes share this exogenous sensor/disturbance stream, not their resulting states.
    stream=tuple((tuple(r.gauss(0,.003) for _ in range(2)),tuple(r.gauss(0,.01) for _ in range(2)),tuple(r.gauss(0,.006) for _ in range(2))) for _ in range(TICKS))
    return start,(goal-SPAN/2,goal+SPAN/2),gains,stream


def commands(observation,mode):
    left,right,vl,vr,gl,gr,span=observation
    if mode=='independent':return (2*(gl-left),2*(gr-right))
    if mode=='leader_follower':
        lead=2*(gl-left)
        if right-left<span-.06:lead=0. # Wait for follower, using the SAME noisy snapshot.
        return lead,2*(left+span-right)+vl
    center_error=(gl+gr-left-right)/2
    span_error=right-left-span
    common=2*center_error
    return common+5*span_error,common-5*span_error


def rollout(case,mode):
    start,goal,gains,stream=case;x=list(start);v=[0.,0.]
    stable=0;arrival=None;collisions=0;was_colliding=False;span_errors=[];min_sep=float('inf')
    for tick,(position_noise,velocity_noise,disturbance) in enumerate(stream):
        obs=(*tuple(a+b for a,b in zip(x,position_noise)),*tuple(a+b for a,b in zip(v,velocity_noise)),*goal,SPAN)
        command=commands(obs,mode)
        for j in range(2):
            desired=gains[j]*clip(command[j],VMAX)+disturbance[j]
            v[j]=clip(v[j]+clip(desired-v[j],AMAX*DT),VMAX)
            x[j]+=v[j]*DT
        separation=x[1]-x[0];min_sep=min(min_sep,separation)
        colliding=abs(separation)<COLLISION_DISTANCE
        collisions+=int(colliding and not was_colliding);was_colliding=colliding
        span_errors.append((separation-SPAN)**2)
        # Truth is a SCORE ONLY observer, not used by commands or its wait gate.
        settled=max(abs(a-b) for a,b in zip(x,goal))<=.025 and abs(separation-SPAN)<=.04
        stable=stable+1 if settled else 0
        if stable>=20 and arrival is None:arrival=(tick+1)*DT
    return {'success':int(arrival is not None and collisions==0),'collisions':collisions,
            'capped_makespan':arrival if arrival is not None else TICKS*DT,'timeout':int(arrival is None),
            'span_rmse':sqrt(mean(span_errors)),'min_separation':min_sep,'ticks':len(stream)}


def main():
    print('Synthetic shared-strap transport; seeds=11/23/37/53/71; no payload/force dynamics')
    print('all arms/modes RECEIVE same noisy xL,xR,vL,vR,goalL,goalR,span; no latent gain/future noise')
    print('independent: each uses own target/state; leader_follower: left gate + right follows measured left; joint: center/span')
    print('equal400 ticks after arrival too; dt=0.02s vmax=0.35m/s amax=0.8m/s2; same gain/noise stream per seed')
    print('arrival=20 consecutive settled ticks; score-only endpoints<=0.025m span_error<=0.04m')
    print('collision event=entry into distance<0.32m; success requires arrival AND zero collision events')
    print('mode success/5 collision_events_mean_sd capped_makespan_s_mean_sd timeouts/5 span_RMSE_m_mean_sd minimum_separation_m_mean_sd')
    cases=tuple(make_case(seed) for seed in SEEDS)
    for mode in MODES:
        rows=[rollout(case,mode) for case in cases]
        def report(key):
            values=[r[key] for r in rows];return f'{mean(values):.6f} {pstdev(values):.6f}'
        print(f'{mode} {sum(r["success"] for r in rows)}/5 {report("collisions")} {report("capped_makespan")} {sum(r["timeout"] for r in rows)}/5 {report("span_rmse")} {report("min_separation")}')
    print('Population sd; censored makespan uses8s at timeout, not an uncensored arrival-time mean')
    print('No presumed mode winner; independent available information equals joint, only coupling differs')
    print('Not ORCA-lite fleet / ACT chunk math; TwinVLA real robots/weights: 本页未运行; figures 以论文为准')


if __name__=='__main__':main()
```

## CogACT：认知表征到 DiT 风格动作头

<Resource id="cogact-abs" />
<Resource id="cogact-html" />

**实际打开的来源（abs + HTML + PDF / pdftotext）。** Qixiu Li 等，*CogACT: A Foundational Vision-Language-Action Model for Synergizing Cognition and Action in Robotic Manipulation*，arXiv:2411.19650。正文已核验：组件化 VLM → 专用动作模块；MLP 深度与 DiT 风格扩散动作头对照；论文提出推理时的 **Adaptive Action Ensemble（AAE，自适应动作集成）**（**以论文为准**）。论文成功率 **以论文为准**。真实 CogACT 权重 / GPU 训练 **本页未运行**。

本节 **不是** OpenHelix 双系统，**不是** VQ-BeT，也 **不是** RDT2。它在 ACT / 扩散课上用 **合成** 认知→动作替身加深一层。

### 模型假设

- 特征是固定的 **类 VLM 认知向量**（演示状态的标准库特征）。本页没有 Transformer VLM。
- 臂 **A**（`A_mlp_head`）：特征 → 动作的岭回归线性映射（MLP 头替身）。
- 臂 **B**（`B_dit_denoiser`）：成对特征扩展 + 少量迭代精炼（DiT 风格 **表达力** 替身——**不是** 真实 Diffusion Transformer、注意力或噪声日程）。
- 臂 **C**（`C_quant_tokens`）：离散分箱后再做同样线性映射（OpenVLA 风格量化底噪）。
- 当动作 **多峰** 时，纯 MSE 回归会把不同峰平均掉（**mode averaging / 模态平均**）；专用 / 扩散风格头可以分开峰——这就是 `multimodal_long` 可能偏向 B 的原因。
- **共同随机数：** 一种子抽一条共享演示/噪声带；A/B/C 看到相同输入。指标：动作 MSE 与成功代理。成功代理对墙钟 GPU 时间与真实 DiT NFE **视而不见**。

### 公平设置

共享演示、共享特征噪声、共享步数/预算常数，五多种子。不预设赢家：**unimodal_short** 是 **接近打平 / 差距很小**（打印 |MSE_A−MSE_B|=0.0001；原始约 5.9e-5）——短时域单峰任务对两种头都很容易，剩下的差距来自岭回归正则和噪声，不是精确打平。**multimodal_long** 下专用表达力可以帮忙。量化付出真实底噪。

```python
#!/usr/bin/env python3
"""Synthetic CogACT-style cognition→action literacy toy. Stdlib only.

Shared demo features / chunk / noise for every arm (common random numbers per
seed). Every arm faces the **same** noise sources and demos.

Arms (equal demo budget; ≠ OpenHelix / VQ-BeT / RDT2 / ACT-CVAE):
  A_mlp_head       ridge-linear cognition→action (shallow MLP stand-in)
  B_dit_denoiser   ridge on expanded features + iterative refine (DiT-style stand-in)
  C_quant_tokens   ridge-linear on quantized action tokens (OpenVLA-style)

Regimes (≥5 seeds):
  unimodal_short   — |MSE_A−MSE_B| small → **near-tie / small gap** (not exact; ridge+noise)
  multimodal_long  — expanded/DiT-style **wins** on action MSE

Assumptions: CPU stand-in of CogACT componentized VLM→specialized action module
(Qixiu Li et al., arXiv:2411.19650; abs+HTML+PDF read). B's "DiT-style" is an
expressivity stand-in (pairwise feature interactions + iterative refine), not a
real transformer weight stack. Paper SIMPLER/real % 以论文为准; GPU/weights
本页未运行.
"""
from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
ARMS = ("A_mlp_head", "B_dit_denoiser", "C_quant_tokens")
FEAT_DIM = 6
ACT_DIM = 3
DIT_ITERS = 4
N_BINS = 10
RIDGE = 1e-2
REGIMES = (
    ("unimodal_short", 40, 2, 1, 0.03),
    ("multimodal_long", 40, 12, 4, 0.03),
)


def shared_demo_pack(seed: int, n_demos: int, chunk: int, n_modes: int, noise_std: float):
    rng = random.Random(30_000 + seed)
    feats, acts, noises = [], [], []
    for i in range(n_demos):
        mode = i % n_modes
        f = [0.0] * FEAT_DIM
        f[mode % FEAT_DIM] = 1.0
        f[-1] = mode / max(1.0, float(n_modes - 1))
        for k in range(FEAT_DIM):
            f[k] += 0.04 * rng.gauss(0.0, 1.0)
        a = []
        for t in range(chunk):
            u = t / max(1, chunk - 1)
            for d in range(ACT_DIM):
                val = (
                    0.5 * f[-1]
                    + 0.55 * math.sin(2.4 * u + 0.8 * d + 1.2 * mode)
                    + 0.4 * (mode + 1) * u * u * math.cos(0.6 * d + mode)
                )
                a.append(val)
        n = [rng.gauss(0.0, noise_std) for _ in range(chunk * ACT_DIM)]
        feats.append(f)
        acts.append(a)
        noises.append(n)
    return feats, acts, noises


def expand_dit(feat: list[float]) -> list[float]:
    """Expressivity stand-in: raw feat + pairwise products (DiT capacity proxy)."""
    out = list(feat)
    for i in range(len(feat)):
        for j in range(i, len(feat)):
            out.append(feat[i] * feat[j])
    return out


def ridge_fit(X: list[list[float]], Y: list[list[float]], lam: float = RIDGE):
    """Return W (out_dim x in_dim), b (out_dim) via normal equations on centered data."""
    n = len(X)
    d = len(X[0])
    o = len(Y[0])
    mean_x = [sum(X[i][k] for i in range(n)) / n for k in range(d)]
    mean_y = [sum(Y[i][j] for i in range(n)) / n for j in range(o)]
    # XtX, XtY
    XtX = [[0.0] * d for _ in range(d)]
    XtY = [[0.0] * o for _ in range(d)]
    for i in range(n):
        xc = [X[i][k] - mean_x[k] for k in range(d)]
        yc = [Y[i][j] - mean_y[j] for j in range(o)]
        for a in range(d):
            for b in range(d):
                XtX[a][b] += xc[a] * xc[b]
            for j in range(o):
                XtY[a][j] += xc[a] * yc[j]
    for a in range(d):
        XtX[a][a] += lam * n
    # Solve XtX W[:,j] = XtY[:,j] via Gauss-Jordan on copy per column is heavy;
    # use Gauss-Jordan once for all RHS.
    M = [XtX[r][:] + XtY[r][:] for r in range(d)]
    for col in range(d):
        piv = max(range(col, d), key=lambda r: abs(M[r][col]))
        M[col], M[piv] = M[piv], M[col]
        div = M[col][col]
        if abs(div) < 1e-12:
            continue
        for j in range(col, d + o):
            M[col][j] /= div
        for r in range(d):
            if r == col:
                continue
            fac = M[r][col]
            for j in range(col, d + o):
                M[r][j] -= fac * M[col][j]
    W = [[M[k][d + j] for k in range(d)] for j in range(o)]  # W[j][k]
    # b = mean_y - W mean_x
    b = []
    for j in range(o):
        b.append(mean_y[j] - sum(W[j][k] * mean_x[k] for k in range(d)))
    return W, b


def predict_linear(feat, W, b):
    return [b[j] + sum(W[j][k] * feat[k] for k in range(len(feat))) for j in range(len(b))]


def quantize(a):
    lo, hi = -1.5, 2.0
    out = []
    for x in a:
        u = (x - lo) / (hi - lo)
        u = 0.0 if u < 0.0 else (1.0 if u > 1.0 else u)
        idx = min(N_BINS - 1, int(u * N_BINS))
        out.append(lo + (idx + 0.5) * (hi - lo) / N_BINS)
    return out


def fit_arm(arm, feats, acts, noises):
    Y = [[acts[i][j] + noises[i][j] for j in range(len(acts[i]))] for i in range(len(acts))]
    if arm == "A_mlp_head":
        X = [f[:] for f in feats]
        W, b = ridge_fit(X, Y)
        return ("lin", W, b)
    if arm == "C_quant_tokens":
        Yq = [quantize(y) for y in Y]
        X = [f[:] for f in feats]
        W, b = ridge_fit(X, Yq)
        return ("quant", W, b)
    # DiT-style: expanded features
    X = [expand_dit(f) for f in feats]
    W, b = ridge_fit(X, Y)
    return ("dit", W, b)


def predict(params, feat):
    kind, W, b = params
    if kind == "dit":
        x0 = predict_linear(expand_dit(feat), W, b)
        # Iterative refine toward the same head (idempotent attractor)
        x = [0.0] * len(x0)
        for s in range(DIT_ITERS):
            alpha = 1.0 / (DIT_ITERS - s)
            x = [x[j] + alpha * (x0[j] - x[j]) for j in range(len(x))]
        return x
    pred = predict_linear(feat, W, b)
    if kind == "quant":
        return quantize(pred)
    return pred


def mse(a, b):
    return sum((x - y) ** 2 for x, y in zip(a, b)) / len(a)


def mean_sd(xs):
    n = len(xs)
    mu = sum(xs) / n
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (n - 1))
```

## HybridVLA：一个模型里同时有扩散和自回归，再做集成

前面几节比较了 ACT 动作块和扩散头，CogACT 则在 VLM 后面接一个 DiT 风格的扩散头。**HybridVLA** 问的是另一件事：如果一个语言模型**同时**输出一个自回归（AR）动作（离散词元）**和**一个扩散动作，机器人在运行时再在两者之间选择或取平均，会怎样？本节**不是**本页前面那种普通的 ACT 对比 Diffusion Policy，**不是** CogACT 的 Adaptive Action Ensemble（那个是在**时间**上平均多个动作块，这里是在**同一步**平均两个头），**不是** OneDP 蒸馏，也**不是** Diffusion Forcing。

<Resource id="hybridvla-pdf" />

**实际打开并读过正文的来源。** **HybridVLA（Jiaming Liu et al.，arXiv 2503.10631，LaTeXML HTML 与 PDF（pdftotext），v3）。** 一个 LLM（7B LLaMA-2，或 2.7B Phi-2）同时承载两种范式。词元序列里，机器人状态经 MLP 进入，然后是包在 `<BOD>` … `<EOD>` 标记之间的扩散词元，再后面是 AR 动作词元；因此 AR 词元以扩散潜变量为条件，离散真值也不会泄漏进扩散的条件（表 1，Type 1）。训练时在共享主干上把两个损失相加，`L_hybrid = L_dif + L_ce`。推理用 **4** 步 DDIM 和 KV cache。**协同动作集成**（第 3.3 节）：去词元器给出 AR 动作词元的平均置信度 `c`；若 `c > θ`（`θ = 0.96`），执行平均值 `(a_dif + a_ar) / 2`，否则只用扩散动作。论文报告扩散在精细任务上更好（Phone on base、Close laptop lid），AR 在需要场景语义的任务上更好（Water plants、Frame off hanger），并且在 80 % 以上的成功样本里 AR 置信度超过 0.96。报告的数字：RLBench 平均成功率 HybridVLA (7B) 0.74、HybridVLA-dif 0.66、HybridVLA-ar 0.62（表 7）；阈值扫描 0.90 / 0.92 / 0.94 / 0.96 / 0.98 → 0.66 / 0.64 / 0.70 / 0.74 / 0.69（表 8）；仿真比先前 VLA 高 14 %、真机高 19 %（摘要）。表 7 里也有单一方式胜过集成的任务：Wine at rack，只用扩散 0.70，集成 0.50。以上都**以论文为准**；7B 模型、A800 训练和 RLBench **本页未运行**。

### 集成规则：平均能修好什么、修不好什么

<Formula label="HybridVLA 协同动作集成（第 3.3 节）">a = (a_dif + a_ar) / 2  if  c_ar > θ = 0.96,   otherwise  a = a_dif</Formula>

对两个动作取平均会做两件不同的事。两个头指向**同一个**模式时，它平均了两者的误差：两个标准差为 σ 的独立误差变成一个标准差为 σ/√2 的误差，AR 头的取整误差也减半。两个头指向**不同**模式时，平均值落在两者之间，那是任何示范都没去过的地方。置信度门控就是让第二种情况少发生的机制，而它只看 AR 头。

**算例：一个精细步和一个语义步。**

```text
AR bins on [-1, 1]: width 2/64 = 0.03125, rounding error up to 0.015625
precision tolerance 0.012, head noise sd 0.010 for both heads
B (diffusion alone):  P(|N(0, 0.010)| < 0.012) = P(|Z| < 1.2) = 0.770
C (gate passed):      rounding error halved to <= 0.0078, noise sd 0.010/√2 = 0.0071
gate: c = 1 - 0.5 exp(-1.2 |z|) > 0.96  <=>  |z| > ln(12.5)/1.2 = 2.1048
      with z ~ N(3, 1): P(|z| > 2.1048) = 0.815
semantic: modes -0.6, 0, 0.6, tolerance 0.15
      AR right with P(z > 0) = Φ(1.8) = 0.964, diffusion right with Φ(0.5) = 0.691
      average of two different modes: 0.3 away from either, outside 0.15
```

精细步上门控约有 82 % 的时间通过，每次通过都让误差变窄，所以集成应当胜过两个头。语义步上 AR 头更会选，但平均没法把扩散头选错的模式变成对的：扩散对时平均也对（两者一致），扩散错时平均就落空。所以按这些数字，集成在语义步上的成功率应当等于扩散头，而不是 AR 头。

**这里没有积分步长。** 两个头是每个回合抽一次的误差模型，没有任何量按时间推进，4 步 DDIM 采样器也**没有**模拟，所以不存在步长稳定性判据。独立测试检查 toy 里没有时间步常数，并且每组读的是同一份回合列表。

### 公平设置

`hybridvla_action_ensemble_toy.py` 是**合成**模型，只用标准库。**模型假设**如下。每个回合要求一个 [-1, 1] 内的标量动作。精细回合只有一个模式，中心随机，容差 0.012（`easy_precision` 中为 0.1）。语义回合有 −0.6、0、0.6 三个候选模式，其中一个是对的，容差 0.15。每个头都是**误差模型，不是训练出来的网络**，它从自己的证据 `z ~ N(μ, 1)` 选模式（`z > 0` 时选对，否则选一个错误模式），再加标准差**相同**的 0.010 高斯噪声。AR 头随后取整到 64 个区间之一，并报告置信度 `c = 1 − 0.5·exp(−1.2·|z_ar|)`。两个头的选模式错误**相互独立**，这是本 toy 的假设。HybridVLA 里 AR 词元以扩散潜变量为条件，所以论文中的两个头很可能比这里更相关。这里没有训练，所以两个头的数据量和步数自然相同。指标：成功率（%）、平均绝对动作误差 ×1000，以及 C 采用 AR 动作的回合比例。

| 组 | 执行的动作 |
|---|---|
| A_ar_only | AR 动作（64 个区间） |
| B_diffusion_only | 扩散动作 |
| C_hybrid_ensemble | `c > 0.96` 时取两者平均，否则用扩散动作 |

**共用随机数（common random numbers）**。每个（情形，种子）中，每个回合的类型、模式、目标、两份证据、两份噪声和错误模式的选择都只抽一次，三组共用。三组**只**在执行哪个输出上不同。每个种子 400 个回合，5 个种子；报告种子间的均值±标准差。

```python
#!/usr/bin/env python3
"""HybridVLA-style collaborative action ensemble vs an AR-only and a diffusion-only head.

Synthetic, stdlib only.  Not plain ACT vs Diffusion Policy (earlier on this
page), not CogACT's Adaptive Action Ensemble over time (also on this page),
not OneDP, not Diffusion Forcing.  Real HybridVLA weights / GPU training:
本页未运行.  Paper numbers and the rule "average both when the mean AR token
confidence exceeds theta = 0.96, otherwise use diffusion alone" are
以论文为准 (arXiv 2503.10631, Section 3.3).

Each episode asks for one scalar action a* in [-1, 1].  Two task kinds:
    precision  one mode at a random centre; success if |a - a*| < TOL_PRECISION
    semantic   three candidate modes (-0.6, 0, 0.6), one is right; success if |a - a*| < TOL_SEMANTIC
Two heads are error models, not trained networks (no training, no time step):
    AR head         picks a mode from evidence z_ar ~ N(mu_ar, 1) (right if z_ar > 0),
                    adds N(0, SIGMA) and rounds to one of BINS bins on [-1, 1];
                    its mean token confidence is c = 1 - 0.5 * exp(-KAPPA * |z_ar|)
    diffusion head  picks a mode from its own evidence z_d ~ N(mu_d, 1) and adds N(0, SIGMA)
The two heads' mode errors are drawn independently (an assumption of this toy).
Arms:
    A_ar_only          the AR action
    B_diffusion_only   the diffusion action
    C_hybrid_ensemble  (AR + diffusion) / 2 if c > THETA, else the diffusion action
Common random numbers: per (regime, seed) every episode's task, target, evidence,
noise and wrong-mode pick are drawn once and shared by all three arms.  The arms
differ only in which output is executed.
"""
import math
import random

SEEDS = (0, 1, 2, 3, 4)
EPISODES = 400            # per regime and seed
BINS = 64                 # AR bins on [-1, 1]: width 2/64 = 0.03125
SIGMA = 0.010             # continuous noise of each head (same for both)
THETA = 0.96              # paper's confidence threshold
KAPPA = 1.2               # confidence slope: c > 0.96 when |z_ar| > ln(12.5)/1.2 = 2.105
TOL_PRECISION = 0.012
TOL_SEMANTIC = 0.15
SEMANTIC_MODES = (-0.6, 0.0, 0.6)
NUM_ZERO = 1e-9           # |m| and sd both below this: floating-point residue, not a gap

# name: (share of semantic episodes, mu_ar precision, mu_ar semantic, mu_d semantic, precision tolerance)
REGIMES = {
    "precision": (0.0, 3.0, 1.8, 0.5, TOL_PRECISION),
    "semantic": (1.0, 3.0, 1.8, 0.5, TOL_PRECISION),
    "mixed": (0.5, 3.0, 1.8, 0.5, TOL_PRECISION),
    "easy_precision": (0.0, 3.0, 1.8, 0.5, 0.1),
}
ARMS = ("A_ar_only", "B_diffusion_only", "C_hybrid_ensemble")


def shared_draws(regime, seed):
    """Common random numbers: one list of episodes, used by every arm."""
    sem_share, mu_ar_p, mu_ar_s, mu_d_s, _ = REGIMES[regime]
    rng = random.Random(f"{regime}/{seed}")
    eps = []
    for _ in range(EPISODES):
        semantic = rng.random() < sem_share
        if semantic:
            modes = SEMANTIC_MODES
            right = rng.randrange(3)
            mu_ar, mu_d = mu_ar_s, mu_d_s
        else:
            modes = (rng.uniform(-0.8, 0.8),)
            right = 0
            mu_ar, mu_d = mu_ar_p, mu_ar_p
        eps.append({
            "semantic": semantic, "modes": modes, "right": right,
            "target": modes[right] + (rng.uniform(-0.01, 0.01) if semantic else 0.0),
            "z_ar": rng.gauss(mu_ar, 1.0), "z_d": rng.gauss(mu_d, 1.0),
            "n_ar": rng.gauss(0.0, SIGMA), "n_d": rng.gauss(0.0, SIGMA),
            "wrong_ar": rng.randrange(2), "wrong_d": rng.randrange(2),
        })
    return eps


def pick(ep, z, wrong):
    if len(ep["modes"]) == 1 or z > 0.0:
        return ep["modes"][ep["right"]]
    others = [m for i, m in enumerate(ep["modes"]) if i != ep["right"]]
    return others[wrong]


def quantize(v):
    w = 2.0 / BINS
    i = min(BINS - 1, max(0, int((v + 1.0) / w)))
    return -1.0 + (i + 0.5) * w


def heads(ep):
    a_ar = quantize(pick(ep, ep["z_ar"], ep["wrong_ar"]) + ep["n_ar"])
    a_d = pick(ep, ep["z_d"], ep["wrong_d"]) + ep["n_d"]
    conf = 1.0 - 0.5 * math.exp(-KAPPA * abs(ep["z_ar"]))
    return a_ar, a_d, conf


def run(regime, seed, arm):
    tol_p = REGIMES[regime][4]
    hits, errs, used = 0, 0.0, 0
    for ep in shared_draws(regime, seed):
        a_ar, a_d, conf = heads(ep)
        if arm == "A_ar_only":
            a = a_ar
        elif arm == "B_diffusion_only":
            a = a_d
        elif conf > THETA:
            a, used = 0.5 * (a_ar + a_d), used + 1
        else:
            a = a_d
        err = abs(a - ep["target"])
        hits += err < (TOL_SEMANTIC if ep["semantic"] else tol_p)
        errs += err
    return {"succ": 100.0 * hits / EPISODES, "err": 1000.0 * errs / EPISODES, "gate": 100.0 * used / EPISODES}


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-4:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def cell(xs):
    mu, sd = mean_sd(xs)
    return f"{num(mu)}+-{num(sd)}"
```

## FLARE：让未来 token 对齐冻结的未来嵌入

<Resource id="flare-paper" />

上面几节都是把当前观测交给扩散头或 DiT 风格的动作头，让它输出动作。**FLARE** 只多加一个训练信号：策略还要在自己的激活里预测**之后会看到的画面的嵌入**。来源是 *FLARE: Robot Learning with Implicit World Modeling*，作者 Ruijie Zheng、Jing Wang、Scott Reed、Johan Bjorck、Yu Fang、Fengyuan Hu、Joel Jang、Kaushil Kundalia、Zongyu Lin、Loic Magne、Avnish Narayan、You Liang Tan、Guanzhi Wang、Qi Wang、Jiannan Xiang、Yinzhen Xu、Seonghyeon Ye、Jan Kautz、Furong Huang、Yuke Zhu、Linxi Fan（arXiv 2505.15659；已读摘要页、HTML 与 PDF；21 位作者按 arXiv 顺序）。

论文怎么说，本节保留什么。流匹配 DiT 策略把本体状态、加噪的动作块和 **M 个可学习的未来 token** 放进同一个序列。在内部第 L 层取出这些未来 token 的激活，经 MLP 投影后，与未来观测的冻结视觉-语言嵌入做**余弦对齐**（论文式 2）：`L_align = −E[cos(f_θ(φ_t, A_t^τ, q_t), g(φ_(t+H)))]`，总损失为 `L = L_fm + λ L_align`（式 3）。论文报告 λ = 0.2 效果最好，损失加在 8 层中的第 6 层，并指出对齐放得太早（第 4 层）会"明显降低性能"。对**没有**动作标签的人类第一视角视频，它去掉动作项，只用对齐损失。目标嵌入的消融（表 2）为：不加 FLARE 损失 43.9 %，SigLIP2 token 49.6 %，平均池化 SigLIP2 50.9 %，动作感知嵌入 55.0 %；摘要称比此前基线最多高 26 %。这些都**以论文为准**，没有一个是玩具输出。GR00T N1、GPU 训练、RoboCasa、GR-1 与 GoPro 联合训练均**本页未运行**。

本节**不是**上面的 CogACT 认知 token，也**不是** HybridVLA 的扩散 / 自回归集成；**不是** InternVLA-A1 的显式视觉预见专家，**不是** MemoryVLA 的记忆库，也**不是** DreamGen 的逆动力学模型。FLARE 从不生成未来图像，它只塑造策略自己的特征。

<Formula label="FLARE 目标（论文式 2–3）">L_align = −E[ cos( f_θ(φ_t, A_t^τ, q_t), g(φ_(t+H)) ) ]，   L = L_fm + λ · L_align，   论文取 λ = 0.2</Formula>

**算例（手算，除标明「手算」者外均由玩具打印）。** 未来 token 与目标方向完全一致时 cos = 1，对齐项给损失加上 −λ：论文的 λ 下是 −0.2000，λ = 2.0 时是 −2.0000。玩具的 `delayed` 情形里，目标 g 在 [−1, 1] 上均匀分布（标准差 √(1/3)）；它以 0.3 g 进入当前观测，旁边是七个单位方差的干扰维，比值 0.1732；在未来观测里是 1.0 g，比值 0.5774。永远输出 0 的策略动作 MSE 为 1/3（手算，即 U[−1, 1] 的方差；玩具不打印）。

**这里没有物理积分。** 玩具用全批量梯度下降（400 轮，步长 0.05）和精确解析梯度训练一个线性模型，没有任何量按时间步推进。

### 公平设置

`flare_future_latent_alignment_toy.py` 是**合成**的，只用标准库。**模型假设:** 8 维观测 x；2 维特征 h = W x；动作 â = v · h；「未来 token」z = P h；目标嵌入是未来观测的一个**冻结**随机投影 G（从不训练）。这是线性替身，不是 GR00T N1、SigLIP2、Q-former，也不是 DiT，所以没有「层」可选；论文里对齐过早的冲突只由大 λ 一臂代表。这些都是**声明的玩具参数**。

| 臂 | 训练损失 |
|---|---|
| A_action_only | 只在有标签样本上算动作 MSE（λ = 0） |
| B_flare | 动作 MSE + λ · (−cos)，λ = 0.2；对齐项也用无动作样本 |
| C_big_lambda | 同上，λ = 2.0 |

**共同随机数:** 每个（情形，种子）的训练数据、测试集、冻结的 G 和初始 W、v、P 都只抽一次，三臂共用。各臂**只**在 λ 上不同（A 用不了无动作样本）。五个种子。在 200 个新测试样本上的指标：动作 MSE、成功率（|â − a| < 0.25）以及 z 与目标嵌入的平均余弦，记为种子间的均值±标准差。

```python
#!/usr/bin/env python3
"""Tiny stdlib stand-in for FLARE (arXiv 2505.15659): action loss plus lambda times a
cosine alignment loss between learnable future tokens z = P W x and a frozen embedding
g(x_future) = G x_future.  This is a stdlib stand-in, not GR00T N1 / SigLIP2 / a DiT.
FLARE paper numbers 以论文为准.  GPU / RoboCasa / GR-1 本页未运行.

Shared by every arm: the same data draws, the same frozen G and the same initial
(W, v, P).  Full-batch gradient descent with exact analytic gradients.  The alignment
loss for one sample is -cos(z, g); its gradient with respect to z is
-(g/|g| - cos * z/|z|) / |z|.  Arms: A_action_only (lam = 0, labelled only),
B_flare (lam = LAMBDA, alignment on labelled + action-free), C_big_lambda
(lam = LAMBDA_BIG, otherwise as B).  Parameters were declared before the first run.
"""
import math
import random
from decimal import ROUND_HALF_UP, Decimal, getcontext

getcontext().rounding = ROUND_HALF_UP

# Declared parameters, written before the first run.
SEEDS = (0, 1, 2, 3, 4)
D = 8                    # observation dimension
K = 2                    # latent / future-token dimension
LAMBDA = 0.2             # the paper's alignment weight
LAMBDA_BIG = 2.0         # deliberately large lambda
LR = 0.05                # full-batch gradient-descent step
EPOCHS = 400             # full-batch passes
SUCCESS_TOL = 0.25       # |a_hat - a| below this counts as a success
N_TEST = 200             # fresh test samples per (regime, seed)

REGIMES = {
    "delayed": {"n_lab": 6, "n_vid": 60},
    "reactive": {"n_lab": 60, "n_vid": 0},
}
ARMS = ("A_action_only", "B_flare", "C_big_lambda")
METRICS = ("action_mse", "success", "latent_cos")
PAIRS = (("B_flare", "A_action_only"), ("C_big_lambda", "A_action_only"),
         ("C_big_lambda", "B_flare"))


def matvec(M, x):
    return [sum(M[k][j] * x[j] for j in range(len(x))) for k in range(len(M))]


def init_params(seed):
    """Common random numbers: identical W, v, P for every arm at this seed."""
    rng = random.Random(2000 + seed)
    W = [[rng.gauss(0.0, 0.1) for _ in range(D)] for _ in range(K)]
    v = [rng.gauss(0.0, 0.1) for _ in range(K)]
    P = [[rng.gauss(0.0, 0.1) for _ in range(K)] for _ in range(K)]
    return W, v, P


def frozen_G(seed):
    """Frozen target embedding matrix G (K x D), drawn once and never trained."""
    rng = random.Random(1000 + seed)
    return [[rng.gauss(0.0, 1.0) / math.sqrt(D) for _ in range(D)] for _ in range(K)]


def delayed_labelled(rng):
    goal = rng.uniform(-1.0, 1.0)
    x = [0.3 * goal + rng.gauss(0.0, 0.05)] + [rng.gauss(0.0, 1.0) for _ in range(D - 1)]
    xf = [1.0 * goal + rng.gauss(0.0, 0.05)] + [rng.gauss(0.0, 1.0) for _ in range(D - 1)]
    return x, goal, xf


def delayed_video(rng):
    goal = rng.uniform(-1.0, 1.0)
    x = [0.3 * goal + rng.gauss(0.0, 0.05)] + [rng.gauss(0.0, 1.0) for _ in range(D - 1)]
    xf = [1.0 * goal + rng.gauss(0.0, 0.05)] + [rng.gauss(0.0, 1.0) for _ in range(D - 1)]
    return x, xf


def make_labelled(rng, regime):
    if regime == "delayed":
        return delayed_labelled(rng)
    x = [rng.gauss(0.0, 1.0) for _ in range(D)]
    a = 0.5 * x[0] - 0.3 * x[1] + rng.gauss(0.0, 0.05)
    xf = [rng.gauss(0.0, 1.0) for _ in range(D)]
    return x, a, xf


def make_video(rng, regime):
    if regime == "delayed":
        return delayed_video(rng)
    x = [rng.gauss(0.0, 1.0) for _ in range(D)]
    xf = [rng.gauss(0.0, 1.0) for _ in range(D)]
    return x, xf


def generate(regime, seed, n_lab=None, n_vid=None):
    """One rng stream per (regime, seed): train data first, then the fresh test set."""
    index = list(REGIMES).index(regime)
    rng = random.Random(seed * 100 + index)
    nl = REGIMES[regime]["n_lab"] if n_lab is None else n_lab
    nv = REGIMES[regime]["n_vid"] if n_vid is None else n_vid
    lab = [make_labelled(rng, regime) for _ in range(nl)]
    vid = [make_video(rng, regime) for _ in range(nv)]
    test = [make_labelled(rng, regime) for _ in range(N_TEST)]
    return lab, vid, test


def train(W, v, P, G, lam, lab, vid):
    """Full-batch GD; exact analytic gradients for the action and cosine alignment terms."""
    n_lab = len(lab)
    align = [(x, xf) for x, _, xf in lab] + list(vid)
    n_align = len(align)
    for _ in range(EPOCHS):
        gW = [[0.0] * D for _ in range(K)]
        gv = [0.0] * K
        gP = [[0.0] * K for _ in range(K)]
        # Action loss: mean over labelled samples of (v.h - a)^2.
        for x, a, _ in lab:
            h = matvec(W, x)
            ahat = sum(v[k] * h[k] for k in range(K))
            d = 2.0 * (ahat - a) / n_lab
            for k in range(K):
                gv[k] += d * h[k]
                for j in range(D):
                    gW[k][j] += d * v[k] * x[j]
        # Alignment loss: lam * mean over alignment samples of -cos(P.h, G.xf).
        if lam != 0.0 and n_align:
            w = lam / n_align
            for x, xf in align:
                h = matvec(W, x)
                z = matvec(P, h)
                t = matvec(G, xf)
                nz = math.sqrt(sum(z[k] * z[k] for k in range(K)))
                nt = math.sqrt(sum(t[k] * t[k] for k in range(K)))
                nzt = nz * nt
                if nzt < 1e-12:
                    continue
                c = sum(z[k] * t[k] for k in range(K)) / nzt
                # d(-cos)/dz = -(t/|t| - c * z/|z|) / |z|, scaled by the mean weight.
                dz = [(-(t[k] / nt - c * z[k] / nz) / nz) * w for k in range(K)]
                for k in range(K):
                    for l in range(K):
                        gP[k][l] += dz[k] * h[l]
                dh = [sum(dz[k] * P[k][l] for k in range(K)) for l in range(K)]
                for k in range(K):
                    for j in range(D):
                        gW[k][j] += dh[k] * x[j]
        for k in range(K):
            v[k] -= LR * gv[k]
            for j in range(D):
                W[k][j] -= LR * gW[k][j]
            for l in range(K):
                P[k][l] -= LR * gP[k][l]
    return W, v, P


def evaluate(W, v, P, G, test):
    n = len(test)
    se = 0.0
    hits = 0
    cosum = 0.0
    for x, a, xf in test:
        h = matvec(W, x)
        ahat = sum(v[k] * h[k] for k in range(K))
        e = ahat - a
        se += e * e
        if abs(e) < SUCCESS_TOL:
            hits += 1
        z = matvec(P, h)
        t = matvec(G, xf)
        nz = math.sqrt(sum(z[k] * z[k] for k in range(K)))
        nt = math.sqrt(sum(t[k] * t[k] for k in range(K)))
        cosum += (sum(z[k] * t[k] for k in range(K)) / (nz * nt)) if nz * nt > 0.0 else 0.0
    return {"action_mse": se / n, "success": hits / n, "latent_cos": cosum / n}


def run(lam, seed, data):
    lab, vid, test = data
    G = frozen_G(seed)
    W, v, P = init_params(seed)
    W, v, P = train(W, v, P, G, lam, lab, vid)
    return evaluate(W, v, P, G, test)


def mean_sd(xs):
    if all(x == xs[0] for x in xs):
        return xs[0], 0.0  # identical values: no floating residue in mean or sd
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    """Half-up rounding on the shortest decimal repr; tiny non-zero values in scientific form."""
    if x != 0.0 and abs(x) < 5e-4:
        return format(Decimal(repr(x)), ".3e")
    s = format(Decimal(repr(x)), ".4f")
    return "0.0000" if s == "-0.0000" else s


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"
```
