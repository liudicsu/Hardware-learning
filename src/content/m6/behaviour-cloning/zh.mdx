到目前为止的每个月，控制器都是你自己写的：PID 回路、LQR 增益、MoveIt 目标。模仿学习（imitation learning，也叫示范学习 learning from demonstration）反过来：你把任务做给机器人看几十遍，通常是你动主臂、从臂跟着动，再由程序学出一个<strong>策略</strong>（policy），也就是从“机器人观测到什么”到“下一步该做什么”的函数。本课在一个每个数字都能核对的玩具任务上实现最简单的版本——行为克隆，并展示所有学习型策略都要面对的失败：机器人一旦漂到示范从未到达的状态，就没有可用的动作输出。

## 示范数据就是一张表

示范数据集就是一张表，每个控制步一行（一<strong>帧</strong>，frame）。每行记录它属于哪个回合（episode）、在回合里的第几帧、机器人观测到了什么、操作者做了什么动作。第 3 个月和 SO-101 一起见过的 LeRobot 正是按这些列存数据的（`episode_index`、`frame_index`、`observation.state`、`action`，另外还有相机图像和任务描述）。在 SO-101 上，状态是六个关节的位置，动作是主臂要求的六个关节目标位置，按每秒 30 帧录制。

行为克隆（behaviour cloning，BC）把这张表当成普通的监督学习问题：输入是观测，标签是动作，拟合一个函数，结束。训练这一步完全不知道这些行来自一台随时间运动的机器人。这正是 BC 容易上手的原因，也是它会以一种特定方式失败的原因。

<Formula label="行为克隆">policy = argmin over π of Σ over frames ‖π(observation) − action‖²</Formula>

## 走廊任务

本课的模型是一个在 L 形走廊里移动的点状夹爪，走廊宽 0.2 m：从 (0, 0) 沿 x 走到拐角 (1, 0)，再沿 y 走到目标 (1, 1)。每一步策略命令一次最多 0.05 m 的位移，夹爪实际移动的是这个位移<strong>再加上执行器噪声</strong>，每个轴 1 cm（舵机从来不会精确停在命令的位置）。在 80 步之内到达目标 5 cm 以内且没有碰墙，就算成功。

专家是一个脚本控制器，始终瞄准中心线上前方 0.15 m 的点；在真实系统里，对应的示范由你操作主臂录制。本课的模型在无执行器噪声的条件下录制示范，因此各帧都落在中心线附近，不包含任何恢复动作。策略用最简单的学习器：1 最近邻 BC，找到观测与当前最接近的那一帧，重放它的动作。按上面平方误差公式训练的神经网络，在每个观测处预测动作的条件均值。沿着走廊，示范在局部是单峰的——中心线上每个位置只有一个动作——所以该均值与最近录制帧的动作一致，也就是 1 最近邻做的同一决定。离开数据后，两者都没有恢复标签可外推，而这正是本课要度量的失败。

<CodeSource path="examples/month-6/behaviour-cloning/bc_reach.py" />

```python
"""bc_reach.py: behaviour cloning, covariate shift and DAgger on a point gripper in an L-shaped corridor.

The gripper moves in a plane (metres). The corridor runs from START (0, 0) along +x to the corner (1, 0),
then along +y to GOAL (1, 1); it is 0.2 m wide (walls 0.1 m either side of the centre line). Each step the
policy commands a displacement (dx, dy) of at most 0.05 m; the gripper moves by that plus actuator noise
(Gaussian, 0.01 m per axis). Success: within 0.05 m of GOAL inside 80 steps without touching a wall.

The expert is a scripted controller (pure pursuit of a point 0.15 m ahead on the centre line). Demonstrations
are recorded like a teleoperated dataset: one row per frame with episode_index, frame_index, the observation
(x, y) and the action (dx, dy). The learned policy is 1-nearest-neighbour behaviour cloning: look up the
recorded frame whose (x, y) is closest and replay its action. Standard library only, fixed seeds.
usage: python3 bc_reach.py [demos.csv]      (writes the 20-demo dataset to demos.csv if a name is given)
"""
import math
import random
import sys

START, CORNER, GOAL = (0.0, 0.0), (1.0, 0.0), (1.0, 1.0)
HALF_WIDTH, STEP, NOISE, MAX_STEPS = 0.10, 0.05, 0.01, 80


def path_s(p):
    """Distance along the centre line of the point on it nearest p, and p's distance from the line."""
    x, y = p
    cx = min(max(x, 0.0), 1.0)                       # nearest point on the first leg, (cx, 0)
    cy = min(max(y, 0.0), 1.0)                       # nearest point on the second leg, (1, cy)
    d1, d2 = math.hypot(x - cx, y), math.hypot(x - 1.0, y - cy)
    return (cx, d1) if d1 < d2 else (1.0 + cy, d2)


def point_at(s):
    s = min(max(s, 0.0), 2.0)
    return (s, 0.0) if s <= 1.0 else (1.0, s - 1.0)


def in_corridor(p):
    x, y = p
    leg1 = -0.1 <= x <= 1.0 + HALF_WIDTH and abs(y) <= HALF_WIDTH
    leg2 = abs(x - 1.0) <= HALF_WIDTH and -HALF_WIDTH <= y <= 1.0 + HALF_WIDTH
    return leg1 or leg2


def expert(p):
    """Pure pursuit: aim at the centre-line point 0.15 m ahead of where we are, at most STEP per step."""
    s, _ = path_s(p)
    tx, ty = point_at(s + 0.15) if s < 1.85 else GOAL
    dx, dy = tx - p[0], ty - p[1]
    d = math.hypot(dx, dy)
    k = min(1.0, STEP / d) if d > 0 else 0.0
    return dx * k, dy * k


def rollout(policy, rng, noise=NOISE, record=None):
    """Run one episode. Returns (result, steps, worst distance from the centre line, final position)."""
    p = (START[0] + rng.uniform(-0.03, 0.03), START[1] + rng.uniform(-0.03, 0.03))
    worst = 0.0
    for t in range(MAX_STEPS):
        a = policy(p)
        if record is not None:
            record.append((t, p, a))
        p = (p[0] + a[0] + rng.gauss(0, noise), p[1] + a[1] + rng.gauss(0, noise))
        worst = max(worst, path_s(p)[1])
        if not in_corridor(p):
            return 'wall', t + 1, worst, p
        if math.hypot(p[0] - GOAL[0], p[1] - GOAL[1]) < 0.05:
            return 'success', t + 1, worst, p
    return 'timeout', MAX_STEPS, worst, p


def record_demos(n, rng, noise=0.0):
    """Expert demonstrations; by default executed without actuator noise (a careful operator)."""
    frames = []
    for ep in range(n):
        rows = []
        rollout(expert, rng, noise=noise, record=rows)
        frames += [(ep, t, p, a) for t, p, a in rows]
    return frames


def nn_policy(frames):
    """1-nearest-neighbour behaviour cloning: replay the action of the closest recorded observation."""
    obs = [(f[2], f[3]) for f in frames]

    def policy(p):
        best = min(obs, key=lambda o: (o[0][0] - p[0]) ** 2 + (o[0][1] - p[1]) ** 2)
        return best[1]
    return policy


def place(p):
    """Where along the corridor a wall was hit."""
    s, _ = path_s(p)
    return 'leg 1' if s < 0.85 else 'corner' if s < 1.15 else 'leg 2' if s < 1.9 else 'goal end'


def evaluate(policy, seed, n=100):
    rng = random.Random(seed)
    counts = {'success': 0, 'wall': 0, 'timeout': 0}
    walls = {'leg 1': 0, 'corner': 0, 'leg 2': 0, 'goal end': 0}
    worst = []
    for _ in range(n):
        result, _, w, p = rollout(policy, rng)
        counts[result] += 1
        worst.append(w)
        if result == 'wall':
            walls[place(p)] += 1
    worst.sort()
    return counts, worst[n // 2], walls


def report(label, frames, policy):
    c, med, walls = evaluate(policy, seed=2026)
    print(f'{label:<20} {len(frames):>5} frames   success {c["success"]:>3}/100   wall {c["wall"]:>3}   '
          f'timeout {c["timeout"]:>3}   median worst offset {med * 100:.1f} cm')
    if c['wall']:
        print(' ' * 21 + 'wall hits at: ' + ', '.join(f'{k} {v}' for k, v in walls.items()))


def main():
    rng = random.Random(6)
    demos = record_demos(80, rng)
    print('Recorded 80 expert demos (no actuator noise), first frames of episode 0:')
    print('episode_index frame_index  observation.state   action')
    for ep, t, p, a in demos[:3]:
        print(f'{ep:>13} {t:>11}  ({p[0]:+.3f}, {p[1]:+.3f})  ({a[0]:+.3f}, {a[1]:+.3f})')
    lengths = {}
    for ep, *_ in demos:
        lengths[ep] = lengths.get(ep, 0) + 1
    print(f'episode length: {min(lengths.values())} to {max(lengths.values())} frames')
    if len(sys.argv) > 1:
        with open(sys.argv[1], 'w') as f:
            f.write('episode_index,frame_index,x,y,dx,dy\n')
            for ep, t, p, a in demos:
                if ep < 20:
                    f.write(f'{ep},{t},{p[0]:.4f},{p[1]:.4f},{a[0]:.4f},{a[1]:.4f}\n')
        print(f'wrote the first 20 episodes to {sys.argv[1]}')

    print('\nEvaluation: 100 rollouts each, actuator noise 1 cm per step, same seed for every policy')
    report('expert', [], expert)
    for n in (5, 20, 80):
        frames = [f for f in demos if f[0] < n]
        report(f'BC, {n} demos', frames, nn_policy(frames))
    noisy = record_demos(20, random.Random(8), noise=NOISE)      # the expert corrects its own noise
    report('BC, 20 noisy demos', noisy, nn_policy(noisy))

    print('\nDAgger: start from BC on 5 demos; each round runs the current policy 10 times with noise,')
    print('asks the expert what it would have done in every visited state, and adds those frames')
    frames = [f for f in demos if f[0] < 5]
    drng = random.Random(7)
    for k in range(1, 4):
        policy = nn_policy(frames)
        new = []
        for ep in range(10):
            rows = []
            rollout(policy, drng, record=rows)
            new += [(1000 * k + ep, t, p, expert(p)) for t, p, _ in rows]
        frames = frames + new
        report(f'DAgger round {k}', frames, nn_policy(frames))


if __name__ == '__main__':
    main()
```

## 协变量偏移

现在打开执行器噪声，每个策略各跑 100 次。每个策略的评估都从同一个随机种子开始。只有每个策略的第一次运行看到的起点和噪声完全相同，因为走的步数不同的策略消耗随机数的速度也不同；第 4 课会讲怎样给每次运行单独设种子，让每个策略遇到完全相同的条件：

```text
                     wall hits at: leg 1 1, corner 2, leg 2 10, goal end 20
BC, 80 demos          3061 frames   success  67/100   wall  33   timeout   0   median worst offset 5.9 cm
                     wall hits at: leg 1 3, corner 1, leg 2 5, goal end 24
```

专家每次都成功：它根据自己真实所在的位置计算动作，所以能纠正噪声。克隆出来的策略失败三分之一甚至更多，而且从 20 条示范加到 80 条毫无变化，两次都是 67/100。“median worst offset” 是 100 次运行里“每次离中心线最远的距离”的中位数；克隆策略偏离的距离几乎是专家的两倍。

原因叫<strong>协变量偏移</strong>（covariate shift）：策略在测试时访问的状态，不是它训练时见过的状态。写成一步递推：每轴约 1 cm 的执行器噪声把夹爪移到 `p_{t+1} = p_t + a_t + ε_t`；a_t 是离 p_t 最近的录制帧的动作；那些帧都在中心线上，所以 a_t 几乎没有侧向纠正分量；下一状态因此离数据更远，那里最近的帧仍是中心线上的帧。每一步重复这个映射，偏移只会增大而不会被纠正。无噪声的示范几步之内就全部收拢到中心线上，数据集里几乎没有偏离中心线 3 cm 以上的帧——当噪声把夹爪推到侧面 5 cm 时，最近帧仍然说“直走”，而不是“回来”。再加同一种示范只会在中心线上加更多帧，所以 80 条并不比 20 条好。

“wall hits at” 这一行显示了哪里出了问题。大多数失败发生在目标端：专家一进入目标 5 cm 范围，示范就结束了，所以数据里没有一帧告诉策略“偏了几厘米到达目标附近时该怎么办”。策略继续往 +y 走，撞上了尽头的墙。真实数据集也有同样的空洞：操作者刚完成任务之后的时刻，以及抓取失败之后的状态——好的操作者从来不会示范这些。

## 两种修复：带噪声的示范与 DAgger

解决办法是把<strong>恢复</strong>放进数据里：来自偏离路径位置的帧，标签是把机器人带回来的动作。常用的有两种做法。

第一种是录示范时就开着噪声，让专家不断纠正自己的漂移（DART 方法的思路）。在真机上，这意味着以正常速度、在自然的扰动下录制，而不是慢慢地、完美地做，并且有意识地示范恢复动作。第二种是 <strong>DAgger</strong>（dataset aggregation，数据集聚合）：运行当前策略，让专家给策略访问过的每个状态标注“专家在这里会怎么做”，把这些帧加进数据集，重新训练，重复。这样收集到的数据恰好在学习者出错的地方。模型从最弱的策略开始 DAgger，也就是只用 5 条示范的 BC：

在真机上，DAgger 里的专家就是你，所以流程是：让策略自己运行，开始出错时用主臂接管，保留纠正后的帧。LeRobot 的 `lerobot-rollout` 有一个 `dagger` 策略（strategy），专门用来做这种人在回路中的数据收集。

## 绕过障碍的两种走法：MSE、k-means 分箱与残差 VQ

上面的走廊在每个位置只有一个正确动作。真实示范常常有**好几个**：一位操作员从杯子左边绕，另一位从右边绕。本页开头的平方损失公式这时会预测两者的**均值**，也就是直接撞向杯子。Behavior Transformers（BeT，[arXiv:2206.11251](https://arxiv.org/abs/2206.11251)）的做法是：用 k-means 把动作聚成若干箱，预测一个关于箱的类别分布，再在选中的箱中心上加一个连续的**偏移**。VQ-BeT（[arXiv:2403.03181](https://arxiv.org/abs/2403.03181)，[项目页](https://sjlee.cc/vq-bet/)）把 k-means 换成**残差向量量化**：第一个码本量化动作（**主码**，粗聚类），第二个码本量化剩下的残差（**次码**，细节），解码动作是所选向量之和，同样再加偏移头。论文使用两层残差，并认为 k-means 难以扩展到高维动作或长动作块，也没有梯度。论文报告的结论——模式捕获优于 BeT 与 Diffusion Policy、仿真中推理比 Diffusion Policy 快约 5 倍——都是**论文的说法：以论文为准**。这里不测任何速度。

### 公平设置

`vqbet_residual_vq_toy.py` 是**合成**的，只用标准库。一个点沿 +x 运动，必须从左或右绕过障碍框（0.40 ≤ x ≤ 0.60，|y| < 0.12）；每条示范以 0.5 的概率选一边，速度有 ±20 % 变化。观测是 x 的粗分箱（10 个）和当前所在一侧（3 个）。每一臂拿到**每个种子同样的 60 条训练示范与 60 条留出示范、同样的观测分箱、同样的计数式预测头**（每个观测下的经验频率）和**同样的 rollout 噪声流**：

| 臂 | 动作表示 | 存储的码本向量 | 码组合数 |
| --- | --- | --- | --- |
| `MSE` | 每个观测的平均动作 | — | — |
| `kmeans`（BeT 式） | 一个码本，K = 8，加每个（观测, 码）偏移 | 8 | 8 |
| `rvq`（VQ-BeT 式） | 主码 4 + 残差上的次码 4，加偏移 | 8 | 16 |

两个量化器都做 12 次 Lloyd 迭代（`rvq` 每级 6 次）。码本大小相同，`rvq` 的组合数仍是两倍，所以它的预测头和偏移表也大一倍；程序把参数量打印出来，不加掩饰。五个种子，每个 100 次 rollout，报 mean±sd。这不是 transformer，也不是 FAST/DCT 分词（6.3）、扩散（6.2）或上面的 DAgger 循环。

### 读结果

- **MSE 把模式平均掉。** 起点处两边相互抵消，平均动作几乎没有侧向分量，66 % 的 rollout 撞上障碍；五个种子里没有一个同时用到两边。
- **两个离散臂都保住了两种模式。** `kmeans` 与 `rvq` 从不碰撞，约一半时间走左边（0.53 与 0.49），因为采样一个码就是选一边，而不是取两边的平均。
- **重建误差接近。** 在留出动作上，`rvq` 量化误差略低（偏移前 9.0e-06 对 1.15e-05），但种子间离散更大；在训练示范上拟合的偏移表对留出误差几乎没有改变。在这个二维、每臂八个向量的任务上，k-means 分箱已经够用；论文声称的残差码本优势针对的是本玩具没有的高维动作与动作块。

```python
#!/usr/bin/env python3
"""vqbet_residual_vq_toy.py: MSE BC vs k-means bins vs residual VQ + offset (stdlib).

Synthetic two-mode demonstrations: a point moves +x through a corridor and must
pass an obstacle box (0.40 <= x <= 0.60, |y| < 0.12) either LEFT or RIGHT; each
demo picks a side with probability 0.5. Action a = (dx, dy) per step.
Observation = (x bin of 10, side bin of 3: y<-0.02 / |y|<=0.02 / y>0.02).
Every arm gets the SAME demos, the SAME observation bins and the SAME
count-based heads; only the action representation differs:
  MSE    : per-observation mean action (least squares with one-hot features)
  kmeans : one codebook of K=8 vectors (Lloyd, 12 iterations), categorical
           over codes per observation + per-(obs, code) mean offset (BeT-style)
  rvq    : residual VQ, 2 stages x 4 vectors (6 + 6 Lloyd iterations; stage 2
           quantizes stage-1 residuals), categorical over the 16 (primary,
           secondary) pairs per observation + per-(obs, pair) mean offset
Both quantizers store 8 codebook vectors and get 12 Lloyd iterations; rvq has
16 code combinations against 8, so its head and offset tables are 2x larger
(printed). Not a transformer, not a trained network, no GPU.
usage: python3 vqbet_residual_vq_toy.py
"""
from __future__ import annotations

import math
import random
import statistics

SEEDS = (0, 1, 2, 3, 4)
N_DEMOS = 60
N_ROLLOUTS = 100
STEPS = 20
DX = 0.05
OBST = (0.40, 0.60, 0.12)
NOISE = 0.004          # per-step actuator noise (demos and rollouts)
K = 8                  # k-means codebook vectors
K1, K2 = 4, 4          # residual VQ: primary and secondary codebook sizes
ITERS = 12             # Lloyd iterations per quantizer (rvq: split 6 + 6)


def obs_of(x, y):
    xb = min(9, max(0, int(x * 10)))
    sb = 0 if y < -0.02 else (2 if y > 0.02 else 1)
    return xb * 3 + sb


def demo(rng):
    side = rng.choice((-1, 1))
    x, y, rows = 0.0, rng.gauss(0, 0.005), []
    gain = 1 + 0.2 * rng.gauss(0, 1)
    for _ in range(STEPS):
        if x < 0.35:
            dy = side * 0.045 * gain
        elif x < 0.65:
            dy = 0.0
        else:
            dy = -side * 0.045 * gain
        a = (DX, dy)
        rows.append((obs_of(x, y), a))
        x += a[0] + rng.gauss(0, NOISE)
        y += a[1] + rng.gauss(0, NOISE)
    return rows


def d2(a, b):
    return (a[0] - b[0]) ** 2 + (a[1] - b[1]) ** 2


def lloyd(points, k, iters, rng):
    cents = [points[i] for i in rng.sample(range(len(points)), k)]
    for _ in range(iters):
        groups = [[] for _ in range(k)]
        for p in points:
            groups[min(range(k), key=lambda j: d2(p, cents[j]))].append(p)
        cents = [(sum(p[0] for p in g) / len(g), sum(p[1] for p in g) / len(g)) if g else cents[j]
                 for j, g in enumerate(groups)]
    return cents


def nearest(p, cents):
    return min(range(len(cents)), key=lambda j: d2(p, cents[j]))


class Quantizer:
    def __init__(self, kind, actions, rng):
        self.kind = kind
        if kind == "kmeans":
            self.books = [lloyd(actions, K, ITERS, rng)]
        else:
            b1 = lloyd(actions, K1, ITERS // 2, rng)
            res = [(a[0] - b1[nearest(a, b1)][0], a[1] - b1[nearest(a, b1)][1]) for a in actions]
            self.books = [b1, lloyd(res, K2, ITERS // 2, rng)]

    def encode(self, a):
        codes, r = [], a
        for b in self.books:
            j = nearest(r, b)
            codes.append(j)
            r = (r[0] - b[j][0], r[1] - b[j][1])
        return tuple(codes)

    def decode(self, codes):
        return (sum(b[j][0] for b, j in zip(self.books, codes)), sum(b[j][1] for b, j in zip(self.books, codes)))

    def combos(self):
        return K if self.kind == "kmeans" else K1 * K2


def fit(kind, rows, rng):
    if kind == "MSE":
        acc = {}
        for o, a in rows:
            s = acc.setdefault(o, [0.0, 0.0, 0])
            s[0] += a[0]; s[1] += a[1]; s[2] += 1
        return {"kind": kind, "mean": {o: (s[0] / s[2], s[1] / s[2]) for o, s in acc.items()}}
    q = Quantizer(kind, [a for _, a in rows], rng)
    counts, off = {}, {}
    for o, a in rows:
        c = q.encode(a)
        counts.setdefault(o, {}).setdefault(c, 0)
        counts[o][c] += 1
        dec = q.decode(c)
        s = off.setdefault((o, c), [0.0, 0.0, 0])
        s[0] += a[0] - dec[0]; s[1] += a[1] - dec[1]; s[2] += 1
    return {"kind": kind, "q": q, "counts": counts,
            "off": {k: (s[0] / s[2], s[1] / s[2]) for k, s in off.items()}}


def act(model, o, rng):
    if model["kind"] == "MSE":
        return model["mean"].get(o, (DX, 0.0))
    cs = model["counts"].get(o)
    if not cs:
        return (DX, 0.0)
    r, acc = rng.random() * sum(cs.values()), 0.0
    for c, n in sorted(cs.items()):
        acc += n
        if r < acc:
            break
    dec, of = model["q"].decode(c), model["off"][(o, c)]
    return (dec[0] + of[0], dec[1] + of[1])


def recon(model, rows):
    """Held-out demo actions: decode-only and decode+offset squared error."""
    if model["kind"] == "MSE":
        e = [d2(a, model["mean"].get(o, (DX, 0.0))) for o, a in rows]
        return statistics.mean(e), statistics.mean(e)
    q, e0, e1 = model["q"], [], []
    for o, a in rows:
        c = q.encode(a)
        dec = q.decode(c)
        of = model["off"].get((o, c), (0.0, 0.0))
        e0.append(d2(a, dec))
        e1.append(d2(a, (dec[0] + of[0], dec[1] + of[1])))
    return statistics.mean(e0), statistics.mean(e1)


def rollout(model, rng):
    x, y, hit, ymin, ymax = 0.0, rng.gauss(0, 0.005), False, 0.0, 0.0
    for _ in range(STEPS):
        a = act(model, obs_of(x, y), rng)
        x += a[0] + rng.gauss(0, NOISE)
        y += a[1] + rng.gauss(0, NOISE)
        if OBST[0] <= x <= OBST[1]:
            hit = hit or abs(y) < OBST[2]
            ymin, ymax = min(ymin, y), max(ymax, y)
    side = "L" if ymin < -OBST[2] else ("R" if ymax > OBST[2] else "-")
    return hit, side, abs(y)


def params(model):
    if model["kind"] == "MSE":
        return f"{2 * len(model['mean'])} (means)"
    q = model["q"]
    book = 2 * sum(len(b) for b in q.books)
    return f"{book} codebook + {q.combos()}x30 head + {2 * q.combos()}x30 offset"


def ms(v, f):
    return f"{statistics.mean(v):{f}}±{statistics.pstdev(v):{f}}"


def main():
    print(f"Synthetic 2-mode demos: {N_DEMOS} train + {N_DEMOS} held-out per seed, {len(SEEDS)} seeds, "
          f"{N_ROLLOUTS} rollouts/seed, obstacle x∈[{OBST[0]},{OBST[1]}] |y|<{OBST[2]}, noise {NOISE}")
    print(f"kmeans K={K}; rvq {K1}x{K2}; {ITERS} Lloyd iterations each; same heads/offset rule")
    rows_out = {}
    for kind in ("MSE", "kmeans", "rvq"):
        res = {"col": [], "left": [], "both": [], "end": [], "q": [], "qo": []}
        for seed in SEEDS:
            drng = random.Random(seed)
            train = [r for _ in range(N_DEMOS) for r in demo(drng)]
            held = [r for _ in range(N_DEMOS) for r in demo(drng)]
            model = fit(kind, train, random.Random(100 + seed))
            q0, q1 = recon(model, held)
            rrng = random.Random(200 + seed)  # same rollout stream for every arm
            outs = [rollout(model, rrng) for _ in range(N_ROLLOUTS)]
            left = sum(s == "L" for _, s, _ in outs)
            right = sum(s == "R" for _, s, _ in outs)
            res["col"].append(sum(h for h, _, _ in outs) / N_ROLLOUTS)
            res["left"].append(left / max(1, left + right))
            res["both"].append(1.0 if left and right else 0.0)
            res["end"].append(statistics.mean(e for _, _, e in outs))
            res["q"].append(q0)
            res["qo"].append(q1)
        rows_out[kind] = (res, params(model))
    print("arm collision left_share both_modes_seen quant_MSE quant+offset_MSE end_|y| params")
    for kind, (r, p) in rows_out.items():
        print(f"{kind} {ms(r['col'], '.2f')} {ms(r['left'], '.2f')} {ms(r['both'], '.1f')} "
              f"{ms(r['q'], '.2e')} {ms(r['qo'], '.2e')} {ms(r['end'], '.3f')} {p}")
    print("MSE regression has no codes: its quant columns are the regression error.")
    print("Paper speed-ups (e.g. 5x vs diffusion) are not measured here: 以论文为准. GPU training: 本页未运行.")


if __name__ == "__main__":
    main()
```

## 常见错误

- <strong>只录完美的示范。</strong>没有失误的数据集里也就没有恢复动作，而策略一定会遇到专家从没展示过的状态。有意示范从小失误中恢复。
- <strong>凭一次运行评价策略。</strong>一段视频只能证明策略<em>能</em>成功，不能说明它多常成功。用一组固定的初始条件来数，如上面的 100 次固定种子运行；本月第 4 课会讲需要多少次试验。
- <strong>两次运行之间改了好几样东西。</strong>模型对每个策略用同样的种子、同样的运行次数和噪声，让策略成为主要的区别。在硬件上比较两个策略时，保持物体、光照和起始位置不变。
- <strong>一味加同样的数据。</strong>策略在某处失败时，先确定失败位置（“wall hits at” 那一行），再在那里录制或重新标注数据。同样的 80 条示范没有赢过 20 条。
- <strong>用机器人实际做了什么来训练，而不是命令了什么。</strong>动作列必须是命令（主臂的关节目标），而不是从臂下一帧测到的位置，否则策略会学会滞后。

## HAMSTER：上层画二维路径，下层三维策略

本页到目前为止的每个策略都把相机看到的东西直接映射成动作，所以图像里的任何东西都可能进入决策：杯子，也包括桌布和光照。**HAMSTER** 把策略拆成两层。上层是一个视觉语言模型，在图像上为夹爪画一条粗略的**二维路径**；下层是一个使用三维输入的小策略，沿路径执行。路径可以从视频、手绘草图或仿真中标注出来，所以上层可以用便宜的非本域数据学习，下层只需学局部几何。本节在一个合成替身上检验这种拆分。这**不是** ACT 或 Diffusion Policy 动作头（第 6 个月 act-diffusion），**不是** MolmoAct 的深度词元和可编辑轨迹（第 6 个月 vla-models），也**不是** OpenVLA 微调。

### 上层画路径，下层执行

<Formula label="上层路径（HAMSTER 第 4.1 节）">p = [(x_t, y_t, gripper_open_t)],  x_t, y_t ∈ [0, 1]</Formula>

<Formula label="以路径为条件的下层策略（HAMSTER 第 4.2 节）">a ∼ πθ(a ∣ s, o, z, p)</Formula>

路径携带的是**做什么**和大致**在哪里**；它不说明怎么抓，作为二维图画也不携带深度。下层从自己的三维观测中获得深度。

**算例。** toy 里每个路径点等于感知到的位置（每轴像素噪声标准差 0.01）加上每轴标准差为 `PATH_SD` 的路径噪声。`PATH_SD = 0.02` 时，一个点的二维误差每轴标准差为 `√(0.02² + 0.01²) = 0.0224`。其平均长度为它乘以 `√(π/2) = 1.2533`，即 `0.0280`，按 toy 的 ×100 单位为 2.80。在三个 `PATH_SD = 0.02` 的情形中，打印的 B 路径 ADE 为 2.7656 到 2.9518。`PATH_SD = 0.06` 时同一公式给出 7.62，打印值为 7.4559。

**这里没有积分步长。** 夹爪是运动学模型：每步朝指令点最多移动 `V = 0.05`，而且没有障碍物，所以没有需要说明的步长判据。

### 公平设置

`hamster_hierarchical_path_toy.py` 是**合成**模型，只用标准库。**模型假设**如下。
- 前置相机看到像平面（`u`、`v`）；`z` 是深度。夹爪要在 60 步内抓起指定物体并放进料箱；桌上还有一个干扰物。
- 每个场景有一个背景外观向量（四个数，代表纹理、光照和颜色）。本域示范中每个数取自 N(0, 0.1)；偏移情形的测试场景取自 N(0.5, 0.1)。
- 上层路径等于感知到的位置加上标准差为 `PATH_SD` 的噪声。因为 VLM 在非本域数据上训练，它的误差与背景无关。这是替身，**不是**训练出来的 VLM。
- 两个需要学习的部分用同一种学习器：在同样的本域示范上做 k 近邻（k = 3）。

| 组 | 模型 |
|---|---|
| A_mono | 整体式：kNN，从全部观测特征（物体或料箱相对夹爪的位置、是否抓着、四个背景数）到动作 |
| B_hier | 路径为起点、物体（闭合）、料箱（张开）；下层只用相对路径的特征做 kNN（下一个路径点减夹爪的 `u`、`v`；该点在三维观测中的深度减夹爪深度；是否抓着），用真值路径学习 |
| C_wrong | B 的下层，但给它偏离任务的路径：起点、干扰物（闭合）、料箱（张开） |

**共用随机数**（common random numbers）的做法是，每个（情形、种子）的示范、测试场景、感知噪声、起点和路径噪声都只抽一次，三组共用；每个种子 40 个测试回合，5 个种子。指标：成功率 %、到料箱的最终三维距离（×100）、路径 ADE（×100，仅 B 和 C）和跟踪误差（夹爪到自身路径的平均二维距离，×100，仅 B 和 C）。

| 情形 | 背景偏移 | 背景标准差 | 本域示范 | 路径标准差 | 预期 |
|---|---|---|---|---|---|
| visual_shift | 0.5 | 0.1 | 20 | 0.02 | B 稳定胜过 A |
| matched_easy | 0 | 0.1 | 200 | 0.02 | 接近打平 |
| coarse_path | 0 | 0.1 | 200 | 0.06 | B 落败 |
| no_appearance | 0 | 0 | 200 | 0.02 | 接近打平或 B 落败（第一次运行后加入） |

**看过结果后做的选择。**
- **`no_appearance` 是在第一次运行后加入的**，因为预先声明的三个情形都没有让 B 打平或落败。它的预期在运行之前就写下了。预先声明的三个情形保留各自的随机流（用固定的 `STREAM` 表代替按字母排序的下标），所以它们的数字与第一次运行逐字节相同。情形标题行增加了一个“background sd”字段。
- 第一次运行后，近邻搜索改写为带提前退出的版本（`nearest`）以提速；输出逐字节相同，并有测试把它与完整排序对照。
- 没有采用的做法：在所有情形中都调低背景标准差，那会改变预先声明的情形；只保留预先声明的三个情形，那样就没有一个让 B 打平或落败的情形。

```python
#!/usr/bin/env python3
"""HAMSTER-style hierarchy: a high-level 2-D path, then a path-conditioned 3-D low-level policy.

Synthetic, stdlib only.  Not an ACT / Diffusion Policy head (earlier sections), not MolmoAct's
depth tokens and trace (Month 6 vla-models), not an OpenVLA-OFT fine-tune.  Real HAMSTER
(VILA-1.5-13B path VLM, RVT-2 / 3D-DA low level, real robot) / GPU: 本页未运行.  Paper numbers
are 以论文为准 (arXiv 2502.05485).

World: a front camera sees the image plane (u, v); z is depth.  The gripper must pick the named
object (on the table) and place it in the bin within T_MAX steps; a distractor object also sits
on the table.  A step moves the gripper by at most V.  No integration step: the gripper is
kinematic and there are no obstacles, so a step's length is the only motion constraint.
Appearance: every scene has a background appearance vector (APP numbers: texture, lighting,
colour).  In-domain demonstrations have background N(0, BG_SD); test scenes have N(SHIFT, BG_SD)
per number, the visual domain gap.
Data, shared by every arm (common random numbers): DEMOS in-domain demonstrations (state-action
pairs of a noisy demonstrator on random in-domain scenes), test scenes, starts, perception noise
and high-level path noise are drawn once per (regime, seed).
Arms:
  A_mono    monolithic policy: k-nearest-neighbour (K_NN = 3) from all observation features
            (object and bin position relative to the gripper, held flag, and the background
            appearance numbers, as an image-in policy sees them) to the action.
  B_hier    high level: a coarse 2-D path [(u, v, gripper)] = start, object (close), bin (open),
            each point off by PATH_SD (the VLM's coarseness; it is trained off-domain, so its
            error does not depend on SHIFT; a stand-in, not a trained VLM).  Low level: the same
            kNN learner on path-relative features only (next path point minus gripper in u, v;
            the point's depth from the 3-D observation minus gripper depth; held flag), learned
            from the same DEMOS with oracle paths, as in the paper.
  C_wrong   B's low level given an off-task path: start, distractor (close), bin (open).
Regimes and expectations, written before the first run:
  visual_shift   SHIFT 0.5, DEMOS 20, PATH_SD 0.02   B consistent win over A
  matched_easy   SHIFT 0,   DEMOS 200, PATH_SD 0.02  near-tie
  coarse_path    SHIFT 0,   DEMOS 200, PATH_SD 0.06  B loses (path error the low level follows)
  C loses to B in every regime.
Added after the first run (none of the three regimes above gave B a tie or a loss):
  no_appearance  SHIFT 0,   DEMOS 200, PATH_SD 0.02, BG_SD 0  near-tie or B loses (without
                 appearance numbers A sees the same geometry as B's low level, and B adds path
                 error); written down before this regime was run.  The three regimes above are
                 unchanged (each keeps its own random stream) and still printed.
Metrics per seed (TESTS episodes): success %, final 3-D distance to the bin (x100), path ADE
(mean 2-D distance of the path points to the true ones, x100; B and C only) and tracking error
(mean 2-D distance from the gripper to its path polyline, x100; B and C only).
"""
import math
import random

SEEDS = (0, 1, 2, 3, 4)
V = 0.05
R = 0.06
T_MAX = 60
V_TABLE = 0.05
PIX_SD = 0.01
Z_SD = 0.02
APP = 4
BG_SD = 0.1
A_SD = 0.005
K_NN = 3
TESTS = 40
NUM_ZERO = 1e-9
ARMS = ("A_mono", "B_hier", "C_wrong")
# name: (SHIFT, DEMOS, PATH_SD, background sd); the first three were declared before the first run
REGIMES = {
    "visual_shift": (0.5, 20, 0.02, BG_SD),
    "matched_easy": (0.0, 200, 0.02, BG_SD),
    "coarse_path": (0.0, 200, 0.06, BG_SD),
    "no_appearance": (0.0, 200, 0.02, 0.0),  # added after the first run
}
STREAM = {"coarse_path": 0, "matched_easy": 1, "visual_shift": 2, "no_appearance": 3}  # random stream per regime


def sub(a, b):
    return [x - y for x, y in zip(a, b)]


def norm(a):
    return math.sqrt(sum(x * x for x in a))


def scene(rng, shift, bg_sd=BG_SD):
    obj = [rng.uniform(0.1, 0.4), V_TABLE, rng.uniform(0.3, 0.7)]
    dis = [rng.uniform(0.1, 0.4), V_TABLE, rng.uniform(0.3, 0.7)]
    while norm(sub(dis, obj)) < 0.15:
        dis = [rng.uniform(0.1, 0.4), V_TABLE, rng.uniform(0.3, 0.7)]
    bin_ = [rng.uniform(0.6, 0.9), V_TABLE, rng.uniform(0.3, 0.7)]
    bg = [rng.gauss(shift, bg_sd) for _ in range(APP)]
    return {"obj": obj, "dis": dis, "bin": bin_, "bg": bg}


def start(rng):
    return [rng.uniform(0.05, 0.45), rng.uniform(0.25, 0.45), rng.uniform(0.3, 0.7)]


def step_to(g, target):
    d = sub(target, g)
    n = norm(d)
    return list(target) if n <= V else [x + V * y / n for x, y in zip(g, d)]


def mono_features(g, held, sc):
    tgt = sc["bin"] if held else sc["obj"]
    return [float(held)] + sub(tgt, g) + list(sc["bg"])


def low_features(g, held, point_uv, depth):
    return [float(held), point_uv[0] - g[0], point_uv[1] - g[1], depth - g[2]]


def demos(rng, n, bg_sd):
    mono, low = [], []
    for _ in range(n):
        sc = scene(rng, 0.0, bg_sd)
        g = start(rng)
        held = 0
        for _ in range(T_MAX):
            tgt = sc["bin"] if held else sc["obj"]
            nxt = step_to(g, tgt)
            a = [x - y + rng.gauss(0.0, A_SD) for x, y in zip(nxt, g)]
            mono.append((mono_features(g, held, sc), a))
            low.append((low_features(g, held, tgt[:2], tgt[2]), a))
            g = [x + y for x, y in zip(g, a)]
            if norm(sub(g, tgt)) <= R / 2:
                if held:
                    break
                held = 1
    return mono, low


def knn_step(table, f, g):
    near = nearest(table, f)
    a = [sum(r[j] for r in near) / K_NN for j in range(3)]
    n = norm(a)
    return [x + y * (min(1.0, V / n) if n > 0 else 0.0) for x, y in zip(g, a)]


def seg_dist(p, a, b):
    d = sub(b, a)
    L = d[0] * d[0] + d[1] * d[1]
    t = 0.0 if L == 0 else max(0.0, min(1.0, ((p[0] - a[0]) * d[0] + (p[1] - a[1]) * d[1]) / L))
    return norm([p[0] - a[0] - t * d[0], p[1] - a[1] - t * d[1]])


def episode(arm, sc, seen, g, path, tables):
    mono, low = tables
    held, track = 0, []
    for _ in range(T_MAX):
        if arm == "A_mono":
            q = knn_step(mono, mono_features(g, held, seen), g)
        else:
            k = 2 if held else 1
            pick = seen["dis"] if arm == "C_wrong" else seen["obj"]
            depth = seen["bin"][2] if held else pick[2]
            q = knn_step(low, low_features(g, held, path[k][:2], depth), g)
            track.append(min(seg_dist(g, path[i], path[i + 1]) for i in range(2)))
        g = q
        if not held and norm(sub(g, sc["obj"])) <= R:
            held = 1
        if held and norm(sub(g, sc["bin"])) <= R:
            return 1.0, norm(sub(g, sc["bin"])), track
    return 0.0, norm(sub(g, sc["bin"])), track


def shared_draws(regime, seed):
    """Common random numbers: demos, scenes, perception, starts and path noise drawn once."""
    shift, n, path_sd, bg_sd = REGIMES[regime]
    rng = random.Random(1000 * seed + STREAM[regime])
    tables = demos(rng, n, bg_sd)
    tests = []
    for _ in range(TESTS):
        sc = scene(rng, shift, bg_sd)
        seen = {k: [x + rng.gauss(0.0, s) for x, s in zip(sc[k], (PIX_SD, PIX_SD, Z_SD))] for k in ("obj", "dis", "bin")}
        seen["bg"] = sc["bg"]
        g = start(rng)
        noise = [[rng.gauss(0.0, path_sd), rng.gauss(0.0, path_sd)] for _ in range(2)]
        tests.append((sc, seen, g, noise))
    return tables, tests


def make_path(arm, seen, g, noise):
    pick = seen["dis"] if arm == "C_wrong" else seen["obj"]
    return [[g[0], g[1], 1], [pick[0] + noise[0][0], pick[1] + noise[0][1], 0], [seen["bin"][0] + noise[1][0], seen["bin"][1] + noise[1][1], 1]]


def evaluate(arm, regime, draw):
    tables, tests = draw
    succ, err, ade, trk = [], [], [], []
    for sc, seen, g, noise in tests:
        path = make_path(arm, seen, g, noise)
        s, e, track = episode(arm, sc, seen, list(g), path, tables)
        succ.append(s)
        err.append(e)
        if arm != "A_mono":
            ade.append((norm(sub(path[1][:2], sc["obj"][:2])) + norm(sub(path[2][:2], sc["bin"][:2]))) / 2)
            trk.append(sum(track) / len(track))
    out = {"succ": 100.0 * sum(succ) / len(succ), "err": 100.0 * sum(err) / len(err)}
    out["ade"] = 100.0 * sum(ade) / len(ade) if ade else None
    out["trk"] = 100.0 * sum(trk) / len(trk) if trk else None
    return out


def nearest(table, f):
    """The K_NN rows nearest to f, ordered by (distance, row index): same as heapq.nsmallest, with early exit."""
    best = []
    worst = float("inf")
    for idx, (row, act) in enumerate(table):
        d = 0.0
        for x, y in zip(row, f):
            d += (x - y) * (x - y)
            if d >= worst:
                break
        else:
            best.append((d, idx, act))
            best.sort(key=lambda b: (b[0], b[1]))
            if len(best) > K_NN:
                best.pop()
            if len(best) == K_NN:
                worst = best[-1][0]
    return [b[2] for b in best]


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


def main():
    print("Synthetic HAMSTER-style 2-D path + path-conditioned low level vs a monolithic kNN policy vs an off-task path; not a VLM")
    print(f"V={V} R={R} T_MAX={T_MAX} PIX_SD={PIX_SD} Z_SD={Z_SD} APP={APP} BG_SD={BG_SD} K_NN={K_NN} tests={TESTS} seeds={len(SEEDS)}")
    print("no integration step: kinematic steps of at most V, no obstacles")
    print("regime arm success_% final_err_x100 path_ade_x100 track_err_x100  (mean+-sd over seeds)")
    for regime, (shift, n, path_sd, bg_sd) in REGIMES.items():
        print(f"{regime} (background shift {shift}; background sd {bg_sd}; in-domain demos {n}; path sd {path_sd})")
        draws = [shared_draws(regime, s) for s in SEEDS]
        res = {arm: [evaluate(arm, regime, d) for d in draws] for arm in ARMS}
        for arm in ARMS:
            cols = []
            for k in ("succ", "err", "ade", "trk"):
                cols.append("n/a" if res[arm][0][k] is None else "{}+-{}".format(*map(num, mean_sd([r[k] for r in res[arm]]))))
            print(f"  {arm} " + " ".join(cols))
        for x, y in (("B_hier", "A_mono"), ("C_wrong", "B_hier")):
            for key in ("succ", "err"):
                print(f"  paired {x[0]}-{y[0]} {key}: {verdict([r[key] for r in res[x]], [r[key] for r in res[y]])}")
    print("No winner declared: the path helps when appearance shifts; a coarse or off-task path is followed faithfully")
    print("HAMSTER VLM / RVT-2 / 3D-DA / real robot / GPU: 本页未运行; paper numbers 以论文为准")


if __name__ == "__main__":
    main()
```

### 读懂各情形

本页标签按以下顺序使用。**打平：每个种子都完全相同**只用于配对的逐种子差值在每个种子上都严格为零；`|配对均值|` 和它的标准差都小于 1e-9 时标为**数值上为零（浮点残差），等同打平**（这种行不打印同号计数）；`|配对均值| ≤ sd` 时为**接近打平、差距很小，在种子噪声之内**；否则是**稳定**差距（`|配对均值| > sd`），`|m|` 小于两组中较小均值的 20 % 时叫**小**，否则叫**明显**；20 % 规则只用来在这两个词之间选择。每条稳定的行都带 5 个种子上的同号计数，符号相反的种子都会报告；只有同号计数不能让差距变成稳定。差距都由未四舍五入的数值计算。配对差值为 B−A 和 C−B。`succ` 是成功率（%），`err` 是到料箱的最终距离（×100）。

- **visual_shift** 情形如下。
  - **分层赢了，差距明显**，B−A 成功率 76.5000±7.4162 个百分点，5 个种子同号（A 2.0 %，B 78.5 %）。
  - A 的每个背景数都偏移了 0.5，所以它的最近邻是按背景挑出来的，而不是按物体在哪里。
  - 偏离任务的路径输了，差距明显：C−B 成功率 −78.0000±6.2249，5/5。C 朝干扰物走去，从未抓到物体；下层无法修复错误的路径。
- **matched_easy** 情形如下。
  - 预期的接近打平**没有**出现：B−A 成功率 62.5000±5.3033，明显，5/5（A 33.5 %）。

- **coarse_path** 情形如下。
  - 路径标准差变为三倍时，B 从 96.0 % 降到 54.5 %，但预期的输给 A **没有**出现：B−A 成功率 17.5000±15.0000，明显，5 个种子中 1 个符号相反。
- **no_appearance** 情形（第一次运行后加入）如下。
  - 没有背景数时，A 看到的几何信息与 B 的下层相同。B−A 成功率为**接近打平、差距很小，在种子噪声之内**（−2.5000±4.3301，没有种子符号相反，5 个中 3 个相等），按均值 B 是较低的一方（96.0 % 对 98.5 %）。
  - B−A `err` 也是接近打平（2.8710±4.3003），尽管 5 个种子上 B 都离料箱更远；在没有什么需要抗干扰时，路径噪声就是分层的代价。
