本月每一课都以类似“success 67/100”的一行结束。在真实机械臂上，100 次试验需要成本：每次都要手动复位场景，一组 20 次的试验可能要一个小时。本课讲怎样从少量试验里得到可靠的估计：成功率有多不确定、怎样公平地比较两个策略、一次比较需要多少次试验，以及怎样把失败变成下一步要修的东西。这也是作品集项目里评审最先看的部分。

## 一个数字不够

n 次试验得到的成功率只是一个估计。它的 95 % 范围默认用 <strong>Wilson 区间</strong>：和教科书上的“p ± 1.96 √(p(1−p)/n)”不同，它不会超出 0..100 %，在 0 次或 n 次成功时也照样可用。程序用的是[第 1 课](/zh/month/month-6/behaviour-cloning)的走廊和策略：

<CodeSource path="examples/month-6/policy-evaluation/eval_report.py" />

```python
"""eval_report.py: how to measure a policy, on the behaviour-cloning corridor from lesson 1.

1. Success rates with Wilson 95 % intervals: what "67/100" and "8/10" can and cannot tell you.
2. How much a 10-trial evaluation of the same policy moves around between sessions.
3. A paired comparison: every policy runs from the same list of per-trial seeds (same start, same noise),
   so trials can be compared one by one, with McNemar's exact test on the trials where they disagree.
4. How many trials you need to tell two success rates apart.
5. A failure table: where and when the failures happen.
Standard library only; imports the corridor, expert and policies from ../behaviour-cloning/bc_reach.py.
"""
import math
import os
import random
import sys

sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'behaviour-cloning'))
import bc_reach  # noqa: E402

Z95, Z80 = 1.959964, 0.841621          # two-sided 95 % confidence; 80 % power


def wilson(k, n, z=Z95):
    p = k / n
    centre = (p + z * z / (2 * n)) / (1 + z * z / n)
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
    return centre - half, centre + half


def trials(policy, seeds):
    """One rollout per seed; each trial gets its own random generator, so its start and noise are fixed."""
    return [bc_reach.rollout(policy, random.Random(s)) for s in seeds]


def mcnemar_p(b, c):
    """Exact two-sided McNemar test: under 'no difference' each disagreement is a fair coin."""
    n = b + c
    if n == 0:
        return 1.0
    tail = sum(math.comb(n, k) for k in range(min(b, c) + 1)) / 2 ** n
    return min(1.0, 2 * tail)


def trials_needed(p1, p2):
    """Trials per policy for a two-sided 5 % test with 80 % power (normal approximation)."""
    pbar = (p1 + p2) / 2
    num = Z95 * math.sqrt(2 * pbar * (1 - pbar)) + Z80 * math.sqrt(p1 * (1 - p1) + p2 * (1 - p2))
    return math.ceil(num * num / (p1 - p2) ** 2)


def main():
    print('1. Success with a Wilson 95 % interval')
    for k, n in ((61, 100), (67, 100), (99, 100), (100, 100), (8, 10), (10, 10)):
        lo, hi = wilson(k, n)
        print(f'  {k:>3}/{n:<3}  {100 * k / n:5.1f} %   95 % interval {100 * lo:5.1f} .. {100 * hi:5.1f} %')

    demos = bc_reach.record_demos(80, random.Random(6))
    bc20 = bc_reach.nn_policy([f for f in demos if f[0] < 20])
    noisy = bc_reach.record_demos(20, random.Random(8), noise=bc_reach.NOISE)
    bc_noisy = bc_reach.nn_policy(noisy)

    print('\n2. BC on 20 demos, ten separate sessions of 10 trials each (different seeds per session)')
    scores = [sum(r[0] == 'success' for r in trials(bc20, range(100 * s, 100 * s + 10))) for s in range(10)]
    print('  successes out of 10: ' + ' '.join(str(v) for v in scores) + f'   (lowest {min(scores)}, highest {max(scores)})')

    print('\n3. Paired comparison over the same 100 trials (seeds 5000..5099)')
    seeds = range(5000, 5100)
    a = trials(bc20, seeds)
    b = trials(bc_noisy, seeds)
    sa, sb = [r[0] == 'success' for r in a], [r[0] == 'success' for r in b]
    both = sum(x and y for x, y in zip(sa, sb))
    only_a = sum(x and not y for x, y in zip(sa, sb))
    only_b = sum(y and not x for x, y in zip(sa, sb))
    neither = sum(not x and not y for x, y in zip(sa, sb))
    for label, s in (('BC, 20 demos', sa), ('BC, 20 noisy demos', sb)):
        lo, hi = wilson(sum(s), len(s))
        print(f'  {label:<20} {sum(s):>3}/100   95 % interval {100 * lo:5.1f} .. {100 * hi:5.1f} %')
    print(f'  both succeed {both}, only the first {only_a}, only the second {only_b}, both fail {neither}')
    print(f'  McNemar exact test on the {only_a + only_b} disagreements: p = {mcnemar_p(only_a, only_b):.2g}')

    print('\n4. Trials per policy to tell two success rates apart (5 % test, 80 % power)')
    for p1, p2 in ((0.67, 0.99), (0.60, 0.80), (0.80, 0.90), (0.90, 0.95)):
        print(f'  {100 * p1:.0f} % vs {100 * p2:.0f} %: {trials_needed(p1, p2):>4} trials each')

    print('\n5. Failures of BC on 20 demos in those 100 trials')
    fails = [r for r in a if r[0] != 'success']
    places = {}
    for result, steps, worst, p in fails:
        key = result if result != 'wall' else 'wall, ' + bc_reach.place(p)
        places.setdefault(key, []).append(steps)
    print(f'  {"failure":<18} {"count":>5} {"share":>7} {"mean step":>10}')
    for key in sorted(places, key=lambda k: -len(places[k])):
        v = places[key]
        print(f'  {key:<18} {len(v):>5} {100 * len(v) / len(fails):>6.0f}% {sum(v) / len(v):>10.1f}')


if __name__ == '__main__':
    main()
```

## 在同样的试验上比较

办法是让条件完全相同，逐次比较。模型里每次试验有自己的种子（种子 s 用 `random.Random(s)`），所以第 5000 次试验对每个策略都有同样的起点和同样的噪声。这比前几课更严格：前几课每次评估从一个共享种子开始，而两个策略一旦走的步数不同，共享的随机数流就会错开。在硬件上，同样的思路就是一份固定的起始位置（和物体摆放）清单，在测试前写好，每个策略按同样的顺序跑。

## 需要多少次试验

需要多少次试验取决于两个策略有多接近。程序用的是比较两个比例的标准公式，检验水平 5 %，发现真实差异的把握为 80 %：

以 80 % 对 90 % 为例逐步计算：合并成功率 p̄ = (0.80 + 0.90) / 2 = 0.85。第一项 z95 × √(2 p̄ (1 − p̄)) = 1.959964 × √0.255 = 0.9897；第二项 z80 × √(p1(1 − p1) + p2(1 − p2)) = 0.841621 × √(0.16 + 0.09) = 0.4208。两项之和 1.4105，平方得 1.9896，再除以差值的平方 0.10² = 0.01：198.96，向上取整为 199 次。

第 1 课 67 % 对 99 % 这样大的差别，约 20 次试验即可分辨。在一个已经不错的策略上提高 10 个百分点（80 % 到 90 %），每个策略需要大约 200 次试验，相当于数天的手动复位。两个实际结论：把精力放在大到能测出来的改动上；用配对试验，当两个策略在大多数试验上结果一致时，它需要的次数比这个非配对公式少。

## 给你的机械臂定一份评估规程

在测试之前写下来，而不是之后：

- <strong>成功标准</strong>，写成其他人无需了解实现也能照着执行的判定标准（“方块完全在盒子里、夹爪张开、30 s 以内”）。
- <strong>试验清单</strong>：起始位置和物体摆放，包括一些训练数据里没有的，每个策略按同样顺序跑。
- <strong>保持不变的东西</strong>：光照、相机位置、物体、机器人的起始姿态、每个策略的代码版本和检查点。
- <strong>要记录的东西</strong>：每次试验一段视频、结果、失败类别和用时。
- <strong>报告</strong>：成功次数/试验次数加 Wilson 区间；比较策略时给出配对表；以及失败表。


## 嵌套评估种子：合成抽样，不是真训练

这一节里的 K 个「训练种子」是 **synthetic policy draws**——脚本化的伯努利成功参数，命名为 `synthetic_policy_draw_k`。它们**不是**真实神经网络训练。把它们当成「我训练了五次、得到五个 checkpoint」的替身，这样不确定度的分层不必上 GPU 也能看清。

### 两张表，两层不确定度

- **`shared_IC`（配对）：** 每个 draw 面对**同一份**评估初始条件列表。成功率在试验层面上可对照（配对）。
- **`independent_IC`（非配对）：** 每个 draw 有**自己的** IC 列表。必须**另表**打印——不要把行合并。

不确定度分层要标注清楚、互不混写：

1. **单个 draw 内的计数区间：** Wilson 95 %（频率派）以及均匀先验 Beta(`1+k`, `1+n−k`) 的中心 95 % 区间（贝叶斯草图）。把多次试验拼成一个 pooled Wilson，只对**同一固定策略的独立评估会话**成立。**不要**把多个 `synthetic_policy_draw_k` × 共享 IC 当成独立 Bernoulli 试验丢进同一个 pooled Wilson——那些 draw 是不同策略。
2. **跨 draw 离散：** K 个点估计的 min / median / max。故意打印 **best-seed 樱桃采摘** 对 **median**：只报最好的一组，正是第 4 课已经警告过的反模式。

清单字段对齐 arXiv 2409.09491v2 §4 *Analysis and Reporting*（Kress-Gazit 等）：实验参数（成功判据、**次数**而非只有百分比、时段、初始条件及其与训练的关系）、统计分析、失败模式。

```python
#!/usr/bin/env python3
"""eval_seed_layers_toy.py: synthetic policy draws + nested eval seed layers (stdlib).

The K "train seeds" here are SYNTHETIC POLICY DRAWS (scripted Bernoulli success
parameters), NOT real neural-network training runs. Prints use the names
  synthetic_policy_draw_k
  shared_IC          (paired: the same evaluation IC list for every draw)
  independent_IC     (unpaired: each draw gets its own IC list)

Uncertainty layers (NEVER mixed into one unlabeled %):
  1. Count interval on one draw's trials: Wilson 95 % (frequentist) and a
     uniform-prior Beta(1+k, 1+n-k) central 95 % interval (Bayesian sketch).
  2. Across-draw dispersion: min / median / max of the K point rates, plus the
     cherry-picked best-seed rate vs the median (reporting the best alone is
     the anti-pattern).

Checklist fields reference arXiv 2409.09491v2 §4 "Analysis and Reporting"
(Kress-Gazit et al. — Robot Learning as an Empirical Science: Best
Practices for Policy Evaluation):
  §4.1 experiment parameters — semantic success criterion; counts not just %;
       timing of sessions; initial conditions and their relation to training;
  §4.2 statistical analysis — interval / Bayesian layer, separate from
       across-draw spread;
  §4.3 failure modes — categories + frequency (toy: one synthetic category).
usage: python3 eval_seed_layers_toy.py
"""
from __future__ import annotations

import math
import random

SEED = 64
K_DRAWS = 5                 # synthetic_policy_draw_0 .. _4
N_IC = 40                   # evaluation initial conditions per table
# Per-draw true success probabilities (scripted policies, not trained nets).
P_DRAWS = (0.55, 0.62, 0.70, 0.78, 0.66)
Z95 = 1.959964


def wilson(k: int, n: int, z: float = Z95) -> tuple[float, float]:
    p = k / n
    centre = (p + z * z / (2 * n)) / (1 + z * z / n)
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / (1 + z * z / n)
    return centre - half, centre + half


def beta_central_interval(k: int, n: int, alpha: float = 0.05) -> tuple[float, float]:
    """Central (1-alpha) interval from Beta(1+k, 1+n-k) via incomplete-beta inverse.

    Uniform prior Beta(1,1) + Bernoulli likelihood → Beta(1+k, 1+n-k).
    Quantiles by bisection on the regularised incomplete beta.
    """
    a = 1.0 + k
    b = 1.0 + (n - k)

    def betacf(x, aa, bb, max_iter=200):
        # Lentz continued fraction for incomplete beta (NR-style).
        tiny = 1e-30
        qab = aa + bb
        qap = aa + 1.0
        qam = aa - 1.0
        c = 1.0
        d = 1.0 - qab * x / qap
        if abs(d) < tiny:
            d = tiny
        d = 1.0 / d
        h = d
        for m in range(1, max_iter + 1):
            m2 = 2 * m
            aa_m = m * (bb - m) * x / ((qam + m2) * (aa + m2))
            d = 1.0 + aa_m * d
            if abs(d) < tiny:
                d = tiny
            c = 1.0 + aa_m / c
            if abs(c) < tiny:
                c = tiny
            d = 1.0 / d
            h *= d * c
            aa_m = -(aa + m) * (qab + m) * x / ((aa + m2) * (qap + m2))
            d = 1.0 + aa_m * d
            if abs(d) < tiny:
                d = tiny
            c = 1.0 + aa_m / c
            if abs(c) < tiny:
                c = tiny
            d = 1.0 / d
            delta = d * c
            h *= delta
            if abs(delta - 1.0) < 1e-10:
                break
        return h

    def betai(x, aa, bb):
        if x <= 0.0:
            return 0.0
        if x >= 1.0:
            return 1.0
        ln_beta = (math.lgamma(aa) + math.lgamma(bb) - math.lgamma(aa + bb))
        front = math.exp(aa * math.log(x) + bb * math.log(1.0 - x) - ln_beta)
        if x < (aa + 1.0) / (aa + bb + 2.0):
            return front * betacf(x, aa, bb) / aa
        return 1.0 - front * betacf(1.0 - x, bb, aa) / bb

    def quantile(p):
        lo, hi = 0.0, 1.0
        for _ in range(80):
            mid = 0.5 * (lo + hi)
            if betai(mid, a, b) < p:
                lo = mid
            else:
                hi = mid
        return 0.5 * (lo + hi)

    return quantile(alpha / 2), quantile(1.0 - alpha / 2)


def median(vals: list[float]) -> float:
    s = sorted(vals)
    n = len(s)
    if n % 2:
        return s[n // 2]
    return 0.5 * (s[n // 2 - 1] + s[n // 2])


def run_table(tag: str, ic_seeds_per_draw: list[list[int]], rng_master: random.Random) -> list[dict]:
    """Evaluate each synthetic draw on its IC list; return per-draw records."""
    rows = []
    print(f"== {tag} ==")
    print(f"{'draw':<26} {'k/n':>7} {'rate%':>7} {'Wilson95%':>18} {'Beta95%':>18}")
    for k, p_true in enumerate(P_DRAWS):
        seeds = ic_seeds_per_draw[k]
        # Independent RNG stream per (draw, IC) from the IC seed alone so a
        # shared IC list is genuinely paired across draws.
        successes = []

            # only through their scripted p_true threshold.
            u = random.Random(s).random()
            successes.append(1 if u < p_true else 0)
        kk = sum(successes)

        wlo, whi = wilson(kk, n)
        blo, bhi = beta_central_interval(kk, n)
        label = f"synthetic_policy_draw_{k}"
        print(f"{label:<26} {kk:>2}/{n:<2} {100 * rate:6.1f}%  "
              f"{100 * wlo:.1f}..{100 * whi:.1f}  {100 * blo:.1f}..{100 * bhi:.1f}")
        rows.append({"k": kk, "n": n, "rate": rate, "p_true": p_true,
                     "wilson": (wlo, whi), "beta": (blo, bhi)})
    rates = [r["rate"] for r in rows]
    best = max(rates)
    med = median(rates)
    print(f"across_draw_dispersion: min={100 * min(rates):.1f}%  "
          f"median={100 * med:.1f}%  max={100 * best:.1f}%  "

    return rows
```

## Set-of-Mark 与 Trace-of-Mark（Magma）

上面的规程在同样的试验上比较两个策略。本节把同样的习惯用在**输出接口**上，而不是策略上：模型应该直接写出一个连续坐标点，还是在图上画好的若干编号标记里选一个，再预测这个标记接下来往哪里走？面向多模态智能体的基础模型 Magma 用的是后一种。下面的 toy 是这个想法的**离散替身**。它**不是** Magma 的模型、数据或基准，**不是** UI 智能体，也**不是** HAMSTER 的二维路径、MolmoAct 的轨迹、TraceVLA 或 ThinkAct。

<Resource id="magma-paper" />

**实际打开的来源（已读 arXiv 摘要页、HTML 和 PDF 正文）。**

- **Yang 等，Magma: A Foundation Model for Multimodal AI Agents（arXiv 2502.13130 v1，13 位作者，2025 年 2 月 18 日提交），第 3.2 节**的内容如下。
  - **Set-of-Mark。** 先提出候选区域或点（例如用分割或检测模型），在上面叠加数字标记，模型输出标记而不是原始坐标。论文给出的理由是模型预测数字标记要容易得多（"faces much less difficulties to predict the numeric marks"）。
  - 坐标按图像尺寸归一化，再“量化为 256 个区间”（"quantized into 256 bins"，图 3 说明）。
  - **Trace-of-Mark。** 在视频上，模型预测标记未来的轨迹。论文说这迫使模型理解时间动态、在行动前“提前看”（"look ahead of time"），而且预测轨迹所用的 token 比预测下一帧少得多（"predicting traces uses much fewer tokens"）。轨迹用 CoTracker 点跟踪器提取，所以无标注视频也能提供监督。
  - 基准数字以论文为准。GPU、UI 或机器人运行**本页未运行**。

### 标记、轨迹与度量

记候选位置为 `p_k`，共享相关性分数为 `s_k`，目标的真实轨迹为 `p_target(τ)`：

<Formula label="直接输出组 A：回归器给出的单个点按 softmax 权重平均各候选">p_A = Σ_k softmax(s)_k · p_k + ε</Formula>

<Formula label="Set-of-Mark 组 B：选分数最高的标记，再读它量化后的位置">p_B = q(p_k*),  k* = argmax_k s_k,  q(u) = (⌊256 u⌋ + 0.5) / 256</Formula>

<Formula label="Trace-of-Mark：所选标记在 τ = 1 … L 上的轨迹，用跟踪得到的速度">p_B(τ) = p_B + (v_k* + η) · τ</Formula>

<Formula label="未来 L 步上的轨迹误差（打印时乘以 100）">ADE = (1 / L) · Σ_τ ‖p(τ) − p_target(τ)‖</Formula>

**算例。** toy 会打印分数完全无噪声时回归器给目标的权重。在 `cluttered` 中，`K 8` 时它是 `0.7416`：剩下的权重分给其余 `K − 1` 个候选，所以即使没有噪声，平均出来的点也被拉离目标，而 `RADIUS 0.05` 很小。目标在 `L` 步内还移动 `0.0800`，超过 `RADIUS`，所以停在起点的计划只能靠运气在第 `L` 步成功。在 `single_target` 中权重是 `1.0000`：A 唯一的误差是回归噪声 `SIG_REG 0.01`，B 唯一的误差是量化，每个轴最多 `0.001953`。在 `static_jitter` 中权重是 `0.9526`，目标在 `L` 步内移动 `0.0000`，但 B 跟踪到的速度带有每步 `SIG_TRK 0.012` 的误差，轨迹每走一步误差就更大。

**正确性判据。** 量化后的点在每个轴上与真实坐标的距离不能超过 `0.5 / BINS`；toy 打印这个上界（`0.001953`），测试文件在几个坐标上检查它，并在手工构造的两物体场景上检查 A、B、C。**没有积分步。** 每个位置都是闭式 `p + v · τ`，所以没有步长需要检验。

### 公平设置

`magma_som_tom_toy.py` 是**合成**模型，只用标准库。**模型假设**如下。
- 图像坐标在 `[0, 1]` 内，`K` 个候选位置均匀随机；物体 0 是指令中的目标；每个物体以该情形的速度、沿随机方向匀速运动。
- 共用一个信念：目标的分数是 `SIGNAL` 加高斯噪声，干扰物只有噪声，噪声标准差为 `SIG_B`。A 和 B 读同一组分数；两者都不是训练出来的网络。
- A 没有轨迹，所以它对未来每一步的计划都是那一个点。B 和 C 用同样的轨迹步骤；C 的数字标签画在错误的物体上（随机置换）。
- grounding 指当前的点落在目标 `RADIUS` 之内；成功指第 `L` 步的计划点落在目标那时位置的 `RADIUS` 之内。

| 组 | 输出 | 轨迹 |
|---|---|---|
| A_direct | 一个连续点，softmax 加权平均再加 `SIG_REG` 噪声 | 无（保持该点） |
| B_somtom | 分数最高的标记，量化到 `BINS` 个区间 | 标记速度加 `SIG_TRK` 噪声 |
| C_shuffle | 同样的选择，但标记画在错误的物体上 | 与 B 相同 |

**共用随机数**的做法是，对每个（情形，种子），每个场景的位置、速度、分数、回归噪声、跟踪噪声和置换都只抽一次，三组共用。5 个种子，每个 `SCENES 400` 个场景。

| 情形 | 候选数 | 目标速度 | 跟踪噪声 | 预期（首次运行前写下） |
|---|---|---|---|---|
| cluttered | K 8 | 每步 0.01 | 0.002 | B 在 grounding 和成功率上稳定胜过 A |
| single_target | K 1 | 静止 | 0 | A 与 B 在 grounding 和成功率上打平 |
| static_jitter | K 2 | 静止 | 0.012 | B 在成功率上与 A 打平或落败 |

预期在候选多于一个的每个情形中，C 在 grounding 上都输给 B。

**看过结果后做的选择。** 没有。首次运行后没有改动任何常数、组、指标或情形，下表就是首次运行的结果。本节的提案对“单个明显目标”预期接近打平；toy 则对 `single_target` 声明在 grounding 和成功率上打平，并加入 `static_jitter`，预期 B 在这里打平或落败。没有采用的做法（因此这里不出现它们的数字）：更大的 `RADIUS`，会让 A 的平均点更常被算作 grounding 成功；给 A 加速度估计，那就把它变成了轨迹模型。

```python
#!/usr/bin/env python3
"""Magma-style Set-of-Mark + Trace-of-Mark vs direct coordinate output vs shuffled marks, on shared scenes.

Synthetic, stdlib only.  Not Magma's model, data or benchmarks: a discrete stand-in for the two
ideas in the paper's section 3.2 (select a numbered mark instead of regressing a coordinate; then
predict the mark's future trace).  Not a UI agent, not HAMSTER's 2-D path, not MolmoAct traces,
not TraceVLA, not ThinkAct.  Magma benchmark numbers are 以论文为准; GPU, UI or robot runs:
本页未运行.

Scene (image coordinates normalised to [0, 1], as in the paper): K candidate objects at uniform
positions; object 0 is the instructed target.  Each object moves with a constant velocity per
step (speed set by the regime, random direction); its true trace is p + v * tau, tau = 1..L.
Shared belief: the same noisy relevance score per candidate, target SIGNAL + N(0, SIG_B),
distractors N(0, SIG_B); softmax weights w_k.
Arms (same scene, same scores):
  A_direct  outputs one continuous point: sum_k w_k p_k plus N(0, SIG_REG) per axis (a regressor
            averages its candidates); no trace, so its plan for every future step is that point
  B_somtom  selects the mark with the highest score; the point is that mark's position quantised
            to BINS bins per axis (the paper quantises coordinates into 256 bins); then predicts
            the mark's trace with a tracked velocity v + N(0, SIG_TRK) per axis
  C_shuffle same selection and trace step as B, but the numeric labels are drawn on the wrong
            objects (a uniform random permutation; with K = 1 it can only be the identity)
Metrics per seed (SCENES scenes): grounding % (point within RADIUS of the target now), trace ADE
(mean distance to the target's true trace over L steps, x 100), success % (planned point at step
L within RADIUS of the target then).  No integration step: positions are closed form per step.
Common random numbers: per (regime, seed), the positions, velocities, scores, regression noise,
tracking noise and permutations are drawn once per scene and used by all three arms.
Regimes and expectations, written before the first run:
  cluttered      K 8, speed 0.01 per step, SIG_TRK 0.002   B consistent win over A on grounding
                                                            and success
  single_target  K 1, static, SIG_TRK 0                      A and B tie on grounding and success
  static_jitter  K 2, static, SIG_TRK 0.012                 B ties or loses to A on success (the
                                                            trace adds error to a static target)
  C loses to B on grounding in every regime with K > 1.
"""
import math
import random

SEEDS = (0, 1, 2, 3, 4)
SCENES = 400
L = 8              # trace length (steps)
RADIUS = 0.05
BINS = 256
SIGNAL, SIG_B = 3.0, 1.0
SIG_REG = 0.01
NUM_ZERO = 1e-9
ARMS = ("A_direct", "B_somtom", "C_shuffle")
# name: (K, speed per step, SIG_TRK); written before the first run
REGIMES = {
    "cluttered": (8, 0.01, 0.002),
    "single_target": (1, 0.0, 0.0),
    "static_jitter": (2, 0.0, 0.012),
}
STREAM = {"cluttered": 0, "single_target": 1, "static_jitter": 2}


def quantise(u):
    k = min(BINS - 1, max(0, int(u * BINS)))
    return (k + 0.5) / BINS


def shared_draws(regime, seed):
    rng = random.Random(1000 * STREAM[regime] + seed)
    k, speed, sig_trk = REGIMES[regime]
    scenes = []
    for _ in range(SCENES):
        pos = [(rng.uniform(0.05, 0.95), rng.uniform(0.05, 0.95)) for _ in range(k)]
        vel = []
        for _ in range(k):
            th = rng.uniform(0.0, 2.0 * math.pi)
            vel.append((speed * math.cos(th), speed * math.sin(th)))
        score = [(SIGNAL if i == 0 else 0.0) + rng.gauss(0.0, SIG_B) for i in range(k)]
        reg = (rng.gauss(0.0, SIG_REG), rng.gauss(0.0, SIG_REG))
        trk = (rng.gauss(0.0, sig_trk), rng.gauss(0.0, sig_trk)) if sig_trk > 0 else (0.0, 0.0)
        perm = list(range(k))
        rng.shuffle(perm)
        scenes.append((pos, vel, score, reg, trk, perm))
    return scenes


def plan(arm, scene):
    pos, vel, score, reg, trk, perm = scene
    if arm == "A_direct":
        mx = max(score)
        w = [math.exp(s - mx) for s in score]
        tot = sum(w)
        px = sum(wi * p[0] for wi, p in zip(w, pos)) / tot + reg[0]
        py = sum(wi * p[1] for wi, p in zip(w, pos)) / tot + reg[1]
        return [(px, py)] * (L + 1)
    sel = max(range(len(score)), key=lambda i: score[i])
    obj = perm[sel] if arm == "C_shuffle" else sel
    p = (quantise(pos[obj][0]), quantise(pos[obj][1]))
    v = (vel[obj][0] + trk[0], vel[obj][1] + trk[1])
    return [(p[0] + v[0] * t, p[1] + v[1] * t) for t in range(L + 1)]


def evaluate(arm, scenes):
    g = s = ade = 0.0
    for sc in scenes:
        pos, vel = sc[0], sc[1]
        tr = [(pos[0][0] + vel[0][0] * t, pos[0][1] + vel[0][1] * t) for t in range(L + 1)]
        pl = plan(arm, sc)
        g += math.dist(pl[0], tr[0]) <= RADIUS
        s += math.dist(pl[L], tr[L]) <= RADIUS
        ade += sum(math.dist(pl[t], tr[t]) for t in range(1, L + 1)) / L
    n = len(scenes)
    return {"ground": 100.0 * g / n, "ade": 100.0 * ade / n, "success": 100.0 * s / n}


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"
```

## 常见错误

- <strong>只报告最好的一组。</strong>如果你对**同一固定策略**跑了三组**独立评估会话**，就报告全部三组或它们的总和（这时 pooled Wilson 才有意义）。挑最好的一组，就是 40 % 变成 90 % 的方式。**不要**把多个 synthetic draw × 共享 IC 当成同一策略的 i.i.d. Bernoulli 去拼一个 pooled Wilson。
- <strong>事后才定成功标准。</strong>同一个接近成功的结果在一组算成功、下一组算失败，数字就没有意义了。
- <strong>只在训练过的地方测试。</strong>加入数据集里没有的起始位置并单独报告；策略之间的差别多半就出在那里。
- <strong>把区间重叠当成打平，或把区间分开当成证明。</strong>区间只是快速检查；两个策略在同样试验上比较时，用配对比较。
- <strong>在两个策略之间改了场景。</strong>在两个策略的测试之间挪了相机或盒子，你的比较就变成了比较场景。
- **把合成抽样叫作「训练好的策略」。** 它们是脚本化的伯努利替身。报告里要写明。
- **把 shared_IC 与 independent_IC 合并成一张表。** 配对与非配对回答不同问题；分表。
- **把 Wilson/Beta 与跨 draw 的 min/max 混成一个未标注的 %。** 计数不确定度与种子离散是不同层。
- **把多个 draw × 共享 IC 拼进一个 Wilson。** 不同的 `synthetic_policy_draw_k` 是不同策略；pooled 计数区间只留给同一固定策略的重复评估。
- **只报最好的合成种子。** 要报 median（以及全集）。樱桃采摘会把 70 % 写成 85 %。
