Lesson 7.2 trained a clipped-ratio policy on a 1-D reach. Manipulation adds a gripper and an object: the state must say where the arm is **and** whether the jaws are closed; the action must move in space **and** open or close; the reward must care about reaching, approaching, grasping and lifting — or the learner never sees a success. This lesson names those pieces, contrasts sparse and dense shaping on a discrete reach–grasp grid, and points at ManiSkill3 / SB3 SAC as the GPU and off-policy counterparts you may run on your own machine.

## From reach to grasp

- **State.** Joint angles, end-effector pose, and object pose (or a compact encoding of them). The toy below bins planar position plus a binary grip bit.
- **Action.** Joint increments, or an end-effector Δxyz plus a grip command. The toy uses five discrete moves: N, S, E, W, CLOSE.
- **Reward shaping.** Arrival / approach / grasp / lift can each add a term. A **sparse** reward gives +1 only on success; a **dense** reward also pays for getting closer and for closing on the goal cell.
- **Success criterion.** Here: the agent occupies the goal cell with grip = 1. In ManiSkill3's `PickCubeSO100-v1` the task card is "pick up a red cube with the SO100 robot and move it to a goal position" (table-top gripper index; max episode length 50).

On-policy methods such as PPO update from data collected by the **current** policy. Off-policy methods such as <Term id="sac">SAC</Term> (Haarnoja et al., arXiv 1801.01290) reuse a replay buffer — Soft Actor-Critic is listed in Stable-Baselines3 as "Off-Policy Maximum Entropy Deep Reinforcement Learning with a Stochastic Actor." One sentence of contrast is enough for this page: when samples are expensive, off-policy reuse helps; when you already have thousands of parallel envs, on-policy PPO is often enough.

## Sparse vs dense on a grid

The runnable deliverable is tabular Q-learning under identical hyperparameters, seed 7, 400 episodes, a 6×6 grid, goal cell (4, 3). Sparse gets +1 only on success; dense gets a Manhattan distance penalty, a grip bonus on the goal cell, and +5 on success. Under that seed the last-50 success rate is **0.000 for sparse** and **1.000 for dense**, and a greedy rollout of the dense Q-table succeeds 20/20 starts.

```python
#!/usr/bin/env python3
"""Sparse vs dense reward shaping on a discrete reach–grasp MDP (stdlib).

Lesson 7.2 used a clipped-ratio PPO toy for a 1-D reach. Here the task adds a
gripper channel: reach a cube, then close. We compare **sparse** (terminal +1)
vs **dense** (distance + grip shaping) under identical tabular Q-learning so the
success gap is seed-stable on CPU.

ManiSkill3 ``PickCubeSO100-v1`` / SB3 SAC are the GPU / off-policy counterparts
described in the MDX — this file does not import them (「本页未强制」).

State bins: x∈[0,1], y∈[0,1], grip∈{0,1}  →  N x N x 2
Actions: 5 moves {N,S,E,W,CLOSE}
Success: cell contains the goal and grip==1
"""
from __future__ import annotations

import random
from typing import Literal

SEED = 7
N = 6
GOAL = (4, 3)  # grid cell
EPISODES = 400
MAX_STEPS = 30
ALPHA = 0.35
GAMMA = 0.95
EPS_START = 0.5
EPS_END = 0.05

Action = Literal[0, 1, 2, 3, 4]  # N S E W CLOSE
N_ACTIONS = 5


def idx(x: int, y: int, g: int) -> int:
    return (g * N + y) * N + x


def clip_cell(v: int) -> int:
    return max(0, min(N - 1, v))


def step(x: int, y: int, g: int, a: int, dense: bool):
    nx, ny, ng = x, y, g
    if a == 0:
        ny = clip_cell(y - 1)
    elif a == 1:
        ny = clip_cell(y + 1)
    elif a == 2:
        nx = clip_cell(x + 1)
    elif a == 3:
        nx = clip_cell(x - 1)
    elif a == 4:
        ng = 1
    success = (nx, ny) == GOAL and ng == 1
    if dense:
        # Manhattan distance penalty + grip bonus on goal cell + terminal
        d = abs(nx - GOAL[0]) + abs(ny - GOAL[1])
        r = -0.1 * d
        if (nx, ny) == GOAL:
            r += 0.5 * ng
        if success:
            r += 5.0
    else:
        r = 1.0 if success else 0.0
    return nx, ny, ng, r, success


def train(dense: bool, seed: int = SEED):
    rng = random.Random(seed)
    q = [[0.0] * N_ACTIONS for _ in range(N * N * 2)]
    successes: list[int] = []
    returns: list[float] = []
    for ep in range(EPISODES):
        x = rng.randint(0, 1)
        y = rng.randint(0, 1)
        g = 0
        ep_ret = 0.0
        ok = False
        eps = EPS_START + (EPS_END - EPS_START) * (ep / max(1, EPISODES - 1))
        for _ in range(MAX_STEPS):
            s = idx(x, y, g)
            if rng.random() < eps:
                a = rng.randrange(N_ACTIONS)
            else:
                row = q[s]
                m = max(row)
                # tie-break deterministically by lowest index among maxima
                cands = [i for i, v in enumerate(row) if v == m]
                a = cands[0]
            nx, ny, ng, r, success = step(x, y, g, a, dense=dense)
            ns = idx(nx, ny, ng)
            best_next = max(q[ns])
            q[s][a] = (1 - ALPHA) * q[s][a] + ALPHA * (r + GAMMA * best_next)
            ep_ret += r
            x, y, g = nx, ny, ng
            if success:
                ok = True
                break
        successes.append(1 if ok else 0)
        returns.append(ep_ret)
    window = 50
    last_s = successes[-window:]
    last_r = returns[-window:]
    return {
        "mean_return": sum(last_r) / window,
        "success_rate": sum(last_s) / window,
        "last_ok": sum(last_s),
        "q": q,
    }


def greedy_rollout(q, seed: int = 99) -> bool:
    rng = random.Random(seed)
    x = rng.randint(0, 1)
    y = rng.randint(0, 1)
    g = 0
    for _ in range(MAX_STEPS):
        s = idx(x, y, g)
        row = q[s]
        m = max(row)
        a = min(i for i, v in enumerate(row) if v == m)
        x, y, g, _, success = step(x, y, g, a, dense=True)
        if success:
            return True
    return False


def main() -> None:
    sparse = train(dense=False)
    dense = train(dense=True)
    print("reward_shaping — tabular Q, sparse vs dense (seed=%d, episodes=%d, grid=%dx%d)"
          % (SEED, EPISODES, N, N))
    print("goal_cell=%s  actions=N,S,E,W,CLOSE" % (GOAL,))
    print("mode    mean_return  success_rate  last%d_ok" % 50)
    print("sparse  %11.4f  %12.3f  %9d" % (sparse["mean_return"], sparse["success_rate"], sparse["last_ok"]))
    print("dense   %11.4f  %12.3f  %9d" % (dense["mean_return"], dense["success_rate"], dense["last_ok"]))
    # evaluate greedy policy from dense Q on a few starts
    greeds = sum(1 for s in range(20) if greedy_rollout(dense["q"], seed=100 + s))
    print("dense_greedy_ok %d/20" % greeds)
    assert dense["success_rate"] > sparse["success_rate"], (
        "dense should beat sparse on success (%.3f vs %.3f)"
        % (dense["success_rate"], sparse["success_rate"])
    )
    assert dense["success_rate"] >= 0.5, "dense success_rate too low: %.3f" % dense["success_rate"]
    assert greeds >= 10, "dense greedy rollouts too weak: %d/20" % greeds
    print("ok: dense shaped reward outperforms sparse under identical Q-learning")


if __name__ == "__main__":
    main()
```

## Common mistakes

- **Leaving the reward sparse with almost no exploration.** The table shows 400 episodes are not enough for sparse to discover CLOSE-on-goal by chance.
- **Forgetting the grip channel in the state.** A reach-only state cannot represent "I am on the cube but still open."
- **Reporting only the dense curve.** Always print sparse next to dense under the same seed and hyperparameters.
- **Assuming ManiSkill GPU sim runs on every laptop.** The install matrix is Linux + NVIDIA for GPU sim; CPU sim is the broader path.

## Hindsight Experience Replay: learn from the goal you did reach

The grid toy above showed sparse tabular Q-learning failing where dense shaping succeeds. Shaping is one fix, but it means writing a reward that already knows the way. **Hindsight Experience Replay** (HER) keeps the sparse success reward and changes the replay instead. An episode that missed its goal still reached *some* place; HER replays it as if that place had been the goal, so the learner sees successes long before it ever reaches the real goal. This section adds HER to the same grid MDP in a **synthetic** tabular model. It is not SB3, ManiSkill or DDPG.

<Resource id="her-andrychowicz-2017" />

**Source actually opened (PDF body read, arXiv 1707.01495 v3).**

- **Andrychowicz et al., "Hindsight Experience Replay" (OpenAI):**
  - The method learns from rewards that are sparse and binary, combines with any off-policy algorithm, and "may be seen as a form of implicit curriculum".
  - The goal "influences the agent's actions but not the environment dynamics", so each trajectory can be replayed with an arbitrary goal when the algorithm is off-policy. The simplest version replays with the goal achieved in the final state.
  - Strategies `final`, `future` (k states observed later in the same episode), `episode` and `random`; `future` with `k` equal to 4 or 8 performs best, and `k` above 8 degrades performance because too little normal replay data is left.
  - In the bit-flipping task, DQN without HER solves only `n ≤ 13`, while DQN with HER solves `n` up to 50.
  - §4.4: with the shaped rewards they tried, neither DDPG nor DDPG+HER solved any task. The paper adds that for every problem a reward exists that makes it easy, but designing it requires a lot of domain knowledge.
  - The paper's reward is `−[f_g(s) = 0]`, that is −1 until success. 以论文为准.

### Relabelling with achieved goals

<Formula label="Sparse goal reward (this toy)">r(s′, g) = 1 if cell(s′) = g and grip(s′) = 1, else 0</Formula>

<Formula label="future relabel">g′ = cell(s_j), with j drawn from the same episode at or after the replayed step, used with probability k / (k + 1)</Formula>

<Formula label="Q-learning backup">Q(s, g, a) ← Q(s, g, a) + α · (r + γ · max Q(s′, g, ·) − Q(s, g, a))</Formula>

A goal counts as achieved only with the gripper closed, so a step `j` with `grip = 0` leaves the original goal in place. With `k = 4` the relabel share is 4 / 5 = 0.80. The paper adds `k` extra goals per transition; this toy draws one goal per replayed sample with the same 4 : 1 ratio.

**Worked example.** An episode starts at (0, 0) with goal (4, 3). The agent closes the gripper at step 3 and wanders until step 30, ending at (3, 1). Under the sparse reward every transition earns 0. Relabelled with `g′ = (3, 1)`, the last transition, from (2, 1) eastwards, now earns 1 and ends the episode. In the goal-relative table used here, that update lands on the entry "offset (−1, 0), gripper closed, action E". That is exactly the entry the agent needs when it is one cell west of (4, 3) with the gripper closed.

**No integration step here.** The environment is a discrete grid; nothing is stepped in continuous time, so no step-size stability criterion applies (the independent tests check that the script has no time step). The learning rate `α = 0.35` and `γ = 0.95` keep every Q value bounded by the largest return, at most 1 for the sparse reward.

### Fair setup

`her_sparse_grasp_toy.py` is **synthetic** and stdlib only. **Model assumptions:**
- The MDP is `reward_shaping.py`'s, made goal-conditioned. The state is (x, y, grip) on an N × N grid; the actions are N, S, E, W and CLOSE; CLOSE sets `grip = 1` for good. Success means the gripper is closed on the goal cell, within 30 steps.
- Q is a table indexed by the goal-relative offset `(x − gx, y − gy, grip)`. It stands in for the paper's goal-conditioned network: what is learned for one goal carries over to every goal at the same offset.
- Every arm learns **only from replay**: after each episode, 64 transitions are drawn uniformly from all stored episodes and backed up. The settings are `α = 0.35` and `γ = 0.95`, ε falls linearly from 0.5 to 0.05, and greedy ties go to the lowest action index.

| Arm | Reward | Replay |
|---|---|---|
| A_sparse | 1 on success, else 0 | plain |
| B_her | the same sparse reward | `future`, k = 4 |
| C_dense | `reward_shaping.py`'s dense reward: −0.1 × Manhattan distance, +0.5 with the gripper closed on the goal, +5 on success | plain |

**Common random numbers:** for each (regime, seed) the start cell and goal of every episode, and both exploration draws of every (episode, step), are drawn once and shared by all three arms. The replay stream starts from the same seed in every arm, but it is consumed differently because the buffers differ. There are 5 seeds.

The metrics are:
- `final`: greedy success over every (start, goal) pair of the regime after the last episode.
- `auc`: mean greedy success over checkpoints every 50 episodes (sample efficiency).
- `train`: success over the last 50 training episodes.

| Regime | Grid | Episodes | Goals |
|---|---|---|---|
| near_goal | 6 × 6 | 400 | 9 cells with x, y ≤ 2 |
| fixed_goal | 6 × 6 | 400 | `reward_shaping.py`'s goal (4, 3) only |
| far_goals | 6 × 6 | 400 | 15 cells with x + y ≥ 6 |
| big_grid | 10 × 10 | 400 | 28 cells with x + y ≥ 12 |

Starts are the four cells (0, 0), (0, 1), (1, 0) and (1, 1) in every regime.

**Choices made after seeing results.** These were not in the first design; the toy prints each alternative so you can see what changed.
- **The goal-relative table.** The first run indexed the table by `(goal, cell, grip)`. A table like that learns nothing about a goal it has never reached, so HER barely helped: final 0.9333 against sparse 0.7556 in `near_goal`, and 0.0000 for both sparse arms in `fixed_goal`. The paper's networks generalise across goals, and the goal-relative table is the closest tabular stand-in. Both tables are printed.
- **A dropped `wall` regime.** The first run also had a regime with five wall cells, where every arm stayed near zero (final A 0.0000, B 0.0000, C 0.0250). It was dropped because a goal-relative table cannot see where a wall is.
- **`big_grid`.** It was added after the first run to find where HER stops helping. An 8 × 8 version (goals with x + y ≥ 9) was tried first; it is printed too (final A 0.0000, B 0.4643, C 0.9571).
- **Other settings tried and not adopted.** With the first table, 256 updates per episode and 1 000 episodes were also tried; HER stayed far below dense on `far_goals` (final 0.333 against 1.000).

```python
#!/usr/bin/env python3
"""Synthetic Hindsight Experience Replay toy on the reach-grasp grid. Stdlib only.

The MDP is the one in reward_shaping.py, made goal-conditioned: state (x, y, grip) on an
N x N grid, actions N, S, E, W, CLOSE (CLOSE sets grip = 1 and it stays closed); the goal g
is a cell, and the episode succeeds when the gripper is closed on g. The predicate
f_g(s) = [cell(s) == g and grip(s) == 1]; the achieved goal of a state with grip = 1 is its
cell (states with grip = 0 achieve no goal).

Q is a table indexed by the goal-relative offset (x - gx, y - gy) and grip, a stand-in for the
goal-conditioned network of the paper: what is learned about one goal carries over to every
goal at the same offset. This representation was chosen after the first run, which indexed
the table by (goal, cell, grip); that run is printed as an alternative.

Arms (identical representation, hyperparameters and replay budget):
  A_sparse  reward 1 on success, 0 otherwise; replay without relabelling
  B_her     the same sparse reward; replay with the "future" strategy (Andrychowicz et al.):
            with probability K / (K + 1) a sampled transition is replayed with a goal achieved
            later in the same episode, its reward and termination recomputed for that goal
  C_dense   reward_shaping.py's dense reward (-0.1 Manhattan distance, +0.5 grip on the goal
            cell, +5 on success); replay without relabelling

Every arm learns only from replay: after each episode, UPDATES transitions are sampled
uniformly from all stored episodes and backed up with Q-learning (ALPHA, GAMMA).
Common random numbers: per (regime, seed) the start cell and goal of every episode and the
two exploration draws of every (episode, step) are drawn once and shared by all arms; the
replay-sampling stream is seeded identically per arm but is consumed differently because the
buffers differ. No integration step: the environment is a discrete grid.
Regimes: near_goal (goals within 2 cells), fixed_goal (reward_shaping.py's single goal (4, 3)),
far_goals (x + y >= 6 on 6 x 6), big_grid (x + y >= 12 on 10 x 10; added after the first run,
the 8 x 8 version tried before it is printed as an alternative).
Metrics per seed: final = greedy success over every (start, goal) pair of the regime after
the last episode; auc = mean greedy success over the checkpoints every EVAL_EVERY episodes
(sample efficiency); train = success share over the last 50 training episodes.
Labels: tie = identical on every seed; numerically zero = |paired mean| and sd both < 1e-9
(effectively a tie, no sign count); |m| <= sd = near-tie; |m| > sd = consistent gap (small if
|m| < 20 % of the smaller arm mean, else clear), with a sign count.
ManiSkill3 / SB3 HER / DDPG / a GPU: 本页未运行. Paper results: 以原文为准.
"""
import math
import random

SEEDS = (0, 1, 2, 3, 4)
N_ACTIONS = 5  # N S E W CLOSE
ALPHA = 0.35
GAMMA = 0.95
EPS_START, EPS_END = 0.5, 0.05
MAX_STEPS = 30
UPDATES = 64
K_FUTURE = 4
EVAL_EVERY = 50
NUM_ZERO = 1e-9
ARMS = ("A_sparse", "B_her", "C_dense")
# name: (grid N, episodes, start cells, goal cells)
REGIMES = {
    "near_goal": (6, 400, [(0, 0), (0, 1), (1, 0), (1, 1)], [(x, y) for x in range(3) for y in range(3)]),
    "fixed_goal": (6, 400, [(0, 0), (0, 1), (1, 0), (1, 1)], [(4, 3)]),
    "far_goals": (6, 400, [(0, 0), (0, 1), (1, 0), (1, 1)], [(x, y) for x in range(6) for y in range(6) if x + y >= 6]),
    "big_grid": (10, 400, [(0, 0), (0, 1), (1, 0), (1, 1)], [(x, y) for x in range(10) for y in range(10) if x + y >= 12]),
}
# big_grid was added after the first run; the 8 x 8 version tried before it is printed as an alternative
ALT_BIG = (8, 400, [(0, 0), (0, 1), (1, 0), (1, 1)], [(x, y) for x in range(8) for y in range(8) if x + y >= 9])
REPR = "relative"  # Q indexed by the goal-relative offset (chosen after the first run; ALT_REPR printed)
ALT_REPR = "absolute"  # Q indexed by (goal, cell, grip): the first run's table


def key(goal, cell, grip, repr_=REPR):
    if repr_ == "relative":
        return (cell[0] - goal[0], cell[1] - goal[1], grip)
    return (goal, cell, grip)


def step(n, cell, grip, a, goal, dense):
    x, y = cell
    nx, ny, ng = x, y, grip
    if a == 0:
        ny = max(0, y - 1)
    elif a == 1:
        ny = min(n - 1, y + 1)
    elif a == 2:
        nx = min(n - 1, x + 1)
    elif a == 3:
        nx = max(0, x - 1)
    else:
        ng = 1
    return (nx, ny), ng, reward((nx, ny), ng, goal, dense)


def reward(cell, grip, goal, dense):
    """Reward and termination of arriving in (cell, grip) when pursuing goal."""
    success = cell == goal and grip == 1
    if not dense:
        return (1.0 if success else 0.0), success
    r = -0.1 * (abs(cell[0] - goal[0]) + abs(cell[1] - goal[1]))
    if cell == goal:
        r += 0.5 * grip
    if success:
        r += 5.0
    return r, success


def shared_draws(regime, seed):
    """Common random numbers: episode (start, goal) and exploration draws, shared by every arm."""
    n, episodes, starts, goals = REGIMES[regime] if regime in REGIMES else ALT_BIG
    rng = random.Random(f"{regime}-{seed}")
    eps = [(rng.choice(starts), rng.choice(goals)) for _ in range(episodes)]
    explore = [[(rng.random(), rng.randrange(N_ACTIONS)) for _ in range(MAX_STEPS)] for _ in range(episodes)]
    return eps, explore


def greedy(row):
    m = max(row)
    return row.index(m)


def evaluate(q, regime, repr_=REPR):
    n, _, starts, goals = REGIMES[regime] if regime in REGIMES else ALT_BIG
    ok = 0
    for s0 in starts:
        for g in goals:
            cell, grip = s0, 0
            for _ in range(MAX_STEPS):
                a = greedy(q[key(g, cell, grip, repr_)])
                cell, grip, (_, done) = step(n, cell, grip, a, g, False)
                if done:
                    ok += 1
                    break
    return ok / (len(starts) * len(goals))


def train(arm, regime, seed, k_future=K_FUTURE, repr_=REPR):
    n, episodes, starts, goals = REGIMES[regime] if regime in REGIMES else ALT_BIG
    cells = [(x, y) for x in range(n) for y in range(n)]
    q = {key(g, c, gr, repr_): [0.0] * N_ACTIONS for g in cells for c in cells for gr in (0, 1)}
    eps_draws, explore = shared_draws(regime, seed)
    replay_rng = random.Random(f"replay-{regime}-{seed}")
    dense = arm == "C_dense"
    her = arm == "B_her"
    buffer, curve, train_ok = [], [], []
    for ep in range(episodes):
        start, goal = eps_draws[ep]
        eps = EPS_START + (EPS_END - EPS_START) * ep / max(1, episodes - 1)
        cell, grip, traj, ok = start, 0, [], False
        for t in range(MAX_STEPS):
            u, ra = explore[ep][t]
            a = ra if u < eps else greedy(q[key(goal, cell, grip, repr_)])
            ncell, ngrip, (_, done) = step(n, cell, grip, a, goal, dense)
            traj.append((cell, grip, a, ncell, ngrip))
            cell, grip = ncell, ngrip
            if done:
                ok = True
                break
        train_ok.append(ok)
        buffer.append((goal, traj))
        for _ in range(UPDATES):
            g, tr = buffer[replay_rng.randrange(len(buffer))]
            i = replay_rng.randrange(len(tr))
            c, gr, a, nc, ngr = tr[i]
            if her and replay_rng.random() < k_future / (k_future + 1.0):
                j = replay_rng.randrange(i, len(tr))
                if tr[j][4] == 1:  # a goal is achieved only with the gripper closed
                    g = tr[j][3]
            r, done = reward(nc, ngr, g, dense)
            target = r if done else r + GAMMA * max(q[key(g, nc, ngr, repr_)])
            row = q[key(g, c, gr, repr_)]
            row[a] += ALPHA * (target - row[a])
        if (ep + 1) % EVAL_EVERY == 0:
            curve.append(evaluate(q, regime, repr_))
    return {"final": curve[-1], "auc": sum(curve) / len(curve), "train": sum(train_ok[-50:]) / 50.0}


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"
```

### Read the regimes

How the labels are used on this page, in this order: **tie: identical on every seed** only when the paired per-seed difference is exactly zero on every seed; **numerically zero (floating-point residue), effectively a tie** when `|paired mean|` and its sd are both below 1e-9 (no sign count is printed on such a line); **near-tie / small gap, within seed noise** when `|paired mean| ≤ sd`; otherwise a **consistent** gap (`|paired mean| > sd`), called **small** if `|m|` is under 20 % of the smaller arm mean and **clear** otherwise; the 20 % rule only chooses between those two words. Every consistent line carries a same-sign count over the 5 seeds, and any seed with the opposite sign is reported; a sign count alone never makes a gap consistent. Gaps are computed from unrounded values. Paired differences are B−A, B−C and C−A.

- **near_goal:** random exploration already closes the gripper near these goals, so every arm ends at 1.0000. The final scores are a **tie: identical on every seed**, and the learning-curve area is a **near-tie** (B−A 0.0021±0.0031, no seed of the opposite sign, 3 of 5 equal; B−C 0.0014±0.0040, 1 of 5 seeds of the opposite sign). HER adds nothing measurable here.
- **fixed_goal:** this is `reward_shaping.py`'s goal. **Sparse stays at 0.0000** on every seed, as in that script, while HER and dense both reach 1.0000. **HER wins against sparse** (B−A final and auc 1.0000±0.0000, clear, same sign on all 5 seeds) and **ties dense** (B−C identical on every seed).
- **far_goals:** sparse learns on some seeds and not on others (final 0.3967±0.5432). **HER wins against sparse** on the curve: B−A auc 0.5846±0.4715, clear, same sign on all 5 seeds. The final score is clear as well (0.5967±0.5523), but 1 of 5 seeds has the opposite sign and 1 of 5 is equal, so read it with care. Against dense, HER is a **near-tie** on both final (−0.0067±0.0091) and auc (−0.0096±0.0146).
- **big_grid:** **HER loses.** Exploration from the corner almost never closes the gripper 10 or more cells away, so there is nothing to relabel at those offsets: A and B both stay at 0.0000 (a tie on every seed). Dense shaping still points the way: B−C final −0.4321±0.2232 and auc −0.1083±0.0606, clear, same sign on all 5 seeds.

The page **does not declare a universal winner**. HER turns failed episodes into useful ones when the goals it achieves are near the goals you want and the learner can carry what it learns across goals. A dense reward that already knows the way can match or beat it, which is not what the paper found with its shaped rewards (§4.4): this toy's dense reward is `reward_shaping.py`'s hand-made one on a tiny grid.
