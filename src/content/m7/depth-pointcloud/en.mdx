Month 5's camera calibration turned a pixel into a ray. A depth value along that ray turns the ray into a 3-D point. A whole depth image becomes a <Term id="point-cloud">point cloud</Term>. This lesson back-projects a synthetic RGB-D desk with three boxes, <Term id="voxel-downsampling">voxel-downsamples</Term> it, removes the desk with <Term id="ransac">RANSAC</Term>, clusters the rest with DBSCAN, and reads the centroids — then names the matching Open3D calls and three ways to get depth in the first place.

## Back-projection

With intrinsics `fx`, `fy`, `cx`, `cy` and depth `Z` at pixel `(u, v)`:

`X = ((u − cx) / fx) · Z`, `Y = ((v − cy) / fy) · Z`

Month 5 already estimated those intrinsics. Here the toy uses `fx = fy = 120` on a 160 × 120 image so the whole pipeline stays under a second on CPU.

## Three sources of depth

1. **A depth camera** (stereo or structured light), e.g. RealSense, with the ROS 2 package `realsense-ros`. Hardware beyond the default SO-101 kit — optional.
2. **Monocular depth networks**, e.g. Depth Anything V2. Small weights are Apache-2.0; Base / Large / Giant are CC-BY-NC-4.0 (non-commercial). Default outputs are **relative** depth; metric models exist on Small / Base, or you calibrate a scale yourself.
3. **A simulation camera** from lesson 7.1's MuJoCo scene (not run in this page's expected output).

Relative depth is enough to segment "closer than the desk"; a grasp pose in metres needs metric depth.

## Desk, three boxes, one pipeline

`cloud_pipeline.py` synthesises a desk at Z = 0.40 m and three axis-aligned boxes, then runs:

1. back-project every pixel → raw cloud  
2. voxel down-sample at 1 cm (Open3D: `voxel_down_sample`)  
3. RANSAC plane fit and remove inliers (Open3D: `segment_plane(distance_threshold, ransac_n, num_iterations)`)  
4. DBSCAN on the rest (Open3D: `cluster_dbscan`) → centroids  

Open3D's RGB-D path starts from `RGBDImage.create_from_color_and_depth`; this toy skips the colour image and builds depth directly so the expected table needs no Open3D install.

```python
#!/usr/bin/env python3
"""cloud_pipeline.py: synthetic RGB-D desk with 3 boxes → back-project → voxel → RANSAC plane → DBSCAN.

Pure standard library (no Open3D / NumPy). Fixed geometry so the centroid table is reproducible.
The lesson maps each step onto the matching Open3D call (voxel_down_sample, segment_plane,
cluster_dbscan, RGBDImage.create_from_color_and_depth).
usage: python3 cloud_pipeline.py
"""
from __future__ import annotations

import math
import random

# Pinhole camera (matches a typical 640x480 depth camera intrinsics, scaled down for speed)
W, H = 160, 120
FX = FY = 120.0
CX, CY = (W - 1) / 2.0, (H - 1) / 2.0
# Desk plane z = 0.40 m in camera frame (camera looks along +z, y down, x right — OpenCV-style)
DESK_Z = 0.40
# Three axis-aligned boxes on the desk: (cx, cy, z_top, sx, sy, sz) in metres
BOXES = (
    (0.00, 0.02, 0.40 - 0.04, 0.06, 0.05, 0.04),   # centre box, 4 cm tall
    (-0.12, -0.05, 0.40 - 0.03, 0.05, 0.04, 0.03), # left
    (0.14, 0.06, 0.40 - 0.05, 0.04, 0.06, 0.05),   # right, taller
)
VOXEL = 0.01          # 1 cm voxels
RANSAC_THRESH = 0.008 # 8 mm
RANSAC_ITERS = 80
DBSCAN_EPS = 0.025
DBSCAN_MIN = 8
SEED = 0


def depth_at(u: int, v: int) -> float:
    """Ray through pixel (u,v): X = (u-cx)/fx * Z, Y = (v-cy)/fy * Z. Closest hit wins."""
    # desk hit
    z_desk = DESK_Z
    x_desk = (u - CX) / FX * z_desk
    y_desk = (v - CY) / FY * z_desk
    best = z_desk
    # boxes: for each, if ray hits the top face (constant z = z_top) within xy footprint
    for cx, cy, z_top, sx, sy, sz in BOXES:
        # hit top face at z_top
        x = (u - CX) / FX * z_top
        y = (v - CY) / FY * z_top
        if abs(x - cx) <= sx / 2 and abs(y - cy) <= sy / 2:
            if z_top < best:
                best = z_top
    return best


def backproject(depth: list[list[float]]) -> list[tuple[float, float, float]]:
    pts = []
    for v in range(H):
        for u in range(W):
            z = depth[v][u]
            if z <= 0:
                continue
            x = (u - CX) / FX * z
            y = (v - CY) / FY * z
            pts.append((x, y, z))
    return pts


def voxel_down(pts: list[tuple[float, float, float]], voxel: float) -> list[tuple[float, float, float]]:
    buckets: dict[tuple[int, int, int], list[tuple[float, float, float]]] = {}
    inv = 1.0 / voxel
    for p in pts:
        key = (math.floor(p[0] * inv), math.floor(p[1] * inv), math.floor(p[2] * inv))
        buckets.setdefault(key, []).append(p)
    out = []
    for group in buckets.values():
        n = len(group)
        out.append((sum(p[0] for p in group) / n, sum(p[1] for p in group) / n, sum(p[2] for p in group) / n))
    return out


def fit_plane(p1, p2, p3):
    # normal from cross product
    ax, ay, az = p2[0] - p1[0], p2[1] - p1[1], p2[2] - p1[2]
    bx, by, bz = p3[0] - p1[0], p3[1] - p1[1], p3[2] - p1[2]
    nx = ay * bz - az * by
    ny = az * bx - ax * bz
    nz = ax * by - ay * bx
    norm = math.sqrt(nx * nx + ny * ny + nz * nz)
    if norm < 1e-12:
        return None
    nx, ny, nz = nx / norm, ny / norm, nz / norm
    d = -(nx * p1[0] + ny * p1[1] + nz * p1[2])
    return nx, ny, nz, d


def segment_plane(pts, thresh=RANSAC_THRESH, iters=RANSAC_ITERS, rng=None):
    rng = rng or random.Random(SEED)
    best_inliers = []
    best_model = None
    n = len(pts)
    if n < 3:
        return best_model, best_inliers
    for _ in range(iters):
        i, j, k = rng.sample(range(n), 3)
        model = fit_plane(pts[i], pts[j], pts[k])
        if model is None:
            continue
        nx, ny, nz, d = model
        inliers = [p for p in pts if abs(nx * p[0] + ny * p[1] + nz * p[2] + d) < thresh]
        if len(inliers) > len(best_inliers):
            best_inliers = inliers
            best_model = model
    return best_model, best_inliers


def dbscan(pts, eps=DBSCAN_EPS, min_pts=DBSCAN_MIN):
    n = len(pts)
    labels = [-1] * n  # -1 unvisited, -2 noise, >=0 cluster
    cluster_id = 0

    def neighbours(i):
        return [j for j in range(n) if (pts[i][0] - pts[j][0]) ** 2 + (pts[i][1] - pts[j][1]) ** 2 + (pts[i][2] - pts[j][2]) ** 2 <= eps * eps]

    for i in range(n):
        if labels[i] != -1:
            continue
        nbrs = neighbours(i)
        if len(nbrs) < min_pts:
            labels[i] = -2
            continue
        labels[i] = cluster_id
        seed = [j for j in nbrs if j != i]
        k = 0
        while k < len(seed):
            j = seed[k]
            if labels[j] == -2:
                labels[j] = cluster_id
            if labels[j] == -1:
                labels[j] = cluster_id
                jnbrs = neighbours(j)
                if len(jnbrs) >= min_pts:
                    for q in jnbrs:
                        if q not in seed:
                            seed.append(q)
            k += 1
        cluster_id += 1
    return labels, cluster_id


def centroid(pts):
    n = len(pts)
    return (sum(p[0] for p in pts) / n, sum(p[1] for p in pts) / n, sum(p[2] for p in pts) / n)


def main() -> None:
    depth = [[depth_at(u, v) for u in range(W)] for v in range(H)]
    raw = backproject(depth)
    down = voxel_down(raw, VOXEL)
    model, inliers = segment_plane(down, rng=random.Random(SEED))
    inlier_set = set(id(p) for p in inliers)
    rest = [p for p in down if id(p) not in inlier_set]
    # also drop by distance in case of float identity issues
    if model is not None:
        nx, ny, nz, d = model
        rest = [p for p in down if abs(nx * p[0] + ny * p[1] + nz * p[2] + d) >= RANSAC_THRESH]
    labels, ncl = dbscan(rest)
    print(f"image {W}x{H}  fx=fy={FX:.0f}  desk_z={DESK_Z}")
    print(f"raw_points {len(raw)}  after_voxel_{VOXEL*100:.0f}cm {len(down)}")
    print(f"plane_inliers {len(inliers)}  remaining {len(rest)}  clusters {ncl}")
    print("cluster  n_points  centroid_x  centroid_y  centroid_z")
    clusters = []
    for cid in range(ncl):
        members = [rest[i] for i, lab in enumerate(labels) if lab == cid]
        if not members:
            continue
        c = centroid(members)
        clusters.append((len(members), c))
    # sort by x so the table order is stable
    clusters.sort(key=lambda t: t[1][0])
    for i, (n, c) in enumerate(clusters):
        print(f"{i:7d}  {n:8d}  {c[0]:10.4f}  {c[1]:10.4f}  {c[2]:10.4f}")
    # ground-truth box centres (top-face centres) for the lesson
    print("true_box_centres (x, y, z_top):")
    for cx, cy, z_top, sx, sy, sz in sorted(BOXES, key=lambda b: b[0]):
        print(f"  ({cx:+.2f}, {cy:+.2f}, {z_top:.2f})")


if __name__ == "__main__":
    main()
```

## What to change when it breaks

- **Voxel too large** merges two boxes into one cluster; too small leaves RANSAC and DBSCAN with tens of thousands of points and a slow, noisy plane.
- **RANSAC threshold too tight** leaves desk points in the "objects" set; too loose eats the bottoms of short boxes.
- **DBSCAN `eps` too small** shatters one box into many clusters; too large glues neighbouring boxes together.

## Common mistakes

- **Treating Depth Anything V2's default output as metres.** It is relative unless you use a metric checkpoint or fit a scale.
- **Using Base/Large/Giant weights in a commercial project.** Those checkpoints are CC-BY-NC-4.0; Small is Apache-2.0.
- **Skipping voxel down-sampling before RANSAC.** The raw cloud is an image's worth of points; the plane fit becomes slow and biased toward dense regions.
- **Forgetting that centroids are in the camera frame.** Lesson 7.6 multiplies by the hand-eye transform before MoveIt sees a base-frame grasp.

## 3DGS literacy: from a radiance map to declared collision geometry

A Gaussian splat stores a mean, covariance, colour and opacity; unlike NeRF's implicit neural density, these parameters expose ellipsoidal geometry. **Gaussians are not hard surfaces**: their tails extend indefinitely, opacity is a rendering parameter, and a missing splat does not establish physical free space. Our synthetic exercise retains opacity at least `0.5` and truncates each Gaussian at `k_sigma = 2.0`. The solid is the set with Mahalanobis distance squared at most 4. With raw covariance C, its shape matrix is `Sigma = 4 C`; semi-axes are twice the raw standard deviations. This is a declared modelling convention, not a calibrated occupancy probability or confidence guarantee. No opacity multiplication of radii is hidden in the code.

To connect this convention to [Splat-Nav v2, Sec. IV Eq. (2)](https://arxiv.org/html/2403.02751v2): the paper thresholds squared Mahalanobis distance by `χ²₃(γ)` and absorbs that factor into the covariance/shape matrix; our convention uses `k_sigma²`, so equal geometry requires `k_sigma² = χ²₃(γ)`. For an ideal normalized 3-D Gaussian, `k_sigma = 2` encloses about **73.85 %**, not the 1-D two-sigma **95.45 %** or the paper’s `γ = 0.99` (**99 %**, `k_sigma ≈ 3.37`). Sec. VI-C2 also uses `χ²₃(γ) = 4` in simulation comparisons — choices and claims **以论文为准**. Thus the geometric kσ cutoff can be parameterized as a Mahalanobis confidence ellipsoid under an ideal Gaussian model, but this lesson does **not** assign calibrated probabilistic confidence to learned splat geometry or physical occupancy. The separate opacity filter `0.5` is not `γ`.

There are three retained, axis-aligned obstacles and a sphere robot of radius **0.12 m**. Both arms receive the same **2004** robot-centre queries (seed **75**, including hand-selected collision, free, corner and tangent cases); neither gets privileged geometry. This is collision-checking literacy, **not another occupancy A*** planner. AABB means a continuous enclosing box, not a grid resolution trick.

### Check the K(s) direction before implementing

[Splat-Nav v1](https://arxiv.org/html/2403.02751v1), Theorem 1, states that two ellipsoids are **disjoint if and only if there exists** `s` strictly between 0 and 1 with `K(s) > 1`. With `d = mu_b - mu_a`, the shape matrices already include the chosen bounds:

```text
K(s) = d^T [Sigma_a/(1-s) + Sigma_b/s]^-1 d
Sigma_a = diag(a_x^2, a_y^2, a_z^2); Sigma_b = radius^2 I
```

Do not reverse the predicate: a large K is a **separation witness**, not a collision flag. Touching counts as collision. Our arm samples `s = 1/16, ..., 15/16` and reports collision unless at least one witness exceeds `1 + 1e-10`. Proof of conservative finite sampling, matching the paper's Corollary 1: sampled maxima cannot exceed the maximum over the whole interval; any sampled witness really exists. Missing the true maximiser can only reject a free query, never certify an intersecting pair as free **in exact arithmetic**. For a union, all obstacle pairs must have witnesses before declaring the robot free. The tolerance biases toward collision but does not make Python floating point interval-certified safety software.

A simple unit check is two unit spheres separated by distance d: at `s=0.5`, `K=d^2/4`. Thus d=3 is separated, d=2 touches, d=1 overlaps. Trace these before looking at the random scene. The theorem's displayed `>1` and Corollary 1 determine our direction, not the nearby paper sentence mentioning “negativeness”.

### Independent truth, conservative box and measured trade-off

Truth does **not** reuse the finite-s arm. For each query centre outside an ellipsoid, minimise Euclidean distance to the solid. The closest point has coordinates `y_i = a_i^2 d_i/(a_i^2 + lambda)`. Solve `sum((y_i/a_i)^2)=1` for non-negative lambda with a monotone bracket and **100 bisections**; an interior centre has distance zero. A sphere collides when this distance is at most its radius (plus `1e-12` numerical tolerance). This is an independent numerical solution of the exact distance problem, not a mesh or physical sensor truth; analytic centre/axis/sphere/tangent cases are asserted. It is not a rigorous error-bounded real-arithmetic oracle.

The AABB arm uses exact sphere-to-box distance. Every ellipsoid is contained in its AABB, so collision with the ellipsoid implies collision with its box: **false-safe should be 0**; box corners can cause false alarms. The sampled ellipsoid arm uses the same shapes and sphere. Both visit all three obstacles without early exits.

- false-safe = predicted free on a truth-collision query / **108** truth-collision queries.
- false-alarm = predicted collision on a truth-free query / **1896** truth-free queries.
- query cost = deterministic axis-kernel evaluations per query, **9** for AABB vs **135** for 15-sample ellipsoids. Kernels perform different operations; these are workload units, **not wall-clock latency or Hz**.

Measured here: AABB **0/108** false-safe and **81/1896** false-alarm; ellipsoids **0/108** and **0/1896**. Zero sampled false alarms on this set does not mean finite sampling is exact in general. The tighter shape costs more arithmetic in this implementation; no universal speed ranking follows. Rendering fidelity is not collision recall, and neither metric validates an unobserved real obstacle.

```python
#!/usr/bin/env python3
"""Thresholded synthetic Gaussians; CPU sphere collision literacy, not a planner.
Splat-Nav v1 Theorem 1 / Corollaries 1,3: separation iff some K(s)>1.
Finite samples certify only witnessed separation (conservative in exact arithmetic).
Ground truth is independent Euclidean point-to-solid-ellipsoid distance, solved
by a monotone Lagrange-multiplier root with 100 bisections; not K(s) sampling.
Splat-Nav v2 Sec. IV Eq. (2) uses D^2 <= chi2_3(gamma) for raw covariance C,
then absorbs that quantile into the shape matrix. Our k-sigma convention uses
D^2 <= k^2, shape = k^2 C; matching thresholds means k^2 = chi2_3(gamma).
For an ideal normalized 3-D Gaussian, k=2 encloses about 73.85 %, NOT the 1-D
95.45 % or the paper's gamma=0.99 (k about 3.37). Sec. VI-C2 also studies
chi2_3(gamma)=4; choices/claims are 以论文为准. Here k=2 is a geometric cutoff,
not calibrated occupancy confidence; opacity_min is a separate filter, not gamma.
Floating-point arithmetic here is NOT interval-certified safety software.
"""
from __future__ import annotations

import math
import random

SEED = 75
K_SIGMA = 2.0
OPACITY_MIN = 0.5
RADIUS = 0.12  # m, sphere robot
# mean[m], raw Gaussian standard deviations[m], opacity; axis-aligned for stdlib.
GAUSSIANS = (
    ((-0.65, 0.0, 0.0), (0.34, 0.10, 0.18), 0.9),
    ((0.55, 0.2, 0.15), (0.12, 0.35, 0.16), 0.8),
    ((0.0, -0.7, -0.1), (0.24, 0.15, 0.10), 0.7),
    ((0.0, 0.0, 0.0), (0.5, 0.5, 0.5), 0.2),  # excluded, not physical free-space proof
)
SCENE = tuple((mu, tuple(K_SIGMA * v for v in sigma))
              for mu, sigma, opacity in GAUSSIANS if opacity >= OPACITY_MIN)
SAMPLES = tuple(i / 16 for i in range(1, 16))


def distance_to_ellipsoid(d, axes):
    """Distance from point d to solid ellipsoid, not distance to its AABB.
    Outside: closest y_i=a_i^2*d_i/(a_i^2+lambda), sum(y_i/a_i)^2=1.
    The latter strictly decreases in lambda>=0, so bracket + bisection applies.
    """
    if sum((x / a) ** 2 for x, a in zip(d, axes)) <= 1:
        return 0.0
    def residual(lam):
        return sum((a * x / (a * a + lam)) ** 2
                   for x, a in zip(d, axes)) - 1
    lo, hi = 0.0, 1.0
    while residual(hi) > 0:
        hi *= 2
    for _ in range(100):
        mid = (lo + hi) / 2
        if residual(mid) > 0:
            lo = mid
        else:
            hi = mid
    y = tuple(a * a * x / (a * a + hi) for x, a in zip(d, axes))
    return math.sqrt(sum((x - z) ** 2 for x, z in zip(d, y)))


def truth(point):
    return any(distance_to_ellipsoid(tuple(x - c for x, c in zip(point, mu)), axes)
               <= RADIUS + 1e-12 for mu, axes in SCENE)


def aabb_collision(point):
    # Each ellipsoid lies in its enclosing AABB. Sphere-box distance is exact.
    hits = []
    for mu, axes in SCENE:
        dist2 = sum(max(abs(x - c) - a, 0.0) ** 2
                    for x, c, a in zip(point, mu, axes))
        hits.append(dist2 <= RADIUS ** 2 + 1e-12)
    # No early exits: both arms visit every obstacle on every query.
    return any(hits), len(SCENE) * 3  # axis-kernel evaluations


def sampled_collision(point, samples=SAMPLES):
    hits = []
    for mu, axes in SCENE:
        d = tuple(x - c for x, c in zip(point, mu))
        # Sa=diag(axes^2), Sb=radius^2 I; direct Theorem1 convention.
        values = [sum(x * x / (a * a / (1 - s) + RADIUS ** 2 / s)
                      for x, a in zip(d, axes)) for s in samples]
        # A witness >1 certifies DISJOINT; no witness means possible collision.
        hits.append(not any(v > 1.0 + 1e-10 for v in values))
    return any(hits), len(SCENE) * len(samples) * 3


def self_test():
    axes = (1.0, 0.5, 0.25)
    assert distance_to_ellipsoid((0, 0, 0), axes) == 0
    assert abs(distance_to_ellipsoid((1.2, 0, 0), axes) - 0.2) < 1e-12
    assert abs(distance_to_ellipsoid((0, 0, 0.45), axes) - 0.2) < 1e-12
    assert abs(distance_to_ellipsoid((2, 0, 0), (1, 1, 1)) - 1) < 1e-12
    assert sampled_collision(SCENE[0][0])[0]
    assert not sampled_collision((5, 5, 5))[0]
    # Near tangency is collision under the lesson's tolerance.
    mu, a = SCENE[0]
    tangent = (mu[0] - a[0] - RADIUS, mu[1], mu[2])
    assert truth(tangent) and aabb_collision(tangent)[0] and sampled_collision(tangent)[0]


def main():
    self_test()
    rng = random.Random(SEED)
    points = [tuple(rng.uniform(-1.5, 1.5) for _ in range(3)) for _ in range(2000)]
    # Include known collision, enclosing-box corner, free and tangent queries.
    points += [SCENE[0][0], (-1.30, 0.19, 0.35), (5, 5, 5),
               (-0.65 - 0.68 - RADIUS, 0, 0)]
    actual = [truth(p) for p in points]
    positives, negatives = sum(actual), len(actual) - sum(actual)
    print(f"seed={SEED} k_sigma={K_SIGMA:.1f} opacity_min={OPACITY_MIN:.1f} "
          f"obstacles={len(SCENE)} robot_radius_m={RADIUS:.2f}")
    print(f"shared_queries={len(points)} truth_collision={positives} truth_free={negatives}")
    print("truth=independent_distance_root_100_bisections; touching=collision")
    print("arm false_safe/count_truth_collision false_alarm/count_truth_free axis_kernel_evals/query")
    rows = []
    for name, checker in (("aabb", aabb_collision), ("ellipsoid_s15", sampled_collision)):
        results = [checker(p) for p in points]
        fs = sum(t and not hit for t, (hit, _) in zip(actual, results))
        fa = sum(not t and hit for t, (hit, _) in zip(actual, results))
        cost = sum(c for _, c in results) / len(points)
        print(f"{name} {fs}/{positives}={fs/positives:.6f} "
              f"{fa}/{negatives}={fa/negatives:.6f} {cost:.0f}")
        assert fs == 0
        rows.append(fa)
    assert rows[0] > rows[1]  # measured on this declared scene, not universal ranking
    print("cost=axis_kernel_evaluations_not_wallclock; kernels_have_different_operations")
    print("finite_s: witness_K_gt_1=separate; no_witness=collision; exact_arithmetic_conservative")
    print("float_not_certified; Gaussian_threshold_not_physical_surface; GPU_not_run")


if __name__ == "__main__":
    main()
```

## Surface normals by local PCA

The pipeline above fits one desk plane and clusters what is left; it never asks which way the surface faces at each point. Grasp approach directions, point-to-plane registration and many shape features need exactly that: a **normal per point**. This section estimates them. It is **not** another voxel / RANSAC pass, and it is **not** the point-to-plane ICP from the SLAM lesson; it produces the normals those methods consume.

- **PCL tutorial — Estimating Surface Normals in a PointCloud:** the normal at a point is approximated by the normal of a least-squares tangent plane, which reduces to an eigen-analysis (PCA) of the covariance matrix of the point's nearest neighbours. The sign is ambiguous and not consistently oriented over a cloud; with a known viewpoint, flip each normal so that it points toward the viewpoint (`flipNormalTowardsViewpoint`; default viewpoint `(0, 0, 0)`), and with several acquisition viewpoints that simple rule no longer holds. On scale: a too-large `k` or radius pulls in points from adjacent surfaces, rotates normals at edges and suppresses fine detail, so the scale has to match the level of detail needed. `computePointNormal` also returns a curvature estimate from the eigenvalues. The page's equations are rendered as images, so only its prose is quoted here. Numbers 以原文为准.
- **Open3D tutorial — Point cloud (release docs):** `estimate_normals` finds adjacent points and takes the principal axis by covariance analysis, with `KDTreeSearchParamHybrid(radius = 0.1, max_nn = 30)` in the example; covariance analysis gives two opposite candidates (the "normal orientation problem"); Open3D aligns with an existing normal if there is one and otherwise guesses, and `orient_normals_to_align_with_direction` / `orient_normals_towards_camera_location` exist for when orientation matters. Numbers 以原文为准.

### The estimator

For a query point `p`:

1. take its `k` nearest neighbours (the query included);
2. compute their centroid `c` and covariance `C = (1/k) Σ (pᵢ − c)(pᵢ − c)ᵀ`;
3. eigen-decompose the 3 × 3 `C` (the toy uses a cyclic Jacobi solver, stdlib only) and take the eigenvector of the **smallest** eigenvalue as the normal;
4. orient it: if `n · (vp − p) < 0`, replace `n` by `−n`.

Why the smallest one: on a plane the points spread widely in the two in-plane directions and only by noise across it, so the direction of least variance is the plane normal. Two errors compete. Depth noise tilts the fitted plane, and more neighbours average it down. Curvature bends the neighbourhood, and more neighbours see more of the bend. At 5 mm grid spacing the neighbourhood radius is roughly `spacing × √(k/π)`: about 5.6 mm for `k = 4` and 12.6 mm for `k = 20`.

### Fair setup

`pointcloud_pca_normals_toy.py` is **synthetic** and stdlib only. **Model assumptions:** a camera at the origin looking along `+z`; the surface is a height field `z = 0.40 m − A sin(2πx/Λ) sin(2πy/Λ)` on a 41 × 41 grid with 5 mm spacing (each `x, y` jittered by ±1.25 mm); depth noise is Gaussian along `z` only (a stand-in for noise along the ray); no outliers, no missing pixels, one viewpoint. The true normal of `z = f(x, y)` is `(f_x, f_y, −1)` normalised, which already faces the camera. Truth comes from this formula, not from any arm.

| Arm | Normal at each query |
|---|---|
| A_global_plane | no per-point normals: one PCA plane fitted to the whole cloud |
| B_pca_k20 | local PCA with `k = 20` |
| C_pca_k4 | local PCA with `k = 4` (a deliberately small neighbourhood) |

Every arm's normal is oriented toward the viewpoint `(0, 0, 0)` before scoring. **Common random numbers:** for each (regime, seed) the grid jitter, every point's depth-noise draw and the 60 interior query points are drawn once; all arms see the same noisy cloud and the same queries. Five seeds. Metrics per seed, reported as mean±sd over seeds: the mean angle between the oriented normal and the true normal (deg); and a **local plane residual**, the RMS distance of the query's 12 nearest noisy points (one evaluation neighbourhood shared by all arms) to the plane through their centroid with the arm's normal (mm). The toy also counts how many raw PCA normals had to be flipped. Pairs are labelled with the same rule as in the manipulability toy of Month 5: **tie** only if identical on every seed, **near-tie / small gap, within seed noise** if the mean paired difference is no larger than its sd, **small but consistent gap, not a tie** if larger but under 20 % of the smaller arm's mean, otherwise **clear gap**. The residual still **rewards fitting the noise**, and it favours the arm whose neighbourhood looks like the evaluation neighbourhood; the angle metric is **blind** to run time, multi-view orientation and outliers.

Regimes: **flat_low_noise** (`A = 0`, noise sd 0.3 mm); **ripple_noisy** (`A = 8 mm`, `Λ = 100 mm`, noise sd 2 mm; radius of curvature at the crests `1/(A (2π/Λ)²) ≈ 31.7 mm`); **fine_ripple_low_noise** (`A = 4 mm`, `Λ = 40 mm`, noise sd 0.1 mm; crest radius ≈ 10.1 mm).

```python
#!/usr/bin/env python3
"""Synthetic PCA normal estimation on a depth-camera height field. Stdlib only.

Model (stated in the lesson prose too): camera at the origin looking along +z; the
surface is a height field z = 0.40 m - A sin(2 pi x / LAM) sin(2 pi y / LAM) on a
41 x 41 grid with 5 mm spacing (x, y jittered by +-1.25 mm); depth noise is
Gaussian along z only (a stand-in for noise along the ray); no outliers, no
missing pixels, one viewpoint. True normal of z = f(x, y): (f_x, f_y, -1)
normalised, which already faces the camera.

Arms (each gives a unit normal at every query point):
  A_global_plane  no per-point normals: one PCA plane fitted to the whole cloud
  B_pca_k20       local PCA: covariance of the k = 20 nearest neighbours (query
                  included), eigenvector of the smallest eigenvalue
  C_pca_k4        the same with k = 4
Every normal is then flipped toward the viewpoint (0, 0, 0): if n . (vp - p) < 0,
n = -n. Raw PCA signs are arbitrary (the eigen-solver returns either sign).

Common random numbers: per (regime, seed) the grid jitter, the depth-noise draw of
every point and the 60 interior query points are drawn once; all arms see the same
noisy cloud and the same queries.
Metrics per seed: mean angle to the true normal after orientation (deg); local
plane residual = RMS distance of the query's 12 nearest noisy points (a fixed
evaluation neighbourhood shared by all arms) to the plane through their centroid
with the arm's normal (mm). The residual still rewards fitting the noise; the
angle metric is blind to run time, to multi-view orientation and to outliers.
No presumed winner. Open3D / PCL on a real sensor: 本页未运行.
"""
from __future__ import annotations

import math
import random

Z0 = 0.40  # m, desk depth
N_GRID = 41
SPACING = 0.005  # m
QUERIES = 60
K_EVAL = 12
SEEDS = (0, 1, 2, 3, 4)
ARMS = ("A_global_plane", "B_pca_k20", "C_pca_k4")
K_OF = {"B_pca_k20": 20, "C_pca_k4": 4}
# regime, amplitude A (m), wavelength LAM (m), depth-noise sd (m)
REGIMES = (("flat_low_noise", 0.0, 0.10, 0.0003), ("ripple_noisy", 0.008, 0.10, 0.002),
           ("fine_ripple_low_noise", 0.004, 0.04, 0.0001))


def height(a: float, lam: float, x: float, y: float) -> tuple[float, float, float]:
    k = 2 * math.pi / lam
    z = Z0 - a * math.sin(k * x) * math.sin(k * y)
    return z, -a * k * math.cos(k * x) * math.sin(k * y), -a * k * math.sin(k * x) * math.cos(k * y)


def unit(v: tuple[float, float, float]) -> tuple[float, float, float]:
    n = math.sqrt(sum(c * c for c in v))
    return (v[0] / n, v[1] / n, v[2] / n)


def covariance(pts: list[tuple[float, float, float]]) -> tuple[list[list[float]], tuple[float, float, float]]:
    n = len(pts)
    c = tuple(sum(p[i] for p in pts) / n for i in range(3))
    m = [[sum((p[i] - c[i]) * (p[j] - c[j]) for p in pts) / n for j in range(3)] for i in range(3)]
    return m, c


def jacobi_eig(m: list[list[float]]) -> tuple[list[float], list[list[float]]]:
    """Cyclic Jacobi for a symmetric 3x3 matrix: eigenvalues and eigenvectors (columns)."""
    a = [row[:] for row in m]
    v = [[1.0 if i == j else 0.0 for j in range(3)] for i in range(3)]
    for _ in range(50):
        off = a[0][1] ** 2 + a[0][2] ** 2 + a[1][2] ** 2
        if off < 1e-30:
            break
        for p, q in ((0, 1), (0, 2), (1, 2)):
            if abs(a[p][q]) < 1e-300:
                continue
            theta = (a[q][q] - a[p][p]) / (2 * a[p][q])
            t = math.copysign(1.0, theta) / (abs(theta) + math.sqrt(theta * theta + 1))
            c = 1 / math.sqrt(t * t + 1)
            s = t * c
            for k in range(3):  # A <- A G
                akp, akq = a[k][p], a[k][q]
                a[k][p], a[k][q] = c * akp - s * akq, s * akp + c * akq
            for k in range(3):  # A <- G^T A
                apk, aqk = a[p][k], a[q][k]
                a[p][k], a[q][k] = c * apk - s * aqk, s * apk + c * aqk
            for k in range(3):
                vkp, vkq = v[k][p], v[k][q]
                v[k][p], v[k][q] = c * vkp - s * vkq, s * vkp + c * vkq
    return [a[i][i] for i in range(3)], v


def pca_normal(pts: list[tuple[float, float, float]]) -> tuple[float, float, float]:
    """Eigenvector of the smallest covariance eigenvalue, with whatever sign Jacobi returns."""
    m, _ = covariance(pts)
    vals, vecs = jacobi_eig(m)
    i = min(range(3), key=lambda j: vals[j])
    return unit((vecs[0][i], vecs[1][i], vecs[2][i]))


def orient(n: tuple[float, float, float], p: tuple[float, float, float]) -> tuple[tuple[float, float, float], bool]:
    """Flip n toward the viewpoint at the origin; report whether it was flipped."""
    if -(n[0] * p[0] + n[1] * p[1] + n[2] * p[2]) < 0:
        return (-n[0], -n[1], -n[2]), True
    return n, False


def knn(cloud: list[tuple[float, float, float]], p: tuple[float, float, float], k: int) -> list[tuple[float, float, float]]:
    return sorted(cloud, key=lambda c: (c[0] - p[0]) ** 2 + (c[1] - p[1]) ** 2 + (c[2] - p[2]) ** 2)[:k]


def shared_scene(regime: str, a: float, lam: float, sd: float, seed: int):
    rng = random.Random(f"{regime}:{seed}")
    half = (N_GRID - 1) / 2
    cloud, truth = [], []
    for i in range(N_GRID):
        for j in range(N_GRID):
            x = (i - half) * SPACING + rng.uniform(-SPACING / 4, SPACING / 4)
            y = (j - half) * SPACING + rng.uniform(-SPACING / 4, SPACING / 4)
            z, fx, fy = height(a, lam, x, y)
            cloud.append((x, y, z + rng.gauss(0.0, sd)))
            truth.append(unit((fx, fy, -1.0)))
    interior = [i * N_GRID + j for i in range(5, N_GRID - 5) for j in range(5, N_GRID - 5)]
    return cloud, truth, rng.sample(interior, QUERIES)


def angle_deg(n: tuple[float, float, float], t: tuple[float, float, float]) -> float:
    return math.degrees(math.acos(max(-1.0, min(1.0, n[0] * t[0] + n[1] * t[1] + n[2] * t[2]))))


def evaluate(regime: str, a: float, lam: float, sd: float, seed: int) -> dict:
    cloud, truth, queries = shared_scene(regime, a, lam, sd, seed)
    g = pca_normal(cloud)
    out = {arm: {"ang": 0.0, "res": 0.0, "flip": 0} for arm in ARMS}
    for qi in queries:
        p = cloud[qi]
        ev = knn(cloud, p, K_EVAL)
        _, c = covariance(ev)
        for arm in ARMS:
            raw = g if arm == "A_global_plane" else pca_normal(knn(cloud, p, K_OF[arm]))
            n, flipped = orient(raw, p)
            r2 = sum(((e[0] - c[0]) * n[0] + (e[1] - c[1]) * n[1] + (e[2] - c[2]) * n[2]) ** 2 for e in ev) / len(ev)
            out[arm]["ang"] += angle_deg(n, truth[qi]) / QUERIES
            out[arm]["res"] += math.sqrt(r2) * 1e3 / QUERIES
            out[arm]["flip"] += flipped
    return out


def ms(xs: list[float]) -> tuple[float, float]:
    m = sum(xs) / len(xs)
    return m, math.sqrt(sum((x - m) ** 2 for x in xs) / (len(xs) - 1))


def sign_note(diffs: list[float], m: float) -> str:
    """How many seeds disagree in sign with the paired mean (zeros listed apart)."""
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa: list[float], xb: list[float], unit: str = "") -> str:
    """tie: identical on every seed; near-tie: |paired mean| <= paired sd.
    "Consistent" means only |paired mean| > paired sd; the 20 % rule (|mean| <
    20 % of the smaller arm mean) only decides whether a consistent gap is
    called "small" or "clear". The appended sign count says how many seeds
    disagree in sign with the paired mean."""
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "tie: identical on every seed"
    m, s = ms(diffs)
    if abs(m) <= s:
        return f"near-tie / small gap, within seed noise (indistinguishable from 0 within +-{s:.4f}{unit})"
    base = "small but consistent gap, not a tie" if abs(m) < 0.2 * min(ms(xa)[0], ms(xb)[0]) else "clear gap, not a tie"
    return base + "; " + sign_note(diffs, m)


def fmt_pair(m: float, s: float) -> str:
    """Paired mean+-sd; extra decimals when 4 would print a signed zero such as -0.0000."""
    if m != 0.0 and abs(m) < 5e-5:
        return f"{m:.6f}+-{s:.6f}"
    return f"{m:.4f}+-{s:.4f}"


def main() -> None:
    print(f"height field z=0.40-A*sin(2pi x/LAM)*sin(2pi y/LAM); grid {N_GRID}x{N_GRID} spacing 5 mm; "
          f"queries={QUERIES} k_eval={K_EVAL} seeds={len(SEEDS)}")
    print("sign check: PCA of an exact z=0.40 plane ->", ", ".join(
        f"{v:.6f}" for v in pca_normal([(0.01 * i, 0.01 * j, Z0) for i in range(5) for j in range(5)])),
          "(either sign is a valid eigenvector; orient toward the viewpoint)")
    print("regime arm angle_deg residual_mm raw_sign_flipped/queries  (mean+-sd over seeds)")
    for regime, a, lam, sd in REGIMES:
        per = {arm: {"ang": [], "res": [], "flip": []} for arm in ARMS}
        for seed in SEEDS:
            out = evaluate(regime, a, lam, sd, seed)
            for arm in ARMS:
                for k in ("ang", "res", "flip"):
                    per[arm][k].append(out[arm][k])
        for arm in ARMS:
            (am, asd), (rm, rsd) = ms(per[arm]["ang"]), ms(per[arm]["res"])
            print(f"{regime} {arm} {am:.4f}+-{asd:.4f} {rm:.4f}+-{rsd:.4f} {sum(per[arm]['flip'])}/{QUERIES * len(SEEDS)}")
        for x, y in (("B_pca_k20", "A_global_plane"), ("B_pca_k20", "C_pca_k4")):
            for k, name in (("ang", "angle_deg"), ("res", "residual_mm")):
                d = ms([u - v for u, v in zip(per[x][k], per[y][k])])
                unit = " deg" if k == "ang" else " mm"
                print(f"{regime} paired {x[0]}-{y[0]} {name} {fmt_pair(*d)}: {verdict(per[x][k], per[y][k], unit)}")
    print("flat_low_noise: one global plane is already the right normal everywhere; local PCA only adds noise")
    print("ripple_noisy: k=4 is noise-dominated, the global plane ignores curvature; k=20 averages the noise")
    print("fine_ripple_low_noise: k=20 spans a large part of a 40 mm ripple and smooths the curvature; k=4 resolves it")
    print("No winner declared: k trades noise averaging against curvature smoothing; the scale is a task choice")
    print("Open3D estimate_normals / PCL NormalEstimation on a real sensor: 本页未运行; tutorial text 以原文为准")


if __name__ == "__main__":
    main()
```

### Read the regimes

The `paired` lines subtract two arms seed by seed on the same draws. Labels follow one rule: **tie** means identical on every seed; **near-tie / small gap, within seed noise** means `|paired mean| ≤ sd`; a **consistent** gap means only `|paired mean| > sd`. The 20 % rule (`|mean|` below 20 % of the smaller arm mean) only decides whether a consistent gap is called **small** or **clear**; it never decides consistency. The appended sign count says how many of the 5 seeds disagree with the mean — every consistent or clear line on this page has the same sign on all 5 seeds.

- **flat_low_noise:** the global plane is already the right normal everywhere, so **B loses to A on angle**: A 0.0050±0.0058°, B 0.7499±0.0447°, C 4.6774±0.5880° (paired B−A 0.7449±0.0397°, a clear gap with the same sign on all 5 seeds, although both are under 1°). On the residual the order flips: B 0.2708±0.0075 mm against A 0.2778±0.0052 mm, paired B−A −0.0070±0.0036 mm (same sign on all 5 seeds), a **small but consistent gap, not a tie**, in B's favour. The reason is the metric, not a better normal: B's local plane follows the noise of a neighbourhood that overlaps the evaluation points, and the residual rewards that.
- **ripple_noisy:** **B wins on both metrics.** Angle: B 5.3848±0.3418°, A 19.1355±0.5304° (the global plane ignores the curvature), C 25.6248±2.6967° (four points are dominated by 2 mm noise); paired B−A −13.7507±0.6334°, B−C −20.2400±2.7704°, both clear gaps with the same sign on all 5 seeds. Residual: B 1.6855±0.0468 mm, A 2.2837±0.0496 mm, C 2.5549±0.1568 mm.
- **fine_ripple_low_noise:** **B loses to C on angle**: C 5.9507±0.4287°, B 11.1983±0.2312°, A 22.5345±0.4940° (paired B−C 5.2476±0.4954°, a clear gap, same sign on all 5 seeds).
