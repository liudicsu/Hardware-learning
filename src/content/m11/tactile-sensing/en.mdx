## Two paths you can take

**Optical tactile.** An elastomer sits over an endoscope camera; shear and normal deformation become image gradients / marker motion. GelSight (Yuan et al., Sensors 2017) is the family landmark; DIGIT (Lambeta et al.; Meta / GelSight collaboration) packages a reproducible open fingertip — design and interface live in `digit-design` / `digit-interface`.

**Magnetic tactile.** AnySkin / ReSkin mix magnetic powder into an elastomer and read field distortion with magnetometers. AnySkin's key design is **electronics separated from the skin, self-aligning, adhesive-free**: a user study reports **12±5 s** to replace (paper Table II; take the paper as source of truth).

## Numbers we verified in the papers (take the paper as source of truth)

From AnySkin (arXiv 2409.08276, HTML opened here):

- Mean replace time **12** s (±5).
- Slip LSTM accuracy **0.92** (92 %) on unseen objects.
- Plug insertion (Table III): cameras only ≈ **1.7**/10; cameras + AnySkin ≈ **6.7**/10; after skin swap ≈ **5.3**/10 (about **14** percentage points down; as a relative drop (6.7−5.3)/6.7 ≈ **21 %**, after rounding). Same table: ReSkin **6.0**/10 → **1.7**/10 (about **43** percentage points; relative drop (6.0−1.7)/6.0 ≈ **72 %**). Do not mix percentage points with relative drops; take the paper Table III counts as source of truth.

3D Cal (arXiv 2511.03078 abstract): mean reconstruction error on unseen objects about **156 µm** / **205 µm** for DIGIT / GelSight Mini — abstract figures; if the PDF tables disagree, trust the PDF. Its pipeline is not run on this page.

```python
#!/usr/bin/env python3
"""tactile_marker_toy.py: marker-grid deformation → contact estimate (stdlib).

3×3 marker grid; a synthetic contact pulls markers radially inward.
Estimate contact as the displacement-weighted centroid of markers
(not the single largest-displacement marker). Also prints AnySkin
paper constants used in the lesson prose (replace time, slip accuracy,
plug-insertion success rates) — paper numbers, not toy measurements.
"""
import math

SEED = 13
# 3x3 marker grid, rest spacing 1.0
grid = [(x, y) for y in (-1.0, 0.0, 1.0) for x in (-1.0, 0.0, 1.0)]
force_N = 2.5
k = 0.08  # synthetic compliance in image units
cx, cy = 0.2, -0.15

obs = []
for x, y in grid:
    dx = x - cx
    dy = y - cy
    r2 = dx * dx + dy * dy + 1e-6
    scale = k * force_N / r2
    obs.append((x - dx * scale, y - dy * scale))

disps = [math.hypot(o[0] - g[0], o[1] - g[1]) for o, g in zip(obs, grid)]
# Displacement-weighted centroid of observed marker positions
wsum = sum(disps)
est_x = sum(o[0] * d for o, d in zip(obs, disps)) / wsum
est_y = sum(o[1] * d for o, d in zip(obs, disps)) / wsum
err = math.hypot(est_x - cx, est_y - cy)

print(f"seed={SEED}")
print(f"true_contact=({cx:.3f},{cy:.3f})")
print(f"force_N={force_N:.2f}")
print(f"est_contact=({est_x:.4f},{est_y:.4f})")
print(f"contact_err={err:.4f}")
print(f"max_disp={max(disps):.4f}")
# AnySkin paper constants (arXiv 2409.08276) for check_diagrams bindings
print(f"anyskin_replace_s=12")
print(f"anyskin_slip_acc=0.92")
print(f"anyskin_plug_cam=1.7")
print(f"anyskin_plug_skin=6.7")
print(f"anyskin_plug_swap=5.3")
```

## Calibration and replaceability

Optical gels usually need recalibration after a swap; 3D Cal turns a cheap FDM printer into an automated indenter (reading only here). Magnetic skins that separate electronics from the skin and keep cross-instance signal consistent lose less policy performance after a swap — that is what AnySkin emphasises against ReSkin / DIGIT in the plug table. Replaceability is the precondition for "touch at data scale"; 11.7 picks that up.

### Axes, rest bias and first contact
This is a **synthetic calibration exercise**, not a validated AnySkin force estimator. Define skin-frame x right, y up the surface, z inward. In the fictitious replacement skin, sensor channel a measures negative y, b positive x, c inward load; gains also change. A label such as Bx in a real magnetometer refers to magnetic field, not a force axis: field units cannot be relabelled Newtons. The older marker toy's `force_N=2.5` is an assumed deformation input, not a measured force. Here all loads are **dimensionless proxies**, and positions/errors use synthetic skin units.

1. At rest, average 80 samples to estimate each channel's bias. Subtract this vector before detection or localisation; do not zero the sensor while it is already in contact.
2. Verify axis order and sign using known-direction gentle probes. Debiasing cannot fix a reversed or swapped axis.
3. After a skin swap, collect 80 independent jig samples at known synthetic x=y=0.5, load=0.2. Estimate gx, gy, gz, rather than testing against the evaluation contacts' hidden truth. This deliberately simple diagonal-gain model does not cover nonlinear hysteresis or cross-axis coupling. Real force calibration needs independent load references and validation; real calibration/capture is 本页未运行 (not run here).
4. Use a first-contact data gate: load above 0.06 and at most 0.15 requests `stop_approach_then_verify`. These are arbitrary dimensionless teaching thresholds, **not safe force limits**. A real device needs validated limits, speed bounds and an emergency stop. Higher-load records are rejected, not silently counted as successful gentle contact.

For a worked example, a contact at x=0.3, y=−0.2, load=0.08 would produce noiseless bias-free a=0.0112, b=0.0336, c=0.096 with gains (1.4, 0.7, 1.2). Recover load=c/gz, x=(b/gx)/load, y=−(a/gy)/load. Dividing near zero amplifies noise: do not localise a resting sensor.

The recorded sequence contains 30 rest, 30 gentle-contact and 30 higher-load samples. **Raw, debiased, sign-corrected (old unit gains), recalibrated and gated conditions reuse identical noise and identical records**; no condition gets fresh, quieter noise. Localisation MAE always uses the same 60 true-contact samples, even for the gated condition, to avoid selection bias. Precontact false positives use the same 30 resting samples. The gate is a replay checklist: it does not simulate stopping the physical sequence or prove a policy safer; policy integration stays in 11.7.

```python
#!/usr/bin/env python3
"""Synthetic tactile calibration, not a magnetometer-to-Newton conversion.

Body x points right, y up on the skin, z inward. After a fictitious swap,
sensor a=-gy*load*y, b=gx*load*x, c=gz*load, plus rest bias and noise.
All conditions reuse the SAME recorded samples. Rest and known-location
probe records estimate bias and gains independently of evaluation contacts.
Load is dimensionless; positions and errors are in synthetic skin units.
The low-load gate is a first-contact teaching rule, NOT hardware safety.
"""
import math
import random
import statistics

SEED = 23
rng = random.Random(SEED)
BIAS = (0.14, -0.12, 0.12)
GAINS = (1.4, 0.7, 1.2)  # gx, gy, gz after synthetic skin swap
THRESHOLD, LOW_MAX = 0.06, 0.15  # dimensionless, NOT N


def measure(x, y, load):
    gx, gy, gz = GAINS
    signal = (-gy * load * y, gx * load * x, gz * load)
    return tuple(s + b + rng.uniform(-0.004, 0.004)
                 for s, b in zip(signal, BIAS))


rest = [measure(0, 0, 0) for _ in range(80)]
bias_hat = tuple(statistics.mean(row[j] for row in rest) for j in range(3))
# Independent calibration jig: known x=y=0.5, load=0.2 (synthetic only).
probes = [measure(0.5, 0.5, 0.2) for _ in range(80)]
a, b, c = (statistics.mean(row[j] for row in probes) - bias_hat[j]
           for j in range(3))
gains_hat = (b / 0.1, -a / 0.1, c / 0.2)

# Shared evaluation records: 30 rest, 30 gentle contact, 30 higher load.
truth, records = [], []
for i in range(90):
    x, y = 0.3 + 0.04 * math.sin(i), -0.2 + 0.03 * math.cos(i)
    load = 0 if i < 30 else (0.08 if i < 60 else 0.4)
    truth.append((x, y, load))
    records.append(measure(x, y, load))


def estimate(row, mode):
    a, b, c = row
    if mode != "raw":
        a, b, c = (v - offset for v, offset in zip(row, bias_hat))
    if mode in ("raw", "debiased"):
        return a / max(c, 1e-6), b / max(c, 1e-6), c
    gx, gy, gz = gains_hat if mode in ("recalibrated", "low_force_gated") else (1, 1, 1)
    load = c / gz
    return (b / gx / max(load, 1e-6), -a / gy / max(load, 1e-6), load)


print(f"seed={SEED}")
print("units=synthetic_skin_and_dimensionless_load_not_measured_Newtons")
print("noise=shared_records_all_conditions")
for mode in ("raw", "debiased", "sign_corrected", "recalibrated", "low_force_gated"):
    estimates = [estimate(row, mode) for row in records]
    # Same 60 real-contact records for localization: avoid selection bias.
    errors = [math.hypot(x - tx, y - ty)
              for (x, y, _), (tx, ty, load) in zip(estimates, truth) if load > 0]
    accepted = [i for i, (_, _, load) in enumerate(estimates)
                if load > THRESHOLD and (mode != "low_force_gated" or load <= LOW_MAX)]
    fp = sum(truth[i][2] == 0 for i in accepted)
    print(f"{mode}_localisation_mae={statistics.mean(errors):.4f}")
    print(f"{mode}_precontact_fp={fp}/30")
    if mode == "low_force_gated":
        print(f"gate_accepted={len(accepted)}/90")
        print(f"first_contact_index={accepted[0] if accepted else -1}")
        print("first_contact_action=stop_approach_then_verify")
print(f"contact_threshold={THRESHOLD:.2f}")
print(f"low_load_ceiling={LOW_MAX:.2f}")
```
