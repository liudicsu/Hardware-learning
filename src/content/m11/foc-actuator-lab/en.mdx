## Why 90°

Lorentz force peaks when current and field are 90° apart. Brushed motors keep that mechanically with brushes and a commutator; FOC does it in software with coordinate transforms so the stator field stays 90° ahead of the rotor flux, \(\tau = K_t \cdot i_q\), with targets <Term id="id-zero">\(i_d = 0\)</Term> and <Term id="iq-torque">\(i_q = \tau / K_t\)</Term>.

## Clarke and Park

Three frames (SimpleFOC `foc_theory`; follow the current docs):

1. **Stationary abc**: three phases \(i_a, i_b, i_c\), 120° apart.
2. **Stationary αβ** (Clarke): two orthogonal components; balanced \(i_\alpha = i_a\), \(i_\beta = (i_a + 2 i_b)/√3\).
3. **Rotating dq** (Park): spins with electrical angle \(\theta_e\); AC becomes near-DC for ordinary PI.

Inverse path: dq → αβ (inverse Park) → abc (inverse Clarke) → PWM. Two-phase steppers are already orthogonal, so Clarke can be skipped.

## Clarke–Park round-trip toy

`clarke_park_toy.py` takes \(i_q=1\), \(i_d=0\), \(\theta=\pi/6\): inverse Park → inverse Clarke to three phases, then the forward transforms recover id/iq. It prints `sum_abc` and the id/iq errors.

<CodeSource path="examples/month-11/foc-actuator-lab/clarke_park_toy.py" />

```python
#!/usr/bin/env python3
"""clarke_park_toy.py: Clarke–Park round-trip for FOC (stdlib).

Given id_cmd=0, iq_cmd and electrical angle θ:
  inverse Park → inverse Clarke → Clarke → Park
and check sum_abc≈0 plus recovered id/iq.
Formulas follow SimpleFOC foc_theory (balanced three-phase).
"""
import math

SEED = 11
theta = math.pi / 6
iq_cmd, id_cmd = 1.0, 0.0


def clarke(ia, ib, ic):
    # Balanced: ia+ib+ic=0; SimpleFOC-style
    i_alpha = ia
    i_beta = (ia + 2 * ib) / math.sqrt(3)
    return i_alpha, i_beta


def park(i_alpha, i_beta, th):
    c, s = math.cos(th), math.sin(th)
    id_ = i_alpha * c + i_beta * s
    iq = -i_alpha * s + i_beta * c
    return id_, iq


# Inverse Park then inverse Clarke
u_alpha = id_cmd * math.cos(theta) - iq_cmd * math.sin(theta)
u_beta = id_cmd * math.sin(theta) + iq_cmd * math.cos(theta)
ia = u_alpha
ib = -0.5 * u_alpha + (math.sqrt(3) / 2) * u_beta
ic = -0.5 * u_alpha - (math.sqrt(3) / 2) * u_beta

a, b = clarke(ia, ib, ic)
id_r, iq_r = park(a, b, theta)

print(f"seed={SEED}")
print(f"theta_rad={theta:.6f}")
print(f"iq_cmd={iq_cmd:.4f} id_cmd={id_cmd:.4f}")
print(f"ia={ia:.6f} ib={ib:.6f} ic={ic:.6f}")
print(f"sum_abc={ia + ib + ic:.3e}")
print(f"id_recovered={id_r:.6f} iq_recovered={iq_r:.6f}")
print(f"id_err={abs(id_r - id_cmd):.3e} iq_err={abs(iq_r - iq_cmd):.3e}")
```

How to read it:

- At \(\theta = \pi/6 \approx\) **0.523599** rad the phases are −0.5 / 1.0 / −0.5 and sum_abc = **0.000e+00** (Kirchhoff).

## SimpleFOC reading map

- **Library**: Arduino SimpleFOC (docs mark the transform page as v2.4+); PlatformIO / many MCUs (including the ESP32 you already have from Month 2).
- **Sensors**: open-loop (no feedback, demo only), Hall, magnetic encoders.
- **Two integration paths**: tune first with the serial <Term id="simplefoc-commander">Commander</Term>; only then consider a micro-ROS client that exposes the joint to a ROS 2 graph. Community micro-ROS + FOC practice exists, but **it is not in CI here and we do not copy third-party blog BOMs**; flash steps live in this folder's README and are marked not run on this page.
- **Against SO-101**: bus servos already run their own servo loops; this lesson does not replace STS3215. Reach for FOC when you build a hub motor, a direct-drive joint, or need a current-loop torque interface.
