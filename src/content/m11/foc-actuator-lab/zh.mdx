## 为什么要 90°

洛伦兹力在电流与磁场夹角 90° 时最大。有刷电机靠电刷与换向器机械地保持这个关系；FOC 用坐标变换在软件里做同样的事：定子磁场始终超前转子磁链 90°，于是 \(\tau = K_t \cdot i_q\)，目标是 <Term id="id-zero">\(i_d = 0\)</Term>、<Term id="iq-torque">\(i_q = \tau / K_t\)</Term>。

## Clarke 与 Park

三个参考系（SimpleFOC `foc_theory`，以当期文档为准）：

1. **静止 abc**：三相 \(i_a, i_b, i_c\)，彼此 120°。
2. **静止 αβ**（Clarke）：两正交分量；平衡时 \(i_\alpha = i_a\)，\(i_\beta = (i_a + 2 i_b)/√3\)。
3. **旋转 dq**（Park）：随转子电角度 \(\theta_e\) 转；AC 变成近似 DC，可用普通 PI。

逆变换：dq → αβ（逆 Park）→ abc（逆 Clarke）得到三相电压，再经 PWM 驱动。步进电机两相已正交，可省 Clarke。

## Clarke–Park 往返玩具

`clarke_park_toy.py` 给定 \(i_q=1\)、\(i_d=0\)、\(\theta=\pi/6\)：逆 Park → 逆 Clarke 得三相，再正变换回收。打印 `sum_abc` 与 id/iq 误差。

```python
#!/usr/bin/env python3
"""clarke_park_toy.py: Clarke–Park round-trip for FOC (stdlib).

Given id_cmd=0, iq_cmd and electrical angle θ:
  inverse Park → inverse Clarke → Clarke → Park
and check sum_abc≈0 plus recovered id/iq.
Formulas follow SimpleFOC foc_theory (balanced three-phase).
"""
import math

SEED = 11
theta = math.pi / 6
iq_cmd, id_cmd = 1.0, 0.0


def clarke(ia, ib, ic):
    # Balanced: ia+ib+ic=0; SimpleFOC-style
    i_alpha = ia
    i_beta = (ia + 2 * ib) / math.sqrt(3)
    return i_alpha, i_beta


def park(i_alpha, i_beta, th):
    c, s = math.cos(th), math.sin(th)
    id_ = i_alpha * c + i_beta * s
    iq = -i_alpha * s + i_beta * c
    return id_, iq


# Inverse Park then inverse Clarke
u_alpha = id_cmd * math.cos(theta) - iq_cmd * math.sin(theta)
u_beta = id_cmd * math.sin(theta) + iq_cmd * math.cos(theta)
ia = u_alpha
ib = -0.5 * u_alpha + (math.sqrt(3) / 2) * u_beta
ic = -0.5 * u_alpha - (math.sqrt(3) / 2) * u_beta

a, b = clarke(ia, ib, ic)
id_r, iq_r = park(a, b, theta)

print(f"seed={SEED}")
print(f"theta_rad={theta:.6f}")
print(f"iq_cmd={iq_cmd:.4f} id_cmd={id_cmd:.4f}")
print(f"ia={ia:.6f} ib={ib:.6f} ic={ic:.6f}")
print(f"sum_abc={ia + ib + ic:.3e}")
print(f"id_recovered={id_r:.6f} iq_recovered={iq_r:.6f}")
print(f"id_err={abs(id_r - id_cmd):.3e} iq_err={abs(iq_r - iq_cmd):.3e}")
```

## SimpleFOC 阅读图

- **库**：Arduino SimpleFOC（文档写 v2.4+ 坐标变换页）；PlatformIO / 多 MCU（含你在 M2 已有的 ESP32）。
- **传感器**：开环（无反馈，仅演示）、霍尔、磁编码器。
- **两条集成路径**：先串口 <Term id="simplefoc-commander">Commander</Term> 调参；再考虑 micro-ROS 客户端把关节接到 ROS 2 图里。micro-ROS + FOC 的社区实践存在，但**本页不进 CI、不抄第三方博客零件表**；刷机步骤放本目录 README，标注本页未运行。
