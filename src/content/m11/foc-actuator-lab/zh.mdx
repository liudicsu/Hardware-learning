## 为什么要 90°

洛伦兹力在电流与磁场夹角 90° 时最大。有刷电机靠电刷与换向器机械地保持这个关系；FOC 用坐标变换在软件里做同样的事：定子磁场始终超前转子磁链 90°，于是 τ = K_t · i_q，目标是 <Term id="id-zero">i_d = 0</Term>、<Term id="iq-torque">i_q = τ / K_t</Term>。

## Clarke 与 Park（代数恒等式）

三个参考系（SimpleFOC `foc_theory`，以当期文档为准）：

1. **静止 abc**：三相 i_a, i_b, i_c，彼此 120°。
2. **静止 αβ**（Clarke）：两正交分量；平衡时 i_α = i_a，i_β = (i_a + 2 i_b)/√3。
3. **旋转 dq**（Park）：随转子电角度 θ_e 转；AC 变成近似 DC，可用普通 PI。

逆变换：dq → αβ（逆 Park）→ abc（逆 Clarke）得到三相电压，再经 PWM 驱动。这些变换本身是**代数恒等式**，不是被控对象动力学——下一节的 R–L 电路才是被控对象。步进电机两相已正交，可省 Clarke。

```python
#!/usr/bin/env python3
"""clarke_park_toy.py: Clarke–Park round-trip for FOC (stdlib).

Given id_cmd=0, iq_cmd and electrical angle θ:
  inverse Park → inverse Clarke → Clarke → Park
and check sum_abc≈0 plus recovered id/iq.
Formulas follow SimpleFOC foc_theory (balanced three-phase).
"""
import math

SEED = 11
theta = math.pi / 6
iq_cmd, id_cmd = 1.0, 0.0


def clarke(ia, ib, ic):
    # Balanced: ia+ib+ic=0; SimpleFOC-style
    i_alpha = ia
    i_beta = (ia + 2 * ib) / math.sqrt(3)
    return i_alpha, i_beta


def park(i_alpha, i_beta, th):
    c, s = math.cos(th), math.sin(th)
    id_ = i_alpha * c + i_beta * s
    iq = -i_alpha * s + i_beta * c
    return id_, iq


# Inverse Park then inverse Clarke
u_alpha = id_cmd * math.cos(theta) - iq_cmd * math.sin(theta)
u_beta = id_cmd * math.sin(theta) + iq_cmd * math.cos(theta)
ia = u_alpha
ib = -0.5 * u_alpha + (math.sqrt(3) / 2) * u_beta
ic = -0.5 * u_alpha - (math.sqrt(3) / 2) * u_beta

a, b = clarke(ia, ib, ic)
id_r, iq_r = park(a, b, theta)

print(f"seed={SEED}")
print(f"theta_rad={theta:.6f}")
print(f"iq_cmd={iq_cmd:.4f} id_cmd={id_cmd:.4f}")
print(f"ia={ia:.6f} ib={ib:.6f} ic={ic:.6f}")
print(f"sum_abc={ia + ib + ic:.3e}")
print(f"id_recovered={id_r:.6f} iq_recovered={iq_r:.6f}")
print(f"id_err={abs(id_r - id_cmd):.3e} iq_err={abs(iq_r - iq_cmd):.3e}")
```

## 电角度与 dq 电流环（R–L 电路）

SimpleFOC 风格电角度：

θ̂_e = normalize(d · p · θ_m,meas − θ_e0)

其中传感器方向 d ∈ `{+1, −1}`，极对数 p，零电角度偏移 θ_e0。

**仿真器 vs 控制器（强制合同）：**

- **物理真值** θ_e★ 只在电路模型积分器里用（反电动势 / 虚构电机如何转）。
- **控制器从不接收** θ_e★。它只看到 θ_m,meas（与重构电流），再算 θ̂_e。
- 「错 offset / 错 p」消融 = 控制器的 θ̂_e 错，而 θ_e★ 仍与被控对象一致。两臂使用**同一组**测量噪声。

电路模型假设（本玩具锁定）：每轴串联 R、L；反电动势 e_q ≈ k_e ω_e、e_d ≈ 0；**交叉耦合项 ω_e L i 在两臂都省略**（不是只省略一臂）。输出 SinePWM 形状的相电压浮点——没有 MCU 定时器。另省略：积分抗饱和、真实 PWM 母线限制（V_LIM 仅为 ud/uq 软钳位）；OMEGA_M 为规定值，iq 不驱动机械。

**PI 算例（单位与离散积分）：** 误差 e = i_ref − i（A）；控制器按前向欧拉离散积分 ∫e ≈ Σ e·DT，玩具 DT = 1e-4 s（与内嵌玩具 docstring 一致），∫e 单位 A·s；输出 u = Kp·e + Ki·∫e（V）。玩具增益 Kp = 3.0 V/A、Ki = 800 V/(A·s)。手算举例：若 e 恒为 0.1 A 持续 10 步，∫e ≈ 10 × 0.1 × 1e-4 = 1e-4 A·s，u = 3.0×0.1 + 800×1e-4 = 0.30 + 0.08 = **0.38 V**。反电动势 e_q = k_e ω_e 同样以 V 计（k_e = 0.04 V·s/rad）。这是手算示意，不是玩具输出。

`foc_current_loop_toy.py` 在同一噪声下跑三臂：正确 p/θ_e0；错 θ_e0；错极对数。指标分控制器帧 RMSE（PI 看见的）与**被控对象真值帧** RMSE（实际力矩/磁通轴）。错角度时控制器帧仍可能「看起来还行」，被控对象帧会垮——这正是对齐的意义。

```python
#!/usr/bin/env python3
"""foc_current_loop_toy.py: electrical angle + dq PI on an R–L circuit (stdlib).

Naming LOCKED: the plant is an R–L electrical circuit model (resistance R,
inductance L). It is NOT reinforcement learning.

Simulator vs controller angle contract:
  - Ground-truth physical electrical angle theta_e_star lives ONLY inside the
    plant integrator (back-EMF / how the fictitious machine rotates).
  - The controller NEVER receives theta_e_star. It only sees noisy theta_m_meas
    (and reconstructed currents) and computes hat_theta_e =
    normalize(d * p_ctrl * theta_m_meas - theta_e0_ctrl).
  - Ablation "wrong offset / wrong p" means the controller's hat_theta_e is wrong
    while theta_e_star stays consistent with the plant. Both arms share the SAME
    measurement-noise draws.

Metrics (LOCKED):
  - ctrl_*_rmse: controller-frame tracking of id/iq refs (what the PI sees).
  - plant_*_rmse: true-frame plant currents vs refs (actual torque/flux axes).
    Wrong hat_theta_e can look "OK" in ctrl frame while plant frame drifts —
    that is the pedagogical point.
  - ang_rmse: wrap(hat_theta_e - theta_e_star), diagnostic only (offline; not a
    controller input).

Clarke / Park transforms that are not plant dynamics are algebraic identities.
Cross-coupling omega*L*i terms are OMITTED on BOTH arms (locked).
SinePWM-shaped phase voltage floats only — no MCU timer.

Also OMITTED (stated in the lesson): anti-windup on the integrators; a real
PWM DC-rail / duty limit (V_LIM is a soft clamp on ud/uq only). With the
chosen gains and back-EMF, all three arms report sat=0 (clamp never hits).
Mechanics: OMEGA_M is a prescribed constant; iq is a torque *proxy* and does
NOT integrate rotor speed. Forward-Euler on the R–L ODE needs DT << L/R
(here DT=1e-4 s, L/R≈2.1 ms).
"""
import math
import random

SEED = 13
DT = 1e-4
N = 4000
WARM = 800
R = 1.2
L = 0.0025
KE = 0.04
V_LIM = 8.0
IQ_REF = 1.0
ID_REF = 0.0
OMEGA_M = 6.0
P_TRUE = 7
D_TRUE = 1
THETA_E0_TRUE = 0.20
NOISE_THETA = 0.0015
NOISE_I = 0.015
KP_D, KI_D = 3.0, 800.0
KP_Q, KI_Q = 3.0, 800.0


def wrap(a):
    return (a + math.pi) % (2 * math.pi) - math.pi


def electrical_angle(d, p, theta_m, theta_e0):
    return wrap(d * p * theta_m - theta_e0)


def inv_park(ud, uq, th):
    c, s = math.cos(th), math.sin(th)
    return c * ud - s * uq, s * ud + c * uq


def inv_clarke(ua, ub):
    return (
        ua,
        -0.5 * ua + (math.sqrt(3) / 2) * ub,
        -0.5 * ua - (math.sqrt(3) / 2) * ub,
    )


def clarke(ia, ib, _ic):
    return ia, (ia + 2 * ib) / math.sqrt(3)


def park(i_alpha, i_beta, th):
    c, s = math.cos(th), math.sin(th)
    return i_alpha * c + i_beta * s, -i_alpha * s + i_beta * c


def run_arm(p_ctrl, theta_e0_ctrl, noise_theta, noise_i):
    theta_m = 0.0
    id_plant = 0.0
    iq_plant = 0.0
    int_d = 0.0
    int_q = 0.0
    s_ctrl_id = s_ctrl_iq = s_plant_id = s_plant_iq = s_ang = 0.0
    n_metric = 0
    sat_hits = 0
    ua = ub = uc = 0.0

    for k in range(N):
        theta_e_star = electrical_angle(D_TRUE, P_TRUE, theta_m, THETA_E0_TRUE)
        omega_e = D_TRUE * P_TRUE * OMEGA_M
        e_q = KE * omega_e

        theta_m_meas = theta_m + noise_theta[k]
        hat_theta_e = electrical_angle(D_TRUE, p_ctrl, theta_m_meas, theta_e0_ctrl)

        i_alpha_p, i_beta_p = inv_park(id_plant, iq_plant, theta_e_star)
        ia, ib, ic = inv_clarke(i_alpha_p, i_beta_p)
        ia_m = ia + noise_i[3 * k]
        ib_m = ib + noise_i[3 * k + 1]
        ic_m = ic + noise_i[3 * k + 2]
        a, b = clarke(ia_m, ib_m, ic_m)
        id_meas, iq_meas = park(a, b, hat_theta_e)

        err_d = ID_REF - id_meas
        err_q = IQ_REF - iq_meas
        int_d += err_d * DT  # no anti-windup (omitted)
        int_q += err_q * DT
        ud_raw = KP_D * err_d + KI_D * int_d
        uq_raw = KP_Q * err_q + KI_Q * int_q
        ud = max(-V_LIM, min(V_LIM, ud_raw))
        uq = max(-V_LIM, min(V_LIM, uq_raw))
        if ud != ud_raw or uq != uq_raw:
            sat_hits += 1  # soft ud/uq clamp only; not a real PWM rail

        ual, ubt = inv_park(ud, uq, hat_theta_e)
        ua, ub, uc = inv_clarke(ual, ubt)

        a_v, b_v = clarke(ua, ub, uc)
        ud_plant, uq_plant = park(a_v, b_v, theta_e_star)

        # R–L circuit; cross-coupling omitted on BOTH arms
        id_plant += ((ud_plant - R * id_plant - 0.0) / L) * DT
        iq_plant += ((uq_plant - R * iq_plant - e_q) / L) * DT

        if k >= WARM:
            s_ctrl_id += (id_meas - ID_REF) ** 2
            s_ctrl_iq += (iq_meas - IQ_REF) ** 2
            s_plant_id += (id_plant - ID_REF) ** 2
            s_plant_iq += (iq_plant - IQ_REF) ** 2
            s_ang += wrap(hat_theta_e - theta_e_star) ** 2
            n_metric += 1

        theta_m += OMEGA_M * DT

    return {
        "ctrl_id_rmse": math.sqrt(s_ctrl_id / n_metric),
        "ctrl_iq_rmse": math.sqrt(s_ctrl_iq / n_metric),
        "plant_id_rmse": math.sqrt(s_plant_id / n_metric),
        "plant_iq_rmse": math.sqrt(s_plant_iq / n_metric),
        "ang_rmse": math.sqrt(s_ang / n_metric),
        "sat_hits": sat_hits,
        "ua": ua, "ub": ub, "uc": uc,
    }


rng = random.Random(SEED)
noise_theta = [rng.gauss(0.0, NOISE_THETA) for _ in range(N)]
noise_i = [rng.gauss(0.0, NOISE_I) for _ in range(3 * N)]

ok = run_arm(P_TRUE, THETA_E0_TRUE, noise_theta, noise_i)
bad_off = run_arm(P_TRUE, THETA_E0_TRUE + 0.55, noise_theta, noise_i)
bad_p = run_arm(5, THETA_E0_TRUE, noise_theta, noise_i)

print(f"seed={SEED}")
print(f"dt={DT:.1e} N={N} warm={WARM}")
print(f"R_ohm={R:.2f} L_H={L:.4f}")
print("plant_model=R_L_circuit")
print(f"p_true={P_TRUE} theta_e0_true={THETA_E0_TRUE:.3f}")
print(f"iq_ref={IQ_REF:.1f} id_ref={ID_REF:.1f}")
print("cross_coupling=omitted_both_arms")
print(f"ok_ctrl_iq_rmse={ok['ctrl_iq_rmse']:.6f}")
print(f"ok_ctrl_id_rmse={ok['ctrl_id_rmse']:.6f}")
print(f"ok_plant_iq_rmse={ok['plant_iq_rmse']:.6f}")
print(f"ok_plant_id_rmse={ok['plant_id_rmse']:.6f}")
print(f"ok_ang_rmse={ok['ang_rmse']:.6f}")
print(f"bad_offset_ctrl_iq_rmse={bad_off['ctrl_iq_rmse']:.6f}")
print(f"bad_offset_plant_iq_rmse={bad_off['plant_iq_rmse']:.6f}")
print(f"bad_offset_plant_id_rmse={bad_off['plant_id_rmse']:.6f}")
print(f"bad_offset_ang_rmse={bad_off['ang_rmse']:.6f}")
print(f"bad_pp_ctrl_iq_rmse={bad_p['ctrl_iq_rmse']:.6f}")
print(f"bad_pp_plant_iq_rmse={bad_p['plant_iq_rmse']:.6f}")
print(f"bad_pp_plant_id_rmse={bad_p['plant_id_rmse']:.6f}")
print(f"bad_pp_ang_rmse={bad_p['ang_rmse']:.6f}")
print(f"ok_ua={ok['ua']:.6f} ok_ub={ok['ub']:.6f} ok_uc={ok['uc']:.6f}")
print(f"ok_sat={ok['sat_hits']} bad_offset_sat={bad_off['sat_hits']} bad_pp_sat={bad_p['sat_hits']}")
print("anti_windup=omitted")
print("pwm_rail_limit=omitted")  # V_LIM is soft ud/uq clamp only
print(f"omega_m_prescribed={OMEGA_M:.1f}")  # iq is torque proxy; does not drive mechanics
print(f"euler_dt={DT:.1e} L_over_R={L/R:.4e}")
print("plant_vs_controller=theta_e_star_not_fed_to_ctrl")

assert bad_off["ang_rmse"] > 10 * ok["ang_rmse"]
assert bad_p["ang_rmse"] > 10 * ok["ang_rmse"]
assert bad_off["plant_iq_rmse"] > 2 * ok["plant_iq_rmse"]
assert bad_p["plant_iq_rmse"] > 2 * ok["plant_iq_rmse"]
assert bad_off["plant_id_rmse"] > 2 * ok["plant_id_rmse"]
assert bad_p["plant_id_rmse"] > 2 * ok["plant_id_rmse"]
assert ok["sat_hits"] == 0 and bad_off["sat_hits"] == 0 and bad_p["sat_hits"] == 0
# Controller can still look OK under constant offset — do NOT require ctrl degrade
print("asserts_ok=true")
```

## 电流模式 d/q 交叉耦合前馈

上面的 R–L 电流环玩具在两臂都省略了交叉耦合，不单臂省略；那条说明保持原样，该玩具也不改。本节是另一条切面：已打开的 SimpleFOC 电流模式前馈如何补偿 d/q 交叉耦合与电感滞后，并在真正含这些项的被控对象上与仅用 PI 的电流模式对照。

**主公式体**。电流模式页 *FOC Current Mode*（`https://docs.simplefoc.com/foc_current_torque_mode`）是官方臂的公式体。它原先不在本课阅读图里，这里作为 Resource 补上。已经链接的 `voltage_torque_control` 页也会复述电流模式前馈，并给出被控对象模型；那**不是**用它代替补上电流模式页。

<Resource id="simplefoc-foc-current-torque" />

当 d 轴目标为 0 时，该页仅用 PI 的定律是 u_q = PI_q(i_q - i_hat_q)、u_d = PI_d(-i_hat_d)。若提供 L_d、L_q，同一页会加上前馈（以文档为准）：

u_q = PI_q(i_q - i_hat_q) + L_d i_d v_e，u_d = PI_d(-i_hat_d) - L_q i_q v_e，

其中 v_e = n_pp · v。本课里这些前馈项中不带帽的 i_d、i_q 取电流参考（d 轴目标为 0），与该页 PI 式里 i_q 表示 q 轴目标的写法一致。

同一电流模式页写明：在稳态、当 PI 环稳定后，即使没有前馈项，交叉耦合与电感滞后 "will be compensated even without the feed-forward terms. However, at highly dynamic conditions and at high speeds, the PI controllers alone may not be able to keep up…"（以文档为准；这是库的表述，不是玩具输出）。下面已稳态格预先声明可能接近打平，并以冻结首次运行的标签为准，予以保留。

**被控对象**。已经链接的 *Torque Control Methods in FOC* 页（`https://docs.simplefoc.com/voltage_torque_control`）把电机建成 d、q 轴两条 R–L 电路（以文档为准）：

u_d = R i_d + L_d di_d/dt - v_e L_q i_q，u_q = R i_q + L_q di_q/dt + v_e L_d i_d + U_bemf。

本课选用的反电势定律取该页第一条公式，并在首次正式运行前写明：U_bemf = K_e · v，其中 v 是机械角速度。每个格里的 v 是规定值；iq 不积分转子力学。积分器无抗饱和。V_LIM 只是 ud/uq 软钳位，不是真实 PWM 母线。官方 SimpleFOC 刷机仍为本页未运行。

电压模式滞后补偿 u_d = -v_e L_q i_q，在玩具里与 u_q = R i_q + U_bemf、且没有电流 PI 配对，是点名、不采用的对照。它不是官方电流模式臂的替代。

维基百科 *Field-oriented control*（`https://en.wikipedia.org/w/index.php?title=Field-oriented_control&oldid=1354069032`）只作定性交叉核对（"A decoupling term is sometimes added to the controller output to improve control performance to mitigate cross coupling…"）。其中的感应电机方程是另一种模型，不是公式体。以 SimpleFOC 文档为准。

弱磁、MTPA 与 SVPWM 仍不在范围内。

**预先写明的工况**（以冻结首次运行打印的标签为准，冻结后不改 R、L 或 v_e）：

```python
#!/usr/bin/env python3
"""foc_dq_decoupling_toy.py: current-mode d/q feedforward on a coupled plant.

stdlib CPU comparison. Official SimpleFOC flash is 本页未运行. This is not a
run of the library, not a port of the firmware, and not a third PWM rail.

Shared plant (opened SimpleFOC voltage-mode model):

    u_d = R * i_d + L_d * di_d/dt - v_e * L_q * i_q
    u_q = R * i_q + L_q * di_q/dt + v_e * L_d * i_d + U_bemf

with v_e = n_pp * v and the opened first back-EMF law U_bemf = K_e * v,
where v is mechanical speed. v is prescribed in each cell; i_q is a torque
proxy and does not integrate rotor mechanics. Forward Euler needs
dt << L/R; the printed hand_calc lines name L_d/R and L_q/R.

Official current-mode laws, if L_d and L_q are provided (opened current-mode
page; feedforward uses the unhatted i_d, i_q, which on that page are the
same symbols as the current references; d-axis target is 0):

    u_q = PI_q(i_q - i_hat_q) + L_d * i_d * v_e
    u_d = PI_d(-i_hat_d) - L_q * i_q * v_e

PI-only (no inductance feedforward) is the same without those extra terms.
PI uses measured currents i_hat_d, i_hat_q. Integrators have no anti-windup.
V_LIM is a soft ud/uq clamp only, not a real PWM DC-rail / duty limit.

Arms, written before the first official run:
  (A) PI-only current mode, no inductance feedforward
  (B) official current-mode feedforward as written above (adopted)
  (C) wrong-sign d-axis compensation: u_d = PI_d + L_q * i_q * v_e (lose arm)
  ALT_VOLTAGE_MODE_LAG: voltage-mode u_d = -v_e * L_q * i_q and
    u_q = R * i_q + U_bemf, with no current PI. Named, printed, not adopted.

Common random numbers: each seed draws one current-noise sequence shared
by all four arms. Five seeds. Metrics are plant-frame RMSE of i_d and i_q
against the references over the declared window (lower is better).

Regimes, written before the first official run (keep whatever the frozen
first run prints; do not retune R, L, or v_e after that freeze):
  low_speed_settled     low speed, modest constant i_q, settled window:
                        A and B may near-tie on i_d or i_q tracking (keep;
                        an exact tie is also allowed if the freeze prints it)
  high_speed_iq_step    high v_e and a dynamic i_q step: B consistent lower
                        |i_d| error and/or better i_q tracking than A (keep);
                        wrong-sign C loses on this cell (keep)

Label order: exact tie; numerically zero (floating-point residue); near-tie
(|m| <= sd); then small vs clear using 20 % of the smaller-arm mean, with a
sign count. Printed numbers use ASCII minus and +-.
"""
from __future__ import annotations

import math
import random
from decimal import ROUND_HALF_UP, Decimal, getcontext

getcontext().rounding = ROUND_HALF_UP

SEEDS = (0, 1, 2, 3, 4)
NUM_ZERO = 1e-9
SMALL_FRAC = 0.2000  # 20 % of the smaller-arm mean; printed as 0.2000

# Lesson-chosen parameters, named before the first official run.
R = 0.8000
L_D = 0.0020
L_Q = 0.0024
N_PP = 7
K_E = 0.0400  # U_bemf = K_E * v; v is mechanical
DT = 1e-4
KP_D = 5.0000
KI_D = 1000.0000
KP_Q = 5.0000
KI_Q = 1000.0000
V_LIM = 24.0000  # soft ud/uq clamp only; not a real PWM rail
ID_REF = 0.0000
NOISE_I = 0.0200

# low_speed_settled: modest i_q, slow / settled reference
LOW_V = 8.0000
LOW_IQ = 1.0000
LOW_TOTAL = 0.0800
LOW_WARM = 0.0400

# high_speed_iq_step: high electrical speed and a step in i_q
HIGH_V = 220.0000
HIGH_IQ_BEFORE = 0.5000
HIGH_IQ_AFTER = 2.0000
HIGH_STEP_T = 0.0100
HIGH_TOTAL = 0.0400
HIGH_METRIC_START = 0.0100


def mean_sd(xs):
    if all(x == xs[0] for x in xs):
        return xs[0], 0.0
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-4:
        return format(Decimal(repr(x)), ".3e")
    s = format(Decimal(repr(x)), ".4f")
    return "0.0000" if s == "-0.0000" else s


def fmt_minus(a, b):
    """ASCII subtraction typography: 0.2000-(-2.0000), never 0.2000--2.0000."""
    right = num(b)
    if right.startswith("-"):
        return f"{num(a)}-({right})"
    return f"{num(a)}-{right}"


def sign_note(diffs, m):
    n = len(diffs)
    opp = sum(1 for d in diffs if d * m < 0)
    zero = sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


def fmt_mean(xs):
    m, s = mean_sd(xs)
    return fmt_pair(m, s)


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return (
            f"{fmt_pair(m, s)}: numerically zero (floating-point residue), "
            "effectively a tie"
        )
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < SMALL_FRAC * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def soft_clamp(u):
    return max(-V_LIM, min(V_LIM, u))


def noise_stream(seed, n_steps):
    """One current-noise sequence per seed, reused by every arm (CRN)."""
    rng = random.Random(seed)
    return [(rng.gauss(0.0, NOISE_I), rng.gauss(0.0, NOISE_I)) for _ in range(n_steps)]


def run_arm(arm, noise, v, iq_of_t, total, metric_start):
    n = int(round(total / DT))
    metric_i0 = int(round(metric_start / DT))
    v_e = N_PP * v
    u_bemf = K_E * v
    id_p = 0.0
    iq_p = 0.0
    int_d = 0.0
    int_q = 0.0
    s_id = 0.0
    s_iq = 0.0
    n_m = 0
    sat = 0
    for k in range(n):
        t = k * DT
        iq_ref = iq_of_t(t)
        n_d, n_q = noise[k]
        id_hat = id_p + n_d
        iq_hat = iq_p + n_q
        err_d = ID_REF - id_hat
        err_q = iq_ref - iq_hat
        if arm == "ALT":
            pi_d = 0.0
            pi_q = 0.0
        else:
            int_d += err_d * DT  # no anti-windup (omitted)
            int_q += err_q * DT
            pi_d = KP_D * err_d + KI_D * int_d
            pi_q = KP_Q * err_q + KI_Q * int_q
        # Unhatted i_d, i_q in the opened feedforward are the references.
        ff_d = -L_Q * iq_ref * v_e
        ff_q = L_D * ID_REF * v_e
        if arm == "A":
            ud, uq = pi_d, pi_q
        elif arm == "B":
            ud, uq = pi_d + ff_d, pi_q + ff_q
        elif arm == "C":
            ud, uq = pi_d - ff_d, pi_q + ff_q
        elif arm == "ALT":
            ud, uq = ff_d, R * iq_ref + u_bemf
        else:
            raise ValueError(arm)
        ud_c = soft_clamp(ud)
        uq_c = soft_clamp(uq)
        if ud_c != ud or uq_c != uq:
            sat += 1
        did = (ud_c - R * id_p + v_e * L_Q * iq_p) / L_D
        diq = (uq_c - R * iq_p - v_e * L_D * id_p - u_bemf) / L_Q
        id_p += did * DT
        iq_p += diq * DT
        if k >= metric_i0:
            s_id += (id_p - ID_REF) ** 2
            s_iq += (iq_p - iq_ref) ** 2
            n_m += 1
    return {
        "id_rmse": math.sqrt(s_id / n_m),
        "iq_rmse": math.sqrt(s_iq / n_m),
        "sat": float(sat),
        "n_m": n_m,
    }


def collect(arm, v, iq_of_t, total, metric_start):
    n = int(round(total / DT))
    rows = []
    for seed in SEEDS:
        noise = noise_stream(seed, n)
        rows.append(run_arm(arm, noise, v, iq_of_t, total, metric_start))
    return rows


def print_arm_means(label, rows):
    print(
        f"{label} id_rmse={fmt_mean([r['id_rmse'] for r in rows])} "
        f"iq_rmse={fmt_mean([r['iq_rmse'] for r in rows])} "
        f"sat_hits={fmt_mean([r['sat'] for r in rows])}"
    )


def print_regime(name, expectation, v, iq_of_t, total, metric_start, extra_lines):
    print(f"regime {name}")
    print(expectation)
    for line in extra_lines:
        print(line)
    series = {}
    for arm in ("A", "B", "C", "ALT"):
        series[arm] = collect(arm, v, iq_of_t, total, metric_start)
        label = "ALT_VOLTAGE_MODE_LAG" if arm == "ALT" else arm
        print_arm_means(label, series[arm])
    print("adopted=B not_adopted=ALT_VOLTAGE_MODE_LAG")
    for key in ("id_rmse", "iq_rmse"):
        xs = {arm: [r[key] for r in series[arm]] for arm in series}
        print(f"paired B-A {key}: {verdict(xs['B'], xs['A'])}")

            f"paired ALT-B {key}: {verdict(xs['ALT'], xs['B'])} (not adopted)"
        )
```
