## Why a desktop arm still needs a power plan

When six bus servos stall together, peak current is not "one servo × 6" in isolation — wire resistance pulls the voltage at the load down while the logic board still wants a steady 5 V / 3.3 V. Month 2 already showed "battery sags → open-loop speed changes"; here we turn that into a checklist you can compute.

Three hard EMC rules (summarised from Novanta / Roboteq / ARK wiring guides; not measured here):

1. **Keep motor phase leads away from encoder / I2C.** Fast current edges are noise sources; separate runs, cross at ~90° when they must meet.
2. **Single-point common ground.** Star the logic and motor grounds near the supply entry so large currents do not return through signal loops.
3. **Distinguish four "grounds" and terminate shields by device spec — no one rule for every cable.** Signal ground (GND_D), power return (GND_P / VBAT−), chassis·PE, and the cable shield are different conductors. For Ethernet / EtherCAT (100Base-Tx) and other HF shields, terminate a continuous low-impedance shield path at **both ends** so shield current can flow; **do not use GND_D as the shield return** (that dumps noise onto the logic reference). Single-ended grounding is only for specific low-frequency schemes, and only when the device manual says so — do not generalise "source-end ground" to every cable.

## Battery packs: read only, do not open

Series raises voltage; parallel raises capacity; C-rate says how much continuous / pulse current the cell can deliver. The BMS cuts on over-discharge, over-current and short — **this lesson does not teach BMS parameter changes or pack teardown**. Bench habits:

- Li-ion uses its own charger; do not "just top it up" on a bench supply.
- Stay present while charging; stop on swelling, smell or heat.
- E-stop cuts the motor bus, not only logic (see [8.5 safety & reliability](/en/month/month-8/safety-reliability)).

## Power-budget toy (one-way)

`power_budget_toy.py` uses a fixed seed and illustrative currents: 6 servos, 0.35 A idle, 1.8 A peak, 12 V nominal, 0.8 m × 50 mΩ/m wire, 10 A fuse. It prints totals, **one-way** peak drop, voltage at the load, the raw fuse/peak ratio, and whether the 11 V floor still holds. `fuse_margin` is a ratio only — **not** a "fuse is suitable" conclusion.

```python
#!/usr/bin/env python3
"""power_budget_toy.py: IR drop and fuse margin for a desktop-arm bus (stdlib).

Illustrative SO-101-like bus-servo currents — NOT measured on this site.
Fixed seed for reproducibility; change n_servos / wire length to explore.
"""
SEED = 5
# SO-101-like bus servos: illustrative currents, not measured
V_nom = 12.0
I_idle = 0.35  # A per servo idle
I_peak = 1.8   # A stall-ish peak
n_servos = 6
wire_mohm_per_m = 50.0  # 22 AWG ballpark illustrative
wire_len_m = 0.8
fuse_A = 10.0
V_floor = 11.0

R = wire_mohm_per_m * 1e-3 * wire_len_m
I_total_peak = n_servos * I_peak
I_total_idle = n_servos * I_idle
V_drop = I_total_peak * R
V_at_load = V_nom - V_drop
margin = fuse_A / I_total_peak

print(f"seed={SEED}")
print(f"V_nom={V_nom:.1f}")
print(f"n_servos={n_servos}")
print(f"I_idle_total={I_total_idle:.2f}")
print(f"I_peak_total={I_total_peak:.2f}")
print(f"wire_R_ohm={R:.4f}")
print(f"V_drop_peak={V_drop:.3f}")
print(f"V_at_load={V_at_load:.3f}")
print(f"fuse_A={fuse_A:.1f}")
print(f"fuse_margin={margin:.3f}")
print(f"pass_11v_floor={str(V_at_load >= V_floor).lower()}")
```

## Round-trip drop, I²R, and fuse data gates

`power_roundtrip_loss_toy.py` compares, on the same illustrative currents:

1. **One-way vs round-trip** drop (R_go + R_ret; symmetric return = 2× one-way).
2. **I²R** wire loss at idle and peak — thermal **hygiene**, not winding MTPA.
3. **Protection status**: missing manufacturer time–current / DC interrupt / fault current → `insufficient_data` by default; `reject_known_constraint` only when an **explicitly supplied** numeric constraint is violated (e.g. `V_at_load < V_floor`, or `I_continuous > wire_ampacity`). **Never** emits `ok_slow_blow`.

Before choosing a fuse you must obtain at least: DC voltage rating, interrupting capacity (DC vs AC), wire ampacity + derating, prospective fault current, manufacturer time–current / I²t, and inrush shape. This lesson does **not** ship those curves; the toy is not a certification; swapping a fuse is 本页未运行.

```python
#!/usr/bin/env python3
"""power_roundtrip_loss_toy.py: round-trip IR drop, I^2R loss, fuse data gates (stdlib).

Illustrative SO-101-like bus-servo currents — NOT measured on this site.
Protection outcomes are ONLY insufficient_data or reject_known_constraint.
Never emits ok_slow_blow / "suitable fuse" from a peak-current ratio alone.
Real fuse selection needs DC voltage rating, interrupt capacity, wire ampacity
+ derating, prospective fault current, and manufacturer time-current / I^2t —
none of which this toy ships.
"""
SEED = 7

# Illustrative currents / geometry (labelled not measured)
V_nom = 12.0
I_idle = 0.35   # A per servo
I_peak = 1.8    # A stall-ish peak
n_servos = 6
wire_mohm_per_m = 50.0  # 22 AWG ballpark illustrative
# Two lengths under equal current — voltage constraint only
len_short_m = 0.8
len_long_m = 1.5
V_floor = 11.0
# Illustrative continuous ampacity input for the reject demo (not a datasheet claim)
wire_ampacity_A = 8.0  # deliberately below peak total for reject_known_constraint arm

I_peak_total = n_servos * I_peak
I_idle_total = n_servos * I_idle


def one_way_R(length_m):
    return wire_mohm_per_m * 1e-3 * length_m


def round_trip_drop(I, length_m):
    # Go + return: R_go + R_ret with symmetric return
    R_rt = 2.0 * one_way_R(length_m)
    return I * R_rt, R_rt


def i2r_loss(I, R):
    return I * I * R


def protection_status(*, v_at_load=None, v_floor=None, i_continuous=None, wire_ampacity=None,
                      have_fuse_curve=False, have_dc_interrupt=False, have_fault_current=False):
    """Data-gated protection literacy. Never certifies a fuse as suitable."""
    if v_at_load is not None and v_floor is not None and v_at_load < v_floor:
        return "reject_known_constraint"
    if (i_continuous is not None and wire_ampacity is not None
            and i_continuous > wire_ampacity):
        return "reject_known_constraint"
    # Missing manufacturer fuse curve / DC interrupt / fault current → cannot certify
    if not (have_fuse_curve and have_dc_interrupt and have_fault_current):
        return "insufficient_data"
    # Even with flags, this course never ships curves — unreachable by design.
    return "insufficient_data"


# --- Run A: short wire, default (no fuse datasheet fields) ---
drop_short, R_rt_short = round_trip_drop(I_peak_total, len_short_m)
V_load_short = V_nom - drop_short
P_idle_short = i2r_loss(I_idle_total, R_rt_short)
P_peak_short = i2r_loss(I_peak_total, R_rt_short)
# one-way for comparison with power_budget_toy
R_ow_short = one_way_R(len_short_m)
drop_ow_short = I_peak_total * R_ow_short
status_default = protection_status()  # missing all fuse fields

# --- Run B: long wire, same peak current — voltage floor only ---
drop_long, R_rt_long = round_trip_drop(I_peak_total, len_long_m)
V_load_long = V_nom - drop_long
status_long_v = protection_status(v_at_load=V_load_long, v_floor=V_floor)

# --- Run C: continuous current vs illustrative ampacity (reject) ---
status_ampacity = protection_status(
    i_continuous=I_peak_total, wire_ampacity=wire_ampacity_A
)

# Which length hits V_floor first (voltage constraint only; equal I)
hits_floor_first = "long" if V_load_long < V_floor and V_load_short >= V_floor else (
    "short" if V_load_short < V_floor else "neither"
)

# Sanity: never emit ok_* 
assert status_default == "insufficient_data"
assert "ok" not in status_default and "ok" not in status_long_v and "ok" not in status_ampacity

print(f"seed={SEED}")
print(f"V_nom={V_nom:.1f}")
print(f"n_servos={n_servos}")
print(f"I_idle_total={I_idle_total:.2f}")
print(f"I_peak_total={I_peak_total:.2f}")
print(f"len_short_m={len_short_m:.1f}")
print(f"len_long_m={len_long_m:.1f}")
print(f"R_oneway_short_ohm={R_ow_short:.4f}")
print(f"R_roundtrip_short_ohm={R_rt_short:.4f}")
print(f"V_drop_oneway_short={drop_ow_short:.3f}")
print(f"V_drop_roundtrip_short={drop_short:.3f}")
print(f"V_at_load_roundtrip_short={V_load_short:.3f}")
print(f"P_i2r_idle_short_W={P_idle_short:.4f}")
print(f"P_i2r_peak_short_W={P_peak_short:.4f}")
print(f"V_drop_roundtrip_long={drop_long:.3f}")
print(f"V_at_load_roundtrip_long={V_load_long:.3f}")
print(f"V_floor={V_floor:.1f}")
print(f"hits_V_floor_first={hits_floor_first}")
print(f"protection_status_default={status_default}")
print(f"protection_status_long_wire={status_long_v}")
print(f"protection_status_ampacity={status_ampacity}")
print(f"wire_ampacity_A={wire_ampacity_A:.1f}")
print("fuse_certification=never")  # explicit: toy never certifies
```

## Mapping back to SO-101

Bus servos (e.g. STS3215) share the motor rail and a TTL bus. Logic 5 V often comes from an on-board LDO or a separate rail: when the motor bus sags, logic needs its own decoupling — do not expect "one fat wire" to keep both sides happy. Retune `n_servos`, `I_peak`, `wire_len_m` to your assumptions, re-run, and put the numbers on your power checklist — alongside a fuse datasheet checklist, not a single fuse_margin figure.
