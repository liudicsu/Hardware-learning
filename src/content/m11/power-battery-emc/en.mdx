## Why a desktop arm still needs a power plan

When six bus servos stall together, peak current is not "one servo × 6" in isolation — wire resistance pulls the voltage at the load down while the logic board still wants a steady 5 V / 3.3 V. Month 2 already showed "battery sags → open-loop speed changes"; here we turn that into a checklist you can compute.

Three hard EMC rules (summarised from Novanta / Roboteq / ARK wiring guides; not measured here):

1. **Keep motor phase leads away from encoder / I2C.** Fast current edges are noise sources; separate runs, cross at ~90° when they must meet.
2. **Single-point common ground.** Star the logic and motor grounds near the supply entry so large currents do not return through signal loops.
3. **Distinguish four "grounds" and terminate shields by device spec — no one rule for every cable.** Signal ground (GND_D), power return (GND_P / VBAT−), chassis·PE, and the cable shield are different conductors. For Ethernet / EtherCAT (100Base-Tx) and other HF shields, terminate a continuous low-impedance shield path at **both ends** so shield current can flow; **do not use GND_D as the shield return** (that dumps noise onto the logic reference). Single-ended grounding is only for specific low-frequency schemes, and only when the device manual says so — do not generalise "source-end ground" to every cable.

## Battery packs: read only, do not open

Series raises voltage; parallel raises capacity; C-rate says how much continuous / pulse current the cell can deliver. The BMS cuts on over-discharge, over-current and short — **this lesson does not teach BMS parameter changes or pack teardown**. Bench habits:

- Li-ion uses its own charger; do not "just top it up" on a bench supply.
- Stay present while charging; stop on swelling, smell or heat.
- E-stop cuts the motor bus, not only logic (see [8.5 safety & reliability](/en/month/month-8/safety-reliability)).

## Round-trip drop, I²R, and fuse data gates

`power_roundtrip_loss_toy.py` compares, on the same illustrative currents:

1. **One-way vs round-trip** drop (R_go + R_ret; symmetric return = 2× one-way).
2. **I²R** wire loss at idle and peak — thermal **hygiene**, not winding MTPA.
3. **Continuous vs peak are independent**: `I_cont_total` (0.55 A × 6 = 3.30 A) and `I_peak_total` (1.8 A × 6 = 10.80 A) are two example assumptions; the ampacity gate uses continuous only — never pretend peak is continuous.
4. **Protection status**: missing manufacturer time–current / DC interrupt / fault current → `insufficient_data` by default; `reject_known_constraint` only when an **explicitly supplied** numeric constraint is violated (e.g. `V_at_load < V_floor`, or `I_continuous > wire_ampacity`). **Never** emits `ok_slow_blow`.

Before choosing a fuse you must obtain at least: DC voltage rating, interrupting capacity (DC vs AC), wire ampacity + derating, prospective fault current, manufacturer time–current / I²t, and inrush shape. This lesson does **not** ship those curves; the toy is not a certification; swapping a fuse is 本页未运行.

```python
#!/usr/bin/env python3
"""power_roundtrip_loss_toy.py: round-trip IR drop, I^2R loss, fuse data gates (stdlib).

Illustrative SO-101-like bus-servo currents — NOT measured on this site.
Continuous and peak currents are INDEPENDENT example assumptions (do not
pretend peak is continuous). Ampacity gate uses continuous only; peak without
a time–current / I^2t curve stays insufficient_data.
Protection outcomes are ONLY insufficient_data or reject_known_constraint.
Never emits ok_slow_blow / "suitable fuse" from a peak-current ratio alone.
"""
SEED = 7

# Illustrative currents / geometry (labelled not measured)
V_nom = 12.0
I_idle = 0.35    # A per servo idle (example assumption)
I_cont = 0.55    # A per servo continuous under load (example assumption; NOT peak)
I_peak = 1.8     # A stall-ish peak (example assumption; duration unknown)
n_servos = 6
wire_mohm_per_m = 50.0  # 22 AWG ballpark illustrative
len_short_m = 0.8
len_long_m = 1.5
V_floor = 11.0
# Illustrative continuous ampacity — deliberately below I_cont_total for reject demo
wire_ampacity_A = 3.0

I_idle_total = n_servos * I_idle
I_cont_total = n_servos * I_cont   # continuous — used for ampacity gate
I_peak_total = n_servos * I_peak   # peak — NOT passed as continuous


def one_way_R(length_m):
    return wire_mohm_per_m * 1e-3 * length_m


def round_trip_drop(I, length_m):
    R_rt = 2.0 * one_way_R(length_m)
    return I * R_rt, R_rt


def i2r_loss(I, R):
    return I * I * R


def protection_status(*, v_at_load=None, v_floor=None, i_continuous=None, wire_ampacity=None,
                      have_fuse_curve=False, have_dc_interrupt=False, have_fault_current=False):
    """Data-gated protection literacy. Never certifies a fuse as suitable."""
    if v_at_load is not None and v_floor is not None and v_at_load < v_floor:
        return "reject_known_constraint"
    if (i_continuous is not None and wire_ampacity is not None
            and i_continuous > wire_ampacity):
        return "reject_known_constraint"
    if not (have_fuse_curve and have_dc_interrupt and have_fault_current):
        return "insufficient_data"
    return "insufficient_data"


def undervoltage_label(v_short, v_long, v_floor):
    short_uv = v_short < v_floor
    long_uv = v_long < v_floor
    if short_uv and long_uv:
        return "both"
    if long_uv:
        return "long_only"
    if short_uv:
        return "short_only"
    return "neither"


# Round-trip IR / I^2R at peak (thermal hygiene numbers); idle I^2R for contrast
drop_short, R_rt_short = round_trip_drop(I_peak_total, len_short_m)
V_load_short = V_nom - drop_short
P_idle_short = i2r_loss(I_idle_total, R_rt_short)
P_peak_short = i2r_loss(I_peak_total, R_rt_short)
R_ow_short = one_way_R(len_short_m)
drop_ow_short = I_peak_total * R_ow_short

drop_long, R_rt_long = round_trip_drop(I_peak_total, len_long_m)
V_load_long = V_nom - drop_long

status_default = protection_status()  # missing fuse datasheet fields
status_long_v = protection_status(v_at_load=V_load_long, v_floor=V_floor)
# Ampacity gate uses CONTINUOUS only — never I_peak_total as i_continuous
status_ampacity = protection_status(
    i_continuous=I_cont_total, wire_ampacity=wire_ampacity_A
)
# Peak alone without curve/duration → still insufficient_data
status_peak_only = protection_status()  # same missing fields; peak not a reject input

hits_V_floor = undervoltage_label(V_load_short, V_load_long, V_floor)

assert status_default == "insufficient_data"
assert status_peak_only == "insufficient_data"
assert status_ampacity == "reject_known_constraint"
assert "ok" not in status_default
assert I_cont_total != I_peak_total

print(f"seed={SEED}")
print(f"V_nom={V_nom:.1f}")
print(f"n_servos={n_servos}")
print(f"I_idle_total={I_idle_total:.2f}")
print(f"I_cont_total={I_cont_total:.2f}")  # continuous example assumption
print(f"I_peak_total={I_peak_total:.2f}")  # peak example assumption (not continuous)
print(f"len_short_m={len_short_m:.1f}")
print(f"len_long_m={len_long_m:.1f}")
print(f"R_oneway_short_ohm={R_ow_short:.4f}")
print(f"R_roundtrip_short_ohm={R_rt_short:.4f}")
print(f"V_drop_oneway_short={drop_ow_short:.3f}")
print(f"V_drop_roundtrip_short={drop_short:.3f}")
print(f"V_at_load_roundtrip_short={V_load_short:.3f}")
print(f"P_i2r_idle_short_W={P_idle_short:.4f}")
print(f"P_i2r_peak_short_W={P_peak_short:.4f}")
print(f"V_drop_roundtrip_long={drop_long:.3f}")
print(f"V_at_load_roundtrip_long={V_load_long:.3f}")
print(f"V_floor={V_floor:.1f}")
print(f"hits_V_floor={hits_V_floor}")
print(f"protection_status_default={status_default}")
print(f"protection_status_long_wire={status_long_v}")
print(f"protection_status_ampacity={status_ampacity}")
print(f"protection_status_peak_only={status_peak_only}")
print(f"wire_ampacity_A={wire_ampacity_A:.1f}")
print("currents_labelled=example_assumptions")
print("fuse_certification=never")
```

## Coulomb-counting SoC and a lesson-defined thermal derate

The earlier toys budget **voltage drop** and refuse to certify a fuse. They still leave the **state of charge** story as "read the C-rate, do not open the pack." This section adds a read-only SoC integrator and a temperature derate — still **no** BMS flash, **no** pack teardown, **no** charging procedure.

### Sign convention and η only on charge

Fixed for this lesson (and printed by the toy):

- `I > 0` — **discharge** (SoC falls)
- `I < 0` — **charge** (SoC rises)
- Coulombic efficiency `η` applies **only on charge**. Discharge uses `η = 1`.

<Formula label="Coulomb count">SoC_(k+1) = SoC_k − η_eff(I_k)·I_k·Δt / Q</Formula>

Four estimators share **one** current profile (discharge → rest → charge → higher discharge):

| Arm | What is wrong |
|---|---|
| `ideal` | nothing — truth reference |
| `shunt_bias` | measured current = I + 0.05 A |
| `q_error` | capacity Q̂ = 0.92 Q |
| `soc0_error` | started 5 points low |

A constant shunt bias makes SoC error grow **~linearly in time** under a non-zero mean current (slope ≈ −bias / Q on discharge). Capacity error and initial-SoC error are separate axes — do not fold them into "the battery drifted." **OCV rest re-anchoring** is named as a concept only: this page does **not** invent an OCV–SoC curve as a datasheet.

### Lesson-defined continuous derate

`I_allow(T) = I_cont_nom · max(0, 1 − K·max(0, T − T_ref))` with lesson-chosen `I_cont_nom`, `K`, `T_ref`. When `|I|` exceeds `I_allow` the toy raises `derate`. Numbers are **not** a cell datasheet. Real LiPo / BMS / thermal chamber: 本页未运行 (not run on this page).

```python
#!/usr/bin/env python3
"""soc_coulomb_thermal_toy.py: coulomb-counting SoC drift + thermal derate (stdlib).

Sign convention (stated, fixed for this toy):
  I > 0  discharge (SoC falls)
  I < 0  charge    (SoC rises)
Coulombic efficiency η applies ONLY on charge (I < 0). Discharge uses η = 1.
Integrator (discrete, Δt seconds):
  SoC_{k+1} = SoC_k - η_eff(I_k) * I_k * Δt / Q
  η_eff = η if I_k < 0 else 1.0

Four estimators share ONE current profile (same I[k] sequence):
  ideal          true I, true Q, true SoC0
  shunt_bias     I_meas = I + BIAS_A  (constant current-shunt offset)
  q_error        Q_hat = Q * Q_SCALE   (capacity mis-estimate)
  soc0_error     SoC_hat0 = SoC0 + SOC0_BIAS

Truth SoC uses ideal parameters. Drift from a constant shunt bias grows
~linearly in time under a non-zero mean current. Capacity and initial-SoC
errors are separate sources; OCV rest re-anchoring is named as a concept
only (no OCV curve is invented as a datasheet).

Thermal hygiene: lesson-defined continuous derate
  I_allow(T) = I_cont_nom * max(0, 1 - K_DERATE * max(0, T - T_REF))
A derate_flag rises when |I| would exceed I_allow at the current T proxy.
Not a fuel-gauge IC; not a BMS flash; no charging procedure taught.
Real LiPo / BMS / thermal chamber: 本页未运行.
usage: python3 soc_coulomb_thermal_toy.py
"""
from __future__ import annotations

SEED = 41
DT = 1.0                 # s
N = 600                  # 10 min profile
Q_AS = 3600.0            # 1 A·h in ampere-seconds
ETA_CHARGE = 0.98        # coulombic efficiency on charge only
SOC0 = 0.80
BIAS_A = 0.05            # shunt offset (A), discharge-positive convention
Q_SCALE = 0.92           # capacity underestimated by 8 %
SOC0_BIAS = -0.05        # started 5 points low
I_CONT_NOM = 2.5         # A continuous rating at T_REF (lesson-defined)
T_REF = 25.0             # °C
K_DERATE = 0.02          # per °C above T_REF (lesson-defined curve)
T_COOL = 0.01            # 1/s cool toward T_REF
T0 = 27.0                # start temperature proxy °C
T_RISE_PER_W = 0.004     # toy thermal rise vs |I|*V_nom proxy
V_NOM = 14.8             # V, example assumption only


def eta_eff(i: float) -> float:
    return ETA_CHARGE if i < 0.0 else 1.0


def current_profile() -> list[float]:
    """Shared profile: discharge, rest, charge, discharge. Fixed, not random."""
    i: list[float] = []
    # 0..199: discharge 1.5 A
    i += [1.5] * 200
    # 200..249: rest
    i += [0.0] * 50
    # 250..399: charge -1.0 A
    i += [-1.0] * 150
    # 400..599: discharge 2.2 A (will trip derate as T rises)
    i += [2.2] * 200
    assert len(i) == N
    return i


def integrate(i_seq: list[float], q: float, soc0: float) -> list[float]:
    soc = soc0
    out = [soc]
    for i in i_seq:
        soc = soc - eta_eff(i) * i * DT / q
        # clip only for display sanity; estimators do not "know" 0/1 walls
        # differently — clip after record so error stays visible
        out.append(max(0.0, min(1.0, soc)))
        soc = out[-1]
    return out  # length N+1


def thermal_series(i_seq: list[float]) -> tuple[list[float], list[bool]]:
    t = T0
    temps: list[float] = []
    flags: list[bool] = []
    for i in i_seq:
        # Lesson-defined proxy: heat ~ |I| * V_nom; cool toward T_REF.
        # Not a cell datasheet; numbers are lesson-chosen.
        t = t + T_RISE_PER_W * abs(i) * V_NOM * DT - T_COOL * (t - T_REF) * DT
        i_allow = I_CONT_NOM * max(0.0, 1.0 - K_DERATE * max(0.0, t - T_REF))
        temps.append(t)
        flags.append(abs(i) > i_allow + 1e-12)
    return temps, flags


def main() -> None:
    i_true = current_profile()
    soc_true = integrate(i_true, Q_AS, SOC0)

    i_bias = [i + BIAS_A for i in i_true]
    soc_bias = integrate(i_bias, Q_AS, SOC0)
    soc_q = integrate(i_true, Q_AS * Q_SCALE, SOC0)
    soc_s0 = integrate(i_true, Q_AS, SOC0 + SOC0_BIAS)

    temps, derate = thermal_series(i_true)

    def err(est: list[float]) -> list[float]:
        return [a - b for a, b in zip(est, soc_true)]

    e_bias, e_q, e_s0 = err(soc_bias), err(soc_q), err(soc_s0)

    # Report at a few anchors + end
    anchors = [0, 200, 250, 400, N]
    print(f"seed={SEED}")
    print("sign: I>0 discharge, I<0 charge; eta applies only on charge")
    print(f"eta_charge={ETA_CHARGE} Q_As={Q_AS:.1f} SoC0={SOC0:.2f} dt={DT}")
    print(f"shunt_bias_A={BIAS_A} Q_scale={Q_SCALE} SoC0_bias={SOC0_BIAS}")
    print("same current profile for all arms")
    print("t_s  SoC_true  err_shunt  err_Q  err_SoC0  T_C  derate")
    for t in anchors:
        print(
            f"{t:4d}  {soc_true[t]:8.4f}  {e_bias[t]:+8.4f}  {e_q[t]:+7.4f}  "
            f"{e_s0[t]:+8.4f}  {temps[t-1] if t else T0:5.2f}  "
            f"{int(derate[t-1]) if t else 0}"
        )

    # Linear-growth check for shunt bias over the first discharge block (mean I > 0)
    # Expected rough slope ≈ -BIAS_A / Q  (SoC/s) under discharge with eta=1
    slope_est = (e_bias[200] - e_bias[0]) / 200.0
    slope_theory = -BIAS_A / Q_AS
    print(f"shunt_err_slope_per_s={slope_est:+.6e}  theory_neg_bias_over_Q={slope_theory:+.6e}")
    print(f"final_err_shunt={e_bias[N]:+.4f} final_err_Q={e_q[N]:+.4f} final_err_SoC0={e_s0[N]:+.4f}")
    print(f"derate_ticks={sum(derate)}/{N}  T_final_C={temps[-1]:.2f}")
    print("OCV rest re-anchor: concept only (no OCV curve / datasheet invented here)")
    print("not a fuel-gauge IC; no charging procedure; LiPo/BMS/thermal chamber 本页未运行")
    # Assertions for CI-style honesty
    assert abs(slope_est - slope_theory) < 5e-7, (slope_est, slope_theory)
    assert abs(e_s0[0] - SOC0_BIAS) < 1e-12
    assert e_q[0] == 0.0
    assert sum(derate) > 0
    print("ok: shared profile; shunt drift ~linear; Q and SoC0 errors separated; derate fires")


if __name__ == "__main__":
    main()
```

## Mapping back to SO-101

Bus servos (e.g. STS3215) share the motor rail and a TTL bus. Logic 5 V often comes from an on-board LDO or a separate rail: when the motor bus sags, logic needs its own decoupling — do not expect "one fat wire" to keep both sides happy. Retune `n_servos`, `I_peak`, `wire_len_m` to your assumptions, re-run, and put the numbers on your power checklist — alongside a fuse datasheet checklist, not a single fuse_margin figure.

**Takeaways**

- Separate logic and motor buses; single-point star ground.
- One-way toy: peak 10.80 A, drop 0.432 V, load 11.568 V; fuse_margin 0.926 is a ratio only.
- Round-trip toy: short load 11.136 V, long 10.380 V is long_only; peak I²R 9.3312 W; default `insufficient_data`.

**Common mistakes**

- Tying logic ground into the middle of a motor return.
- Running encoder leads parallel to phase leads for a long run.
- "Just topping up" Li-ion on a bench supply.
- Writing "slow-blow is fine" from I_fuse / I_peak alone.
