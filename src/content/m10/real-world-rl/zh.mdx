## 为什么真机械臂是很难的 RL 环境

7.3 在仿真里训练：复位免费，一百万步只是一杯咖啡的时间。换成真机械臂：

- **奖励是稀疏的。** 「零件进槽了」容易判断却难以塑形；稠密的塑形奖励容易引出 reward hacking（7.2）。
- **每次失败都要复位。** 得有人重新摆好场景。首次成功前要失败几千次的学习器不可用。
- **探索必须安全。** 随机动作会撞东西；8.5 的限位用来约束动作空间。
- **以小时计，不是以天计。** 预算是几小时的机器人时间，所以每条转移都要被反复使用：用带回放缓冲区的离策略 RL，而不是在策略的 PPO。

## RLPD：每个批次都放离线数据

RLPD（Ball 等，2023）研究的是：不做预训练，如何在 SAC 这类普通离策略学习器里用上一小份离线数据（示范）。配方有三部分：

- <Term id="symmetric-sampling">对称采样</Term>：每个训练批次 50 % 来自离线缓冲区、50 % 来自在线回放缓冲区。论文发现这比开始时把离线数据直接放进回放缓冲区更好，而且具体比例不太敏感。
- **critic 里加 LayerNorm**，限制 Q 值向数据没覆盖到的动作外推的幅度。
- **样本效率技巧**：较大的 critic 集成，以及每个环境步做多次梯度更新（较高的更新/数据比）。

摘要报告在多类基准上比以往方法最多提升 2.5×；这是论文的测量，本页未运行。

## HIL-SERL：RLPD 加上真机旁的人

HIL-SERL（Luo 等，2024）建立在 RLPD 之上，补上真机需要的部分：

- **少量示范**（论文里 20–30 条）放在单独的缓冲区；学习器从示范缓冲区和 RL 缓冲区等量采样。
- **<Term id="reward-classifier">奖励分类器</Term>** 代替手写奖励：在成功 / 失败帧上训练的小型图像分类器（论文用约 200 张正样本、1000 张负样本，约 5 分钟采完，报告准确率超过 95 %）。它把「成功了吗？」变成二值奖励和回合结束信号。
- **训练中的人工介入**，用 SpaceMouse。介入产生的转移同时进两个缓冲区；策略自己的转移只进 RL 缓冲区。论文提醒：长时间、稀疏地把任务一路接管到成功，会让 critic 高估价值——纠正一下就交还。
- **工程部分**：末端坐标系下的有界动作、阻抗控制器、预训练视觉骨干网络，以及 actor–learner 分离，让机器人在学习器更新时继续动作。

论文报告的结果（论文的测量，本页未运行）：几乎所有任务的训练时间为 1 到 2.5 小时；与用相当数据训练的模仿学习基线相比，成功率平均约提升 2×，节拍时间约快 1.8×。在其消融实验中，既无示范又无介入的从零训练成功率为 0 %。

```python
"""rlpd_chain_toy.py: why a few demos plus 50/50 sampling make sparse-reward RL possible (stdlib).

A 10-state "combination lock" chain stands in for a real-robot task:
- states 0..9, start at 0, goal is state 9;
- in every state one of two actions is right (fixed per state); the right one
  moves forward, the wrong one sends you back to 0 (think: the part slipped,
  someone resets the scene);
- reward is 1 only on reaching the goal, 0 everywhere else; at most 30 steps
  per episode, 40 episodes per run.

Three tabular Q-learning learners share the same replay update (8 sampled
transitions per environment step, epsilon-greedy with epsilon 0.1):
  online    online replay only, no demos
  one_buf   3 demos dumped into the same buffer as online data (uniform
            sampling, so the demos get diluted as online data piles up)
  rlpd_5050 3 demos in their own buffer, every sample is a coin flip between
            the demo buffer and the online buffer (RLPD's symmetric sampling)

20 seeds each. Reported: how many seeds ever reached the goal while
training, mean episode of the first success, how many resets the learner
caused (each one is a human walking over on a real robot), greedy success at
the end, and what share of the last episode's samples came from demos.
No neural nets, no ensembles, no LayerNorm: only the data-mixing idea.
"""

import random

N = 10            # states 0..9, goal = N - 1
H = 30            # steps per episode
EPISODES = 40
SEEDS = 20
ALPHA = 0.5
GAMMA = 0.9
EPS = 0.1
UPDATES = 8       # sampled Q updates per environment step
DEMOS = 3
LOCK_SEED = 7     # the "right" action per state is the same for every run


def make_lock():
    r = random.Random(LOCK_SEED)
    return [r.randrange(2) for _ in range(N - 1)]


LOCK = make_lock()


def step(s, a):
    """Return (next_state, reward, done)."""
    if a != LOCK[s]:
        return 0, 0.0, False          # wrong action: back to the start
    s2 = s + 1
    if s2 == N - 1:
        return s2, 1.0, True
    return s2, 0.0, False


def demo_transitions():
    out = []
    for _ in range(DEMOS):
        s = 0
        while True:
            a = LOCK[s]
            s2, r, done = step(s, a)
            out.append((s, a, r, s2, done))
            if done:
                break
            s = s2
    return out


def act(q, s, rng, eps):
    if rng.random() < eps or q[s][0] == q[s][1]:
        return rng.randrange(2)
    return 0 if q[s][0] > q[s][1] else 1


def update(q, t):
    s, a, r, s2, done = t
    target = r if done else r + GAMMA * max(q[s2])
    q[s][a] += ALPHA * (target - q[s][a])


def greedy_success(q):
    s = 0
    for _ in range(H):
        a = 0 if q[s][0] >= q[s][1] else 1   # fixed tie-break, no luck
        s, _, done = step(s, a)
        if done:
            return True
    return False


def run(mode, seed):
    rng = random.Random(1000 + seed)
    q = [[0.0, 0.0] for _ in range(N)]
    demos = demo_transitions()
    online = []
    first = None
    resets = 0
    from_demo = drawn = 0
    for ep in range(1, EPISODES + 1):
        s = 0
        ep_demo = ep_drawn = 0
        for _ in range(H):
            a = act(q, s, rng, EPS)
            s2, r, done = step(s, a)
            t = (s, a, r, s2, done)
            online.append(t)
            if a != LOCK[s]:
                resets += 1
            for _ in range(UPDATES):
                if mode == "online":
                    x = online[rng.randrange(len(online))]
                    d = False
                elif mode == "one_buf":
                    i = rng.randrange(len(demos) + len(online))
                    d = i < len(demos)
                    x = demos[i] if d else online[i - len(demos)]
                else:  # rlpd_5050
                    d = rng.random() < 0.5
                    x = demos[rng.randrange(len(demos))] if d else online[rng.randrange(len(online))]
                update(q, x)
                ep_demo += d
                ep_drawn += 1
            if done:
                if first is None:
                    first = ep
                break
            s = s2
        from_demo, drawn = ep_demo, ep_drawn
    return {
        "first": first,
        "resets": resets,
        "greedy": greedy_success(q),
        "demo_share": from_demo / drawn,
        "steps": len(online),
    }


def summarize(mode):
    rs = [run(mode, k) for k in range(SEEDS)]
    hit = [r["first"] for r in rs if r["first"] is not None]
    never = SEEDS - len(hit)
    mean_first = sum(hit) / len(hit) if hit else float("nan")
    resets = sum(r["resets"] for r in rs) / SEEDS
    greedy = sum(r["greedy"] for r in rs)
    share = sum(r["demo_share"] for r in rs) / SEEDS
    steps = sum(r["steps"] for r in rs) / SEEDS
    return len(hit), never, mean_first, resets, greedy, share, steps


def main():
    print("10-state lock chain: wrong action -> back to 0, reward only at the goal")
    print(f"right actions per state: {LOCK}")
    print(f"chance a uniformly random run of 9 moves opens the lock: 1/{2 ** (N - 1)}")
    print(f"{EPISODES} episodes x <= {H} steps, {UPDATES} sampled updates per step, epsilon {EPS}, {SEEDS} seeds")
    print(f"demos: {DEMOS} x {N - 1} transitions = {DEMOS * (N - 1)} transitions")
    print()
    print("mode       reached  never  first_ep  resets/run  greedy_end  demo_share_last  env_steps/run")
    rows = {}
    for mode in ("online", "one_buf", "rlpd_5050"):
        rows[mode] = summarize(mode)
        hit, never, mf, rs, g, sh, st = rows[mode]
        print(f"{mode:<10} {hit:>4}/{SEEDS}  {never:>5}  {mf:>8.1f}  {rs:>10.1f}  {g:>7}/{SEEDS}  {100 * sh:>13.1f} %  {st:>13.1f}")
    print()
    o, b, p = rows["online"], rows["one_buf"], rows["rlpd_5050"]
    print(f"resets per run: online {o[3]:.1f} vs rlpd_5050 {p[3]:.1f} (each reset = a person re-staging the scene)")
    print(f"demo share of the last episode's samples: one_buf {100 * b[5]:.1f} %, rlpd_5050 {100 * p[5]:.1f} %")
    print("note: tabular Q never forgets, so one_buf still works here; with a neural critic the")
    print("diluted demos are what RLPD found weaker than keeping a fixed 50/50 split.")


if __name__ == "__main__":
    main()
```

## 常见错误

- **既没示范也没介入。** 奖励稀疏时学习器可能永远见不到成功；论文的从零消融停在 0 %，玩具里只用在线的学习器也有种子失败。
- **一路接管到完成任务。** 会抬高 critic 的价值估计；纠正后就交还。
- **奖励分类器被骗。** 如果它在「差一点」时也判成功，策略就学会「差一点」。把误报加进负样本重训。
- **探索不设边界。** 第一个在线回合之前就设好关节 / 末端限位（8.5）。

## 偏好：DPO 风格损失与学习奖励模型
偏好对说的是**同一上下文**下哪个候选更好，不是机器人视频进度。它不同于 [10.7 SARM / RA-BC](/zh/month/month-10/vla-rl-finetune)、Cal-ConRFT 标定、RPD 教师引导和 OneDP 蒸馏；前文 RLPD/HIL-SERL 链条仍是另一实验。Rafailov 等（2023）的 [Direct Preference Optimization](https://arxiv.org/abs/2305.18290) 从 KL 正则奖励目标及 Bradley–Terry 偏好模型推导成对目标。原论文是语言模型工作，不等于此玩具运行了 VLA 偏好训练。论文数字**以论文为准**；完整 VLA/GPU 与真机在线 RL：**本页未运行**。

### 损失与参考策略

偏好赢家 `y_w` 和输家 `y_l` 的所有概率都以 x 为条件：

<Formula label="DPO 风格偏好损失">−logσ(β[(logπ−logπref)(y_w)−(logπ−logπref)(y_l)])</Formula>

`σ(z)=1/(1+exp(−z))`。**πref 冻结**且有正支持，不是随 π 一起更新的另一策略。对数比衡量相对参考的变化，成对归一化项相消。**β** 缩放偏好 logit，对应论文奖励到策略推导中的 KL 强度；但有限步、固定学习率下，改 β 也改变梯度量级 / 饱和，不能保证 β 越大成功率越高，或实测 KL 一定单调更小。π=πref 时单对损失为 log2，不是0。线性 logit 玩具的上升更新为 `β σ(−z)(f_w−f_l)`，可执行测试用对数概率损失的有限差分核对。

### 同一语料与明确的总更新预算

全部值**合成**。上下文 x 均匀于 [−1,1]，动作 `a∈{−1,0,1}`；生成器效用 `u(x,a)=−[a−(0.85x+0.2sin4x)]²`。策略共享四特征 logit `f=(ax,a sin4x,a,a²)`，冻结参考权重 **(−0.3,0,0.2,−0.5)**，所有策略从它初始化。每种子 **11/23/37/53/71** 为各组生成相同 **64** 对候选动作。干净标签排序训练候选；**25 % 翻转概率情形**只反转固定随机子集，不改候选、上下文或评估起点。训练二元成功标签用效用差≤0.12 定义，是额外监督，不是偏好标签本身。

每组 **240 个总梯度更新槽**，全批64，学习率 **0.12**，β=**0.5**，RM+RL 的 KL 系数 τ=**0.5**。每槽使用同一上下文 / 成对批次，复用数据，不是新采240批偏好。预算按对一个四参数块的一次梯度更新计，**不是 FLOPs 或总参数量**：

| 组 | 实际目标 / 监督 | 策略 / 奖励更新 |
|---|---|---|
| 仅偏好赢家 BC | 对标签赢家做交叉熵，不用输家似然 | 240 / 0 |
| DPO | 参考相对成对损失，不显式拟合奖励 | 240 / 0 |
| 奖励模型 + RL | 先拟合 Bradley–Terry 奖励，再最大化 `Eπ[r_hat]−τ KL(π,πref)` | 120 / 120 |
| BC-all | 对两个候选平均做交叉熵 | 240 / 0 |
| success-filter | 对候选中二元成功者 BC；都失败则该对贡献零 | 240 / 0 |

<strong>不能给 RM+RL240 次奖励更新再加240 次策略更新却称等预算。</strong>120+120 的分配在评估前声明；更少策略步与独立奖励块是此固定预算比较的一部分。RL 阶段枚举三个动作，精确算学习奖励 / KL 的期望梯度，不用 PPO、环境采样交互或真实奖励 oracle。三种核心偏好组都不读二元标签；记录对所有组暴露相同字段，但 **success-filter 使用额外二元训练监督**，只是辅助基线，不表示在纯偏好信息下过滤优于偏好学习。加 BC-all 和 success-filter 是为了区分丢数据与学习成对排序。

### 留出表现与标签损坏

#!/usr/bin/env python3
"""Synthetic contextual bandit, not robot/VLA DPO or an online RL reproduction.
Five arms reconcile BC-all/success-filter literacy with the three core baselines.
Every arm receives SAME 64 training preference pairs and 240 total gradient slots.
RM+RL spends 120 slots fitting reward, then 120 on exact expected reward-minus-KL.
Binary success labels are extra TRAINING supervision for success_filter only;
all records include them but core DPO/RM/BC_preferred do not consume them.
Truth utility is used only by data generation and held-out scoring, never training.
"""
from math import exp, log, log1p, sin
from random import Random
from statistics import mean, pstdev

SEEDS=(11,23,37,53,71)
ACTIONS=(-1.,0.,1.)
REF=(-.3,0.,.2,-.5)
PAIRS, UPDATES, BETA, LR=64,240,.5,.12
ARMS=('BC_all','success_filter','BC_preferred','DPO','RM_RL')


def features(x,a):return (a*x,a*sin(4*x),a,a*a)


def dot(a,b):return sum(x*y for x,y in zip(a,b))


def probabilities(theta,x):
    scores=[dot(theta,features(x,a)) for a in ACTIONS];mx=max(scores)
    values=[exp(v-mx) for v in scores];total=sum(values)
    return tuple(v/total for v in values)


def utility(x,a):return -(a-(.85*x+.2*sin(4*x)))**2


def successful(x,a):return max(utility(x,b) for b in ACTIONS)-utility(x,a)<=.12


def make_data(seed,noise):
    rng=Random(seed);flip=Random(seed+9000);records=[]
    for _ in range(PAIRS):
        x=rng.uniform(-1,1);a,b=rng.sample(range(3),2)
        w,l=(a,b) if utility(x,ACTIONS[a])>=utility(x,ACTIONS[b]) else (b,a)
        if flip.random()<noise:w,l=l,w
        records.append((x,w,l,tuple(int(successful(x,a)) for a in ACTIONS)))
    erng=Random(seed+1000);evaluation=tuple(erng.uniform(-1,1) for _ in range(256))
    assert not set(evaluation)&{x for x,_,_,_ in records}
    return tuple(records),evaluation


def sigmoid_minus(z):
    if z>=0:
        e=exp(-z);return e/(1+e)
    return 1/(1+exp(z))


def dpo_loss(theta,x,w,l):
    p,ref=probabilities(theta,x),probabilities(REF,x)
    z=BETA*((log(p[w])-log(ref[w]))-(log(p[l])-log(ref[l])))
    return max(0.,-z)+log1p(exp(-abs(z)))


def gradient(theta,reward,records,arm,slot):
    grad=[0.]*4
    for x,w,l,success in records:
        fs=tuple(features(x,a) for a in ACTIONS)
        if arm=='DPO' or (arm=='RM_RL' and slot<UPDATES//2):
            delta=tuple(a-b for a,b in zip(fs[w],fs[l]))
            if arm=='DPO':
                z=BETA*dot(tuple(a-b for a,b in zip(theta,REF)),delta)
                g=tuple(BETA*sigmoid_minus(z)*v for v in delta)
            else:g=tuple(sigmoid_minus(dot(reward,delta))*v for v in delta)
        else:
            p=probabilities(theta,x)
            if arm=='RM_RL':
                ref=probabilities(REF,x)
                adjusted=tuple(dot(reward,f)-BETA*log(pa/pr) for f,pa,pr in zip(fs,p,ref))
                baseline=dot(p,adjusted)
                g=tuple(sum(pa*(v-baseline)*f[j] for pa,v,f in zip(p,adjusted,fs)) for j in range(4))
            else:
                candidates=(w,l) if arm=='BC_all' else ((w,) if arm=='BC_preferred' else tuple(a for a in (w,l) if success[a]))
                # Empty binary-success pairs contribute zero, but still use the same slot/batch denominator.
                g=tuple((mean(fs[a][j] for a in candidates)-sum(pa*f[j] for pa,f in zip(p,fs))) if candidates else 0. for j in range(4))
        grad=[a+b/len(records) for a,b in zip(grad,g)]
    return tuple(grad)


def train(records,arm):
    theta=REF;reward=(0.,)*4;policy_updates=reward_updates=0
    for slot in range(UPDATES):
        g=gradient(theta,reward,records,arm,slot)
        if arm=='RM_RL' and slot<UPDATES//2:
            reward=tuple(a+LR*b for a,b in zip(reward,g));reward_updates+=1
        else:
            theta=tuple(a+LR*b for a,b in zip(theta,g));policy_updates+=1
    return theta,(policy_updates,reward_updates)


def evaluate(theta,contexts):
    successes=[];regrets=[]
    for x in contexts:
        p=probabilities(theta,x);u=tuple(utility(x,a) for a in ACTIONS)
        successes.append(sum(pa*int(successful(x,a)) for pa,a in zip(p,ACTIONS)))
        regrets.append(max(u)-dot(p,u))
    return 100*mean(successes),mean(regrets)


def main():
    print('Synthetic offline bandit; seeds=11/23/37/53/71; held-out256 contexts per seed')
    print('shared64 preference pairs; total_gradient_updates=240 each; full_batch=64; lr=0.12 beta=KL_tau=0.5')
    print('RM_RL budget: reward120+policy120; others policy240; equal slots, NOT equal FLOPs/parameter counts')
    print('success_filter alone consumes extra binary TRAINING success labels; core three use preferences only')
    print('noise arm heldout_expected_success_pct_mean_sd regret_mean_sd policy_updates reward_updates')
    for noise in (0.,.25):
        cases=tuple(make_data(seed,noise) for seed in SEEDS)
        for arm in ARMS:
            trained=[train(data,arm) for data,_ in cases]
            metrics=[evaluate(theta,case[1]) for (theta,_),case in zip(trained,cases)]
            success,regret=zip(*metrics);pu,ru=trained[0][1]
            print(f'{noise:.2f} {arm} {mean(success):.4f} {pstdev(success):.4f} {mean(regret):.6f} {pstdev(regret):.6f} {pu} {ru}')
    print('Population sd across all5 seeds; exact policy expectation, no sampled rollout winner assumption')
    print('No SARM progress weights / Cal-ConRFT / RPD / OneDP; full VLA and online RL: 本页未运行')
    print('DPO paper figures: 以论文为准; this is loss/budget literacy, not a robot benchmark')


if __name__=='__main__':main()

## 先推理再行动：视觉规划潜变量（ThinkAct）

上面的 RLPD 与 HIL-SERL 用奖励改进一个策略。预训练 VLA 还会因为另一个原因失败。它把当前观测直接映射成动作，当任务的两个阶段在相机里看起来一样时，它不知道自己处在哪个阶段。**ThinkAct** 把工作拆成两半。一个多模态大模型根据指令和图像推理，写出**视觉规划潜变量**（一条很短的二维轨迹），并用从这条规划算出的奖励做强化学习训练。另一个动作模型再以这个潜变量为条件行动。本节为"规划潜变量"这个想法搭一个**合成**替身。它不是 Qwen2.5-VL，不是 GRPO 训练，也不是 DiT 策略，也不重做 CoT-VLA、MAP-VLA（10.5）或 TraceVLA。

<Resource id="thinkact-paper" />

**实际打开过的来源（经 pdftotext 读过 PDF 正文，arXiv 2507.16815 v2，cs.CV）。**

- **Huang、Wu、Chen、Wang 与 Yang，《ThinkAct: Vision-Language-Action Reasoning via Reinforced Visual Latent Planning》（NVIDIA、台湾大学）。**
  - 推理用的多模态大模型 `F_θ`（Qwen2.5-VL 7B）输出推理文本和视觉规划潜变量 `c_t`。潜变量解码成 [0, 1]² 中的 K = 8 个夹爪点。
  - **目标奖励**（式 1）是 `r_goal = ½ (f(p_1, p̂_1) + f(p_K, p̂_K))`，其中 `f(p, p′) = max(0, 1 − ‖p − p′‖²)`。**轨迹奖励**（式 2）是 `r_traj = max(0, 1 − d(τ, τ̂))`，距离用动态时间规整。式 3 把它们合成 `r = 0.9 · r_visual + 0.1 · r_format`，其中 `r_visual = 0.5 · r_goal + 0.5 · r_traj`。
  - 训练用 GRPO（式 4），优势按组归一化，β = 1e-2，每组 5 个 rollout，6K 次迭代。
  - 动作模型 `π_φ` 是 432M 的 DiT 策略，经 Q-Former（32 个查询）以 `c_t` 为条件，在 `F_θ` 冻结时用模仿学习（式 5）训练。它**异步**运行：一个潜变量服务 N 个动作（SimplerEnv 上 N = 15，LIBERO 上 75）。附录 B.6 报告 LIBERO 上 N = 25 / 50 / 75 / 100 → 84.0 / 84.6 / 84.4 / 83.7 %。
  - **报告的结果（以论文为准）。** 表 1 给出 LIBERO 总体 84.4（OpenVLA 76.5，DiT-Policy 76.8，CoT-VLA 83.9）、LIBERO-Long 70.9，以及 SimplerEnv Google-VM 71.5、Google-VA 65.1、Bridge-VM 43.8。表 3（SimplerEnv）对奖励做消融：完整 60.1，去掉 `r_traj` 59.2，去掉 `r_goal` 59.1，两者都去掉 56.9，只做 SFT 56.4。附录 B.7 报告 ThinkAct 比 OpenVLA 慢约 17 %，那里按子集给出的差值与表 1 的差并不全部一致；本页不解决这个差异。

### 规划奖励与潜变量携带的信息

<Formula label="目标奖励（ThinkAct 式 1）">r_goal = ½ · (f(p_1, q_1) + f(p_K, q_K))，f(p, q) = max(0, 1 − ‖p − q‖²)</Formula>

<Formula label="轨迹奖励（ThinkAct 式 2）">r_traj = max(0, 1 − DTW(p, q))</Formula>

<Formula label="视觉奖励（ThinkAct 式 3，不含格式项）">r_visual = 0.5 · r_goal + 0.5 · r_traj</Formula>

本 toy 里，潜变量是剩下的**阶段目标**列表，在 9 × 9 网格上缩放到 [0, 1]²。它不是 ThinkAct 的 8 个夹爪点。

**算例。** 取任务 P → Q → P，网格上 P = (2, 6)、Q = (6, 2)，缩放后每格是 1/8。正确的潜变量得到 `r_visual = 1`。**轮换**后的潜变量 Q → P → P 终点正确，终点误差为 0 格，但第一个点偏了 (0.5, 0.5)：`f = 1 − 0.5 = 0.5`，`r_goal = 0.75`，DTW = 0.7071，`r_traj = 0.2929`，`r_visual = 0.5214`。第一个点抖动一格的潜变量得 0.9336。**只看终点误差看不出顺序错了，轨迹项能看出来。**

**这里没有积分步长。** 机器人每步走一格，不按连续时间步进，不涉及步长稳定性判据。扮演这个角色的量是**潜变量刷新**间隔，即本 toy 版本的 ThinkAct "每个潜变量 N 个动作"。

### 公平设置

`thinkact_visual_latent_toy.py` 是**合成**的，只用标准库。**模型假设**如下。
- 任务是一个有序的目标格列表，有些格要去两次（PQP、PQPQ）。机器人站到下一个目标上时阶段前进。
- 相机以概率 `1 − q_hide` 显示阶段指示；被遮住时，同一个格在不同阶段看起来一样。
- **共享示范。** 每次试验 20 条专家回合（先走 x 再走 y；每步有 0.1 的概率打滑成随机移动），为每个学习出来的表提供标签。
- 推理替身写出剩下的目标。每个目标以概率 `p_plan` 被移到相邻格（幻觉的替身）；若阶段可见，潜变量每隔 `refresh` 步重写一次。
- 没见过的键先退回"阶段被遮住"的多数动作，再退回"原地不动"。

| 组 | 动作表的输入 |
|---|---|
| A_direct | （格，可见的阶段或"被遮住"） |
| B_latent | （格，当前规划点）；到达一个点后转向下一个点 |
| C_scrambled | B 的表，目标相同但顺序轮换（t_2, …, t_K, t_1）；只有一个阶段时等同于不变 |

**共同随机数。** 每个（情形、种子、试验）的场景、任务、示范、规划抖动、打滑抽样和遮挡抽样只抽一次，三组共用。共 5 个种子 × 40 次试验。

指标：
- `stage`：完成的阶段比例。
- `full`：所有阶段都完成。
- `endpoint`：潜变量终点误差（格）。
- `r_visual`：第一个潜变量的式 3 视觉奖励；A 没有潜变量，打印 0。

| 情形 | 阶段 | q_hide | 遮挡块 | p_plan | 刷新 | 掉落 |
|---|---|---|---|---|---|---|
| single_step | P | 0.5 | 1 | 0.1 | 只在开始 | 否 |
| multi_stage | PQP | 0.5 | 1 | 0.1 | 只在开始 | 否 |
| ambiguous | PQPQ | 0.8 | 1 | 0.1 | 只在开始 | 否 |
| multi_stage_block | PQP | 0.5 | 8 | 0.1 | 只在开始 | 否 |
| ambiguous_block | PQPQ | 0.8 | 8 | 0.1 | 只在开始 | 否 |
| noisy_plan | PQP | 0.5 | 1 | 0.5 | 只在开始 | 否 |
| drop_dense | PQP | 0.5 | 1 | 0.1 | 每 5 步 | 是 |
| drop_sparse | PQP | 0.5 | 1 | 0.1 | 只在开始 | 是 |

`drop` 情形里，回合中间三分之一的某一步，阶段计数回退一格（物体滑落）。这时潜变量必须重写，否则它会指向一个已经不算完成的阶段之后。

**看过结果后做的选择。** 第一次完整运行后改了三处；toy 会打印每处的第一版。
- **退回规则。** 起初，没见过的（格，规划点）键让 B 原地不动，A 却保留（格，被遮住）退回。决定结果的是这个不对称，而不是潜变量：B 在每个情形都输给 A，例如 multi_stage B−A full −0.2000±0.0901，noisy_plan −0.6850±0.0576。现在所有组用同一个退回规则。旧的那一行对每个情形都会打印。
- **C 是什么。** C 起初用同一场景里另一个任务的潜变量。它的键在示范里从未出现，于是退回 A 的"被遮住"表，实际上忽略了潜变量（single_step 的 C−B 在每个种子上都打平）。现在 C 轮换真实目标的顺序，键在示范里出现过，但顺序错了。第一版 C 也会打印（C−B full）。
- **`_block` 情形。** 遮挡每步重新抽时，multi_stage 的差距只是接近打平。相机连续 8 步看不到指示，正是潜变量要应对的情况，所以加了两个分块情形。逐步遮挡的情形仍留在表里和输出里。

#!/usr/bin/env python3
"""Synthetic ThinkAct-style toy: direct policy vs plan-latent policy vs a scrambled latent. Stdlib only.

A 9 x 9 grid; a task is an ordered list of target cells (stages), possibly revisiting a cell.
The stage counter advances when the robot stands on the next target. A camera shows the stage
indicator with probability 1 - Q_HIDE per step; otherwise the observation is the cell only, so
a revisited cell looks the same in different stages (perceptual aliasing).
Shared demos: N_DEMO expert episodes per trial (x first, then y; each step slips to a random
move with probability SLIP) give the labels for every learned table.

Arms (same task, same demos, same slip draws, same hide draws):
  A_direct   obs -> action: majority demo action for (cell, visible stage or "hidden")
  B_latent   a reasoner stand-in writes a plan latent = the remaining targets (each cell jittered
             to a neighbour with probability P_PLAN, a hallucination stand-in); the action model is
             the majority demo action for (cell, current plan point) and moves to the next point when
             it stands on one; the latent is rewritten every REFRESH steps when the stage is visible
             (REFRESH = 0: written once at the start)
  C_scrambled  B's action model with the same targets in a rotated order (t_2, ..., t_K, t_1);
             with one stage the rotation is the identity, so C equals B there by construction
  The first version's C used the targets of a different task in the same scene; its (cell, point)
  keys never occur in the demos, so it fell back to A's hidden-stage table; it is printed as an
  alternative.
An unseen key falls back to the (cell, hidden) majority for every arm, then to "stay"; the first
version let B stay at once and is printed as the fallback alternative.
Plan metrics for a latent (points scaled to [0, 1]^2 as in ThinkAct eq. 1-3):
  r_goal = (f(p_1, q_1) + f(p_K, q_K)) / 2 with f = max(0, 1 - |p - q|^2)
  r_traj = max(0, 1 - DTW(p, q)) (DTW: sum of Euclidean distances along the best alignment)
  r_visual = 0.5 r_goal + 0.5 r_traj; endpoint error = |p_K - q_K| in cells
The latent is a list of stage targets, not ThinkAct's 8 gripper points; no MLLM, no GRPO, no DiT.
No integration step: the grid moves one cell per step, nothing is stepped in continuous time.
Common random numbers: per (regime, seed, trial) the scene, the tasks, the demos, the plan jitter,
the slip draws and the hide draws are drawn once and shared by every arm.
Metrics per trial, averaged over TRIALS per seed: stage (share of stages completed), full
(all stages completed), endpoint, r_visual (latent arms only).
Labels: tie = identical on every seed; numerically zero = |paired mean| and sd both < 1e-9
(effectively a tie, no sign count); |m| <= sd = near-tie; |m| > sd = consistent gap (small if
|m| < 20 % of the smaller arm mean, else clear), with a sign count.

import math
import random

SEEDS = (0, 1, 2, 3, 4)
TRIALS = 40
SIZE = 9
N_DEMO = 20
SLIP = 0.1
MOVES = ((0, 0), (1, 0), (-1, 0), (0, 1), (0, -1))
NUM_ZERO = 1e-9
ARMS = ("A_direct", "B_latent", "C_scrambled")
# name: (stage pattern, Q_HIDE, P_PLAN, REFRESH, drop, HIDE_BLOCK)
# HIDE_BLOCK = steps per hide draw (1 = a fresh draw every step); the two *_block regimes were
# added after the per-step regimes had run (see the en / zh prose); every regime is printed.
REGIMES = {
    "single_step": ("P", 0.5, 0.1, 0, False, 1),
    "multi_stage": ("PQP", 0.5, 0.1, 0, False, 1),
    "ambiguous": ("PQPQ", 0.8, 0.1, 0, False, 1),
    "multi_stage_block": ("PQP", 0.5, 0.1, 0, False, 8),
    "ambiguous_block": ("PQPQ", 0.8, 0.1, 0, False, 8),
    "noisy_plan": ("PQP", 0.5, 0.5, 0, False, 1),
    "drop_dense": ("PQP", 0.5, 0.1, 5, True, 1),
    "drop_sparse": ("PQP", 0.5, 0.1, 0, True, 1),
}


def cell(rng):
    return (rng.randrange(SIZE), rng.randrange(SIZE))


def expert(c, t):
    if c[0] != t[0]:
        return 1 if t[0] > c[0] else 2
    if c[1] != t[1]:
        return 3 if t[1] > c[1] else 4
    return 0


def step(c, a):
    return (min(SIZE - 1, max(0, c[0] + MOVES[a][0])), min(SIZE - 1, max(0, c[1] + MOVES[a][1])))


def world(regime, seed, trial):
    pattern, q_hide, p_plan, refresh, drop, block = REGIMES[regime]
    rng = random.Random(f"{regime}-{seed}-{trial}")
    start = cell(rng)
    names = sorted(set(pattern))
    while True:
        spots = {n: cell(rng) for n in names}
        other = {n: cell(rng) for n in names}
        allc = list(spots.values()) + list(other.values()) + [start]
        if len(set(allc)) == len(allc):
            break
    task = [spots[n] for n in pattern]
    wrong = [other[n] for n in pattern]
    horizon = 2 * sum(abs(a[0] - b[0]) + abs(a[1] - b[1]) for a, b in zip([start] + task, task)) + 6
    demos = []
    for _ in range(N_DEMO):
        c, s, rec = start, 0, []
        for _ in range(horizon):
            if s == len(task):
                break
            a = expert(c, task[s])
            rec.append((c, s, rng.random() < q_hide, task[s], a))
            c = step(c, rng.randrange(5) if rng.random() < SLIP else a)
            if c == task[s]:
                s += 1
        demos.append(rec)
    jit = [[(rng.random(), rng.randrange(4)) for _ in range(len(task))] for _ in range(horizon + 1)]
    slips = [(rng.random(), rng.randrange(5)) for _ in range(horizon)]
    draws = [rng.random() < q_hide for _ in range(horizon)]
    hides = [draws[t // block] for t in range(horizon)]
    t_drop = rng.randrange(horizon // 3, 2 * horizon // 3) if drop else -1
    return start, task, wrong, horizon, demos, jit, slips, hides, t_drop, p_plan, refresh


def majority(table, key):
    votes = table.get(key)
    if not votes:
        return None
    return max(range(5), key=lambda a: (votes[a], -a))


def tables(demos):
    ta, tb = {}, {}
    for rec in demos:
        for c, s, hid, tgt, a in rec:
            for key in ((c, s if not hid else -1), (c, -1)):
                ta.setdefault(key, [0] * 5)[a] += 1
            tb.setdefault((c, tgt), [0] * 5)[a] += 1
    return ta, tb


def jitter(points, draws, p_plan):
    out = []
    for p, (u, d) in zip(points, draws):
        if u < p_plan:
            m = MOVES[1 + d]
            p = (min(SIZE - 1, max(0, p[0] + m[0])), min(SIZE - 1, max(0, p[1] + m[1])))
        out.append(p)
    return out


def dtw(p, q):
    inf = float("inf")
    d = [[inf] * (len(q) + 1) for _ in range(len(p) + 1)]
    d[0][0] = 0.0
    for i in range(1, len(p) + 1):
        for j in range(1, len(q) + 1):
            c = math.dist(p[i - 1], q[j - 1])
            d[i][j] = c + min(d[i - 1][j], d[i][j - 1], d[i - 1][j - 1])
    return d[len(p)][len(q)]


def plan_scores(plan, task):
    p = [(x / (SIZE - 1), y / (SIZE - 1)) for x, y in plan]
    q = [(x / (SIZE - 1), y / (SIZE - 1)) for x, y in task]
    f = lambda a, b: max(0.0, 1.0 - math.dist(a, b) ** 2)
    r_goal = 0.5 * (f(p[0], q[0]) + f(p[-1], q[-1]))
    r_traj = max(0.0, 1.0 - dtw(p, q))
    return math.dist(plan[-1], task[-1]), 0.5 * r_goal + 0.5 * r_traj


def rotate(points):
    return points[1:] + points[:1]


def latent_source(arm, task, wrong):
    if arm == "B_latent":
        return task
    if arm == "C_scrambled":
        return rotate(task)
    return wrong


def run(arm, regime, seed, trial, fallback="table"):
    start, task, wrong, horizon, demos, jit, slips, hides, t_drop, p_plan, refresh = world(regime, seed, trial)
    ta, tb = tables(demos)
    c, s = start, 0
    source = latent_source(arm, task, wrong)
    plan = jitter(source, jit[0], p_plan)
    endpoint, r_vis = plan_scores(plan, task)
    ptr = 0
    for t in range(horizon):
        if s == len(task):
            break
        if t == t_drop and s > 0:
            s -= 1
        if arm == "A_direct":
            a = majority(ta, (c, -1 if hides[t] else s))
            a = majority(ta, (c, -1)) if a is None and fallback == "table" else a
        else:
            if refresh and t > 0 and t % refresh == 0 and not hides[t]:
                remaining = latent_source(arm, task[s:], wrong[s:]) or source[-1:]
                plan, ptr = jitter(remaining, jit[t], p_plan), 0
            a = majority(tb, (c, plan[ptr])) if ptr < len(plan) else None
            a = majority(ta, (c, -1)) if a is None and fallback == "table" else a
        a = 0 if a is None else a
        u, r = slips[t]
        c = step(c, r if u < SLIP else a)
        if c == task[s]:
            s += 1
        if arm != "A_direct" and ptr < len(plan) and c == plan[ptr]:
            ptr += 1
    out = {"stage": s / len(task), "full": 1.0 if s == len(task) else 0.0}
    out["endpoint"] = endpoint if arm != "A_direct" else 0.0
    out["r_visual"] = r_vis if arm != "A_direct" else 0.0
    return out


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


KEYS = ("stage", "full", "endpoint", "r_visual")

            res[arm] = []

                rs = [run(arm, regime, seed, t) for t in range(TRIALS)]
                res[arm].append({k: sum(r[k] for r in rs) / TRIALS for k in KEYS})
            cells = " ".join("{}+-{}".format(*map(num, mean_sd([r[k] for r in res[arm]]))) for k in KEYS)
            print(f"  {arm} {cells}")
        for x, y in (("B_latent", "A_direct"), ("C_scrambled", "B_latent"), ("C_scrambled", "A_direct")):
            for k in ("stage", "full"):
                print(f"  paired {x[0]}-{y[0]} {k}: {verdict([r[k] for r in res[x]], [r[k] for r in res[y]])}")
    print("fallback alternative (first version: an unseen (cell, plan point) key makes B stay; A keeps its (cell, hidden) fallback); paired B-A full")
    for regime in REGIMES:
        xa = [sum(run("A_direct", regime, seed, t)["full"] for t in range(TRIALS)) / TRIALS for seed in SEEDS]
        xb = [sum(run("B_latent", regime, seed, t, "stay")["full"] for t in range(TRIALS)) / TRIALS for seed in SEEDS]
        print(f"  {regime}: {verdict(xb, xa)}")
    print("C alternative (first version: the latent of a different task in the same scene); paired C-B full")
    for regime in REGIMES:

### 读这些情形

本页标签按以下顺序使用。**打平：每个种子都完全相同**只用于配对的逐种子差值在每个种子上都严格为零；`|配对均值|` 和它的标准差都小于 1e-9 时标为**数值上为零（浮点残差），等同打平**（这种行不打印同号计数）；`|配对均值| ≤ sd` 时为**接近打平、差距很小，在种子噪声之内**；否则是**稳定**差距（`|配对均值| > sd`），`|m|` 小于两组中较小均值的 20 % 时叫**小**，否则叫**明显**；20 % 规则只用来在这两个词之间选择。每条稳定的行都带 5 个种子上的同号计数，符号相反的种子都会报告；只有同号计数不能让差距变成稳定。差距都由未四舍五入的数值计算。 配对差值是 B−A、C−B 与 C−A。

- **single_step。** 两个指标上 B−A 都是**打平：每个种子都完全相同**；C−B 也打平，因为轮换一个目标什么都不变。只有一个阶段时，没有被遮住的上下文需要潜变量携带。
- **multi_stage（遮挡每步重抽）。** **接近打平**，B−A full −0.0250±0.0306，没有种子符号相反，5 个中 2 个相等。一半的步能看到阶段，这对 A 已经够了。
- **ambiguous。** 潜变量**赢**，差距小但稳定：B−A full 0.0800±0.0597，没有种子符号相反，5 个中 1 个相等。
- **multi_stage_block 与 ambiguous_block。** 潜变量小而稳定地赢，B−A full 分别为 0.0300±0.0209（5 个中 1 个相等）和 0.0950±0.0371（5 个种子同号）。
- **顺序被打乱的潜变量。** C−B full 在 multi_stage（−0.1500±0.0661）和 multi_stage_block（−0.1700±0.0274）中明显，5/5。在 ambiguous 中小但稳定（−0.0700±0.0326），在 ambiguous_block 中**接近打平**（−0.0300±0.0326，5 个中 2 个相等）。那里 PQPQ 轮换后是 QPQP，一路上仍会经过许多正确的格。
- **noisy_plan。** **潜变量输了。** `p_plan = 0.5` 时 B−A full 为 −0.0950±0.0622，小但稳定，没有种子符号相反（5 个中 1 个相等）。在这里，带幻觉的规划比没有规划还差。
- **drop_dense 与 drop_sparse。** 掉落之后，每 5 步重写的潜变量小而稳定地赢（B−A full 0.0450±0.0447，5 个种子中 1 个符号相反）。只在开始写一次时**接近打平**（−0.0200±0.0622）。过期的潜变量失去优势，就像 ThinkAct 要重新推理才能自我纠正。

本页**不宣布普遍赢家**。在这个 toy 里，规划潜变量在携带相机遮住的阶段上下文时有帮助，而且优势不大。没有被遮住的信息时它打平，规划有幻觉时它输。顺序重要时，顺序错误的代价最大。ThinkAct（Qwen2.5-VL、GRPO、LIBERO、SimplerEnv、GPU）均**本页未运行**；论文数字以论文为准。
