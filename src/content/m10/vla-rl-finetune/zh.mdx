## 为什么 SFT 之后还要 RL

SFT 会把数据连同其中的错误一起照抄，并停在示范的水平。RL 可以超过示范，但用几十亿参数的 VLA 做探索很贵，稀疏奖励给的信息也很少。目前出现了四类做法，区别在于**训练什么**和**信号从哪来**。

| 类别 | 例子 | 训练什么 | 学习信号 | 论文在哪里跑 |
| --- | --- | --- | --- | --- |
| 整个 VLA 上的结果奖励 RL | SimpleVLA-RL | VLA 全部权重 | 每次 rollout 的二值任务成功 | 仿真基准，再加真实世界测试 |
| <Term id="advantage-conditioning">优势条件</Term> | π*0.6 / RECAP | VLA，以「这一步是否好于预期」为条件 | 学到的价值函数 | 真机 |
| 冻结基座上的<Term id="residual-policy">残差策略</Term> | ResiP、Policy Decorator | 一个小的修正网络 | 稀疏奖励，PPO 或 SAC | 主要在仿真 |
| 奖励模型加权的模仿 | LeRobot SARM + RA-BC | 策略本身，带逐帧权重 | 预测的任务进度 | 你自己的数据集 |

## 结果奖励 RL：SimpleVLA-RL

SimpleVLA-RL（Li 等，2025）在整个 VLA 上做大规模 RL，基于 veRL 框架，用 GRPO 式目标和二值奖励：这次 rollout 成功或没成功。基座取自 OpenVLA-OFT 系；但 SimpleVLA-RL 为便于采样，改用离散动作 token + 交叉熵（LLaMA2 输出头、单视角），不是官方 L1 连续动作版本（§4.1）。官方 OpenVLA-OFT（并行解码、动作块、连续动作、L1 损失）的摘要报告 LIBERO 平均成功率从 76.5 % 提到 97.1 %，动作生成快 26×。SimpleVLA-RL 的摘要报告在 LIBERO 上达到最好水平，在 RoboTwin 1.0 和 2.0 上超过 π0，并在 RL 中出现作者称为「pushcut」的新行为——例如在 RoboTwin2.0 的 move can pot、place a2b 等任务上推动物体，而不是示范里的抓取。论文报告：在 5 个 RoboTwin2.0 任务上，不经轨迹微调的基座成功率为 0，仅靠结果奖励的 RL 无法提升（§6.2/Tab.7）；每任务 1 条示范微调后 RL 即可大幅提升（LIBERO-Long 17.3 %→91.7 %，§5.1）。以论文为准。以上都是作者在 GPU 集群上的测量，本页未运行。

GRPO 的直观理解：同一提示下采一组 rollout，用组内归一化的优势更新策略；若一组全成或全败，优势为 0、没有梯度，该组会被丢弃。相关方法还包括 ConRFT、RIPT-VLA、RLinf（一句话入口见下方资源，不写数字）。

## 优势条件：π*0.6 与 RECAP

Physical Intelligence 的 π*0.6 文章介绍了 RECAP，即「RL with Experience & Corrections via Advantage-conditioned Policies」。价值函数预测离任务完成还剩多少步；据此给数据里每一步一个优势（好于还是差于预期）。不是把差数据扔掉，而是用**全部**数据训练 VLA，并以优势为条件；运行时要求它给出「好于预期」的行为。数据来自示范、机器人自己的自主尝试和专家纠正。文章报告在一些最难的任务上吞吐量提高到两倍以上，失败率可降低 2× 或更多，例子包括从早上 5:30 到晚上 11:30 做浓缩咖啡和叠衣服。π0.6 本身用 5B 视觉语言骨干加动作专家。这些是公司报告的结果，本页未运行。

## 残差策略：ResiP 与 Policy Decorator

这里大模型保持冻结，由一个小网络在它的动作之上学修正：

- **ResiP**（Ankile 等，2024）固定一个按动作块输出的行为克隆模型（扩散策略），用 PPO 在稀疏奖励上训练闭环、逐步的残差，并把残差保持得很小。在其仿真家具装配任务上，报告用 50 条示范带来大幅提升（例如 one_leg 在低随机化 ±1.5 cm、最佳 checkpoint、仿真条件下从 54 % 到 98 %；中随机化 26 %→76 %）；以论文为准。
- **Policy Decorator**（Yuan 等，2024）让残差与基座模型无关，用 SAC 训练；它限制残差的幅度，并在探索中逐步提高使用残差的频率，避免早期破坏基座策略的好行为。实验用 ManiSkill 和 Adroit，基座是 Behaviour Transformer 和扩散策略。

残差对业余硬件有吸引力，因为要训练的部分小；但论文结果主要在仿真里。

## 奖励模型加权的模仿：SARM + RA-BC

在你自己的数据上，最便宜的一步根本不是 RL。LeRobot 的 SARM 页面介绍了一个分阶段的奖励模型，逐帧预测 0 到 1 的任务进度；以及奖励对齐的行为克隆（RA-BC），按每个样本的进度变化加权：超过阈值 κ 时权重为 1，0 到 κ 之间是软权重，**进度倒退时权重为 0**。这就是用学到的进度信号做优势加权模仿。本页未运行，以当期文档为准：需要 GPU，命令（例如 `python -m lerobot.rewards.sarm.compute_rabc_weights`）来自 main 文档，可能与你安装的 LeRobot v0.6.x 版本不同。

```python
"""advantage_filter_toy.py: behaviour cloning that keeps only steps with A > 0 (stdlib).

Same 10-state lock chain as 10.6 (wrong action -> back to state 0, goal at
state 9, at most 30 steps). A mediocre behaviour policy (think: an SFT'd
VLA, or teleop plus autonomous rollouts) records 40 episodes. It gets most
states right but is worse than a coin flip in states 2 and 5.

1. Value from the log: V(s) = mean of "minus steps to finish" over every
   visit to s (a timed-out episode counts its remaining steps plus a
   30-step penalty). This is the flavour of value pi*0.6 / RECAP describes
   (predicting how far you are from done); here it is a plain average.
2. Advantage per logged step: A = -1 + V(s') - V(s), with V(goal) = 0.
3. Three tabular "policies" built by counting logged actions per state:
     bc            every step, equal weight
     success_only  only steps from episodes that reached the goal
     adv_filter    only steps with A > 0 (binary advantage weight)
   Each is evaluated by sampling actions in proportion to the counts,
   2000 rollouts with a fixed seed.
4. Same recipe on a log with no successes at all: V has nothing to rank,
   so the filter keeps noise (outcome-reward RL also needs a policy that
   already succeeds sometimes).
No VLA, no GPU: only the reweighting idea.
"""

import random

N = 10
H = 30
LOCK = [1, 0, 1, 0, 0, 0, 1, 0, 0]     # same right actions as rlpd_chain_toy.py
GOOD = [0.9, 0.9, 0.35, 0.9, 0.9, 0.4, 0.9, 0.9, 0.9]   # P(right action) of the behaviour policy
EPISODES = 40
EVAL = 2000


def step(s, a):
    if a != LOCK[s]:
        return 0, False
    s2 = s + 1
    return s2, s2 == N - 1


def collect(p_right, episodes, seed):
    rng = random.Random(seed)
    log = []   # list of episodes; each a list of (s, a, s2, done)
    for _ in range(episodes):
        ep, s = [], 0
        for _ in range(H):
            a = LOCK[s] if rng.random() < p_right[s] else 1 - LOCK[s]
            s2, done = step(s, a)
            ep.append((s, a, s2, done))
            if done:
                break
            s = s2
        log.append(ep)
    return log


def values(log):
    tot = [0.0] * N
    cnt = [0] * N
    for ep in log:
        success = ep[-1][3]
        L = len(ep)
        for t, (s, _, _, _) in enumerate(ep):
            g = -(L - t) if success else -(L - t) - H
            tot[s] += g
            cnt[s] += 1
    v = [tot[s] / cnt[s] if cnt[s] else -2.0 * H for s in range(N)]
    v[N - 1] = 0.0
    return v


def count_policy(steps):
    c = [[0, 0] for _ in range(N - 1)]
    for s, a in steps:
        c[s][a] += 1
    return c


def p_right(c, s):
    n = c[s][0] + c[s][1]
    return c[s][LOCK[s]] / n if n else 0.5


def evaluate(c, seed):
    rng = random.Random(seed)
    wins = lens = 0
    for _ in range(EVAL):
        s = 0
        for t in range(1, H + 1):
            a = LOCK[s] if rng.random() < p_right(c, s) else 1 - LOCK[s]
            s, done = step(s, a)
            if done:
                wins += 1
                lens += t
                break
    return wins / EVAL, (lens / wins if wins else float("nan"))


def build(log, v):
    all_steps, succ_steps, adv_steps = [], [], []
    for ep in log:
        success = ep[-1][3]
        for s, a, s2, done in ep:
            all_steps.append((s, a))
            if success:
                succ_steps.append((s, a))
            if -1.0 + v[s2] - v[s] > 0:
                adv_steps.append((s, a))
    return {
        "bc": (count_policy(all_steps), len(all_steps)),
        "success_only": (count_policy(succ_steps), len(succ_steps)),
        "adv_filter": (count_policy(adv_steps), len(adv_steps)),
    }


def report(title, log, seed):
    v = values(log)
    wins = sum(ep[-1][3] for ep in log)
    print(title)
    print(f"  logged episodes {len(log)}, successes {wins}, steps {sum(len(ep) for ep in log)}")
    print("  V(s): " + " ".join(f"{x:.1f}" for x in v))
    pols = build(log, v)
    print("  policy        kept_steps  P(right) in states 2 / 5  success  mean_steps_if_success")
    for name, (c, kept) in pols.items():
        sr, ml = evaluate(c, seed)
        mls = f"{ml:.1f}" if sr else "n/a"
        print(f"  {name:<12} {kept:>11}  {p_right(c, 2):>12.2f} / {p_right(c, 5):.2f}  {100 * sr:>6.1f} %  {mls:>8}")
    print()


def main():
    print("lock chain: wrong action -> state 0, goal at 9, at most 30 steps; A = -1 + V(s') - V(s)")
    print()
    report("A) mediocre log (right action 90 % of the time, 35 % in state 2, 40 % in state 5)",
           collect(GOOD, EPISODES, seed=3), seed=11)
    report("B) log with no successes (coin-flip policy, 6 episodes)",
           collect([0.5] * (N - 1), 6, seed=4), seed=11)
    print("in A the filter drops the wrong actions that BC copies; in B nothing ever")
    print("finished, so V cannot tell good steps from bad and the filter keeps noise.")


if __name__ == "__main__":
    main()
```

## 常见错误

- **指望 RL 拯救从不成功的策略。** 结果奖励和优势过滤都需要数据里有一些成功。
- **把失败数据扔掉。** RECAP 保留它们并以优势为条件；直接丢弃的过滤器也丢掉了「更差」长什么样。
- **残差不设上限。** 允许很大的残差可能抵消基座策略；ResiP 让它保持很小，Policy Decorator 给它设界。
- **把论文数字当成自己的。** 上面每个百分比都是作者在其设置上的测量。

## 离线 Cal-ConRFT：校准 critic，不只贴名称

本节区别于已有 `advantage_filter_toy.py` 和 **10.6 HIL-SERL**。过滤器给日志动作排序；这里真正从固定离线 MDP 批次优化 critic 与 actor，不是从零做真机 RL。

<Resource id="calql-paper" />

已打开的 ConRFT 原文（arXiv2502.05450，离线方法节）区分 **Cal-ConRFT 离线** 与 **HIL-ConRFT 在线**。离线用 Cal-QL 风格 critic 配合一致性策略头，在少量示范上做 **BC + Q 引导**；在线保持 BC/Q 结构，加入交互和人工介入，权重可变化。本节分类 actor **不复现一致性策略头**、扩散 / 一致性训练、Octo 主干或 Franka 实验。GPU/VLA/真机：**本页未运行**。**96.3 %** 等论文数字均 **以论文为准**，不是玩具实测。

### 下界放在保守正则项内部

已打开的 Cal-QL 原文（arXiv2303.05479，校准定义与方法）解释：保守 critic 可能远低于有效行为策略的回报。实用修改是在下压项内部使用 **max(Q, V_MC)**，并保留数据动作补偿。这里 V_MC(s) 是**同一离线行为示范**经过 s 后的折扣回报到达终点的均值，不是评估回报或最优真值 oracle。

本节离散温度 logsumexp 版本为：

- TD：`0.5 E_D[(Q(s,a) − (r + γ E_π Q_old(s',·)))²]`；终止目标为 r。
- CQL：`α [T logsumexp_a(Q(s,a)/T) − E_D[Q(s,a) | s]]`。
- Cal-QL：仅在 logsumexp **内部**把 Q 换成 `max(Q(s,a), V_MC(s))`。低于参考时下压导数为零；数据补偿不变，V_MC 不参与梯度。本玩具的 active mask ≈ ∂max(Q,V_MC)/∂Q（等号处选零次梯度）。
- Actor：`β CE(behavior,π) − η E_π Q`，固定 critic 更新分类 logits；**不是优势过滤**。

下界约束正则项的输入，**不是事后硬裁剪学习 Q 或 Bellman 目标**。如原文所提醒，函数逼近和有限优化不保证每个原始 Q 或每个状态均值都满足下界。打印 `min_state_Q_minus_V` 以暴露残余欠校准。缓解在线遗忘 / 微调初期下跌**只作阅读**：本玩具**没有在线阶段**，不展示该收益。

### 一个 MDP，共享数据，等更新次数

四状态锁链有三动作：0以0.9概率前进（仅最后一次成功前进奖励1），1是错误钥匙、终止奖励0，2中止奖励0.2但**不算目标成功**。γ=0.95。行为概率为0.75/0.10/0.15；每种子48条日志轨迹包含失败与中止。声明种子都覆盖四状态。学习器只看转移，不拿正确动作标签。

种子 **1071–1075** 各生成一个不可变批次，供 **BC_only / CQL_BC / CalQL_BC** 复用。各臂 **1000次全批 actor 更新**，状态等权、logits 零初始化、更新日程相同。各臂 β=1；η=0(BC)、η=2(两 RL 臂)。Critic 的 TD 权重1、α=1、T=0.1，学习率0.03(Q)/0.06(actor)；两 RL critic 从零开始，各更新1000次。BC **没有 critic**，Q=NA；等外层 / actor 更新**不表示等 FLOPs / 参数量**。运行内不根据留出评估结果调参。

默认 critic：**Q(s,a)=w_s·features[a]**，features=(1.0,1.2,1.4)。这个刻意保留的**模型误设**共享动作效应：正 w 会把中止排在前进之上，无法拟合全部真实价值。两 RL 臂限制完全相同。这是为诊断选定的配置，不是无偏算法排行榜。它暴露保守梯度耦合，不是断言 CQL 总会尺度过低。`--tabular` 对照移除限制，但不改 MDP、数据、更新或损失。

每种子 **1000条评估轨迹**共享动作抽样与转移均匀随机数，各策略都按分类分布抽样。报告目标成功率、折扣回报和包含失败的步数。`policy_Q` 是 E_π Q 在**四个数据状态上等权**的均值；`MC_behavior_V` 对行为 MC 参考用相同状态权重。两者都不是起始状态评估回报；差值是校准诊断，而非同策略预测误差。

### 保留不利的尺度与策略结果

受限 CQL 的策略 Q 均值 **0.135372** 低于 MC 参考 **0.439094**；Cal-QL 把它拉到 **0.419844**。这是更接近，而非硬下界证书：状态差仍为负（种子1072最小 **−0.092253**）；下压屏蔽比例也打印出来。尺度修正不能修复 critic 的错误动作排序。

五种子目标成功率均值±总体标准差为 **BC0.2142±0.0494**、**CQL0.1958±0.0400**、**Cal-QL0.1628±0.0305**，逐行及最小 / 最大值都保留。BC 在这个受限 critic 配置最好，不是普遍赢家或显著性结论。不得删除不利于 Cal-QL 的结果。

完整表格 critic 对照的 Q 均值为 **0.457688/0.604030**（CQL/Cal-QL），同一参考0.439094；CQL 大幅欠尺度消失。成功率均值为 **0.2786/0.2748**，BC仍为0.2142。这是表示能力敏感性检查，不是偷偷给竞争臂分配不同 critic。Cal-QL 原文也解释了校准效果为何随数据集变化。把 max 放对位置，既不保证离线策略收益，也不能据此宣称缓解在线下跌。

```python
#!/usr/bin/env python3
"""Offline discrete lock-chain; BC vs CQL+BC vs Cal-QL+BC (stdlib).
No consistency head, VLA backbone, online phase or HIL-SERL reproduction.
Tabular actor, restricted shared-action-feature linear critic (misspecified).
CQL uses a temperature-logsumexp conservative penalty; Cal-QL masks its
push-down via max(Q, V_MC) INSIDE that penalty, not a post-hoc Q clamp.
V_MC is behavior return-to-go from the SAME demos, never an eval oracle.
In this toy, the active mask ≈ ∂max(Q,V_MC)/∂Q (zero subgradient at equality).
Equal full-batch actor updates; BC has no critic (Q scale NA), not equal FLOPs.
All settings synthetic; paper numbers 以论文为准; GPU/robot 本页未运行.
"""
import math
import random
import statistics
import sys

FEATURES = (1., 1.2, 1.4)  # Deliberately restricted critic: Q(s,a)=w_s*FEATURES[a].
SEEDS = (1071, 1072, 1073, 1074, 1075)
STATES, ACTIONS, DEMOS, UPDATES, EVAL_N = 4, 3, 48, 1000, 1000
GAMMA, ALPHA, TEMP, LR_Q, LR_PI = .95, 1., .1, .03, .06
BC_WEIGHT, Q_WEIGHT = 1., 2.
ARMS = ("BC_only", "CQL_BC", "CalQL_BC")


def softmax(xs):
    m = max(xs)
    es = [math.exp(x-m) for x in xs]
    return [x/sum(es) for x in es]


def transition(s, a, noise):
    # 0: advance with 90% probability; 1: wrong key, fail; 2: abort for .2.
    if a == 1:
        return 0., STATES, False
    if a == 2:
        return .2, STATES, False
    if noise >= .9:
        return 0., STATES, False
    return (1. if s == STATES-1 else 0.), s+1, s == STATES-1


def dataset(seed):
    rng = random.Random(seed)
    by_state = [[] for _ in range(STATES)]
    for _ in range(DEMOS):
        episode, s = [], 0
        while s < STATES:
            u = rng.random()
            a = 0 if u < .75 else (1 if u < .85 else 2)
            r, ns, _ = transition(s,a,rng.random())
            episode.append((s,a,r,ns)); s = ns
        ret = 0.
        for s,a,r,ns in reversed(episode):
            ret = r+GAMMA*ret
            by_state[s].append((a,r,ns,ret))
    assert all(by_state), "declared seeds must cover all four states"
    return tuple(tuple(rows) for rows in by_state)


def train(arm, data, tabular=False):
    weights, features = [0.]*STATES, FEATURES
    q = [[0.]*ACTIONS for _ in range(STATES)]
    logits = [[0.]*ACTIONS for _ in range(STATES)]
    refs = [statistics.fmean(row[3] for row in rows) for rows in data]
    beta = [[sum(row[0]==a for row in rows)/len(rows) for a in range(ACTIONS)] for rows in data]
    masked, proposals = 0, 0
    for _ in range(UPDATES):
        pi = [softmax(z) for z in logits]
        grads = [[0.]*ACTIONS for _ in range(STATES)]
        for s,rows in enumerate(data):
            if arm != "BC_only":
                scores = [max(x,refs[s]) if arm=="CalQL_BC" else x for x in q[s]]
                proposal = softmax([x/TEMP for x in scores])
                td = [0.]*ACTIONS
                for a,r,ns,_ in rows:
                    target = r if ns==STATES else r+GAMMA*sum(p*x for p,x in zip(pi[ns],q[ns]))
                    td[a] += (q[s][a]-target)/len(rows)
                for a in range(ACTIONS):
                    active = arm!="CalQL_BC" or q[s][a] > refs[s]
                    masked += not active; proposals += 1
                    grad = td[a]+ALPHA*(proposal[a]*active-beta[s][a])
                    grads[s][a] = grad
            # CE gradient plus gradient of -E_pi Q; critic held fixed here.
            meanq = sum(p*x for p,x in zip(pi[s],q[s]))
            eta = 0. if arm=="BC_only" else Q_WEIGHT
            for a in range(ACTIONS):
                grad = BC_WEIGHT*(pi[s][a]-beta[s][a])-eta*pi[s][a]*(q[s][a]-meanq)
                logits[s][a] -= LR_PI*grad
        if arm != "BC_only":
            if tabular:
                q = [[x-LR_Q*g for x,g in zip(qs,gs)] for qs,gs in zip(q,grads)]
            else:
                for s in range(STATES):
                    weights[s] -= LR_Q*sum(g*f for g,f in zip(grads[s],features))
                q = [[w*f for f in features] for w in weights]
    pi = [softmax(z) for z in logits]
    # Uniform weighting over the four covered dataset states (not start return).
    # Same dataset-state weighting for learned policy Q and MC behavior V.
    qscale = statistics.fmean(sum(p*x for p,x in zip(ps,qs)) for ps,qs in zip(pi,q))
    reference = statistics.fmean(refs)
    gaps = [sum(p*x for p,x in zip(ps,qs))-ref for ps,qs,ref in zip(pi,q,refs)]
    return pi,qscale,reference,min(gaps),masked/max(proposals,1)


def evaluate(pi, draws):
    successes, returns, lengths = 0, [], []
    for trajectory in draws:
        s, ret = 0, 0.
        for t,(u,noise) in enumerate(trajectory):
            cdf = 0.
            for a,p in enumerate(pi[s]):
                cdf += p
                if u < cdf:
                    break
            r,s,success = transition(s,a,noise)
            ret += GAMMA**t*r
            if s == STATES:
                successes += success; lengths.append(t+1); break
        returns.append(ret)
    return successes/EVAL_N,statistics.fmean(returns),statistics.fmean(lengths)


def main():
    assert sys.argv[1:] in ([], ["--tabular"]), "optional representation control: --tabular"
    tabular = "--tabular" in sys.argv
    print(f"offline lock-chain: states={STATES} actions={ACTIONS} demos={DEMOS} updates={UPDATES} eval={EVAL_N}/seed")
    print(f"actor beta_BC={BC_WEIGHT} eta_Q=0(BC)/{Q_WEIGHT}(RL); critic TD=1 alpha={ALPHA} LSE_temperature={TEMP}; gamma={GAMMA}")
    print("critic=full tabular representation control" if tabular else
          f"critic Q(s,a)=w_s*features[a], features={FEATURES}; model misspecification intentionally retained")
    print("same full demo batch/actor updates and eval action+transition uniforms; BC critic=NA, not equal FLOPs")
    print("seed arm transitions success mean_return mean_steps policy_Q MC_behavior_V min_state_Q_minus_V masked_fraction")
    scores = {a:[] for a in ARMS}
    for seed in SEEDS:
        data = dataset(seed)
        rng = random.Random(seed+10000)
        draws = tuple(tuple((rng.random(),rng.random()) for _ in range(STATES)) for _ in range(EVAL_N))
        for arm in ARMS:
            pi,q,ref,gap,masked = train(arm,data,tabular)
            success,ret,steps = evaluate(pi,draws)
            scores[arm].append((success,ret,q,ref,gap))
            mechanism = f"{q:.6f} {ref:.6f} {gap:.6f} {masked:.4f}" if arm!="BC_only" else f"NA {ref:.6f} NA NA"
            print(f"{seed} {arm} {sum(map(len,data))} {success:.3f} {ret:.6f} {steps:.3f} {mechanism}")
    print("arm success_mean population_sd min max return_mean policy_Q_mean MC_behavior_V_mean")
    for arm,rs in scores.items():
        success = [r[0] for r in rs]
        q = f"{statistics.fmean(r[2] for r in rs):.6f}" if arm!="BC_only" else "NA"
        print(f"{arm} {statistics.fmean(success):.4f} {statistics.pstdev(success):.4f} {min(success):.3f} {max(success):.3f} "
              f"{statistics.fmean(r[1] for r in rs):.6f} {q} {statistics.fmean(r[3] for r in rs):.6f}")
    print("Cal-QL masks conservative push-down below MC reference; learned Q is NOT hard-clipped or a universal per-action lower bound")
    print("offline only: online unlearning dip is reading, NOT demonstrated; no universal winner")
    print("distinct from advantage filtering/10.6 HIL-SERL; consistency head not reproduced; paper 以论文为准; GPU/robot 本页未运行")


if __name__ == "__main__":
    main()
```
