## 空等帧 vs 接缝

动作块策略在执行一个块的同时计算下一个块。会出两类不同的问题：

| 问题 | 现象 | 解法 |
| --- | --- | --- |
| 空等帧 | 机械臂停下来等推理 | 异步推理（8.3） |
| 不连续 | 新块接手时机械臂一抖 | <Term id="real-time-chunking">实时动作块（RTC）</Term> |

LeRobot 的 RTC 文档也这样划分，并建议两者一起用。ACT 的 temporal ensembling（6.2）走另一条路：每步都查询策略，对同一时间索引的多份预测加权平均。这要求每个控制周期都推理一次；RTC 论文报告，注入 100 ms 或 200 ms 额外延迟时，temporal ensembling 触发了机器人的保护性停机。

## 冻结与软掩码

RTC（Black、Galliker 与 Levine，arXiv **2506.07339**）把下一个块看成推理期的 inpainting 问题；不需要重训，适用于扩散或流匹配策略，如 π0、π0.5、SmolVLA。

记号（Δt 为控制周期，δ 为从观测到拿到可用动作块的时间）：

- **H**：预测长度（块长）。
- **s**：新一次推理开始前，已从上一块执行掉的动作数。
- **d = floor(δ / Δt)**：以控制步计的推理延迟。本课简化条件：d ≤ s ≤ H − d（RTC 原文未写此式）。

新块去噪期间，前 d 个动作已经按旧块执行掉了，所以它们被**冻结**。再往后，<Term id="soft-mask">软掩码</Term> W 决定新块要在多大程度上贴近旧块剩下的部分（论文式 5）：

| 下标 i | W[i] |
| --- | --- |
| i 小于 d | 1（冻结） |
| d ≤ i，且 i 小于 H − s | `c·(e^c − 1)/(e − 1)`，其中 `c = (H − s − i)/(H − s − d + 1)` |
| i ≥ H − s | 0（自由） |

一个块的时间轴（H=16、s=8、d=2，即下面的玩具）：

| 步 | 0–1 | 2–7 | 8–15 |
| --- | --- | --- | --- |
| 区段 | 冻结（旧块） | 软区（衰减） | 自由（新块） |
| W | 1.00 | 0.68 → 0.01 | 0.00 |

真正的方法里，W 在每一步去噪时进入一个引导项（向量–雅可比积，并用最大权重 β 截断）；论文取 β = 5。按论文测量，这个引导让每个去噪步慢约 2.5 倍，所以下面的玩具不去实现它。

## 跑线性替身

`rtc_blend_toy.py` 保留掩码、去掉网络。旧计划是匀速斜坡（每步 0.05）；新块来自「另一种策略」（0.20 + 0.03·i）。**naive** 先用冻结前缀，然后直接播放新块；**blend** 事后计算 `W·旧 + (1 − W)·新`。这种事后混合是 RTC 引导去噪的简化线性替身，不是方法本身。

```python
"""rtc_blend_toy.py: chunk seam, naive switch vs soft-mask blend (stdlib).

Simplified LINEAR stand-in for real-time chunking (RTC, arXiv 2506.07339).
Real RTC puts the soft mask W inside a guidance term during flow-matching
denoising (a vector-Jacobian product, clipped by beta). Here we skip the
network and apply W directly as a post-hoc blend:

    blended[i] = W[i] * prev_left[i] + (1 - W[i]) * fresh[i]

W follows Eq. 5 of the RTC paper:
    W[i] = 1                              if i < d
    W[i] = c * (e^c - 1) / (e - 1)        if d <= i < H - s,  c = (H-s-i)/(H-s-d+1)
    W[i] = 0                              if i >= H - s

H = prediction horizon, s = actions executed from the previous chunk before
this inference started, d = inference delay in control steps.
"""

import math

H = 16
S = 8
DELAYS = (0, 2, 4)


def prev_chunk() -> list[float]:
    """Old plan: a steady ramp (rad), 0.05 per step."""
    return [0.05 * k for k in range(H)]


def fresh_chunk() -> list[float]:
    """New plan from a newer observation: a different 'strategy' (lower, slower)."""
    return [0.20 + 0.03 * i for i in range(H)]


def soft_mask(d: int) -> list[float]:
    w = []
    for i in range(H):
        if i < d:
            w.append(1.0)
        elif i < H - S:
            c = (H - S - i) / (H - S - d + 1)
            w.append(c * (math.exp(c) - 1.0) / (math.e - 1.0))
        else:
            w.append(0.0)
    return w


def executed(d: int, use_blend: bool) -> list[float]:
    """Last executed old action, then what the robot actually plays next."""
    prev = prev_chunk()
    left = prev[S:] + [0.0] * S  # right-pad to length H (paper: Algorithm 1)
    fresh = fresh_chunk()
    w = soft_mask(d) if use_blend else [1.0 if i < d else 0.0 for i in range(H)]
    new = [w[i] * left[i] + (1.0 - w[i]) * fresh[i] for i in range(H)]
    # actions 0..d-1 run from the old chunk while inference is in flight
    return [prev[S - 1]] + left[:d] + new[d:]


def stats(seq: list[float]) -> tuple[float, float]:
    steps = [abs(b - a) for a, b in zip(seq, seq[1:])]
    acc = [abs(seq[k + 1] - 2 * seq[k] + seq[k - 1]) for k in range(1, len(seq) - 1)]
    return max(steps), max(acc)


def main() -> None:
    print(f"H={H} s={S}  prev ramp 0.05/step, fresh = 0.20 + 0.03*i (other strategy)")
    print(f"{'d':>2} {'mode':<6} {'max_step':>8} {'max_acc':>8} {'tail=fresh':>10}")
    for d in DELAYS:
        for mode in ("naive", "blend"):
            seq = executed(d, mode == "blend")
            mstep, macc = stats(seq)
            tail_ok = all(
                abs(seq[1 + i] - fresh_chunk()[i]) < 1e-12 for i in range(H - S, H)
            )
            print(f"{d:>2} {mode:<6} {mstep:>8.3f} {macc:>8.3f} {str(tail_ok):>10}")
    w = soft_mask(2)
    print("W (d=2): " + " ".join(f"{v:.2f}" for v in w))
    print("naive jumps once at the seam; the blend spreads it over the overlap,")
    print("and the last s actions still follow the fresh chunk.")


if __name__ == "__main__":
    main()
```

## 常见错误

- **把玩具的混合当成 RTC。** 玩具是事后混合；真正的 RTC 在每一步去噪时引导。
- **远程推理时还开着 ACT 的 temporal ensembling。** LeRobot 远程推理文档要求 ACT 关闭 temporal ensembling。
- **只按模型耗时设 `inference_delay`。** 相机、网络和预处理也要算（10.3）。
- **指望 RTC 消除空等帧。** 那是异步推理（8.3）的事；两者一起用。

## 分段测试时搜索：FORGE-Tree

上面的 RTC 让新块与已经执行的动作保持一致。长时程、多阶段任务里还有另一个问题：策略一次解码整个时域，小误差不断累积，前面每一步看起来都没问题，后面一次精确放置却失败了。**FORGE-Tree** 保持预训练 VLA 冻结，在测试时多花算力：它只对规划好的动作 token 中**一个片段**重新加噪、重新去噪，用树搜索挑选要改的片段，并且从不碰已经执行的部分。本节为这个想法搭一个**合成**替身。它不是 OpenVLA、Octo 或 LIBERO，也不是 RTC 的引导。

<Resource id="forge-tree-pdf" />

**实际打开过的来源（经 pdftotext 读过 PDF 正文，arXiv 2510.21744 v1，cs.RO）。**

- **Huang、Liu、Liu、Xu、Wu、Gao 与 Tu，《FORGE-Tree: Diffusion-Forcing Tree Search for Long-Horizon Robot Manipulation》（Texas A&M、华盛顿大学、KIT）。**
  - 在冻结的 VLA 编码器（OpenVLA 或 Octo）上接一个**按阶段对齐的 Diffusion Forcing 头**（带 FiLM 的 Transformer），建模 64 个 7 维动作 token。每个 token 有自己的噪声水平，子任务 j 的所有 token 共用 `t_j`（"noise = mask"）。训练时 T = 1000，`t_j` 取自 U[400, 900]。
  - **部分去噪**（算法 1）：片段掩码 `s_i = 1[k ≤ i ≤ k+m−1]` 选出 token；只有这个片段按步长 s 的跳步 DDIM 演化，其余部分冻结。几何引导从预测噪声里减去 `w · ∇U`。
  - **Monte Carlo Tree Diffusion**（算法 2，式 III.6–III.8）：元动作是 `(k, m, s, w, τ)`，其中 `m ∈ (8, 12, 16)`、`s ∈ (2, 4, 8)`、`w ∈ [0, 5]`、`τ ∈ [0.5, 1.0]`，k 限制在下一个阶段边界之前 16 个 token 以内。子节点按带 Laplace 平滑的 P-UCT 打分。未访问的子节点按**快速启发式**奖励排序，回传的值则是**场景图**给出的真实几何回报。搜索逐阶段进行，每阶段预算 B，提交最佳子节点的第一个片段，"保留已执行的前缀"。
  - **报告的结果（以论文为准）。** LIBERO 上，表 II 给出 OpenVLA 76.5 → 89.9（+13.4 个百分点；Long +29.5），Octo 75.1 → 92.3（+17.2 个百分点；Long +39.9）。表 III 去掉阶段引导后，Goal 88.2 → 75.9，Long 83.2 → 60.7，正文称下降 14 % 和 27 %。表 III 完整模型的 Goal 值（88.2）与表 II 的 89.3 不一致；本页不解决这个差异。
  - **报告的失败模式。** 场景图出错会误导搜索；搜索要花时间；搜索可能卡在第一次抓取，反复访问同一个短片段。论文说没有场景图时需要更大的搜索预算，但没有给出预算缩放表。
  - 训练使用 4 × 48 GB Ada GPU，在 EMMA-X 上训练，在 LIBERO 上零样本评测（本页未运行）。

### 部分去噪、P-UCT 与冻结的前缀

<Formula label="位移 token（本 toy 的一次性解码）">δ_i = μ_i + b_j + σ · ε_i，阶段 j 的终点位置是它各 token 的 δ_i 之和</Formula>

<Formula label="片段 k 的部分去噪（只有这 M 个 token 改变）">δ′_i = μ_i + b_k + σ · (√(1 − ρ) · ε_i + √ρ · η_i) − w · ê_k / M</Formula>

<Formula label="带 Laplace 平滑的 P-UCT（论文式 III.6，此处先验均匀）">Score(a) = Q(a) + c_puct · P(a) · √(log(N + 1) / (N(a) + 1))</Formula>

<Formula label="几何回报（本 toy）">R = − Σ（对未来各阶段）max(0, |ê_j| − TOL)</Formula>

token 是以 cm 为单位的二维末端位移，所以一个 token 的误差会平移之后所有位置；长时程上误差就是这样累积的。`ρ` 表示旧噪声被替换的比例（本 toy 用它代替片段重新加噪的深度），`w` 是引导强度，`ê_k` 是阶段 k 终点误差的**带噪**估计，噪声 `σ_eval` 代表场景图误差。

**算例。** 一次性解码时，阶段 1 终点误差每个轴的标准差是 `√(8 · 0.4² + (8 · 0.15)²) = √2.72 = 1.649 cm`。二维高斯落在半径 r 以内的概率是 `1 − exp(−r² / (2 · 2.72))`：r = 1.0 cm 时为 0.168，r = 1.5 cm 时为 0.339。toy 的 200 次单阶段试验在 r = 1.5 时给出 0.2550。现在假设估计为 `ê = (1.2, −0.8)` cm，用 `w = 0.6`、`M = 8`、`ρ = 0.5` 编辑这个片段。引导让每个 token 移动 (−0.09, +0.06)，终点移动 (−0.72, +0.48)，即估计值的 60 %。重新加噪的部分还会在每个轴上叠加标准差 `√0.5 · 1.131 = 0.80 cm` 的新误差。所以一次编辑可能让结果更差，搜索只在估计回报变好时才保留候选，原因就在这里。

**完整性判据（没有积分步长）。** 每次部分去噪都是一次闭式跳跃，不按时间步进，不涉及步长稳定性判据。真正重要的是论文的判据。**一个阶段提交后，它的 token 永不改变**。编辑算子原样复制片段 k 以外的每个 token，当前阶段之前的片段也从不作为元动作出现。toy 统计每一组的前缀违例，独立测试要求为 0。它还打印反例：不加掩码的重新去噪会改变已提交阶段 1 的 8 个 token 中的 8 个。

### 公平设置

`forge_tree_mctd_toy.py` 是**合成**的，只用标准库。**模型假设**如下。
- 共 S 个阶段，每个阶段 M = 8 个 token。目标在 x 方向相隔 6–10 cm，y 方向最多 ±4 cm，示范位移 `μ` 从一个目标直线通到下一个目标。
- 冻结的解码器加上每阶段偏置 `b_j`（每个 token 标准差 0.15 cm）和每个 token 的噪声（σ = 0.4 cm）。没有网络，没有 VLA 似然，也没有场景图。
- 元动作是（从当前阶段起的片段 k，`ρ ∈ (0.5, 1.0)`，`w ∈ (0.3, 0.6)`）。片段长度固定为 M，没有步长。
- 树只有**一层**，根是当前计划，子节点是元动作。先验 P 均匀（1 / 子节点数），`c_puct = 1.0`。未访问的子节点先试，按快速启发式 `|ê_k| / TOL` 排序（相同时取较小的 ρ 和 w）。阶段 1 有 16 个子节点，预算 8 全部花在这个排序上；只有每个子节点都被访问过之后 UCT 项才起作用（阶段 4 只有 4 个子节点）。
- 候选的回报用新的噪声估计，若超过当前计划用同样方式估计的回报就保留。预算用完后提交当前阶段。

| 组 | 编辑哪个片段 | 预算 |
|---|---|---|
| A_oneshot | 不编辑（执行一次性解码） | 0 |
| B_tree | 一层 P-UCT，加快速启发式排序 | 每阶段 N 次模拟 |
| C_random | 在同样的元动作里均匀随机 | 同样的 N |

**共同随机数。** 每个（情形、种子、试验）的目标、一次性解码噪声、阶段偏置、候选噪声池和评估噪声池只抽一次。第 n 次模拟在 B 和 C 中都用池里的第 n 项。共 5 个种子 × 40 次试验。

指标：
- `stage`：在 TOL 以内到达的阶段目标比例。
- `final`：所有阶段都在 TOL 以内。
- `edits`：被接受的编辑次数。
- `prefix`：前缀违例次数。

| 情形 | 阶段数 | TOL | 每阶段模拟次数 | σ_eval |
|---|---|---|---|---|
| single_stage | 1 | 1.5 cm | 8 | 0.3 cm |
| long_loose | 4 | 4.0 cm | 8 | 0.3 cm |
| long_tight | 4 | 1.0 cm | 8 | 0.3 cm |
| low_budget | 4 | 1.0 cm | 1 | 0.3 cm |
| noisy_graph | 4 | 1.0 cm | 8 | 1.5 cm |

预算扫描用 N = 1、2、4、8、16 重跑 `long_tight`。

**看过结果后做的选择。** 第一次完整运行后，上面的参数一个都没改。之后只做了清理：删掉一个没用的 `mask` 参数，完整性那一行改为计算加掩码时的计数，而不是打印常数。运行过的每个情形都打印出来，包括搜索没有帮助的两个。

#!/usr/bin/env python3
"""Synthetic FORGE-Tree-style toy: one-shot decoding vs segment search with a frozen prefix. Stdlib only.

A trajectory is L = S x M action tokens; each token is a 2-D end-effector displacement (cm), so
positions are cumulative sums and an error in one token shifts every later position (drift
compounds). Stage j ends at token (j + 1) M - 1 and must land within TOL of its goal G_j.
The frozen "VLA + Diffusion Forcing head" stand-in decodes token i as the demo displacement
plus noise: delta_i = mu_i + b_j + SIGMA * eps_i (b_j a per-stage bias, eps_i ~ N(0, 1)).

Arms (same decoded trajectory, same candidate noise pool, same evaluation noise pool):
  A_oneshot  execute the one-shot decode (fixed schedule, no test-time search)
  B_tree     stage by stage: spend BUDGET partial-denoise simulations on future segments, chosen
             by P-UCT with Laplace smoothing (Score = Q + C_PUCT P sqrt(log(N + 1) / (N_a + 1)))
             over meta-actions a = (segment, strength, guidance); unvisited children are ordered by
             a fast heuristic (estimated end error / TOL); keep a candidate if its noisy geometry
             return beats the current plan's; then commit the current stage (prefix frozen)
  C_random   the same budget, edit operator, acceptance rule and commit, segment and meta-action
             picked uniformly at random (no tree value)
The tree here is depth 1 (root = current plan, children = meta-actions), a stand-in for the
paper's stage-aware MCTD; there is no scene graph, no VLA likelihood and no learned network.
Partial denoise of segment k at strength rho with guidance w (only segment k changes):
  delta'_i = mu_i + b_k + SIGMA (sqrt(1 - rho) eps_i + sqrt(rho) eta_i) - w e_hat / M
with eta from the shared candidate pool and e_hat the noisy estimate of stage k's end error.
Geometry return = - sum over future stages of max(0, |e_hat_j| - TOL)  (e_hat = e + N(0, SIGMA_EVAL)).

Integrity criterion (the paper preserves the executed prefix): once a stage is committed its
tokens never change; prefix violations are counted for every arm (must be 0 for B and C) and an
unmasked edit is printed as a check. No integration step: each partial denoise is one closed-form
jump, nothing is stepped in time.
Common random numbers: per (regime, seed, trial) the goals, the one-shot decode noise, the stage
biases, the candidate noise pool and the evaluation noise pool are drawn once; simulation number
n uses pool entry n in both B and C.
Metrics per trial, averaged over TRIALS per seed: stage (share of stage goals within TOL), final
(all stages within TOL), edits (accepted edits), prefix (prefix violations).
Labels: tie = identical on every seed; numerically zero = |paired mean| and sd both < 1e-9
(effectively a tie, no sign count); |m| <= sd = near-tie; |m| > sd = consistent gap (small if
|m| < 20 % of the smaller arm mean, else clear), with a sign count.
OpenVLA / Octo / LIBERO / a GPU: 本页未运行. Paper numbers: 以论文为准.
"""
import math
import random

SEEDS = (0, 1, 2, 3, 4)
TRIALS = 40
M = 8  # tokens per stage
SIGMA = 0.4  # per-token decode noise (cm)
BIAS = 0.15  # per-stage bias sd (cm per token)
SIGMA_EVAL = 0.3  # geometry-score noise (cm)
C_PUCT = 1.0
STRENGTHS = (0.5, 1.0)
GUIDES = (0.3, 0.6)
POOL = 400
NUM_ZERO = 1e-9
ARMS = ("A_oneshot", "B_tree", "C_random")
# name: (stages S, TOL cm, simulations per stage, SIGMA_EVAL)
REGIMES = {
    "single_stage": (1, 1.5, 8, SIGMA_EVAL),
    "long_loose": (4, 4.0, 8, SIGMA_EVAL),
    "long_tight": (4, 1.0, 8, SIGMA_EVAL),
    "low_budget": (4, 1.0, 1, SIGMA_EVAL),
    "noisy_graph": (4, 1.0, 8, 1.5),
}
BUDGETS = (1, 2, 4, 8, 16)


def world(stages, seed, trial, tag):
    """Common random numbers for one (regime, seed, trial)."""
    rng = random.Random(f"{tag}-{seed}-{trial}")
    goals, mu, p = [], [], (0.0, 0.0)
    for _ in range(stages):
        g = (p[0] + rng.uniform(6.0, 10.0), p[1] + rng.uniform(-4.0, 4.0))
        mu += [((g[0] - p[0]) / M, (g[1] - p[1]) / M)] * M
        goals.append(g)
        p = g
    bias = [(rng.gauss(0.0, BIAS), rng.gauss(0.0, BIAS)) for _ in range(stages)]
    eps = [(rng.gauss(0.0, 1.0), rng.gauss(0.0, 1.0)) for _ in range(stages * M)]
    pool = [[(rng.gauss(0.0, 1.0), rng.gauss(0.0, 1.0)) for _ in range(M)] for _ in range(POOL)]
    evals = [[(rng.gauss(0.0, 1.0), rng.gauss(0.0, 1.0)) for _ in range(stages)] for _ in range(2 * POOL + 2)]
    picks = [rng.random() for _ in range(2 * POOL)]
    return goals, mu, bias, eps, pool, evals, picks


def decode(mu, bias, eps):
    return [(mu[i][0] + bias[i // M][0] + SIGMA * eps[i][0], mu[i][1] + bias[i // M][1] + SIGMA * eps[i][1]) for i in range(len(mu))]


def stage_errors(tokens, goals):
    x = y = 0.0
    errs = []
    for i, (dx, dy) in enumerate(tokens):
        x += dx
        y += dy
        if (i + 1) % M == 0:
            g = goals[i // M]
            errs.append((x - g[0], y - g[1]))
    return errs


def estimate(errs, noise, sig):
    return [(e[0] + sig * n[0], e[1] + sig * n[1]) for e, n in zip(errs, noise)]


def ret(est, tol, first):
    return -sum(max(0.0, math.hypot(*e) - tol) for e in est[first:])


def edit(tokens, mu, bias, eps_now, k, rho, w, e_hat, eta):
    """Partial denoise of segment k only: every other token is copied unchanged."""
    out = list(tokens)
    new_eps = []
    for t in range(M):
        i = k * M + t
        ex = math.sqrt(1.0 - rho) * eps_now[i][0] + math.sqrt(rho) * eta[t][0]
        ey = math.sqrt(1.0 - rho) * eps_now[i][1] + math.sqrt(rho) * eta[t][1]
        new_eps.append((ex, ey))
        out[i] = (mu[i][0] + bias[k][0] + SIGMA * ex - w * e_hat[0] / M, mu[i][1] + bias[k][1] + SIGMA * ey - w * e_hat[1] / M)
    return out, new_eps


def run(arm, regime, seed, trial, budget=None):
    stages, tol, sims, sig = REGIMES[regime]
    sims = sims if budget is None else budget
    goals, mu, bias, eps, pool, evals, picks = world(stages, seed, trial, regime)
    tokens = decode(mu, bias, eps)
    eps_now = list(eps)
    edits = viol = 0
    n = 0  # simulation counter: pool entry n is used by B and C alike
    if arm != "A_oneshot":
        for s in range(stages):
            actions = [(k, rho, w) for k in range(s, stages) for rho in STRENGTHS for w in GUIDES]
            visits, value = {a: 0 for a in actions}, {a: 0.0 for a in actions}
            for _ in range(sims):
                cur = estimate(stage_errors(tokens, goals), evals[2 * n], sig)
                if arm == "B_tree":
                    unvisited = [a for a in actions if visits[a] == 0]
                    if unvisited:
                        a = max(unvisited, key=lambda a: (math.hypot(*cur[a[0]]) / tol, -a[1], -a[2]))
                    else:
                        tot = sum(visits.values())
                        a = max(actions, key=lambda a: value[a] / visits[a] + C_PUCT / len(actions) * math.sqrt(math.log(tot + 1) / (visits[a] + 1)))
                else:
                    a = actions[int(picks[n] * len(actions))]
                k, rho, w = a
                cand, cand_eps = edit(tokens, mu, bias, eps_now, k, rho, w, cur[k], pool[n % POOL])
                new = estimate(stage_errors(cand, goals), evals[2 * n + 1], sig)
                gain = ret(new, tol, s) - ret(cur, tol, s)
                visits[a] += 1
                value[a] += gain
                if gain > 0.0:
                    before = tokens[: s * M]
                    tokens = cand
                    for t in range(M):
                        eps_now[k * M + t] = cand_eps[t]
                    edits += 1
                    viol += sum(1 for p, q in zip(before, tokens[: s * M]) if p != q)
                n += 1
    errs = stage_errors(tokens, goals)
    ok = [math.hypot(*e) <= tol for e in errs]
    return {"stage": sum(ok) / len(ok), "final": 1.0 if all(ok) else 0.0, "edits": float(edits), "prefix": float(viol)}


def unmasked_edit_check():
    """Stage 1 committed: a masked edit of segment 2 vs a re-denoise of the whole trajectory (no mask)."""
    goals, mu, bias, eps, pool, evals, picks = world(4, 0, 0, "long_tight")
    tokens = decode(mu, bias, eps)
    masked, _ = edit(tokens, mu, bias, eps, 1, 1.0, 0.3, (0.0, 0.0), pool[0])
    redo = decode(mu, bias, [(math.sqrt(0.5) * a[0] + math.sqrt(0.5) * b[0], math.sqrt(0.5) * a[1] + math.sqrt(0.5) * b[1]) for a, b in zip(eps, [p for seg in pool[:4] for p in seg])])
    changed = lambda new: sum(1 for p, q in zip(tokens[:M], new[:M]) if p != q)
    return changed(redo), changed(masked)


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


KEYS = ("stage", "final", "edits", "prefix")


def per_seed(arm, regime, budget=None):
    out = []
    for seed in SEEDS:
        rs = [run(arm, regime, seed, t, budget) for t in range(TRIALS)]
        out.append({k: sum(r[k] for r in rs) / TRIALS for k in KEYS})
    return out


def main():
    print("Synthetic FORGE-Tree-style toy; displacement tokens, depth-1 segment search, frozen prefix; not OpenVLA / Octo / LIBERO")
    print(f"seeds={len(SEEDS)} trials={TRIALS} tokens/stage={M} sigma={SIGMA} bias={BIAS} c_puct={C_PUCT} strengths={STRENGTHS} guidance={GUIDES}; no integration step (closed-form partial denoise)")
    bad, good = unmasked_edit_check()
    print(f"integrity check: a re-denoise without the segment mask changes {bad} of the {M} committed stage-1 tokens; a masked edit of segment 2 changes {good}")
    print("regime arm stage final edits prefix  (mean+-sd over seeds of per-seed trial means)")
    for regime, (stages, tol, sims, sig) in REGIMES.items():
        print(f"{regime} (stages={stages}, tol={tol} cm, simulations/stage={sims}, sigma_eval={sig} cm)")
        res = {arm: per_seed(arm, regime) for arm in ARMS}
        for arm in ARMS:
            cells = " ".join("{}+-{}".format(*map(num, mean_sd([r[k] for r in res[arm]]))) for k in KEYS)
            print(f"  {arm} {cells}")
        for x, y in (("B_tree", "A_oneshot"), ("C_random", "B_tree"), ("C_random", "A_oneshot")):
            for k in ("stage", "final"):
                print(f"  paired {x[0]}-{y[0]} {k}: {verdict([r[k] for r in res[x]], [r[k] for r in res[y]])}")
    print("budget sweep on long_tight (final: mean over seeds; paired B-A final)")
    a = per_seed("A_oneshot", "long_tight")
    for b in BUDGETS:
        rb = per_seed("B_tree", "long_tight", budget=b)
        rc = per_seed("C_random", "long_tight", budget=b)
        print(f"  budget={b}: A {num(mean_sd([r['final'] for r in a])[0])} B {num(mean_sd([r['final'] for r in rb])[0])} C {num(mean_sd([r['final'] for r in rc])[0])}; B-A final: {verdict([r['final'] for r in rb], [r['final'] for r in a])}")
    print("No winner declared: search helps where clearances are tight and the score is informative; it costs edits and can hurt when the score is noisy or the budget tiny")
    print("Real FORGE-Tree on OpenVLA / Octo, LIBERO, a GPU: 本页未运行; Huang et al. results 以论文为准")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Stdlib stand-in of fixed-rate chunks vs motion-dependent splines.

Stdlib only. Not a GPU LIBERO-X / EBench / real cooking run, and not a
redo of RTC seam-smoothing, FORGE-Tree, or pi0 / flow-matching already
on this page or on flow-matching-policies. GPU / real cooking / EBench:
本页未运行.

Vela (Li, Wang, Wu, et al., arXiv 2610.05230 v1) represents future
robot behaviour as continuous trajectories: a compact spline-based
action with motion-dependent temporal support, so a fixed output budget
can trade horizon against local resolution instead of emitting a
fixed-rate action chunk. The visible title spelling is Parametrization.
Paper scores on LIBERO-X, EBench, and the real egg-cake cooking and
potato-shredding tasks are 以论文为准 and are not toy outputs.

Shared continuous reference motions (a long smooth move and a short
precise move), a shared output-budget K, and a shared query grid are
generated once per (regime, seed) and then read by every arm (common
random numbers).

Arms:
  A_fixed     fixed-rate action chunk of length K (uniform temporal grid)
  B_spline    compact spline / control-point curve with motion-dependent
              temporal support, evaluated on the same query grid
  C_lose      the same K budget spread so a long horizon becomes too
              coarse (official). A spline queried on a dropped-knot
              support is a named alternative on the same seeds.

Regimes and parameters were written before the first run.

Labels: tie = identical on every seed; numerically zero = |paired mean|
and sd both < 1e-9; |m| <= sd = near-tie; |m| > sd = consistent gap
(small if |m| < 20 % of the smaller arm mean, else clear), with a
sign count. ROUND_HALF_UP output. Lower tracking error is better.

Vela paper: body read; 以论文为准.
"""
from __future__ import annotations

import math
import random
from decimal import ROUND_HALF_UP, Decimal, getcontext

getcontext().rounding = ROUND_HALF_UP

SEEDS = (0, 1, 2, 3, 4)
NUM_ZERO = 1e-9
SMALL_FRAC = 0.2000  # 20 % of the smaller-arm mean; printed as 0.2000

# Declared stand-in parameters. Written before the first run.
# These are toy tracking errors, not paper success rates.
K = 8
N_QUERY = 121
T_SHORT = 1.0000
T_LONG = 4.0000
T_PRECISE = 1.0000
# Mixed motion lives on [0, T_LONG + T_PRECISE].
T_MIXED = T_LONG + T_PRECISE
# C official: stretch the same K over a longer horizon, which coarsens
# the precise part. Named alternative (same seeds, not adopted): drop
# the knot nearest the precise peak.
C_STRETCH = 2.0000
BUMP_AMP = 1.0000
BUMP_WIDTH = 0.1600

ARMS = ("A_fixed", "B_spline", "C_lose")

REGIMES = {
    "short_smooth": (
        "short, already-smooth move whose uniform grid is fine enough; "
        "A and B may near-tie on tracking error - keep"
    ),
    "mixed_motion": (
        "long smooth + short precise under the same K; B consistent "
        "lower error than A - keep"
    ),
    "coarse_horizon": (
        "C spreads the same K over a longer horizon and loses - keep"
    ),
}


def mean_sd(xs):
    if all(x == xs[0] for x in xs):
        return xs[0], 0.0
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-4:
        return format(Decimal(repr(x)), ".3e")
    s = format(Decimal(repr(x)), ".4f")
    return "0.0000" if s == "-0.0000" else s


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < SMALL_FRAC * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def rng_for(*parts):
    material = "vela-spline|" + "|".join(str(p) for p in parts)
    return random.Random(material)


def linspace(a, b, n):
    if n == 1:
        return [a]
    step = (b - a) / (n - 1)
    return [a + i * step for i in range(n)]


def query_grid(horizon):
    return linspace(0.0, horizon, N_QUERY)


def bump(t, center, amp=BUMP_AMP, width=BUMP_WIDTH):
    """A compact smooth bump (not a toy paper score)."""
    u = (t - center) / width
    return amp * math.exp(-0.5 * u * u)


def reference(regime, t):
    """Shared continuous reference. 2-D path (x, y)."""
    if regime == "short_smooth":
        # Already-smooth unit-time line; a uniform grid is exact.
        return (t, t)
    # Long smooth transport on [0, T_LONG], then a short precise bump.
    x = t
    if t <= T_LONG:
        y = 0.0
    else:
        y = bump(t, T_LONG + 0.5 * T_PRECISE)
    return (x, y)


def curvature_weight(regime, t, dt=0.0100):
    """Local motion variation used only to place B's temporal support."""
    horizon = T_SHORT if regime == "short_smooth" else T_MIXED
    t0 = t - dt
    t1 = t + dt
    if t0 < 0.0 or t1 > horizon:
        # One-sided speed only; an uneven stencil would invent curvature
        # at the endpoints of a straight move.
        t0 = max(0.0, t0)
        t1 = min(horizon, t1)
        x0, y0 = reference(regime, t0)
        x1, y1 = reference(regime, t1)
        speed = math.hypot(x1 - x0, y1 - y0) / max(t1 - t0, 1e-12)
        return 0.0500 + speed
    x0, y0 = reference(regime, t0)
    x1, y1 = reference(regime, t1)
    xm, ym = reference(regime, t)
    speed = math.hypot(x1 - x0, y1 - y0) / max(t1 - t0, 1e-12)
    second = math.hypot(x0 - 2.0 * xm + x1, y0 - 2.0 * ym + y1) / max((t1 - t0) ** 2, 1e-12)
    return 0.0500 + speed + 8.0000 * second


def invert_cdf(dense, cdf, frac):
    if frac <= 0.0:
        return dense[0]
    if frac >= 1.0:
        return dense[-1]
    i = 1
    while i < len(cdf) - 1 and cdf[i] < frac:
        i += 1
    t0, t1 = dense[i - 1], dense[i]
    c0, c1 = cdf[i - 1], cdf[i]
    if c1 == c0:
        return t1
    return t0 + (frac - c0) / (c1 - c0) * (t1 - t0)


def motion_dependent_times(regime, horizon, k=K):
    """Place K strictly increasing support times by local variation."""
    dense = linspace(0.0, horizon, 400)
    weights = [curvature_weight(regime, t) for t in dense]
    total = sum(weights)
    acc = 0.0
    cdf = []
    for w in weights:
        acc += w
        cdf.append(acc / total)
    raw = [invert_cdf(dense, cdf, j / (k - 1)) for j in range(k)]
    raw[0] = 0.0
    raw[-1] = horizon
    min_gap = horizon / (8.0 * (k - 1))
    times = [0.0]
    n_left = k - 2  # remaining interior + we add them one by one
    for idx, t in enumerate(raw[1:-1]):
        remain = k - 1 - (idx + 1)  # points still to place after this one, including end
        latest = horizon - min_gap * remain
        t = min(max(t, times[-1] + min_gap), latest)
        times.append(t)
    times.append(horizon)
    if not all(times[i] > times[i - 1] for i in range(1, len(times))):
        times = linspace(0.0, horizon, k)
    return times


def piecewise_linear(ts, xs, ys, query):
    out = []
    i = 0
    for t in query:
        while i + 1 < len(ts) - 1 and ts[i + 1] < t:
            i += 1
        t0, t1 = ts[i], ts[i + 1]
        if t1 == t0:
            out.append((xs[i], ys[i]))
            continue
        a = (t - t0) / (t1 - t0)
        a = 0.0 if a < 0.0 else 1.0 if a > 1.0 else a
        out.append((xs[i] + a * (xs[i + 1] - xs[i]), ys[i] + a * (ys[i + 1] - ys[i])))
    return out


def finite_slopes(ts, vs):
    """Finite-difference tangents for a cubic Hermite / Catmull-Rom curve."""
    n = len(ts)
    s = [0.0] * n
    s[0] = (vs[1] - vs[0]) / (ts[1] - ts[0])
    s[-1] = (vs[-1] - vs[-2]) / (ts[-1] - ts[-2])
    for i in range(1, n - 1):
        s[i] = (vs[i + 1] - vs[i - 1]) / (ts[i + 1] - ts[i - 1])
    return s


def eval_hermite(ts, vs, slopes, query):
    out = []
    i = 0
    for t in query:
        while i + 1 < len(ts) - 1 and ts[i + 1] < t:
            i += 1
        t0, t1 = ts[i], ts[i + 1]
        h = t1 - t0
        if h == 0.0:
            out.append(vs[i])
            continue
        u = (t - t0) / h
        u = 0.0 if u < 0.0 else 1.0 if u > 1.0 else u
        h00 = 2.0 * u ** 3 - 3.0 * u ** 2 + 1.0
        h10 = u ** 3 - 2.0 * u ** 2 + u
        h01 = -2.0 * u ** 3 + 3.0 * u ** 2
        h11 = u ** 3 - u ** 2
        out.append(h00 * vs[i] + h10 * h * slopes[i] + h01 * vs[i + 1] + h11 * h * slopes[i + 1])
    return out


def spline_path(ts, xs, ys, query):
    """Cubic Hermite curve through the control points, same query grid."""
    sx = finite_slopes(ts, xs)
    sy = finite_slopes(ts, ys)
    qx = eval_hermite(ts, xs, sx, query)
    qy = eval_hermite(ts, ys, sy, query)
    return list(zip(qx, qy))


def rmse(pred, truth):
    acc = 0.0
    for (x0, y0), (x1, y1) in zip(pred, truth):
        acc += (x0 - x1) ** 2 + (y0 - y1) ** 2
    return math.sqrt(acc / len(truth))


def sample_at(regime, times):
    xs, ys = [], []
    for t in times:
        x, y = reference(regime, t)
        xs.append(x)
        ys.append(y)
    return xs, ys


def dropped_knot_times(times, regime):
    """Drop the support time nearest the precise peak (broken support)."""
    if regime == "short_smooth":
        # Still drop an interior knot so C is a broken support on the
        # same short move (declared lose arm).
        peak = 0.5 * T_SHORT
    else:
        peak = T_LONG + 0.5 * T_PRECISE
    interior = list(range(1, len(times) - 1))
    drop = min(interior, key=lambda i: abs(times[i] - peak))
    return [t for i, t in enumerate(times) if i != drop]


def evaluate(regime, seed, stretch=None, drop_knot=False, k=K):
    # Seed is part of the CRN contract even when the official geometry
    # is deterministic: the shared bank is reserved for alternatives.
    _ = rng_for(regime, seed, "bank")
    if regime == "short_smooth":
        horizon = T_SHORT
        ref_regime = "short_smooth"
        official_stretch = 1.0000
    else:
        # mixed_motion and coarse_horizon share the mixed reference.
        horizon = T_MIXED
        ref_regime = "mixed_motion"
        official_stretch = C_STRETCH
    query = query_grid(horizon)
    truth = [reference(ref_regime, t) for t in query]

    # A: fixed-rate chunk of length K on the true horizon.
    a_times = linspace(0.0, horizon, k)
    ax, ay = sample_at(ref_regime, a_times)
    a_pred = piecewise_linear(a_times, ax, ay, query)

    # B: cubic Hermite curve on motion-dependent support, same K, same query.
    b_times = motion_dependent_times(ref_regime, horizon, k=k)
    bx, by = sample_at(ref_regime, b_times)
    b_pred = spline_path(b_times, bx, by, query)

    # C official: the same K spread over a longer horizon (too coarse).
    # Alternative (drop_knot=True): query a spline on a dropped-knot support.
    if drop_knot:
        c_times = dropped_knot_times(b_times, ref_regime)
        cx, cy = sample_at(ref_regime, c_times)
        c_pred = spline_path(c_times, cx, cy, query)
    else:
        use_stretch = official_stretch if stretch is None else stretch
        c_times = [t for t in linspace(0.0, horizon * use_stretch, k) if t <= horizon + 1e-12]
        if not c_times:
            c_times = [0.0, horizon]
        if c_times[0] != 0.0:
            c_times = [0.0] + c_times
        if c_times[-1] < horizon:
            c_times.append(horizon)
        cx, cy = sample_at(ref_regime, c_times)
        c_pred = piecewise_linear(c_times, cx, cy, query)

    return {
        "k": k,
        "n_query": N_QUERY,
        "horizon": horizon,
        "A_rmse": rmse(a_pred, truth),
        "B_rmse": rmse(b_pred, truth),
        "C_rmse": rmse(c_pred, truth),
        "A_n": len(a_times),
        "B_n": len(b_times),
        "C_n": len(c_times),
    }


def official_rows(name, stretch=None, drop_knot=False, k=K):
    return [evaluate(name, seed, stretch=stretch, drop_knot=drop_knot, k=k) for seed in SEEDS]


def print_regime(title, rows):
    print(f"regime {title}  (mean+-sd over seeds)")
    print(
        f"  k={rows[0]['k']} n_query={rows[0]['n_query']} "
        f"horizon={num(rows[0]['horizon'])} "
        f"A_n={rows[0]['A_n']} B_n={rows[0]['B_n']} C_n={rows[0]['C_n']}"
    )
    a = [r["A_rmse"] for r in rows]
