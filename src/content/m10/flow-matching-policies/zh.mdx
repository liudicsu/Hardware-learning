## 输出动作的三种方式

[6.2](/zh/month/month-6/act-diffusion) 讲过示范数据的核心难题：专家有时从障碍物左边绕、有时从右边绕，用均方误差训练的策略会输出两者的**平均**，正好撞上障碍物。

| 动作头 | 网络学什么 | 动作怎么出来 | 推理代价 |
| --- | --- | --- | --- |
| MSE 回归 | 每个观测对应一个动作 | 一次前向 | 最低；会把模式平均掉 |
| 扩散（6.2） | 每一步加进去的噪声 | 多步去噪 | 多次前向 |
| <Term id="flow-matching">流匹配</Term> | <Term id="velocity-field">速度场</Term> v(x, τ) | 从噪声沿速度场积分 | 几步到几十步 |

流匹配（Lipman 等，arXiv **2210.02747**）训练连续归一化流时不需要模拟整条流：网络沿一条从噪声到数据的固定路径回归目标速度。因为路径是直线，少量积分步就能得到不错的样本。

## π0 的约定

π0（arXiv **2410.24164**）在 PaliGemma 3B 视觉语言模型上接一个 3 亿参数的动作专家（合计约 3.3B 参数），一次预测 **H=50** 个动作。按论文记号，它的流匹配约定是：

- 路径：`A^τ = τ·A + (1−τ)·ε`，其中 `ε ~ N(0, I)`，τ 从 0（纯噪声）到 1（动作块）。
- 目标速度：`u = A − ε`。网络学 `v_θ(A^τ, o) ≈ u`。
- 训练时 τ 从一个偏向噪声较大（τ 较小）时刻的 Beta 分布中采样，截断值 s = 0.999。
- 推理：从噪声出发做前向欧拉，`A^{τ+δ} = A^τ + δ·v_θ`，共 **10** 步（`δ = 0.1`）。

这 10 步每一步都要再跑一次动作专家。论文在 RTX 4090 上报告：10 步动作流 **27 ms**，板上合计 **73 ms**（图像编码器 14 ms、观测前向 32 ms）。步数是推理延迟的一部分；这段延迟对动作块接缝的影响由 [10.2](/zh/month/month-10/real-time-chunking) 处理。以上是论文公布的数字，本页未运行。

## 跑闭式玩具

```python
"""flow_match_toy.py: 1-D flow matching with a closed-form velocity (stdlib).

Target: a bimodal mixture 0.5*N(-1, 0.1^2) + 0.5*N(+1, 0.1^2) — think of it as
"go left of the obstacle" vs "go right". Path (pi0 convention):

    x_tau = tau * x1 + (1 - tau) * eps,   eps ~ N(0, 1),   tau in [0, 1]
    target velocity u = x1 - eps

Because the target is a Gaussian mixture, the *marginal* velocity
E[x1 - eps | x_tau = x] has a closed form, so no network is trained here.
We integrate it with forward Euler from tau=0 (noise) to tau=1 and count how
many samples land near a mode vs near the (invalid) mean 0.

This is a toy: a real policy learns v_theta(A_tau, obs) with a network.
"""

import math
import random

SEED = 7
N = 2000
MODES = (-1.0, 1.0)
SIGMA = 0.1
STEPS = (1, 2, 3, 5, 10, 50)
NEAR = 0.3  # "near" radius for both mode and mean


def gauss(rng: random.Random) -> float:
    """Box-Muller from rng.random() so the stream is stable across versions."""
    u1 = rng.random()
    u2 = rng.random()
    return math.sqrt(-2.0 * math.log(1.0 - u1)) * math.cos(2.0 * math.pi * u2)


def velocity(x: float, tau: float) -> float:
    """Closed-form marginal velocity E[x1 - eps | x_tau = x] for the mixture."""
    var = tau * tau * SIGMA * SIGMA + (1.0 - tau) ** 2
    cov = tau * SIGMA * SIGMA - (1.0 - tau)  # Cov(x1 - eps, x_tau | mode)
    logw = [-(x - tau * m) ** 2 / (2.0 * var) for m in MODES]
    top = max(logw)
    w = [math.exp(v - top) for v in logw]
    z = sum(w)
    return sum(
        (wk / z) * (m + cov / var * (x - tau * m)) for wk, m in zip(w, MODES)
    )


def sample(x0: float, steps: int) -> float:
    x = x0
    dt = 1.0 / steps
    for k in range(steps):
        x = x + dt * velocity(x, k * dt)
    return x


def main() -> None:
    rng = random.Random(SEED)
    noise = [gauss(rng) for _ in range(N)]
    print(f"target: 0.5*N(-1,{SIGMA}^2) + 0.5*N(+1,{SIGMA}^2)  samples={N}  seed={SEED}")
    print(f"v(x=0.50, tau=0.0) = {velocity(0.5, 0.0):+.3f}   (= mean(x1) - x)")
    print(f"v(x=0.50, tau=0.9) = {velocity(0.5, 0.9):+.3f}   (points to the +1 mode)")
    print(f"{'steps':>5} {'near_mode':>9} {'near_mean':>9} {'mean_abs':>8}")
    for steps in STEPS:
        xs = [sample(x0, steps) for x0 in noise]
        near_mode = sum(1 for x in xs if abs(abs(x) - 1.0) < NEAR) / N
        near_mean = sum(1 for x in xs if abs(x) < NEAR) / N
        mean_abs = sum(abs(x) for x in xs) / N
        print(f"{steps:>5} {near_mode:>9.3f} {near_mean:>9.3f} {mean_abs:>8.3f}")
    print("1 Euler step lands every sample on the mean (an action between the modes);")
    print("more steps recover both modes. pi0 uses 10 steps (delta = 0.1).")


if __name__ == "__main__":
    main()
```

怎么读：

- τ=0 时速度场是 `mean(x1) − x`：噪声还没「看到」任何模式，所有样本都被拉向平均值 0。只走 **1** 步时整条轨迹就是这一步：near_mean = **1.000**，和 MSE 的失败一模一样。
- 路径后段（τ=0.9）在 x=0.5 处速度为 **+3.011**，强烈指向 +1 模式。步数越多，样本越有时间选定一边：3 步 near_mode 升到 **0.780**，10 步 **0.987**，50 步 **0.996**。
- 10 步已拿到大部分质量；从 10 步加到 50 步收益很小，却要多跑 5 倍动作专家。这就是 π0 选 10 步的原因。

这是玩具：真实策略要用网络从数据里学 `v_θ`，并以观测为条件。

## 更少的步数：rectified flow 与一致性

每一步都占延迟，所以有几条工作线追求更少步数。Rectified flow（arXiv 2209.03003）把学到的路径「拉直」，让粗的欧拉步也不跑偏。Consistency Policy（arXiv 2405.07503）把扩散策略蒸馏成一两步即可；其摘要称推理比所比较的最快替代方法快一个数量级。本课只讲动机，不推导也不运行。

## absolute、relative 与 delta 动作

动作块里*装的是什么*，和怎么采样同样重要。LeRobot 的动作表示页区分三种：

| 表示 | 每个动作是 | 说明 |
| --- | --- | --- |
| absolute | 目标关节（或末端）位置 | LeRobot 默认 |
| relative | 目标减去块开始时的当前状态 | OpenPI / π0 使用；误差不会跨块累积 |
| delta | 相对上一个动作的变化量 | 误差沿块累积；UMI 主张不用 |

relative 动作与 RTC（10.2）兼容。`--policy.use_relative_actions=true` 等参数以 LeRobot v0.6.x 文档为准，命令可能随版本变化。本页未运行。

## 常见错误

- **为省时间只用 1、2 步却不检查样本。** 玩具显示 1 步会塌到均值，和 MSE 同样失败。
- **默认认为流匹配「比扩散快」。** 路径直，得到好样本所需步数少；但每一步仍是一次完整的动作专家前向。
- **混用动作表示。** 用 relative 动作训练、却当 absolute 目标执行，机械臂会去错地方。
- **把 73 ms 当成你机器人的延迟。** 那是论文在 RTX 4090 上的数字，本页没有实测。

## OneDP 风格单步回归替身
[OneDP 原论文](https://arxiv.org/abs/2410.21257)把预训练扩散策略蒸馏为单步生成器：沿去噪链匹配**加噪动作分布的反向 KL**，梯度依赖 score 之差；OneDP-S 加辅助 score 估计器，OneDP-D 使用解析简化。这个 KL-along-chain 目标**只作阅读**，不是逐点教师 MSE。[Consistency Policy](https://arxiv.org/abs/2405.07503)使用沿概率流 ODE 的一致性轨迹建模 / 自一致性及去噪目标；这里两篇都没有实现。OneDP 的额外 2 %–10 % 成本、1.5→62 Hz 及任何 Consistency Policy 数字均**以论文为准**。真实扩散 / GPU / 机器人：**本页未运行**。

论文中的 Hz 与成功率数字仅供阅读对比，不是本页实测或复现结果。

新增实验只是**回归替身** （regression surrogate）：教师是解析迭代器，不是学到的扩散模型；不复现多模态动作分布或 score 目标，也不推翻上面的闭式混合玩具：单步生成需要学到的信息，不是直接删积分步。本节不重做 RTC（10.2）、Cal-ConRFT / 优势筛选（10.7）或 VLA RL（8.2）。

### 声明数据、拟合预算与独立成功判据

合成对象位移 `D(a)=a+0.22*a³`，起始位置 `x0=−e`，目标 0。教师从 `a=0` 开始，做八次 `a←a+0.5*(e−D(a))`：**N=8 次实际场函数调用**，无需训练。**11/23/37/53/71** 每个种子生成 64 个 `e∈[−1.2,1.2]` 分层演示，每格内分数 0.25…0.75，标签为 `teacher(e)+Normal(0,0.008²)`，并生成一份共享随机初值。两学生拿到完全相同的演示对、特征和初值。四个固定 Legendre 特征为 `[1,x,(5x³−3x)/2,(63x⁵−70x³+15x)/8]`，`x=e/1.2`。全批 MSE 梯度下降 lr=0.25；完整学生 **240 次更新**，刻意欠拟合的学生 **2 次**。更新数不同是欠拟合对照，**不宣称收敛或训练效率比较**。

三组用相同 64 个**留出评估起始**（每格内分数 0.9，与所有种子的训练状态不交）。拟合函数不给评估起始或教师评估标签。动作 MSE 对照留出教师动作；教师自身的 MSE **按定义为零**，并非真值。独立任务成功由非线性对象判 `abs(−e+D(a))≤0.004`，不是看是否模仿教师。一次学生特征点积前向计 NFE=1，教师每次场函数计一次；评分器参考查询不计入策略推理 NFE。两类调用的 FLOPs 不同：**NFE 不是实测延迟或 Hz**，8→1 不代表墙钟快 8 倍。

```python
#!/usr/bin/env python3
"""OneDP-style REGRESSION SURROGATE, not KL-along-chain/score distillation.
Synthetic analytic eight-field-call teacher solves a nonlinear inverse plant.
Both students see the SAME 64 noisy teacher demos and copy the SAME init;
240 vs 2 updates is a deliberately unequal underfit control, not convergence proof.
Every scored state/start is held out; fit() never receives eval states/labels.
NFE counts actual field/forward calls, not FLOPs, Hz or wall-clock speed.
Original Consistency Policy and GPU OneDP/Franka are not run: 本页未运行.
"""
from random import Random
from statistics import mean, pstdev

SEEDS = (11, 23, 37, 53, 71)
N_STEPS = 8
N_DEMOS = N_EVAL = 64
FULL_UPDATES, UNDER_UPDATES = 240, 2
LR, DEMO_SIGMA, TOLERANCE = .25, .008, .004
EVAL_STARTS = tuple(-1.2 + 2.4*(j+.9)/N_EVAL for j in range(N_EVAL))


def displacement(action):
    """Independent nonlinear one-step plant: x_next=-error+D(action), goal=0."""
    return action + .22*action**3


def field(error, action):
    return error - displacement(action)


def teacher(error):
    action, nfe = 0., 0
    for _ in range(N_STEPS):
        action += .5*field(error, action)
        nfe += 1
    return action, nfe


def features(error):
    """Fixed Legendre basis on normalized error; not evaluated teacher labels."""
    x = error/1.2
    return (1., x, (5*x**3-3*x)/2, (63*x**5-70*x**3+15*x)/8)


def student(weights, error):
    return sum(w*x for w,x in zip(weights, features(error))), 1


def demonstrations(seed):
    rng = Random(seed)
    # Training fractional bins .25..75 never overlap held-out fractional bin .9.
    starts = tuple(-1.2 + 2.4*(j+.25+.5*rng.random())/N_DEMOS for j in range(N_DEMOS))
    demos = tuple((s, teacher(s)[0]+rng.gauss(0,DEMO_SIGMA)) for s in starts)
    initial = tuple(rng.gauss(0,.02) for _ in range(4))
    return demos, initial


def fit(demos, initial, updates):
    """Only training pairs and initial weights; no teacher query or held-out input."""
    weights = list(initial)
    design = tuple((features(state), label) for state,label in demos)
    for _ in range(updates):
        gradient = [0.]*len(weights)
        for basis, label in design:
            residual = sum(w*x for w,x in zip(weights,basis))-label
            for j,x in enumerate(basis):
                gradient[j] += 2*residual*x/len(design)
        weights = [w-LR*g for w,g in zip(weights,gradient)]
    return tuple(weights)


def evaluate(policy, starts, references, training_states):
    if set(starts) & set(training_states):
        raise ValueError("training/evaluation state overlap")
    mse, successes, calls = 0., 0, 0
    for state, reference in zip(starts,references):
        action, nfe = policy(state)
        mse += (action-reference)**2
        successes += int(abs(-state+displacement(action)) <= TOLERANCE)
        calls += nfe
    return mse/len(starts), calls/len(starts), successes/len(starts)


def run(seed):
    demos, initial = demonstrations(seed)
    full, under = fit(demos, initial,FULL_UPDATES), fit(demos, initial,UNDER_UPDATES)
    # References are SCORER-ONLY; no student inference/fitting receives them.
    references = tuple(teacher(s)[0] for s in EVAL_STARTS)
    states = tuple(s for s,_ in demos)
    policies = (("teacher_N8",teacher,0),
                ("student_1",lambda s: student(full,s),FULL_UPDATES),
                ("underfit_1",lambda s: student(under,s),UNDER_UPDATES))
    return [(name,updates,evaluate(policy,EVAL_STARTS,references,states)) for name,policy,updates in policies]


def main():
    print("OneDP-style regression surrogate ONLY; KL-along-chain is reading, not implemented")
    print("shared demos=64 held-out eval starts=64 overlap=0; N-step teacher=8 actual field calls")
    print("student updates=240 underfit updates=2 (unequal on purpose); same data/features/init")
    print("demo_sigma=0.008 success_abs_plant_error<=0.004; NFE is calls, not Hz or wall time")
    print("seed arm fit_updates action_MSE NFE_per_query success")
    all_rows = {name: [] for name in ("teacher_N8","student_1","underfit_1")}
    for seed in SEEDS:
        for name,updates,metrics in run(seed):
            all_rows[name].append(metrics)
            mse,nfe,success=metrics
            print(f"{seed} {name} {updates} {mse:.8f} {nfe:.1f} {success:.6f}")
    print("five-seed spread: arm metric mean population_sd min max")
    for name,rows in all_rows.items():
        for j,metric in enumerate(("action_MSE","NFE","success")):
            values=[row[j] for row in rows]
            print(f"{name} {metric} {mean(values):.8f} {pstdev(values):.8f} {min(values):.8f} {max(values):.8f}")
    print("Teacher self-reference MSE=0 by definition; success independently uses nonlinear plant")
    print("Scorer reference queries excluded from policy NFE; different call types are not equal FLOPs")
    print("No diffusion distribution/score/consistency training; GPU and robot: 本页未运行; paper 以论文为准")


if __name__ == "__main__":
    main()
```

## Diffusion Forcing：每个 token 一个独立噪声级

上面的内容都把动作块当成一个整体一起去噪，每个元素处在同一个噪声级。**Diffusion Forcing** 问的是：如果训练时序列里每个 **token**（一个动作、一个状态、一帧）都有**自己独立的噪声级**，会怎样？这样训练出的因果模型，既能当 next-token 预测器用（过去干净、下一个 token 带噪），也能当整序列扩散用（所有 token 一样噪），或者介于两者之间，而且由采样器挑模式，不必重训。这一节**不是**上面 OneDP 的一致性蒸馏，**不是** WorldVLA 的注意力掩码，也**不是**把流匹配的数学重讲一遍：它讲的是**模型在训练时见过哪些噪声模式**。

**实际打开过的来源（读过正文）。** **Diffusion Forcing（arXiv 2407.01392，HTML 与 PDF 经 pdftotext；NeurIPS 2024）。** 第 3.1 节把加噪看成**部分掩码**：teacher forcing 掩掉下一个 token、用干净的过去预测它（沿时间轴掩码），整序列扩散把所有 token 加到同一噪声级（沿噪声轴掩码）。第 3.2 节：每个 token `x_t` 的噪声级 `k_t` **独立**采样（算法 1；附录 B.2：在各噪声级上独立同分布的均匀分布），因果 RNN 维持一个隐状态 `z_t`，损失就是对各 token 求和的普通噪声预测损失（式 3.1）；定理 3.1 说明它优化的是一个重加权的 ELBO，在一定条件下同时是所有噪声级序列的下界。采样沿一个调度矩阵 `K` 往下走（行 = 去噪步，列 = token）。第 3.3 节与附录 B.4：长 rollout 靠在小噪声级 `0 < k_small ≪ K` 下以前一个 token 为条件来**稳定**；zig-zag 调度让远期比近期更噪；未来 token 的引导梯度可以影响过去的 token（第 3.3 节，第 3.4 节的 Monte Carlo Guidance）。第 4.1 节：在 DMLab 和 Minecraft 视频上，用同一个 RNN 的 teacher forcing 和因果整序列基线在超出训练长度后**发散**，Diffusion Forcing 却能稳定 rollout（例如 1000 帧）。第 4.2 节：在 Maze2D 规划上它胜过 Diffuser，后者要靠手写 PD 控制器才能执行自己的计划。第 4.4 节：在一个需要记住初始摆放的真实 Franka 换水果任务上，它报告 80 % 成功，而无记忆的 diffusion policy 失败；有遮挡和干扰时 76 % 对 next-frame 扩散基线的 48 %。所有数字以论文为准；视频模型、Franka 和 GPU 训练：本页未运行。**FORGE-Tree（arXiv 2510.21744，经 pdftotext 读摘要与引言）**：后续工作，在冻结的 VLA 编码器上接一个按阶段对齐的 Diffusion Forcing 头，再配 Monte Carlo Tree Diffusion，每次只部分去噪一个目标片段；报告在 LIBERO 上高 13.4 到 17.2 个百分点（以论文为准）。**只作阅读**，这里没有 toy。

### 三种噪声模式，同一个模型类

把带噪 token 写成 `x̃ = √ᾱ_k · x + √(1 − ᾱ_k) · ε`，`ᾱ_0 = 1`（干净），`ᾱ_K = 0`（纯噪声）。因果去噪器看到带噪的前一个 token 和带噪的当前 token，预测干净的当前 token。三组用**同一个模型类**、在**同一份数据与噪声**上训练，唯一的区别是它们见过哪些噪声级对 `(k_prev, k_cur)`：

| 组 | 训练模式 | 采样器能做什么 |
|---|---|---|
| teacher forcing | `k_prev = 0`，`k_cur` 随机 | 把自己的输出当成干净的再喂回去 |
| Diffusion Forcing | `k_prev`、`k_cur` 独立 | 把自己的输出重新加噪到 `k_small`，少信它一点 |
| 整序列（因果） | `k_prev = k_cur` | 每一步都必须把上下文加噪到当前噪声级 |

<Formula label="反馈稳定性（生成一个 token）">x_new = G·x_prev +（新噪声项）；ρ(G) &lt; 1 ⇒ 喂回的历史收缩，ρ(G) &gt; 1 ⇒ 每步都在放大</Formula>

**算例**。若模型的单 token 增益 `ρ(G) = 1.023`，一个当作干净历史喂回去的误差，在 8 个 token 的训练窗口之后再走 120 个 token，会放大 `1.023^120 ≈ 15` 倍；`ρ(G) = 0.95` 时同一个误差缩到 `0.95^120 ≈ 0.002`。把上下文重新加噪到 `ᾱ = 0.976`（toy 的 `k_small = 1`），等于告诉模型「这个 token 有点不确定」，最小二乘拟合就会减小它对这个 token 的权重。代价是每个采样出的 token 都继承了这份不确定，样本会更飘。

### 公平设定

`diffusion_forcing_token_noise_toy.py` 是**合成**的，只用标准库。**模型假设**：token 是二维点，来自带噪的极限环映射 `x′ = R(0.3) · x · (1 + 0.15 (1 − |x|²)) + N(0, 0.02² I)`，真实轨道是单位圆；训练序列长 **8 个 token**，起始半径 `U(0.2, 1.2)`，所以里面有向外和向内的螺线。去噪器是论文 RNN 的**线性替身**：每对噪声级一个最小二乘映射 `x̂₀ = P x̃_prev + Q x̃_cur + b`，`K = 10` 个噪声级，余弦调度 `ᾱ_k = cos²(πk/20)`；每个 token 用确定性 DDIM 从第 10 级走到第 0 级。线性映射表示不了极限环，所以每组都以同样的方式模型失配。**稳定性判据**是从前一个 token 到新 token 的单 token 映射的 `ρ(G)`；采样器对前一个 token 是仿射的，所以 toy 用两个单位差分就能精确算出 `G`。

**共同随机数**（common random numbers）：每个种子里，三组在同样的 2000 条序列上训练，用同样的噪声向量和同样决定噪声级的均匀随机数；每个评估回合共享圆上的起点、真实续写、每个 token 的初始噪声和每个上下文噪声。5 个种子 × 20 个回合。**情形**：`in_horizon`（8 个 token：`mse` 是到共享真实续写的误差，`jit` = 平均 `|x_{t+1} − f(x_t)|`，即动力学残差）；`past_horizon`（128 个 token：`div` = 半径曾超过 3 的回合比例，`amp` = 第 9–128 个 token 上平均 `|r − 1|`，`r` 截到 3）；`guided_s8` / `guided_s32`（8 个 token 的计划应停在真实第 8 个 token 附近：**引导替身**是在 S 个采样计划里按终点距离留最好的一个——**不是**论文的梯度引导或 Monte Carlo Guidance；`goal` = 这个距离，`jit` = 选中计划的动力学残差）。C 组是**因果**、逐 token 的：它在所有 token 上**共用一个噪声级**（`k_prev = k_cur`），并在每一步把上下文**重新加噪**到该级，所以单 token 增益 `ρ(G)` 为 0.6755–0.6890（约 0.68）。正是这个收缩映射，让 C **没有**复现 Diffusion Forcing 第 4.1 节里**会发散**的因果整序列基线；带联合梯度引导的非因果整序列规划器（Diffuser）也**没有**建模。toy 还对 B 扫了一遍 `k_small`。

```python
#!/usr/bin/env python3
"""Diffusion Forcing stand-in: what the training noise pattern does to a causal token model. Stdlib only.

Model assumptions (also stated in the lesson prose):
  tokens are 2D points from a noisy limit-cycle map x' = R(0.3) x (1 + 0.15 (1 - |x|^2)) + N(0, 0.02^2 I);
  the true orbit is the unit circle. Training sequences are 8 tokens long and start at radius
  U(0.2, 1.2), so they contain growing and shrinking spirals. The causal denoiser is the SAME
  model class for every arm: for each pair of noise levels (k_prev, k_cur) one linear map
  x0_hat(cur) = P x~prev + Q x~cur + b, fit by least squares (tiny ridge), where x~ = sqrt(abar_k) x
  + sqrt(1 - abar_k) eps. K = 10 levels, cosine schedule abar_k = cos^2(pi k / 20), abar_10 = 0.
  Sampling one token runs deterministic DDIM from level 10 to 0 with the previous token as context.
  This is a linear stand-in for the paper's RNN; it is not a video model and not a robot policy.

Arms (Common random numbers: per seed the same training sequences, the same per-token noise
vectors and the same uniform draws that set noise levels; per evaluation episode the same start,
true continuation, initial token noise and context noise):
  A_teacher   teacher forcing: history always clean (k_prev = 0), current token at a random level;
              at sampling time the model's own previous output is fed back as if clean
  B_dforcing  Diffusion Forcing: k_prev and k_cur drawn independently per token; at sampling time
              the previous output is re-noised to k_small = 1 before it is used (the paper's
              stabilisation, App. B.4), which the model has been trained to discount
  C_fullseq   causal full-sequence diffusion: one shared level for every token (k_prev = k_cur);
              at sampling time the context is re-noised to the current token's level at every step
              (the only pattern it has seen), a stand-in for conditioning without reconstruction guidance

Stability criterion: sampling one token is affine in the previous token for fixed noise, so its
Jacobian G is exact; rho(G) < 1 means fed-back history contracts, rho(G) > 1 means it grows every step.

Regimes: in_horizon (8 tokens, mse to the shared true continuation, jit = mean |x_{t+1} - f(x_t)|),
past_horizon (128 tokens: div = share of episodes whose radius ever exceeds 3, amp = mean |r - 1|
over tokens 9..128 with r capped at 3), guided_s8 / guided_s32 (an 8-token plan must end near a goal;
guidance stand-in = best of S sampled plans by final distance, not the paper's gradient / Monte
Carlo guidance; goal = final distance of the chosen plan, jit = its dynamics residual).

Labels: tie = identical on every seed; |m| < 1e-9 and sd < 1e-9 = numerically zero
(floating-point residue), effectively a tie, no sign count; |paired mean| <= sd = near-tie / small
gap within seed noise; |m| > sd = consistent gap (small if |m| < 20 % of the smaller arm mean, else
clear), always with a sign count.
Video / robot results and GPU training: 本页未运行. Paper numbers: 以论文为准.
"""
from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
K = 10
ABAR = tuple(0.0 if k == K else math.cos(math.pi * k / (2 * K)) ** 2 for k in range(K + 1))
THETA, GAMMA, SIG_W = 0.3, 0.15, 0.02
N_TRAIN, T_TRAIN = 2000, 8
EPISODES = 20
T_PAST = 128
K_SMALL = 1
ARMS = ("A_teacher", "B_dforcing", "C_fullseq")
REGIMES = (
    ("in_horizon", ("mse", "jit")),
    ("past_horizon", ("div", "amp")),
    ("guided_s8", ("goal", "jit")),
    ("guided_s32", ("goal", "jit")),
)


def f(x):
    """True limit-cycle map (deterministic part)."""
    g = 1.0 + GAMMA * (1.0 - (x[0] ** 2 + x[1] ** 2))
    c, s = math.cos(THETA), math.sin(THETA)
    return (g * (c * x[0] - s * x[1]), g * (s * x[0] + c * x[1]))


def noisy(x, k, e):
    a = ABAR[k]
    return (math.sqrt(a) * x[0] + math.sqrt(1 - a) * e[0], math.sqrt(a) * x[1] + math.sqrt(1 - a) * e[1])


def solve(a, b):
    n = len(a)
    m = [row[:] + [b[i]] for i, row in enumerate(a)]
    for i in range(n):
        p = max(range(i, n), key=lambda r: abs(m[r][i]))
        m[i], m[p] = m[p], m[i]
        for r in range(n):
            if r != i:
                q = m[r][i] / m[i][i]
                for c in range(i, n + 1):
                    m[r][c] -= q * m[i][c]
    return [m[i][n] / m[i][i] for i in range(n)]


def fit(rows):
    """Least squares (ridge 1e-6) for x0_hat = W [x~prev, x~cur, 1]."""
    d = 5
    a = [[1e-6 if i == j else 0.0 for j in range(d)] for i in range(d)]
    b = [[0.0] * d for _ in range(2)]
    for ft, y in rows:
        for i in range(d):
            for j in range(d):
                a[i][j] += ft[i] * ft[j]
            for o in range(2):
                b[o][i] += ft[i] * y[o]
    return [solve(a, b[o]) for o in range(2)]


def training_draws(seed):
    """Common random numbers for training: sequences, noise vectors, level draws."""
    rng = random.Random(7000 + seed)
    data, draws = [], []
    for _ in range(N_TRAIN):
        r, ph = rng.uniform(0.2, 1.2), rng.uniform(0, 2 * math.pi)
        x = (r * math.cos(ph), r * math.sin(ph))
        seq = [x]
        for _ in range(T_TRAIN - 1):
            y = f(x)
            x = (y[0] + rng.gauss(0, SIG_W), y[1] + rng.gauss(0, SIG_W))
            seq.append(x)
        data.append(seq)
        u_seq = rng.random()
        draws.append([(rng.random(), rng.random(), u_seq, (rng.gauss(0, 1), rng.gauss(0, 1)),
                       (rng.gauss(0, 1), rng.gauss(0, 1))) for _ in range(T_TRAIN)])
    return data, draws


def level(u):
    return min(K, int(u * (K + 1)))


def train(arm, data, draws):
    rows = {}
    for seq, dr in zip(data, draws):
        for t in range(1, T_TRAIN):
            u_prev, u_cur, u_seq, e_prev, e_cur = dr[t]
            if arm == "A_teacher":
                kp, kc = 0, level(u_cur)
            elif arm == "B_dforcing":
                kp, kc = level(u_prev), level(u_cur)
            else:
                kp = kc = level(u_seq)
            xp, xc = noisy(seq[t - 1], kp, e_prev), noisy(seq[t], kc, e_cur)
            rows.setdefault((kp, kc), []).append(((xp[0], xp[1], xc[0], xc[1], 1.0), seq[t]))
    return {key: fit(v) for key, v in rows.items()}


def predict(w, xp, xc):
    ft = (xp[0], xp[1], xc[0], xc[1], 1.0)
    return (sum(a * b for a, b in zip(w[0], ft)), sum(a * b for a, b in zip(w[1], ft)))


def sample_token(models, arm, prev, init, ctx_noise, k_small=K_SMALL):
    """Deterministic DDIM from level K to 0 for one token, given the previous (generated) token."""
    x = init
    for k in range(K, 0, -1):
        kp = 0 if arm == "A_teacher" else (k_small if arm == "B_dforcing" else k)
        x0 = predict(models[(kp, k)], noisy(prev, kp, ctx_noise), x)
        a, an = ABAR[k], ABAR[k - 1]
        eh = ((x[0] - math.sqrt(a) * x0[0]) / math.sqrt(1 - a), (x[1] - math.sqrt(a) * x0[1]) / math.sqrt(1 - a))
        x = (math.sqrt(an) * x0[0] + math.sqrt(1 - an) * eh[0], math.sqrt(an) * x0[1] + math.sqrt(1 - an) * eh[1])
    return x


def token_gain(models, arm, k_small=K_SMALL):
    """Spectral radius of G = d(new token)/d(previous token). sample_token is affine in the previous
    token for fixed noise, so two unit differences give G exactly (up to round-off). rho(G) < 1 is
    the stability criterion for feeding generated tokens back: the deterministic part contracts."""
    z = ((0.0, 0.0), (0.0, 0.0))
    o = sample_token(models, arm, (0.0, 0.0), *z, k_small)
    c1 = sample_token(models, arm, (1.0, 0.0), *z, k_small)
    c2 = sample_token(models, arm, (0.0, 1.0), *z, k_small)
    a, b, c, d = c1[0] - o[0], c2[0] - o[0], c1[1] - o[1], c2[1] - o[1]
    tr, det = a + d, a * d - b * c
    disc = tr * tr / 4 - det
    if disc >= 0:
        return max(abs(tr / 2 + math.sqrt(disc)), abs(tr / 2 - math.sqrt(disc)))
    return math.sqrt(det)


def episode_draws(regime, seed, ep):
    """Common random numbers for one evaluation episode, shared by all arms."""
    rng = random.Random(100000 * [r[0] for r in REGIMES].index(regime) + 1000 * seed + ep)
    ph = rng.uniform(0, 2 * math.pi)
    x0 = (math.cos(ph), math.sin(ph))
    truth = [x0]
    for _ in range(T_TRAIN):
        y = f(truth[-1])
        truth.append((y[0] + rng.gauss(0, SIG_W), y[1] + rng.gauss(0, SIG_W)))
    n_plans = {"guided_s8": 8, "guided_s32": 32}.get(regime, 1)
    length = T_PAST if regime == "past_horizon" else T_TRAIN
    noise = [[((rng.gauss(0, 1), rng.gauss(0, 1)), (rng.gauss(0, 1), rng.gauss(0, 1))) for _ in range(length)]
             for _ in range(n_plans)]
    return x0, truth, noise


def rollout(models, arm, x0, noise_row, k_small=K_SMALL):
    xs, x = [x0], x0
    for init, ctx in noise_row:
        x = sample_token(models, arm, x, init, ctx, k_small)
        xs.append(x)
        if math.hypot(*x) > 1e6:
            break
    return xs


def jitter(xs):
    return sum(math.dist(xs[t + 1], f(xs[t])) for t in range(len(xs) - 1)) / (len(xs) - 1)


def run_episode(regime, models, arm, x0, truth, noise, k_small=K_SMALL):
    if regime == "in_horizon":
        xs = rollout(models, arm, x0, noise[0], k_small)
        mse = sum((xs[t][0] - truth[t][0]) ** 2 + (xs[t][1] - truth[t][1]) ** 2 for t in range(1, T_TRAIN + 1)) / T_TRAIN
        return {"mse": mse, "jit": jitter(xs)}
    if regime == "past_horizon":
        xs = rollout(models, arm, x0, noise[0], k_small)
        rs = [min(math.hypot(*x), 3.0) for x in xs[1:]] + [3.0] * (T_PAST + 1 - len(xs))
        return {"div": 1.0 if max(rs) >= 3.0 else 0.0, "amp": sum(abs(r - 1.0) for r in rs[T_TRAIN:]) / (T_PAST - T_TRAIN)}
    goal = truth[T_TRAIN]
    best = min((rollout(models, arm, x0, row) for row in noise), key=lambda xs: math.dist(xs[-1], goal))
    return {"goal": math.dist(best[-1], goal), "jit": jitter(best)}


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x: float) -> str:
    if x != 0.0 and abs(x) < 5e-4:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


NUM_ZERO = 1e-9  # |m| and sd both below this: floating-point residue, not a gap


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(mean_sd(xa)[0], mean_sd(xb)[0]):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def main() -> None:
```

## Knowledge Insulation：离散动作与被截断的专家梯度

把一个新初始化的连续**扩散 / 流匹配动作专家**接到预训练 VLM 上，正是 [Knowledge Insulation](https://arxiv.org/abs/2505.23705)（官方标题为 Knowledge Insulating Vision-Language-Action Models: Train Fast, Run Fast, Generalize Better；Danny Driess、Jost Tobias Springenberg、Brian Ichter、Lili Yu、Adrian Li-Bell、Karl Pertsch、Allen Z. Ren、Homer Walke、Quan Vuong、Lucy Xiaoyang Shi、Sergey Levine；arXiv **2505.23705**）研究的设定。摘要、引言和第 5.2 节的主张是：把专家梯度朴素地反传到主干，会损害训练速度和知识迁移。做法是**用离散动作的 next-token 损失微调 VLM**（他们的完整配方里还有 VLM 数据），连续专家仍用流匹配训练，**但不把梯度传回 VLM**。截断做在注意力层里（文中式 5–6）：主干词元收不到来自专家一侧的梯度。论文里的速度、语言跟随和 LIBERO / DROID 数字均**以论文为准**。GPU 训练、π0 权重和这些基准都**本页未运行**。

这**不是** ChatVLA 的分阶段对齐（只做机器人 SFT 就会冲掉 VQA 头，已在 VLA 微调那课），也**不是**本页已有的 OneDP 单步回归。

### 公平设定

`knowledge_insulation_flow_toy.py` 是**合成的**，只用标准库。**模型假设。** 输入在 R⁶。预训练风格的主干 `h = A x` 一开始是**语义投影**。`A0` 是块对角（前三个坐标上为 `I₃`，其余为零），只在语义块上加很小的高斯抖动，因此冻结主干看不到 `x` 的第 3、4 个坐标。一个**冻结**的 VQA / 指令探针读取 `h` 的前两个坐标（在前两个隐藏坐标上均分的 `NQ` 个原型）；标签由未扰动的投影定义，打印的冻结基线是该探针在 `A0` 上的结果，不是重新训练的头。`conflict` 和 `coarse_bins` 里，二维动作落在第 3、4 个坐标。离散动作词元是 [−3, 3]² 上均匀的 `BINS × BINS` 网格，只是论文 FAST / 朴素词元的替身，**不是 FAST 本身**。首跑之后，离散头只读动作槽隐藏单元 `h[3:6]`（对应论文里分开的离散动作词元）；首跑时离散头读的是**整个** `h`，这一对照仍在相同种子上训练并打印——这一选择**不是**首跑前写定的。

动作专家是**线性流匹配残差**。给定 `h`、带噪动作 `a_τ = τ a + (1−τ)ε` 和 `τ`，它预测 `u = a − ε`。训练是普通 SGD。**没有对象积分步**（离散 SGD 更新）。推理用固定的 1 步欧拉读出（沿直线路径的真实速度是常数，专家若完美，1 步就是精确的）；也打印 4 步读出，但那不是稳定性判据。

**对照臂**，使用**公共随机数**（每个体制与种子上，`A0` 抖动、专家与离散头初始化、每一批 `(x, ε, τ)` 以及测试集都只抽一次并共用）；同等预算 `STEPS = 400`、批次 8、学习率 0.05，五个种子：

- **A_naive**——流匹配损失反传到 `A`；没有离散动作交叉熵。
- **B_insulate**——用离散动作交叉熵更新 `A`；专家梯度在 `h` 处截断。
- **C_frozen**——`A` 保持为 `A0`；只训练专家；没有离散动作交叉熵。

**指标。** 测试集上的探针准确率 %；控制成功率 %（1 步读出满足 `|a_hat − a| ≤ 0.35`）；1 步与 4 步动作 MSE；`fit_mid` / `fit_final` 为 100 步与 400 步后测试集上流匹配残差的均值（训练速度代理）。

**体制写在第一次运行之前。**

- **conflict**——动作 `(x₃, x₄)`，`BINS = 4`。A 相对 B 探针稳定下降，和 / 或残差下降更慢；A 与 B 在分布内控制上可能接近打平；C 赢探针、输控制——两个指标都保留。
- **coarse_bins**——同样的动作，`BINS = 2`（更弱的离散交叉熵）。B 可能在控制上输给 A；探针比较无论结果如何都打印。
- **aligned**——动作 `(x₀, x₁)`（落在语义块内），`BINS = 4`。C 可能在控制上接近打平；探针若有下降也打印；不用来挑选赢家。

```python
#!/usr/bin/env python3
"""Knowledge Insulation stand-in for a VLM backbone + continuous action expert. Stdlib only.

Not π0 weights, not ChatVLA (no MoE / phased VQA replay), not OneDP (no one-step distillation),
not DPO. Paper (arXiv 2505.23705) speed, language-following and LIBERO / DROID numbers
are 以论文为准; GPU / π0 / real-robot runs: 本页未运行.

Model assumptions (also stated in the lesson prose):
  Input x in R^D, D=6. A pretrained-style backbone h = A x starts as a semantic projector:
  A0 is block-diagonal (I_3 on the first three coordinates, zeros elsewhere) plus a small
  Gaussian jitter only in the semantic block. A frozen VQA / instruction probe reads the
  first two coordinates of h (prototypes at 0, 120, 240 degrees); its labels are defined by
  the unperturbed projector, so the printed frozen baseline is the probe on A0, not a
  retrained head. The continuous target is a 2-D action that, in the conflict and coarse_bins
  regimes, lives on coordinates 3 and 4 — coordinates the frozen backbone does not pass
  through. Discrete-action tokens are a uniform grid of BINS x BINS bins on [-3, 3]^2, a
  stand-in for the paper's FAST / naive tokens, not FAST itself. After the first run, the discrete head reads only the action-slot hidden units h[SEM:] (a stand-in for the paper's separate discrete-action tokens). The first-run alternative, which fed the full h to the discrete head, is still trained on the same seeds and printed; that choice was not fixed before the first run.

  The action expert is a linear flow-matching residual: given h, a noisy action
  a_τ = τ a + (1-τ) ε and τ, it predicts u = a - ε. Training is plain SGD on that residual
  plus, where the arm allows it, softmax cross-entropy on the discrete bins. There is no
  plant integration step (discrete SGD). Inference uses a fixed 1-step Euler read-out
  (the true velocity is constant along the straight path, so 1 step is exact for a perfect
  expert); a 4-step read-out is also printed, not as a stability criterion.

Arms (Common random numbers: per (regime, seed) the A0 jitter, expert and discrete-head
init, every training batch of (x, ε, τ), and the test set are drawn once and reused):
  A_naive      flow-matching loss back-propagates into A; no discrete-action CE
  B_insulate   discrete-action CE into A; expert grads stop at h (sg)
  C_frozen     A is held at A0; expert only; no discrete-action CE

Equal step budget STEPS, batch BATCH, learning rate LR.

Metrics per seed: probe accuracy % on the test set; control success % (|a_hat - a| <= TOL
with the 1-step read-out); 1-step and 4-step action MSE; fit_mid = mean test FM residual
after MID steps (training-speed proxy); fit_final = the same after STEPS.

Regimes, written before the first run:
  conflict     action = (x_3, x_4), BINS=4
               A consistent probe drop vs B and/or slower residual drop (higher fit_mid);
               A and B may near-tie on in-distribution control;
               C wins the probe and loses on control — both metrics kept
  coarse_bins  same targets, BINS=2 (weaker discrete CE)
               B may lose control to A; probe comparison printed either way
  aligned      action = (x_0, x_1) (inside the semantic block), BINS=4
               C may near-tie on control (the frozen features already carry the action);
               probe drop, if any, is printed; not used to pick a winner

Paper numbers 以论文为准. GPU / π0 / LIBERO: 本页未运行.

from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
D, ACT, NQ = 6, 2, 3
SEM = 3
STEPS, MID, BATCH, TEST = 400, 100, 8, 400
LR = 0.05
TOL = 0.35
INIT_SD = 0.05
EXP_SD = 0.05
BIN_LO, BIN_HI = -3.0, 3.0
NUM_ZERO = 1e-9
ARMS = ("A_naive", "B_insulate", "C_frozen")
# name: (action coordinates, bins-per-axis); written before the first run
REGIMES = {
    "conflict": ((3, 4), 4),
    "coarse_bins": ((3, 4), 2),
    "aligned": ((0, 1), 4),
}
STREAM = {"conflict": 0, "coarse_bins": 1, "aligned": 2}
# frozen probe prototypes in the first two hidden coordinates
V0 = [[math.cos(2 * math.pi * k / NQ), math.sin(2 * math.pi * k / NQ)] for k in range(NQ)]


def zeros(r, c=None):
    if c is None:
        return [0.0] * r
    return [[0.0] * c for _ in range(r)]


def matvec(mat, v):
    return [sum(a * b for a, b in zip(row, v)) for row in mat]


def add_vec(a, b, s=1.0):
    return [x + s * y for x, y in zip(a, b)]


def axpy_mat(dst, src, s):
    for i, row in enumerate(src):
        for j, v in enumerate(row):
            dst[i][j] += s * v


def axpy_vec(dst, src, s):
    for i, v in enumerate(src):
        dst[i] += s * v


def outer(u, v):
    return [[ui * vj for vj in v] for ui in u]


def argmax(v):
    return max(range(len(v)), key=lambda k: v[k])


def softmax(logits):
    m = max(logits)
    ex = [math.exp(x - m) for x in logits]
    z = sum(ex)
    return [e / z for e in ex]


def clip_bin(val, bins):
    t = (val - BIN_LO) / (BIN_HI - BIN_LO)
    i = int(math.floor(t * bins))
    return max(0, min(bins - 1, i))


def action_of(x, coord):
    return [x[coord[0]], x[coord[1]]]


def token_of(a, bins):
    return clip_bin(a[0], bins) * bins + clip_bin(a[1], bins)


def vqa_label(x):
    # defined by the unperturbed semantic projector: h* = (x0, x1)
    return argmax([v[0] * x[0] + v[1] * x[1] for v in V0])


def probe_pred(h):
    return argmax([v[0] * h[0] + v[1] * h[1] for v in V0])


def make_A0(rng):
    A = zeros(D, D)
    for i in range(SEM):
        for j in range(SEM):
            A[i][j] = (1.0 if i == j else 0.0) + rng.gauss(0.0, INIT_SD)
    return A


def feat_of(h, a_tau, tau):
    return list(h) + list(a_tau) + [tau]


def shared_draws(regime, seed):
    rng = random.Random(2000 * STREAM[regime] + seed)
    coord, bins = REGIMES[regime]
    nclass = bins * bins
    A0 = make_A0(rng)
    We0 = [[rng.gauss(0.0, EXP_SD) for _ in range(D + ACT + 1)] for _ in range(ACT)]
    be0 = [rng.gauss(0.0, EXP_SD) for _ in range(ACT)]
    Wd0 = [[rng.gauss(0.0, EXP_SD) for _ in range(D)] for _ in range(nclass)]
    bd0 = [0.0] * nclass
    batches = []
    for _ in range(STEPS):
        xs, eps, taus = [], [], []
        for _ in range(BATCH):
            x = [rng.gauss(0.0, 1.0) for _ in range(D)]
            e = [rng.gauss(0.0, 1.0) for _ in range(ACT)]
            t = rng.random()
            xs.append(x)
            eps.append(e)
            taus.append(t)
        batches.append((xs, eps, taus))
    test = []
    for _ in range(TEST):
        x = [rng.gauss(0.0, 1.0) for _ in range(D)]
        e = [rng.gauss(0.0, 1.0) for _ in range(ACT)]
        test.append((x, action_of(x, coord), e, vqa_label(x)))
    return {
        "coord": coord,
        "bins": bins,
        "nclass": nclass,
        "A0": A0,
        "We0": We0,
        "be0": be0,
        "Wd0": Wd0,
        "bd0": bd0,
        "batches": batches,
        "test": test,
    }


def copy_mat(m):
    return [row[:] for row in m]


def flow_predict(We, be, h, a_tau, tau):
    return add_vec(matvec(We, feat_of(h, a_tau, tau)), be)


def integrate(We, be, h, eps, steps):
    a = list(eps)
    if steps <= 1:
        u = flow_predict(We, be, h, a, 0.0)
        return add_vec(a, u)
    dt = 1.0 / steps
    t = 0.0
    for _ in range(steps):
        u = flow_predict(We, be, h, a, t)
        a = add_vec(a, u, dt)
        t += dt
    return a


def train_arm(arm, draws, discrete="slot"):
    A = copy_mat(draws["A0"])
    We = copy_mat(draws["We0"])
    be = draws["be0"][:]
    Wd = copy_mat(draws["Wd0"])
    bd = draws["bd0"][:]
    coord, bins, nclass = draws["coord"], draws["bins"], draws["nclass"]
    # "slot": discrete head sees h[SEM:] only (main; chosen after the first run)
    # "full": first-run alternative, discrete head sees the whole of h
    if discrete == "slot":
        Wd = [row[SEM:] for row in Wd]
        d_in = D - SEM
    else:
        d_in = D
    mid_snapshot = None
    for step, (xs, eps, taus) in enumerate(draws["batches"]):
        gA, gWe, gbe = zeros(D, D), zeros(ACT, D + ACT + 1), zeros(ACT)
        gWd, gbd = zeros(nclass, d_in), zeros(nclass)
        for x, e, tau in zip(xs, eps, taus):
            a = action_of(x, coord)
            h = matvec(A, x)
            a_tau = add_vec([tau * ai for ai in a], e, 1.0 - tau)
            u = add_vec(a, e, -1.0)
            feat = feat_of(h, a_tau, tau)
            u_hat = add_vec(matvec(We, feat), be)
            err = add_vec(u_hat, u, -1.0)
            # dL/d u_hat = 2 err
            scale = 2.0 / BATCH
            derr = [scale * v for v in err]
            axpy_mat(gWe, outer(derr, feat), 1.0)
            axpy_vec(gbe, derr, 1.0)
            dfeat = [sum(We[k][j] * derr[k] for k in range(ACT)) for j in range(D + ACT + 1)]
            dh_fm = dfeat[:D]
            if arm == "A_naive":
                axpy_mat(gA, outer(dh_fm, x), 1.0)
            if arm == "B_insulate":
                y = token_of(a, bins)
                h_d = h if discrete == "full" else h[SEM:]
                logits = add_vec(matvec(Wd, h_d), bd)
                p = softmax(logits)
                dlog = [scale * (pj - (1.0 if i == y else 0.0)) for i, pj in enumerate(p)]
                axpy_mat(gWd, outer(dlog, h_d), 1.0)
                axpy_vec(gbd, dlog, 1.0)
                dh_part = [sum(Wd[k][j] * dlog[k] for k in range(nclass)) for j in range(len(h_d))]
                dh_ce = dh_part if discrete == "full" else ([0.0] * SEM + dh_part)
                axpy_mat(gA, outer(dh_ce, x), 1.0)
            # C_frozen: no gA, no discrete CE
        if arm != "C_frozen":
            axpy_mat(A, gA, -LR)
        axpy_mat(We, gWe, -LR)
        axpy_vec(be, gbe, -LR)
        if arm == "B_insulate":
            axpy_mat(Wd, gWd, -LR)
            axpy_vec(bd, gbd, -LR)
        if step + 1 == MID:
            mid_snapshot = (copy_mat(A), copy_mat(We), be[:])
    return A, We, be, mid_snapshot


def eval_metrics(A, We, be, draws, steps_euler=1):
    probe_ok = 0
    ctrl_ok = 0
    mse1 = 0.0
    mse4 = 0.0
    fm = 0.0
    n = len(draws["test"])
    for x, a, e, y in draws["test"]:
        h = matvec(A, x)
        if probe_pred(h) == y:
            probe_ok += 1
        a1 = integrate(We, be, h, e, 1)
        a4 = integrate(We, be, h, e, 4)
        se1 = sum((p - q) ** 2 for p, q in zip(a1, a))
        se4 = sum((p - q) ** 2 for p, q in zip(a4, a))
        mse1 += se1
        mse4 += se4
        if math.sqrt(se1) <= TOL:
            ctrl_ok += 1
        # FM residual at a random-path point using the same test ε at τ=0.5
        tau = 0.5
        a_tau = add_vec([tau * ai for ai in a], e, 1.0 - tau)
        u = add_vec(a, e, -1.0)
        u_hat = flow_predict(We, be, h, a_tau, tau)
        fm += sum((p - q) ** 2 for p, q in zip(u_hat, u))
    return {
        "probe_%": 100.0 * probe_ok / n,
        "control_%": 100.0 * ctrl_ok / n,
        "mse_1step": mse1 / n,
        "mse_4step": mse4 / n,
        "fm": fm / n,
    }


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


def fmt_arm(name, rows, keys):
    parts = []
    for k in keys:
        xs = [r[k] for r in rows]
        m, s = mean_sd(xs)
        parts.append(f"{k}={num(m)}+-{num(s)}")
    return f"  {name} " + " ".join(parts)
```

### 读这些体制

本页标签的用法：只有配对的逐种子差在每个种子上都恰好为零，才叫**打平：每个种子都完全相同**；`|配对均值|` 和 sd 都小于 `10⁻⁹` 时，叫**数值上为零（浮点残差），等同打平**（在 sd 检验之前判断；这种行不带同号计数，也绝不叫稳定或明显）；`|配对均值| ≤ sd` 时叫**接近打平、差距很小，在种子噪声之内**；`|配对均值| > sd` 时叫**稳定**的差距，`|m|` 小于两组中较小均值的 20 % 时叫**小而稳定的差距**，否则叫**明显差距**（20 % 规则只在这两个说法之间选）。每条稳定或明显的行都带 5 个种子上的同号计数，符号相反（或恰好相等）的种子都会报出来；只靠同号计数，永远不能把差距叫成稳定。配对差为 B−A、C−B 和 C−A，写成种子间的均值 ± sd。

- **conflict——A 的探针下降，A 与 B 在控制上接近打平，C 保住探针并在控制上输。** 冻结基线探针为 97.8000±0.7583 %。训练之后 B 仍是 97.8000±0.7583 %，C 与 B **打平：每个种子都完全相同**（槽式离散头不会碰到 `A` 的语义行，所以 B 的探针等于冻结主干）。A 降到 63.9000±6.8934 %（B−A 33.9000±6.9991，**明显差距**，5 个种子全部同号）。分布内 1 步控制是**接近打平**（B−A 0.8500±4.2815，5 个种子中 3 个符号相反）；1 步 MSE 0.1695±0.3947 与 4 步 MSE 0.0451±0.0604 也是接近打平。C 在控制上输（C−B −10.1500±6.3161，**明显**，5/5），所有残差指标也输。A 与 B 的 `fit_final` 接近打平（0.1121±0.1390），但在中段预算上 A 的流匹配残差*下降得更快*（B−A 的 `fit_mid` 2.1921±0.6843，**明显**，5/5）。预先声明里 A「和 / 或残差下降更慢」**没有出现**；这里稳定的差距在探针上，中段残差按打印结果如实写出。
