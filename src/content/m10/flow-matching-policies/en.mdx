## Three ways to output an action

[6.2](/en/month/month-6/act-diffusion) showed the core problem with demonstrations: when experts sometimes go left of an obstacle and sometimes go right, a policy trained with mean-squared error outputs the **average**, which drives straight into the obstacle.

| Head | What the network learns | How an action comes out | Cost at inference |
| --- | --- | --- | --- |
| MSE regression | one action per observation | one forward pass | lowest; averages modes |
| Diffusion (6.2) | the noise added at each step | many denoising steps | many forward passes |
| <Term id="flow-matching">Flow matching</Term> | a <Term id="velocity-field">velocity field</Term> v(x, τ) | integrate from noise along the field | a few to tens of steps |

Flow matching (Lipman et al., arXiv **2210.02747**) trains a continuous normalising flow without simulating it: the network regresses a target velocity along a fixed path from noise to data. Because the path is a straight line, a handful of integration steps already gives good samples.

## π0's conventions

π0 (arXiv **2410.24164**) attaches a 300M-parameter action expert to a PaliGemma 3B vision-language model (about 3.3B parameters in total) and predicts chunks of **H=50** actions. Its flow-matching conventions, in the notation of the paper:

- Path: `A^τ = τ·A + (1−τ)·ε`, with `ε ~ N(0, I)` and τ from 0 (pure noise) to 1 (the action chunk).
- Target velocity: `u = A − ε`. The network learns `v_θ(A^τ, o) ≈ u`.
- Training samples τ from a Beta distribution that puts more weight on noisy (low τ) times, with s = 0.999 as the cut-off.
- Inference: start from noise and apply forward Euler, `A^{τ+δ} = A^τ + δ·v_θ`, with **10** steps (`δ = 0.1`).

Every one of those 10 steps runs the action expert again. On an RTX 4090 the paper reports **27 ms** for the 10 action steps, out of **73 ms** on board (14 ms image encoders, 32 ms observation forward pass). The step count is part of inference latency; [10.2](/en/month/month-10/real-time-chunking) deals with what that latency does to the seams between chunks. These are published figures from the paper; they were not run on this page (本页未运行).

## Run the closed-form toy

`flow_match_toy.py` uses a 1-D target with two modes, ±1 with standard deviation 0.1 (think "left of the obstacle" and "right of it"). For a Gaussian mixture the marginal velocity has a closed form, so there is **no network**: we integrate the exact field with 1, 2, 3, 5, 10 and 50 Euler steps and count how many of 2000 samples land near a mode (within 0.3 of ±1) or near the invalid mean 0.

```python
"""flow_match_toy.py: 1-D flow matching with a closed-form velocity (stdlib).

Target: a bimodal mixture 0.5*N(-1, 0.1^2) + 0.5*N(+1, 0.1^2) — think of it as
"go left of the obstacle" vs "go right". Path (pi0 convention):

    x_tau = tau * x1 + (1 - tau) * eps,   eps ~ N(0, 1),   tau in [0, 1]
    target velocity u = x1 - eps

Because the target is a Gaussian mixture, the *marginal* velocity
E[x1 - eps | x_tau = x] has a closed form, so no network is trained here.
We integrate it with forward Euler from tau=0 (noise) to tau=1 and count how
many samples land near a mode vs near the (invalid) mean 0.

This is a toy: a real policy learns v_theta(A_tau, obs) with a network.
"""

import math
import random

SEED = 7
N = 2000
MODES = (-1.0, 1.0)
SIGMA = 0.1
STEPS = (1, 2, 3, 5, 10, 50)
NEAR = 0.3  # "near" radius for both mode and mean


def gauss(rng: random.Random) -> float:
    """Box-Muller from rng.random() so the stream is stable across versions."""
    u1 = rng.random()
    u2 = rng.random()
    return math.sqrt(-2.0 * math.log(1.0 - u1)) * math.cos(2.0 * math.pi * u2)


def velocity(x: float, tau: float) -> float:
    """Closed-form marginal velocity E[x1 - eps | x_tau = x] for the mixture."""
    var = tau * tau * SIGMA * SIGMA + (1.0 - tau) ** 2
    cov = tau * SIGMA * SIGMA - (1.0 - tau)  # Cov(x1 - eps, x_tau | mode)
    logw = [-(x - tau * m) ** 2 / (2.0 * var) for m in MODES]
    top = max(logw)
    w = [math.exp(v - top) for v in logw]
    z = sum(w)
    return sum(
        (wk / z) * (m + cov / var * (x - tau * m)) for wk, m in zip(w, MODES)
    )


def sample(x0: float, steps: int) -> float:
    x = x0
    dt = 1.0 / steps
    for k in range(steps):
        x = x + dt * velocity(x, k * dt)
    return x


def main() -> None:
    rng = random.Random(SEED)
    noise = [gauss(rng) for _ in range(N)]
    print(f"target: 0.5*N(-1,{SIGMA}^2) + 0.5*N(+1,{SIGMA}^2)  samples={N}  seed={SEED}")
    print(f"v(x=0.50, tau=0.0) = {velocity(0.5, 0.0):+.3f}   (= mean(x1) - x)")
    print(f"v(x=0.50, tau=0.9) = {velocity(0.5, 0.9):+.3f}   (points to the +1 mode)")
    print(f"{'steps':>5} {'near_mode':>9} {'near_mean':>9} {'mean_abs':>8}")
    for steps in STEPS:
        xs = [sample(x0, steps) for x0 in noise]
        near_mode = sum(1 for x in xs if abs(abs(x) - 1.0) < NEAR) / N
        near_mean = sum(1 for x in xs if abs(x) < NEAR) / N
        mean_abs = sum(abs(x) for x in xs) / N
        print(f"{steps:>5} {near_mode:>9.3f} {near_mean:>9.3f} {mean_abs:>8.3f}")
    print("1 Euler step lands every sample on the mean (an action between the modes);")
    print("more steps recover both modes. pi0 uses 10 steps (delta = 0.1).")


if __name__ == "__main__":
    main()
```

How to read it:

- At τ=0 the field is `mean(x1) − x`: the noise has not yet "seen" any mode, so every sample is pulled towards the average 0. With **1** step that is the whole trajectory: near_mean = **1.000**, exactly the MSE failure.
- Late in the path (τ=0.9) the field near x=0.5 is **+3.011**, pointing hard at the +1 mode. More steps give samples time to commit to a side: near_mode rises to **0.780** at 3 steps, **0.987** at 10 and **0.996** at 50.
- 10 steps already gets most of the quality; going from 10 to 50 buys little and costs 5× the action-expert passes. That is why π0 uses 10.

This is a toy: a real policy learns `v_θ` from data with a network and conditions on the observation.

## Fewer steps: rectified flow and consistency

Because every step costs latency, several lines of work try to need fewer steps. Rectified flow (arXiv 2209.03003) straightens the learned paths so that a coarse Euler step stays on track. Consistency Policy (arXiv 2405.07503) distils a diffusion policy so that one or two steps suffice; its abstract reports an order-of-magnitude inference speed-up over the fastest alternative it compares with. ## Absolute, relative and delta actions

What a chunk *contains* matters as much as how it is sampled. The LeRobot action-representations page distinguishes three choices:

| Representation | Each action is | Notes |
| --- | --- | --- |
| absolute | the target joint (or end-effector) position | LeRobot default |
| relative | target minus the current state at chunk start | used by OpenPI / π0; errors do not accumulate across chunks |
| delta | change from the previous action | errors accumulate along the chunk; UMI argues against it |

Relative actions are compatible with RTC (10.2). Flags such as `--policy.use_relative_actions=true` follow the LeRobot v0.6.x docs; commands may change between versions. Not run on this page (本页未运行).

## Common mistakes

- **Using 1 or 2 steps to save time without checking samples.** The toy shows 1 step collapses to the mean, the same failure as MSE.
- **Calling flow matching "faster than diffusion" by default.** It is cheaper per good sample because paths are straight, but each step is still a full action-expert pass.
- **Mixing action representations.** Training on relative actions and executing them as absolute targets sends the arm to the wrong place.
- **Reading the 73 ms as your robot's latency.** It is an RTX 4090 figure from the paper, not measured here.

## OneDP-style one-step regression surrogate
The original [OneDP paper](https://arxiv.org/abs/2410.21257) distils a pretrained diffusion policy by matching **diffused action distributions along the chain with reverse KL**. Its gradient uses a difference of scores; OneDP-S introduces an auxiliary score estimator and OneDP-D uses an analytic simplification. That KL-along-chain objective is **reading only**, not ordinary pointwise teacher MSE. [Consistency Policy](https://arxiv.org/abs/2405.07503) uses consistency trajectory modelling/self-consistency along a probability-flow ODE (with a denoising objective); neither paper is implemented here. OneDP's 2 %–10 % additional cost and 1.5→62 Hz, and any Consistency Policy figures, are **以论文为准**. Real diffusion/GPU/robot work: **本页未运行**.

The papers' Hz and success-rate numbers are for reading comparison only, not measurements or reproduced results on this page.

This additive experiment is a **regression surrogate**: an analytic teacher, not a learned diffusion model. It does not reproduce multimodal action distributions or the score objective, and does not contradict the earlier closed-form mixture toy: one-step generation needs learned information, not merely removing integration steps. We do not redo RTC (10.2), Cal-ConRFT/advantage filtering (10.7), or VLA RL (8.2).

### Declared data, fit budget and independent success

Synthetic plant displacement is `D(a)=a+0.22*a³`. A start has position `x0=−e`, goal 0. Teacher starts `a=0` and makes eight updates `a←a+0.5*(e−D(a))`: **N=8 actual field calls**, no training. Each seed in **11/23/37/53/71** creates 64 stratified demo errors `e∈[−1.2,1.2]` with within-bin fraction 0.25…0.75, labels `teacher(e)+Normal(0,0.008²)`, and one shared random initialization. Both students get identical demo pairs, features and initialization. The four fixed Legendre features are `[1,x,(5x³−3x)/2,(63x⁵−70x³+15x)/8]`, `x=e/1.2`. Full-batch MSE GD uses lr=0.25; the full student has **240 updates**, the deliberately underfit student **2**. This unequal optimization budget is an underfit control, **not a convergence or training-efficiency comparison**.

All three arms are evaluated on the same 64 **held-out eval starts** (within-bin fraction 0.9, disjoint from every seed's demos). No student fitting receives eval starts or teacher eval labels. Action MSE is relative to held-out teacher actions; the teacher's own MSE is zero **by definition**, not ground truth. Independent task success is `abs(−e+D(a))≤0.004`, evaluated by the nonlinear plant, not by agreement with the teacher. One student feature-dot-product forward counts as NFE=1; each teacher field call counts as one. Scorer-only reference queries are excluded from policy inference NFE. These are different call types/FLOPs: **NFE is not measured latency or Hz**, and 8→1 is not an 8× wall-clock claim.

```python
#!/usr/bin/env python3
"""OneDP-style REGRESSION SURROGATE, not KL-along-chain/score distillation.
Synthetic analytic eight-field-call teacher solves a nonlinear inverse plant.
Both students see the SAME 64 noisy teacher demos and copy the SAME init;
240 vs 2 updates is a deliberately unequal underfit control, not convergence proof.
Every scored state/start is held out; fit() never receives eval states/labels.
NFE counts actual field/forward calls, not FLOPs, Hz or wall-clock speed.
Original Consistency Policy and GPU OneDP/Franka are not run: 本页未运行.
"""
from random import Random
from statistics import mean, pstdev

SEEDS = (11, 23, 37, 53, 71)
N_STEPS = 8
N_DEMOS = N_EVAL = 64
FULL_UPDATES, UNDER_UPDATES = 240, 2
LR, DEMO_SIGMA, TOLERANCE = .25, .008, .004
EVAL_STARTS = tuple(-1.2 + 2.4*(j+.9)/N_EVAL for j in range(N_EVAL))


def displacement(action):
    """Independent nonlinear one-step plant: x_next=-error+D(action), goal=0."""
    return action + .22*action**3


def field(error, action):
    return error - displacement(action)


def teacher(error):
    action, nfe = 0., 0
    for _ in range(N_STEPS):
        action += .5*field(error, action)
        nfe += 1
    return action, nfe


def features(error):
    """Fixed Legendre basis on normalized error; not evaluated teacher labels."""
    x = error/1.2
    return (1., x, (5*x**3-3*x)/2, (63*x**5-70*x**3+15*x)/8)


def student(weights, error):
    return sum(w*x for w,x in zip(weights, features(error))), 1


def demonstrations(seed):
    rng = Random(seed)
    # Training fractional bins .25..75 never overlap held-out fractional bin .9.
    starts = tuple(-1.2 + 2.4*(j+.25+.5*rng.random())/N_DEMOS for j in range(N_DEMOS))
    demos = tuple((s, teacher(s)[0]+rng.gauss(0,DEMO_SIGMA)) for s in starts)
    initial = tuple(rng.gauss(0,.02) for _ in range(4))
    return demos, initial


def fit(demos, initial, updates):
    """Only training pairs and initial weights; no teacher query or held-out input."""
    weights = list(initial)
    design = tuple((features(state), label) for state,label in demos)
    for _ in range(updates):
        gradient = [0.]*len(weights)
        for basis, label in design:
            residual = sum(w*x for w,x in zip(weights,basis))-label
            for j,x in enumerate(basis):
                gradient[j] += 2*residual*x/len(design)
        weights = [w-LR*g for w,g in zip(weights,gradient)]
    return tuple(weights)


def evaluate(policy, starts, references, training_states):
    if set(starts) & set(training_states):
        raise ValueError("training/evaluation state overlap")
    mse, successes, calls = 0., 0, 0
    for state, reference in zip(starts,references):
        action, nfe = policy(state)
        mse += (action-reference)**2
        successes += int(abs(-state+displacement(action)) <= TOLERANCE)
        calls += nfe
    return mse/len(starts), calls/len(starts), successes/len(starts)


def run(seed):
    demos, initial = demonstrations(seed)
    full, under = fit(demos, initial,FULL_UPDATES), fit(demos, initial,UNDER_UPDATES)
    # References are SCORER-ONLY; no student inference/fitting receives them.
    references = tuple(teacher(s)[0] for s in EVAL_STARTS)
    states = tuple(s for s,_ in demos)
    policies = (("teacher_N8",teacher,0),
                ("student_1",lambda s: student(full,s),FULL_UPDATES),
                ("underfit_1",lambda s: student(under,s),UNDER_UPDATES))
    return [(name,updates,evaluate(policy,EVAL_STARTS,references,states)) for name,policy,updates in policies]


def main():
    print("OneDP-style regression surrogate ONLY; KL-along-chain is reading, not implemented")
    print("shared demos=64 held-out eval starts=64 overlap=0; N-step teacher=8 actual field calls")
    print("student updates=240 underfit updates=2 (unequal on purpose); same data/features/init")
    print("demo_sigma=0.008 success_abs_plant_error<=0.004; NFE is calls, not Hz or wall time")
    print("seed arm fit_updates action_MSE NFE_per_query success")
    all_rows = {name: [] for name in ("teacher_N8","student_1","underfit_1")}
    for seed in SEEDS:
        for name,updates,metrics in run(seed):
            all_rows[name].append(metrics)
            mse,nfe,success=metrics
            print(f"{seed} {name} {updates} {mse:.8f} {nfe:.1f} {success:.6f}")
    print("five-seed spread: arm metric mean population_sd min max")
    for name,rows in all_rows.items():
        for j,metric in enumerate(("action_MSE","NFE","success")):
            values=[row[j] for row in rows]
            print(f"{name} {metric} {mean(values):.8f} {pstdev(values):.8f} {min(values):.8f} {max(values):.8f}")
    print("Teacher self-reference MSE=0 by definition; success independently uses nonlinear plant")
    print("Scorer reference queries excluded from policy NFE; different call types are not equal FLOPs")
    print("No diffusion distribution/score/consistency training; GPU and robot: 本页未运行; paper 以论文为准")


if __name__ == "__main__":
    main()
```

## Diffusion Forcing: an independent noise level per token

Everything above treats an action chunk as one object that is denoised all at once, every element at the same noise level. **Diffusion Forcing** asks what happens if each **token** of a sequence (an action, a state, a frame) gets **its own, independent noise level** during training. A causal model trained that way can act like a next-token predictor (clean past, noisy next token), like a full-sequence diffusion model (everything equally noisy), or anything in between, and the sampler chooses the pattern without retraining. This section is **not** OneDP's consistency distillation (above), **not** a WorldVLA attention mask and **not** a rewrite of the flow-matching maths: it is about **which noise patterns the model is trained on**.

**Sources actually opened (body read).** **Diffusion Forcing (arXiv 2407.01392, HTML and PDF via pdftotext; NeurIPS 2024).** §3.1 reads noising as **partial masking**: teacher forcing masks the next token and predicts it from a clean past (masking along the time axis), full-sequence diffusion noises all tokens to the same level (masking along the noise axis). §3.2: each token `x_t` gets a level `k_t` sampled **independently** (Algorithm 1; App. B.2: i.i.d. uniform over the levels), a causal RNN keeps a latent `z_t`, and the loss is the ordinary noise-prediction loss summed over tokens (Eq. 3.1); Theorem 3.1 states that this optimises a reweighted ELBO, and under conditions a bound for every sequence of noise levels at once. Sampling walks down a scheduling matrix `K` (rows = denoising steps, columns = tokens). §3.3 and App. B.4: long rollouts are **stabilised** by conditioning on the previous token at a small noise level `0 < k_small ≪ K`; a zig-zag schedule keeps the far future noisier than the near future; guidance gradients from future tokens can steer past ones (§3.3, Monte Carlo Guidance §3.4). §4.1: on DMLab and Minecraft video, teacher-forcing and causal full-sequence baselines with the same RNN **diverge** past the training horizon while Diffusion Forcing rolls out stably (e.g. 1000 frames). §4.2: on Maze2D planning it beats Diffuser, which needs a hand-made PD controller to execute its plans. §4.4: on a real Franka fruit-swap task that needs memory of the initial layout it reports 80 % success where a memoryless diffusion policy fails, and 76 % against 48 % for a next-frame diffusion baseline under occlusions and distractors. All numbers **以论文为准**; video models, the Franka and GPU training: **本页未运行**. **FORGE-Tree (arXiv 2510.21744, abstract and introduction via pdftotext):** a follow-on that couples a stage-aligned Diffusion Forcing head on a frozen VLA encoder with Monte Carlo Tree Diffusion, partially denoising one target segment at a time; reported +13.4 to +17.2 points on LIBERO (以论文为准). **Reading only** — no toy here.

### Three noise patterns, one model class

Write a noisy token as `x̃ = √ᾱ_k · x + √(1 − ᾱ_k) · ε` with `ᾱ_0 = 1` (clean) and `ᾱ_K = 0` (pure noise). A causal denoiser sees the noisy previous token and the noisy current token and predicts the clean current token. The three arms train **the same model class** on **the same data and noise**, and differ only in which pairs of levels `(k_prev, k_cur)` they ever see:

| Arm | Training pattern | What the sampler can do |
|---|---|---|
| teacher forcing | `k_prev = 0`, `k_cur` random | feed its own output back as if it were clean |
| Diffusion Forcing | `k_prev`, `k_cur` independent | re-noise its own output to `k_small` and trust it less |
| full-sequence (causal) | `k_prev = k_cur` | context must be noised to the current level at every step |

<Formula label="Feedback stability (one generated token)">x_new = G·x_prev + (terms in the fresh noise); ρ(G) &lt; 1 ⇒ fed-back history contracts, ρ(G) &gt; 1 ⇒ it grows every step</Formula>

**Worked example.** If a model's one-token gain is `ρ(G) = 1.023`, an error fed back as clean history grows by `1.023^120 ≈ 15` over 120 tokens past an 8-token training window; with `ρ(G) = 0.95` the same error shrinks to `0.95^120 ≈ 0.002`. Re-noising the context to `ᾱ = 0.976` (the toy's `k_small = 1`) tells the model "this token is slightly uncertain", and the least-squares fit shrinks its weight on that token. The price is that every sampled token inherits that uncertainty, so the sample wanders more.

### Fair setup

`diffusion_forcing_token_noise_toy.py` is **synthetic** and stdlib only. **Model assumptions:** tokens are 2D points from a noisy limit-cycle map `x′ = R(0.3) · x · (1 + 0.15 (1 − |x|²)) + N(0, 0.02² I)` whose true orbit is the unit circle; training sequences are **8 tokens** long and start at radius `U(0.2, 1.2)`, so they contain growing and shrinking spirals. The denoiser is a **linear stand-in** for the paper's RNN: one least-squares map `x̂₀ = P x̃_prev + Q x̃_cur + b` per pair of levels, `K = 10` levels on a cosine schedule `ᾱ_k = cos²(πk/20)`; each token is sampled by deterministic DDIM from level 10 to 0. The linear map cannot represent a limit cycle, so every arm is misspecified in the same way. The **stability criterion** is `ρ(G)` of the one-token map from the previous token to the new one; the sampler is affine in the previous token, so the toy computes `G` exactly from two unit differences.

**Common random numbers:** per seed all arms train on the same 2000 sequences with the same noise vectors and the same uniform draws that set the levels; per evaluation episode they share the start on the circle, the true continuation, every initial token noise and every context noise. Five seeds × 20 episodes. **Regimes:** `in_horizon` (8 tokens: `mse` to the shared true continuation, `jit` = mean `|x_{t+1} − f(x_t)|`, the dynamics residual); `past_horizon` (128 tokens: `div` = share of episodes whose radius ever exceeds 3, `amp` = mean `|r − 1|` over tokens 9–128 with `r` capped at 3); `guided_s8` / `guided_s32` (an 8-token plan should end near the true token 8: a **guidance stand-in** that keeps the best of S sampled plans by final distance — **not** the paper's gradient or Monte Carlo Guidance; `goal` = that distance, `jit` = the chosen plan's dynamics residual). The C arm is **causal** and token-by-token: it **shares a single noise level** across tokens (`k_prev = k_cur`) and **re-noises the context** to that level at every step, so its one-token gain is `ρ(G)` 0.6755–0.6890 (about 0.68) on every seed. That contracting map is why C does **not** reproduce the **diverging** causal full-sequence baseline in Diffusion Forcing §4.1; a non-causal full-sequence planner with joint gradient guidance (Diffuser) is **not** modelled either. The toy also sweeps `k_small` for B.

#!/usr/bin/env python3
"""Diffusion Forcing stand-in: what the training noise pattern does to a causal token model. Stdlib only.

Model assumptions (also stated in the lesson prose):
  tokens are 2D points from a noisy limit-cycle map x' = R(0.3) x (1 + 0.15 (1 - |x|^2)) + N(0, 0.02^2 I);
  the true orbit is the unit circle. Training sequences are 8 tokens long and start at radius
  U(0.2, 1.2), so they contain growing and shrinking spirals. The causal denoiser is the SAME
  model class for every arm: for each pair of noise levels (k_prev, k_cur) one linear map
  x0_hat(cur) = P x~prev + Q x~cur + b, fit by least squares (tiny ridge), where x~ = sqrt(abar_k) x
  + sqrt(1 - abar_k) eps. K = 10 levels, cosine schedule abar_k = cos^2(pi k / 20), abar_10 = 0.
  Sampling one token runs deterministic DDIM from level 10 to 0 with the previous token as context.
  This is a linear stand-in for the paper's RNN; it is not a video model and not a robot policy.

Arms (Common random numbers: per seed the same training sequences, the same per-token noise
vectors and the same uniform draws that set noise levels; per evaluation episode the same start,
true continuation, initial token noise and context noise):
  A_teacher   teacher forcing: history always clean (k_prev = 0), current token at a random level;
              at sampling time the model's own previous output is fed back as if clean
  B_dforcing  Diffusion Forcing: k_prev and k_cur drawn independently per token; at sampling time
              the previous output is re-noised to k_small = 1 before it is used (the paper's
              stabilisation, App. B.4), which the model has been trained to discount
  C_fullseq   causal full-sequence diffusion: one shared level for every token (k_prev = k_cur);
              at sampling time the context is re-noised to the current token's level at every step
              (the only pattern it has seen), a stand-in for conditioning without reconstruction guidance

Stability criterion: sampling one token is affine in the previous token for fixed noise, so its
Jacobian G is exact; rho(G) < 1 means fed-back history contracts, rho(G) > 1 means it grows every step.

Regimes: in_horizon (8 tokens, mse to the shared true continuation, jit = mean |x_{t+1} - f(x_t)|),
past_horizon (128 tokens: div = share of episodes whose radius ever exceeds 3, amp = mean |r - 1|
over tokens 9..128 with r capped at 3), guided_s8 / guided_s32 (an 8-token plan must end near a goal;
guidance stand-in = best of S sampled plans by final distance, not the paper's gradient / Monte
Carlo guidance; goal = final distance of the chosen plan, jit = its dynamics residual).

Labels: tie = identical on every seed; |m| < 1e-9 and sd < 1e-9 = numerically zero
(floating-point residue), effectively a tie, no sign count; |paired mean| <= sd = near-tie / small
gap within seed noise; |m| > sd = consistent gap (small if |m| < 20 % of the smaller arm mean, else
clear), always with a sign count.
Video / robot results and GPU training: 本页未运行. Paper numbers: 以论文为准.
"""
from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
K = 10
ABAR = tuple(0.0 if k == K else math.cos(math.pi * k / (2 * K)) ** 2 for k in range(K + 1))
THETA, GAMMA, SIG_W = 0.3, 0.15, 0.02
N_TRAIN, T_TRAIN = 2000, 8
EPISODES = 20
T_PAST = 128
K_SMALL = 1
ARMS = ("A_teacher", "B_dforcing", "C_fullseq")
REGIMES = (
    ("in_horizon", ("mse", "jit")),
    ("past_horizon", ("div", "amp")),
    ("guided_s8", ("goal", "jit")),
    ("guided_s32", ("goal", "jit")),
)


def f(x):
    """True limit-cycle map (deterministic part)."""
    g = 1.0 + GAMMA * (1.0 - (x[0] ** 2 + x[1] ** 2))
    c, s = math.cos(THETA), math.sin(THETA)
    return (g * (c * x[0] - s * x[1]), g * (s * x[0] + c * x[1]))


def noisy(x, k, e):
    a = ABAR[k]
    return (math.sqrt(a) * x[0] + math.sqrt(1 - a) * e[0], math.sqrt(a) * x[1] + math.sqrt(1 - a) * e[1])


def solve(a, b):
    n = len(a)
    m = [row[:] + [b[i]] for i, row in enumerate(a)]
    for i in range(n):
        p = max(range(i, n), key=lambda r: abs(m[r][i]))
        m[i], m[p] = m[p], m[i]
        for r in range(n):
            if r != i:
                q = m[r][i] / m[i][i]
                for c in range(i, n + 1):
                    m[r][c] -= q * m[i][c]
    return [m[i][n] / m[i][i] for i in range(n)]


def fit(rows):
    """Least squares (ridge 1e-6) for x0_hat = W [x~prev, x~cur, 1]."""
    d = 5
    a = [[1e-6 if i == j else 0.0 for j in range(d)] for i in range(d)]
    b = [[0.0] * d for _ in range(2)]
    for ft, y in rows:
        for i in range(d):
            for j in range(d):
                a[i][j] += ft[i] * ft[j]
            for o in range(2):
                b[o][i] += ft[i] * y[o]
    return [solve(a, b[o]) for o in range(2)]


def training_draws(seed):
    """Common random numbers for training: sequences, noise vectors, level draws."""
    rng = random.Random(7000 + seed)
    data, draws = [], []
    for _ in range(N_TRAIN):
        r, ph = rng.uniform(0.2, 1.2), rng.uniform(0, 2 * math.pi)
        x = (r * math.cos(ph), r * math.sin(ph))
        seq = [x]
        for _ in range(T_TRAIN - 1):
            y = f(x)
            x = (y[0] + rng.gauss(0, SIG_W), y[1] + rng.gauss(0, SIG_W))
            seq.append(x)
        data.append(seq)
        u_seq = rng.random()
        draws.append([(rng.random(), rng.random(), u_seq, (rng.gauss(0, 1), rng.gauss(0, 1)),
                       (rng.gauss(0, 1), rng.gauss(0, 1))) for _ in range(T_TRAIN)])
    return data, draws


def level(u):
    return min(K, int(u * (K + 1)))


def train(arm, data, draws):
    rows = {}
    for seq, dr in zip(data, draws):
        for t in range(1, T_TRAIN):
            u_prev, u_cur, u_seq, e_prev, e_cur = dr[t]
            if arm == "A_teacher":
                kp, kc = 0, level(u_cur)
            elif arm == "B_dforcing":
                kp, kc = level(u_prev), level(u_cur)
            else:
                kp = kc = level(u_seq)
            xp, xc = noisy(seq[t - 1], kp, e_prev), noisy(seq[t], kc, e_cur)
            rows.setdefault((kp, kc), []).append(((xp[0], xp[1], xc[0], xc[1], 1.0), seq[t]))
    return {key: fit(v) for key, v in rows.items()}


def predict(w, xp, xc):
    ft = (xp[0], xp[1], xc[0], xc[1], 1.0)
    return (sum(a * b for a, b in zip(w[0], ft)), sum(a * b for a, b in zip(w[1], ft)))


def sample_token(models, arm, prev, init, ctx_noise, k_small=K_SMALL):
    """Deterministic DDIM from level K to 0 for one token, given the previous (generated) token."""
    x = init
    for k in range(K, 0, -1):
        kp = 0 if arm == "A_teacher" else (k_small if arm == "B_dforcing" else k)
        x0 = predict(models[(kp, k)], noisy(prev, kp, ctx_noise), x)
        a, an = ABAR[k], ABAR[k - 1]
        eh = ((x[0] - math.sqrt(a) * x0[0]) / math.sqrt(1 - a), (x[1] - math.sqrt(a) * x0[1]) / math.sqrt(1 - a))
        x = (math.sqrt(an) * x0[0] + math.sqrt(1 - an) * eh[0], math.sqrt(an) * x0[1] + math.sqrt(1 - an) * eh[1])
    return x


def token_gain(models, arm, k_small=K_SMALL):
    """Spectral radius of G = d(new token)/d(previous token). sample_token is affine in the previous
    token for fixed noise, so two unit differences give G exactly (up to round-off). rho(G) < 1 is
    the stability criterion for feeding generated tokens back: the deterministic part contracts."""
    z = ((0.0, 0.0), (0.0, 0.0))
    o = sample_token(models, arm, (0.0, 0.0), *z, k_small)
    c1 = sample_token(models, arm, (1.0, 0.0), *z, k_small)
    c2 = sample_token(models, arm, (0.0, 1.0), *z, k_small)
    a, b, c, d = c1[0] - o[0], c2[0] - o[0], c1[1] - o[1], c2[1] - o[1]
    tr, det = a + d, a * d - b * c
    disc = tr * tr / 4 - det
    if disc >= 0:
        return max(abs(tr / 2 + math.sqrt(disc)), abs(tr / 2 - math.sqrt(disc)))
    return math.sqrt(det)


def episode_draws(regime, seed, ep):
    """Common random numbers for one evaluation episode, shared by all arms."""
    rng = random.Random(100000 * [r[0] for r in REGIMES].index(regime) + 1000 * seed + ep)
    ph = rng.uniform(0, 2 * math.pi)
    x0 = (math.cos(ph), math.sin(ph))
    truth = [x0]
    for _ in range(T_TRAIN):
        y = f(truth[-1])
        truth.append((y[0] + rng.gauss(0, SIG_W), y[1] + rng.gauss(0, SIG_W)))
    n_plans = {"guided_s8": 8, "guided_s32": 32}.get(regime, 1)
    length = T_PAST if regime == "past_horizon" else T_TRAIN
    noise = [[((rng.gauss(0, 1), rng.gauss(0, 1)), (rng.gauss(0, 1), rng.gauss(0, 1))) for _ in range(length)]
             for _ in range(n_plans)]
    return x0, truth, noise


def rollout(models, arm, x0, noise_row, k_small=K_SMALL):
    xs, x = [x0], x0
    for init, ctx in noise_row:
        x = sample_token(models, arm, x, init, ctx, k_small)
        xs.append(x)
        if math.hypot(*x) > 1e6:
            break
    return xs


def jitter(xs):
    return sum(math.dist(xs[t + 1], f(xs[t])) for t in range(len(xs) - 1)) / (len(xs) - 1)


def run_episode(regime, models, arm, x0, truth, noise, k_small=K_SMALL):
    if regime == "in_horizon":
        xs = rollout(models, arm, x0, noise[0], k_small)
        mse = sum((xs[t][0] - truth[t][0]) ** 2 + (xs[t][1] - truth[t][1]) ** 2 for t in range(1, T_TRAIN + 1)) / T_TRAIN
        return {"mse": mse, "jit": jitter(xs)}
    if regime == "past_horizon":
        xs = rollout(models, arm, x0, noise[0], k_small)
        rs = [min(math.hypot(*x), 3.0) for x in xs[1:]] + [3.0] * (T_PAST + 1 - len(xs))
        return {"div": 1.0 if max(rs) >= 3.0 else 0.0, "amp": sum(abs(r - 1.0) for r in rs[T_TRAIN:]) / (T_PAST - T_TRAIN)}
    goal = truth[T_TRAIN]
    best = min((rollout(models, arm, x0, row) for row in noise), key=lambda xs: math.dist(xs[-1], goal))
    return {"goal": math.dist(best[-1], goal), "jit": jitter(best)}


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x: float) -> str:
    if x != 0.0 and abs(x) < 5e-4:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


NUM_ZERO = 1e-9  # |m| and sd both below this: floating-point residue, not a gap


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(mean_sd(xa)[0], mean_sd(xb)[0]):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def main() -> None:
    print("Synthetic 2D limit-cycle tokens; shared training sequences / noise / levels and shared evaluation draws; "
          "linear stand-in denoiser, not a video model or robot")
    print(f"seeds={len(SEEDS)} train={N_TRAIN}x{T_TRAIN} tokens K={K} cosine levels k_small={K_SMALL} "
          f"episodes={EPISODES} past horizon={T_PAST}")
    models = {seed: None for seed in SEEDS}
    for seed in SEEDS:
        data, draws = training_draws(seed)
        models[seed] = {arm: train(arm, data, draws) for arm in ARMS}
    for arm in ARMS:
        print(f"{arm} one-token gain rho(G) per seed: " + " ".join(f"{token_gain(models[s][arm], arm):.4f}" for s in SEEDS))
    print("B_dforcing k_small=0 rho(G) per seed: " + " ".join(f"{token_gain(models[s]['B_dforcing'], 'B_dforcing', 0):.4f}" for s in SEEDS)
          + " (rho < 1: generated history contracts; rho > 1: it grows)")
    print("regime arm metrics  (mean+-sd over seeds of the per-seed episode means)")
    kept = {}
    for regime, metrics in REGIMES:
        per = {arm: {m: [] for m in metrics} for arm in ARMS}
        for seed in SEEDS:
            acc = {arm: {m: 0.0 for m in metrics} for arm in ARMS}
            for ep in range(EPISODES):
                x0, truth, noise = episode_draws(regime, seed, ep)
                for arm in ARMS:
                    out = run_episode(regime, models[seed][arm], arm, x0, truth, noise)
                    for m in metrics:
                        acc[arm][m] += out[m] / EPISODES
            for arm in ARMS:
                for m in metrics:
                    per[arm][m].append(acc[arm][m])
        kept[regime] = per
        for arm in ARMS:
            print(f"{regime} {arm} " + " ".join("{}={}+-{}".format(m, *map(num, mean_sd(per[arm][m]))) for m in metrics))
        for a, b in (("B_dforcing", "A_teacher"), ("C_fullseq", "B_dforcing")):
            for m in metrics:
                print(f"{regime} paired {a[0]}-{b[0]} {m}: {verdict(per[a][m], per[b][m])}")
    for ks in (0, 1, 2):
        mse, div = [], []
        for seed in SEEDS:
            a = b = 0.0
            for ep in range(EPISODES):
                x0, truth, noise = episode_draws("in_horizon", seed, ep)
                a += run_episode("in_horizon", models[seed]["B_dforcing"], "B_dforcing", x0, truth, noise, ks)["mse"] / EPISODES
                x0, truth, noise = episode_draws("past_horizon", seed, ep)
                b += run_episode("past_horizon", models[seed]["B_dforcing"], "B_dforcing", x0, truth, noise, ks)["div"] / EPISODES
            mse.append(a)
            div.append(b)
        print(f"B_dforcing k_small={ks}: in_horizon mse={'{}+-{}'.format(*map(num, mean_sd(mse)))} "
              f"past_horizon div={'{}+-{}'.format(*map(num, mean_sd(div)))}")
        if ks == 0:
            print(f"in_horizon paired B(k_small=0)-A mse: {verdict(mse, kept['in_horizon']['A_teacher']['mse'])}")
    print("in_horizon: re-noising the history costs B accuracy inside the training length; A uses the clean history")
    print("past_horizon: A feeds its own output back as clean history and its growing linear map diverges")
    print("guided: best-of-S selection rewards diverse samples; the chosen plan's jit shows whether it is dynamically consistent")
    print("k_small=0 turns B's sampler into teacher-forcing-style feedback: in-horizon it is within seed noise of A, past the horizon it diverges like A")
    print("C here is causal and token-by-token; a non-causal full-sequence planner with joint gradient guidance is not modelled")
    print("No winner declared; Diffusion Forcing video / planning / Franka results 以论文为准; GPU training 本页未运行")


if __name__ == "__main__":
    main()

### Read the regimes

How the labels are used on this page: **tie** only when the paired per-seed difference is exactly zero on every seed; **numerically zero (floating-point residue), effectively a tie** when both `|paired mean|` and sd are below `10⁻⁹` (checked before the sd test; such lines carry no sign count and are never called consistent or clear); **near-tie / small gap, within seed noise** when `|paired mean| ≤ sd`; a **consistent** gap when `|paired mean| > sd`, called **small** if `|m|` is under 20 % of the smaller arm mean and **clear** otherwise (the 20 % rule only chooses between those two words). Every consistent or clear line carries a same-sign count over the 5 seeds, any seed with the opposite sign (or an exactly equal seed) is reported, and a sign count alone never makes a gap consistent. Paired differences are B−A and C−B, shown as mean ± sd over seeds; for every metric here lower is better.

- **Stability criterion first:** teacher forcing learns a clean-history map with `ρ(G)` 1.0216–1.0262 on every seed (> 1); Diffusion Forcing with `k_small = 1` has 0.9383–0.9624 and the causal full-sequence arm C, which shares one noise level and re-noises the context, has 0.6755–0.6890 (about 0.68, < 1) — so C stays bounded here and does **not** match the diverging causal full-sequence baseline of §4.1. With `k_small = 0` the same B model is back at 1.0194–1.0306.
- **in_horizon — Diffusion Forcing loses inside the training length:** B's `mse` is 0.3560±0.0450 against A's 0.0183±0.0017 (**clear gap**, paired 0.3378±0.0455, same sign on all 5 seeds), and `jit` 0.2495 against 0.0569 (clear, 0.1927±0.0242, 5/5): re-noising the history costs accuracy when the clean history was fine. Sampled with `k_small = 0`, the **same** B model is a **near-tie** with A (paired 0.0011±0.0062, 3 of 5 seeds opposite). C is worse again (C−B `mse` 0.5024±0.0885, clear, 5/5).
- **past_horizon — Diffusion Forcing wins where teacher forcing diverges:** A diverges in every episode (`div` 1.0000), B and C in none: B−A `div` −1.0000±0.0000 and `amp` −1.2794±0.0317 (clear, 5/5). C−B `div` is a **tie: identical on every seed** (both 0), but C's amplitude error is larger (0.5493 against 0.3899; paired 0.1594±0.0106, clear, 5/5). B does **not** track the true circle: `amp` 0.3899 means its radius is off by about 0.39 on average. Bounded is not the same as accurate.
- **guided_s8 — teacher forcing beats Diffusion Forcing on the guided score:** with 8 candidate plans A's best final distance is 0.1931 against B's 0.2382 (B−A 0.0451±0.0242, clear, 5/5), and A's plans are far smoother (`jit` 0.0496 against 0.2124).
- **guided_s32 — more candidates flip it:** with 32 plans B's more varied samples reach the goal closer, 0.1222 against 0.1737 (B−A −0.0515±0.0210, clear, 5/5), but the chosen plan is still about 4.6 times less dynamically consistent (`jit` 0.2109 against 0.0460). Best-of-S selection rewards diversity, which is not the same as a better model.
- **Full-sequence never ties or beats B on the guided score here:** C−B `goal` is 0.2966±0.0505 at S = 8 and 0.2248±0.0468 at S = 32 (clear losses for C, 5/5). In this causal, token-by-token stand-in the regime where full-sequence guidance wins does not appear; that would need a non-causal planner with joint guidance, which the toy does not model.

The page **does not declare a universal winner**: independent per-token noise buys a stable rollout past the training horizon at the cost of in-horizon accuracy and smoothness, and the stability comes from the re-noising step at sampling time (`k_small = 0` diverges like teacher forcing). ## Knowledge Insulation: discretized actions and stopped expert gradients

Attaching a newly initialised continuous **diffusion or flow-matching action expert** to a pretrained VLM is the setting of [Knowledge Insulation](https://arxiv.org/abs/2505.23705) (Danny Driess, Jost Tobias Springenberg, Brian Ichter, Lili Yu, Adrian Li-Bell, Karl Pertsch, Allen Z. Ren, Homer Walke, Quan Vuong, Lucy Xiaoyang Shi, Sergey Levine; arXiv **2505.23705**). The paper's claim, read in the abstract, introduction and §5.2, is that **naively back-propagating the expert's gradients into the backbone harms training speed and knowledge transfer**. The recipe **fine-tunes the VLM with a next-token loss on discretized actions** (and, in their full method, VLM data) while the continuous expert is trained with flow matching **without propagating its gradients back into the VLM**. The stop is implemented in the attention layers (their eqs. 5–6): backbone tokens do not receive expert-side gradients. Paper speed, language-following and LIBERO / DROID numbers are **以论文为准**. GPU training, π0 weights and those benchmarks are **本页未运行**.

This is **not** ChatVLA phased alignment (robot-only SFT wiping a VQA head, already on the VLA fine-tune lesson) and **not** the OneDP one-step regression already on this page.

### Fair setup

`knowledge_insulation_flow_toy.py` is **synthetic** and stdlib only. **Model assumptions:** the input is in R⁶. A pretrained-style backbone `h = A x` starts as a **semantic projector**: `A0` is block-diagonal (`I₃` on the first three coordinates, zeros elsewhere) plus a small Gaussian jitter only in the semantic block, so coordinates 3 and 4 of `x` do not pass through a frozen backbone. A **frozen** VQA / instruction probe reads the first two coordinates of `h` (NQ equally spaced prototypes in the first two hidden coordinates); its labels are defined by the unperturbed projector, and the printed frozen baseline is that probe on `A0`, not a retrained head. In the `conflict` and `coarse_bins` regimes the 2-D action lives on coordinates 3 and 4. Discrete-action tokens are a uniform `BINS × BINS` grid on [−3, 3]², a stand-in for the paper's FAST / naive tokens, **not FAST itself**. After the first run, the discrete head reads only the action-slot units `h[3:6]` (a stand-in for the paper's separate discrete-action tokens); the first-run alternative, which fed the **full** `h` to the discrete head, is still trained on the same seeds and printed — that choice was **not** fixed before the first run.

The action expert is a **linear flow-matching residual**: given `h`, a noisy action `a_τ = τ a + (1−τ)ε` and `τ`, it predicts `u = a − ε`. Training is plain SGD. **There is no plant integration step** (discrete SGD updates). Inference uses a fixed 1-step Euler read-out (the true velocity is constant along the straight path, so 1 step is exact for a perfect expert); a 4-step read-out is also printed, not as a stability criterion.

**Arms**, with **common random numbers** (per regime and seed the `A0` jitter, expert and discrete-head init, every training batch of `(x, ε, τ)`, and the test set are drawn once and reused); equal budget `STEPS = 400`, batch 8, learning rate 0.05, five seeds:

- **A_naive** — the flow-matching loss back-propagates into `A`; no discrete-action CE.
- **B_insulate** — discrete-action CE into `A`; expert gradients stop at `h`.
- **C_frozen** — `A` is held at `A0`; expert only; no discrete-action CE.

**Metrics:** probe accuracy % on the test set; control success % (`|a_hat − a| ≤ 0.35` with the 1-step read-out); 1-step and 4-step action MSE; `fit_mid` / `fit_final` = mean test flow-matching residual after 100 and 400 steps (a training-speed proxy).

**Regimes, written before the first run:**

- **conflict** — action `(x₃, x₄)`, `BINS = 4`. A consistent probe drop versus B and/or a slower residual drop; A and B may near-tie on in-distribution control; C wins the probe and loses on control — both metrics kept.
- **coarse_bins** — same targets, `BINS = 2` (weaker discrete CE). B may lose control to A; the probe comparison is printed either way.
- **aligned** — action `(x₀, x₁)` (inside the semantic block), `BINS = 4`. C may near-tie on control; any probe drop is printed; not used to pick a winner.

from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
D, ACT, NQ = 6, 2, 3
SEM = 3
STEPS, MID, BATCH, TEST = 400, 100, 8, 400
LR = 0.05
TOL = 0.35
INIT_SD = 0.05
EXP_SD = 0.05
BIN_LO, BIN_HI = -3.0, 3.0
NUM_ZERO = 1e-9
ARMS = ("A_naive", "B_insulate", "C_frozen")
# name: (action coordinates, bins-per-axis); written before the first run
REGIMES = {
    "conflict": ((3, 4), 4),
    "coarse_bins": ((3, 4), 2),
    "aligned": ((0, 1), 4),
}
STREAM = {"conflict": 0, "coarse_bins": 1, "aligned": 2}
# frozen probe prototypes in the first two hidden coordinates
V0 = [[math.cos(2 * math.pi * k / NQ), math.sin(2 * math.pi * k / NQ)] for k in range(NQ)]


def zeros(r, c=None):
    if c is None:
        return [0.0] * r
    return [[0.0] * c for _ in range(r)]


def matvec(mat, v):
    return [sum(a * b for a, b in zip(row, v)) for row in mat]


def add_vec(a, b, s=1.0):
    return [x + s * y for x, y in zip(a, b)]


def axpy_mat(dst, src, s):
    for i, row in enumerate(src):
        for j, v in enumerate(row):
            dst[i][j] += s * v


def axpy_vec(dst, src, s):
    for i, v in enumerate(src):
        dst[i] += s * v


def outer(u, v):
    return [[ui * vj for vj in v] for ui in u]


def argmax(v):
    return max(range(len(v)), key=lambda k: v[k])


def softmax(logits):
    m = max(logits)
    ex = [math.exp(x - m) for x in logits]
    z = sum(ex)
    return [e / z for e in ex]


def clip_bin(val, bins):
    t = (val - BIN_LO) / (BIN_HI - BIN_LO)
    i = int(math.floor(t * bins))
    return max(0, min(bins - 1, i))


def action_of(x, coord):
    return [x[coord[0]], x[coord[1]]]


def token_of(a, bins):
    return clip_bin(a[0], bins) * bins + clip_bin(a[1], bins)


def vqa_label(x):
    # defined by the unperturbed semantic projector: h* = (x0, x1)
    return argmax([v[0] * x[0] + v[1] * x[1] for v in V0])


def probe_pred(h):
    return argmax([v[0] * h[0] + v[1] * h[1] for v in V0])


def make_A0(rng):
    A = zeros(D, D)
    for i in range(SEM):
        for j in range(SEM):
            A[i][j] = (1.0 if i == j else 0.0) + rng.gauss(0.0, INIT_SD)
    return A


def feat_of(h, a_tau, tau):
    return list(h) + list(a_tau) + [tau]


def shared_draws(regime, seed):
    rng = random.Random(2000 * STREAM[regime] + seed)
    coord, bins = REGIMES[regime]
    nclass = bins * bins
    A0 = make_A0(rng)
    We0 = [[rng.gauss(0.0, EXP_SD) for _ in range(D + ACT + 1)] for _ in range(ACT)]
    be0 = [rng.gauss(0.0, EXP_SD) for _ in range(ACT)]
    Wd0 = [[rng.gauss(0.0, EXP_SD) for _ in range(D)] for _ in range(nclass)]
    bd0 = [0.0] * nclass
    batches = []
    for _ in range(STEPS):
        xs, eps, taus = [], [], []
        for _ in range(BATCH):
            x = [rng.gauss(0.0, 1.0) for _ in range(D)]
            e = [rng.gauss(0.0, 1.0) for _ in range(ACT)]
            t = rng.random()
            xs.append(x)
            eps.append(e)
            taus.append(t)
        batches.append((xs, eps, taus))
    test = []
    for _ in range(TEST):
        x = [rng.gauss(0.0, 1.0) for _ in range(D)]
        e = [rng.gauss(0.0, 1.0) for _ in range(ACT)]
        test.append((x, action_of(x, coord), e, vqa_label(x)))
    return {
        "coord": coord,
        "bins": bins,
        "nclass": nclass,
        "A0": A0,
        "We0": We0,
        "be0": be0,
        "Wd0": Wd0,
        "bd0": bd0,
        "batches": batches,
        "test": test,
    }


def copy_mat(m):
    return [row[:] for row in m]


def flow_predict(We, be, h, a_tau, tau):
    return add_vec(matvec(We, feat_of(h, a_tau, tau)), be)


def integrate(We, be, h, eps, steps):
    a = list(eps)
    if steps <= 1:
        u = flow_predict(We, be, h, a, 0.0)
        return add_vec(a, u)
    dt = 1.0 / steps
    t = 0.0
    for _ in range(steps):
        u = flow_predict(We, be, h, a, t)
        a = add_vec(a, u, dt)
        t += dt
    return a


def train_arm(arm, draws, discrete="slot"):
    A = copy_mat(draws["A0"])
    We = copy_mat(draws["We0"])
    be = draws["be0"][:]
    Wd = copy_mat(draws["Wd0"])
    bd = draws["bd0"][:]
    coord, bins, nclass = draws["coord"], draws["bins"], draws["nclass"]
    # "slot": discrete head sees h[SEM:] only (main; chosen after the first run)
    # "full": first-run alternative, discrete head sees the whole of h
    if discrete == "slot":
        Wd = [row[SEM:] for row in Wd]
        d_in = D - SEM
    else:
        d_in = D
    mid_snapshot = None
    for step, (xs, eps, taus) in enumerate(draws["batches"]):
        gA, gWe, gbe = zeros(D, D), zeros(ACT, D + ACT + 1), zeros(ACT)
        gWd, gbd = zeros(nclass, d_in), zeros(nclass)
        for x, e, tau in zip(xs, eps, taus):
            a = action_of(x, coord)
            h = matvec(A, x)
            a_tau = add_vec([tau * ai for ai in a], e, 1.0 - tau)
            u = add_vec(a, e, -1.0)
            feat = feat_of(h, a_tau, tau)
            u_hat = add_vec(matvec(We, feat), be)
            err = add_vec(u_hat, u, -1.0)
            # dL/d u_hat = 2 err
            scale = 2.0 / BATCH
            derr = [scale * v for v in err]
            axpy_mat(gWe, outer(derr, feat), 1.0)
            axpy_vec(gbe, derr, 1.0)
            dfeat = [sum(We[k][j] * derr[k] for k in range(ACT)) for j in range(D + ACT + 1)]
            dh_fm = dfeat[:D]
            if arm == "A_naive":
                axpy_mat(gA, outer(dh_fm, x), 1.0)
            if arm == "B_insulate":
                y = token_of(a, bins)
                h_d = h if discrete == "full" else h[SEM:]
                logits = add_vec(matvec(Wd, h_d), bd)
                p = softmax(logits)
                dlog = [scale * (pj - (1.0 if i == y else 0.0)) for i, pj in enumerate(p)]
                axpy_mat(gWd, outer(dlog, h_d), 1.0)
                axpy_vec(gbd, dlog, 1.0)
                dh_part = [sum(Wd[k][j] * dlog[k] for k in range(nclass)) for j in range(len(h_d))]
                dh_ce = dh_part if discrete == "full" else ([0.0] * SEM + dh_part)
                axpy_mat(gA, outer(dh_ce, x), 1.0)
            # C_frozen: no gA, no discrete CE
        if arm != "C_frozen":
            axpy_mat(A, gA, -LR)
        axpy_mat(We, gWe, -LR)
        axpy_vec(be, gbe, -LR)
        if arm == "B_insulate":
            axpy_mat(Wd, gWd, -LR)
            axpy_vec(bd, gbd, -LR)
        if step + 1 == MID:
            mid_snapshot = (copy_mat(A), copy_mat(We), be[:])
    return A, We, be, mid_snapshot


def eval_metrics(A, We, be, draws, steps_euler=1):
    probe_ok = 0
    ctrl_ok = 0
    mse1 = 0.0
    mse4 = 0.0
    fm = 0.0
    n = len(draws["test"])
    for x, a, e, y in draws["test"]:
        h = matvec(A, x)
        if probe_pred(h) == y:
            probe_ok += 1
        a1 = integrate(We, be, h, e, 1)
        a4 = integrate(We, be, h, e, 4)
        se1 = sum((p - q) ** 2 for p, q in zip(a1, a))
        se4 = sum((p - q) ** 2 for p, q in zip(a4, a))
        mse1 += se1
        mse4 += se4
        if math.sqrt(se1) <= TOL:
            ctrl_ok += 1
        # FM residual at a random-path point using the same test ε at τ=0.5
        tau = 0.5
        a_tau = add_vec([tau * ai for ai in a], e, 1.0 - tau)
        u = add_vec(a, e, -1.0)
        u_hat = flow_predict(We, be, h, a_tau, tau)
        fm += sum((p - q) ** 2 for p, q in zip(u_hat, u))
    return {
        "probe_%": 100.0 * probe_ok / n,
        "control_%": 100.0 * ctrl_ok / n,
        "mse_1step": mse1 / n,
        "mse_4step": mse4 / n,
        "fm": fm / n,
    }


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


def fmt_arm(name, rows, keys):

### Read the regimes

How the labels are used on this page: **tie** only when the paired per-seed difference is exactly zero on every seed; **numerically zero (floating-point residue), effectively a tie** when both `|paired mean|` and sd are below `10⁻⁹` (checked before the sd test; such lines carry no sign count and are never called consistent or clear); **near-tie / small gap, within seed noise** when `|paired mean| ≤ sd`; a **consistent** gap when `|paired mean| > sd`, called **small** if `|m|` is under 20 % of the smaller arm mean and **clear** otherwise (the 20 % rule only chooses between those two words). Every consistent or clear line carries a same-sign count over the 5 seeds, any seed with the opposite sign (or an exactly equal seed) is reported, and a sign count alone never makes a gap consistent.
