## From DAgger to recovery + correction

| method | who decides when the human acts | what gets labelled |
| --- | --- | --- |
| DAgger (Ross et al., 2011; 6.1) | the algorithm queries the expert | every state the learner visits |
| HG-DAgger (Kelly et al., 2019) | the human, by taking over | only the frames under human control |
| RaC (Hu et al., 2025) | the human, by taking over | the takeover split into **recovery** then **correction** |

HG-DAgger made DAgger practical with a real human: the expert watches and only takes control when the learner looks unsafe, and only those frames are added to the training set (the paper also learns a "doubt" threshold from the data; its experiments are on driving). RaC adds two rules for long-horizon tasks: when you take over, first teleoperate back to a familiar, in-distribution state (recovery), then demonstrate the right behaviour from there (correction); and end the episode after an intervention rather than handing back. Its abstract reports reaching strong performance on real bimanual tasks with about 10× less data-collection time and samples than prior approaches; that is the paper's measurement, not run on this page.

## What LeRobot records

LeRobot v0.6.0 added `lerobot-rollout` with a `dagger` strategy that "turns deployment into data collection", and its Human-In-the-Loop Data Collection page describes the protocol. Follow the LeRobot v0.6.x docs; options may change between versions (以当期文档为准):

| key | action |
| --- | --- |
| Space | pause the policy / resume it |
| Tab | start / stop a correction (only while paused); corrections are recorded |
| Enter | push the dataset to the Hub (corrections-only mode) |
| ESC | stop the session |

- While paused the robot holds and an actuated leader arm (the SO-101 leader is listed) moves to match the follower, so the handover has no jump; **no frames are recorded during the pause**.
- By default only the human-controlled segments are recorded and **each correction becomes its own episode**. With `--strategy.record_autonomous=true` the autonomous frames are recorded too, as one continuous trajectory split into episodes automatically.
- Every human-controlled frame is tagged in an extra `intervention` column. Datasets can only be merged when their features match, so the docs remove that column before merging with your demonstrations.

## Run the log toy

`intervention_log_toy.py` fakes a full-logging session (`record_autonomous=true` style): 6 episodes of 240 frames at 30 fps. The policy drifts; once the drift `dev` passes 0.6 the operator takes over, drives back until `dev` is at most 0.2 (recovery) and keeps correcting for a while before handing back. That is the LeRobot DAgger flow, where control returns to the policy after each correction and the episode continues; the toy does not simulate RaC's "end the episode after an intervention" rule, it only counts what that rule would keep.
```python
"""intervention_log_toy.py: read a human-in-the-loop log the way a dataset sees it (stdlib).

A seeded stand-in for a DAgger-style rollout recorded with an `intervention`
column. Each frame row is (episode_index, frame_index, intervention, dev),
where dev is how far the arm has drifted from where the demos go.

1. Generate episodes: the policy drifts; when dev crosses TAKE_OVER the
   operator pauses (no frames recorded while paused), takes over with the
   leader arm (intervention=1) and hands back after finishing the fix.
   This is the LeRobot DAgger flow: after a correction, control returns to
   the policy and the episode goes on. It is NOT RaC's rule of ending the
   episode after an intervention; step 4 only counts what that rule keeps.
2. Split each intervention run into segments; intervention rate per episode.
3. Label frames inside a segment, RaC-style: "recovery" while dev is still
   above IN_DIST (getting back to familiar states), "correction" after that.
4. Count what RaC's second rule (end the episode after an intervention)
   would keep.
5. Merge: a demo dataset without `intervention` and the HIL dataset do not
   share a schema; the toy merge refuses, then passes after the column is
   removed. The error text is this toy's, not LeRobot's.
No robot, no LeRobot install.
"""

import random

SEED = 5
FPS = 30
EPISODES = 6
FRAMES_PER_EPISODE = 240
TAKE_OVER = 0.60   # operator presses the key once drift passes this
IN_DIST = 0.20     # below this the state looks like the demos again
RECOVER_STEP = 0.08
CORRECT_FRAMES = (12, 30)

DEMO_FEATURES = ["observation.state", "action", "timestamp", "frame_index", "episode_index", "index", "task_index"]
HIL_FEATURES = DEMO_FEATURES + ["intervention"]


def rollout(rng, ep):
    rows, dev, f = [], 0.05, 0
    while f < FRAMES_PER_EPISODE:
        dev = max(0.0, dev + rng.gauss(0.006, 0.03))
        if dev <= TAKE_OVER:
            rows.append((ep, f, 0, dev))
            f += 1
            continue
        # pause: robot holds, nothing is recorded; then the human drives
        while dev > IN_DIST and f < FRAMES_PER_EPISODE:
            dev = max(0.0, dev - RECOVER_STEP + rng.gauss(0, 0.01))
            rows.append((ep, f, 1, dev))
            f += 1
        for _ in range(rng.randint(*CORRECT_FRAMES)):
            if f >= FRAMES_PER_EPISODE:
                break
            dev = max(0.0, dev * 0.7 + rng.gauss(0, 0.01))
            rows.append((ep, f, 1, dev))
            f += 1
    return rows


def segments(rows):
    segs, start = [], None
    for i, r in enumerate(rows):
        if r[2] and start is None:
            start = i
        if start is not None and (not r[2] or i == len(rows) - 1):
            end = i if r[2] else i - 1
            segs.append(rows[start:end + 1])
            start = None
    return segs


def label(seg):
    """RaC-style split: recovery until dev first drops to IN_DIST, then correction."""
    rec = 0
    for r in seg:
        if r[3] > IN_DIST:
            rec += 1
        else:
            break
    return rec, len(seg) - rec


def timeline(rows, step=4):
    out = []
    in_dist_seen = False
    for r in rows[::step]:
        if not r[2]:
            out.append(".")
            in_dist_seen = False
        else:
            if r[3] <= IN_DIST:
                in_dist_seen = True
            out.append("c" if in_dist_seen else "R")
    return "".join(out)


def merge(a_name, a_feats, b_name, b_feats):
    extra_b = [f for f in b_feats if f not in a_feats]
    extra_a = [f for f in a_feats if f not in b_feats]
    if extra_a or extra_b:
        raise ValueError(f"features differ: only in {b_name}: {extra_b}; only in {a_name}: {extra_a}")
    return a_feats


def main() -> None:
    rng = random.Random(SEED)
    data = [rollout(rng, ep) for ep in range(EPISODES)]
    print(f"seed={SEED}  {EPISODES} episodes x {FRAMES_PER_EPISODE} frames @ {FPS} fps  "
          f"take-over dev>{TAKE_OVER}  in-distribution dev<={IN_DIST}")
    print("keys (lerobot-rollout --strategy.type=dagger, docs main): Space pause/resume policy, "
          "Tab start/stop correction, Enter push to Hub (corrections-only), ESC stop")
    print("timeline ep0 (every 4th frame; . policy, R recovery, c correction):")
    print("  " + timeline(data[0]))

    print(f"{'ep':>2} {'frames':>6} {'interv':>6} {'rate':>6} {'segs':>4} {'recov':>5} {'corr':>5} {'keep_rule2':>10}")
    tot = tot_i = tot_s = tot_r = tot_c = tot_keep = 0
    seg_lens = []
    for ep, rows in enumerate(data):
        segs = segments(rows)
        n_i = sum(r[2] for r in rows)
        rec = sum(label(s)[0] for s in segs)
        cor = sum(label(s)[1] for s in segs)
        keep = (rows.index(segs[0][-1]) + 1) if segs else len(rows)
        seg_lens += [len(s) for s in segs]
        print(f"{ep:>2} {len(rows):>6} {n_i:>6} {n_i / len(rows):>6.1%} {len(segs):>4} {rec:>5} {cor:>5} {keep:>10}")
        tot, tot_i, tot_s, tot_r, tot_c, tot_keep = (tot + len(rows), tot_i + n_i, tot_s + len(segs),
                                                     tot_r + rec, tot_c + cor, tot_keep + keep)
    print(f"all {tot:>6} {tot_i:>6} {tot_i / tot:>6.1%} {tot_s:>4} {tot_r:>5} {tot_c:>5} {tot_keep:>10}")
    mean_len = sum(seg_lens) / len(seg_lens)
    print(f"segments: {tot_s}  mean length {mean_len:.1f} frames = {mean_len / FPS:.2f} s  "
          f"shortest {min(seg_lens)}  longest {max(seg_lens)}")
    print(f"recovery share of intervention frames: {tot_r / tot_i:.1%}")
    print(f"corrections-only recording would save {tot_s} episodes with {tot_i} frames; "
          f"full logging keeps {tot} frames incl. autonomous context")
    print(f"RaC rule 2 (end after the first intervention) keeps {tot_keep} of {tot} frames")

    try:
        merge("demos", DEMO_FEATURES, "hil", HIL_FEATURES)
    except ValueError as e:
        print(f"merge demos + hil: ERROR {e}")
    stripped = [f for f in HIL_FEATURES if f != "intervention"]
    merge("demos", DEMO_FEATURES, "hil_stripped", stripped)
    print(f"after remove_feature('intervention'): merge ok, {len(stripped)} features")


if __name__ == "__main__":
    main()
```

## Common mistakes

- **Merging before removing `intervention`.** The merge needs matching features; strip the column on a copy, keep the original.
- **Only logging corrections and then reporting a rate.** In corrections-only mode there are no autonomous frames, so the rate is undefined; use `record_autonomous=true` when you want the metric.
- **Taking over late.** Long recovery segments teach recovery from far-off states and little about the task; take over when failure is imminent.
- **Jerky handovers.** Use an actuated leader that follows the follower while paused; jumps end up in the training data.

## Stage memory prompts: MAP-VLA

The logs above hold more than a rate. Each correction is a short, labelled piece of "how an expert finished this stage". A frozen VLA never looks at them again once training ends: at run time it sees only the current observation. **MAP-VLA** (Memory-Augmented Prompting for VLA) turns stage-segmented demonstrations into a **memory library of soft prompts**, retrieves the right one by **trajectory similarity** while the robot runs, and **ensembles** the memory-prompted action chunk with the ordinary one. The VLA weights do not change. This section is **not** MemoryVLA's perceptual memory bank or a WorldVLA attention mask (both in [world models](/en/month/month-9/world-models-overview)), **not** X-VLA's per-embodiment soft prompts ([cross-embodiment datasets](/en/month/month-11/cross-embodiment-datasets)) and **not** MTC stage prefixes: here the memory is indexed by **task stage** and chosen by where the arm has just been.

<Resource id="mapvla-pdf" />

**Sources actually opened (body read).** **MAP-VLA (Runhao Li et al., arXiv 2511.09516, HTML and PDF via pdftotext).** The method runs on a π0 policy, fine-tuned with LoRA and then frozen. *Memory Prompt Construction:* key poses of one reference demonstration are found with the Ramer–Douglas–Peucker algorithm, stage boundaries sit at the midpoints between key poses, and every other demonstration is aligned to the reference with dynamic time warping, giving K stage-aligned segments. Each stage k gets a learnable soft prompt `V_k` that is **added element-wise** to the base prompt tokens, `P_k = P_base + V_k` (Eq. 2), and only `V_k` is optimised with the flow-matching loss on that stage's frames (Eq. 3). The library also stores the demonstration trajectories and action sequences. *Memory-Augmented Action Generation:* the last W robot states are compared with every W-long window of every demonstration by an L2 cost (Eq. 4), restricted to windows whose stage label is within 1 of the current stage (`|k − k_cur| ≤ 1`), and the arg-min (Eq. 5) updates the current stage, picks `V_k` and supplies a reference action chunk from that demonstration. The frozen model runs twice (base prompt and memory prompt) and the two chunks are mixed with `α_t` = the softmax of their negative squared distances to the reference chunk (Eq. 6), `A = α A_mem + (1 − α) A_base` (Eq. 7). Reported results: LIBERO-Long 83.4 % against 76.4 % for π0 (+7.0 points), real-robot complete success 48.3 % against 23.3 % (+25.0 points) on a Galaxea A1 arm, the ablation 81.4 % for stage prompts without ensembling, and 21.6 ms average retrieval with about 37.8 demonstrations per task — all **以论文为准**; π0 weights, LIBERO and the robot: **本页未运行**.

### What the memory is and why logs feed it

A memory unit is a pair: a stage prompt and the demonstrations that taught it. The prompt is tiny compared with the model, so a library of K prompts per task is cheap; the retrieval cost grows with the number of demonstrations of that task, not with the number of tasks. The intervention logs of this lesson are a natural source: a correction already starts and ends at a stage boundary, and its frames carry the robot state that retrieval matches against.

<Formula label="Memory-aware prompt ensembling (MAP-VLA Eq. 6–7)">α = exp(−‖A_mem − A_ref‖²) / (exp(−‖A_mem − A_ref‖²) + exp(−‖A_base − A_ref‖²)),  A = α·A_mem + (1 − α)·A_base</Formula>

**Worked example.** Suppose the memory chunk is 0.1 (squared distance) from the reference and the base chunk is 0.9. Then `α = e^−0.1 / (e^−0.1 + e^−0.9) = 1 / (1 + e^−0.8) = 0.690`, so the executed chunk is 69 % memory and 31 % base. If retrieval went wrong and the reference disagrees with the memory chunk (2.0 against 0.5), `α = 1 / (1 + e^1.5) = 0.182` and the base dominates — but only if the reference itself came from the right stage. When the prompt and the reference are **both** from the wrong stage, they agree with each other and the ensemble cannot catch it.

### Fair setup

`map_vla_memory_prompt_toy.py` is **synthetic** and stdlib only. **Model assumptions:** a 2D point stands in for the end effector and must visit K stage goals in order (step ≤ 0.25, goal reached within 0.15, 14 steps per stage, otherwise the episode stops); the observation is the noisy state plus a 4-dim noisy one-hot "scene look"; in the ambiguous regimes stages 1 and 3 (and 2 and 4) share one look, the way a camera can see the same scene at two points of a long task. The **frozen VLA** is a single linear map `W` from `[state, look, 1]` to the action, fit by least squares on 8 logged demonstrations per seed. A stage soft prompt `V_k` is added to the prompt features, so its effect is `W V_k`; **prompt tuning** is the least-squares fit of that effect on stage-k frames, which for a constant offset is the mean residual of the frozen `W` there. Stage labels in the demos are given (the paper's RDP + DTW step is **not** simulated). Retrieval and ensembling follow Eq. 4–7 with a 4-state window and a 4-step chunk. It is a **stand-in**, not π0 and not prompt tuning through a transformer.

| Arm | What it does |
|---|---|
| A_memoryless | base prompt only: the current observation, no memory |
| B_map | retrieve stage and reference (stage within 1 of the current estimate), add that stage's prompt, ensemble with the base chunk |
| C_wrongstage | same retrieval, but the prompt **and** reference come from the neighbouring stage (a mismatched memory, e.g. a segmentation off by one), ensemble as in B |

**Common random numbers:** for each regime and seed the demos and the frozen `W` are shared, and for each episode the start, observation noise, look noise and motion noise are drawn once, indexed by step, and read by every arm. Five seeds × 20 episodes. Metrics per seed: `stage` = share of stages completed, `full` = share of episodes that finish every stage, `steps` = environment steps used (an episode stops at the first stage that runs out of budget, so **fewer steps can mean earlier failure**), `hit` = share of retrievals whose stage is the true stage (A retrieves nothing). Prompt size, chunk length and step budget are the same for every arm.

```python
#!/usr/bin/env python3
"""MAP-VLA stand-in: stage memory soft prompts, trajectory retrieval and prompt ensembling. Stdlib only.

Model assumptions (also stated in the lesson prose):
  a 2D point "end effector" must visit K stage goals in order (step <= 0.25, goal reached within
  0.15, 14 steps per stage, else the episode stops). The observation is the noisy state plus a
  4-dim noisy one-hot "scene look"; in ambiguous regimes two stages share one look, like the same
  camera view at different points of a long task. The "frozen VLA" is one linear map W from
  [state, look, 1] to the action, fit by least squares on 8 logged demonstrations (corrections) per
  seed and never changed afterwards. A stage "soft prompt" V_k is added to the prompt features, so
  its effect on the action is W V_k; prompt tuning is the least-squares fit of that effect on the
  stage-k frames (the mean residual of the frozen W there). Stage labels in the demos are known
  (the paper finds them with RDP key poses + DTW; that step is not simulated).
  Retrieval: the last 4 observed states are compared with every 4-state demo window whose stage is
  within 1 of the current stage estimate (L2 cost, paper Eq. 4-5); the best window gives the stage
  and a 4-step reference action chunk. Ensembling (Eq. 6-7): alpha = softmax weight of the memory
  chunk against the base chunk by squared distance to the reference chunk.

Arms (Common random numbers: per (regime, seed) the same demos and frozen W; per episode the same
start, observation noise, look noise and motion noise, indexed by step):
  A_memoryless  base prompt only: the current observation, no memory
  B_map         retrieve stage + reference, add that stage's prompt, ensemble with the base chunk
  C_wrongstage  same retrieval, but the prompt AND reference come from the neighbouring stage
                (a mismatched memory, e.g. a segmentation off by one); ensemble as in B

Metrics per seed (means over 20 episodes): stage = share of stages completed, full = share of
episodes that complete every stage, steps = environment steps used (an episode stops at the first
stage that runs out of budget), hit = share of retrievals whose stage equals the true stage.

Labels: tie = identical on every seed; |m| < 1e-9 and sd < 1e-9 = numerically zero
(floating-point residue), effectively a tie, no sign count; |paired mean| <= sd = near-tie / small
gap within seed noise; |m| > sd = consistent gap (small if |m| < 20 % of the smaller arm mean, else
clear), always with a sign count.
pi0 weights / LIBERO / real robot / GPU: 本页未运行. Paper numbers: 以论文为准.
"""
from __future__ import annotations

import math
import random

SEEDS = (0, 1, 2, 3, 4)
STEP, TOL, BUDGET = 0.25, 0.15, 14
WIN, H = 4, 4
N_DEMO, EPISODES = 8, 20
LOOKS = 4
SIG_DEMO, SIG_MOTION = 0.03, 0.01
ARMS = ("A_memoryless", "B_map", "C_wrongstage")
METRICS = ("stage", "full", "steps")
SQUARE = ((1.0, 0.0), (1.0, 1.0), (0.0, 1.0), (0.0, 0.0))
# name, stage goals, stage -> look, state noise sd, look noise sd
REGIMES = (
    ("ambiguous_long", SQUARE, (0, 1, 0, 1), 0.02, 0.1),
    ("distinct_long", SQUARE, (0, 1, 2, 3), 0.02, 0.1),
    ("single_stage", ((1.0, 0.0),), (0,), 0.02, 0.1),
    ("noisy_retrieval", SQUARE, (0, 1, 0, 1), 0.12, 0.1),
)


def clip(v, m=STEP):
    n = math.hypot(*v)
    return v if n <= m else (v[0] * m / n, v[1] * m / n)


def solve(a, b):
    n = len(a)
    m = [row[:] + [b[i]] for i, row in enumerate(a)]
    for i in range(n):
        p = max(range(i, n), key=lambda r: abs(m[r][i]))
        m[i], m[p] = m[p], m[i]
        for r in range(n):
            if r != i:
                q = m[r][i] / m[i][i]
                for c in range(i, n + 1):
                    m[r][c] -= q * m[i][c]
    return [m[i][n] / m[i][i] for i in range(n)]


def look(noise, stage, lookmap, sd):
    return [(1.0 if i == lookmap[stage] else 0.0) + sd * noise[i] for i in range(LOOKS)]


def feats(s, c):
    return [s[0], s[1], *c, 1.0]


def demos(regime, seed):
    """Logged demonstrations / corrections with stage labels; shared by all arms."""
    name, goals, lookmap, _, sd_c = regime
    rng = random.Random(100000 * [r[0] for r in REGIMES].index(name) + 1000 * seed)
    out = []
    for _ in range(N_DEMO):
        s, traj = (rng.gauss(0, 0.05), rng.gauss(0, 0.05)), []
        for k, g in enumerate(goals):
            n = 0
            while math.dist(s, g) > TOL / 2 and n < BUDGET:
                c = look([rng.gauss(0, 1) for _ in range(LOOKS)], k, lookmap, sd_c)
                a = clip((g[0] - s[0], g[1] - s[1]))
                a = (a[0] + rng.gauss(0, SIG_DEMO), a[1] + rng.gauss(0, SIG_DEMO))
                traj.append((s, c, a, k))
                s, n = (s[0] + a[0], s[1] + a[1]), n + 1
        out.append(traj)
    return out


def fit_base(demo):
    d = 2 + LOOKS + 1
    a = [[1e-6 if i == j else 0.0 for j in range(d)] for i in range(d)]
    b = [[0.0] * d for _ in range(2)]
    for traj in demo:
        for s, c, act, _ in traj:
            x = feats(s, c)
            for i in range(d):
                for j in range(d):
                    a[i][j] += x[i] * x[j]
                for o in range(2):
                    b[o][i] += x[i] * act[o]
    return [solve(a, b[o]) for o in range(2)]


def policy(w, s, c, prompt=(0.0, 0.0)):
    x = feats(s, c)
    return clip((sum(p * q for p, q in zip(w[0], x)) + prompt[0], sum(p * q for p, q in zip(w[1], x)) + prompt[1]))


def tune_prompts(w, demo, n_stages):
    """Least-squares effect W V_k of each stage soft prompt on the frozen W: mean residual on stage k."""
    out = []
    for k in range(n_stages):
        r, n = [0.0, 0.0], 0
        for traj in demo:
            for s, c, act, kk in traj:
                if kk == k:
                    p = policy(w, s, c)
                    r[0] += act[0] - p[0]
                    r[1] += act[1] - p[1]
                    n += 1
        out.append((r[0] / n, r[1] / n))
    return out


def chunk(w, s, c, prompt):
    out, x = [], s
    for _ in range(H):
        a = policy(w, x, c, prompt)
        out.append(a)
        x = (x[0] + a[0], x[1] + a[1])
    return out


def retrieve(demo, hist, ok):
    """Sliding-window L2 match over demo windows whose stage passes ok(stage)."""
    best = None
    for i, traj in enumerate(demo):
        for j in range(WIN - 1, len(traj)):
            if not ok(traj[j][3]):
                continue
            cost = sum(math.dist(hist[q], traj[j - WIN + 1 + q][0]) ** 2 for q in range(WIN))
            if best is None or cost < best[0]:
                best = (cost, i, j)
    _, i, j = best
    traj = demo[i]
    return traj[j][3], [traj[min(j + h, len(traj) - 1)][2] for h in range(H)]


def episode_draws(regime, seed, ep):
    rng = random.Random(100000 * [r[0] for r in REGIMES].index(regime[0]) + 1000 * seed + 500 + ep)
    n = BUDGET * len(regime[1]) + 1
    return {"s0": (rng.gauss(0, 0.05), rng.gauss(0, 0.05)),
            "obs": [(rng.gauss(0, 1), rng.gauss(0, 1)) for _ in range(n)],
            "look": [[rng.gauss(0, 1) for _ in range(LOOKS)] for _ in range(n)],
            "motion": [(rng.gauss(0, 1), rng.gauss(0, 1)) for _ in range(n)]}


def run_episode(arm, regime, w, prompts, demo, nz):
    _, goals, lookmap, sd_s, sd_c = regime
    n_st = len(goals)
    s = nz["s0"]
    hist, k_cur, done, hits, queries, t = [s] * WIN, 0, 0, 0, 0, 0
    for k, g in enumerate(goals):
        n = 0
        while math.dist(s, g) > TOL:
            if n >= BUDGET:
                return {"stage": done / n_st, "full": 0.0, "steps": float(t)}, hits, queries
            e = nz["obs"][t]
            so = (s[0] + sd_s * e[0], s[1] + sd_s * e[1])
            c = look(nz["look"][t], k, lookmap, sd_c)
            hist = hist[1:] + [so]
            if arm == "A_memoryless":
                a = policy(w, so, c)
            else:
                k_ret, ref = retrieve(demo, hist, lambda kk: abs(kk - k_cur) <= 1)
                k_cur, queries, hits = k_ret, queries + 1, hits + (k_ret == k)
                k_use = k_ret
                if arm == "C_wrongstage":
                    k_use = k_ret + 1 if k_ret + 1 < n_st else k_ret - 1
                    _, ref = retrieve(demo, hist, lambda kk: kk == k_use)
                mem, base = chunk(w, so, c, prompts[k_use]), chunk(w, so, c, (0.0, 0.0))
                dm = sum((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2 for p, q in zip(mem, ref))
                db = sum((p[0] - q[0]) ** 2 + (p[1] - q[1]) ** 2 for p, q in zip(base, ref))
                alpha = 1.0 / (1.0 + math.exp(dm - db))
                a = clip((alpha * mem[0][0] + (1 - alpha) * base[0][0], alpha * mem[0][1] + (1 - alpha) * base[0][1]))
            m = nz["motion"][t]
            s = (s[0] + a[0] + SIG_MOTION * m[0], s[1] + a[1] + SIG_MOTION * m[1])
            n, t = n + 1, t + 1
        done += 1
    return {"stage": 1.0, "full": 1.0, "steps": float(t)}, hits, queries


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x: float) -> str:
    if x != 0.0 and abs(x) < 5e-4:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


NUM_ZERO = 1e-9  # |m| and sd both below this: floating-point residue, not a gap


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(mean_sd(xa)[0], mean_sd(xb)[0]):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def main() -> None:
    print("Synthetic staged reaching task; shared demos / frozen base / episode noise; stand-in for a frozen VLA, not pi0")
    print(f"seeds={len(SEEDS)} demos={N_DEMO} episodes={EPISODES} window={WIN} chunk={H} step<={STEP} tol={TOL} "
          f"budget={BUDGET}/stage")
    print("regime arm stage full steps hit  (mean+-sd over seeds of the per-seed episode means)")
    for regime in REGIMES:
        name, goals, lookmap, sd_s, sd_c = regime
        arms = ARMS if len(goals) > 1 else ARMS[:2]
        per = {arm: {m: [] for m in METRICS + ("hit",)} for arm in arms}
        for seed in SEEDS:
            demo = demos(regime, seed)
            w = fit_base(demo)
            prompts = tune_prompts(w, demo, len(goals))
            for arm in arms:
                acc, hits, queries = {m: 0.0 for m in METRICS}, 0, 0
                for ep in range(EPISODES):
                    out, h, q = run_episode(arm, regime, w, prompts, demo, episode_draws(regime, seed, ep))
                    hits, queries = hits + h, queries + q
                    for m in METRICS:
                        acc[m] += out[m] / EPISODES
                for m in METRICS:
                    per[arm][m].append(acc[m])
                per[arm]["hit"].append(hits / queries if queries else 0.0)
        print(f"{name} ({len(goals)} stage{'s' if len(goals) > 1 else ''}, looks {list(lookmap)}, state noise sd={sd_s}, look noise sd={sd_c})")
        for arm in arms:
            hit = "-" if arm == "A_memoryless" else "{}+-{}".format(*map(num, mean_sd(per[arm]["hit"])))
            print(f"{name} {arm} " + " ".join("{}+-{}".format(*map(num, mean_sd(per[arm][m]))) for m in METRICS)
                  + f" {hit}")
        pairs = (("B_map", "A_memoryless"), ("C_wrongstage", "B_map")) if len(arms) == 3 else (("B_map", "A_memoryless"),)
        for a, b in pairs:
            for m in METRICS:
                print(f"{name} paired {a[0]}-{b[0]} {m}: {verdict(per[a][m], per[b][m])}")
        if len(arms) == 2:
            print(f"{name}: C_wrongstage not run (one stage, no neighbouring stage to mismatch)")
    print("ambiguous_long: stages 1 and 3 (and 2 and 4) share one look, so the memoryless base cannot tell them apart")
    print("distinct_long: the look already names the stage, so memory adds little and the gap stays within seed noise")
    print("single_stage: one stage, one prompt; retrieval cannot pick anything else")
    print("noisy_retrieval: state noise lowers B's retrieval hit rate and shrinks its gain over A")
    print("C_wrongstage: a neighbouring stage's prompt and reference pull the arm to the wrong goal; fewer steps there mean earlier failure")
    print("No winner declared; MAP-VLA LIBERO / real-robot gains 以论文为准; pi0 weights / GPU 本页未运行")

    main()
```

### Read the regimes

How the labels are used on this page: **tie** only when the paired per-seed difference is exactly zero on every seed; **numerically zero (floating-point residue), effectively a tie** when both `|paired mean|` and sd are below `10⁻⁹` (checked before the sd test; such lines carry no sign count and are never called consistent or clear); **near-tie / small gap, within seed noise** when `|paired mean| ≤ sd`; a **consistent** gap when `|paired mean| > sd`, called **small** if `|m|` is under 20 % of the smaller arm mean and **clear** otherwise (the 20 % rule only chooses between those two words). Every consistent or clear line carries a same-sign count over the 5 seeds, any seed with the opposite sign (or an exactly equal seed) is reported, and a sign count alone never makes a gap consistent. Paired differences are B−A and C−B, shown as mean ± sd over seeds.

- **ambiguous_long — memory wins where the observation cannot name the stage:** `stage` 0.7000±0.0331 against 0.3500±0.1222 (**clear gap**, paired 0.3500±0.1075, same sign on all 5 seeds) and `full` 0.4000±0.1696 against 0.0200±0.0274 (clear, 0.3800±0.1525, 5/5). B's retrievals name the true stage 0.7403 of the time. `steps` is a **near-tie** (0.3500±2.2201, 2 of 5 seeds opposite): B is not faster, it gets further.
- **distinct_long — memory adds nothing measurable:** when every stage has its own look, the frozen base already knows the stage; B−A `stage` 0.0200±0.0456, `full` 0.0200±0.0908 and `steps` −0.2200±0.6150 are all **near-ties / small gaps, within seed noise** (for `stage` 1 of 5 seeds has the opposite sign and 1 of 5 is equal).
- **single_stage — a tie on success:** one stage, one prompt, so B−A `stage` and `full` are a **tie: identical on every seed** (every episode succeeds for both); `steps` −0.0300±0.0447 is a near-tie (no seed has the opposite sign, 3 of 5 equal). - **noisy_retrieval — the gain shrinks with retrieval quality:** with state noise sd 0.12, B's hit rate drops from 0.7403 to 0.6391 and its `stage` gain over A falls to 0.1375±0.0395 (still clear, 5/5); `full` 0.2000±0.1458 is clear but **1 of 5 seeds has the opposite sign**.
