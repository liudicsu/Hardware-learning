Month 5 MoveIt pick-place plans a **whole trajectory once**, then plays it. <Term id="moveit-servo">MoveIt Servo</Term> uses a different cadence: **every control cycle** it consumes one velocity/pose command and emits the next joint command. That fits jogging, teleop, and closed-loop “steer while you go.”

## Whole trajectory vs per-cycle commands

| | Month 5 planning | MoveIt Servo |
| --- | --- | --- |
| Input | Start/goal → one joint trajectory | One `JointJog` / `Twist` / `Pose` every cycle |
| Timing | Offline (or occasional replan) | Online, at the servo rate |
| Safety hooks | Collision check at plan time | **Per-cycle** singularity / collision / smoothing |

Three command types (C++ API → common ROS messages):

- `JointJogCommand` → `control_msgs/JointJog` (joint-velocity jog)
- `TwistCommand` → `geometry_msgs/TwistStamped` (EE linear/angular velocity)
- `PoseCommand` → `geometry_msgs/PoseStamped` (EE pose tracking)

Loop shape: `servo.setCommandType(...)`, then repeatedly `getNextJointState(command)`; `getStatus()` reports singularity/collision slowdowns.

## Safety: singularity, collision, smoothing

The docs list **singularity checks, collision checks, motion smoothing, joint limits**. Parameters you will see:

- `check_collisions` — run collision checks inside the servo loop
- `use_smoothing` — enable a smoothing plugin
- `smoothing_filter_plugin_name` — e.g. **Butterworth**, **AccelerationLimited**, **Ruckig**
- `command_out_type` — emit `trajectory_msgs/JointTrajectory` or `std_msgs/Float64MultiArray`

With a realtime kernel, the `ServoNode` main thread tries **SCHED_FIFO** priority **40** (this lesson’s toy does not need a realtime kernel).

## CPU: scale Cartesian speed near a singularity

Planar 2-link RR arm: θ₁ fixed, θ₂ sweeps from a bend toward a stretch singularity. Each step computes Jacobian condition number κ; when κ > `KAPPA_THRESH` (**12.0** here), multiply the EE speed norm by `KAPPA_THRESH / κ`. The table contrasts **unscaled** vs **scaled**.

```python
#!/usr/bin/env python3
"""servo_loop_sim.py: scale Cartesian speed near singularity (stdlib).

Discrete-time toy of a MoveIt Servo-style loop: each control cycle consumes a
Cartesian twist. When the planar 2-link Jacobian condition number κ exceeds
KAPPA_THRESH, scale the twist so the end-effector speed norm drops
(unscaled vs scaled table).

Pinned constants keep expected/ stable. No ROS / MoveIt runtime.
usage: python3 servo_loop_sim.py
"""
from __future__ import annotations

import math

L1 = 0.30  # m
L2 = 0.25  # m
THETA1 = 0.40  # rad, fixed
# Sweep θ2 from a comfortable bend toward a stretch singularity (θ2 → 0).
THETA2_START = 1.20
THETA2_END = 0.05
N_STEPS = 8
V_CMD = (0.10, 0.00)  # m/s desired Cartesian twist (vx, vy)
KAPPA_THRESH = 12.0  # condition-number threshold → start scaling
EPS = 1e-12


def jacobian(theta1: float, theta2: float) -> list[list[float]]:
    """2×2 planar RR geometric Jacobian mapping dq → [vx, vy]."""
    s1 = math.sin(theta1)
    c1 = math.cos(theta1)
    s12 = math.sin(theta1 + theta2)
    c12 = math.cos(theta1 + theta2)
    return [
        [-L1 * s1 - L2 * s12, -L2 * s12],
        [L1 * c1 + L2 * c12, L2 * c12],
    ]


def condition_number(J: list[list[float]]) -> float:
    """κ = σ_max / σ_min via eigenvalues of JᵀJ (2×2)."""
    a, b = J[0][0], J[0][1]
    c, d = J[1][0], J[1][1]
    g00 = a * a + c * c
    g01 = a * b + c * d
    g11 = b * b + d * d
    tr = g00 + g11
    det = g00 * g11 - g01 * g01
    disc = max(0.0, tr * tr - 4.0 * det)
    root = math.sqrt(disc)
    lam1 = 0.5 * (tr + root)
    lam2 = 0.5 * (tr - root)
    sig1 = math.sqrt(max(lam1, 0.0))
    sig2 = math.sqrt(max(lam2, 0.0))
    sig_max = max(sig1, sig2)
    sig_min = min(sig1, sig2)
    if sig_min < EPS:
        return float("inf")
    return sig_max / sig_min


def speed_norm(vx: float, vy: float) -> float:
    return math.hypot(vx, vy)


def main() -> None:
    vx0, vy0 = V_CMD
    v_des = speed_norm(vx0, vy0)
    print(
        f"L1={L1:.2f} L2={L2:.2f} theta1={THETA1:.2f} "
        f"theta2=[{THETA2_START:.2f}..{THETA2_END:.2f}] steps={N_STEPS} "
        f"v_cmd=({vx0:.2f},{vy0:.2f}) kappa_thresh={KAPPA_THRESH:.1f}"
    )
    print(
        f"{'step':>4} {'theta2':>8} {'kappa':>10} "
        f"{'v_unscaled':>12} {'scale':>8} {'v_scaled':>10}"
    )
    scaled_rows = 0
    for i in range(N_STEPS):
        t = i / (N_STEPS - 1)
        theta2 = THETA2_START + t * (THETA2_END - THETA2_START)
        kappa = condition_number(jacobian(THETA1, theta2))
        if kappa == float("inf"):
            scale = 0.0
            kappa_s = f"{'inf':>10}"
        elif kappa > KAPPA_THRESH:
            scale = KAPPA_THRESH / kappa
            kappa_s = f"{kappa:10.4f}"
        else:
            scale = 1.0
            kappa_s = f"{kappa:10.4f}"
        if scale < 0.0:
            scale = 0.0
        if scale > 1.0:
            scale = 1.0
        v_un = v_des
        v_sc = v_des * scale
        if scale < 1.0:
            scaled_rows += 1
        print(
            f"{i:4d} {theta2:8.4f} {kappa_s} "
            f"{v_un:12.4f} {scale:8.4f} {v_sc:10.4f}"
        )
    print(
        f"ok: scaled_rows={scaled_rows} "
        f"(near singularity v_scaled < v_unscaled)"
    )


if __name__ == "__main__":
    main()
```

## Common mistakes

- **Treating Servo as “plan another trajectory.”** It is per-cycle velocity/pose commands.
- **Disabling singularity/collision checks only to feel snappier.** Read the slowdown first, then tune.
- **Expecting SCHED_FIFO 40 on a non-realtime kernel.** The docs say the node *tries* that when a realtime kernel is present.

### A far wall, an in-band approach and an over-conservative threshold

**Worked example (hand_calc).** The stand-in uses a declared toy step `DT = 0.0100` s and a commanded speed `V_CMD = 0.0500` m/s, not a vendor-universal default. A 100-step jog therefore commands `hand_calc far commanded travel = V_CMD * FAR_HORIZON_STEPS * DT = 0.0500 * 100 * 0.0100 = 0.0500` m. In `far_scene` the start clearance is `1.0000` m, so an unscaled jog ends at `0.9500` m, still above the scene threshold `0.0200` m. In `in_band_scene` the start clearance is `0.0300` m, so the same unscaled travel would cross the wall by `0.0200` m. In `in_band_self` the start clearance is `0.0150` m, and the unscaled travel would cross the envelope by `0.0350` m. Once inside a band, the linear scale updates clearance by the factor `1 - V_CMD*DT/threshold`, which is `0.9750` for `0.0200` m and `0.9500` for `0.0100` m. Arm C uses a declared over-conservative `C_THRESHOLD = 2.0000` m, which is **not** a demo-config value.

**Correctness criterion for the counts.** `progress` is metres travelled along the command. A `collision_steps` count increments on every step whose clearance is `<= 0`. `min_clearance` is the smallest clearance (negative if the jog penetrated). `max_penetration` is the largest depth past contact, or 0 if there was no contact. `terminal_speed` is the scaled speed on the last step. The scale is 1 when clearance is at least the threshold, falls linearly as `clearance / threshold` down to 0 at contact, and is 0 past contact.

**No live collision checker here.** The stand-in is a planar 1-D clearance with an Euler step; it does not run a Planning Scene, and `collision_check_rate = 10.0000` is printed as an opened demo-config constant, not used as the toy's step rate.

### Fair setup

`servo_collision_proximity_toy.py` is **synthetic** and stdlib only, a planar stand-in, **not** MoveIt or FCL. **Model assumptions:**

- A shared commanded jog toward a fixed obstacle (scene wall or self-collision envelope). Clearance starts at a declared value and decreases by `scale * V_CMD * DT` each step, with the scale taken from the clearance at the start of the step.
- Arm A has `check_collisions` off and never scales. Arm B has `check_collisions` on and uses the opened `0.0200` m scene constant or the opened `0.0100` m self constant, as the regime requires. Arm C has `check_collisions` on but uses the huge declared `C_THRESHOLD`.

**Common random numbers:** the command timeline and obstacle poses are deterministic and shared across arms. Five seeds `0,1,2,3,4` repeat the same timeline so the exact-tie cells can be printed as identical on every seed. Seeds do not add jitter.

| Regime | Obstacle | Expected (written before the first run) |
|---|---|---|
| far_scene | starts `1.0000` m away, stays beyond `0.0200` m | A and B may exact-tie or near-tie on progress (keep); C over-conservative loses on progress (keep) |
| in_band_scene | starts `0.0300` m away, enters the `0.0200` m scene band | B consistent lower collision / penetration counts (keep); A (no scale) loses on collisions (keep) |
| in_band_self | starts `0.0150` m away, enters the `0.0100` m self envelope | B consistent lower collision / penetration counts (keep); A (no scale) loses on collisions (keep) |

Labels: identical on every seed is a **tie**; numerically zero if the absolute paired mean and sd are both below `1e-9`; `|m| <= sd` is a **near-tie**; `|m| > sd` is a consistent gap, **small** if `|m|` is below 20 % of the smaller-arm mean (the toy prints `0.2000`), else **clear**, with a sign count.

**Choices made after seeing results.** None. The three arms, the three regimes, the thresholds and the command were written down before the first run and not changed. Alternatives not taken: a quadratic scale `(clearance / threshold)^2` between the threshold and contact. That alternative is printed on the same timeline and was **not adopted**.

```python
#!/usr/bin/env python3
"""MoveIt Servo collision-proximity scale stand-in.

A planar 1-D jog toward a fixed obstacle compares (A) check_collisions
off with no scale, (B) a linear proximity scale that is 1 at the opened
demo-config threshold and 0 at contact, and (C) an over-conservative
huge threshold.  Synthetic; not live MoveIt, FCL, or a real arm.

The opened panda_simulated_config.yaml distances
self_collision_proximity_threshold = 0.01 m and
scene_collision_proximity_threshold = 0.02 m are demo-config constants,
以文档为准, not vendor-universal defaults and not toy measurements.
check_collisions and collision_check_rate are printed as the same opened
constants.  The stand-in applies the scale every DT seconds; it does not
run a Planning Scene or honour the check rate as a live servo loop.

Common random numbers: the command timeline and obstacle poses are
deterministic and shared across arms.  Five seeds repeat the same
timeline so exact-tie cells can be printed as identical on every seed.
Seeds do not add jitter.

Metrics per seed: progress (metres travelled along the command),
collision_steps (steps with clearance <= 0), min_clearance (metres),
terminal_speed (m/s), max_penetration (metres, 0 if no contact).

Regimes and expectations, written before the first run:
  far_scene        obstacle stays beyond the 0.02 m scene band for the
                   whole jog: A and B may exact-tie or near-tie on
                   progress (keep); C over-conservative loses on
                   progress (keep)
  in_band_scene    a straight jog enters the 0.02 m scene band: B
                   consistent lower collision / penetration counts
                   (keep); A (no scale) loses on collisions (keep)
  in_band_self     a straight jog enters the 0.01 m self-collision
                   envelope: same B-vs-A collision reduction (keep)

Named alternative, same timeline, not adopted: a quadratic scale
(clearance / threshold)^2 between the threshold and contact.

Tutorial wording 以文档为准.  MoveIt / FCL / official keyboard demo:
本页未运行.
"""
from __future__ import annotations

import math
from decimal import ROUND_HALF_UP, Decimal, getcontext

getcontext().rounding = ROUND_HALF_UP

SEEDS = (0, 1, 2, 3, 4)
NUM_ZERO = 1e-9
SMALL_FRAC = 0.2000  # 20 % of the smaller-arm mean; printed as 0.2000

# Opened panda_simulated_config.yaml demo-config constants (metres, Hz).
SELF_COLLISION_PROXIMITY_THRESHOLD = 0.01
SCENE_COLLISION_PROXIMITY_THRESHOLD = 0.02
CHECK_COLLISIONS_DEMO = True
COLLISION_CHECK_RATE = 10.0

# Declared toy step and command (not vendor-universal defaults).
DT = 0.01
V_CMD = 0.05
# Over-conservative lose-arm threshold (metres), declared, not from the yaml.
C_THRESHOLD = 2.0000

# far_scene: start 1.00 m from the wall, travel 0.05 m (1.0 s), end 0.95 m.
FAR_START_CLEARANCE = 1.0000
FAR_HORIZON_STEPS = 100
# in_band_scene: start 0.030 m from the wall, 1.0 s would travel 0.05 m.
SCENE_START_CLEARANCE = 0.0300
SCENE_HORIZON_STEPS = 100
# in_band_self: start 0.015 m from a self envelope, 1.0 s would travel 0.05 m.
SELF_START_CLEARANCE = 0.0150
SELF_HORIZON_STEPS = 100

ARMS = ("A", "B", "C")
METRICS = ("progress", "collision_steps", "min_clearance", "terminal_speed", "max_penetration")


def mean_sd(xs):
    if all(x == xs[0] for x in xs):
        return xs[0], 0.0
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-4:
        return format(Decimal(repr(x)), ".3e")
    s = format(Decimal(repr(x)), ".4f")
    return "0.0000" if s == "-0.0000" else s


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def fmt_pair(m, s):
    return f"{num(m)}+-{num(s)}"


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{fmt_pair(m, s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < SMALL_FRAC * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{fmt_pair(m, s)}: {label}; {sign_note(diffs, m)}"


def proximity_scale(clearance: float, threshold: float, law: str) -> float:
    """1 at threshold, 0 at contact; 1 when farther than the threshold."""
    if threshold <= 0.0:
        raise ValueError("threshold must be positive")
    if clearance >= threshold:
        return 1.0
    if clearance <= 0.0:
        return 0.0
    frac = clearance / threshold
    if law == "linear":
        return frac
    if law == "quadratic":
        return frac * frac
    raise ValueError(law)


def run_arm(arm: str, start_clearance: float, steps: int, threshold: float, law: str = "linear") -> dict:
    if arm == "A":
        check = False
        used_threshold = threshold
    elif arm == "B":
        check = True
        used_threshold = threshold
    elif arm == "C":
        check = True
        used_threshold = C_THRESHOLD
    elif arm == "B_quad":
        check = True
        used_threshold = threshold
        law = "quadratic"
    else:
        raise ValueError(arm)

    clearance = start_clearance
    min_clearance = clearance
    collision_steps = 0
    max_penetration = 0.0
    speed = V_CMD
    for _ in range(steps):
        if check:
            scale = proximity_scale(clearance, used_threshold, law)
        else:
            scale = 1.0
        speed = scale * V_CMD
        clearance = clearance - speed * DT
        if clearance < min_clearance:
            min_clearance = clearance
        if clearance <= 0.0:
            collision_steps += 1
            pen = -clearance
            if pen > max_penetration:
                max_penetration = pen
    progress = start_clearance - clearance
    return {
        "progress": progress,
        "collision_steps": float(collision_steps),
        "min_clearance": min_clearance,
        "terminal_speed": speed,
        "max_penetration": max_penetration,
        "check_collisions": 1.0 if check else 0.0,
        "used_threshold": used_threshold,
    }


def col(rows, metric):
    return [row[metric] for row in rows]


def print_regime(name: str, expl: str, start_clearance: float, steps: int, threshold: float) -> None:
    print(f"declared expectation {name}: {expl}")
    print(
        f"regime {name}  (mean+-sd over seeds; deterministic jog) "
        f"start_clearance={num(start_clearance)} steps={steps} "
        f"band_threshold={num(threshold)} horizon_s={num(steps * DT)}"
    )
    rows = {arm: [] for arm in ARMS}
    recs0 = {}
    for seed in SEEDS:
        _ = seed
        for arm in ARMS:
            rec = run_arm(arm, start_clearance, steps, threshold)
            rows[arm].append(rec)
        if seed == 0:
            recs0 = {arm: rows[arm][0] for arm in ARMS}

    print(f"  seed 0 (all {len(SEEDS)} seeds identical):")
    for arm in ARMS:
        rec = recs0[arm]
        print(
            f"    {arm}: progress={num(rec['progress'])} collision_steps={num(rec['collision_steps'])} "
            f"min_clearance={num(rec['min_clearance'])} terminal_speed={num(rec['terminal_speed'])} "
            f"max_penetration={num(rec['max_penetration'])} "
            f"check_collisions={int(rec['check_collisions'])} used_threshold={num(rec['used_threshold'])}"
        )
    for arm in ARMS:
        for metric in METRICS:
            print(f"  {arm} {metric} {fmt_pair(*mean_sd(col(rows[arm], metric)))}")
    for metric in METRICS:
        print(f"  paired B-A {metric}: {verdict(col(rows['B'], metric), col(rows['A'], metric))}")
        print(f"  paired C-A {metric}: {verdict(col(rows['C'], metric), col(rows['A'], metric))}")
        print(f"  paired C-B {metric}: {verdict(col(rows['C'], metric), col(rows['B'], metric))}")


def main():
    print("Synthetic Servo collision-proximity stand-in; not MoveIt, FCL, or a real arm")
    print(
        "declared demo-config constants "
        f"self_collision_proximity_threshold={num(SELF_COLLISION_PROXIMITY_THRESHOLD)} "
        f"scene_collision_proximity_threshold={num(SCENE_COLLISION_PROXIMITY_THRESHOLD)} "
        f"check_collisions={str(CHECK_COLLISIONS_DEMO).lower()} "
        f"collision_check_rate={num(COLLISION_CHECK_RATE)}"
    )
    print(
        "declared toy DT="
        + num(DT)
        + " V_CMD="
        + num(V_CMD)
        + " C_THRESHOLD="
        + num(C_THRESHOLD)
        + " FAR_START_CLEARANCE="
        + num(FAR_START_CLEARANCE)
        + " FAR_HORIZON_STEPS="
        + str(FAR_HORIZON_STEPS)
        + " SCENE_START_CLEARANCE="
        + num(SCENE_START_CLEARANCE)
        + " SCENE_HORIZON_STEPS="
        + str(SCENE_HORIZON_STEPS)
        + " SELF_START_CLEARANCE="
        + num(SELF_START_CLEARANCE)
        + " SELF_HORIZON_STEPS="
        + str(SELF_HORIZON_STEPS)
        + " SMALL_FRAC="
        + num(SMALL_FRAC)
        + " seeds="
        + ",".join(str(s) for s in SEEDS)
    )
    print("declared scale law (B): 1 when clearance >= threshold, linear clearance/threshold down to 0 at contact")
    print("declared arm A: check_collisions off, scale = 1, no proximity scale")
    print("declared arm B: check_collisions on, scene 0.02 m or self 0.01 m as the regime's opened demo-config threshold")
    print("declared arm C: check_collisions on, over-conservative C_THRESHOLD (not a demo-config value)")
    print("hand_calc 20 percent small-vs-clear factor = " + num(SMALL_FRAC))
    print(
        "hand_calc far commanded travel = V_CMD * FAR_HORIZON_STEPS * DT = "
        + num(V_CMD)
        + " * "
        + str(FAR_HORIZON_STEPS)
        + " * "
        + num(DT)
        + " = "
        + num(V_CMD * FAR_HORIZON_STEPS * DT)
```
