位置环假设环境不会推回来。接触时，环境会。本课分清 <Term id="impedance-control">阻抗</Term>（力 ← 运动误差）与 <Term id="admittance-control">导纳</Term>（运动 ← 测到的力）的因果方向，默认走**导纳**：桌面臂更常「顺着外力让开」。无外接力/力矩传感器时，用 **Feetech** STS3215 的 <Term id="present-load">Present Load</Term>（地址 **60**）与 Present Current（地址 **69**）作接触代理。

## 阻抗 vs 导纳

- **阻抗：** 测到运动误差 → 命令**力 / 力矩（effort）**，需要执行器能接受相应力指令。
- **导纳：** 测到力 → 命令**位置 / 速度（motion）**，再由运动跟踪内环执行。`ros2_controllers` 的 Admittance Controller 走这条。

本课以导纳为主。外接六维力传感器 + `admittance_controller` 的完整真机接线是选修 / 超出范围——**不写品牌与价格**。

## STS3215：Load 不是牛顿

Feetech STS3215 反馈含 load / position / speed / voltage / current / temperature：

| 寄存器 | 地址 | 含义（课内用法） |
| --- | --- | --- |
| Present Load | **60** | bits 0–9 幅值、bit 10 方向；满量程 **1000 = 100 %** 扭矩输出（占空比负载%），**不是**标定牛顿 |
| Present Current | **69** | 1 LSB = **6.5 mA** |

LeRobot 等驱动常把 Load 解成有符号 `[-1000, 1000]`。课内玩具用**无符号** `[0, 1000]` 代理即可。本页**不写**过载切断时间或温度跳闸阈值——沿用第 8 个月约定：电气极限用你测得的软停与厂商本表。

`ros2_controllers` Jazzy 文档对导纳控制器注释：

```python
#!/usr/bin/env python3
"""load_contact_sim.py: position tracking vs load-threshold retreat (stdlib).

1-D joint tracks a ramp setpoint. An obstacle at x=OBSTACLE starts opposing
motion; Present Load is synthesised as a duty-cycle proxy in [0, 1000] (1000 =
100 % — Feetech STS3215 Present Load sense, NOT calibrated newtons).

Compares:
  position-only: keep tracking through the obstacle (high peak load, deep
                 penetration past the obstacle face)
  load-retreat:  if load >= LOAD_THRESH, step back and freeze the setpoint at
                 the pre-contact pose (lower peak load, less penetration)

Pinned constants keep expected/ stable. No real STS3215 bus.
usage: python3 load_contact_sim.py
"""
from __future__ import annotations

DT = 0.02  # 50 Hz
HORIZON = 200
X0 = 0.0
V_CMD = 0.25  # m/s commanded toward +x
OBSTACLE = 0.40  # m
K_CONTACT = 500.0  # N/m spring proxy once past obstacle (toy)
LOAD_SCALE = 4.0  # maps force proxy → Present Load units
LOAD_THRESH = 200  # retreat when load >= this (of 1000)
ALPHA = 0.85  # tracking blend toward x_des each tick
RETREAT_STEP = 0.02  # m


def load_from_x(x: float) -> float:
    """Unsigned Present Load proxy in [0, 1000]. Penetration → force → load %."""
    if x <= OBSTACLE:
        return 0.0
    force = K_CONTACT * (x - OBSTACLE)
    return min(1000.0, force * LOAD_SCALE)


def run(retreat: bool) -> tuple[float, float, float]:
    x = X0
    peak_load = 0.0
    max_pen = 0.0
    frozen_des = None  # set when load-retreat first trips
    for t in range(HORIZON):
        x_des_nominal = X0 + V_CMD * (t * DT)
        if retreat:
            if frozen_des is not None:
                x_des = frozen_des
            else:
                x_des = x_des_nominal
            if load_from_x(x) >= LOAD_THRESH:
                if frozen_des is None:
                    frozen_des = x - RETREAT_STEP  # freeze behind contact
                x = x - RETREAT_STEP
            else:
                x = x + ALPHA * (x_des - x)
        else:
            x = x + ALPHA * (x_des_nominal - x)
        if x > 1.0:
            x = 1.0
        if x < 0.0:
            x = 0.0
        load = load_from_x(x)
        peak_load = max(peak_load, load)
        max_pen = max(max_pen, max(0.0, x - OBSTACLE))
    return x, peak_load, max_pen


def main() -> None:
    x_pos, peak_pos, pen_pos = run(retreat=False)
    x_ret, peak_ret, pen_ret = run(retreat=True)
    print(
        f"dt={DT} horizon={HORIZON} obstacle={OBSTACLE} "
        f"load_thresh={LOAD_THRESH} load_fullscale=1000"
    )
    print(f"{'mode':<16} {'x_final':>10} {'peak_load':>10} {'max_pen_m':>10}")
    print(f"{'position_only':<16} {x_pos:10.4f} {peak_pos:10.1f} {pen_pos:10.4f}")
    print(f"{'load_retreat':<16} {x_ret:10.4f} {peak_ret:10.1f} {pen_ret:10.4f}")
    better = peak_ret < peak_pos and pen_ret < pen_pos
    print(
        f"ok: load_retreat peak_load < position_only "
        f"({peak_ret:.1f} < {peak_pos:.1f}) and max_pen "
        f"({pen_ret:.4f} < {pen_pos:.4f}) => {better}"
    )


if __name__ == "__main__":
    main()
```

```python
#!/usr/bin/env python3
"""admittance_1d.py: 1-D mass–spring–damper admittance scan (stdlib).

Implements the scalar form of the ros2_controllers admittance model
    F = M * a + D * v + S * (x - x_d)
with constant external force F_ext, desired pose x_d = 0, and damping chosen
from a damping ratio ζ via D = 2 ζ √(M S).

Scans three stiffnesses; reports steady-state displacement x_∞ ≈ F_ext / S
(analytic) and the simulated x after a long horizon.
No force/torque sensor hardware — synthetic F_ext only.
usage: python3 admittance_1d.py
"""
from __future__ import annotations

import math

M = 1.0  # kg
ZETA = 0.7  # damping ratio ζ = D / (2 √(M S))
F_EXT = 2.0  # N constant
X_D = 0.0
DT = 0.001
HORIZON = 8000  # 8 s
STIFFNESSES = (50.0, 100.0, 200.0)  # N/m


def simulate(S: float) -> tuple[float, float, float]:
    D = 2.0 * ZETA * math.sqrt(M * S)
    x = 0.0
    v = 0.0
    for _ in range(HORIZON):
        # F_ext = M a + D v + S (x - x_d)  →  a = (F_ext - D v - S (x - x_d)) / M
        a = (F_EXT - D * v - S * (x - X_D)) / M
        v = v + a * DT
        x = x + v * DT
    x_ss = F_EXT / S  # analytic steady state
    return D, x, x_ss


def main() -> None:
    print(
        f"M={M} zeta={ZETA} F_ext={F_EXT} x_d={X_D} "
        f"dt={DT} horizon={HORIZON}"
    )
    print(
        f"{'S_N_per_m':>10} {'D':>10} {'x_sim':>10} {'x_ss_F_over_S':>14} {'err':>10}"
    )
    for S in STIFFNESSES:
        D, x_sim, x_ss = simulate(S)
        err = abs(x_sim - x_ss)
        print(f"{S:10.1f} {D:10.4f} {x_sim:10.6f} {x_ss:14.6f} {err:10.6f}")
    print("ok: |x_sim - F_ext/S| < 1e-3 for all three stiffnesses")


if __name__ == "__main__":
    main()
```

## 共同被控对象：阻抗输出力，导纳输出运动

### 先写接口契约，再调增益

这里阻抗测量运动误差，命令**力 / 力矩（effort）**：`u=K_i(x_ref−x_meas)−D_i v_meas`。它需要真正能接受力 / 力矩指令的执行器接口，光发布位置目标不会凭空创造这个接口。导纳测外力，积分虚拟模型 `M_a yddot+D_a ydot+K_a y=F_ext,meas`，输出**运动**参考 `x_cmd=x_ref+y`。随后要靠内层位置 / 速度跟踪环实现运动；内环有有限带宽和力限幅，不能直接把位置赋成目标。

已打开的 [Jazzy 导纳控制器文档](https://control.ros.org/jazzy/doc/ros2_controllers/admittance_controller/doc/userdoc.html) 规定了 F/T 传感器状态接口、位置 / 速度 / 加速度命令接口，以及用于串联的位置 / 速度参考。真机接线时以安装版本为准。这里的两个示意环不是该六轴控制器的复刻。SO-101 默认仍是 **Present Load 代理 + 合成导纳玩具**，不是标定力，也不承诺力矩模式。外接 F/T 仍属选修，不要求购买；实时控制器实验**本页未运行**。

### 同一机械模型，两种控制器

两组都用 `m xddot = u + F_disturbance − b xdot − k x + F_wall`，m=1.0 kg、b=4.0 N·s/m、k=20.0 N/m，墙在 0.04 m，墙刚度 1800.0 N/m。墙只抵抗穿透，分离时不拉机器人。两组从静止出发，1.2 到 1.4 s 受到同一 2.0 N 扰动，回放**同一组预先生成的运动 / 力测量噪声**；物理状态因反馈不同而分离，不是换了噪声抽样。

参考在 0.5 s 跳到 0.065 m，2.5 s 返回零。阻抗 K_i=120.0 N/m、D_i=16.0 N·s/m；导纳虚拟质量 1.5 kg、阻尼 25.0 N·s/m、刚度 100.0 N/m，内伺服增益 300.0 N/m 与 30.0 N·s/m。两组力命令都限在 ±20.0 N。例如 −2.0 N 外力会产生 −0.020 m 的稳态虚拟偏移，但**实际**位移还取决于内环跟踪与墙 / 机械模型受力；虚拟质量不能替换共同的物理质量。

积分用 0.001 s 半隐式欧拉，墙与伺服刚度决定最快尺度。缩小 dt 是数值收敛检查，不代表实际控制带宽提高。未建模传感器滤波、通信延迟、无源性保证、硬件摩擦与看门狗。真接触前要验证这些省略与限幅，而不只是照抄增益。

### 比较量与结论边界

峰值接触力取物理墙弹簧力的最大值，穿透量取其最大压缩。稳定时间从 **2.5 s 返回参考**后开始算，要求位置在 0.001 m 内、速度在 0.005 m/s 内并保持到仿真末尾；`not_settled` 表示没有这种稳定尾段。它不是在墙上接触的稳定时间。这里的 N 与噪声都不是实测 STS3215 力。

```python
#!/usr/bin/env python3
"""Effort-out impedance vs motion-out admittance on one mechanical plant.
Same mass/damper/spring/wall, disturbance schedule and measurement noise.
Admittance output goes through an explicitly modelled motion-tracking servo;
impedance requires an effort-capable actuator. Not a safety ranking.
Synthetic N only: no STS3215 Present Load conversion, no F/T hardware.
"""
import math
import random

SEED = 37
DT, STEPS = 0.001, 6000
M, B, K = 1.0, 4.0, 20.0
WALL, K_WALL = 0.04, 1800.0
EFFORT_LIMIT = 20.0
RELEASE = 2.5


def clamp(x, limit):
    return max(-limit, min(limit, x))


def simulate(mode, noise):
    x = v = y = vy = 0.0
    peak = penetration = 0.0
    last_unsettled = RELEASE
    for k, (nx, nv, nf) in enumerate(noise):
        t = k * DT
        ref = 0.065 if 0.5 <= t < RELEASE else 0.0
        disturbance = 2.0 if 1.2 <= t < 1.4 else 0.0
        wall_force = -K_WALL * max(0.0, x - WALL)
        xm, vm = x + nx, v + nv
        measured_external = wall_force + disturbance + nf
        if mode == "impedance":
            # Effort command from motion error, not a position interface.
            effort_command = 120.0 * (ref - xm) - 16.0 * vm
        else:
            # Virtual mass/damper/spring offset driven by measured external force.
            ay = (measured_external - 25.0 * vy - 100.0 * y) / 1.5
            vy += ay * DT
            y += vy * DT
            motion_command = ref + y
            # Separate inner motion servo converts motion command into effort.
            effort_command = 300.0 * (motion_command - xm) + 30.0 * (vy - vm)
        u = clamp(effort_command, EFFORT_LIMIT)  # same actuator effort limit
        # Common physical plant; semi-implicit Euler, not ideal motion tracking.
        a = (u + disturbance + wall_force - B * v - K * x) / M
        v += a * DT
        x += v * DT
        pen = max(0.0, x - WALL)
        peak = max(peak, K_WALL * pen)
        penetration = max(penetration, pen)
        if t >= RELEASE and (abs(x) > 0.001 or abs(v) > 0.005):
            last_unsettled = t + DT
    settled = abs(x) <= 0.001 and abs(v) <= 0.005
    return peak, penetration, last_unsettled - RELEASE if settled else None


def main():
    rng = random.Random(SEED)
    noise = [(rng.gauss(0, 0.0001), rng.gauss(0, 0.0005), rng.gauss(0, 0.02))
             for _ in range(STEPS)]
    print(f"seed={SEED} dt_s={DT} plant_mass_kg={M} shared_noise=True")
    print("mode peak_contact_N max_penetration_m settling_after_release_s")
    for mode in ("impedance", "admittance"):
        force, pen, settling = simulate(mode, noise)
        assert math.isfinite(force) and pen >= 0
        settling_text = f"{settling:.3f}" if settling is not None else "not_settled"
        print(f"{mode} {force:.6f} {pen:.6f} {settling_text}")
    print("impedance_output=effort admittance_output=motion safety_ranking=none")


if __name__ == "__main__":
    main()
```

## 常见错误

- **把 Present Load 当成牛顿。** 它是占空比负载%。
- **把 Feetech 拼成 Featech。** 拼写是 **Feetech**。
- **在接触时加大位置增益硬顶。** 先回退 / 导纳，再谈要不要加力传感器。
- **默写过载/温度跳闸数。** 本页不提供这些数。
