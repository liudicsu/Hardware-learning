A position loop assumes the world will not push back. In contact, it does. This lesson separates <Term id="impedance-control">impedance</Term> (force ← motion error) from <Term id="admittance-control">admittance</Term> (motion ← measured force). The default path here is **admittance**: desk arms more often “give way” under external force. Without an external force/torque sensor, use **Feetech** STS3215 <Term id="present-load">Present Load</Term> (address **60**) and Present Current (address **69**) as a contact proxy.

## Impedance vs admittance

- **Impedance:** measured motion error → commanded **force/torque (effort)**, requiring an effort-capable actuator interface.
- **Admittance:** measured force → commanded **position/velocity (motion)** through a motion-tracking inner loop. The `ros2_controllers` Admittance Controller takes this path.

This lesson focuses on admittance. Wiring a real six-axis F/T sensor into `admittance_controller` is elective / out of scope — **no brand names or prices**.

## STS3215: Load is not newtons

Feetech STS3215 feedback includes load / position / speed / voltage / current / temperature:

| Register | Addr | Meaning (lesson use) |
| --- | --- | --- |
| Present Load | **60** | bits 0–9 magnitude, bit 10 direction; full-scale **1000 = 100 %** torque output (duty-cycle load %), **not** calibrated newtons |
| Present Current | **69** | 1 LSB = **6.5 mA** |

Drivers such as LeRobot often decode Load as signed `[-1000, 1000]`. The toys here use an **unsigned** `[0, 1000]` proxy. This page **does not** invent overload trip times or temperature cutouts — same Month 8 rule: electrical limits come from your measured soft stops and the vendor’s own table.

## Admittance equation (from the docs)

`ros2_controllers` Jazzy documents the controller as:

<Formula label="admittance">F = M·a + D·v + S·(x − x_d)</Formula>

Damping ratio ζ = D / (2 √(M S)), so D = 2 ζ √(M S). Parameters include `admittance.mass` / `damping_ratio` / `stiffness`. The real path needs an `ft_sensor` semantic interface — the default SO-101 lesson uses “load proxy + synthetic admittance toys.”

```python
#!/usr/bin/env python3
"""load_contact_sim.py: position tracking vs load-threshold retreat (stdlib).

1-D joint tracks a ramp setpoint. An obstacle at x=OBSTACLE starts opposing
motion; Present Load is synthesised as a duty-cycle proxy in [0, 1000] (1000 =
100 % — Feetech STS3215 Present Load sense, NOT calibrated newtons).

Compares:
  position-only: keep tracking through the obstacle (high peak load, deep
                 penetration past the obstacle face)
  load-retreat:  if load >= LOAD_THRESH, step back and freeze the setpoint at
                 the pre-contact pose (lower peak load, less penetration)

Pinned constants keep expected/ stable. No real STS3215 bus.
usage: python3 load_contact_sim.py
"""
from __future__ import annotations

DT = 0.02  # 50 Hz
HORIZON = 200
X0 = 0.0
V_CMD = 0.25  # m/s commanded toward +x
OBSTACLE = 0.40  # m
K_CONTACT = 500.0  # N/m spring proxy once past obstacle (toy)
LOAD_SCALE = 4.0  # maps force proxy → Present Load units
LOAD_THRESH = 200  # retreat when load >= this (of 1000)
ALPHA = 0.85  # tracking blend toward x_des each tick
RETREAT_STEP = 0.02  # m


def load_from_x(x: float) -> float:
    """Unsigned Present Load proxy in [0, 1000]. Penetration → force → load %."""
    if x <= OBSTACLE:
        return 0.0
    force = K_CONTACT * (x - OBSTACLE)
    return min(1000.0, force * LOAD_SCALE)


def run(retreat: bool) -> tuple[float, float, float]:
    x = X0
    peak_load = 0.0
    max_pen = 0.0
    frozen_des = None  # set when load-retreat first trips
    for t in range(HORIZON):
        x_des_nominal = X0 + V_CMD * (t * DT)
        if retreat:
            if frozen_des is not None:
                x_des = frozen_des
            else:
                x_des = x_des_nominal
            if load_from_x(x) >= LOAD_THRESH:
                if frozen_des is None:
                    frozen_des = x - RETREAT_STEP  # freeze behind contact
                x = x - RETREAT_STEP
            else:
                x = x + ALPHA * (x_des - x)
        else:
            x = x + ALPHA * (x_des_nominal - x)
        if x > 1.0:
            x = 1.0
        if x < 0.0:
            x = 0.0
        load = load_from_x(x)
        peak_load = max(peak_load, load)
        max_pen = max(max_pen, max(0.0, x - OBSTACLE))
    return x, peak_load, max_pen


def main() -> None:
    x_pos, peak_pos, pen_pos = run(retreat=False)
    x_ret, peak_ret, pen_ret = run(retreat=True)
    print(
        f"dt={DT} horizon={HORIZON} obstacle={OBSTACLE} "
        f"load_thresh={LOAD_THRESH} load_fullscale=1000"
    )
    print(f"{'mode':<16} {'x_final':>10} {'peak_load':>10} {'max_pen_m':>10}")
    print(f"{'position_only':<16} {x_pos:10.4f} {peak_pos:10.1f} {pen_pos:10.4f}")
    print(f"{'load_retreat':<16} {x_ret:10.4f} {peak_ret:10.1f} {pen_ret:10.4f}")
    better = peak_ret < peak_pos and pen_ret < pen_pos
    print(
        f"ok: load_retreat peak_load < position_only "
        f"({peak_ret:.1f} < {peak_pos:.1f}) and max_pen "
        f"({pen_ret:.4f} < {pen_pos:.4f}) => {better}"
    )


if __name__ == "__main__":
    main()
```

```python
#!/usr/bin/env python3
"""admittance_1d.py: 1-D mass–spring–damper admittance scan (stdlib).

Implements the scalar form of the ros2_controllers admittance model
    F = M * a + D * v + S * (x - x_d)
with constant external force F_ext, desired pose x_d = 0, and damping chosen
from a damping ratio ζ via D = 2 ζ √(M S).

Scans three stiffnesses; reports steady-state displacement x_∞ ≈ F_ext / S
(analytic) and the simulated x after a long horizon.
No force/torque sensor hardware — synthetic F_ext only.
usage: python3 admittance_1d.py
"""
from __future__ import annotations

import math

M = 1.0  # kg
ZETA = 0.7  # damping ratio ζ = D / (2 √(M S))
F_EXT = 2.0  # N constant
X_D = 0.0
DT = 0.001
HORIZON = 8000  # 8 s
STIFFNESSES = (50.0, 100.0, 200.0)  # N/m


def simulate(S: float) -> tuple[float, float, float]:
    D = 2.0 * ZETA * math.sqrt(M * S)
    x = 0.0
    v = 0.0
    for _ in range(HORIZON):
        # F_ext = M a + D v + S (x - x_d)  →  a = (F_ext - D v - S (x - x_d)) / M
        a = (F_EXT - D * v - S * (x - X_D)) / M
        v = v + a * DT
        x = x + v * DT
    x_ss = F_EXT / S  # analytic steady state
    return D, x, x_ss


def main() -> None:
    print(
        f"M={M} zeta={ZETA} F_ext={F_EXT} x_d={X_D} "
        f"dt={DT} horizon={HORIZON}"
    )
    print(
        f"{'S_N_per_m':>10} {'D':>10} {'x_sim':>10} {'x_ss_F_over_S':>14} {'err':>10}"
    )
    for S in STIFFNESSES:
        D, x_sim, x_ss = simulate(S)
        err = abs(x_sim - x_ss)
        print(f"{S:10.1f} {D:10.4f} {x_sim:10.6f} {x_ss:14.6f} {err:10.6f}")
    print("ok: |x_sim - F_ext/S| < 1e-3 for all three stiffnesses")


if __name__ == "__main__":
    main()
```

## Effort-out vs motion-out on a shared plant

### Interface contracts before gains

Impedance here measures motion error and commands **effort**: `u=K_i(x_ref−x_meas)−D_i v_meas`. It needs a torque/force-capable actuator interface; merely publishing a position goal does not create that interface. Admittance measures external force and integrates a virtual model `M_a yddot+D_a ydot+K_a y=F_ext,meas`, producing the **motion** reference `x_cmd=x_ref+y`. An inner position/velocity tracking loop must then realise that motion. That inner loop has finite bandwidth and effort limits: it is not a magic position assignment.

The opened [Jazzy admittance-controller documentation](https://control.ros.org/jazzy/doc/ros2_controllers/admittance_controller/doc/userdoc.html) specifies F/T sensor state interfaces, motion command interfaces (position/velocity/acceleration), and position/velocity references for chaining. Check the installed version when wiring a real controller. Our two illustrative loops are not a reproduction of that six-axis controller. Default SO-101 still means **Present Load proxy + synthetic admittance toys**, not calibrated force or a promise of torque mode. External F/T hardware remains elective, not a required purchase; live controller experiments are **本页未运行 (not run on this page)**.

### One mechanical plant, two controllers

Both conditions use `m xddot = u + F_disturbance − b xdot − k x + F_wall`, with m=1.0 kg, b=4.0 N·s/m, k=20.0 N/m, wall at 0.04 m and wall stiffness 1800.0 N/m. The wall only opposes penetration; it does not pull when separated. Both start at rest, receive the same 2.0 N disturbance between 1.2 and 1.4 s, and replay the **same pre-generated motion/force measurement noise**. Physical states diverge through feedback, not through different noise draws.

The reference steps to 0.065 m at 0.5 s and returns to zero at 2.5 s. Impedance uses K_i=120.0 N/m, D_i=16.0 N·s/m. Admittance uses virtual mass 1.5 kg, damping 25.0 N·s/m, stiffness 100.0 N/m; its inner servo uses 300.0 N/m and 30.0 N·s/m. Both effort commands clip at ±20.0 N. Example: a −2.0 N external force would produce a steady virtual offset −0.020 m, but the **physical** displacement also depends on inner tracking and wall/plant forces. The virtual mass is not a replacement for the shared physical mass.

Integration is semi-implicit Euler at 0.001 s; the wall/servo stiffness sets the fastest scales. Smaller dt is a numerical convergence check, not higher real control bandwidth. No sensor filtering, communications delay, passivity guarantee, hardware friction or watchdog is modelled. Before real contact, validate those omissions and limits, not just these gains.

### Measured quantities and limits of the comparison

Peak contact force is the maximum physical wall spring force, penetration is its maximum compression. Settling is measured **after the return at 2.5 s**, requiring position within 0.001 m and speed within 0.005 m/s for the remainder of the simulated horizon; `not_settled` means no such tail. It is not a wall-contact settling-time claim. Neither the modelled N nor the noise are measured STS3215 forces.

```python
#!/usr/bin/env python3
"""Effort-out impedance vs motion-out admittance on one mechanical plant.
Same mass/damper/spring/wall, disturbance schedule and measurement noise.
Admittance output goes through an explicitly modelled motion-tracking servo;
impedance requires an effort-capable actuator. Not a safety ranking.
Synthetic N only: no STS3215 Present Load conversion, no F/T hardware.
"""
import math
import random

SEED = 37
DT, STEPS = 0.001, 6000
M, B, K = 1.0, 4.0, 20.0
WALL, K_WALL = 0.04, 1800.0
EFFORT_LIMIT = 20.0
RELEASE = 2.5


def clamp(x, limit):
    return max(-limit, min(limit, x))


def simulate(mode, noise):
    x = v = y = vy = 0.0
    peak = penetration = 0.0
    last_unsettled = RELEASE
    for k, (nx, nv, nf) in enumerate(noise):
        t = k * DT
        ref = 0.065 if 0.5 <= t < RELEASE else 0.0
        disturbance = 2.0 if 1.2 <= t < 1.4 else 0.0
        wall_force = -K_WALL * max(0.0, x - WALL)
        xm, vm = x + nx, v + nv
        measured_external = wall_force + disturbance + nf
        if mode == "impedance":
            # Effort command from motion error, not a position interface.
            effort_command = 120.0 * (ref - xm) - 16.0 * vm
        else:
            # Virtual mass/damper/spring offset driven by measured external force.
            ay = (measured_external - 25.0 * vy - 100.0 * y) / 1.5
            vy += ay * DT
            y += vy * DT
            motion_command = ref + y
            # Separate inner motion servo converts motion command into effort.
            effort_command = 300.0 * (motion_command - xm) + 30.0 * (vy - vm)
        u = clamp(effort_command, EFFORT_LIMIT)  # same actuator effort limit
        # Common physical plant; semi-implicit Euler, not ideal motion tracking.
        a = (u + disturbance + wall_force - B * v - K * x) / M
        v += a * DT
        x += v * DT
        pen = max(0.0, x - WALL)
        peak = max(peak, K_WALL * pen)
        penetration = max(penetration, pen)
        if t >= RELEASE and (abs(x) > 0.001 or abs(v) > 0.005):
            last_unsettled = t + DT
    settled = abs(x) <= 0.001 and abs(v) <= 0.005
    return peak, penetration, last_unsettled - RELEASE if settled else None


def main():
    rng = random.Random(SEED)
    noise = [(rng.gauss(0, 0.0001), rng.gauss(0, 0.0005), rng.gauss(0, 0.02))
             for _ in range(STEPS)]
    print(f"seed={SEED} dt_s={DT} plant_mass_kg={M} shared_noise=True")
    print("mode peak_contact_N max_penetration_m settling_after_release_s")
    for mode in ("impedance", "admittance"):
        force, pen, settling = simulate(mode, noise)
        assert math.isfinite(force) and pen >= 0
        settling_text = f"{settling:.3f}" if settling is not None else "not_settled"
        print(f"{mode} {force:.6f} {pen:.6f} {settling_text}")
    print("impedance_output=effort admittance_output=motion safety_ranking=none")


if __name__ == "__main__":
    main()
```

## Batch-6 H5: estimated F/T bias and gravity
Present Load remains the default proxy above: **it is not N**. This section uses **synthetic six-axis F/T** readings, not a conversion of Present Load and not a requirement to buy a sensor. We estimate mass, center of mass (COM) and both force/torque offsets from free-space static data, then evaluate on **held-out poses**. Real F/T hardware: **本页未运行**.

The opened `ft_tools_ros2` calibration README describes sensor-frame least-squares estimates of mass, COM and offsets (its implementation uses Eigen SVD and suggests about ten well-chosen poses). The official Jazzy admittance documentation explicitly identifies the gravity-compensation frame, COM position and tool weight. Our stdlib QR model is educational; it does not run either package or calibrate sensor-to-robot rotation.

### Fix sign, axes and origin first

`R_BS` maps **sensor frame S → base axes B**. Base gravity is `gB=(0,0,−9.81) m/s²`, so **gS=R_BSᵀ gB**. Every measured force, torque, offset and COM below is expressed in **sensor axes at the sensor origin**. For the same origin, vectors rotate as `fB=R_BS fS`, `τB=R_BS τS`; moving the wrench to the actual base origin additionally needs a moment-arm cross product, which we do not do. Contact commands are specified in base-oriented axes **at that same sensor origin**, then rotated into S.

Choose **payload-on-sensor positive**: `f_meas = f_contact + m gS + bF`; `τ_meas = τ_contact + h×gS + bT`, with **h=m c** (kg·m). Here m is kg, c is metres, bF is N, bT is N·m. The linked README writes a **−mg reaction convention**; our **+mg convention** is intentional. Do not copy its subtraction sign without mapping sensor polarity and the definition of g. Compensation subtracts our own declared model, not an oracle contact signal.

Use **six orientations**, giving gravity along ±X/±Y/±Z in S, **16 samples each =96 contact-free calibration rows**. For each force component j, the LS row is `[gS_j, e_j]` for unknown `[m,bFx,bFy,bFz]`. Torque uses unknown `[hx,hy,hz,bTx,bTy,bTz]` and the design:

```text
h cross gS = [  0   gz  -gy ] h
             [ -gz   0   gx ]
             [  gy -gx    0 ]
```

Solve the two systems, then **c_hat=h_hat/m_hat**. We use reorthogonalized modified Gram-Schmidt QR and reject a rank-deficient orientation set; production code should use a well-conditioned/pivoted solver or SVD. **At least three sufficiently distinct orientations** are needed for this joint identification, but a pose count alone does not ensure rank or conditioning; six full-rank synthetic orientations are not a universal hardware recipe. Calibration has no contact, no known true mass/COM/offset supplied to the fitter, and no held-out labels used for fitting or threshold selection.

### Information audit and shared evaluation

| Arm | What it uses / subtracts |
|---|---|
| raw | Same provided data, no correction. |
| one_pose_tare | Mean of only the first pose's **16/96** rows; subtracts bias **plus gravity at that pose**, not identified bias. |
| bias_only_ls | Estimated bF/bT from all **96** rows; ignores fitted gravity. |
| ls_gravity | Estimated m/c/bF/bT from the same **96** rows; subtracts bias and orientation-dependent gravity. |

All four arms are supplied the same calibration records and known poses and consume the **identical stored evaluation stream/noise**. Raw and one-pose tare deliberately discard information; this is disclosed, not an equal-used-samples or sample-efficiency claim. Bias-only vs full compensation shares the same LS fit; no arm gets oracle mass or COM.

The generator alone uses synthetic truth: **m=0.72 kg**, **c=(0.035,−0.018,0.065) m**, bF=(0.32,−0.25,0.42) N and bT=(0.018,−0.012,0.009) N·m. Independent component noise is Gaussian with **σF=0.08 N**, **στ=0.003 N·m**, identical within each arm comparison. Five seeds **11/23/37/53/71** use separate calibration/evaluation RNG streams. Each evaluates **12 held-out orientations ×10 =120** rows, **60 free +60 contact**; the static contact force in base-oriented axes is (1.2,0.4,0.2) N and torque (0.045,−0.025,0.020) N·m.

Metrics are **vector RMSE**, `sqrt(mean(||estimated−true||²))`, separately in N and N·m, not per-component RMSE. Fixed contact detection is `||estimated force|| >1.2 N`; F1=`2TP/(2TP+FP+FN)`, and false triggers count only the **60 free-space** rows. The threshold is declared before evaluation, not retuned per arm. Near-threshold contact plus shared noise keeps detection imperfect even after good calibration.

#!/usr/bin/env python3
"""Synthetic static F/T calibration; stdlib only, no sensor purchase.
R_BS maps sensor axes to base axes; gS=R_BS^T*(0,0,-9.81).
Positive wrench here is payload-on-sensor: fS=m*gS+bF+contactS;
tauS=(m*c) cross gS+bT+contactTorqueS, all at the sensor origin.
This sign is declared, not copied from ft_tools_ros2's opposite reaction sign.
Fit only measured free-space calibration rows. Mass, COM and both offsets are
ESTIMATED, never supplied to compensation. All arms share recorded eval data.
Real F/T hardware: 本页未运行. No safety or universal performance claim.
"""
from math import cos, sin, pi, sqrt
from random import Random
from statistics import mean, pstdev

SEEDS = (11, 23, 37, 53, 71)
G_BASE = (0., 0., -9.81)
SIGMA_F, SIGMA_T = .08, .003  # N, N m per independent sensor component
THRESHOLD = 1.2  # N; declared before evaluation, not tuned on held-out data
ARMS = ("raw", "one_pose_tare", "bias_only_ls", "ls_gravity")
ZERO = (0., 0., 0.)
TRUTH = (.72, (.035, -.018, .065), (.32, -.25, .42), (.018, -.012, .009))
CAL_POSES = ((0., 0., 0.), (pi, 0., 0.), (0., pi/2, 0.),
             (0., -pi/2, 0.), (pi/2, 0., 0.), (-pi/2, 0., 0.))
EVAL_POSES = tuple((-.9 + .17*k, .35*sin(.7*k) + .21, .13 + .29*k) for k in range(12))


def add(a, b):
    return tuple(x+y for x, y in zip(a, b))


def sub(a, b):
    return tuple(x-y for x, y in zip(a, b))


def scale(k, a):
    return tuple(k*x for x in a)


def dot(a, b):
    return sum(x*y for x, y in zip(a, b))


def norm(a):
    return sqrt(dot(a, a))


def cross(a, b):
    return (a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0])


def rotation(pose):
    """R_BS = Rz(yaw) Ry(pitch) Rx(roll), right-handed."""
    r, p, y = pose
    cr, sr, cp, sp, cy, sy = cos(r), sin(r), cos(p), sin(p), cos(y), sin(y)
    return ((cy*cp, cy*sp*sr-sy*cr, cy*sp*cr+sy*sr),
            (sy*cp, sy*sp*sr+cy*cr, sy*sp*cr-cy*sr), (-sp, cp*sr, cp*cr))


def to_sensor(r, base):
    return tuple(dot(column, base) for column in zip(*r))


def to_base(r, sensor):
    return tuple(dot(row, sensor) for row in r)


def least_squares(rows, targets):
    """Reorthogonalized modified Gram-Schmidt QR; reject rank-deficient poses.
    Educational small matrices, not a substitute for production pivoted QR/SVD.
    """
    columns = [tuple(c) for c in zip(*rows)]
    n = len(columns)
    q, upper = [], [[0.]*n for _ in range(n)]
    for j, column in enumerate(columns):
        v = column
        for _ in range(2):
            for k, basis in enumerate(q):
                coefficient = dot(basis, v)
                upper[k][j] += coefficient
                v = sub(v, scale(coefficient, basis))
        upper[j][j] = norm(v)
        if upper[j][j] < 1e-10:
            raise ValueError("insufficient orientation excitation / rank deficient")
        q.append(scale(1/upper[j][j], v))
    rhs, solution = [dot(basis, targets) for basis in q], [0.]*n
    for j in range(n-1, -1, -1):
        solution[j] = (rhs[j]-sum(upper[j][k]*solution[k] for k in range(j+1, n)))/upper[j][j]
    return tuple(solution)


def fit(calibration):
    """Receives only (gS, measured_fS, measured_tauS); no true mass/COM/bias."""
    frows, trows, fy, ty = [], [], [], []
    for g, f, tau in calibration:
        h_design = ((0., g[2], -g[1]), (-g[2], 0., g[0]), (g[1], -g[0], 0.))
        for axis in range(3):
            unit = tuple(float(axis == j) for j in range(3))
            frows.append((g[axis],) + unit)
            trows.append(h_design[axis] + unit)
            fy.append(f[axis]); ty.append(tau[axis])
    mass_bias = least_squares(frows, fy)
    h_bias = least_squares(trows, ty)
    mass = mass_bias[0]
    if mass <= 0:
        raise ValueError("unphysical fitted mass")
    return mass, scale(1/mass, h_bias[:3]), mass_bias[1:], h_bias[3:]


def measurement(pose, contact_f, contact_t, rng, sigma_f=SIGMA_F, sigma_t=SIGMA_T):
    """Truth is used ONLY by synthetic data generator and error scorer."""
    mass, com, bf, bt = TRUTH
    r = rotation(pose)
    g = to_sensor(r, G_BASE)
    f_true, t_true = to_sensor(r, contact_f), to_sensor(r, contact_t)
    f = add(add(f_true, scale(mass, g)), bf)
    tau = add(add(t_true, cross(scale(mass, com), g)), bt)
    return g, add(f, tuple(rng.gauss(0, sigma_f) for _ in range(3))), add(tau, tuple(rng.gauss(0, sigma_t) for _ in range(3)))


def datasets(seed, sigma_f=SIGMA_F, sigma_t=SIGMA_T):
    cal_rng, eval_rng = Random(seed), Random(10000+seed)
    calibration = [measurement(pose, ZERO, ZERO, cal_rng, sigma_f, sigma_t)
                   for pose in CAL_POSES for _ in range(16)]
    evaluation = []
    for pose in EVAL_POSES:
        r = rotation(pose)
        for k in range(10):
            contact = k >= 5
            f, t = ((1.2, .4, .2), (.045, -.025, .020)) if contact else (ZERO, ZERO)
            g, fm, tm = measurement(pose, f, t, eval_rng, sigma_f, sigma_t)
            evaluation.append((g, fm, tm, to_sensor(r, f), to_sensor(r, t), contact))
    return calibration, evaluation


def tare(calibration):
    """Constant one-pose zero uses first 16 rows only; it includes gravity."""
    return tuple(tuple(mean(row[index][axis] for row in calibration[:16]) for axis in range(3)) for index in (1, 2))


def compensate(arm, sample, estimated, zero):
    g, fm, tm = sample[:3]
    mass, com, bf, bt = estimated
    if arm == "raw":
        return fm, tm
    if arm == "one_pose_tare":
        return sub(fm, zero[0]), sub(tm, zero[1])
    if arm == "bias_only_ls":
        return sub(fm, bf), sub(tm, bt)
    if arm != "ls_gravity":
        raise ValueError("unknown arm")
    return sub(sub(fm, bf), scale(mass, g)), sub(sub(tm, bt), cross(scale(mass, com), g))


def score(arm, evaluation, estimated, zero):
    f2 = t2 = 0.
    tp = fp = fn = 0
    for sample in evaluation:
        f, t = compensate(arm, sample, estimated, zero)
        f2 += norm(sub(f, sample[3]))**2
        t2 += norm(sub(t, sample[4]))**2
        detected, contact = norm(f) > THRESHOLD, sample[5]
        tp += int(detected and contact)
        fp += int(detected and not contact)
        fn += int(not detected and contact)
    f1 = 2*tp/(2*tp+fp+fn) if 2*tp+fp+fn else 0.
    return sqrt(f2/len(evaluation)), sqrt(t2/len(evaluation)), f1, fp
