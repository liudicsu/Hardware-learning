A position loop assumes the world will not push back. In contact, it does. This lesson separates <Term id="impedance-control">impedance</Term> (force ← motion error) from <Term id="admittance-control">admittance</Term> (motion ← measured force). The default path here is **admittance**: desk arms more often “give way” under external force. Without an external force/torque sensor, use **Feetech** STS3215 <Term id="present-load">Present Load</Term> (address **60**) and Present Current (address **69**) as a contact proxy.

## Impedance vs admittance

- **Impedance:** measured motion error → commanded **force/torque (effort)**, requiring an effort-capable actuator interface.
- **Admittance:** measured force → commanded **position/velocity (motion)** through a motion-tracking inner loop. The `ros2_controllers` Admittance Controller takes this path.

This lesson focuses on admittance. Wiring a real six-axis F/T sensor into `admittance_controller` is elective / out of scope — **no brand names or prices**.

## STS3215: Load is not newtons

Feetech STS3215 feedback includes load / position / speed / voltage / current / temperature:

| Register | Addr | Meaning (lesson use) |
| --- | --- | --- |
| Present Load | **60** | bits 0–9 magnitude, bit 10 direction; full-scale **1000 = 100 %** torque output (duty-cycle load %), **not** calibrated newtons |
| Present Current | **69** | 1 LSB = **6.5 mA** |

Drivers such as LeRobot often decode Load as signed `[-1000, 1000]`. The toys here use an **unsigned** `[0, 1000]` proxy. This page **does not** invent overload trip times or temperature cutouts — same Month 8 rule: electrical limits come from your measured soft stops and the vendor’s own table.

## Admittance equation (from the docs)

`ros2_controllers` Jazzy documents the controller as:

<Formula label="admittance">F = M·a + D·v + S·(x − x_d)</Formula>

Damping ratio ζ = D / (2 √(M S)), so D = 2 ζ √(M S). Parameters include `admittance.mass` / `damping_ratio` / `stiffness`. The real path needs an `ft_sensor` semantic interface — the default SO-101 lesson uses “load proxy + synthetic admittance toys.”

```python
#!/usr/bin/env python3
"""load_contact_sim.py: position tracking vs load-threshold retreat (stdlib).

1-D joint tracks a ramp setpoint. An obstacle at x=OBSTACLE starts opposing
motion; Present Load is synthesised as a duty-cycle proxy in [0, 1000] (1000 =
100 % — Feetech STS3215 Present Load sense, NOT calibrated newtons).

Compares:
  position-only: keep tracking through the obstacle (high peak load, deep
                 penetration past the obstacle face)
  load-retreat:  if load >= LOAD_THRESH, step back and freeze the setpoint at
                 the pre-contact pose (lower peak load, less penetration)

Pinned constants keep expected/ stable. No real STS3215 bus.
usage: python3 load_contact_sim.py
"""
from __future__ import annotations

DT = 0.02  # 50 Hz
HORIZON = 200
X0 = 0.0
V_CMD = 0.25  # m/s commanded toward +x
OBSTACLE = 0.40  # m
K_CONTACT = 500.0  # N/m spring proxy once past obstacle (toy)
LOAD_SCALE = 4.0  # maps force proxy → Present Load units
LOAD_THRESH = 200  # retreat when load >= this (of 1000)
ALPHA = 0.85  # tracking blend toward x_des each tick
RETREAT_STEP = 0.02  # m


def load_from_x(x: float) -> float:
    """Unsigned Present Load proxy in [0, 1000]. Penetration → force → load %."""
    if x <= OBSTACLE:
        return 0.0
    force = K_CONTACT * (x - OBSTACLE)
    return min(1000.0, force * LOAD_SCALE)


def run(retreat: bool) -> tuple[float, float, float]:
    x = X0
    peak_load = 0.0
    max_pen = 0.0
    frozen_des = None  # set when load-retreat first trips
    for t in range(HORIZON):
        x_des_nominal = X0 + V_CMD * (t * DT)
        if retreat:
            if frozen_des is not None:
                x_des = frozen_des
            else:
                x_des = x_des_nominal
            if load_from_x(x) >= LOAD_THRESH:
                if frozen_des is None:
                    frozen_des = x - RETREAT_STEP  # freeze behind contact
                x = x - RETREAT_STEP
            else:
                x = x + ALPHA * (x_des - x)
        else:
            x = x + ALPHA * (x_des_nominal - x)
        if x > 1.0:
            x = 1.0
        if x < 0.0:
            x = 0.0
        load = load_from_x(x)
        peak_load = max(peak_load, load)
        max_pen = max(max_pen, max(0.0, x - OBSTACLE))
    return x, peak_load, max_pen


def main() -> None:
    x_pos, peak_pos, pen_pos = run(retreat=False)
    x_ret, peak_ret, pen_ret = run(retreat=True)
    print(
        f"dt={DT} horizon={HORIZON} obstacle={OBSTACLE} "
        f"load_thresh={LOAD_THRESH} load_fullscale=1000"
    )
    print(f"{'mode':<16} {'x_final':>10} {'peak_load':>10} {'max_pen_m':>10}")
    print(f"{'position_only':<16} {x_pos:10.4f} {peak_pos:10.1f} {pen_pos:10.4f}")
    print(f"{'load_retreat':<16} {x_ret:10.4f} {peak_ret:10.1f} {pen_ret:10.4f}")
    better = peak_ret < peak_pos and pen_ret < pen_pos
    print(
        f"ok: load_retreat peak_load < position_only "
        f"({peak_ret:.1f} < {peak_pos:.1f}) and max_pen "
        f"({pen_ret:.4f} < {pen_pos:.4f}) => {better}"
    )


if __name__ == "__main__":
    main()
```

```python
#!/usr/bin/env python3
"""admittance_1d.py: 1-D mass–spring–damper admittance scan (stdlib).

Implements the scalar form of the ros2_controllers admittance model
    F = M * a + D * v + S * (x - x_d)
with constant external force F_ext, desired pose x_d = 0, and damping chosen
from a damping ratio ζ via D = 2 ζ √(M S).

Scans three stiffnesses; reports steady-state displacement x_∞ ≈ F_ext / S
(analytic) and the simulated x after a long horizon.
No force/torque sensor hardware — synthetic F_ext only.
usage: python3 admittance_1d.py
"""
from __future__ import annotations

import math

M = 1.0  # kg
ZETA = 0.7  # damping ratio ζ = D / (2 √(M S))
F_EXT = 2.0  # N constant
X_D = 0.0
DT = 0.001
HORIZON = 8000  # 8 s
STIFFNESSES = (50.0, 100.0, 200.0)  # N/m


def simulate(S: float) -> tuple[float, float, float]:
    D = 2.0 * ZETA * math.sqrt(M * S)
    x = 0.0
    v = 0.0
    for _ in range(HORIZON):
        # F_ext = M a + D v + S (x - x_d)  →  a = (F_ext - D v - S (x - x_d)) / M
        a = (F_EXT - D * v - S * (x - X_D)) / M
        v = v + a * DT
        x = x + v * DT
    x_ss = F_EXT / S  # analytic steady state
    return D, x, x_ss


def main() -> None:
    print(
        f"M={M} zeta={ZETA} F_ext={F_EXT} x_d={X_D} "
        f"dt={DT} horizon={HORIZON}"
    )
    print(
        f"{'S_N_per_m':>10} {'D':>10} {'x_sim':>10} {'x_ss_F_over_S':>14} {'err':>10}"
    )
    for S in STIFFNESSES:
        D, x_sim, x_ss = simulate(S)
        err = abs(x_sim - x_ss)
        print(f"{S:10.1f} {D:10.4f} {x_sim:10.6f} {x_ss:14.6f} {err:10.6f}")
    print("ok: |x_sim - F_ext/S| < 1e-3 for all three stiffnesses")


if __name__ == "__main__":
    main()
```

## Effort-out vs motion-out on a shared plant

### Interface contracts before gains

Impedance here measures motion error and commands **effort**: `u=K_i(x_ref−x_meas)−D_i v_meas`. It needs a torque/force-capable actuator interface; merely publishing a position goal does not create that interface. Admittance measures external force and integrates a virtual model `M_a yddot+D_a ydot+K_a y=F_ext,meas`, producing the **motion** reference `x_cmd=x_ref+y`. An inner position/velocity tracking loop must then realise that motion. That inner loop has finite bandwidth and effort limits: it is not a magic position assignment.

The opened [Jazzy admittance-controller documentation](https://control.ros.org/jazzy/doc/ros2_controllers/admittance_controller/doc/userdoc.html) specifies F/T sensor state interfaces, motion command interfaces (position/velocity/acceleration), and position/velocity references for chaining. Check the installed version when wiring a real controller. Our two illustrative loops are not a reproduction of that six-axis controller. Default SO-101 still means **Present Load proxy + synthetic admittance toys**, not calibrated force or a promise of torque mode. External F/T hardware remains elective, not a required purchase; live controller experiments are **本页未运行 (not run on this page)**.

### One mechanical plant, two controllers

Both conditions use `m xddot = u + F_disturbance − b xdot − k x + F_wall`, with m=1.0 kg, b=4.0 N·s/m, k=20.0 N/m, wall at 0.04 m and wall stiffness 1800.0 N/m. The wall only opposes penetration; it does not pull when separated. Both start at rest, receive the same 2.0 N disturbance between 1.2 and 1.4 s, and replay the **same pre-generated motion/force measurement noise**. Physical states diverge through feedback, not through different noise draws.

The reference steps to 0.065 m at 0.5 s and returns to zero at 2.5 s. Impedance uses K_i=120.0 N/m, D_i=16.0 N·s/m. Admittance uses virtual mass 1.5 kg, damping 25.0 N·s/m, stiffness 100.0 N/m; its inner servo uses 300.0 N/m and 30.0 N·s/m. Both effort commands clip at ±20.0 N. Example: a −2.0 N external force would produce a steady virtual offset −0.020 m, but the **physical** displacement also depends on inner tracking and wall/plant forces. The virtual mass is not a replacement for the shared physical mass.

Integration is semi-implicit Euler at 0.001 s; the wall/servo stiffness sets the fastest scales. Smaller dt is a numerical convergence check, not higher real control bandwidth. No sensor filtering, communications delay, passivity guarantee, hardware friction or watchdog is modelled. Before real contact, validate those omissions and limits, not just these gains.

### Measured quantities and limits of the comparison

Peak contact force is the maximum physical wall spring force, penetration is its maximum compression. Settling is measured **after the return at 2.5 s**, requiring position within 0.001 m and speed within 0.005 m/s for the remainder of the simulated horizon; `not_settled` means no such tail. It is not a wall-contact settling-time claim. Neither the modelled N nor the noise are measured STS3215 forces.

```python
#!/usr/bin/env python3
"""Effort-out impedance vs motion-out admittance on one mechanical plant.
Same mass/damper/spring/wall, disturbance schedule and measurement noise.
Admittance output goes through an explicitly modelled motion-tracking servo;
impedance requires an effort-capable actuator. Not a safety ranking.
Synthetic N only: no STS3215 Present Load conversion, no F/T hardware.
"""
import math
import random

SEED = 37
DT, STEPS = 0.001, 6000
M, B, K = 1.0, 4.0, 20.0
WALL, K_WALL = 0.04, 1800.0
EFFORT_LIMIT = 20.0
RELEASE = 2.5


def clamp(x, limit):
    return max(-limit, min(limit, x))


def simulate(mode, noise):
    x = v = y = vy = 0.0
    peak = penetration = 0.0
    last_unsettled = RELEASE
    for k, (nx, nv, nf) in enumerate(noise):
        t = k * DT
        ref = 0.065 if 0.5 <= t < RELEASE else 0.0
        disturbance = 2.0 if 1.2 <= t < 1.4 else 0.0
        wall_force = -K_WALL * max(0.0, x - WALL)
        xm, vm = x + nx, v + nv
        measured_external = wall_force + disturbance + nf
        if mode == "impedance":
            # Effort command from motion error, not a position interface.
            effort_command = 120.0 * (ref - xm) - 16.0 * vm
        else:
            # Virtual mass/damper/spring offset driven by measured external force.
            ay = (measured_external - 25.0 * vy - 100.0 * y) / 1.5
            vy += ay * DT
            y += vy * DT
            motion_command = ref + y
            # Separate inner motion servo converts motion command into effort.
            effort_command = 300.0 * (motion_command - xm) + 30.0 * (vy - vm)
        u = clamp(effort_command, EFFORT_LIMIT)  # same actuator effort limit
        # Common physical plant; semi-implicit Euler, not ideal motion tracking.
        a = (u + disturbance + wall_force - B * v - K * x) / M
        v += a * DT
        x += v * DT
        pen = max(0.0, x - WALL)
        peak = max(peak, K_WALL * pen)
        penetration = max(penetration, pen)
        if t >= RELEASE and (abs(x) > 0.001 or abs(v) > 0.005):
            last_unsettled = t + DT
    settled = abs(x) <= 0.001 and abs(v) <= 0.005
    return peak, penetration, last_unsettled - RELEASE if settled else None


def main():
    rng = random.Random(SEED)
    noise = [(rng.gauss(0, 0.0001), rng.gauss(0, 0.0005), rng.gauss(0, 0.02))
             for _ in range(STEPS)]
    print(f"seed={SEED} dt_s={DT} plant_mass_kg={M} shared_noise=True")
    print("mode peak_contact_N max_penetration_m settling_after_release_s")
    for mode in ("impedance", "admittance"):
        force, pen, settling = simulate(mode, noise)
        assert math.isfinite(force) and pen >= 0
        settling_text = f"{settling:.3f}" if settling is not None else "not_settled"
        print(f"{mode} {force:.6f} {pen:.6f} {settling_text}")
    print("impedance_output=effort admittance_output=motion safety_ranking=none")


if __name__ == "__main__":
    main()
```

## Common mistakes

- **Reading Present Load as newtons.** It is duty-cycle load %.
- **Misspelling Feetech as Featech.** The spelling is **Feetech**.
- **Cranking position gain into a contact.** Retreat / admit first; add a real F/T sensor only as elective hardware.
- **Quoting overload/temperature trip numbers from memory.** This page does not provide them.
