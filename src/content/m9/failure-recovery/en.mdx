Open-loop skill sequences fail in the real world: empty grasps, slips, blocked goals. <Term id="inner-monologue">Inner Monologue</Term> feeds success detection, scene descriptions or human feedback back into a language model as **text** for closed-loop replanning — **without further training** that LLM. In engineering terms, the same idea lands as Sequence / Fallback / Retry on a behaviour tree: this lesson's <Term id="behaviour-tree-recovery">behaviour-tree recovery</Term>.

| This lesson | **Skill-semantic failures** (missed grasp, object gone) | this page |

A watchdog will not notice “gripper still looks open after a close”; that is semantic, and needs a detect signal plus retry / backup skill.

## Three BT building blocks

- **Sequence:** every child must succeed; one failure fails the sequence.
- **Fallback:** try children in order; the first success wins (“primary, else backup”).
- **Retry(n):** tick the child up to n times.

BehaviorTree.CPP emphasises async Actions and runtime XML; this toy is a tiny isomorphic implementation — it does not link real BT.CPP.

## CPU: after two grasp fails, take the backup

Tree shape:

```text
Fallback(root)
  Sequence(primary)
    Retry(GraspPrimary, n=2)
    Lift
  Sequence(backup)
    GraspBackup
    Lift
```

Injection: `GraspPrimary` returns FAILURE on the first two calls. After Retry exhausts, Fallback ticks `GraspBackup`.

```python
#!/usr/bin/env python3
"""recovery_bt_toy.py: mini behaviour tree with grasp retry + fallback (stdlib).

Tree (tick until SUCCESS or root FAILURE):
  Fallback(root)
    Sequence(primary)
      Retry(n=2) → Action(GraspPrimary)   # fails twice, then would fail
      Action(Lift)
    Sequence(backup)
      Action(GraspBackup)                 # succeeds
      Action(Lift)

Injected: GraspPrimary fails on attempts 1 and 2 (returns FAILURE). After
Retry exhausts, Fallback ticks the backup sequence. Prints a decision trace.

Contrasts with Month 4 Nav2 recoveries (map clear / spin) and Month 8 watchdog
(command timeout): this toy is *semantic skill* failure, not packet silence.
usage: python3 recovery_bt_toy.py
"""
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Callable, List

SUCCESS, FAILURE, RUNNING = "SUCCESS", "FAILURE", "RUNNING"


@dataclass
class Trace:
    lines: List[str] = field(default_factory=list)

    def log(self, msg: str) -> None:
        self.lines.append(msg)
        print(msg)


class Node:
    def tick(self, tr: Trace) -> str:
        raise NotImplementedError


@dataclass
class Action(Node):
    name: str
    fn: Callable[[Trace], str]

    def tick(self, tr: Trace) -> str:
        status = self.fn(tr)
        tr.log(f"action {self.name} -> {status}")
        return status


@dataclass
class Retry(Node):
    child: Node
    max_attempts: int
    name: str = "Retry"

    def tick(self, tr: Trace) -> str:
        for attempt in range(1, self.max_attempts + 1):
            tr.log(f"retry {self.name} attempt={attempt}/{self.max_attempts}")
            status = self.child.tick(tr)
            if status == SUCCESS:
                return SUCCESS
            if status == RUNNING:
                return RUNNING
        tr.log(f"retry {self.name} exhausted -> FAILURE")
        return FAILURE


@dataclass
class Sequence(Node):
    children: List[Node]
    name: str = "Sequence"

    def tick(self, tr: Trace) -> str:
        tr.log(f"sequence {self.name} enter")
        for ch in self.children:
            status = ch.tick(tr)
            if status != SUCCESS:
                tr.log(f"sequence {self.name} -> {status}")
                return status
        tr.log(f"sequence {self.name} -> SUCCESS")
        return SUCCESS


@dataclass
class Fallback(Node):
    children: List[Node]
    name: str = "Fallback"

    def tick(self, tr: Trace) -> str:
        tr.log(f"fallback {self.name} enter")
        for ch in self.children:
            status = ch.tick(tr)
            if status == SUCCESS:
                tr.log(f"fallback {self.name} -> SUCCESS")
                return SUCCESS
            if status == RUNNING:
                return RUNNING
        tr.log(f"fallback {self.name} -> FAILURE")
        return FAILURE


def main() -> None:
    grasp_attempts = {"n": 0}

    def grasp_primary(tr: Trace) -> str:
        grasp_attempts["n"] += 1
        # Fail the first two calls; would succeed on a 3rd but Retry max=2.
        if grasp_attempts["n"] <= 2:
            return FAILURE
        return SUCCESS

    def grasp_backup(tr: Trace) -> str:
        return SUCCESS

    def lift(tr: Trace) -> str:
        return SUCCESS

    tree = Fallback(
        name="root",
        children=[
            Sequence(
                name="primary",
                children=[
                    Retry(
                        name="grasp_primary",
                        max_attempts=2,
                        child=Action("GraspPrimary", grasp_primary),
                    ),
                    Action("Lift", lift),
                ],
            ),
            Sequence(
                name="backup",
                children=[
                    Action("GraspBackup", grasp_backup),
                    Action("Lift", lift),
                ],
            ),
        ],
    )

    tr = Trace()
    print("bt=Fallback(Sequence(Retry(GraspPrimary,2),Lift), Sequence(GraspBackup,Lift))")
    status = tree.tick(tr)
    print(f"root_status={status}")
    print(f"grasp_primary_attempts={grasp_attempts['n']}")
    print(f"trace_lines={len(tr.lines)}")
    # Key assertions mirrored in expected/
    used_backup = any("GraspBackup" in line for line in tr.lines)
    print(f"used_backup={used_backup}")
    print(
        f"ok: root SUCCESS after GraspPrimary failed twice and GraspBackup ran "
        f"({status == SUCCESS and grasp_attempts['n'] == 2 and used_backup})"
    )


if __name__ == "__main__":
    main()
```

## Escalation budget: when to stop retrying and hand off

“Cap retries, then Fallback to another skill or ask a human” hides a ladder with a price on every rung: **detect → retry (capped) → backup skill → human handoff → abort**. BehaviorTree.CPP's [`RetryUntilSuccessful`](https://www.behaviortree.dev/docs/nodes-library/DecoratorNode) takes `num_attempts`, and `-1` means infinite retries; its [Fallback](https://www.behaviortree.dev/docs/nodes-library/FallbackNode) ticks the next child after a FAILURE and returns FAILURE when the last child fails. Neither node decides **who pays** after the tree runs out. That is the escalation budget.

| Rung | Toy cost | Risk |
| --- | --- | --- |
| detect (gripper-empty check after every grasp) | 1 s | a wrong detect poisons every arm alike |
| primary grasp | 8 s | repeating a failed grasp into the same clutter |
| backup grasp | 12 s | different approach, new failure modes |
| human handoff | 45 s robot wait + 1.5 operator min | operator budget is finite; some handoffs still fail |
| abort | 5 s | task lost, but safe and visible |

### Fair setup

`recovery_escalate_budget_toy.py` is **synthetic** and stdlib only. Each seed draws one stream of 40 tasks with a hidden case — `transient` (primary 0.6, backup 0.6), `primary_blocked` (primary never, backup 0.7), `needs_human` (only a person, 0.9), `unrecoverable` (nobody) — and **pre-draws every outcome** (common random numbers). All three arms see the same stream, the same outcomes and the same detect signal; only the policy differs:

- **A `infinite_retry`:** retry the primary until the 120 s per-task deadline (a bookkeeping limit, not a watchdog).
- **B `retry_fallback`:** `Retry(primary, 2)` → backup once → FAILURE (this lesson's BT shape).
- **C `escalate_ladder`:** B's ladder, then a human handoff while the stream's operator budget (6) lasts, else abort.

`unsafe_retry` counts attempts of a skill that already failed 3 times in the task. Five seeds; mean±sd.

### Reading the result

- **A** succeeds only when the primary eventually works (19.2/40). On `primary_blocked` and worse it livelocks (20.8 tasks) and racks up 209 unsafe retries and the longest makespan. Infinite retry is not persistence; it is a missing budget.
- **B** recovers 26.2/40 **autonomously**, with zero operator minutes and the shortest makespan. Fallback is where most recoveries come from.
- **C** keeps B's 26.2 autonomous successes and adds about four through people — for 6 calls, 9 operator minutes, +250 s makespan, and about 2 of 6 handoffs that still fail (the unrecoverable cases). The budget sweep shows the trade: budget 0 reproduces B exactly; budget 20 reaches 35.6 successes for 13.8 calls.

Which arm is “best” depends on what an operator minute costs you relative to a lost task; the toy does not pick one. Escalation must not be the only success path — the autonomous rungs carry most of the load here.

### Handoff schema

A handoff the person can act on needs at least: `escalate_reason` (why the ladder stopped), `last_obs_summary` (what the robot last saw), and `attempted_skills[]` (what was already tried, in order). The toy prints its first record.
```python
#!/usr/bin/env python3
"""recovery_escalate_budget_toy.py: infinite retry vs Retry+Fallback vs escalation ladder.

Synthetic, stdlib only. One shared task stream per seed: every task has a
hidden failure case and pre-drawn outcomes (common random numbers), so all
three arms see the SAME failures and the SAME detect signal (a post-grasp
"object in gripper" check, assumed correct here). Arms differ only in policy:
  A infinite_retry      retry the primary grasp until the episode deadline
  B retry_fallback      Retry(primary, 2) -> backup grasp once -> FAILURE
  C escalate_ladder     detect -> Retry(primary, 2) -> backup once -> human
                        handoff (if operator budget left) -> abort
Explicit rung costs (seconds of robot time, operator minutes) are toy values.
unsafe_retry = any attempt of a skill that has already failed RISK_AFTER times
in this task (a stand-in for "repeating a failed grasp into the same clutter").
usage: python3 recovery_escalate_budget_toy.py
"""
from __future__ import annotations

import json
import random
import statistics

SEEDS = (0, 1, 2, 3, 4)
TASKS = 40
# Hidden case mix (probabilities) and per-attempt success probabilities.
CASES = (("transient", 0.50), ("primary_blocked", 0.25), ("needs_human", 0.15), ("unrecoverable", 0.10))
P_SUCCESS = {  # case -> (primary, backup, human)
    "transient": (0.6, 0.6, 0.95),
    "primary_blocked": (0.0, 0.7, 0.95),
    "needs_human": (0.0, 0.0, 0.90),
    "unrecoverable": (0.0, 0.0, 0.00),
}
COST_S = {"detect": 1.0, "primary": 8.0, "backup": 12.0, "handoff_wait": 45.0, "abort": 5.0}
OPERATOR_MIN = 1.5      # operator minutes per handoff
DEADLINE_S = 120.0      # per-task episode bookkeeping deadline (not a watchdog)
RETRY_CAP = 2
RISK_AFTER = 3
OPERATOR_BUDGET = 6     # handoffs allowed per 40-task stream (arm C)
MAX_DRAWS = 40          # pre-drawn uniforms per skill per task
ARMS = ("A_infinite_retry", "B_retry_fallback", "C_escalate_ladder")


def make_stream(seed):
    rng = random.Random(seed)
    stream = []
    for i in range(TASKS):
        r, acc, case = rng.random(), 0.0, CASES[-1][0]
        for name, p in CASES:
            acc += p
            if r < acc:
                case = name
                break
        draws = {k: [rng.random() for _ in range(MAX_DRAWS)] for k in ("primary", "backup", "human")}
        stream.append({"id": i, "case": case, "draws": draws})
    return stream


def attempt(task, skill, n):
    p = P_SUCCESS[task["case"]][("primary", "backup", "human").index(skill)]
    return task["draws"][skill][n] < p


def run_task(arm, task, ops_left):
    t, tried, fails = 0.0, [], {"primary": 0, "backup": 0}
    out = {"success": False, "operator_calls": 0, "unsafe": 0, "livelock": False,
           "aborted": False, "handoff": None}

    def try_skill(skill):
        nonlocal t
        if fails[skill] >= RISK_AFTER:
            out["unsafe"] += 1
        n = fails[skill]
        t += COST_S[skill] + COST_S["detect"]
        tried.append(skill)
        ok = attempt(task, skill, n)
        if not ok:
            fails[skill] += 1
        return ok

    if arm == "A_infinite_retry":
        while t + COST_S["primary"] + COST_S["detect"] <= DEADLINE_S:
            if try_skill("primary"):
                out["success"] = True
                break
        else:
            out["livelock"] = True
        out["time"] = t
        return out
    for _ in range(RETRY_CAP):
        if try_skill("primary"):
            out["success"] = True
            out["time"] = t
            return out
    if try_skill("backup"):
        out["success"] = True
        out["time"] = t
        return out
    if arm == "C_escalate_ladder" and ops_left > 0:
        out["operator_calls"] = 1
        out["handoff"] = {
            "escalate_reason": "retry_cap_and_backup_exhausted",
            "last_obs_summary": f"task {task['id']}: gripper empty after {len(tried)} attempts",
            "attempted_skills": list(tried),
        }
        t += COST_S["handoff_wait"]
        if attempt(task, "human", 0):
            out["success"] = True
            out["time"] = t
            return out
    t += COST_S["abort"]
    out["aborted"] = True
    out["time"] = t
    return out


def run_stream(arm, seed, budget=OPERATOR_BUDGET):
    ops_left = budget
    tot = {"success": 0, "operator_calls": 0, "unsafe": 0, "livelock": 0, "aborted": 0,
           "makespan_s": 0.0, "auto_success": 0, "budget_exhausted_aborts": 0,
           "handoff_failed": 0}
    first_handoff = None
    for task in make_stream(seed):
        exhausted = arm == "C_escalate_ladder" and ops_left == 0
        r = run_task(arm, task, ops_left)
        ops_left -= r["operator_calls"]
        tot["success"] += r["success"]
        tot["auto_success"] += r["success"] and not r["operator_calls"]
        tot["operator_calls"] += r["operator_calls"]
        tot["handoff_failed"] += r["operator_calls"] and not r["success"]
        tot["unsafe"] += r["unsafe"]
        tot["livelock"] += r["livelock"]
        tot["aborted"] += r["aborted"]
        tot["budget_exhausted_aborts"] += exhausted and r["aborted"]
        tot["makespan_s"] += r["time"]
        if r["handoff"] and first_handoff is None:
            first_handoff = r["handoff"]
    return tot, first_handoff


def ms(vals, f=".1f"):
    return f"{statistics.mean(vals):{f}}±{statistics.pstdev(vals):{f}}"


def main():
    print(f"Synthetic stream: {TASKS} tasks x {len(SEEDS)} seeds; cases {dict(CASES)}")
    print(f"Rung costs s: {COST_S}; operator {OPERATOR_MIN} min/handoff; "
          f"retry_cap={RETRY_CAP} risk_after={RISK_AFTER} deadline={DEADLINE_S}s operator_budget={OPERATOR_BUDGET}")
    cases = [sum(t["case"] == c for t in make_stream(s)) for s in SEEDS for c, _ in CASES]
    print("case counts per seed:", [cases[i:i + 4] for i in range(0, len(cases), 4)])
    print("arm success auto_success operator_calls operator_min unsafe_retry livelock aborted budget_exhausted_aborts makespan_s")
    sample = None
    for arm in ARMS:
        rows = [run_stream(arm, s) for s in SEEDS]
        if arm == "C_escalate_ladder":
            sample = rows[0][1]
        t = [r[0] for r in rows]
        print(arm, ms([x["success"] for x in t]), ms([x["auto_success"] for x in t]),
              ms([x["operator_calls"] for x in t]), ms([x["operator_calls"] * OPERATOR_MIN for x in t]),
              ms([x["unsafe"] for x in t]), ms([x["livelock"] for x in t]), ms([x["aborted"] for x in t]),
              ms([x["budget_exhausted_aborts"] for x in t]), ms([x["makespan_s"] for x in t], ".0f"))
    for b in (0, 6, 20):
        t = [run_stream("C_escalate_ladder", s, b)[0] for s in SEEDS]
        print(f"C operator_budget={b}: success {ms([x['success'] for x in t])} operator_calls "
              f"{ms([x['operator_calls'] for x in t])} handoff_failed {ms([x['handoff_failed'] for x in t])} "
              f"makespan_s {ms([x['makespan_s'] for x in t], '.0f')}")
    print("first handoff record (seed 0):", json.dumps(sample, sort_keys=True))
    print("Same stream, outcomes and detect signal for every arm; no winner is declared.")


if __name__ == "__main__":
    main()
```

## Common mistakes

- **Expecting the watchdog to cover empty grasps.** Commands often still arrive on time.
- **Retry forever.** Cap retries, then Fallback to another skill or ask a human.
- **Omitting the detect signal.** No observable signal, no automatic recovery.
- **Re-teaching all of Nav2 recovery tuning.** Revisit Month 4; this lesson only cross-links.
