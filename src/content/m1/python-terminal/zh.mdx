## 为什么机器人离不开终端

一台 ROS 2 机器人不是“一个程序”，而是一群叫节点（node）的小程序：一个读摄像头，一个把轮速指令变成电机电压，一个发布电池状态。它们通常从终端启动，日志打在终端里，出问题时也是你在终端里把某一个节点停掉。测试脚本、标定脚本、数据记录脚本，都是普通的 Python 文件，用 `python3` 运行。机器人上的计算机——树莓派（Raspberry Pi）、Jetson 或迷你主机——通常跑 Linux，而且常常没有接显示器；你通过 `ssh` 登进去，看文字、敲命令。

因此在现场调试、没有图形界面时，终端仍是唯一可用的界面。你不需要背一百条命令，只需要一小套词汇。学完这一课，你会有三个能跑的脚本：欧姆定律计算器、电阻类、以及把测量结果写成 <Term id="json">JSON</Term> 的记录器；也会知道怎样安装依赖而不影响系统其他部分。

## 准备：一个终端，一个 Python

macOS 打开“终端”（应用程序 → 实用工具）。Linux 打开发行版自带的终端，Bash 和 Zsh 都可以。Windows 有两条路：

- **WSL2 + Ubuntu（推荐）**：WSL2 在 Windows 里跑真正的 Linux 内核。ROS 2 官方支持 Ubuntu，多数机器人教程也假设 Linux 路径。用管理员权限打开 PowerShell，运行 `wsl --install`，需要时重启，然后从开始菜单打开 **Ubuntu**。
- **Git Bash**：更轻量，提供 Bash 风格和常用 Unix 命令。本课够用，但它不是以后跑 ROS 2 的真正 Linux 环境。

检查解释器：

```bash
python3 --version
```

需要 **3.10 或更高**。Windows 原生环境通常用 `py`：

```bash
py --version
```

macOS 上的 `python3` 可能来自 Xcode Command Line Tools；如果没有，去 python.org 安装。还要记住：`python` 和 `python3` 不一定是同一个程序。很多 Linux 系统根本没有 `python`，有些系统的 `python` 还是 Python 2。macOS/Linux 用 `python3`，Windows 用 `python` 或 `py`，并且保持一致。

## 虚拟环境与 pip

一个 Python 安装自带一套共享的第三方包。如果每个项目都往里装，两个项目需要同一个库的不同版本就会冲突，一次不经意的升级可能使原本可用的脚本失效。**虚拟环境（virtual environment，venv）** 是一个私有目录，里面有属于自己的 Python 链接和包目录。激活后，这个 shell 里的 `python` 和 `pip` 都指向私有副本。

```bash
cd ~/robotics/month1
python3 -m venv .venv
source .venv/bin/activate
```

Windows 原生环境（PowerShell 或 cmd）的激活命令是：

```text
.venv\Scripts\activate
```

提示符前面会出现 `(.venv)`。这个标记不是装饰：它告诉你下一条 `pip install` 会装到哪里。接着升级 <Term id="pip">pip</Term>、装一个包：

```bash
python -m pip install --upgrade pip
pip install rich
```

`python -m pip` 保证 pip 属于你刚调用的那个 Python，能避开“我明明装了，Python 却找不到”的经典问题。`rich` 是用于格式化终端输出的小型库；`numpy` 是以后会用到的数值计算库。把当前依赖固定下来，才能复现：

```bash
pip freeze > requirements.txt
pip install -r requirements.txt
deactivate
```

第一条把包名和版本写进文本文件；第二条在另一台机器或新建的 <Term id="venv">venv</Term> 里照单重装；`deactivate` 退出环境，`(.venv)` 消失。

两条规则：**绝不把 `.venv` 提交到 Git**——它含二进制和绝对路径、体积大，而且用 `requirements.txt` 就能重建；把 `.venv/` 写进 `.gitignore`。**不要因为嫌激活麻烦就全局安装项目依赖**，那正是“一次无关升级导致机器人脚本失效”的常见原因。

## 用 Python 实现命令行工具：ohm.py

这个脚本从电压和电阻算电流，也算两个电阻分压后的输出电压。它用 <Term id="argparse">`argparse`</Term> 做两个子命令。新建 `ohm.py`：

<CodeSource path="examples/month-1/python-terminal/ohm.py" />

```python
"""ohm.py — command-line Ohm's law and voltage divider calculator."""

import argparse
import sys


def current(volts: float, ohms: float) -> float:
    """Return the current, in amps, through a resistance at a given voltage."""
    if ohms <= 0:
        raise ValueError("ohms must be positive")
    return volts / ohms


def divider(vin: float, r1: float, r2: float) -> float:
    """Return the output voltage of a two-resistor divider, in volts."""
    if r1 <= 0 or r2 <= 0:
        raise ValueError("resistances must be positive")
    return vin * r2 / (r1 + r2)


def main() -> None:
    parser = argparse.ArgumentParser(
        description="Ohm's law and voltage divider calculator"
    )
    sub = parser.add_subparsers(dest="command", required=True)

    p_current = sub.add_parser("current", help="I = V / R, printed in mA")
    p_current.add_argument("--volts", type=float, required=True)
    p_current.add_argument("--ohms", type=float, required=True)

    p_divider = sub.add_parser("divider", help="Vout = Vin * R2 / (R1 + R2)")
    p_divider.add_argument("--vin", type=float, required=True)
    p_divider.add_argument("--r1", type=float, required=True)
    p_divider.add_argument("--r2", type=float, required=True)

    args = parser.parse_args()

    if args.command == "current":
        ma = current(args.volts, args.ohms) * 1000
        print(f"{ma:.1f} mA")
    elif args.command == "divider":
        v = divider(args.vin, args.r1, args.r2)
        print(f"{v:.3f} V")


if __name__ == "__main__":
    try:
        main()
    except ValueError as e:
        print(f"error: {e}", file=sys.stderr)
        sys.exit(1)
```

运行两个例子：

```bash
python ohm.py current --volts 5 --ohms 220
```

```text
22.7 mA
```

```bash
python ohm.py divider --vin 5 --r1 10000 --r2 4700
```

```text
1.599 V
```

手算核对。第一条：

```text
I = V / R = 5 V / 220 Ω = 0.022727... A
0.022727... A × 1000 = 22.727... mA
```

`{ma:.1f}` 保留一位小数，所以打印 `22.7 mA`。分压：

```text
Vout = Vin × R2 / (R1 + R2)
     = 5 V × 4700 Ω / (10 000 Ω + 4700 Ω)
     = 5 × 4700 / 14 700 V
     = 23 500 / 14 700 V
     = 1.598639... V
```

`{v:.3f}` 保留三位小数，得到 `1.599 V`。这就是组件那一课 Falstad 练习里的分压器，只是现在不打开浏览器也能算。

代码各部分的作用：

- **函数是“有名字的计算”**。`current(volts, ohms)` 收两个浮点数、返回一个浮点数。类型标注是给人看、给编辑器提示的，Python 运行时并不强制；文档字符串（docstring）就是 `help(current)` 显示的内容。
- **计算里 return，程序边缘才 print**。返回数字，测试、图形界面或另一个脚本都能复用；只在 `main()` 里打印一次，计算才保持可复用。
- **在边界做校验**。电阻为零或负数在这里没有物理意义，`raise ValueError` 用清楚的报错停下，而不是返回无穷大。
- **`argparse` 负责接口**。`add_subparsers(..., required=True)` 让 `current` 或 `divider` 必填；`type=float, required=True` 把文本转成浮点数，缺参数时给出提示。试试 `python ohm.py --help` 和 `python ohm.py divider --help`。
- **`if __name__ == "__main__":`** 只在文件被直接执行时运行命令行部分。别的脚本写 `from ohm import divider` 时，<Term id="function">函数</Term>能用，`main()` 不会自己跑。
- **最外层 `try`/`except`** 把故意的报错变成一句短消息，并以退出码 1 结束：

```text
$ python ohm.py current --volts 5 --ohms 0
error: ohms must be positive
```

`$` 是 shell 提示符，不是命令的一部分。退出码 1 告诉脚本或 CI：这条命令失败了。在加上 shebang 和可执行权限之前，用 `python ohm.py` 而不是 `./ohm.py`；显式指定解释器能消掉一大类“跑错 Python”的问题。

## 类：带误差范围的电阻

类（class）把数据和属于数据的操作绑在一起。电阻有标称值和误差，还能给出合理范围。Python 的 `@dataclass` 替我们省掉大量样板代码：

<CodeSource path="examples/month-1/python-terminal/resistors.py" />

```python
"""resistors.py — dataclass Resistor, series/parallel helpers."""

from dataclasses import dataclass


@dataclass
class Resistor:
    """A resistor with a nominal value and a tolerance (0.05 = 5 %)."""

    ohms: float
    tolerance: float = 0.05

    def min(self) -> float:
        """Lowest value within tolerance."""
        return self.ohms * (1 - self.tolerance)

    def max(self) -> float:
        """Highest value within tolerance."""
        return self.ohms * (1 + self.tolerance)


def series(*rs: Resistor) -> Resistor:
    """Resistors in series: values add up, absolute deviations (ohms x tolerance) add too."""
    if not rs:
        raise ValueError("series() needs at least one resistor")
    ohms = sum(r.ohms for r in rs)
    tolerance = sum(r.ohms * r.tolerance for r in rs) / ohms
    return Resistor(ohms=ohms, tolerance=tolerance)


def parallel(*rs: Resistor) -> Resistor:
    """Resistors in parallel: conductances add up."""
    if not rs:
        raise ValueError("parallel() needs at least one resistor")
    conductance = sum(1 / r.ohms for r in rs)
    return Resistor(ohms=1 / conductance)


if __name__ == "__main__":
    r2k2 = Resistor(2_200)
    print(r2k2)
    print(f"range: {r2k2.min():.0f}–{r2k2.max():.0f} Ω")

    result = parallel(Resistor(10_000), Resistor(10_000))
    print(f"parallel: {result.ohms:.0f} Ω")

    chain = series(Resistor(1_000), Resistor(4_700))
    print(f"series: {chain.ohms:.0f} Ω, range {chain.min():.0f}–{chain.max():.0f} Ω")
```

运行 `python resistors.py`：

```text
Resistor(ohms=2200, tolerance=0.05)
range: 2090–2310 Ω
parallel: 5000 Ω
series: 5700 Ω, range 5415–5985 Ω
```

第一行是 `@dataclass` 自动生成的 `__repr__`。`Resistor(2_200)` 调用自动生成的初始化方法，`ohms` 是 2200，`tolerance` 取默认 0.05。范围来自 ±5 % 的定义：

```text
min = 2200 Ω × (1 − 0.05) = 2200 Ω × 0.95 = 2090 Ω
max = 2200 Ω × (1 + 0.05) = 2200 Ω × 1.05 = 2310 Ω
```

金环电阻就是 ±5 % 的元件；用万用表实测，读数通常应落在这个窗口里。方法返回数字，所以能用在比较和测试里，而不只是打印给人看。

`*rs` 把任意多个参数收成一个元组。`series` 把阻值相加；误差不能按百分比相加，而应把绝对偏差（阻值 × 误差）相加。串联时两个 −5 % 的电阻整体仍然只偏低 5 %。以 1 kΩ ±5 % 和 4.7 kΩ ±5 % 为例：

```text
1 kΩ ±5 %   → 950–1050 Ω
4.7 kΩ ±5 % → 4465–4935 Ω
串联        → 5415–5985 Ω
(50 + 235) / 5700 = 0.05 = ±5 %
```

把两个百分比直接相加（10 %，5130–6270 Ω）是错误的：相对误差相加适用于乘积和商，不适用于和。`parallel` 用电导相加：

```text
1 / Rtotal = 1 / R1 + 1 / R2
```

两个 10 kΩ 并联：

```text
1 / Rtotal = 1 / 10 000 Ω + 1 / 10 000 Ω
           = 0.0001 + 0.0001 S
           = 0.0002 S
Rtotal = 1 / 0.0002 Ω = 5000 Ω
```

两个等值电阻并联，结果是一半——5 kΩ，不是 20 kΩ。注意代码里的 `parallel` 返回默认 5 % 误差，并没有合并输入误差；做最坏情况设计时要分别算上下限。

## 文件与 JSON：测量日志

万用表那一课要求你测 5 个电阻，并与色环读数比较。用脚本记录更好：带时间戳、可重复使用。JSON 是一种表示嵌套数据的文本格式——带字符串键的对象、数组、数字、字符串、布尔值和 null——几乎能直接对应 Python 的列表和字典。一条测量正好是字典，整个日志就是字典的列表。

<CodeSource path="examples/month-1/python-terminal/log.py" />

```python
"""log.py — append a measurement to measurements.json and check tolerance."""

import json
from datetime import datetime, timezone
from pathlib import Path

LOG_FILE = Path("measurements.json")


def load_measurements() -> list[dict]:
    """Read the log if it exists, else start with an empty list."""
    if LOG_FILE.exists():
        text = LOG_FILE.read_text(encoding="utf-8")
        return json.loads(text)
    return []


def save_measurements(measurements: list[dict]) -> None:
    """Write the whole list back, pretty-printed."""
    LOG_FILE.write_text(
        json.dumps(measurements, indent=2), encoding="utf-8"
    )


def record(part: str, expected_ohms: float, measured_ohms: float) -> dict:
    """Append one measurement and return that entry."""
    entry = {
        "part": part,
        "expected_ohms": expected_ohms,
        "measured_ohms": measured_ohms,
        "time": datetime.now(timezone.utc).isoformat(timespec="seconds"),
    }
    measurements = load_measurements()
    measurements.append(entry)
    save_measurements(measurements)
    return entry


def report_out_of_tolerance(measurements: list[dict], limit: float = 0.05) -> None:
    """Print every measurement that misses its nominal value by more than limit."""
    bad = 0
    for m in measurements:
        expected = m["expected_ohms"]
        measured = m["measured_ohms"]
        if expected == 0:
            continue
        error = abs(measured - expected) / expected
        if error > limit:
            bad += 1
            print(
                f"{m['part']}: expected {expected:.0f} Ω, "
                f"measured {measured:.0f} Ω → off by {error * 100:.1f} %"
            )
    print(f"{bad} of {len(measurements)} measurements out of {limit * 100:.0f} % tolerance")


if __name__ == "__main__":
    record("R1", 4700, 4688)
    print("Logged 1 measurement.")
    report_out_of_tolerance(load_measurements())
```


```text

0.002553... × 100 = 0.255... %
```

约 0.3 %，远在 ±5 % 之内。把调用改成 `record("R1", 4700, 4400)` 再运行，文件会保留两条记录，报告会列出超差的一条：

```text
Logged 1 measurement.
R1: expected 4700 Ω, measured 4400 Ω → off by 6.4 %
1 of 2 measurements out of 5 % tolerance
```

判断式是 `abs(measured - expected) / expected > 0.05`，因为 5 % 的元件允许往高或往低偏 5 %，通常以标称值作分母。

代码为什么这样写：

- **`Path("measurements.json")`** 是路径对象，有 `.exists()`、`.read_text()`、`.write_text()`，不用手工拼字符串，在 Windows 和 Linux 上行为也更可靠。
- **显式指定编码**。`encoding="utf-8"` 保证各平台读写一致；依赖系统默认编码，是出现莫名其妙的 Unicode 错误的常见原因。
- **读—改—写**。JSON 没有“追加一行”这种操作。脚本读出整个列表，追加一个字典，再用 `indent=2` 写回，人也能在 Git 里读。
- **`with open(...)` 是经典写法**。`Path.read_text()` / `write_text()` 会替你打开和关闭文件；需要更细的控制（逐行读取、往文本日志末尾追加）时，用 `with` 代码块——即使块内抛出异常，文件也会被自动关闭：

```python
with open("notes.txt", "a", encoding="utf-8") as f:
    f.write("R1 measured 4688 ohms\n")
```
- **时间戳让记录有用**：几个月后比较电阻漂移，或把日志和当时的工作台照片对上，都靠它。

## 采样与混叠：快的音调为什么会读成慢的

到目前为止，本课的脚本算的都是你自己输入的数。机器人代码算的大多是传感器**采样**得到的数：ADC、IMU 或编码器以固定频率 `fs` 读取一个连续信号。本节用刚学的 Python（`math`、`cmath`、`random`、字典和列表推导式）做一个小的数值实验，看采样保留了什么、打乱了什么。这是一个**合成**模型，采样是理想的，不是 ADC 实测。

<Resource id="wiki-nyquist-shannon" />

<Resource id="wiki-aliasing" />

**实际打开的来源（已读 HTML 正文）。**

- **Wikipedia — Nyquist–Shannon sampling theorem**，内容如下。如果函数 `x(t)` 不含高于 `B` 赫兹的频率，那么间隔小于 `1/(2B)` 秒的采样就能完全确定它，所以任何大于 `2B` 次每秒的采样率都足够；等价地说，给定 `fs` 时，带宽 `B < fs/2` 才保证能完全重建。阈值 `2B` 叫**奈奎斯特速率**（Nyquist rate），是输入信号的属性；`fs/2` 叫**奈奎斯特频率**（Nyquist frequency），是采样设备的属性。带宽太高时，重建会出现叫作混叠的缺陷。以原文为准。
- **Wikipedia — Aliasing**，内容如下。原信号含有高于奈奎斯特频率 `fs/2` 的分量时，重建信号里会出现原信号没有的低频分量；实正弦的混叠频率为 `|f + N·fs|`，重建在 `f = fs/2` 处折叠，这个点叫折叠频率。避免混叠的一般做法是在采样前加低通的抗混叠滤波器；被衰减的高频分量仍会产生混叠，但幅值通常低到不成问题。以原文为准。

### 奈奎斯特速率与折叠

<Formula label="足够的采样率">fs > 2 × B</Formula>

以 `fs` 采样频率为 `f` 的实音调，读到的是折叠后的频率，也就是 `f` 到最近的 `fs` 整数倍的距离：

<Formula label="折叠">f_seen = min(f mod fs, fs − (f mod fs))</Formula>

**算例。** `fs = 50 Hz` 时奈奎斯特频率是 25 Hz。40 Hz 的音调给出 `40 mod 50 = 40`，`50 − 40 = 10`，所以采样值和 10 Hz 音调完全一样。`fs = 200 Hz` 时，同一个 40 Hz 音调低于 `fs/2 = 100 Hz`，读成 40 Hz；但同一根线上的 150 Hz 振动折叠到 `200 − 150 = 50 Hz`，变成一个原本不在你要的频带里的峰。边界处：`fs = 100 Hz` 时，49 Hz（0.98 × fs/2）的音调读成 49 Hz，51 Hz（1.02 × fs/2）的音调也读成 49 Hz。

**为什么每个周期至少要约两个采样。** 要把一个正弦和更慢的正弦区分开，采样必须既抓到它上升也抓到它下降，所以每个周期要多于两个采样、每半个周期至少一个；少于这个数，就会有一个更慢的正弦恰好穿过同样的采样点，两者无法区分。

抗混叠前置滤波器是放在采样器**之前**的低通。本 toy 用 4 阶 Butterworth 的幅频特性，转折频率取采样率的四分之一：

<Formula label="前置滤波器幅值">|H(f)| = 1 / √(1 + (f / FC)^8), FC = 0.25 × fs</Formula>

`fs = 200 Hz`（`FC = 50 Hz`）时，toy 打印的增益为：30 Hz 0.9917，45 Hz 0.8361，80 Hz 0.1508，120 Hz 0.0301。去掉 150 Hz 振动的同一个滤波器，也会把你想要的 45 Hz 音调缩小 16 %。本 toy 里的**安全采样**指：对想要的音调 `fs > 2B`，**并且**经过声明的前置滤波器后，没有高于 `fs/2` 的音调仍超过 0.05 的峰值阈值。

**这里没有积分步长。** 每个采样值都在 `t = n / fs` 处用闭式算出，没有时间步进，所以不存在步长稳定性判据（独立测试会检查脚本里没有时间步长）。真正要紧的边界是奈奎斯特频率本身，测试在 `fs/2` 的 0.98 倍和 1.02 倍处检查它。

### 公平设置

`nyquist_aliasing_toy.py` 是**合成**模型，只用标准库。**模型假设**如下。理想冲激采样（没有孔径、没有抖动、没有量化；这**不是**对任何真实 ADC 的说法）；记录长 1 s，所以普通 DFT 的频率分辨率是 1 Hz；每个音调都落在整数赫兹上，所以低于 `fs/2` 的音调只落在一个频点上，没有泄漏；前置滤波器按稳态作用在每个音调的幅值上（不模拟它的相位延迟，因为这里所有指标都是频谱幅值）；标准差 0.01 的 ADC 噪声加在前置滤波器之后。

| 组 | 采样率 | 前置滤波器 |
|---|---|---|
| A_low | 50 Hz | 无 |
| B_aaf | 200 Hz | 4 阶 Butterworth，FC = 0.25 × fs |
| C_raw | 200 Hz | 无 |

**共用随机数**（common random numbers）的做法是，每个（情形，种子，试次）的目标音调频率、幅值和相位，干扰音调的频率和相位，以及噪声序列都只抽一次，三组共用（50 Hz 那组用前 50 个噪声样本）。5 个种子 × 8 个试次；每个指标先在一个种子内对试次取平均，再报告种子间的均值±标准差。`freq_err_Hz` 是最强 DFT 峰到目标音调的距离；`false_peaks` 统计超过 0.05、且不在目标音调 ±1 个频点内的频点数；`amp_err_%` 是最强峰处的幅值误差，所以音调折叠后，A 的幅值误差是**在混叠频率上**量的。

| 情形 | 目标音调 | 干扰 |
|---|---|---|
| slow_tone | 2–8 Hz | 无 |
| single_tone | 35–45 Hz | 无 |
| interferer | 10–30 Hz | 120–180 Hz，幅值 0.5 |
| near_edge | 70–90 Hz | 无 |

**看过结果后做的选择。** 第一次运行只有三种情形；`slow_tone` 是之后加的，用来展示 50 Hz 足够的情况。其他情形和所有参数（`FC = 0.25 × fs`、4 阶、阈值 0.05、噪声 0.01）都和第一次运行相同，所以三情形的结果就是下面打印的那三段。名为 `A_low` 的组在第一次运行时叫 `A_under`；因为它在 `slow_tone` 中并没有欠采样，所以改了名。

```python
            4th-order Butterworth magnitude |H(f)| = 1 / sqrt(1 + (f / FC)^8), FC = 0.25 fs,
            applied to each tone's amplitude (steady state; phase delay not modelled,
            the metrics are spectral magnitudes)
  C_raw     fs = FS_HIGH, no prefilter

slow_tone was added after the first run (the other regimes and every parameter are unchanged).

Common random numbers: per seed and trial the tone frequencies, amplitudes, phases
and the ADC noise sequence (sd 0.01, added after the prefilter, drawn once at the
longest record and truncated) are shared by every arm. No integration step: the
signal is evaluated in closed form at each sample instant.

Metrics per trial, averaged over TRIALS per seed: freq_err = |strongest DFT peak -
wanted tone| in Hz; false_peaks = bins above THRESH that are not the wanted tone
(+-1 bin); amp_err = |amplitude at the strongest peak - wanted amplitude| in %.
Safe sampling: fs > 2B and no tone above fs/2 left above THRESH after the declared
prefilter. Labels: tie = identical on every seed; numerically zero = |paired mean|
and sd both < 1e-9 (effectively a tie, no sign count); |m| <= sd = near-tie;
|m| > sd = consistent gap (small if |m| < 20 % of the smaller arm mean, else clear),
with a sign count. Real scope / ADC: 本页未运行. Wikipedia definitions: 以原文为准.
"""
import cmath
import math
import random

SEEDS = (0, 1, 2, 3, 4)
TRIALS = 8
FS_LOW, FS_HIGH = 50, 200  # Hz, 1 s records -> 1 Hz DFT bins
FC_RATIO = 0.25  # prefilter corner FC = FC_RATIO * fs
ORDER = 4
THRESH = 0.05  # peak threshold (amplitude units; full-scale tone = 1)
NOISE = 0.01
NUM_ZERO = 1e-9
ARMS = ("A_low", "B_aaf", "C_raw")
# name: wanted tone range (Hz), wanted amplitude range, interferer range (Hz) or None, interferer amplitude
REGIMES = {
    "slow_tone": ((2, 8), (0.5, 1.0), None, 0.0),
    "single_tone": ((35, 45), (0.5, 1.0), None, 0.0),
    "interferer": ((10, 30), (0.5, 1.0), (120, 180), 0.5),
    "near_edge": ((70, 90), (0.5, 1.0), None, 0.0),
}
ARM_FS = {"A_low": FS_LOW, "B_aaf": FS_HIGH, "C_raw": FS_HIGH}


def prefilter(f, fs):
    return 1.0 / math.sqrt(1.0 + (f / (FC_RATIO * fs)) ** (2 * ORDER))


def alias(f, fs):
    """Apparent frequency of a real tone f after sampling at fs (folding about fs/2)."""
    r = f % fs
    return min(r, fs - r)


def shared_trial(regime, seed, trial):
    """Common random numbers: one signal + one noise record per (regime, seed, trial)."""
    (lo, hi), (alo, ahi), intr, iamp = REGIMES[regime]
    rng = random.Random(f"{regime}-{seed}-{trial}")
    tones = [(rng.randint(lo, hi), rng.uniform(alo, ahi), rng.uniform(0.0, 2 * math.pi))]
    if intr:
        tones.append((rng.randint(*intr), iamp, rng.uniform(0.0, 2 * math.pi)))
    noise = [rng.gauss(0.0, NOISE) for _ in range(FS_HIGH)]
    return tones, noise


def sample(arm, tones, noise):
    fs = ARM_FS[arm]
    gains = [prefilter(f, fs) if arm == "B_aaf" else 1.0 for f, _, _ in tones]
    return [sum(g * a * math.sin(2 * math.pi * f * n / fs + p) for g, (f, a, p) in zip(gains, tones)) + noise[n]
            for n in range(fs)]


def spectrum(x):
    """One-sided amplitude spectrum, bins 1..N/2-1 (1 Hz apart for a 1 s record)."""
    n = len(x)
    return {k: 2.0 / n * abs(sum(v * cmath.exp(-2j * math.pi * k * i / n) for i, v in enumerate(x)))
            for k in range(1, n // 2)}


def trial_metrics(arm, tones, noise):
    spec = spectrum(sample(arm, tones, noise))
    f0, a0, _ = tones[0]
    peak = max(spec, key=lambda k: (spec[k], -k))
    false = sum(1 for k, v in spec.items() if v > THRESH and abs(k - f0) > 1)
    return {"freq": float(abs(peak - f0)), "false": float(false), "amp": 100.0 * abs(spec[peak] - a0) / a0}


def safe(arm, tones):
    fs = ARM_FS[arm]
    g = (lambda f: prefilter(f, fs)) if arm == "B_aaf" else (lambda f: 1.0)
    left = [f for f, a, _ in tones if f >= fs / 2 and g(f) * a > THRESH]
    return fs > 2 * tones[0][0] and not left


def mean_sd(xs):
    mu = sum(xs) / len(xs)
    return mu, math.sqrt(sum((x - mu) ** 2 for x in xs) / (len(xs) - 1))


def num(x):
    if x != 0.0 and abs(x) < 5e-5:
        return f"{x:.3e}"
    return f"{x:.4f}"


def sign_note(diffs, m):
    n, opp, zero = len(diffs), sum(1 for d in diffs if d * m < 0), sum(1 for d in diffs if d == 0)
    if opp == 0 and zero == 0:
        return f"same sign on all {n} seeds"
    if opp == 0:
        return f"no seed has the opposite sign, {zero} of {n} equal"
    note = f"{opp} of {n} seeds {'has' if opp == 1 else 'have'} the opposite sign"
    return note + (f", {zero} of {n} equal" if zero else "")


def verdict(xa, xb):
    diffs = [a - b for a, b in zip(xa, xb)]
    if all(d == 0.0 for d in diffs):
        return "0.0000+-0.0000: tie: identical on every seed"
    m, s = mean_sd(diffs)
    if abs(m) < NUM_ZERO and s < NUM_ZERO:
        return f"{num(m)}+-{num(s)}: numerically zero (floating-point residue), effectively a tie"
    if abs(m) <= s:
        label = "near-tie / small gap, within seed noise (|m| <= sd)"
    elif abs(m) < 0.2 * min(abs(mean_sd(xa)[0]), abs(mean_sd(xb)[0])):
        label = "small but consistent gap, not a tie (|m| > sd)"
    else:
        label = "clear gap, not a tie (|m| > sd)"
    return f"{num(m)}+-{num(s)}: {label}; {sign_note(diffs, m)}"


def main():
    print("Synthetic sampling toy; ideal impulse sampling + plain DFT; shared tones / phases / ADC noise; not a real ADC")
    print(f"seeds={len(SEEDS)} trials={TRIALS} record=1 s fs_low={FS_LOW} Hz fs_high={FS_HIGH} Hz "
          f"prefilter Butterworth order {ORDER} FC={FC_RATIO} fs threshold={THRESH} noise sd={NOISE}; no time step (closed-form samples)")
    print(f"folding check: fs=100 Hz, tone 49 Hz -> {alias(49, 100)} Hz, tone 51 Hz -> {alias(51, 100)} Hz, "
          f"tone 150 Hz -> {alias(150, 100)} Hz; fs=200 Hz, tone 150 Hz -> {alias(150, 200)} Hz")
    print(f"prefilter gain at fs=200 Hz: 30 Hz {prefilter(30, 200):.4f}, 45 Hz {prefilter(45, 200):.4f}, "
          f"80 Hz {prefilter(80, 200):.4f}, 120 Hz {prefilter(120, 200):.4f}, 180 Hz {prefilter(180, 200):.4f}")
    print("regime arm freq_err_Hz false_peaks amp_err_%  safe_trials  (mean+-sd over seeds of per-seed trial means)")
    for regime in REGIMES:
        (lo, hi), _, intr, iamp = REGIMES[regime]
        print(f"{regime} (wanted {lo}..{hi} Hz" + (f", interferer {intr[0]}..{intr[1]} Hz amp {iamp}" if intr else "") + ")")
        res = {a: [] for a in ARMS}
        nsafe = {a: 0 for a in ARMS}
        for seed in SEEDS:
            per = {a: [] for a in ARMS}
            for trial in range(TRIALS):
                tones, noise = shared_trial(regime, seed, trial)
                for a in ARMS:
                    per[a].append(trial_metrics(a, tones, noise))
                    nsafe[a] += safe(a, tones)
            for a in ARMS:
                res[a].append({k: sum(t[k] for t in per[a]) / TRIALS for k in ("freq", "false", "amp")})
        for a in ARMS:
            cells = " ".join("{}+-{}".format(*map(num, mean_sd([r[k] for r in res[a]]))) for k in ("freq", "false", "amp"))
            print(f"  {a} fs={ARM_FS[a]} {cells}  safe {nsafe[a]}/{len(SEEDS) * TRIALS}")
        for x, y in (("A_low", "B_aaf"), ("C_raw", "B_aaf")):
            for k in ("freq", "false", "amp"):
                print(f"  paired {x[0]}-{y[0]} {k}: {verdict([r[k] for r in res[x]], [r[k] for r in res[y]])}")
    print("slow_tone: 50 Hz is already above 2B, so the low rate reads the tone as well as the high one")
    print("single_tone: below 2B the tone folds to fs - f; above 2B the prefilter costs passband droop at 35..45 Hz")
    print("interferer: without a prefilter the 120..180 Hz tone folds into 20..80 Hz and reads as a real peak")
    print("near_edge: a corner at 0.25 fs eats a 70..90 Hz wanted tone; fs > 2B is not enough with a real filter")
    print("No winner declared: an anti-alias filter needs fs well above 2B so its corner clears the band you want")
    print("Real scope / ADC: 本页未运行; Wikipedia definitions 以原文为准")


if __name__ == "__main__":
    main()
```
